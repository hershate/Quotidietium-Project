# 食物模板

> 适用于创建带有自定义饥饿值、效果和消耗行为的食物/消耗品。
> 在 Minecraft 1.21.2+ 中，推荐使用 Components 方式定义食物属性。

---

## Minecraft 1.21.2+ 食物配置（推荐）

```yaml
# =============================================================================
# 自定义食物 - 使用 Components 方式（1.21.2+）
# =============================================================================
custom_food:
  displayname: "<gradient:#FF8800:#FFAA00>能量面包"
  material: BREAD                    # 推荐材质: COOKED_BEEF, APPLE, BREAD
                                     #           GOLDEN_APPLE, CARROT
                                     #           或 PAPER（完全自定义）

  Pack:
    generate_model: true
    parent_model: "item/generated"   # 食物使用 generated
    textures:
      - custom_food.png

  # ---------------------------------------------------------------------------
  # 食物组件 - 控制营养值和饱食度
  # ---------------------------------------------------------------------------
  Components:
    food:
      nutrition: 8                   # 恢复的饥饿值点数（半鸡腿）
      saturation: 12.8               # 饱和度修饰符（通常 = nutrition * 1.6）
      can_always_eat: false          # true=饱腹时也能食用

    # -------------------------------------------------------------------------
    # 消耗品组件 - 控制食用行为和效果
    # -------------------------------------------------------------------------
    consumable:
      consume_seconds: 1.6           # 食用时间（秒）
      animation: EAT                 # 动画类型: EAT, DRINK, BLOCK, BOW
      sound: entity.generic.eat      # 食用时的声音
      has_consume_particles: true    # 是否显示食用粒子
      on_consume_effects:            # 食用后触发的效果列表
        - type: apply_effects        # 应用药水效果
          effects:
            minecraft:regeneration:
              duration: 100          # 持续时间（刻，100=5秒）
              amplifier: 0           # 效果等级（0=等级I）
              ambient: false         # 是否为环境效果（半透明粒子）
              show_particles: true
              show_icon: true
          probability: 1.0           # 应用概率（1.0=100%）
```

## Minecraft 1.20.5 - 1.21 食物配置（旧版 Components）

```yaml
# 在 1.20.5 到 1.21 中，food 组件统一处理所有食物属性
custom_food_legacy:
  displayname: "<#FFAA00>旧版食物"
  material: COOKED_BEEF
  Pack:
    generate_model: true
    parent_model: "item/generated"
    textures:
      - custom_food.png
  Components:
    food:
      nutrition: 8
      saturation: 12.8
      can_always_eat: false
      eat_seconds: 1.6                          # 食用时间
      effects:                                  # 食用时的药水效果
        haste:
          duration: 200                         # 持续时间（刻）
          amplifier: 0
          ambient: false
          show_particles: true
          show_icon: true
          probability: 1.0
```

## 使用 Mechanics 方式（旧版，1.20.5 之前）

```yaml
# 在 1.20.5 之前的版本，使用 Mechanics 下的 food 机制
custom_food_mechanic:
  displayname: "<#FFAA00>传统自定义食物"
  material: COOKED_BEEF
  Pack:
    generate_model: true
    parent_model: "item/generated"
    textures:
      - custom_food.png
  Mechanics:
    food:
      hunger: 10                                # 恢复的饥饿值
      saturation: 10                            # 饱和度
      replacement:                              # 食用后返还的物品
        oraxen_item: bowl                       # 或 minecraft_type: BOWL
      effect_probability: 0.35                  # 效果触发概率
      effects:
        hunger:                                 # 药水效果类型
          amplifier: 1
          duration: 20                          # 持续时间（秒！注意不是刻）
          is_ambient: true
          has_particles: true
          has_icon: true
        night_vision:
          duration: 60
```

## 消耗品机制（非食物类消耗）

> 对于非食物但可右键消耗的物品（如药品、卷轴等）。

```yaml
# 消耗品药水
# consumable_potion:
#   displayname: "<gradient:#FF00FF:#8800FF>魔力药水"
#   material: POTION
#   Pack:
#     generate_model: true
#     parent_model: "item/generated"
#     textures:
#       - magic_potion.png
#   Mechanics:
#     consumable: {}                             # 右键消耗1个物品
#     consumable_potion_effects:                 # 消耗时应用的药水效果
#       speed:
#         amplifier: 1                           # 效果等级（0=等级I）
#         duration: 600                          # 持续时间（刻，600=30秒）
#         ambient: false
#         particles: true
#         icon: true
#       regeneration:
#         amplifier: 0
#         duration: 200
```

### consumable 组件的消耗后效果类型（1.21.2+）

| 效果类型 | 描述 | 关键参数 |
|----------|------|----------|
| `apply_effects` | 应用药水效果 | `effects`（映射表）, `probability` |
| `remove_effects` | 移除特定效果 | `effects`（效果ID列表） |
| `clear_all_effects` | 清除所有药水效果 | 无 |
| `teleport_randomly` | 随机传送玩家 | `diameter`（默认16） |
| `play_sound` | 播放声音 | `sound` |

## 完整示例：带多种效果的豪华食物

```yaml
legendary_feast:
  displayname: "<gradient:#FFD700:#FF4500>传说盛宴"
  material: COOKED_BEEF
  lore:
    - "<gray>一道传说级料理"
    - "<gold>提供多种强力增益效果</gold>"
  Pack:
    generate_model: true
    parent_model: "item/generated"
    textures:
      - legendary_feast.png
  Components:
    food:
      nutrition: 12
      saturation: 19.2
      can_always_eat: true
    consumable:
      consume_seconds: 3.2
      animation: EAT
      sound: entity.generic.eat
      has_consume_particles: true
      on_consume_effects:
        - type: apply_effects
          effects:
            minecraft:regeneration:
              duration: 200
              amplifier: 1
            minecraft:absorption:
              duration: 1200
              amplifier: 2
            minecraft:resistance:
              duration: 600
              amplifier: 0
          probability: 1.0
        - type: clear_all_effects              # 食用后清除所有负面效果
      #   - type: teleport_randomly            # 示例：随机传送
      #     diameter: 8
    use_cooldown:
      seconds: 60
      group: oraxen:feast_items
```

## 常用食物材质参考

| 材质 | 默认饥饿值 | 默认饱和度 | 备注 |
|------|-----------|-----------|------|
| `APPLE` | 4 | 2.4 | 基础食物 |
| `BREAD` | 5 | 6.0 | 基础食物 |
| `COOKED_BEEF` | 8 | 12.8 | 高营养食物 |
| `COOKED_PORKCHOP` | 8 | 12.8 | 高营养食物 |
| `GOLDEN_APPLE` | 4 | 9.6 | 附带特殊效果 |
| `GOLDEN_CARROT` | 6 | 14.4 | 高饱和度 |
| `PUMPKIN_PIE` | 8 | 4.8 | 低饱和度 |
| `PAPER` | N/A | N/A | 完全自定义，无默认食物属性 |
