## 收割 (harvesting)

### 概述

允许玩家在一定半径内自动收获成熟作物并重新种植。适用于小麦、胡萝卜、马铃薯等作物。右键点击作物触发范围内的批量收获和补种。

### 完整 YAML 配置

```yaml
# ============================================================
# 物品配置示例：收割镰刀
# ============================================================
harvesting_scythe:
  material: IRON_HOE                                      # 【必填】物品的基础材质
  displayname: "<green>收割镰刀"                            # 【必填】物品的显示名称
  lore:                                                    # 【可选】物品的描述文字
    - "<gray>右键收获范围内所有成熟作物"
    - "<gray>自动重新种植"
  Mechanics:
    harvesting:
      cooldown: 10000                                      # 【可选】每次使用的冷却时间，以毫秒为单位（默认：0）
                                                           #   10000ms = 10 秒
                                                           #   有效范围：0 ~ 3600000（1小时）
      radius: 5                                            # 【可选】点击方块周围的水平收获范围（默认：3）
                                                           #   5 = 5x5 区域（以目标为中心的 11x11 区域）
                                                           #   有效范围：1 ~ 10
      height: 3                                            # 【可选】点击方块上方的垂直收获范围（默认：1）
                                                           #   有效范围：1 ~ 10
      lower_item_durability: true                          # 【可选】收割是否消耗工具耐久度（默认：true）
                                                           #   true = 每次收获消耗耐久度
                                                           #   false = 不消耗耐久度
```

### 参数详解

| 参数 | 类型 | 默认值 | 有效范围 | 必填 | 说明 |
|------|------|--------|----------|------|------|
| `cooldown` | 整数 | `0` | `0` ~ `3600000` | 否 | 两次收割之间的冷却时间（毫秒）。1000ms = 1秒 |
| `radius` | 整数 | `3` | `1` ~ `10` | 否 | 以点击方块为中心的水平收获半径（方块数） |
| `height` | 整数 | `1` | `1` ~ `10` | 否 | 以点击方块为起点的垂直向上收获范围（方块数） |
| `lower_item_durability` | 布尔 | `true` | `true` / `false` | 否 | 收获操作是否降低工具的耐久度 |

### 工作流程

1. **手持工具**：玩家手持带有收割机制的物品
2. **右键田地**：右键点击成熟的作物
3. **范围收获**：以点击方块为中心的 `radius` x `height` 范围内所有成熟作物被收获
4. **自动补种**：收获后自动重新种植种子（从背包中消耗种子）
5. **冷却与耐久**：若有冷却时间则进入冷却，若启用耐久消耗则降低耐久

## 范围挖掘 (bigmining)

### 概述

允许玩家同时挖掘多个方块。默认用于锤子类工具，实现 3x3 及更大的方形区域挖掘。也常被称为"连锁挖掘"或"矿脉挖掘"。

### 完整 YAML 配置

```yaml
# ============================================================
# 物品配置示例：范围挖掘锤
# ============================================================
excavation_hammer:
  material: DIAMOND_PICKAXE                               # 【必填】物品的基础材质
  displayname: "<blue>挖掘锤"                               # 【必填】物品的显示名称
  lore:                                                    # 【可选】物品的描述文字
    - "<gray>一次性挖掘 3x3 区域"
    - "<gray>适合快速采矿"
  Mechanics:
    bigmining:
      radius: 1                                            # 【可选】水平方向破坏方块周围的范围（默认：1）
                                                           #   1 = 3x3 区域
                                                           #   2 = 5x5 区域
                                                           #   有效范围：0 ~ 5
      depth: 1                                             # 【可选】垂直方向破坏方块周围的范围（默认：1）
                                                           #   1 = 上下各 1 层，共 3 层
                                                           #   有效范围：0 ~ 5
```

### 参数详解

| 参数 | 类型 | 默认值 | 有效范围 | 必填 | 说明 |
|------|------|--------|----------|------|------|
| `radius` | 整数 | `1` | `0` ~ `5` | 否 | 以目标方块为中心的水平挖掘半径。1=3x3，2=5x5，以此类推 |
| `depth` | 整数 | `1` | `0` ~ `5` | 否 | 以目标方块为中心的垂直挖掘深度。1=上下各1层，共3层 |

### 全局配置（mechanics.yml）

```yaml
bigmining:
  enabled: true                                            # 是否全局启用范围挖掘
  call_events: true                                        # 【可选】是否为每个被破坏的方块调用 BlockBreakEvent（默认：true）
                                                           #   true = 调用事件（兼容保护插件）
                                                           #   false = 仅监听事件（某些附魔插件需要设为 false）
```

### 工作流程

1. **手持工具**：玩家手持带有范围挖掘机制的物品
2. **挖掘方块**：正常挖掘一个方块
3. **范围破坏**：以目标方块为中心，在 `radius` x `depth` 范围内同时破坏所有匹配类型的方块
4. **耐久度**：每破坏一个方块消耗 1 点耐久度

> **注意：** 如果与某些附魔插件出现冲突，可在 mechanics.yml 中将 `bigmining.call_events` 设为 `false`。

## 熔炼 (smelting)

### 概述

允许玩家在挖掘矿石时自动将其熔炼为成品。例如挖掘铁矿石时直接掉落铁锭。支持时运（Fortune）和精准采集（Silk Touch）附魔。

### 完整 YAML 配置

```yaml
# ============================================================
# 物品配置示例：自动熔炼镐
# ============================================================
autosmelter_pickaxe:
  material: NETHERITE_PICKAXE                             # 【必填】物品的基础材质
  displayname: "<gold>熔炼镐"                               # 【必填】物品的显示名称
  lore:                                                    # 【可选】物品的描述文字
    - "<gray>挖掘矿石时自动将其熔炼"
  Mechanics:
    smelting:
      enabled: true                                        # 【必填】是否启用熔炼机制
      play_sound: true                                     # 【可选】熔炼时是否播放声音（默认：true）
                                                           #   true = 播放熔炼音效
                                                           #   false = 静默熔炼
```

### 参数详解

| 参数 | 类型 | 默认值 | 有效范围 | 必填 | 说明 |
|------|------|--------|----------|------|------|
| `enabled` | 布尔 | `false` | `true` / `false` | **是** | 是否启用熔炼功能 |
| `play_sound` | 布尔 | `true` | `true` / `false` | 否 | 熔炼时是否播放音效 |

### 全局配置（mechanics.yml）

```yaml
smelting:
  enabled: true                                            # 是否全局启用熔炼机制
  blacklist_cooked:                                        # 【可选】不应自动熔炼的物品黑名单
    - WET_SPONGE                                           #   湿海绵（熔炼后会变干海绵）
    # - ICE                                                #   如果需要，可以加入冰块等
```

### 工作流程

1. **挖掘矿石**：使用带有熔炼机制的镐子挖掘矿石
2. **自动熔炼**：矿石直接掉落其熔炼产物（例如铁矿石掉落铁锭）
3. **附魔兼容**：时运附魔增加掉落数量，精准采集附魔则掉落原矿
4. **黑名单检查**：黑名单中的物品不会自动熔炼

### 支持的矿石类型

默认支持的熔炼转换包括：铁矿石 -> 铁锭、金矿石 -> 金锭、铜矿石 -> 铜锭、远古残骸 -> 下界合金碎片、沙子 -> 玻璃、仙人掌 -> 绿色染料 等所有原版熔炼配方。

## 瓶装经验 (bottledexp)

### 概述

允许玩家通过右键将自身经验值转化为经验瓶。可配置转换比例，支持经验损失。

### 完整 YAML 配置

```yaml
# ============================================================
# 物品配置示例：经验瓶
# ============================================================
experience_bottle:
  material: GLASS_BOTTLE                                  # 【必填】物品的基础材质
  displayname: "<yellow>经验瓶"                             # 【必填】物品的显示名称
  lore:                                                    # 【可选】物品的描述文字
    - "<gray>右键将经验存入瓶中"
    - "<gray>转换效率：95%"
  Mechanics:
    bottledexp:
      ratio: 0.95                                          # 【可选】经验转换比例（默认：1.0）
                                                           #   1.0 = 100% 效率，无损失
                                                           #   0.95 = 95% 效率，损失 5% 经验
                                                           #   有效范围：0.0 ~ 1.0
```

### 参数详解

| 参数 | 类型 | 默认值 | 有效范围 | 必填 | 说明 |
|------|------|--------|----------|------|------|
| `ratio` | 小数 | `1.0` | `0.0` ~ `1.0` | 否 | 经验转换效率。`1.0` = 无损失，`0.95` = 损失 5% 经验 |

### 全局配置（mechanics.yml）

```yaml
bottledexp:
  enabled: true                                            # 是否全局启用瓶装经验机制
  durability_cost: 1                                       # 【可选】每次使用消耗的耐久度（默认：1）
                                                           #   0 = 不消耗耐久度
```

### 工作流程

1. **积累经验**：玩家拥有一定量的经验值
2. **右键存储**：手持经验瓶右键，将经验值按 `ratio` 比例转化为经验瓶
3. **物品生成**：背包中获得对应数量的经验瓶
4. **耐久消耗**：工具扣除相应耐久度

## 基岩破坏 (bedrockbreak)

### 概述

允许玩家使用特定工具破坏基岩方块。可配置破坏动画速度和基岩掉落概率。

> **依赖：** 此机制依赖 ProtocolLib。如果服务器无法使用 ProtocolLib，需要在 mechanics.yml 中禁用此机制。

### 完整 YAML 配置

```yaml
# ============================================================
# 物品配置示例：基岩破坏器
# ============================================================
bedrock_breaker:
  material: NETHERITE_PICKAXE                             # 【必填】物品的基础材质
  displayname: "<dark_gray>基岩破坏者"                      # 【必填】物品的显示名称
  lore:                                                    # 【可选】物品的描述文字
    - "<gray>能够破坏基岩"
    - "<gray>需要一定时间来凿穿"
  Mechanics:
    bedrockbreak:
      hardness: 10                                         # 【可选】破坏动画切换之间的刻数（默认：10）
                                                           #   值越小破坏越快
                                                           #   有效范围：1 ~ 200
      probability: 1.0                                     # 【可选】破坏后获得基岩方块的掉落概率（默认：1.0）
                                                           #   1.0 = 100% 掉落
                                                           #   0.5 = 50% 掉落
                                                           #   有效范围：0.0 ~ 1.0
```

### 参数详解

| 参数 | 类型 | 默认值 | 有效范围 | 必填 | 说明 |
|------|------|--------|----------|------|------|
| `hardness` | 整数 | `10` | `1` ~ `200` | 否 | 破坏动画切换之间的刻数。值越小破坏越快，10 约为 0.5 秒一阶段 |
| `probability` | 小数 | `1.0` | `0.0` ~ `1.0` | 否 | 破坏后基岩方块的掉落概率。`1.0`=100%，`0.10`=10% |

### 全局配置（mechanics.yml）

```yaml
bedrockbreak:
  enabled: true                                            # 是否全局启用基岩破坏机制
  disable_on_first_layer: false                            # 【可选】是否禁止破坏 Y=0 层的基岩（默认：false）
                                                           #   true = 无法破坏底层基岩（防止掉入虚空）
                                                           #   false = 可破坏所有层的基岩
  durability_cost: 500                                     # 【可选】每次破坏基岩方块消耗的耐久度（默认：500）
                                                           #   高消耗防止过度开采
```

### 工作流程

1. **手持工具**：玩家手持带有基岩破坏机制的物品
2. **开始挖掘**：持续挖掘基岩方块
3. **破坏动画**：经过 `hardness` 刻后破坏阶段动画切换一次
4. **完成破坏**：到达最终阶段后基岩被破坏
5. **掉落判定**：根据 `probability` 概率掉落基岩方块
6. **耐久扣除**：从工具扣除 `durability_cost` 的耐久度

## 浇水 (watering)

### 概述

创建一个洒水壶系统。此机制需要定义两个物品：空壶和装满水的壶，两者通过 `filledCanItem` 和 `emptyCanItem` 互相链接。空壶在右键水或含水炼药锅时装水，装满水的壶可以浇灌农田。

### 完整 YAML 配置

```yaml
# ============================================================
# 物品配置：空洒水壶
# ============================================================
empty_watering_can:
  material: PAPER                                          # 【必填】物品的基础材质
  displayname: "<gray>空洒水壶"                             # 【必填】物品的显示名称
  lore:                                                    # 【可选】物品的描述文字
    - "<gray>右键水源或含水炼药锅来装水"
  Mechanics:
    watering:
      filledCanItem: filled_watering_can                   # 【必填】装水后变成的已装满水壶的物品 ID

# ============================================================
# 物品配置：装满的洒水壶
# ============================================================
filled_watering_can:
  material: PAPER                                          # 【必填】物品的基础材质（建议与空壶不同材质或不同纹理）
  displayname: "<aqua>装满的洒水壶"                          # 【必填】物品的显示名称
  lore:                                                    # 【可选】物品的描述文字
    - "<gray>右键农田来浇灌作物"
  Mechanics:
    watering:
      emptyCanItem: empty_watering_can                     # 【必填】浇灌或倒水后变成的空壶物品 ID
```

### 参数详解

| 参数 | 类型 | 默认值 | 有效范围 | 必填 | 说明 |
|------|------|--------|----------|------|------|
| `filledCanItem` | 字符串 | - | 有效的 Oraxen 物品 ID | **是（空壶）** | 空壶装水后转换成的已装满水壶的物品 ID |
| `emptyCanItem` | 字符串 | - | 有效的 Oraxen 物品 ID | **是（满壶）** | 满壶浇灌或倒水后转换成的空壶的物品 ID |

### 工作流程

1. **装水**：手持空壶右键水源方块或含水炼药锅，空壶变为装满水的壶
2. **浇灌**：手持装满水的壶右键农田或 Oraxen 农场方块，土壤被湿润，满壶变为空壶
3. **循环使用**：重复装水和浇灌的过程

> **提示：** 两个物品必须互相链接（空壶的 `filledCanItem` 指向满壶，满壶的 `emptyCanItem` 指向空壶），否则系统无法正常工作。

```yaml
# ============================================================

  enabled: true                                            # 是否全局启用熔炼机制

  enabled: true                                            # 是否全局启用瓶装经验

# 基岩破坏
bedrockbreak:
  enabled: true                                            # 是否全局启用基岩破坏
  disable_on_first_layer: false                            # 禁止破坏 Y=0 层基岩
  durability_cost: 500                                     # 每次破坏消耗的耐久度

# 浇水
watering:
  enabled: true                                            # 是否全局启用浇水机制
```

## 常见问题

### 收割机制与保护插件兼容性如何？

收割机制会检查目标方块是否有保护，不会在受保护区域自动收割。如果区域被 WorldGuard 等插件保护，收割不会触发。

### 范围挖掘为什么能破坏不同类型方块？

范围挖掘匹配的是被破坏方块的类型。例如你破坏一个石头，只会连锁破坏相邻的石头，不会误伤其他类型方块。radius 和 depth 只在匹配的方块类型上生效。

### 如何让熔炼镐兼容时运和精准采集？

熔炼机制原生支持这两种附魔。时运增加熔炼产物的掉落数量，精准采集则强制掉落原矿（不触发熔炼）。

### 基岩破坏需要 ProtocolLib 吗？

是的，基岩破坏机制依赖 ProtocolLib 来修改方块破坏动画。如果服务器没有 ProtocolLib，需要在 mechanics.yml 中将 `bedrockbreak.enabled` 设为 `false`。

### 洒水壶可以浇灌 Oraxen 自定义农田吗？

是的，洒水壶支持原版农田和 Oraxen 自定义农场方块。
