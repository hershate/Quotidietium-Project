# 家具进化（植物生长）配置模板

> Oraxen 进化机制允许家具/植物随时间自动生长，经历多个视觉阶段。
> 适用于自定义作物、花卉、果树等所有需要分阶段生长的内容。

---

## 一、配置方式选择

Oraxen 提供两种方式来实现多阶段植物：

| 方式 | 复杂度 | 性能 | 维护性 | 推荐度 |
|------|--------|------|--------|--------|
| **内联阶段** (stages) | 低 | 高（模型切换） | 高（单文件） | **强烈推荐** |
| 旧版多物品 | 高 | 低（实体重建） | 低（多文件） | 已弃用 |

> **推荐使用内联阶段方式。** 旧版方式已弃用，会产生控制台警告。

---

## 二、内联阶段（推荐方式）

### 2.1 核心概念

- 一个 Oraxen 物品定义所有生长阶段
- 使用 `Pack.models` 定义每个阶段的模型
- 使用 `stages` 数组按顺序排列阶段
- 自动按数组顺序依次进化（不需要手动指定 `next_stage`）
- **最后一个阶段不要写 `evolution` 部分**（表示最终阶段）

### 2.2 完整 4 阶段植物示例

```yaml
# ============================================================
# 示例: 玫瑰 —— 4 阶段进化植物（种子 → 幼苗 → 花苞 → 开花）
# ============================================================
rose_seed:
  displayname: "<gradient:#46EEAA:#2CBFC7>玫瑰种子</gradient>"
  material: PAPER
  Pack:
    generate_model: true
    parent_model: "item/generated"
    textures:
      - custom/plants/rose_seed
    # ==========================================================
    # Pack.models: 定义所有阶段模型
    # 键名会在 stages 的 model 字段中引用
    # 自动注册路径:
    #   oraxen:rose_seed          → stage0 (基础模型)
    #   oraxen:rose_seed/stage0   → stage0 变体
    #   oraxen:rose_seed/stage1   → stage1 变体
    #   oraxen:rose_seed/stage2   → stage2 变体
    #   oraxen:rose_seed/stage3   → stage3 变体
    # ==========================================================
    models:
      stage0: custom/plants/rose_stage_0
      stage1: custom/plants/rose_stage_1
      stage2: custom/plants/rose_stage_2
      stage3: custom/plants/rose_stage_3

  Mechanics:
    furniture:
      type: DISPLAY_ENTITY
      barrier: false                      # 植物通常不需要碰撞
      farmblock_required: true            # 需要种在自定义耕地上
      # 或者 farmland_required: true     # 需要种在原版耕地上

      initial_stage: 0                    # 放置时从哪个阶段开始（默认 0）

      # ========================================================
      # stages: 阶段列表（按生长顺序）
      # 每个阶段包含:
      #   - model: 引用 Pack.models 中的键名（必填）
      #   - evolution: 进化到下一阶段的条件（最终阶段省略）
      #   - drop: 此阶段的掉落物（可选，未设置则继承全局 drop）
      #   - light: 此阶段的光照等级（可选，-1 表示继承全局）
      # ========================================================
      stages:
        # ---------- 阶段 0: 种子 ----------
        - model: stage0
          evolution:
            delay: 6000                    # 每次检查间隔（刻，6000=5分钟）
            probability: 0.6               # 通过概率 (0.0-1.0)
            light_boost:                   # 光照加速（详细格式）
              minimum_light_level: 9       # 最低光照等级要求
              boost_tick: 2000             # 充足光照时每次增加 2000 刻进度
            rain_boost:                    # 雨天加速
              boost_tick: 1500             # 下雨时每次增加 1500 刻进度
            bone_meal:                     # 骨粉催熟
              chance: 50                   # 使用骨粉有 50% 几率推进
          drop:
            silktouch: true
            loots:
              - { oraxen_item: rose_seed, probability: 1.0 }

        # ---------- 阶段 1: 幼苗 ----------
        - model: stage1
          evolution:
            delay: 10000                   # 10,000 刻 = 约 8 分 20 秒
            probability: 0.5
            light_boost: true              # 简写格式: 启用默认光照加速
            bone_meal:
              chance: 50
          drop:
            silktouch: true
            loots:
              - { oraxen_item: rose_seed, probability: 1.0 }

        # ---------- 阶段 2: 花苞 ----------
        - model: stage2
          evolution:
            delay: 10000
            probability: 0.5
            rain_boost: true               # 简写格式: 启用默认雨天加速
            bone_meal:
              chance: 50
          drop:
            silktouch: true
            loots:
              - { oraxen_item: rose_seed, probability: 1.0 }

        # ---------- 阶段 3: 开花（最终阶段，无 evolution）----------
        - model: stage3
          light: 5                         # 此阶段发出 5 级光（可选）
          drop:
            silktouch: true
            loots:
              - { oraxen_item: rose_seed, max_amount: 2, probability: 0.75 }
              - { oraxen_item: rose_plant, max_amount: 5, probability: 0.55 }
```

### 2.3 阶段流程说明

```
放置物品 → 阶段0 (种子)
              ↓ evolution (delay + probability)
           阶段1 (幼苗)
              ↓ evolution
           阶段2 (花苞)
              ↓ evolution
           阶段3 (开花) [最终阶段，不再进化]
```

## 三、进化选项详解

### 3.1 基础进化参数

```yaml
evolution:
  delay: 10000              # 进化检查的间隔（单位: 刻，20刻=1秒）
                            # 每过这么多刻，进行一次概率判定
                            # 示例: 6000=5分钟, 12000=10分钟, 24000=20分钟

  probability: 0.5          # 达到 delay 后成功进化的概率 (0.0 ~ 1.0)
                            # 0.5 = 50% 几率
                            # 1.0 = 必定进化
                            # 0.0 = 永不进化（无意义）
```

### 3.2 光照加速 (light_boost)

> 方块光照等级足够时，生长速度加快。

```yaml
evolution:
  delay: 10000
  probability: 0.5

  # ---- 简写格式（使用默认值） ----
  light_boost: true                     # 启用光照加速（默认最低光照 9）

  # ---- 详细格式（自定义参数） ----
  # light_boost:
  #   minimum_light_level: 9            # 加速所需的最低光照等级 (0-15)
  #   boost_tick: 500                   # 光照充足时，每次检查额外增加的进度刻数
```

**工作原理**: 每次进化检查时，如果光照 >= `minimum_light_level`，则进度额外增加 `boost_tick` 刻。这**不改变** `probability`，而是让检查更快到来。

### 3.3 雨天加速 (rain_boost)

> 下雨时生长速度加快。

```yaml
evolution:
  delay: 10000
  probability: 0.5

  # ---- 简写格式 ----
  rain_boost: true                      # 启用雨天加速（默认 boost_tick）

  # ---- 详细格式 ----
  # rain_boost:
  #   boost_tick: 500                   # 下雨时每次检查额外增加的进度刻数
```

### 3.4 骨粉催熟 (bone_meal)

> 允许玩家使用骨粉右键推动植物生长。

```yaml
evolution:
  delay: 10000
  probability: 0.5

  # ---- 简写格式 ----
  bone_meal: true                       # 启用骨粉（默认 50% 几率）

  # ---- 详细格式 ----
  # bone_meal:
  #   chance: 30                        # 使用骨粉成功推进的百分比几率 (0-100)
```

### 3.5 完整进化选项表

| 选项 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `delay` | 整数 | (必填) | 进化检查间隔（刻） |
| `probability` | 浮点 | `1.0` | 达到延迟后进化的几率 |
| `light_boost` | 布尔/对象 | `false` | 光照加速。`true` 使用默认值 |
| `light_boost.minimum_light_level` | 整数 | `9` | 加速所需的最低光照等级 |
| `light_boost.boost_tick` | 整数 | (内置) | 光照充足时每次检查额外增加的刻数 |
| `rain_boost` | 布尔/对象 | `false` | 雨天加速。`true` 使用默认值 |
| `rain_boost.boost_tick` | 整数 | (内置) | 下雨时每次检查额外增加的刻数 |
| `bone_meal` | 布尔/对象 | `false` | 骨粉催熟。`true` 使用默认 50% |
| `bone_meal.chance` | 整数 | `50` | 骨粉成功推进的百分比几率 (0-100) |

## 四、阶段配置选项

`stages` 数组中每个阶段的可用选项:

| 选项 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `model` | 字符串 | **是** | 引用 `Pack.models` 中的键名 |
| `evolution` | 对象 | 否 | 进化到下一阶段的条件。**最终阶段必须省略此项** |
| `drop` | 对象 | 否 | 此阶段的特定掉落物。如果省略，继承家具级别的 `drop` |
| `light` | 整数 | 否 | 此阶段的光照等级。`-1` 表示从家具机制的 `light` 继承 |

## 六、其他完整示例

### 6.1 2 阶段果树（无放置要求）

```yaml
fruit_tree:
  displayname: "<green>果树</green>"
  material: PAPER
  Pack:
    generate_model: false
    model: custom/trees/fruit_sapling
    models:
      sapling: custom/trees/fruit_sapling
      grown: custom/trees/fruit_grown
  Mechanics:
    furniture:
      type: DISPLAY_ENTITY
      barrier: true
      initial_stage: 0
      stages:
        - model: sapling
          evolution:
            delay: 24000               # 20 分钟现实时间
            probability: 0.8
            light_boost:
              minimum_light_level: 10
              boost_tick: 3000
            bone_meal:
              chance: 40
          drop:
            silktouch: true
            loots:
              - { oraxen_item: fruit_tree, probability: 1.0 }

        - model: grown                  # 最终阶段
          light: 3
          drop:
            silktouch: false
            loots:
              - { oraxen_item: fruit_tree, probability: 0.3 }
              - { oraxen_item: fruit, probability: 0.8, max_amount: 3 }
```

## 七、进化机制常见问题

**Q: 如何让植物只在特定生物群系中生长？**
A: 进化机制本身不支持生物群系限制。可以配合 `limited_placing` 限制放置位置，或使用第三方插件控制。

**Q: 骨粉可以在最终阶段使用吗？**
A: 最终阶段没有 `evolution` 部分，骨粉无法作用（因为没有下一阶段可推进）。

**Q: 植物会被水流冲走或爆炸破坏吗？**
A: 默认情况下家具是实体，水流不影响。爆炸破坏需要通过外部保护插件或游戏规则控制。

**Q: 如果玩家破坏中间阶段的植物会怎样？**
A: 根据该阶段的 `drop` 配置掉落。未配置 `drop` 的阶段会继承全局 `drop` 设置。

**Q: 从旧版多物品迁移到内联阶段后，已有植物会怎样？**
A: 已经放置的旧版植物**不会自动更新**。建议在重启/维护窗口期让玩家重新种植，或使用迁移脚本。
