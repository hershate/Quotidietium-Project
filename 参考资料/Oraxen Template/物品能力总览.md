# 物品能力总览

> 本文档列出 Oraxen 所有物品机制（Mechanics）的概览，包含简要描述和交叉引用。
> 每种机制在对应的模板文件中有详细配置示例。

---

## 战斗类机制

与战斗、伤害、法术相关的物品能力。

| 机制名称 (英文) | 中文名称 | 描述 | 详细模板 | 触发方式 |
|----------------|----------|------|---------|----------|
| `spear_lunge` | 长矛突刺 | 按住右键蓄力，松开后向前突刺，对路径上敌人造成伤害 | [武器.md](./武器.md) | 右键蓄力+松开 |
| `thor` | 雷神之锤 | 右键投掷闪电，对目标区域造成雷击伤害 | [武器.md](./武器.md) | 右键 |
| `lifeleech` | 生命吸取 | 击中敌人时吸取生命值 | [武器.md](./武器.md) | 被动（命中触发） |
| `bleeding` | 流血 | 命中时概率触发持续流血伤害 | [武器.md](./武器.md) | 被动（概率触发） |
| `energyblast` | 能量冲击波 | 右键发射粒子锥形区域攻击前方实体 | [武器.md](./武器.md) | 右键 |
| `witherskull` | 凋零骷髅头 | 右键发射凋零骷髅头 | [武器.md](./武器.md) | 右键 |
| `fireball` | 火球 | 右键发射爆炸火球，撞击时造成爆炸伤害 | [武器.md](./武器.md) | 右键 |
| `knockback_strike` | 击退连击 | 连续命中一定次数后触发强力击退 | [武器.md](./武器.md) | 被动（连击触发） |

**共同选项：**

- `charges`: 物品消耗前的使用次数，`-1` = 无限。适用于 `thor`, `energyblast`, `witherskull`, `fireball`
- 注意：同时只能有一个主动右键法术机制（多个会冲突）

## 农耕/工具类机制

与采矿、挖掘、农业相关的物品能力。

| 机制名称 (英文) | 中文名称 | 描述 | 详细模板 | 触发方式 |
|----------------|----------|------|---------|----------|
| `harvesting` | 收割 | 右键农田自动收割并重新种植作物 | [工具.md](./工具.md) | 右键 |
| `bigmining` | 范围挖掘 | 一次破坏多个方块（3x3, 5x5 等） | [工具.md](./工具.md) | 被动（挖掘触发） |
| `smelting` | 熔炼 | 挖掘矿石时自动熔炼为成品 | [工具.md](./工具.md) | 被动（挖掘触发） |
| `bottledexp` | 瓶装经验 | 右键将玩家经验转化为经验瓶 | [工具.md](./工具.md) | 右键 |
| `bedrockbreak` | 基岩破坏 | 允许工具破坏基岩（需要 ProtocolLib） | [工具.md](./工具.md) | 被动（挖掘触发） |
| `watering` | 浇水 | 洒水壶系统，右键装水/浇水 | [工具.md](./工具.md) | 右键 |
| `efficiency` | 效率 | 手持时获得急迫效果（挖掘速度提升） | [工具.md](./工具.md) | 被动（手持触发） |

## 杂项类机制

通用物品行为和特殊功能。

### 物品基础功能

| 机制名称 (英文) | 中文名称 | 描述 | 适用版本 | 注意 |
|----------------|----------|------|---------|------|
| `durability` | 耐久度 | 自定义物品耐久值 | 全版本 | 1.20.5+ 推荐使用 Components: durability |
| `custom_food` / `food` | 自定义食物 | 自定义饥饿值、饱和度、食用效果 | 旧版 (1.20.5-) | 1.20.5+ 使用 Components: food |
| `consumable` | 消耗品 | 右键消耗 1 个物品 | 旧版 | 1.21.2+ 使用 Components: consumable |
| `consumable_potion_effects` | 消耗品药水效果 | 消耗物品时应用药水效果 | 旧版 | 常与 consumable 配合使用 |
| `repair` | 修复 | 使用物品修复另一个物品的耐久度 | 全版本 | 默认绑定铁/金/钻石齿轮 |
| `commands` | 命令 | 使用物品时执行控制台/玩家命令 | 全版本 | 支持冷却和一次性使用 |
| `backpack` | 背包 | 将物品变为便携式存储 | 全版本 | 建议设为不可堆叠 |
| `backpack_cosmetic` | 背包装饰 | 在玩家背部显示装饰性背包 | 1.21+ | 纯装饰，使用隐形盔甲架渲染 |
| `music_disc` | 音乐唱片 | 自定义音乐唱片 | 旧版 | 1.21+ 使用 Components: jukebox_playable |
| `armor_effects` | 护甲效果 | 装备护甲时获得持续药水效果 | 全版本 | 支持需要穿戴全套的条件 |
| `aura` | 光环 | 手持物品时显示粒子光环效果 | 全版本 | 支持 simple/ring/helix 三种类型 |
| `hat` | 帽子 | 允许物品作为帽子装备在头部 | 全版本 | 支持任何物品 |
| `skinnable` / `skin` | 可换肤 / 皮肤 | 通过使用皮肤物品改变物品纹理 | 全版本 | skinnable 接收方；skin 消耗方 |
| `soulbound` | 灵魂绑定 | 玩家死亡时保留物品 | 全版本 | lose_chance: 0-1 控制丢失概率 |
| `toggle_light` | 切换灯光 | 右键切换家具/方块的灯光等级 | 全版本 | light 基础值 + toggle_light 切换值 |
| `misc` | 杂项 | 一组小型修改项 | 全版本 | 见下方详解 |

### misc 杂项配置项

```yaml
Mechanics:
  misc:
    breaks_from_cactus: true       # 物品可被仙人掌破坏
    burns_in_fire: true            # 物品可在火焰中烧毁
    burns_in_lava: true            # 物品可在岩浆中烧毁
    disable_vanilla_interactions: false  # 禁用原版交互（如剥木头）
    can_strip_logs: false          # 可用于剥原木
    piglins_ignore_when_equipped: false  # 猪灵忽视装备此物品的玩家
    compostable: false             # 可放入堆肥桶
    allow_in_vanilla_recipes: true # 允许在原版合成配方中使用
```

> 1.20.5+ 版本中，防火相关选项推荐使用 `Components: fire_resistant: true`

## 点击动作 (ClickAction)

| 机制名称 (英文) | 中文名称 | 描述 | 适用对象 |
|----------------|----------|------|---------|
| `clickAction` | 点击动作 | 玩家点击方块/家具时执行命令/播放声音/发送消息 | 音符盒、家具、绊线钩 |

```yaml
# 示例：在音符盒/furniture/stringblock 机制下配置
Mechanics:
  noteblock:   # 或 furniture 或 stringblock
    clickActions:
      - conditions:
          - '#player.hasPermission("test.permission")'
        actions:
          - '[console] say <player> hello!'
```

## 自定义机制 (Custom)

| 机制名称 (英文) | 中文名称 | 描述 | 适用对象 |
|----------------|----------|------|---------|
| `custom` | 自定义机制 | 通过事件+条件+动作创建自定义行为 | 仅物品（非方块/家具） |

可用事件: CLICK, DROP, PICKUP, BREAK, EQUIP, UNEQUIP, INV_CLICK, DEATH
可用条件: HAS_PERMISSION
可用动作: COMMAND, MESSAGE, ACTIONBAR

```yaml
Mechanics:
  custom:
    my_mechanic_name:
      one_usage: false
      event: "CLICK:right:all"
      conditions:
        - "HAS_PERMISSION:example.permission"
      actions:
        - "[console] give <player> cooked_beef 1"
```

## 版本迁移对照

| 旧版 Mechanism | 新版 Component | 最低版本 |
|---------------|---------------|---------|
| `Mechanics.durability` | `Components.durability` | 1.20.5 |
| `Mechanics.food` | `Components.food` + `Components.consumable` | 1.20.5 / 1.21.2 |
| `Mechanics.consumable` | `Components.consumable` | 1.21.2 |
| `Mechanics.music_disc` | `Components.jukebox_playable` | 1.21 |
| `Mechanics.misc.burns_in_*` | `Components.fire_resistant` | 1.20.5 |

> **建议：** 如果服务器版本 >= 1.21.2，优先使用 Components 方式定义物品属性。旧版 Mechanics 方式仍可用但不推荐。
