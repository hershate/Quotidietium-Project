# 家具唱片机配置模板

> Oraxen 唱片机（Jukebox）机制允许家具接受并播放原版音乐唱片和自定义音乐唱片。
> 支持播放状态下的模型切换，以及音量、音调和权限控制。

---

## 一、核心概念

- 家具唱片机可以接收音乐唱片物品（原版或 Oraxen 自定义唱片）
- 播放音乐时，家具可以切换为不同的模型（如唱片机盖子打开）
- 支持自定义音量、音调
- 可通过权限控制谁可以播放音乐

---

## 二、基础唱片机配置

```yaml
# ============================================================
# 示例: 简单唱片机（不切换模型）
# ============================================================
simple_turntable:
  displayname: "<yellow>唱片机</yellow>"
  material: PAPER
  Pack:
    generate_model: false
    model: default/simple_turntable
  Mechanics:
    furniture:
      type: DISPLAY_ENTITY
      barrier: true

      jukebox:
        # 基础唱片机配置（无 active_model）
        volume: 1.0                     # 音量 (默认 1.0)
        pitch: 1.0                      # 音调 (默认 1.0)
        permission: ""                  # 权限节点（空=任何人都可播放）
```

## 三、带状态模型切换的唱片机（推荐）

> 使用 `active_model` 在播放唱片时切换家具外观。
> 需要在 `Pack.models` 中定义至少两个模型：关闭状态和打开状态。

```yaml
# ============================================================
# 示例: 带开盖动画的唱片机
# ============================================================
turntable:
  displayname: "<gold>高级唱片机</gold>"
  material: PAPER

  # ==========================================================
  # Pack 节: 定义关闭和打开两种状态的模型
  # ==========================================================
  Pack:
    generate_model: false
    model: default/turntable_closed     # 默认显示（没有唱片时）
    models:
      opened: default/turntable_opened  # 播放唱片时显示

  Mechanics:
    furniture:
      type: DISPLAY_ENTITY
      barrier: true

      jukebox:
        # ----------------------------------------------------
        # active_model: 播放时切换到的模型
        # 引用 Pack.models 中定义的键名
        # ----------------------------------------------------
        active_model: opened            # 播放时显示 turntable_opened 模型

        volume: 1.0                     # 音量
        pitch: 1.0                      # 音调
        permission: ""                  # 权限（空=无限制）
```

### 模型切换的完整流程

```
1. 玩家右键 → 放入音乐唱片
2. 模型从 turntable_closed → turntable_opened（active_model）
3. 音乐开始播放
4. 音乐结束/取出唱片 → 模型恢复为 turntable_closed（默认 model）
```

## 四、唱片机选项详解

### 4.1 完整选项表

```yaml
Mechanics:
  furniture:
    type: DISPLAY_ENTITY
    barrier: true

    jukebox:
      active_model: opened              # [可选] 播放时显示的模型键名
                                        # 引用 Pack.models 中定义的键
                                        # 不设置则不切换模型

      volume: 1.0                       # [可选] 播放音量 (默认 1.0)
                                        # 0.0 = 静音
                                        # 1.0 = 正常音量
                                        # >1.0 = 放大（可能失真）

      pitch: 1.0                        # [可选] 音调 (默认 1.0)
                                        # 0.5 = 低八度
                                        # 1.0 = 正常音调
                                        # 2.0 = 高八度

      permission: "oraxen.jukebox.play" # [可选] 播放所需权限
                                        # 空字符串 "" = 任何人都可播放
                                        # 设为权限节点 = 仅拥有该权限的玩家可播放
```

### 4.2 各字段说明

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `active_model` | 字符串 | 否 | (无) | 播放时切换到的模型，引用 `Pack.models` 键名 |
| `volume` | 浮点 | 否 | `1.0` | 播放音量，可 >1.0 |
| `pitch` | 浮点 | 否 | `1.0` | 播放音调，0.5=低八度, 2.0=高八度 |
| `permission` | 字符串 | 否 | `""` | 播放权限节点，空字符串表示无限制 |

## 五、Pack.models 详解

> `Pack.models` 是唱片机功能的关键配合配置。用于定义多个模型变体。

```yaml
# ============================================================
# Pack.models 配置模式
# ============================================================
Pack:
  # ----------------------------------------------------------
  # model: 基础/默认模型
  # 唱片机不播放时显示此模型
  # ----------------------------------------------------------
  model: default/my_jukebox_closed

  # ----------------------------------------------------------
  # models: 额外模型变体映射
  # 键名 → 模型路径
  # 自动注册为 oraxen:<物品id>/<键名>
  # ----------------------------------------------------------
  models:
    opened: default/my_jukebox_opened    # 播放状态
    empty: default/my_jukebox_empty      # 无唱片状态（可选）
    broken: default/my_jukebox_broken    # 其他状态（可选）
```

### 自动注册路径

以物品 ID `turntable` 为例：

| 配置 | 自动注册路径 |
|------|-------------|
| `model: default/turntable_closed` | `oraxen:turntable` |
| `models: { opened: ... }` | `oraxen:turntable/opened` |
| `models: { empty: ... }` | `oraxen:turntable/empty` |

## 六、完整示例

### 6.1 带权限控制的唱片机

```yaml
vip_jukebox:
  displayname: "<light_purple>VIP 唱片机</light_purple>"
  material: PAPER
  Pack:
    generate_model: false
    model: default/vip_jukebox
    models:
      active: default/vip_jukebox_active
  Mechanics:
    furniture:
      type: DISPLAY_ENTITY
      barrier: true
      jukebox:
        active_model: active
        volume: 1.2
        pitch: 1.0
        permission: "oraxen.jukebox.vip"   # 仅 VIP 玩家可播放
      drop:
        silktouch: false
        loots:
          - { oraxen_item: vip_jukebox, probability: 1.0 }
```

### 6.2 低音增强唱片机

```yaml
bass_jukebox:
  displayname: "<dark_red>低音炮唱片机</dark_red>"
  material: PAPER
  Pack:
    generate_model: false
    model: default/bass_jukebox_idle
    models:
      active: default/bass_jukebox_active
  Mechanics:
    furniture:
      type: DISPLAY_ENTITY
      barrier: true
      light: 3                            # 播放时可能有视觉效果
      jukebox:
        active_model: active
        volume: 1.5                       # 更高的音量
        pitch: 0.8                        # 略微降低音调以增强低音感
      drop:
        silktouch: false
        loots:
          - { oraxen_item: bass_jukebox, probability: 1.0 }
```

### 6.3 社区音乐盒（无权限限制）


## 七、与自定义音乐唱片配合

Oraxen 允许创建自定义音乐唱片物品，可与唱片机家具配合使用：

```yaml
# ============================================================
# 自定义音乐唱片物品（参考，用于配合唱片机家具）
# ============================================================
my_custom_disc:
  displayname: "<green>自定义音乐唱片</green>"
  material: PAPER
  Pack:
    generate_model: false
    model: item/my_custom_disc
  Mechanics:
    music_disc:
      song: "custom:my_song"              # 引用的音乐资源
      comparator_signal: 15               # 比较器输出信号强度
```

## 八、常见问题

**Q: 唱片机需要屏障吗？**
A: 是的。玩家需要右键屏障方块来放入/取出唱片。如果不使用屏障，则玩家无法交互。

**Q: 可以使用 `hitbox` 代替屏障吗？**
A: 可以。使用展示实体的 `hitbox` 定义交互区域即可。

**Q: 如何让唱片机支持多个不同的播放状态模型？**
A: 当前 `active_model` 只支持一个播放状态模型。如果需要多个状态，可以考虑使用进化机制（stages）来切换模型。

**Q: 可以在唱片机上同时使用存储功能吗？**
A: 不建议。唱片机的右键交互用于放入/取出唱片，存储功能的交互与之冲突。

**Q: 播放结束或取出唱片后，模型会自动恢复吗？**
A: 是的。取出唱片或音乐播放完毕后，模型自动恢复为基础 `model`。
