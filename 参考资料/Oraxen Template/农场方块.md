# 农场方块 (FarmBlock) 配置模板

> **机制说明**: 农场方块机制是一个用于自定义植物和作物的方块系统。它使用「干燥 + 湿润」双方块模型，配合洒水壶系统实现浇水/干旱循环，让方块在两种状态之间切换。
>
> **核心概念**:
> - **双方块系统**: 每个农场方块需要两个配置 — 干燥版本 (dry) 和湿润版本 (wet)
> - **自动切换**: 浇水后从 dry 变成 wet，干旱时间到后从 wet 变回 dry
> - **洒水壶**: 自定义的可装水/倒水物品，用于给农场方块浇水
> - **植物生长**: 可以与家具的植物进化系统结合，实现多种作物的生长
>
> **注意**: 如果需要完整的自定义农耕体验（多种作物、生长阶段、收获系统），强烈推荐考虑使用 [CustomCrops](https://polymart.org/resource/customcrops.2625) 插件，它与 Oraxen 完全兼容。

---

## 一、全局配置 (mechanics.yml)

将以下内容配置在 `plugins/Oraxen/mechanics.yml` 中：

```yaml
# ============================================================
# 农场方块相关全局配置 (plugins/Oraxen/mechanics.yml)
# ============================================================

# ---- 音符盒机制 (农场方块基于音符盒) ----
noteblock:
  enabled: true
  tool_types:
    - WOODEN
    - STONE
    - IRON
    - GOLDEN
    - DIAMOND
    - NETHERITE

  # [可选] 农场方块干旱检查间隔（刻）
  # 20刻 = 1秒。值越小检查越频繁，干旱越灵敏
  # 值越大性能越好
  farmblock_check_delay: 1000

# ---- 收获机制 ----
harvesting:
  # [必需] 启用/禁用自动收获作物
  # 使玩家可以用锄头等工具收获成熟作物并自动补种
  enabled: true

# ---- 浇水机制 ----
watering:
  # [必需] 启用/禁用浇水系统
  # 使玩家可以使用洒水壶给农场方块浇水
  enabled: true
```

## 二、农场方块双配置（干燥 + 湿润）

每个农场方块需要 **两个物品配置**：干燥版本和湿润版本。

### 2.1 干燥方块 (基础放置方块)

```yaml
# ============================================================
# 干燥农场方块 — 这是玩家物品栏中持有的方块
# ============================================================
epic_box_dry:
  # ---- 基础信息 ----
  displayname: "<white>史诗箱子"
  material: PAPER

  # ---- 资源包/模型配置 ----
  # 需要预制两个模型：干燥版和湿润版
  Pack:
    generate_model: false             # 使用预制模型
    model: epic_box_dry               # 干燥状态模型

  # ---- 方块机制配置 ----
  Mechanics:
    noteblock:
      # [必需] 变体编号
      custom_variation: 49
      # [必需] 干燥模型
      model: epic_box_dry
      # [可选] 硬度
      hardness: 5

      # ========== 农场方块子机制 ==========
      farmblock:
        # [必需★] 湿润版本的 Oraxen 物品 ID
        # 浇水后此方块会变成这个湿润版本
        moistFarmBlockPath: epic_box_wet

        # [必需★] 水分耗尽时间（毫秒）
        # 到达此时间后，湿润方块会自动变回干燥方块
        # 30000ms = 30秒, 60000ms = 1分钟, 300000ms = 5分钟
        farmBlockDryOutTime: 30000

      # ---- 掉落物配置 ----
      drop:
        silktouch: false
        loots:
          - oraxen_item: epic_box_dry
            probability: 1.0
```

### 2.2 湿润方块 (浇水后版本)

```yaml
# ============================================================
# 湿润农场方块 — 浇水后的状态，不在物品栏中显示
# ============================================================
epic_box_wet:
  # ---- 基础信息 ----
  displayname: "<white>史诗箱子 (湿润)"

  # [重要★] 从物品栏中排除此方块
  # 玩家只能获得干燥版本，湿润版本只在水合时出现
  excludeFromInventory: true

  material: PAPER

  # ---- 资源包/模型配置 ----
  Pack:
    generate_model: false
    model: epic_box_wet               # 湿润状态模型

  # ---- 方块机制配置 ----
  Mechanics:
    noteblock:
      # [必需] 变体编号 (必须与干燥版本不同!)
      custom_variation: 48
      # [必需] 湿润模型
      model: epic_box_wet
      hardness: 5

      # ========== 农场方块子机制 ==========
      farmblock:
        # [必需★] 干燥版本的 Oraxen 物品 ID
        # 水分耗尽后会变回这个干燥版本
        farmBlockPath: epic_box_dry

        # [必需★] 水分耗尽时间（毫秒）
        # 建议与干燥版本保持一致
        farmBlockDryOutTime: 30000

      drop:
        silktouch: false
        loots:
          # [重要] 湿润方块被破坏时通常掉落干燥版本
          - oraxen_item: epic_box_dry
            probability: 1.0
```

## 三、洒水壶配置

洒水壶是用于给农场方块浇水的物品，同样需要「空壶 + 满壶」双模型。

### 3.1 空洒水壶

```yaml
# ============================================================
# 空洒水壶 — 默认持有的版本
# ============================================================
epic_watering_vacuum:
  displayname: '<white>史诗洒水壶 (空)'
  material: LEATHER_HORSE_ARMOR

  Pack:
    generate_model: false
    model: items/epic_watering_vacuum

  Mechanics:
    watering:
      # [必需★] 装满水后替换成的物品 ID
      filledCanItem: epic_watering_full
```

### 3.2 满洒水壶

```yaml
# ============================================================
# 满洒水壶 — 装水后的版本
# ============================================================
epic_watering_full:
  displayname: '<white>史诗洒水壶 (满)'
  material: LEATHER_HORSE_ARMOR

  Pack:
    generate_model: false
    model: custom/plants/epic_watering_full

  Mechanics:
    watering:
      # [必需★] 水倒光后替换成的物品 ID
      emptyCanItem: epic_watering_vacuum
```

## 四、完整农场系统整合示例

以下是一个完整的农场系统配置，包含方块、洒水壶和作物的关系：

```yaml
# ============================================================
# 完整农场系统
# ============================================================

# ==================== 方块部分 ====================

# 1. 干燥农场方块（可在物品栏中获得）
farmland_dry:
  displayname: "<#8B4513>肥沃耕地"
  material: PAPER
  Pack:
    generate_model: false
    model: custom/farmland_dry
  Mechanics:
    noteblock:
      custom_variation: 100
      model: custom/farmland_dry
      hardness: 3
      block_sounds:
        place_sound: block.grass.place
        break_sound: block.grass.break
        step_sound: block.grass.step
      farmblock:
        moistFarmBlockPath: farmland_wet
        farmBlockDryOutTime: 60000    # 1 分钟后干旱
      drop:
        silktouch: false
        best_tools:
          - SHOVEL
        loots:
          - oraxen_item: farmland_dry
            probability: 1.0

# 2. 湿润农场方块（浇水后自动切换）
farmland_wet:
  displayname: "<#3B7A3B>湿润耕地"
  excludeFromInventory: true          # [重要] 隐藏
  material: PAPER
  Pack:
    generate_model: false
    model: custom/farmland_wet
  Mechanics:
    noteblock:
      custom_variation: 101
      model: custom/farmland_wet
      hardness: 3
      block_sounds:
        place_sound: block.grass.place
        break_sound: block.grass.break
        step_sound: block.grass.step
      farmblock:
        farmBlockPath: farmland_dry
        farmBlockDryOutTime: 60000
      drop:
        silktouch: false
        best_tools:
          - SHOVEL
        loots:
          - oraxen_item: farmland_dry
            probability: 1.0

# ==================== 洒水壶部分 ====================

# 3. 空洒水壶
watering_can_empty:
  displayname: '<white>洒水壶 (空)'
  material: LEATHER_HORSE_ARMOR
  Pack:
    generate_model: false
    model: items/watering_can_empty
  Mechanics:
    watering:
      filledCanItem: watering_can_full

# 4. 满洒水壶
watering_can_full:
  displayname: '<white>洒水壶 (满)'
  material: LEATHER_HORSE_ARMOR
  Pack:
    generate_model: false
    model: items/watering_can_full
  Mechanics:
    watering:
      emptyCanItem: watering_can_empty
```

## 五、农场方块工作流程

```yaml
# ============================================================
# 工作流程说明
# ============================================================
#
# 1. 玩家放置 farmland_dry (干燥方块)
#    ↓
# 2. 玩家手持洒水壶对干燥方块浇水
#    → 洒水壶: 满 → 空 (filledCanItem → emptyCanItem)
#    → 方块: farmland_dry → farmland_wet
#    ↓
# 3. 湿润方块保持湿润状态
#    ↓
# 4. farmBlockDryOutTime 时间到达后
#    → 方块自动: farmland_wet → farmland_dry
#    ↓
# 5. 可以再次浇水，循环往复
#
# 时间线示例 (farmBlockDryOutTime: 60000):
#   t=0s   放置干燥方块
#   t=5s   浇水 → 变成湿润方块
#   t=65s  干旱 → 自动变回干燥方块 (60秒后)
#   t=70s  再次浇水 → 又变成湿润方块
```

## 六、与植物进化系统结合

农场方块最强大的用途是与家具 (Furniture) 的植物进化系统结合，实现作物生长。

```yaml
# ============================================================
# 植物 + 农场方块结合示例
# ============================================================
# 此植物家具需要下方有自定义农场方块才能生长

magic_crop_seed:
  displayname: "<gradient:#46EEAA:#2CBFC7>魔法作物种子"
  material: PAPER
  Pack:
    generate_model: true
    parent_model: "item/generated"
    textures:
      - custom/plants/magic_seed
    models:
      stage0: custom/plants/magic_stage_0
      stage1: custom/plants/magic_stage_1
      stage2: custom/plants/magic_stage_2
      stage3: custom/plants/magic_stage_3
  Mechanics:
    furniture:
      barrier: false

      # [关键] 要求下方有自定义农场方块!
      farmblock_required: true

      initial_stage: 0
      stages:
        - model: stage0
          evolution:
            delay: 10000
            probability: 0.5
            light_boost: true
            bone_meal:
              chance: 50
          drop:
            silktouch: true
            loots:
              - { oraxen_item: magic_crop_seed, probability: 1.0 }

        - model: stage1
          evolution:
            delay: 10000
            probability: 0.5
            light_boost: true
            bone_meal:
              chance: 50
          drop:
            silktouch: true
            loots:
              - { oraxen_item: magic_crop_seed, probability: 1.0 }

        - model: stage2
          evolution:
            delay: 10000
            probability: 0.5
            light_boost: true
            bone_meal:
              chance: 50
          drop:
            silktouch: true
            loots:
              - { oraxen_item: magic_crop_seed, probability: 1.0 }

        - model: stage3   # 最终可收获阶段
          drop:
            silktouch: true
            loots:
              - { oraxen_item: magic_crop_seed, max_amount: 2, probability: 0.75 }
              - { oraxen_item: magic_fruit, max_amount: 5, probability: 0.55 }

# ============================================================
# 植物生长条件说明:
#
# farmblock_required: true  → 下方必须是自定义农场方块
#
# 生长加速条件 (evolution):
#   light_boost: true  → 光照充足时加速生长
#   rain_boost: true   → 下雨时加速生长
#   bone_meal: true    → 可被骨粉催熟
#
# 注意: 农场方块是否湿润影响植物是否能够生长。
# 干燥的农场方块通常会阻止植物生长或大幅降低概率。
# ============================================================
```

## 八、注意事项

1. **双模型必需**: 农场方块必须有干燥和湿润两个模型。没有预制模型无法使用此机制。
2. **excludeFromInventory 很重要**: 湿润方块必须设置 `excludeFromInventory: true`，这样玩家物品栏中只出现干燥版本。
3. **custom_variation 唯一性**: 干燥和湿润方块各需要唯一的 `custom_variation`。一个农场方块 = 消耗 2 个音符盒变体。
4. **farmBlockDryOutTime 一致**: 干燥和湿润方块的 `farmBlockDryOutTime` 应保持一致，否则会出现异常行为。
5. **基于音符盒**: 农场方块是音符盒 (NoteBlock) 的扩展，因此受音符盒全局配置影响（如 `remove_mineable_tag`）。
6. **洒水壶兼容性**: 洒水壶使用 `LEATHER_HORSE_ARMOR` 材质是为了获得可染色、可自定义模型的最佳兼容性。
7. **植物生长依赖农场方块**: 使用 `farmblock_required: true` 的植物只能种在自定义农场方块上，不能种在原版耕地上。
8. **CustomCrops 推荐**: 对于复杂的农耕系统（多种作物、季节、施肥等），官方推荐使用 CustomCrops 插件。
9. **旧版弃用**: 旧版的 `farmland_required`（需要原版耕地）已被 `farmblock_required` 取代。新项目请使用 `farmblock_required`。
