## 方法概述

组件方式是 Minecraft 1.21.2+ 引入的全新盔甲系统，Oraxen 对此提供了完整支持。与旧方法相比，它具有以下核心优势：

| 特性 | 组件方式 | 纹饰方式 | 着色器方式 |
|------|:--------:|:--------:|:----------:|
| 任意基础材质 | **是** | 仅锁链 | 仅皮革 |
| 着色器兼容 (Optifine/Iris) | **原生** | 原生 | 需要 CIT |
| 动画纹理 | **是** | 是 | 是 |
| 纹饰图案支持 | **是** | 是 | 否 |
| 可染色 | **是** | 否 | 是 |
| 性能 | **最佳** | 良好 | 一般 |
| 自定义鞘翅 | **是** | 否 | 否 |

**核心原理**：利用 Minecraft 1.21.2+ 的 `equippable` 物品组件，直接将自定义模型绑定到指定盔甲槽位，无需任何 hack 或间接手段。

## 命名规范

### 物品 ID 命名

> **强制要求** — 所有盔甲物品的 ID 必须遵循 `<盔甲名>_<部位类型>` 格式。

```
# 部位类型必须是以下之一（英文小写）:
_helmet      → 头盔
_chestplate  → 胸甲
_leggings    → 护腿
_boots       → 靴子
```

**示例 — 以 "ruby" (红宝石) 套装为例:**

| 物品 ID | 含义 |
|---------|------|
| `ruby_helmet` | 红宝石头盔 |
| `ruby_chestplate` | 红宝石胸甲 |
| `ruby_leggings` | 红宝石护腿 |
| `ruby_boots` | 红宝石靴子 |

### 纹理文件命名

> **强制要求** — 盔甲层纹理必须遵循 `<盔甲名>_armor_layer_<层级>.png` 格式。

```
<盔甲名>_armor_layer_1.png   → 第一层纹理 (头盔/胸甲/靴子的基础层)
<盔甲名>_armor_layer_2.png   → 第二层纹理 (护腿层, 以及头盔/胸甲的覆盖层)
```

**示例 — "ruby" 套装需要在资源包中存在以下纹理:**

```
~/textures/default/armors/ruby_armor_layer_1.png
~/textures/default/armors/ruby_armor_layer_2.png
```

两个文件必须同时存在。Oraxen 会根据你配置的盔甲部位自动选择正确的层级进行渲染。

## 纹理格式

### 分辨率与位深

组件的盔甲分辨率在 `settings.yml` 中由 `CustomArmor.armor_resolution` 控制:

```yaml
# settings.yml (与着色器方式共享此设置)
CustomArmor:
  armor_type: COMPONENTS       # [必须] 设为 COMPONENTS
  armor_resolution: 16         # [可选] 默认 16, 即纹理 64x32 像素
```

| armor_resolution | 纹理实际尺寸 (宽 x 高) |
|:-----------------:|:------------------------:|
| 16 (默认)         | 64 x 32 像素             |
| 32                | 128 x 64 像素            |
| 64                | 256 x 128 像素           |

**公式**: 纹理宽度 = resolution x 4, 纹理高度 = resolution x 2

### 物品图标纹理

物品图标 (在物品栏中显示的纹理) 的路径在 `Pack.textures` 中指定:

```yaml
Pack:
  generate_model: true
  parent_model: "item/generated"
  textures:
    - default/armors/ruby_helmet    # 指向 ~/textures/default/armors/ruby_helmet.png
```

物品图标纹理与盔甲层纹理是**独立的两套文件**。物品图标只影响物品栏/手中的外观，盔甲层纹理只影响穿戴后的外观。

## 完整配置模板 (4件套)

以下是一套完整的 4 件盔甲配置。可以直接复制使用，替换 `ruby` 为你的盔甲名称。

```yaml
# =============================================================================
# 红宝石盔甲套装 — 组件方式 (Minecraft 1.21.2+)
# 使用方法: 全局替换 "ruby" 为你的盔甲名称, "Ruby" 为显示名称
# =============================================================================

# ============================
# 1. 头盔
# ============================
ruby_helmet:
  # ---- [必须] 显示名称 ----
  displayname: "<gradient:#FA7CBB:#F14658>Ruby Helmet"     # 支持 MiniMessage 格式

  # ---- [必须] 基础材质 ----
  # 可以设置为任意材质! 无需使用盔甲类物品。
  # 材质决定物品的基础属性 (堆叠数、默认音效等)。
  # 如果你需要实际的盔甲防御值, 请配合 Attribute 组件使用。
  material: PAPER                                            # 也可以使用 DIAMOND_HELMET / IRON_HELMET 等

  # ---- [必须] 资源包配置 ----
  Pack:
    generate_model: true                                     # 自动生成物品模型
    parent_model: "item/generated"                           # 使用 generated 父模型 (手持/物品栏显示)
    textures:
      - default/armors/ruby_helmet                           # 物品图标纹理路径 (不含 .png)

  # ---- [可选] 可装备组件 ----
  # 如果省略, Oraxen 会根据物品 ID 后缀自动推断。
  # 手动指定可精确控制槽位和模型名称。
  Components:
    equippable:
      slot: HEAD                                             # 槽位: HEAD / CHEST / LEGS / FEET
      model: oraxen:ruby                                     # 模型命名空间, 指向 oraxen:ruby 模型

# ============================
# 2. 胸甲
# ============================
ruby_chestplate:
  displayname: "<gradient:#FA7CBB:#F14658>Ruby Chestplate"
  material: PAPER
  Pack:
    generate_model: true
    parent_model: "item/generated"
    textures:
      - default/armors/ruby_chestplate
  Components:
    equippable:
      slot: CHEST
      model: oraxen:ruby

# ============================
# 3. 护腿
# ============================
ruby_leggings:
  displayname: "<gradient:#FA7CBB:#F14658>Ruby Leggings"
  material: PAPER
  Pack:
    generate_model: true
    parent_model: "item/generated"
    textures:
      - default/armors/ruby_leggings
  Components:
    equippable:
      slot: LEGS
      model: oraxen:ruby

# ============================
# 4. 靴子
# ============================
ruby_boots:
  displayname: "<gradient:#FA7CBB:#F14658>Ruby Boots"
  material: PAPER
  Pack:
    generate_model: true
    parent_model: "item/generated"
    textures:
      - default/armors/ruby_boots
  Components:
    equippable:
      slot: FEET
      model: oraxen:ruby
```

### 使用此模板的步骤

1. **全局替换盔甲名称**: 将所有 `ruby` 替换为你的盔甲名 (如 `emerald`), 将 `Ruby` 替换为显示名 (如 `Emerald`)
2. **选择基础材质**: 将 `material: PAPER` 改为你需要的材质。**任何材质都可以!**
3. **准备纹理文件** (共 6 个):
   - `ruby_armor_layer_1.png` — 64x32 (resolution=16 时)
   - `ruby_armor_layer_2.png` — 64x32 (resolution=16 时)
   - `ruby_helmet.png` — 物品栏图标
   - `ruby_chestplate.png` — 物品栏图标
   - `ruby_leggings.png` — 物品栏图标
   - `ruby_boots.png` — 物品栏图标
4. **放置纹理路径**: 所有纹理放入 `~/textures/default/armors/` (或其他你配置的路径)
5. **启动服务器**: 运行 `/o reload all` 或重启服务器
6. **获取物品**: `/o give <玩家> ruby_helmet` 等

## Equippable 组件详解

`equippable` 是 Minecraft 1.21.2+ 的原版物品组件，Oraxen 通过它来关联自定义模型与盔甲槽位。

### 自动推断 vs 手动指定

| 场景 | 说明 |
|------|------|
| **自动推断** (省略 Components 块) | Oraxen 根据物品 ID 后缀 (`_helmet` → `HEAD`, `_chestplate` → `CHEST` 等) 自动分配 slot 和 model。model 名自动取 `oraxen:<盔甲名>` |
| **手动指定** (书写 Components 块) | 当你需要自定义槽位或不同模型名时使用 |

### slot 可选值

| slot 值 | 对应部位 | 说明 |
|---------|:--------:|------|
| `HEAD` | 头盔 | 占据头部槽位 |
| `CHEST` | 胸甲 / 鞘翅 | 占据胸部槽位 |
| `LEGS` | 护腿 | 占据腿部槽位 |
| `FEET` | 靴子 | 占据脚部槽位 |

### model 命名规则

`model` 的值格式为 `oraxen:<盔甲名>` (不含 `_helmet` 等后缀):

```yaml
# 正确示例:
#   物品 ID: ruby_helmet     → model: oraxen:ruby
#   物品 ID: emerald_boots   → model: oraxen:emerald
#   物品 ID: dragon_chestplate → model: oraxen:dragon

# 错误示例:
#   model: oraxen:ruby_helmet   ← 不要包含 _helmet
#   model: minecraft:diamond    ← 不要使用 minecraft 命名空间
```

## 自定义鞘翅 (Elytra)

组件方式支持创建具有自定义纹理的鞘翅。

### 命名规范

物品 ID 必须以 `_elytra` 结尾:

```
<前缀>_elytra
```

### 配置模板

```yaml
# ============================
# 自定义鞘翅示例
# ============================
magic_elytra:
  displayname: "<gradient:#FA7CBB:#F14658>Magic Elytra"      # 显示名称
  material: ELYTRA                                            # [建议] 使用 ELYTRA 以获得鞘翅的原版行为
  Pack:
    generate_model: true
    parent_model: "item/generated"
    textures:
      - default/armors/magic_elytra                           # 物品栏图标
  Components:
    equippable:
      slot: CHEST                                              # 鞘翅占据胸部槽位
      model: oraxen:magic_elytra                               # 注意: model 名保留 _elytra 后缀
```

### 纹理文件

为鞘翅提供 `magic_elytra.png` 纹理文件 (与盔甲层纹理放在同一文件夹中)。Oraxen 会自动生成带有 `wings` 图层的装备模型。

```
~/textures/default/armors/magic_elytra.png    # 鞘翅翅膀纹理
```

### 鞘翅检测

Oraxen 通过以下三种方式之一检测物品是否为鞘翅:

1. **物品 ID 包含 `_elytra` 后缀** (推荐)
2. **material 设为 `ELYTRA`**
3. **物品元标记 `isGlider()`**

满足任意一个条件即可触发鞘翅行为。

## 与其他方法的对比

### 为什么组件方式是最佳选择

#### vs 纹饰方式 (Trims, 1.20-1.21.1)

| 对比点 | 组件 | 纹饰 |
|--------|:----:|:----:|
| 基础材质限制 | **无限制** — 可使用 PAPER, 任意盔甲等 | 仅限于 CHAINMAIL (可配置) |
| 需要服务器重启循环 | **否** — `/o reload` 即刻生效 | **是** — 第一次启动→生成数据包→停止→第二次启动 |
| Minecraft 版本要求 | 1.21.2+ | 1.20-1.21.1 |

#### vs 着色器方式 (Shaders, 1.18-1.19.4)

| 对比点 | 组件 | 着色器 |
|--------|:----:|:----:|
| 基础材质限制 | **无限制** | 仅限于 LEATHER (皮革) |
| Optifine 着色器 | **原生兼容** | Oraxen 自动生成 CIT 修复 |
| Iris 着色器 | **原生兼容** | 需要额外安装 CIT Resewn 模组 |
| 纹理位深要求 | 无特殊要求 | **必须 32 位** — 否则原版客户端显示黑像素 |
| 盔甲分辨率 | 统一 (settings.yml) | 统一 (settings.yml) |
| 发光纹理 (`_e.png`) | 支持 | 支持 |

### 何时应该坚持旧方法

- **服务器运行 1.20-1.21.1**: 使用纹饰方式
- **服务器运行 1.18-1.19.4**: 使用着色器方式
- **需要兼容非常旧的客户端**: 使用着色器方式
- **其他所有情况**: **使用组件方式**

## 常见问题

### Q: 材质设为 PAPER 后, 盔甲有防御值吗?

**没有。** `material` 只决定物品的基础属性。如果需要盔甲防御值, 应通过 `Attribute` 组件添加:

```yaml
ruby_helmet:
  material: PAPER
  Components:
    equippable:
      slot: HEAD
      model: oraxen:ruby
    attribute_modifiers:            # 添加属性修改器
      - attribute: armor            # 盔甲值
        operation: add_value
        amount: 3
      - attribute: armor_toughness  # 盔甲韧性
        operation: add_value
        amount: 2
```

### Q: 可以使用 DIAMOND_CHESTPLATE 作为材质吗?

**可以。** 这也是推荐的简便做法 — 如果你使用 `DIAMOND_HELMET` 作为头盔的材质, 它会自动继承钻石盔甲的原版防御值和耐久度, 无需手动添加 Attribute 组件。

但需要注意: 原版材质自带的属性可能会与你添加的自定义属性叠加, 导致数值异常。建议测试后选择一种方式。

### Q: 纹理文件无法加载?

检查以下几点:
1. 文件名是否正确 (`<盔甲名>_armor_layer_1.png`)
2. 文件路径是否在资源包纹理目录下
3. `settings.yml` 中 `CustomArmor.armor_type` 是否为 `COMPONENTS`
4. 是否执行了 `/o reload pack` 或重启服务器

### Q: 模型不显示或显示为紫色/黑色方块?

- 检查 `model` 值格式: 必须是 `oraxen:<盔甲名>` (不含 `_helmet` 后缀)
- 确保 `model` 值与你的物品 ID 前缀匹配
- 查看控制台是否有模型加载错误

### Q: 可以给盔甲添加纹饰吗?

**可以!** 组件方式完全支持 Minecraft 原版盔甲纹饰系统。你可以在锻造台中使用盔甲纹饰锻造模板来给自定义盔甲添加纹饰图案。

## 配置文件清单

创建一套完整的组件盔甲套装需要准备:

```
资源包纹理:
├── textures/default/armors/
│   ├── <盔甲名>_armor_layer_1.png     ← [必须] 盔甲层 1 (64x32@16px)
│   ├── <盔甲名>_armor_layer_2.png     ← [必须] 盔甲层 2 (64x32@16px)
│   ├── <盔甲名>_helmet.png            ← [必须] 头盔物品图标
│   ├── <盔甲名>_chestplate.png        ← [必须] 胸甲物品图标
│   ├── <盔甲名>_leggings.png          ← [必须] 护腿物品图标
│   ├── <盔甲名>_boots.png             ← [必须] 靴子物品图标
│   └── <盔甲名>_elytra.png            ← [可选] 鞘翅纹理 (如有)
│
Oraxen 配置:
├── settings.yml:
│   └── CustomArmor.armor_type: COMPONENTS
│
└── items/<你的配置>.yml:
    ├── <盔甲名>_helmet
    ├── <盔甲名>_chestplate
    ├── <盔甲名>_leggings
    ├── <盔甲名>_boots
    └── <盔甲名>_elytra              ← [可选]
```
