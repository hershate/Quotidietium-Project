# 音符盒方块 (NoteBlock) 配置模板

> **机制说明**: 音符盒机制使用 Minecraft 的音符盒状态来创建自定义方块。提供多达约 **800 种独特的方块变体**，是大多数自定义方块的最佳选择。
>
> **适用场景**: 实心方块（矿石、石头变体、木板）、需要标准碰撞箱的方块、需要最多槽位的方块。
>
> **Paper 服务器推荐**: 在 `config/paper-global.yml` 中启用:
> ```yaml
> block-updates:
>   disable-noteblock-updates: true
> ```

---

## 一、全局配置 (mechanics.yml)

将以下内容配置在 `plugins/Oraxen/mechanics.yml` 中：

```yaml
# ============================================================
# 音符盒机制全局配置 (plugins/Oraxen/mechanics.yml)
# ============================================================
noteblock:
  # [必需] 启用/禁用此机制
  enabled: true

  # [可选] 可以破坏自定义方块的镐工具等级 (默认: 以下全部)
  # 如果未列出某等级，该等级的镐将无法破坏自定义方块
  tool_types:
    - WOODEN      # 木镐
    - STONE       # 石镐
    - IRON        # 铁镐
    - GOLDEN      # 金镐
    - DIAMOND     # 钻石镐
    - NETHERITE   # 下界合金镐

  # [可选] 农场方块干燥检查间隔（刻），仅在使用 FarmBlock 子机制时需要
  # 20刻 = 1秒。值越大检查越少，性能越好
  farmblock_check_delay: 1000

  # [可选] 是否移除 mineable/axe 标签，防止斧头快速破坏自定义方块
  # true = 斧头无法快速挖掘自定义音符盒方块
  # false = 保留原版行为（斧头可快速挖掘）
  remove_mineable_tag: false
```

## 二、物品/方块配置模板

所有音符盒方块配置在 `plugins/Oraxen/items/` 目录下的 YAML 文件中。

### 2.1 最简配置 (完整方块)

```yaml
# ============================================================
# 示例: 最简单的自定义方块
# ============================================================
my_simple_block:
  # ---- 基础信息 ----
  # [必需] 显示名称，支持 MiniMessage 格式
  displayname: "<white>我的自定义方块"

  # [必需] 物品的基础材质，方块类物品通常用 PAPER、DIAMOND 等
  # 这个材质决定了手持时的物品外观和合成配方中的物品类型
  material: PAPER

  # ---- 资源包/模型配置 ----
  Pack:
    # [必需] 是否自动生成模型文件
    generate_model: true

    # [必需] 父模型类型，决定了方块的形状和纹理映射
    # 可选值见下方「父模型说明」
    parent_model: "block/cube_all"

    # [必需] 纹理文件列表（不需要 .png 扩展名）
    # 纹理文件放在 plugins/Oraxen/pack/textures/ 目录下
    textures:
      - my_block_texture

  # ---- 方块机制配置 ----
  Mechanics:
    noteblock:
      # [必需★] 自定义变体编号，范围 1-800 (最大约800)
      # 每个音符盒方块必须使用唯一的 custom_variation
      custom_variation: 1

      # [必需★] 模型引用，通常与方块 ID 相同
      model: my_simple_block
```

### 2.2 父模型 (parent_model) 详细说明

```yaml
# ============================================================
# 父模型选择指南
# ============================================================
# 以下是 Oraxen 支持的 5 种父模型:

# --- 模型 1: block/cube_all ---
# 所有6个面使用相同纹理，需要 1 个纹理文件
# 适用于: 矿石、金属块、木板、石砖、玻璃等
cube_all_example:
  Pack:
    generate_model: true
    parent_model: "block/cube_all"
    textures:
      - stone_texture     # 全部6面使用此纹理

# --- 模型 2: block/cube_column ---
# 顶面/底面 + 侧面分开使用纹理，需要 2 个纹理文件
# 第1个纹理 = 顶面和底面，第2个纹理 = 四个侧面
# 适用于: 原木、柱子、玄武岩、骨块等
cube_column_example:
  Pack:
    generate_model: true
    parent_model: "block/cube_column"
    textures:
      - log_top           # 顶面 + 底面纹理
      - log_side          # 四个侧面纹理

# --- 模型 3: block/cross ---
# 十字交叉模型（平面），需要 1 个纹理文件
# 适用于: 植物、花朵、树苗、草丛、蘑菇等
cross_example:
  Pack:
    generate_model: true
    parent_model: "block/cross"
    textures:
      - flower_texture

# --- 模型 4: block/orientable ---
# 前面/侧面/顶部三个方向纹理，需要 3 个纹理文件
# 第1个纹理 = 前面，第2个纹理 = 侧面，第3个纹理 = 顶部
# 适用于: 熔炉、侦测器、投掷器等有方向的方块
orientable_example:
  Pack:
    generate_model: true
    parent_model: "block/orientable"
    textures:
      - front_texture     # 前面
      - side_texture      # 侧面
      - top_texture       # 顶部

# --- 模型 5: block/orientable_vertical ---
# 垂直方向模型，需要 2 个纹理文件
# 第1个纹理 = 顶面/底面，第2个纹理 = 侧面
# 适用于: 垂直朝向的方块
orientable_vertical_example:
  Pack:
    generate_model: true
    parent_model: "block/orientable_vertical"
    textures:
      - top_bottom        # 顶面 + 底面纹理
      - side_texture      # 侧面纹理

# ============================================================
# 父模型对比表
# ============================================================
# | parent_model              | 纹理数量 | 适用场景               |
# |---------------------------|----------|------------------------|
# | block/cube_all            | 1        | 矿石、金属块、石砖     |
# | block/cube_column         | 2        | 原木、柱子、玄武岩     |
# | block/cross               | 1        | 植物、花朵、树苗       |
# | block/orientable          | 3        | 熔炉、侦测器           |
# | block/orientable_vertical | 2        | 垂直朝向方块           |
```

## 三、完整配置模板（含所有可选字段）

```yaml
# ============================================================
# 完整示例: 自定义矿石 (包含所有常用配置选项)
# ============================================================
amethyst_ore:
  # ---- 基础信息 ----
  displayname: "<light_purple>紫水晶矿石"
  material: DIAMOND

  # ---- 资源包/模型配置 ----
  Pack:
    generate_model: true
    parent_model: "block/cube_all"
    textures:
      - amethyst_ore

  # ---- 方块机制 (完整配置) ----
  Mechanics:
    noteblock:
      # ========== 核心配置 ==========

      # [必需★] 自定义变体编号 (1-800)
      custom_variation: 1

      # [必需★] 模型名称
      model: amethyst_ore

      # ========== 物理属性 ==========

      # [可选] 硬度，数值越大挖掘时间越长
      # 参考: 石头=3, 铁矿石=5, 黑曜石=50, 基岩=∞
      hardness: 6

      # [可选] 光照等级 0-15，默认为 0（不发光）
      # 参考: 火把=14, 荧石=15, 红石矿石(激活)=9
      light: 0

      # [可选] 防爆，设为 true 使方块在爆炸中存活（如 TNT、苦力怕）
      blast_resistant: true

      # [可选] 像沙子/沙砾一样受重力影响下落
      is_falling: false

      # [可选] 防止被活塞推动
      immovable: false

      # [可选] 允许被火焰/打火石点燃
      can_ignite: false

      # ========== 方块音效 ==========
      # [可选] 自定义方块的各种交互音效
      # block_sounds 有两种写法：简写和详细写法（见下方说明）
      block_sounds:
        # 简写方式 - 直接指定音效 ID
        place_sound: block.stone.place
        break_sound: block.stone.break
        hit_sound: block.stone.hit
        step_sound: block.stone.step
        fall_sound: block.stone.fall

        # [可选] 全局音量和音调 (应用于所有未单独设置的音效)
        volume: 0.8      # 音量 0.0-1.0
        pitch: 0.8       # 音调 0.5-2.0

      # [可选] 逐音效自定义音量和音调的详细写法:
      # block_sounds:
      #   place:
      #     sound: block.amethyst_block.place
      #     volume: 1.0
      #     pitch: 0.8
      #   break:
      #     sound: block.amethyst_block.break
      #     volume: 1.0
      #     pitch: 0.9
      #   hit:
      #     sound: block.amethyst_block.hit
      #     volume: 0.6
      #     pitch: 0.7
      #   step:
      #     sound: block.amethyst_block.step
      #     volume: 0.4
      #     pitch: 0.6
      #   fall:
      #     sound: block.amethyst_block.fall
      #     volume: 0.5
      #     pitch: 0.7

      # ========== 掉落物配置 ==========
      # [可选] 配置方块被破坏时的掉落行为
      drop:
        # [可选] 是否必须用精准采集才能掉落 (默认: false)
        # true = 只有精准采集的工具才能让方块掉落
        silktouch: true

        # [可选] 是否受时运附魔影响 (默认: false)
        # true = 时运会增加掉落物数量
        fortune: true

        # [可选] 挖掘所需的最低工具等级 (默认: STONE)
        # 可用值: WOODEN, STONE, IRON, GOLDEN, DIAMOND, NETHERITE
        # 低于此等级的工具破坏方块后不会掉落任何物品
        minimal_type: IRON

        # [可选] 最适合的挖掘工具类型
        # 使用正确工具类型的挖掘速度会更快
        best_tools:
          - PICKAXE       # 镐
          # - AXE         # 斧
          # - SHOVEL      # 锹
          # - HOE         # 锄头
          # - SHEARS      # 剪刀
          # - SWORD       # 剑

        # [必需] 掉落物列表
        # 每个条目定义一个掉落物及其掉率
        loots:
          # 主掉落物
          - oraxen_item: amethyst     # [必需] Oraxen 物品 ID 或原版物品 ID
            probability: 1.0          # [必需] 掉率 0.0-1.0 (1.0 = 100%)
            max_amount: 1             # [可选] 最大掉落数量 (默认: 1)
            min_amount: 1             # [可选] 最小掉落数量 (默认: 1)

          # 额外掉落物（概率独立计算）
          - oraxen_item: DIAMOND      # 也可以是原版物品 material 名
            probability: 0.1          # 10% 几率额外掉落钻石
            max_amount: 2

          # 经验掉落
          - oraxen_item: experience
            probability: 1.0
            max_amount: 5

      # ========== 存储容器 ==========
      # [可选] 将方块变成可打开的容器
      # 当与 blocklocker 一起使用时需要 barrier: true 以防止音符盒弹音
      # storage:
      #   # [必需] 存储类型
      #   type: STORAGE
      #
      #   # [可选] 行数 1-6 (默认: 6)
      #   rows: 5
      #
      #   # [可选] 容器标题，支持 MiniMessage 格式
      #   title: "<red>我的存储箱"
      #
      #   # [可选] 打开/关闭容器时播放的音效
      #   open_sound: entity.shulker.open
      #   close_sound: entity.shulker.close
      #
      #   # [可选] 防止音符盒本身发出声音 (使用存储时必须设为 true)
      #   barrier: true

      # 存储类型说明:
      # - STORAGE      普通箱子，任何人都可以访问
      # - PERSONAL     每个玩家独立的物品栏（类似末影箱但各自独立）
      # - ENDERCHEST   直接访问玩家的末影箱
      # - DISPOSAL     垃圾桶，关闭容器时所有物品被删除

      # ========== 方向性放置 (directional) ==========
      # [可选] 使方块根据放置方向改变纹理（类似原木、熔炉）
      # 方向类型:
      # - LOG: 3种变体 (Y轴、X轴、Z轴)，类似原木
      # - FURNACE: 4种变体 (北、南、东、西)，类似熔炉
      # - DROPPER: 6种变体 (全部6个方向)，类似投掷器
      # directional:
      #   directional_type: LOG
      #   y_block: custom_log_y    # Y轴朝向的子方块 ID
      #   x_block: custom_log_x    # X轴朝向的子方块 ID
      #   z_block: custom_log_z    # Z轴朝向的子方块 ID

      # ========== 去皮原木机制 ==========
      # [可选] 需要 Oraxen 1.134.0+
      # 允许自定义原木像原版原木一样被斧头去皮
      # logStrip:
      #   stripped_log: stripped_custom_log  # 去皮后变成的方块 ID
      #   drop: bark                          # [可选] 去皮时额外掉落的物品

      # ========== 限制放置 ==========
      # [可选] 限制方块可以放置的位置
      # limited_placing:
      #   # 允许/禁止在以下表面放置:
      #   roof: true       # 天花板
      #   floor: true      # 地面
      #   wall: true       # 墙壁
      #
      #   # [必需] 类型: ALLOW (白名单) 或 DENY (黑名单)
      #   type: ALLOW
      #
      #   # [可选] 允许/禁止的原版方块类型列表
      #   block_types:
      #     - GRASS_BLOCK
      #     - DIRT
      #     - STONE
      #     - DEEPSLATE
      #
      #   # [可选] 允许/禁止的方块标签
      #   block_tags:
      #     - base_stone_overworld  # 主世界石头标签
      #     - base_stone_nether     # 下界石头标签
      #     - dirt                  # 泥土标签
      #
      #   # [可选] 允许/禁止的 Oraxen 自定义方块
      #   oraxen_blocks:
      #     - ruby_ore
      #     - custom_stone

      # ========== BlockLocker 保护 ==========
      # [可选] 启用 BlockLocker 插件保护
      # blocklocker:
      #   # [必需] 是否允许此方块被保护
      #   can_protect: true
      #
      #   # [必需] 保护类型
      #   protection_type: CONTAINER
      #   # 可选值:
      #   # - CONTAINER   容器类型保护
      #   # - DOOR        门类型保护
      #   # - ATTACHABLE  附着类型保护

      # ========== ClickActions 点击动作 ==========
      # [可选] 玩家点击方块时执行命令、播放音效或发送消息
      # clickActions:
      #   # 动作组 1: 有条件限制的点击
      #   - conditions:
      #       # 条件表达式，使用 Spring EL 语法
      #       # 可用对象: #player, #server
      #       - '#player.hasPermission("my.permission")'
      #       - '#player.world.name == "world"'
      #     actions:
      #       # 控制台执行命令
      #       - '[console] say %player% 点击了方块!'
      #       # 玩家执行命令
      #       - '[player] help'
      #       # 发送聊天消息
      #       - '[message] <green>你点击了这个方块!'
      #       # 发送操作栏消息
      #       - '[actionbar] <gray>点击了自定义方块'
      #       # 播放音效 {source=音源 volume=音量 pitch=音调}
      #       - '{source=AMBIENT volume=0.1 pitch=1} [sound] minecraft:block.shulker_box.close'
      #
      #   # 动作组 2: 无条件点击
      #   - conditions: []
      #     actions:
      #       - '[message] <yellow>欢迎使用自定义方块!'

      # ========== 农场方块 (FarmBlock) ==========
      # [可选] 将此方块配置为农场方块系统的一部分
      # 详见「农场方块.md」模板文件
      # farmblock:
      #   moistFarmBlockPath: 湿润版本方块ID
      #   farmBlockPath: 干燥版本方块ID (用于湿润方块回指)
      #   farmBlockDryOutTime: 30000  # 水分耗尽时间（毫秒）
```

## 四、方向性方块完整配置

方向性方块需要一个「父方块」和多个「子方块」配合使用。子方块使用 `excludeFromInventory: true`
从物品栏中隐藏。

```yaml
# ============================================================
# 方向性方块 - 父方块配置 (LOG 类型示例)
# ============================================================
custom_log:
  displayname: "<white>自定义原木"
  material: PAPER
  Pack:
    generate_model: false       # 使用自定义模型时设为 false
    model: custom_log_model     # 自定义模型的路径
  Mechanics:
    noteblock:
      model: custom_log_model
      custom_variation: 1
      directional:
        directional_type: LOG   # LOG / FURNACE / DROPPER
        y_block: custom_log_y   # Y 轴朝向的方块
        x_block: custom_log_x   # X 轴朝向的方块
        z_block: custom_log_z   # Z 轴朝向的方块
      hardness: 1
      drop:
        best_tools:
          - AXE
        loots:
          - {oraxen_item: custom_log, probability: 1.0}

# ============================================================
# 方向性方块 - Y 轴子方块
# ============================================================
custom_log_y:
  excludeFromInventory: true    # [重要] 从物品栏隐藏
  material: PAPER
  Pack:
    generate_model: false
    model: custom_log_model_y
  Mechanics:
    noteblock:
      custom_variation: 1
      directional:
        parent_block: custom_log  # 指向父方块

# ============================================================
# 方向性方块 - X 轴子方块
# ============================================================
custom_log_x:
  excludeFromInventory: true
  material: PAPER
  Pack:
    generate_model: false
    model: custom_log_model_x
  Mechanics:
    noteblock:
      custom_variation: 2
      directional:
        parent_block: custom_log

# ============================================================
# 方向性方块 - Z 轴子方块
# ============================================================
custom_log_z:
  excludeFromInventory: true
  material: PAPER
  Pack:
    generate_model: false
    model: custom_log_model_z
  Mechanics:
    noteblock:
      custom_variation: 3
      directional:
        parent_block: custom_log

# ============================================================
# 方向类型与变体数对照
# ============================================================
# | 类型     | 消耗变体数 | 朝向说明               |
# |----------|-----------|------------------------|
# | LOG      | 3         | Y轴、X轴、Z轴         |
# | FURNACE  | 4         | 北、南、东、西         |
# | DROPPER  | 6         | 全部6个方向           |
```

```yaml
# ============================================================
# 音符盒机制配置字段一览

# drop                | object    | 可选 | 不掉落   | 掉落物配置

# directional         | object    | 可选 | -        | 方向性放置配置
# logStrip            | object    | 可选 | -        | 去皮原木配置
# limited_placing     | object    | 可选 | -        | 放置限制配置
# blocklocker         | object    | 可选 | -        | BlockLocker 保护

# farmblock           | object    | 可选 | -        | 农场方块子机制
# barrier             | boolean   | 可选 | false    | 阻止音符盒发声(配合storage使用)
```

## 六、常见场景示例

### 6.1 自定义矿石

```yaml
ruby_ore:
  displayname: "<red>红宝石矿石"
  material: DIAMOND
  Pack:
    generate_model: true
    parent_model: "block/cube_all"
    textures:
      - ruby_ore
  Mechanics:
    noteblock:
      custom_variation: 2
      model: ruby_ore
      hardness: 8
      light: 3
      blast_resistant: true
      block_sounds:
        place_sound: block.deepslate.place
        break_sound: block.deepslate.break
        step_sound: block.deepslate.step
      drop:
        silktouch: true
        fortune: true
        minimal_type: IRON
```

## 七、注意事项

1. **custom_variation 唯一性**: 每个音符盒方块必须使用唯一的 `custom_variation` 值，范围 1 至约 800。重复会导致方块渲染错误。
2. **Paper 优化**: 强烈建议在 `config/paper-global.yml` 中禁用音符盒更新以获得最佳性能。
3. **model 与 Pack 的对应**: `Mechanics.noteblock.model` 的值应与 `Pack` 中的模型引用相匹配。使用自动生成时通常等于方块 ID。
4. **存储需要 barrier**: 当方块配置了 `storage` 时，需要同时设置 `barrier: true` 来阻止音符盒本身的弹音行为。
5. **方向性方块共消耗 3/4/6 个变体**: 方向性子方块各自占据一个 `custom_variation`。从 800 个变体池中扣除。
6. **移除 mineable 标签**: 如果你的自定义方块看起来不像木头但使用音符盒作为基础方块，玩家可能用斧头快速挖掘。设置 `remove_mineable_tag: true` 来防止。
