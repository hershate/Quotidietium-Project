## 使用方式

1. 将对应的 YAML 配置复制到 `plugins/EpicAchievements/achievements/` 对应分类文件夹
2. 根据需要修改成就 ID、名称、数值和奖励
3. 执行 `/achievements reload` 重新加载配置
4. 确保服务器 ID 在 `config.yml` 中正确设置
