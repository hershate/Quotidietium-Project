# 基础挑战成就

> 最简单的成就类型。每个成就只有一个层级（tier），玩家完成指定次数即解锁。
> 这是理解 EpicAchievements 成就配置体系的**最佳起点**。

---

## 设计思路

基础挑战成就只需要三个核心要素：
1. **触发类型（type）**：告诉插件"玩家做什么时检查成就"（钓鱼、挖矿、杀怪等）
2. **条件（conditions）**：告诉插件"具体做了什么才计数"（钓到什么物品、挖什么方块、杀什么生物）
3. **目标值（required-amount）**：告诉插件"做多少次达标"

---

## 完整示例 1：钓鱼挑战（FISH）

追踪玩家钓到附魔书的次数。

```yaml
lucky-catch:
  type: FISH  # 触发类型：钓鱼时检测钓到的物品
  name: "&a幸运之钩"  # 成就显示名称（支持 & 颜色代码）
  description:  # 成就描述文本（YAML 列表格式）
    - "&7从水中钓到 &b50 &7本附魔书"
  conditions:  # 过滤条件列表
    - type: items  # 条件类型：匹配物品
      items:  # 匹配的物品列表（OR 关系）
        - ENCHANTED_BOOK
  tiers:  # 层级配置
    1:  # 层级编号（必须从 1 开始）
      required-amount: 50  # 完成 50 次即达标
      rewards:  # 达成奖励列表
        - type: points  # 奖励类型：增加成就点数
          amount: 20  # 给予 20 成就点数
        - type: message  # 奖励类型：发送私聊消息
          message: "&a你完成了成就：幸运之钩！钓到了50本附魔书！"
```

## 完整示例 2：伐木挑战（BREAK）

追踪玩家砍伐各类原木的总数。

```yaml
woodcutter:
  type: BREAK  # 触发类型：破坏方块时检测
  name: "&a伐木工"  # 成就显示名称
  description:  # 成就描述
    - "&7砍伐 &e500 &7棵原木"
  conditions:  # 过滤条件
    - type: blocks  # 条件类型：匹配方块
      blocks:  # 匹配的方块列表（OR 关系，任一即计数）
        - OAK_LOG
        - SPRUCE_LOG
        - BIRCH_LOG
        - JUNGLE_LOG
        - ACACIA_LOG
        - DARK_OAK_LOG
        - CHERRY_LOG
        - MANGROVE_ROOT
  tiers:
    1:
      required-amount: 500  # 砍伐 500 棵原木达标
      rewards:
        - type: points
          amount: 30  # 给予 30 成就点数
        - type: vault  # 奖励类型：给予 Vault 货币
          amount: 1000  # 给予 1000 货币
```

## 完整示例 3：僵尸杀手（KILL + 生存模式限制）

在生存模式下击杀僵尸才计数，防止创造模式刷成就。

```yaml
zombie-hunter:
  type: KILL  # 触发类型：击杀实体时检测
  name: "&a僵尸猎人"  # 成就显示名称
  description:
    - "&7在生存模式下击杀 &c100 &7只僵尸"
  conditions:
    - type: entities  # 条件类型：匹配被击杀的实体
      entities:
        - ZOMBIE
    - type: game_modes  # 条件类型：匹配游戏模式
      game-modes:
        - SURVIVAL  # 仅在生存模式下计数
  tiers:
    1:
      required-amount: 100  # 击杀 100 只僵尸达标
      rewards:
        - type: points
          amount: 25
        - type: vault
          amount: 800
```

## 关键概念总结

| 概念 | 说明 | 是否必需 |
|------|------|:--------:|
| `type` | 触发类型（FISH / BREAK / KILL 等） | **必填** |
| `name` | 成就显示名称（支持 `&` 颜色代码） | 推荐 |
| `description` | 成就描述文本（YAML 列表格式） | 推荐 |
| `conditions` | 过滤条件列表，每项含 `type` 和匹配字段 | 可选 |
| `tiers` | 层级配置，每层含 `required-amount` 和可选 `rewards` | **必填** |
| `rewards` | 奖励列表，每项含 `type` 和对应参数 | 可选 |

### 常见条件类型速查

| 条件类型 | 匹配字段 | 适用 type |
|---------|---------|-----------|
| `items` | `items` | FISH, CRAFT, CONSUME, ENCHANT |
| `blocks` | `blocks` | BREAK, PLACE, HARVEST |
| `entities` | `entities` | KILL, DAMAGE, TAME |
| `game_modes` | `game-modes` | 任意 |
| `worlds` | `worlds` | 任意 |
| `potion_types` | `types` | BREW, CONSUME |
| `damage_causes` | `causes` | DAMAGE |

### 常见奖励类型速查

| 奖励类型 | 参数 | 说明 |
|---------|------|------|
| `points` | `amount` | 增加成就点数 |
| `vault` | `amount` | 给予 Vault 货币 |
| `message` | `message` | 发送私聊消息 |
| `broadcast` | `message` | 全服广播 |
| `command` | `command` | 执行控制台命令 |
| `item` | `material`, `amount` | 给予物品 |
| `experience` | `amount` | 给予经验值 |
| `title` | `title`, `subtitle` | 发送标题消息 |

> **核心原则：基础成就用单类型 + 单条件 + 单层级，保持简单明确。**
