# 服务器分类配置

> 多服务器网络中成就分类（categories）的配置方案。通过 categories.yml 定义分类，控制每个成就在 GUI 中的分组显示和可见性。

---

## 设计思路

当服务器有多个子服务器（生存、创造、空岛等）时，需要合理组织成就分类：

1. **按服务器隔离成就**：生存服的成就不应出现在创造服的 GUI 中
2. **跨服共享成就**：某些通用成就需要跨所有服务器共享
3. **GUI 组织**：将相似成就归类，玩家更容易找到目标
4. **插槽布局**：控制成就在 GUI 中的位置

---

## 完整示例 1：生存模式分类（servers: survival）

```yaml
survival:  # 分类标识符（唯一键名）
  name: "&a生存挑战"  # 分类显示名称
  description:  # 分类描述
    - "&7在生存模式中完成各种挑战"
  servers:  # 服务器限定列表
    - survival  # 仅在 survival 服务器显示
  item:  # GUI 图标配置
    material: DIAMOND_PICKAXE  # 图标材质
    slot: 12  # GUI 插槽位置（0-53）
```

---

## 完整示例 2：创造模式分类（servers: creative）

```yaml
creative:  # 分类标识符
  name: "&b创意天地"
  description:
    - "&7在创造模式中展现你的建筑才华"
  servers:
    - creative  # 仅在 creative 服务器显示
  item:
    material: GRASS_BLOCK
    slot: 13
```

---

## 完整示例 3：全局分类（servers: ALL）

使用 `ALL` 关键字表示在所有服务器均显示。

```yaml
global:  # 分类标识符
  name: "&6&l玩家生涯"
  description:
    - "&7追踪你在所有服务器的整体游戏生涯"
  servers:
    - ALL  # ALL 表示在所有服务器均显示
  item:
    material: TOTEM_OF_UNDYING
    slot: 14
```

---

## 完整示例 4：完整 categories.yml

```yaml
survival:  # 生存分类
  name: "&a生存挑战"
  description:
    - "&7在生存模式中完成各种挑战"
  servers:
    - survival  # 仅 survival 子服可见
  item:
    material: DIAMOND_PICKAXE  # 图标：钻石镐
    slot: 12  # GUI 第 2 行第 4 列

creative:  # 创造分类
  name: "&b创意天地"
  description:
    - "&7在创造模式中展现你的建筑才华"
  servers:
    - creative  # 仅 creative 子服可见
  item:
    material: GRASS_BLOCK  # 图标：草方块
    slot: 13  # GUI 第 2 行第 5 列

global:  # 全局分类
  name: "&6&l玩家生涯"
  description:
    - "&7追踪你在所有服务器的整体游戏生涯"
  servers:
    - ALL  # 所有子服均可见
  item:
    material: TOTEM_OF_UNDYING  # 图标：不死图腾
    slot: 14  # GUI 第 2 行第 6 列
```

## 关键概念总结

| 属性 | 说明 | 是否必需 |
|------|------|:--------:|
| `name` | 分类显示名称 | **必填** |
| `description` | 分类描述（YAML 列表） | 推荐 |
| `servers` | 服务器限定列表 | 可选（默认 ALL） |
| `item.material` | GUI 图标材质 | **必填** |
| `item.slot` | GUI 插槽位置（0-53） | 推荐 |

### Servers 配置模式

| 配置 | 效果 | 使用场景 |
|------|------|---------|
| `servers: [ALL]` | **所有服务器**可见 | 全局生涯、通用成就 |
| `servers: [survival]` | 仅 **survival** 服务器可见 | 生存模式专属成就 |
| `servers: [survival, skyblock]` | **多个指定**服务器可见 | 共享部分成就 |
