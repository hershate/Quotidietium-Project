# 奖励等级系统

> 本文档提供 EpicAchievements 奖励等级系统（Reward Leveling System）的完整配置参考。
> 玩家可以使用完成成就获得的**点数**来解锁奖励等级，每等级解锁后可领取对应奖励。
> 配置文件位于 `plugins/EpicAchievements/rewards.yml`。

---

## 系统概述

奖励等级系统允许你创建多层次的奖励体系，玩家通过积累成就点数逐步解锁更高级的奖励。

**核心机制：**
- 玩家完成成就获得**点数**
- 点数可用于解锁**奖励等级**
- 每个等级需要一定**点数**才能解锁
- 解锁后可领取对应的**奖励**
- 可定义**多系列**奖励（如 normal、special）

---

## 完整配置模板

```yaml
# =============================================================================
# rewards.yml - 奖励等级系统完整配置
# 位置: plugins/EpicAchievements/rewards.yml
# =============================================================================

# =============================================================================
# 奖励系列（Reward Series）
# 可以定义多个奖励系列，每个系列独立运作
# 当同一等级有多个系列的奖励时，使用 weight 决定优先级
# =============================================================================
rewards:

  # ===== 普通奖励系列 =====
  normal:
    # ------ 等级范围 ------
    levels:
      from: 1                          # 起始等级
      to: 48                           # 结束等级
      # step: 1                        # （可选）等级增量，默认值为 1

    # ------ 解锁条件 ------
    # 解锁该等级所需的点数。支持数学表达式！
    required-points: "{level} * 100"

    # ------ 权重（可选） ------
    # 如果同一等级定义了多个奖励系列，将使用权重最高的那个
    # 默认值: 1
    # weight: 1

    # ------ 奖励列表 ------
    rewards:
      - type: vault
        amount: "{level} * 10"         # 支持数学表达式！

    # ------ 锁定状态显示 ------
    # 玩家尚未达到该等级时显示的物品
    locked:
      material: "COAL"                 # 物品材质
      name: "&c普通奖励等级 {level}"    # 物品名称（支持占位符）
      lore:                            # 物品描述
        - "&8等级 {level}"
        - "&7所需点数: &e{points}"
        - ""
        - "&7奖励:"
        - "{rewards}"
        - ""
        - "&c你还无法领取此奖励"

    # ------ 已领取状态显示 ------
    # 玩家已领取该等级奖励时显示的物品
    claimed:
      material: "GOLD_NUGGET"          # 物品材质
      name: "&a普通奖励等级 {level}"    # 物品名称
      lore:
        - "&8等级 {level}"
        - "&7所需点数: &e{points}"
        - ""
        - "&7奖励:"
        - "{rewards}"
        - ""
        - "&a你已经领取过此奖励！"

    # ------ 未领取状态显示 ------
    # 玩家已解锁但尚未领取奖励时显示的物品
    unclaimed:
      material: "GOLD_NUGGET"          # 物品材质
      name: "&e普通奖励等级 {level}"    # 物品名称
      lore:
        - "&8等级 {level}"
        - "&7所需点数: &e{points}"
        - ""
        - "&7奖励:"
        - "{rewards}"
        - ""
        - "&e点击领取此奖励！"
      glow: true                       # 物品是否发光（附魔光泽）

  # ===== 特殊奖励系列 =====
  special:
    # ------ 每 5 级一个特殊奖励 ------
    levels:
      from: 5
      to: 48
      step: 5                          # 每 5 级一个特殊奖励

    # ------ 解锁条件 ------
    required-points: "{level} * 100"

    # ------ 权重 ------
    weight: 2                          # 权重 2 > 1，因此同等级时优先显示 special

    # ------ 奖励列表 ------
    rewards:
      - type: vault
        amount: "{level} * 20"

    # ------ 锁定状态 ------
    locked:
      material: "COAL_BLOCK"
      name: "&c特殊奖励等级 {level}"
      lore:
        - "&8等级 {level}"
        - "&7所需点数: &e{points}"
        - ""
        - "&7奖励:"
        - "{rewards}"
        - ""
        - "&c你还无法领取此奖励"

    # ------ 已领取状态 ------
    claimed:
      material: "GOLD_BLOCK"
      name: "&a特殊奖励等级 {level}"
      lore:
        - "&8等级 {level}"
        - "&7所需点数: &e{points}"
        - ""
        - "&7奖励:"
        - "{rewards}"
        - ""
        - "&a你已经领取过此奖励！"

    # ------ 未领取状态 ------
    unclaimed:
      material: "GOLD_BLOCK"
      name: "&e特殊奖励等级 {level}"
      lore:
        - "&8等级 {level}"
        - "&7所需点数: &e{points}"
        - ""
        - "&7奖励:"
        - "{rewards}"
        - ""
        - "&e点击领取此奖励！"
      glow: true
```

## 多系列奖励说明

> 奖励等级系统支持定义多个奖励系列（如 `normal`、`special`、`vip` 等），在同一等级下可以有多种奖励选择。
> 当同一等级存在多个系列的奖励时，使用 `weight`（权重）决定优先级，权重高的系列将优先显示。

```yaml
# =============================================================================
# 多系列奖励配置示例
# =============================================================================
rewards:

  # ----- 普通系列（权重 1）-----
  normal:
    levels:
      from: 1
      to: 100
      step: 1
    required-points: "{level} * 100"
    weight: 1                         # 默认权重
    rewards:
      - type: vault
        amount: 100
    # ... 状态物品配置 ...

  # ----- 特殊系列（权重 2，每 10 级出现）-----
  special:
    levels:
      from: 10
      to: 100
      step: 10
    required-points: "{level} * 200"
    weight: 2                         # 权重更高，同等级时优先
    rewards:
      - type: vault
        amount: 500
    # ... 状态物品配置 ...

  # ----- VIP 系列（权重 3，仅 VIP 可见）-----
  vip:
    levels:
      from: 5
      to: 50
      step: 5
    required-points: "{level} * 100"
    weight: 3                         # 权重最高
    permission: "group.vip"           # 需要 VIP 权限才能看到
    rewards:
      - type: vault
        amount: 1000
      - type: command
        command: "say {player} 领取了 VIP 奖励等级 {level}！"
    # ... 状态物品配置 ...
```

## 数学表达式支持

> EpicAchievements 的奖励等级系统支持在以下字段中使用数学表达式：
> - `required-points`
> - `amount`（奖励的数值参数）

### 支持的运算符

| 运算符 | 描述 | 示例 |
|--------|------|------|
| `+` | 加法 | `{level} + 10` |
| `-` | 减法 | `{level} - 1` |
| `*` | 乘法 | `{level} * 100` |
| `/` | 除法 | `{level} / 2` |
| `**` | 幂运算 | `{level} ** 2`（等级的平方）|
| `%` | 取模 | `{level} % 5`（判断是否被 5 整除）|

### 支持的函数

| 函数 | 描述 | 示例 |
|------|------|------|
| `floor()` | 向下取整 | `floor({level} / 10)` |
| `ceil()` | 向上取整 | `ceil({level} / 10)` |
| `round()` | 四舍五入 | `round({level} / 3)` |
| `sqrt()` | 平方根 | `sqrt({level} * 100)` |
| `abs()` | 绝对值 | `abs({level} - 50)` |

### 数学表达式示例

```yaml
# =============================================================================
# 数学表达式配置示例
# =============================================================================
rewards:
  normal:
    levels:
      from: 1
      to: 100
    # 等级越高，所需点数增长越快
    required-points: "{level} ** 2 * 50 + 100"

    rewards:
      # 奖励随等级线性增长
      - type: vault
        amount: "{level} * 10 + 50"
      # 每 10 级给予额外奖励
      - type: command
        command: "say {player} 达到了等级 {level}！"
      # 等级平方根形式的奖励
      - type: experience_levels
        amount: "floor(sqrt({level})) + 1"
```

## 三种显示状态说明

| 状态 | 键名 | 描述 | 玩家条件 |
|------|------|------|---------|
| **锁定** | `locked` | 玩家尚未达到该等级，无法领取 | `玩家点数 < required-points` |
| **未领取** | `unclaimed` | 玩家已达到等级但尚未领取奖励 | `玩家点数 >= required-points` 且未领取 |
| **已领取** | `claimed` | 玩家已领取该等级的奖励 | 已点击领取 |

每种状态都可独立配置 `material`、`name`、`lore` 以及可选的 `glow` 属性。

---

## 可用占位符

| 占位符 | 描述 | 可用范围 |
|--------|------|---------|
| `{level}` | 当前等级编号 | 全部字段 |
| `{points}` | 达到该等级所需的点数 | 全部字段 |
| `{rewards}` | 该等级的奖励列表文本 | `lore` 描述中 |
| `{status}` | 该等级的状态文本 | `lore` 描述中 |

> 提示：`{rewards}` 和 `{status}` 占位符主要在物品 lore 中使用，会自动渲染为对应的格式文本。

## 字段参考表

### 奖励系列层级

| 字段 | 必填 | 类型 | 默认值 | 描述 |
|------|------|------|--------|------|
| `levels.from` | 是 | Integer | - | 奖励系列的起始等级 |
| `levels.to` | 是 | Integer | - | 奖励系列的结束等级 |
| `levels.step` | 否 | Integer | `1` | 等级之间的增量 |
| `required-points` | 是 | String | - | 解锁所需点数（支持数学表达式） |
| `weight` | 否 | Integer | `1` | 同等级多系列时的优先级，越高越优先 |
| `permission` | 否 | String | `None` | 查看该系列的权限要求 |
| `rewards` | 是 | List\<Object\> | - | 奖励列表（奖励格式见 奖励配置.md） |

### 显示状态层级

| 字段 | 必填 | 类型 | 描述 |
|------|------|------|------|
| `locked.material` | 是 | String | 锁定状态的物品材质 |
| `locked.name` | 是 | String | 锁定状态的物品名称 |
| `locked.lore` | 否 | List\<String\> | 锁定状态的物品描述 |
| `claimed.material` | 是 | String | 已领取状态的物品材质 |
| `claimed.name` | 是 | String | 已领取状态的物品名称 |
| `claimed.lore` | 否 | List\<String\> | 已领取状态的物品描述 |
| `unclaimed.material` | 是 | String | 未领取状态的物品材质 |
| `unclaimed.name` | 是 | String | 未领取状态的物品名称 |
| `unclaimed.lore` | 否 | List\<String\> | 未领取状态的物品描述 |
| `unclaimed.glow` | 否 | Boolean | 未领取物品是否发光 |

## 文件放置说明

```
plugins/EpicAchievements/
  rewards.yml                         # 奖励等级系统配置文件
  achievements/                       # 成就配置文件夹
```

- 奖励等级系统配置文件必须命名为 `rewards.yml`
- 文件直接放在 `plugins/EpicAchievements/` 根目录下
- 玩家通过完成成就获得的点数来解锁这里的奖励等级
- 每个奖励系列独立运作，多个系列可在同一等级共存
