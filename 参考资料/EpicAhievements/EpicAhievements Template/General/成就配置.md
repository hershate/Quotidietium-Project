# 成就配置模板

> 本文档提供 EpicAchievements 成就配置文件的完整模板参考。
> 成就文件位于 `plugins/EpicAchievements/achievements/<分类名称>/` 文件夹中，每个分类下可放置任意数量的 YAML 文件。

---

## 成就类型说明

> 成就分为两种类型，根据等级（tier）数量自动确定：

| 类型 | 等级数量 | 说明 |
|------|---------|------|
| **CHALLENGE**（挑战） | 单等级（仅 `1` 一个等级） | 一次性完成的独立挑战 |
| **TIERED**（阶梯） | 多等级（`1`、`2`、`3`...） | 逐步递进的系列成就，每完成一级获得递增奖励 |

- 类型由等级数量**自动判定**，无需在配置中显式指定
- CHALLENGE 适合大型里程碑式成就，TIERED 适合渐进式成长成就

## 完整模板

```yaml
# =============================================================================
# 成就标识符（必填）- 唯一标识此成就，请勿修改，否则玩家将丢失进度！
# 只能使用小写字母、数字和下划线
# =============================================================================
my_achievement:

  # ===========================================================================
  # 任务类型（必填）- 成就的触发方式
  # 详见 任务类型参考.md 中的完整列表
  # 常用类型: BREAK, PLACE, KILL, CRAFT, FISH, CONSUME, PICKUP 等
  # ===========================================================================
  type: BREAK

  # ===========================================================================
  # 成就名称（必填）- 显示在消息和菜单中的名称
  # 支持 & 颜色代码
  # ===========================================================================
  name: "&a矿石收集者"

  # ===========================================================================
  # 成就描述（必填）- 显示在消息和菜单中的描述
  # 每行一个字符串，支持 & 颜色代码
  # ===========================================================================
  description:
    - "&f挖掘指定数量的矿石"
    - "&7包括铁矿、金矿和钻石矿"

  # ===========================================================================
  # 权重（可选）- 用于确定菜单中的默认排序顺序
  # 数值越大，排序越靠前
  # 默认值: 1
  # ===========================================================================
  weight: 5

  # ===========================================================================
  # 权限（可选）- 在该成就中取得进展所需的权限
  # 没有此权限的玩家无法推进该成就
  # 默认值: None（无权限限制）
  # ===========================================================================
  # permission: "achievements.my_achievement"

  # ===========================================================================
  # 隐藏成就（可选）- 设为 true 时该成就将从菜单中隐藏，保持秘密状态
  # 隐藏的成就仍然可以正常完成和触发
  # 默认值: false
  # ===========================================================================
  # hidden: true

  # ===========================================================================
  # 前置成就（可选）- 玩家必须先完成这些成就才能访问本成就
  # 有效格式:
  #   - "<成就ID>"         - 需要完成该成就的所有等级
  #   - "<成就ID>:<等级>"   - 需要完成该成就的指定等级
  # 默认值: None
  # ===========================================================================
  # requirements:
  #   - "miner"
  #   - "farmer:3"

  # ===========================================================================
  # 条件（可选）- 完成成就必须满足的条件列表（v2.0 结构化格式）
  # 详见 条件配置.md
  # ===========================================================================
  # conditions:
  #   - type: game_modes
  #     game-modes:
  #       - SURVIVAL
  #   - type: worlds
  #     worlds:
  #       - "world"
  #       - "world_nether"
  #   - type: blocks
  #     blocks:
  #       - IRON_ORE
  #       - GOLD_ORE
  #       - DIAMOND_ORE
  #       - DEEPSLATE_IRON_ORE
  #       - DEEPSLATE_GOLD_ORE
  #       - DEEPSLATE_DIAMOND_ORE

  # ===========================================================================
  # 设置（可选）- 成就的附加设置
  # ===========================================================================
  # settings:
  #
  #   # -------------------------------------------------------------------------
  #   # 弹出消息（可选）- 覆盖 config.yml 中设置的默认成就弹出消息
  #   # 需要安装 CrazyAdvancementsAPI 插件
  #   # -------------------------------------------------------------------------
  #   toast-message:
  #     icon: DIAMOND_ORE          # 弹出消息中显示的图标材质
  #     message: "&a你完成了矿石收集者成就！"  # 弹出消息中显示的文字
  #     type: CHALLENGE            # 弹出类型: CHALLENGE | TASK | GOAL

  # ===========================================================================
  # 等级列表（必填）- 至少需要一个等级
  # CHALLENGE 类型仅定义一个等级，TIERED 类型定义多个等级
  # 等级编号从 1 开始递增
  # ===========================================================================
  tiers:

    # ------ 等级 1 ------
    1:
      # 完成该等级所需的进度值（必填）
      required-amount: 100

      # 完成该等级后的奖励列表（可选，v2.0 对象格式）
      # 详见 奖励配置.md
      rewards:
        - type: points
          amount: 25
        - type: message
          message: "&a你完成了成就！"
        - type: command
          command: "say {player} 完成了成就！"
        - type: vault
          amount: 100

    # ------ 等级 2 （可选，用于 TIERED 类型）------
    2:
      required-amount: 500
      rewards:
        - type: points
          amount: 50
        - type: vault
          amount: 500

    # ------ 等级 3 （可选）------
    3:
      required-amount: 2000
      rewards:
        - type: points
          amount: 100
        - type: command
          command: "broadcast &6{player} 完成了矿石收集者终极成就！"
```

## 字段参考表

### 成就层级

| 字段 | 必填 | 类型 | 默认值 | 描述 |
| --- | --- | --- | --- | --- |
| `type` | 是 | String | - | 任务类型，定义成就的触发方式 |
| `name` | 是 | String | - | 成就名称，显示在消息和菜单中 |
| `description` | 是 | List\<String\> | - | 成就描述，每行一条 |
| `tiers` | 是 | Map | - | 等级列表，至少需要一个等级 |
| `weight` | 否 | Integer | `1` | 菜单排序权重，越大越靠前 |
| `permission` | 否 | String | `None` | 推进成就所需的权限 |
| `hidden` | 否 | Boolean | `false` | 是否从菜单中隐藏 |
| `requirements` | 否 | List\<String\> | `None` | 前置成就列表 |
| `conditions` | 否 | List\<Object\> | `None` | 完成成就必须满足的条件（v2.0 结构化格式） |
| `settings` | 否 | Object | `None` | 附加设置（如 toast-message） |

### 等级（tiers）层级

| 字段 | 必填 | 类型 | 描述 |
| --- | --- | --- | --- |
| `required-amount` | 是 | Integer | 完成该等级所需的进度值 |
| `rewards` | 否 | List\<Object\> | 完成该等级后的奖励列表（v2.0 对象格式） |

### settings 层级

| 字段 | 必填 | 类型 | 描述 |
| --- | --- | --- | --- |
| `toast-message` | 否 | Object | 弹出消息配置（需 CrazyAdvancementsAPI） |
| `toast-message.icon` | 否 | Material | 弹出消息图标材质 |
| `toast-message.message` | 否 | String | 弹出消息文本 |
| `toast-message.type` | 否 | String | 弹出类型: `CHALLENGE` / `TASK` / `GOAL` |

## 文件放置说明

```
plugins/EpicAchievements/
  achievements/                        # 成就配置文件目录
    <分类名称>/                         # 按分类组织文件夹
      achievements.yml                 # 成就配置文件（可自定义文件名）
      challenges.yml                   # 建议将 CHALLENGE 挑战分开管理
      tiered.yml                       # 建议将 TIERED 阶梯成就分开管理
```

- 成就文件放在 `plugins/EpicAchievements/achievements/<分类名称>/` 目录中
- 每个分类下可以放置**任意数量**的成就文件
- 文件名和文件数量无限制，方便按功能模块组织
- 默认情况下，游戏内编辑器会将新成就创建在 `achievements.yml` 中
- 建议按类型将 CHALLENGE 和 TIERED 分开管理到不同文件
