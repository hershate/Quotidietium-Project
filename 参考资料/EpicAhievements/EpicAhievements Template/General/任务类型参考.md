# 任务类型参考

> 本文档提供 EpicAchievements 所有任务类型的完整参考。
> 任务类型决定了成就的游戏内触发方式，通过 `type` 字段配置。

## 特殊任务类型配置示例

### ADVANCEMENT - 进度任务

> 玩家完成指定的 Minecraft 进度时触发。
> **注意：** 此类成就仅限于 **1** 个等级（只能作为 CHALLENGE）。

```yaml
# =============================================================================
# ADVANCEMENT 类型 - 完成指定进度
# =============================================================================
birdwatcher:
  type: ADVANCEMENT
  name: "&b观鸟者"
  description:
    - "&f用望远镜观察一只鹦鹉！"

  # v2.0 settings 格式
  settings:
    # 进度 ID（如有自定义命名空间请添加前缀）
    # 格式: <命名空间>:<进度路径>
    # 未指定命名空间时默认使用 minecraft
    advancement: "adventure/spyglass_at_parrot"

  tiers:
    1:
      required-amount: 1
      rewards:
        - type: points
          amount: 10
```

> 有效的进度 ID 请参考 [Minecraft Wiki - 进度列表](https://minecraft.fandom.com/wiki/Advancements#List_of_advancements)，使用 `Resource location` 列中的值。

---

### COMMAND - 命令任务

> 玩家执行匹配的命令时触发。
> **注意：** 此类成就仅限于 **1** 个等级（只能作为 CHALLENGE）。

```yaml
# =============================================================================
# COMMAND 类型 - 执行指定命令
# =============================================================================
mayor:
  type: COMMAND
  name: "&6市长"
  description:
    - "&f创建你自己的城镇！"

  # v2.0 settings 格式
  settings:
    # 命令匹配模式（支持正则表达式）
    command: "^town create .+$"

  tiers:
    1:
      required-amount: 1
      rewards:
        - type: points
          amount: 10
```

> 使用 `^` 和 `$` 进行精确匹配，`.+` 匹配任意字符。
> 在线正则测试: [regex101.com](https://regex101.com/)

### PLACEHOLDER - 占位符任务

> 评估 PlaceholderAPI 占位符的值来判定进度。
> 需要安装 [PlaceholderAPI](https://www.spigotmc.org/resources/6245/)。

#### 输出整数的占位符

> 配置与其他任务类型基本相同，使用 `required-amount` 设置目标值。

```yaml
# =============================================================================
# PLACEHOLDER 类型 - 数值占位符（推荐用于 TIERED）
# =============================================================================
lumberjack:
  type: PLACEHOLDER
  name: "&2专业伐木工"
  description:
    - "&f砍倒足够多的树木！"

  # v2.0 settings 格式
  settings:
    # 要评估的 PlaceholderAPI 占位符
    placeholder: "%auraskills_foraging%"

  tiers:
    1:
      required-amount: 1
      rewards:
        - type: points
          amount: 10
    2:
      required-amount: 5
      rewards:
        - type: points
          amount: 15
    3:
      required-amount: 10
      rewards:
        - type: points
          amount: 20
```

#### 输出文本的占位符

> **注意：** 此类成就仅限于 **1** 个等级。
> 使用运算符来测试占位符的输出值。

```yaml
# =============================================================================
# PLACEHOLDER 类型 - 文本占位符（仅限 CHALLENGE）
# =============================================================================
first-nap:
  type: PLACEHOLDER
  name: "&3第一次小睡"
  description:
    - "&f第一次上床睡觉！"

  # v2.0 settings 格式
  settings:
    placeholder: "%player_is_sleeping%"
    operator: EQUALS
    value: "yes"

  tiers:
    1:
      required-amount: 1
      rewards:
        - type: points
          amount: 10
```

## 文本占位符运算符参考

| 运算符 | 描述 |
|--------|------|
| `EQUALS` | 检查输出是否与指定值完全匹配 |
| `EQUALS_IGNORE_CASE` | 检查输出是否与指定值匹配（**忽略大小写**） |
| `NOT_EQUALS` | 检查输出是否与指定值**不**匹配 |
| `NOT_EQUALS_IGNORE_CASE` | 检查输出是否与指定值不匹配（忽略大小写） |
| `CONTAINS` | 检查输出是否包含指定值作为子字符串 |
| `STARTS_WITH` | 检查输出是否以指定值开头 |
| `ENDS_WITH` | 检查输出是否以指定值结尾 |
| `REGEX` | 检查输出是否与指定的正则表达式匹配 |

## 字段参考表

### 特殊任务 settings 字段

| 任务类型 | settings 字段 | 类型 | 必填 | 描述 |
|---------|--------------|------|------|------|
| `ADVANCEMENT` | `advancement` | String | 是 | 进度 ID，格式 `<命名空间>:<路径>` |
| `COMMAND` | `command` | String | 是 | 命令匹配模式（支持正则表达式） |
| `PLACEHOLDER` | `placeholder` | String | 是 | PlaceholderAPI 占位符（含 `%`） |
| `PLACEHOLDER` | `operator` | String | 文本时必填 | 文本占位符运算符（见上表） |
| `PLACEHOLDER` | `value` | String | 文本时必填 | 要比较的参考值 |

## 文件放置说明

```
plugins/EpicAchievements/
  achievements/
    <分类名称>/
      achievements.yml        # 普通成就文件
      challenges.yml          # CHALLENGE 类型成就
      tiered.yml              # TIERED 类型成就
```

- 任务类型在成就配置文件中通过 `type` 字段指定
- 特殊任务（ADVANCEMENT、COMMAND、PLACEHOLDER）需额外配置 `settings` 字段
- 所有任务类型都支持通过 `conditions` 添加条件过滤
