- **翻译范围**：所有正文、标题、链接文本均已翻译为简体中文；代码块、行内代码、YAML 键值、URL 保留原文

- **EpicAchievements**、**SpigotMC**、**Polymart**、**PlaceholderAPI**、**Vault**、**WorldGuard** 等专有名称保留原文
- 文档目录结构与官方文档保持一致
