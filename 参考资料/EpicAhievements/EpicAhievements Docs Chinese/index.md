# EpicAchievements

EpicAchievements 通过 30 多种类型的成就来增强游戏体验，涵盖农耕、探索、建筑等多种任务！

它提供挑战型成就和分级成就，并配有可自定义的条件与奖励。该插件与主流插件相集成，玩家可以轻松获得点数、解锁奖励并追踪进度。

立即在 [SpigotMC](https://www.spigotmc.org/resources/116800/)、[Polymart](https://polymart.org/r/5931) 或 [BuiltByBit](https://builtbybit.com/resources/44823) 购买本插件！

## 需求
- **Java 17** 或更高版本
- Minecraft 1.8.8 - 26.1 服务器
- **（可选）** MySQL 或 MongoDB 数据库
