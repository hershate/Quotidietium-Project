# 分类配置模板

> 本文档提供 EpicAchievements 分类配置文件的完整模板参考。
> 分类用于将成就按服务器/游戏模式/主题进行分组管理。
> 配置文件位于 `plugins/EpicAchievements/categories.yml`。

---

## 完整模板

```yaml
# =============================================================================
# 分类标识符（必填）- 唯一的分类标识符
# 用于成就配置中的文件夹名称，以及 conditions 中的引用
# 只能使用小写字母、数字和下划线
# =============================================================================
survival:

  # ===========================================================================
  # 分类名称（必填）- 显示在菜单和消息中的分类名称
  # 支持 & 颜色代码
  # ===========================================================================
  name: "&a生存模式"

  # ===========================================================================
  # 分类描述（必填）- 显示在菜单中的描述文字
  # 每行一个字符串，支持 & 颜色代码
  # ===========================================================================
  description:
    - "&7在生存模式中完成各种挑战"
    - "&7包括挖矿、战斗、建造和探索"

  # ===========================================================================
  # 启用服务器列表（必填）- 在该分类的成就可在哪些服务器上完成
  # 服务器 ID 在 config.yml 中定义: server: <服务器ID>
  # 使用 ALL 可在所有服务器上启用
  # ===========================================================================
  servers:
    - ALL
    # - survival       # 仅在特定服务器启用
    # - survival_nether
    # - survival_end

  # ===========================================================================
  # 菜单物品（必填）- 在主菜单中为该分类显示的物品
  # ===========================================================================
  item:
    # 物品材质（必填）- Minecraft 原版材质
    material: DIAMOND_PICKAXE
    # 菜单槽位（必填）- 物品在菜单中显示的槽位编号
    # 槽位从 0 开始编号，从左到右、从上到下排列
    # 0-8: 第一行, 9-17: 第二行, 依此类推
    slot: 12

  # ===========================================================================
  # 访问权限（可选）- 访问该分类所需的权限
  # 没有此权限的玩家无法在菜单中看到该分类
  # 默认值: None
  # ===========================================================================
  # permission: "achievements.category.survival"
```

## 多分类配置示例

```yaml
# =============================================================================
# categories.yml - 完整分类配置示例
# 位置: plugins/EpicAchievements/categories.yml
# =============================================================================

# ===== 生存类 =====
survival:
  name: "&a生存模式"
  description:
    - "&7在生存模式中完成各种挑战"
  servers:
    - ALL
  item:
    material: DIAMOND_PICKAXE
    slot: 12
  permission: "achievements.category.survival"

# ===== 冒险类 =====
adventure:
  name: "&6冒险世界"
  description:
    - "&7在冒险世界中探索和战斗"
  servers:
    - adventure
  item:
    material: BOW
    slot: 14
  # 此分类无需额外权限

# ===== 小游戏类 =====
minigames:
  name: "&d小游戏"
  description:
    - "&7在各种小游戏中获得成就"
  servers:
    - skywars
    - bedwars
  item:
    material: FIREWORK_STAR
    slot: 16
```

## 字段参考表

| 字段 | 必填 | 类型 | 默认值 | 描述 |
|------|------|------|--------|------|
| 分类标识符 | 是 | String | - | 唯一的分类键名，用于成就文件夹名和引用 |
| `name` | 是 | String | - | 分类名称，显示在菜单和消息中 |
| `description` | 是 | List\<String\> | - | 分类描述，每行一条 |
| `servers` | 是 | List\<String\> | - | 启用该分类的服务器列表，`ALL` 表示所有服务器 |
| `item.material` | 是 | Material | - | 菜单中显示的物品材质 |
| `item.slot` | 是 | Integer | - | 物品在菜单中显示的槽位 |
| `permission` | 否 | String | `None` | 访问该分类所需的权限 |

## config.yml 服务器配置参考

```yaml
# =============================================================================
# config.yml - 服务器标识符定义
# =============================================================================
# 服务器标识符，用于 categories.yml 中的 servers 字段匹配
server: survival
```

- 在 `config.yml` 中定义的 `server` 值决定了本服务器运行的服务器标识符
- `categories.yml` 中 `servers` 包含该标识符的分类才会在本服务器上显示
- 使用 `ALL` 可跨所有服务器显示该分类

## 文件放置说明

```
plugins/EpicAchievements/
  categories.yml                     # 分类配置文件（固定文件名）
  config.yml                         # 主配置文件（在此定义 server ID）
  achievements/                      # 成就配置文件目录
    survival/                        # 分类标识符作为文件夹名
      achievements.yml               # 该分类下的成就文件
    adventure/
      achievements.yml
```

- 分类配置文件必须命名为 `categories.yml`
- 文件直接放在 `plugins/EpicAchievements/` 根目录下
- 分类标识符同时也是成就文件夹的名称（`achievements/<分类ID>/`）
- 同一个分类下的成就可以分布在多个 YAML 文件中
