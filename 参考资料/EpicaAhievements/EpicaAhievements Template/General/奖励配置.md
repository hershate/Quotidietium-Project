# 奖励配置参考

> 本文档提供 EpicAchievements 所有奖励类型的完整参考。
> 奖励是玩家完成成就等级后获得的回报，在成就的 `tiers.<等级>.rewards` 字段中配置。
> 在所有奖励中均可使用 `{player}` 和 `{uuid}` 占位符。

---

## v2.0 格式（type-based 对象格式）

> v2.0 使用 `type` + 参数的**对象格式**定义奖励，更加清晰可读。

### 完整模板

```yaml
# =============================================================================
# 完整奖励配置示例（v2.0 type-based 格式）
# =============================================================================
tiers:
  1:
    required-amount: 100
    rewards:
      # =======================================================================
      # 内置奖励（Built-in Rewards）
      # =======================================================================

      # ------ 点数奖励 ------
      - type: points
        amount: 25                     # 给予玩家的成就点数
        # description: "&8+ &7{amount} 成就点数"    # （可选）自定义描述
        # permission: "group.vip"                    # （可选）领取所需权限

      # ------ 动作栏消息 ------
      - type: action_bar
        message: "&a你完成了一个成就！"   # 在动作栏显示的消息

      # ------ 广播消息 ------
      - type: broadcast
        message: "&6{player} 完成了一个成就！"  # 向全服广播的消息

      # ------ 控制台命令 ------
      - type: command
        command: "say {player} 完成了成就！"    # 由控制台执行的命令

      # ------ 经验等级 ------
      - type: experience_levels
        amount: 5                      # 给予的经验等级数量

      # ------ 经验值 ------
      - type: experience
        amount: 100                    # 给予的经验值数量

      # ------ 物品奖励 ------
      # - type: item
      #   item:                         # 物品定义（详见 item-format 文档）
      #     material: DIAMOND
      #     amount: 1

      # ------ 消息奖励 ------
      - type: message
        message: "&a恭喜！你完成了成就！"  # 发送给玩家的私人消息

      # ------ 标题奖励 ------
      - type: title
        title: "&a成就完成！"             # 主标题
        subtitle: "&7你获得了成就点数"     # 副标题

      # =======================================================================
      # 插件钩子奖励（Plugin Hooks）
      # =======================================================================

      # ------ Vault 经济奖励 ------
      # 需要安装 Vault 插件
      - type: vault
        amount: 100.0                  # 给予的金钱数量

      # ------ PlayerPoints 奖励 ------
      # 需要安装 PlayerPoints 插件
      - type: player_points
        amount: 50                     # 给予的 PlayerPoints 点数

      # ------ EcoBits 货币奖励 ------
      # 需要安装 EcoBits 插件
      # - type: ecobits
      #   currency: "coins"             # 货币名称
      #   amount: 100                   # 数量
```

## 奖励类型参考表

### 内置奖励

| 奖励类型 | 描述 | 必要参数 | 可用占位符 |
|---------|------|---------|-----------|
| `points` | 给予玩家成就点数（用于解锁奖励等级）| `amount` | `{player}` `{uuid}` |
| `action_bar` | 发送动作栏消息 | `message` | `{player}` `{uuid}` |
| `broadcast` | 向服务器广播消息 | `message` | `{player}` `{uuid}` |
| `command` | 执行控制台命令 | `command` | `{player}` `{uuid}` |
| `experience_levels` | 给予玩家经验等级 | `amount` | `{player}` `{uuid}` |
| `experience` | 给予玩家经验值 | `amount` | `{player}` `{uuid}` |
| `item` | 给予玩家物品 | `item`（含 material、amount 等） | `{player}` `{uuid}` |
| `message` | 向玩家发送消息 | `message` | `{player}` `{uuid}` |
| `title` | 向玩家发送标题和副标题 | `title` `subtitle` | `{player}` `{uuid}` |

### 插件钩子奖励

| 插件 | 奖励类型 | 描述 | 必要参数 |
|------|---------|------|---------|
| [Vault](https://www.spigotmc.org/resources/34315/) | `vault` | 给予玩家金钱 | `amount` |
| [PlayerPoints](https://www.spigotmc.org/resources/80745/) | `player_points` | 给予玩家 PlayerPoints 点数 | `amount` |
| [EcoBits](https://www.spigotmc.org/resources/109967/) | `ecobits` | 给予玩家特定货币 | `currency` `amount` |

## 可选字段

### `description` - 自定义奖励描述

> 用于覆盖 `rewards.yml` 中定义的默认奖励描述。
> `{amount}` 占位符可在描述中使用，代表奖励的数量。

```yaml
rewards:
  - type: vault
    amount: 100
    description: "&8+ &7{amount} &e金币"    # 自定义描述文本
```

### `permission` - 领取权限

> 领取该奖励所需的权限。没有此权限的玩家不会在列表中看到该奖励。
> **默认值：** `None`

```yaml
rewards:
  - type: vault
    amount: 200
    permission: "group.vip"               # 只有 VIP 可领取此奖励
```

## 完整配置示例

```yaml
# =============================================================================
# 成就配置中的完整奖励示例
# =============================================================================
my_achievement:
  type: KILL
  name: "&a成就奖励示例"
  description:
    - "&f展示所有奖励类型"
  tiers:
    1:
      required-amount: 50
      rewards:
        # 多种奖励组合
        - type: points
          amount: 10
        - type: message
          message: "&a你击杀了 50 个怪物！"
        - type: command
          command: "lp user {player} permission set achievements.killer.1 true"
        - type: vault
          amount: 500
          description: "&8+ &7{amount} &6金币"
    2:
      required-amount: 100
      rewards:
        - type: points
          amount: 25
        - type: broadcast
          message: "&6{player} 击杀了 100 个怪物！"
        - type: title
          title: "&c怪物杀手"
          subtitle: "&7你已经击杀了 100 个怪物"
        - type: experience_levels
          amount: 10
    3:
      required-amount: 500
      rewards:
        - type: points
          amount: 50
        - type: command
          command: "broadcast &6&l{player} 成为了传说级怪物杀手！"
        - type: vault
          amount: 2000
          permission: "group.vip"         # 仅 VIP 可获得额外金币奖励
```

## v1.0 / v2.0 格式对照表

| 功能 | v1.0 字符串格式 | v2.0 对象格式 |
|------|----------------|--------------|
| 点数 | `"POINTS:25"` | `type: points` + `amount: 25` |
| 消息 | `"MESSAGE:&a文字"` | `type: message` + `message: "&a文字"` |
| 广播 | `"BROADCAST:&6文字"` | `type: broadcast` + `message: "&6文字"` |
| 命令 | `"COMMAND:say ..."` | `type: command` + `command: "say ..."` |
| 金钱 | `"VAULT:100"` | `type: vault` + `amount: 100` |
| 经验等级 | `"EXPERIENCE_LEVELS:5"` | `type: experience_levels` + `amount: 5` |
| 经验值 | `"EXPERIENCE:100"` | `type: experience` + `amount: 100` |

## 字段参考表

### v2.0 奖励对象字段

| 字段 | 必填 | 类型 | 描述 |
|------|------|------|------|
| `type` | 是 | String | 奖励类型名称 |
| `amount` | 因类型而异 | Integer/Double | 奖励的数量 |
| `message` | 因类型而异 | String | 消息文本（message、broadcast、action_bar 类型）|
| `command` | 因类型而异 | String | 控制台命令（command 类型）|
| `title` | 因类型而异 | String | 标题文本（title 类型）|
| `subtitle` | 可选 | String | 副标题文本（title 类型）|
| `item` | 因类型而异 | Object | 物品定义（item 类型）|
| `currency` | 因类型而异 | String | 货币名称（ecobits 类型）|
| `description` | 否 | String | 自定义奖励描述 |
| `permission` | 否 | String | 领取奖励所需的权限 |

## 文件放置说明

```
plugins/EpicAchievements/
  achievements/
    <分类名称>/
      achievements.yml        # 在 tiers.<等级>.rewards 中配置奖励
  rewards.yml                 # 奖励等级系统（详见 奖励等级系统.md）
```

- 奖励配置是成就文件内部的一部分，通过 `tiers.<等级>.rewards` 字段定义
- 每个等级可以定义**多个**奖励，玩家完成等级后将获得所有奖励
- v2.0 推荐使用对象格式（`type` + 参数），更清晰易读
- v1.0 字符串格式仍然兼容，但建议迁移到 v2.0
