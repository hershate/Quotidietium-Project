# 占位符参考

> 本文档提供 EpicAchievements 所有占位符的完整参考。
> 占位符可在菜单配置、消息文本、奖励描述等几乎所有配置位置中使用。
> 支持使用 `{placeholder}` 花括号格式（内部占位符）和 `%placeholder%` 百分号格式（PlaceholderAPI 外部占位符）。

---

## 内部占位符（Internal Placeholders）

> 内部占位符由 EpicAchievements 原生提供，可在奖励消息、菜单、成就配置等中使用。

### v2.0 内部占位符

#### 通用占位符（General）

> 这些占位符可用于任何菜单和配置位置。

| 占位符 | 描述 |
|--------|------|
| `{player}` | 玩家名称 |
| `{uuid}` | 玩家的 UUID |
| `{points}` | 玩家的成就点数 |
| `{total_points}` | 所有成就的总点数 |
| `{points_percentage}` | 已获得点数的百分比 |
| `{unlocked_achievements}` | 已解锁成就的数量 |
| `{total_achievements}` | 成就的总数量 |
| `{unlocked_achievements_percentage}` | 已解锁成就的百分比 |
| `{unclaimed_rewards}` | 未领取奖励的数量 |

#### 分类占位符（Category）

> 用于分类相关菜单和消息。

| 占位符 | 描述 |
|--------|------|
| `{category_id}` | 分类的唯一标识符 |
| `{category_name}` | 分类的名称 |
| `{category_description}` | 分类的描述 |
| `{category_permission}` | 访问分类所需的权限 |
| `{category_achievements}` | 该分类中的成就数量 |
| `{category_servers}` | 可完成该分类成就的服务器 |

#### 成就占位符（Achievement）

> 用于成就详情和进度显示。

| 占位符 | 描述 |
|--------|------|
| `{achievement_id}` | 成就的唯一标识符 |
| `{achievement_name}` | 成就的名称 |
| `{achievement_description}` | 成就的描述 |
| `{achievement_type}` | 成就的类型（challenge / tiered） |
| `{achievement_task}` | 成就的任务类型 |
| `{achievement_progress}` | 玩家在该成就中的进度（数值） |
| `{achievement_progress_percentage}` | 该成就进度的百分比 |
| `{achievement_progress_bar}` | 显示当前进度的进度条 |
| `{achievement_permission}` | 在该成就中推进所需的权限 |
| `{achievement_requirements}` | 在该成就中推进所需的前置成就 |
| `{tier}` | 当前等级编号 |
| `{tier_roman}` | 罗马数字表示的等级编号 |
| `{tier_requirement}` | 完成该等级的要求 |
| `{tier_rewards}` | 奖励列表 |
| `{tier_progress_percentage}` | 该等级进度的百分比 |
| `{tier_progress_bar}` | 显示当前等级进度的进度条 |
| `{tier_unlock_percentage}` | 已解锁该等级的玩家百分比 |

#### 奖励等级占位符（Reward Level）

> 用于 rewards.yml 奖励等级菜单。

| 占位符 | 描述 |
|--------|------|
| `{level}` | 奖励等级编号 |
| `{points}` | 达到该奖励等级所需的点数 |
| `{rewards}` | 该等级的奖励列表文本 |

#### 排序占位符（Sorting）

> 用于排序相关菜单显示。

| 占位符 | 描述 |
|--------|------|
| `{sorting_type}` | 当前排序方式 |
| `{sorting_description}` | 当前排序方式的描述 |
| `{next_sorting_type}` | 下一个排序方式 |
| `{next_sorting_description}` | 下一个排序方式的描述 |
| `{completion_sorting_type}` | 完成度排序方式 |

## PlaceholderAPI 外部占位符

> 通过 [PlaceholderAPI](https://www.spigotmc.org/resources/6245/) 钩子，EpicAchievements 对外暴露了一系列占位符供其他插件使用。
> 格式：`%achievements_<占位符>%`

### 占位符完整列表

> 参数约定：
> - `<required>` - 必需参数
> - `[optional]` - 可选参数

| 占位符 | 描述 |
|--------|------|
| `%achievements_points_[分类ID]_[challenge/tiered]%` | 玩家在该分类中的点数 |
| `%achievements_points_percentage_[分类ID]_[challenge/tiered]%` | 玩家在该分类中的点数百分比 |
| `%achievements_points_total_[分类ID]_[challenge/tiered]%` | 分类中的可用总点数 |
| `%achievements_unlocked_[分类ID]_[challenge/tiered]%` | 玩家已解锁的成就数量 |
| `%achievements_unlocked_percentage_[分类ID]_[challenge/tiered]%` | 玩家已解锁的成就百分比 |
| `%achievements_total_[分类ID]_[challenge/tiered]%` | 分类中的成就总数 |
| `%achievements_achievement_<成就ID>_<points/requirement/progress/percentage/bar/unlocked>_[等级]%` | 关于特定成就的详细信息。未指定等级时默认为 `1` |
| `%achievements_tracked%` | 玩家正在追踪的成就数量 |
| `%achievements_unclaimed%` | 未领取的奖励数量 |

### PlaceholderAPI 使用示例

```
# 获取玩家在 survival 分类中的 CHALLENGE 点数
%achievements_points_survival_challenge%

# 获取玩家在 survival 分类中的 TIERED 成就完成百分比
%achievements_unlocked_percentage_survival_tiered%

# 获取玩家在 adventure 分类中的总成就数
%achievements_total_adventure_challenge%

# 获取 miners 成就的进度
%achievements_achievement_miners_progress%

# 获取 miners 成就第 3 等级的完成进度百分比
%achievements_achievement_miners_percentage_3%

# 获取 miners 成就第 2 等级是否已解锁
%achievements_achievement_miners_unlocked_2%
```

## 参数替换示例

> 以下展示各占位符在实际配置中的具体用法。

### 奖励消息中的使用

```yaml
# =============================================================================
# 在成就配置的奖励消息中使用占位符
# =============================================================================
my_achievement:
  type: BREAK
  name: "&a采集大师"
  description:
    - "&f挖掘 {required-amount} 个矿石"
    - "&7当前进度: {achievement_progress} / {tier_requirement}"

  tiers:
    1:
      required-amount: 100
      rewards:
        - type: message
          message: "&a{player}，你完成了 \"{achievement_name}\" 成就！（进度: {achievement_progress_percentage}%）"
        - type: command
          command: "say &6{player} 完成了成就 {achievement_id}！"
        - type: broadcast
          message: "&6&l{player} 刚刚完成了 &e{achievement_name}&6&l！总共已解锁: &e{unlocked_achievements}&6&l/{total_achievements}"
```

### 分类菜单中的使用

```yaml
# categories.yml
survival:
  name: "&a{category_name}"
  description:
    - "&7{category_description}"
    - ""
    - "&7成就: &e{category_achievements} 个"
    - "&7进度: &e{unlocked_achievements_percentage}%"
```

### 奖励等级菜单中的使用

```yaml
# rewards.yml - 使用占位符和数学表达式
rewards:
  normal:
    levels:
      from: 1
      to: 100
    required-points: "{level} * 100"
    rewards:
      - type: vault
        amount: "{level} * 10"
    locked:
      material: "COAL"
      name: "&c奖励等级 {level}"
      lore:
        - "&8等级 {level}"
        - "&7所需点数: &e{points}"
        - ""
        - "&7奖励:"
        - "{rewards}"
        - ""
        - "&c你还无法领取此奖励"
    claimed:
      material: "GOLD_NUGGET"
      name: "&a奖励等级 {level}"
      lore:
        - "&8等级 {level}"
        - "&7所需点数: &e{points}"
        - ""
        - "&7奖励:"
        - "{rewards}"
        - ""
        - "&a你已经领取过此奖励！"
    unclaimed:
      material: "GOLD_NUGGET"
      name: "&e奖励等级 {level}"
      lore:
        - "&8等级 {level}"
        - "&7所需点数: &e{points}"
        - ""
        - "&7奖励:"
        - "{rewards}"
        - ""
        - "&e点击领取此奖励！"
      glow: true
```

## 占位符使用场景速查表

| 使用位置 | 可用占位符范围 | 典型用途 |
|---------|--------------|---------|
| 成就名称/描述 | `{achievement_*}` `{tier_*}` | 显示成就名称、进度 |
| 成就奖励消息 | `{player}` `{achievement_*}` `{tier_*}` | 个性化奖励消息 |
| 成就奖励命令 | `{player}` `{uuid}` | 命令参数传递 |
| 分类菜单 | `{category_*}` | 分类信息展示 |
| 奖励等级菜单 | `{level}` `{points}` `{rewards}` `{status}` | 奖励等级信息展示 |
| 全局菜单 | `{player}` `{points}` `{unlocked_achievements}` | 玩家全局状态 |
| 外部插件 | `%achievements_*%` | 广告板、计分板等 |

## 字段参考表

### 内部占位符类别

| 类别 | 前缀 | 用途 |
|------|------|------|
| 通用 | `{player}`, `{points}` 等 | 任何菜单和消息 |
| 分类 | `{category_*}` | 分类相关显示 |
| 成就 | `{achievement_*}` | 成就相关显示 |
| 等级 | `{tier_*}` | 成就等级相关显示 |
| 奖励等级 | `{level}`, `{points}`, `{rewards}` | 奖励等级菜单（rewards.yml）|
| 排序 | `{sorting_*}` | 排序方式显示 |

### v1.0 与 v2.0 差异

| 占位符 | v2.0 | v1.0 |
|--------|------|------|
| 分类物品材质 | `{category_servers}` 无替代 | `{category_item}` |
| 分类物品槽位 | `{category_servers}` 无替代 | `{category_item_slot}` |
| 成就类型名称 | 同 `{achievement_type}` | `{achievement_type_name}` |
| 前置成就 | `{achievement_requirements}` | `{achievement_required_achievements}` |
| 等级点数 | 同 `{tier_rewards}` | `{tier_points}` |
| 奖励等级状态 | 同 `{rewards}` | `{status}` |

## 文件放置说明

```
plugins/EpicAchievements/
  config.yml                          # 菜单配置中使用占位符
  categories.yml                      # 分类名称/描述中使用占位符
  rewards.yml                         # 奖励等级系统中使用占位符
  achievements/                       # 成就配置中使用占位符
    <分类名称>/
      achievements.yml
```

- 内部占位符（花括号格式 `{}`）可在 EpicAchievements 的所有配置文件中使用
- PlaceholderAPI 外部占位符（百分号格式 `%%`）可在支持 PAPI 的其他插件中使用
- 奖励等级系统中 `{level}` 和 `{points}` 占位符还支持数学表达式运算
