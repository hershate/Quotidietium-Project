# 条件配置参考

> 本文档提供 EpicAchievements 所有条件类型的完整参考。
> 条件用于限制成就完成的前置环境要求，通过 `conditions` 字段配置。

---

## 条件系统说明

- 条件定义了成就完成时必须满足的**环境要求**
- 默认情况下，所有实体、物品等列表均被视为**白名单**
- 可添加 `blacklist: true` 将其转换为**黑名单**
- 大多数列表类型条件支持**通配符** `*`
- 可在 `conditions` 列表中定义**多个条件**，所有条件需**同时满足**

### 白名单 vs 黑名单

```yaml
# =============================================================================
# 白名单示例 - 仅统计列表中的内容
# =============================================================================
conditions:
  - type: items
    items:
      - NETHERITE_INGOT

# =============================================================================
# 黑名单示例 - 排除列表中的内容，统计其他所有内容
# =============================================================================
conditions:
  - type: items
    items:
      - NETHERITE_INGOT
    blacklist: true       # 将白名单转换为黑名单
```

### 通配符支持

```yaml
conditions:
  - type: items
    items:
      - "*_PICKAXE"        # 匹配所有类型的镐（WOODEN_PICKAXE、STONE_PICKAXE...）
      - "*_SWORD"          # 匹配所有类型的剑
      - "DIAMOND_*"        # 匹配所有钻石类物品
  - type: entities
    entities:
      - "*_ZOMBIE"         # 匹配所有僵尸变种（ZOMBIE、HUSK、DROWNED...）
```

## 完整条件 YAML 模板

```yaml
# =============================================================================
# 完整条件配置模板 - 涵盖所有条件类型
# =============================================================================
my_achievement:
  type: KILL
  name: "&a条件示例成就"
  description:
    - "&f展示所有条件类型的用法"

  conditions:

    # =========================================================================
    # 全局条件（Global Conditions）- 适用于所有类型的成就
    # =========================================================================

    # ------ 游戏模式条件 ------
    - type: game_modes
      game-modes:
        - SURVIVAL           # 仅限生存模式
        - ADVENTURE          # 或冒险模式

    # ------ 世界条件 ------
    - type: worlds
      worlds:
        - "world"            # 仅限主世界
        - "world_nether"     # 或下界

    # ------ 生物群系条件 ------
    - type: biomes
      biomes:
        - PLAINS             # 仅限平原
        - FOREST             # 或森林
        - BIRCH_FOREST

    # ------ 物品栏条件 ------
    - type: has_item
      items:
        - DIAMOND_SWORD      # 玩家物品栏中必须有钻石剑

    # ------ 手持物品条件 ------
    - type: has_held
      items:
        - BOW                # 玩家手中必须持有弓

    # ------ 装备条件 ------
    - type: has_equipped
      items:
        - DIAMOND_CHESTPLATE # 玩家必须装备钻石胸甲

    # ------ 骑乘实体条件 ------
    - type: riding_entity
      entities:
        - ALL                # ALL 匹配所有实体
        # - HORSE            # 或指定实体类型

    # ------ 潜行状态条件 ------
    - type: is_sneaking
      value: true            # 玩家必须正在潜行

    # ------ 疾跑状态条件 ------
    - type: is_sprinting
      value: false           # 玩家必须没有疾跑

    # ------ 飞行状态条件 ------
    - type: is_flying
      value: false           # 玩家必须没有飞行

    # ------ 打开菜单/界面条件 ------
    - type: has_inventory_open
      value: true            # 玩家必须打开了一个界面
                             # 注意：无法检查玩家是否打开了自己的物品栏

    # =========================================================================
    # 插件钩子条件（Plugin Hooks）
    # =========================================================================

    # ------ WorldGuard 区域条件 ------
    # 需要安装 WorldGuard 插件
    - type: regions
      regions:
        - "spawn"            # 玩家必须在 spawn 区域内
        - "warzone"          # 或 warzone 区域内

    # ------ Vault 经济条件 ------
    # 需要安装 Vault 插件
    - type: vault
      balance: 100.0         # 玩家的余额必须大于等于 100

    # ------ PlaceholderAPI 条件 ------
    # 需要安装 PlaceholderAPI 插件
    - type: placeholder
      placeholder: "%player_level%"       # 要检查的占位符
      value: "10"                          # 比较值
      operator: GREATER_THAN_OR_EQUAL      # 比较运算符

    # ------ CustomFishing 战利品条件 ------
    # 需要安装 CustomFishing 插件
    - type: custom_fishing_loot
      loot:
        - "mythical_treasure"  # 战利品 ID 列表
        - "legendary_fish"

    # =========================================================================
    # 任务特定条件（Task-specific Conditions）- 仅适用于特定任务类型
    # =========================================================================

    # ------ 实体条件（用于 KILL、BREED、TAME、SHEAR、DAMAGE 等） ------
    - type: entities
      entities:
        - ZOMBIE             # Minecraft 原版实体
        - SKELETON
        - CREEPER
        # 支持 MythicMobs 实体
        # - mythicmobs:<mob-id>
        # - mm:<mob-id>
      # blacklist: true      # 可选：转换为黑名单

    # ------ 敌对判定条件（用于 KILL、BREED、DAMAGE 等） ------
    - type: is_hostile
      value: true            # true=仅统计敌对实体, false=仅统计友好实体

    # ------ 物品条件（用于 CRAFT、CONSUME、ENCHANT、PICKUP 等） ------
    - type: items
      items:
        - DIAMOND_SWORD
        - NETHERITE_SWORD
        # 支持通配符
        # - "*_PICKAXE"

    # ------ 方块条件（用于 BREAK、PLACE、HARVEST 等） ------
    - type: blocks
      blocks:
        - DIAMOND_ORE
        - DEEPSLATE_DIAMOND_ORE

    # ------ 药水类型条件（用于 BREW） ------
    - type: potion_types
      types:
        - SWIFTNESS           # 迅捷药水
        - STRENGTH            # 力量药水
        - REGEN               # 再生药水
        # 完整列表: https://hub.spigotmc.org/javadocs/spigot/org/bukkit/potion/PotionType.html

    # ------ 作物生长阶段条件（用于 BREAK、PLACE、HARVEST） ------
    - type: crop_age
      age: MAX               # 作物必须完全成熟
      # age: 7               # 或指定具体生长阶段（0-7）

    # ------ 伤害原因条件（用于 DAMAGE、DEATH） ------
    - type: damage_causes
      causes:
        - FALL                # 摔落伤害
        - FIRE                # 火焰伤害
        - ENTITY_ATTACK       # 实体攻击
        - PROJECTILE          # 弹射物伤害
        # 完整列表: https://hub.spigotmc.org/javadocs/bukkit/org/bukkit/event/entity/EntityDamageEvent.DamageCause.html

  # ------ 等级配置 ------
  tiers:
    1:
      required-amount: 50
      rewards:
        - type: points
          amount: 25
        - type: message
          message: "&a你完成了条件成就示例！"
```

## 全局条件参考表

> 这些条件适用于所有类型的成就。

| 条件类型 | 必要参数 | 描述 |
|---------|---------|------|
| `game_modes` | `game-modes` | 允许的游戏模式列表（SURVIVAL、CREATIVE、ADVENTURE、SPECTATOR） |
| `worlds` | `worlds` | 允许的世界名称列表 |
| `biomes` | `biomes` | 允许的生物群系列表 |
| `has_item` | `items` | 要求玩家物品栏中有指定物品 |
| `has_held` | `items` | 要求玩家手中持有指定物品 |
| `has_equipped` | `items` | 要求玩家装备了指定物品 |
| `riding_entity` | `entities` | 要求玩家骑乘指定实体，`ALL` 匹配所有实体 |
| `is_sneaking` | `value` | 要求玩家处于潜行状态（true/false） |
| `is_sprinting` | `value` | 要求玩家处于疾跑状态（true/false） |
| `is_flying` | `value` | 要求玩家处于飞行状态（true/false） |
| `has_inventory_open` | `value` | 检查玩家是否打开了某个界面（true/false） |

## 任务特定条件参考表

> 这些条件仅适用于某些特定类型的任务。

| 条件类型 | 必要参数 | 适用任务 | 描述 |
|---------|---------|---------|------|
| `entities` | `entities` | KILL, BREED, TAME, SHEAR, DAMAGE, ENTER_VEHICLE, EXIT_VEHICLE | 实体列表，支持 MythicMobs（`mythicmobs:<id>` 或 `mm:<id>`）|
| `is_hostile` | `value` | KILL, BREED, TAME, SHEAR, DAMAGE | 实体敌对性判定（true=敌对/false=友好）|
| `items` | `items` | CRAFT, CONSUME, ENCHANT, PICKUP, FISH, SMELT, DROP, BREW, TRADE | 物品列表 |
| `blocks` | `blocks` | BREAK, PLACE, HARVEST, INTERACT | 方块列表 |
| `potion_types` | `types` | BREW | 药水类型列表，参考 [PotionType](https://hub.spigotmc.org/javadocs/spigot/org/bukkit/potion/PotionType.html) |
| `crop_age` | `age` | BREAK, PLACE, HARVEST | 作物生长阶段（`MAX` 或数值 0-7）|
| `damage_causes` | `causes` | DAMAGE, DEATH | 伤害原因列表，参考 [DamageCause](https://hub.spigotmc.org/javadocs/bukkit/org/bukkit/event/entity/EntityDamageEvent.DamageCause.html) |

## PlaceholderAPI 条件运算符参考

| 运算符 | 描述 |
|--------|------|
| `EQUALS` | 输出值等于指定值 |
| `EQUALS_IGNORE_CASE` | 输出值等于指定值（忽略大小写）|
| `NOT_EQUALS` | 输出值不等于指定值 |
| `NOT_EQUALS_IGNORE_CASE` | 输出值不等于指定值（忽略大小写）|
| `GREATER_THAN` | 输出值大于指定值 |
| `GREATER_THAN_OR_EQUAL` | 输出值大于或等于指定值 |
| `LESS_THAN` | 输出值小于指定值 |
| `LESS_THAN_OR_EQUAL` | 输出值小于或等于指定值 |
| `CONTAINS` | 输出值包含指定值作为子字符串 |
| `STARTS_WITH` | 输出值以指定值开头 |
| `ENDS_WITH` | 输出值以指定值结尾 |
| `REGEX` | 输出值与指定正则表达式匹配 |

## 黑名单使用示例

```yaml
# =============================================================================
# 黑名单示例 - 排除特定实体、物品、方块等
# =============================================================================
conditions:
  # 击杀任何实体除了 CREEPER
  - type: entities
    entities:
      - CREEPER
    blacklist: true

  # 破坏任何方块除了 TNT
  - type: blocks
    blocks:
      - TNT
    blacklist: true

  # 在任何世界除了 world_void
  - type: worlds
    worlds:
      - "world_void"
    blacklist: true
```

## 文件放置说明

```
plugins/EpicAchievements/
  achievements/
    <分类名称>/
      achievements.yml        # 在成就配置中使用 conditions 字段
```

- 条件配置是成就文件内部的一部分，通过 `conditions` 字段定义
- 每个条件是一个包含 `type` 和其他参数的对象
- 多个条件之间是**与**（AND）关系，必须全部满足
- 条件中的列表默认为白名单，可添加 `blacklist: true` 反转
