# 1. 基础任务类型

> EpicAchievements 中最常用的任务类型，覆盖 Minecraft 生存核心玩法。每个任务示例均包含完整的 v2.0 格式 YAML 配置。

---

## 设计思路

基础任务类型的核心设计原则是"直观可感知"——玩家完成某个游戏行为后立即获得进度反馈。每个任务由以下要素构成：

- **`type`**：触发类型（BREAK, CRAFT, FISH 等），决定何时检查进度
- **`conditions`**：过滤条件列表，精确约束匹配目标
- **`tiers`**：层级配置，`required-amount` 设定完成门槛

---

## 完整示例

### 1. 挖矿类 - 采集铁矿石

```yaml
miner-novice:
  type: BREAK                # 任务类型：破坏方块时触发
  name: "&7挖矿新手"         # 成就显示名称
  description:               # 成就描述，每行一条
    - "&7采集 &f64 &7个铁矿石"
  conditions:                # 过滤条件，精确约束匹配目标
    - type: blocks           # 条件类型：指定方块
      blocks:                # 目标方块列表
        - IRON_ORE
        - DEEPSLATE_IRON_ORE
  tiers:                     # 层级配置，支持多阶段递进
    1:                       # 第一层
      required-amount: 64    # 完成 64 次即达标
      rewards:               # 完成任务给予的奖励列表
        - type: points       # 奖励类型：成就点数
          amount: 5          # 给予 5 成就点数
        - type: vault        # 奖励类型：Vault 货币
          amount: 200        # 给予 200 货币
```

### 2. 合成类 - 制作钻石剑

```yaml
weapon-smith:
  type: CRAFT               # 任务类型：合成物品时触发
  name: "&b神兵锻造"        # 成就显示名称
  description:              # 成就描述
    - "&7合成一把钻石剑"
  conditions:               # 过滤条件
    - type: items           # 条件类型：指定物品
      items:                # 目标物品列表
        - DIAMOND_SWORD
  tiers:
    1:
      required-amount: 1    # 合成 1 次即达标
      rewards:
        - type: points
          amount: 10
        - type: vault
          amount: 500
        - type: message     # 奖励类型：发送消息
          message: "&b你合成了一把钻石剑！"  # 消息内容
```

### 6. 钓鱼类 - 钓取宝藏

```yaml
master-angler:
  type: FISH                # 任务类型：钓鱼时检测钓到的物品
  name: "&b海钓达人"        # 成就显示名称
  description:
    - "&7钓到 &b3 &7件宝藏"

    - type: items           # 条件类型：指定钓到的物品

        - ENCHANTED_BOOK
        - NAME_TAG
        - NAUTILUS_SHELL

  tiers:

          amount: 1000
```

### 7. 交易类 - 与村民交易

```yaml
shrewd-merchant:
  type: TRADE               # 任务类型：与村民交易时触发

        - type: vault
```

## 关键概念总结

| 任务类型 | type 值 | 核心条件 | 说明 |
|---------|---------|---------|------|
| 挖矿/采集 | BREAK | `blocks` | 支持多种矿石同时计数 |
| 合成 | CRAFT | `items` | 仅统计成功合成 |
| 烧炼 | SMELT | `items` | 按产出物计数 |
| 附魔 | ENCHANT | `items` | 每次附魔计 1 |
| 消耗 | CONSUME | `items` | 吃/喝均可触发 |
| 钓鱼 | FISH | `items` | 仅统计钓上来的物品 |
| 交易 | TRADE | 无条件 | 任何交易均计入 |

### 通用配置结构

```yaml
task-id:                   # 成就唯一标识 ID
  type: TASK_TYPE          # 任务类型，决定何时触发检查
  name: "&a名称"           # 成就显示名称（支持颜色代码）
  description:             # 成就描述，每行一条
    - "&7描述"
  conditions:              # 完成条件列表
    - type: 条件类型       # 条件类型：blocks / items 等
      字段名:              # 取决于条件类型
        - 值1
        - 值2
  tiers:                   # 层级配置
    1:                     # 第一层
      required-amount: 目标值  # 完成多少次即达标
      rewards:             # 奖励列表
        - type: 奖励类型   # 奖励类型：points / vault / message 等
          参数: 值
```

> **提示**：所有示例中的 `required-amount` 值可根据服务器经济体系调整。TRADE 类型可能对服务端有特殊要求（部分服务端需要 Paper 或其衍生版本）。
