# 3. 命令任务（COMMAND）

> COMMAND 类型任务通过正则表达式监听玩家输入的游戏内命令，完成特定命令操作时触发计数。相比其他任务类型，COMMAND 具有最高的自定义灵活性。

---

## 设计思路

COMMAND 类型的核心是通过**正则表达式匹配**来检测玩家命令。设计要点：

- **不含前导斜杠**：正则表达式匹配的是玩家输入的**命令本身**，不包含开头的 `/`
- **精确匹配 vs 模糊匹配**：`^命令$` 完全匹配 vs `^命令` 前缀匹配
- **交替匹配**：使用 `(a|b|c)` 语法匹配多条类似命令
- **配置格式**：通过 `settings.command` 字段指定正则表达式

```yaml
achievement_id:
  type: COMMAND                # 任务类型：监听玩家命令
  settings:                    # COMMAND 类型的专用配置
    command: "^regex_pattern$"  # 正则表达式匹配命令（不含前导 /）
```

## 完整示例

### 1. 创建城镇

匹配 Towny 插件的 `/town create <名称>` 命令。

```yaml
town-founder:
  type: COMMAND                # 任务类型：监听玩家命令
  name: "&a城镇建设者"         # 成就显示名称
  description:
    - "&7创建一个城镇"
  settings:                    # COMMAND 专用配置段
    command: "^town create .+$"  # 正则：匹配 /town create <名称> 命令
  tiers:
    1:
      required-amount: 1       # 执行命令 1 次即达标
      rewards:
        - type: points
          amount: 10
        - type: vault
          amount: 2000
        - type: broadcast
          message: "&e&l[成就] &f<player> &7创建了一个新城镇！"
```

### 2. 商店购物

匹配商店插件的购买命令。

```yaml
shopaholic:
  type: COMMAND                # 任务类型：监听玩家命令
  name: "&6购物狂"             # 成就显示名称
  description:
    - "&7在商店购买 &e50 &7次物品"
  settings:
    command: "^shop buy .+$"   # 正则：匹配 /shop buy <物品> 命令
  tiers:
    1:
      required-amount: 50      # 购买 50 次即达标
      rewards:
        - type: points
          amount: 10
        - type: vault
          amount: 1000
```

### 3. 传送达人

匹配多种传送命令。

```yaml
frequent-traveler:
  type: COMMAND                # 任务类型：监听玩家命令
  name: "&b旅行者"             # 成就显示名称
  description:
    - "&7使用传送命令 &b100 &7次"
  settings:
    command: "^(tpa|warp|spawn|home)( .*)?$"  # 正则：匹配多种传送命令
  tiers:
    1:
      required-amount: 100     # 传送 100 次即达标
      rewards:
        - type: points
          amount: 15
        - type: vault
          amount: 2000
        - type: message
          message: "&b你使用了 100 次传送！"
```

### 4. 投票达人

匹配服务器投票命令。

```yaml
active-voter:
  type: COMMAND                # 任务类型：监听玩家命令
  name: "&a积极选民"           # 成就显示名称
  description:
    - "&7投票 &a10 &7次"
  settings:
    command: "^vote$"          # 正则：完全匹配 /vote（不含参数）
  tiers:
    1:
      required-amount: 10      # 投票 10 次即达标
      rewards:
        - type: points
          amount: 5
        - type: vault
          amount: 500
        - type: message
          message: "&a感谢你的 10 次投票！"
```

## 正则表达式快速参考

| 模式 | 含义 | 示例 |
|------|------|------|
| `^` | 字符串开头 | `^town` 匹配以 town 开头的命令 |
| `$` | 字符串结尾 | `^vote$` 只匹配 vote，不含参数 |
| `.` | 任意单个字符 | `t.wn` 匹配 town、t1wn |
| `+` | 前一个字符出现 1 次或多次 | `town .+` 匹配 town 后有至少一个字符 |
| `*` | 前一个字符出现 0 次或多次 | `town .*` 匹配 town 后可有可无参数 |
| `\d` | 任意数字 | `\d+` 匹配任意数值 |
| `(a\|b)` | 匹配 a 或 b（交替） | `(tpa\|warp)` 匹配 tpa 或 warp |

### 正则测试建议

- 使用 [regex101.com](https://regex101.com/) 验证正则表达式
- 测试前将语言切换为 **Java** 风格
- 匹配的字符串**不含前导斜杠**——测试时输入 `town create MyTown` 而非 `/town create MyTown`
- 建议上线前在测试服务器用相关命令验证匹配结果

### 常见经济插件命令示例

| 用途 | 正则模式 | 匹配示例 |
|------|---------|---------|
| 转账 | `^pay .+ \d+$` | `pay Steve 100` |
| 查余额 | `^balance$` | `balance` |
| 地皮认领 | `^plot claim$` | `plot claim` |
| 菜单打开 | `^menu$` | `menu` |

> **提示**：COMMAND 类型的 `settings.command` 字段实际匹配的是**不含前导斜杠**的命令字符串。所有正则上线前务必验证。
