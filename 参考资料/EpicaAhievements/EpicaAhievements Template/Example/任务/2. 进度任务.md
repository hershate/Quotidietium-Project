# 2. 进度任务（ADVANCEMENT）

> ADVANCEMENT 类型任务将 Minecraft 原版进度系统与 EpicAchievements 任务体系桥接。玩家完成指定原版进度时自动触发任务计数。

---

## 设计思路

ADVANCEMENT 类型的核心优势在于**零额外配置成本**——直接复用 Mojang 原版已定义好的进度体系：

- **命名空间格式**：`命名空间/路径` 的层级结构，与原版进度 ID 完全一致
- **触发条件**：无需额外 conditions 条件，进度完成即触发
- **配置格式**：通过 `settings.advancement` 字段指定进度 ID

```yaml
achievement_id:
  type: ADVANCEMENT            # 任务类型：追踪原版进度完成
  settings:                    # ADVANCEMENT 类型的专用配置
    advancement: "命名空间/路径"   # 原版进度 ID，格式如 adventure/spyglass_at_parrot
```

## 完整示例

### 1. 鸟类观察者

用望远镜观察鹦鹉。

```yaml
birdwatcher:
  type: ADVANCEMENT            # 任务类型：原版进度
  name: "&a鸟类观察者"         # 成就显示名称
  description:
    - "&7用望远镜观察鹦鹉"
  settings:                    # ADVANCEMENT 专用配置段
    advancement: "adventure/spyglass_at_parrot"  # 原版进度 ID
  tiers:
    1:
      required-amount: 1       # 完成进度 1 次即达标
      rewards:
        - type: points
          amount: 5
        - type: vault
          amount: 500
        - type: message
          message: "&a你完成了一次鸟类观察！"
```

### 2. 下界来客

进入下界。

```yaml
nether-visitor:
  type: ADVANCEMENT            # 任务类型：原版进度
  name: "&c下界来客"           # 成就显示名称
  description:
    - "&7首次进入下界"
  settings:
    advancement: "story/enter_the_nether"  # 原版进度 ID
  tiers:
    1:
      required-amount: 1       # 完成进度 1 次即达标
      rewards:
        - type: points
          amount: 10
        - type: vault
          amount: 2000
        - type: broadcast       # 奖励类型：全服广播
          message: "&c&l[成就] &f<player> &7首次踏入了下界！"
```

### 3. 屠龙勇士

击杀末影龙。

```yaml
dragon-slayer:
  type: ADVANCEMENT            # 任务类型：原版进度
  name: "&5屠龙勇士"           # 成就显示名称
  description:
    - "&7击杀末影龙"
  settings:
    advancement: "end/kill_dragon"  # 原版进度 ID
  tiers:
    1:
      required-amount: 1       # 击杀 1 次即达标
      rewards:
        - type: points
          amount: 50
        - type: vault
          amount: 10000
        - type: broadcast
          message: "&5&l[史诗] &f<player> &5击杀了末影龙！"
        - type: title           # 奖励类型：屏幕标题显示
          title: "&5&l屠龙勇士"  # 标题文字
          subtitle: "&7你拯救了末地！"  # 副标题文字
```

## 关键概念总结

| 概念 | 说明 |
|------|------|
| `type: ADVANCEMENT` | 任务类型，追踪原版进度完成情况 |
| `settings.advancement` | 指定原版进度 ID，格式为 `命名空间/路径` |
| 无需 conditions | 进度完成本身即触发，无需额外过滤条件 |
| 命名空间格式 | `story/root`、`adventure/trade`、`nether/summon_wither`、`end/kill_dragon` |

> **提示**：进度 ID 可在游戏中通过 `/advancement grant @s only <命名空间>:<路径>` 命令验证，或直接查阅服务端 jar 包内的 `data/minecraft/advancements/` 目录。
