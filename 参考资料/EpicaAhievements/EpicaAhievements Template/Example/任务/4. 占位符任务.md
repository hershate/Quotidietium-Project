# 4. 占位符任务（PLACEHOLDER）

> PLACEHOLDER 类型任务通过 PlaceholderAPI 读取占位符变量的值，并基于该值判定任务进度。支持整数数值型和文本型两种模式，通过 `conditions` 中的 `placeholder` 条件实现。

---

## 设计思路

PLACEHOLDER 类型非常适合**与服务器经济、技能、在线时间等外部插件联动**。通过 `placeholder` 条件类型中的不同字段区分两种模式：

- **整数类型**：使用 `placeholder` + `value`（数值）进行比较，支持 `GREATER_THAN`、`GREATER_OR_EQUAL` 等操作符
- **文本类型**：使用 `placeholder` + `value`（字符串） + `operator`（如 `EQUALS`、`CONTAINS`）进行比较

---

## 完整示例

### 1. 整数类型 - 逐级递进（多层级）

检测 AuraSkills 的采集技能等级，使用多层级实现递进目标。

```yaml
foraging-novice:
  type: PLACEHOLDER                # 任务类型：读取占位符变量
  name: "&7伐木初心"               # 成就显示名称
  description:
    - "&7采集技能达到 &f10 &7级"
  conditions:                      # 完成条件
    - type: placeholder            # 条件类型：占位符
      placeholder: "%auraskills_foraging%"  # PAPI 占位符变量
      operator: GREATER_OR_EQUAL   # 比较操作符：大于等于
      value: 10                    # 目标值：技能等级 >= 10
  tiers:
    1:
      required-amount: 1
      rewards:
        - type: points
          amount: 5
        - type: vault
          amount: 500

foraging-expert:
  type: PLACEHOLDER
  name: "&a木艺精通"
  description:
    - "&7采集技能达到 &a25 &7级"
  conditions:
    - type: placeholder
      placeholder: "%auraskills_foraging%"
      operator: GREATER_OR_EQUAL
      value: 25                    # 技能等级 >= 25（递进目标）
  tiers:
    1:
      required-amount: 1
      rewards:
        - type: points
          amount: 15
        - type: vault
          amount: 3000

foraging-king:
  type: PLACEHOLDER
  name: "&6森林之王"
  description:
    - "&7采集技能达到 &e50 &7级"
  conditions:
    - type: placeholder
      placeholder: "%auraskills_foraging%"
      operator: GREATER_OR_EQUAL
      value: 50                    # 技能等级 >= 50（最终目标）
  tiers:
    1:
      required-amount: 1
      rewards:
        - type: points
          amount: 30
        - type: vault
          amount: 10000
        - type: broadcast
          message: "&6&l[传奇] &f<player> &6成为了森林之王！"
```

### 3. 文本类型 - 睡眠检测（单层级）

检测玩家是否正在睡觉。使用文本比较操作符。

```yaml
sweet-dreams:
  type: PLACEHOLDER                # 任务类型：读取占位符变量
  name: "&a美梦成真"               # 成就显示名称
  description:
    - "&7在服务器中入睡"
  conditions:
    - type: placeholder            # 条件类型：占位符
      placeholder: "%player_is_sleeping%"  # PAPI 占位符（返回 yes/no）
      operator: EQUALS             # 文本操作符：完全匹配
      value: "yes"                 # 目标值：正在睡觉
  tiers:
    1:
      required-amount: 1
      rewards:
        - type: points
          amount: 5
        - type: vault
          amount: 200
        - type: message
          message: "&a晚安，好梦！"
```

## 操作符参考

### 整数类型操作符

| 操作符 | 含义 | 示例 |
|--------|------|------|
| `GREATER_THAN` | 大于 value | `value: 50` 表示 > 50 |
| `GREATER_OR_EQUAL` | 大于等于 value | `value: 50` 表示 >= 50（默认） |
| `LESS_THAN` | 小于 value | `value: 50` 表示 < 50 |
| `LESS_OR_EQUAL` | 小于等于 value | `value: 50` 表示 <= 50 |
| `EQUAL` | 精确等于 value | `value: 50` 表示 == 50 |

> 整数类型未指定 `operator` 时，**默认使用 GREATER_OR_EQUAL**。

### 文本类型操作符

| 操作符 | 含义 | 示例 |
|--------|------|------|
| `EQUALS` | 字符串完全匹配 value | `value: "yes"` |
| `CONTAINS` | 字符串包含 value 子串 | `value: "days"` |
| `STARTS_WITH` | 字符串以 value 开头 | `value: "world_"` |
| `ENDS_WITH` | 字符串以 value 结尾 | `value: "_nether"` |

> 文本类型**必须指定** `operator`，否则任务无法正常工作。

---

## 关键概念总结

| 要点 | 说明 |
|------|------|
| **占位符验证** | 使用 `/papi parse me <占位符>` 命令验证占位符是否正常返回 |
| **整数类型** | `placeholder` + `value`（数字） + 可选 `operator`，默认 `GREATER_OR_EQUAL` |
| **文本类型** | `placeholder` + `value`（字符串） + **必须的** `operator` |
| **多层级** | 同一个占位符用不同 value 值创建多个任务，可实现递进目标 |
| **常见占位符源** | AuraSkills、Vault、PlayerPoints、McMMO |

> **提示**：配置完成后务必使用 `/papi parse <玩家名> %占位符%` 确认占位符返回值的格式。整数类型确保返回纯数字，文本类型确认大小写和拼写。
