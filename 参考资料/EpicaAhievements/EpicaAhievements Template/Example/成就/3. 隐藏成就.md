# 隐藏成就

> 带有 `hidden: true` 标记的成就，解锁前在 GUI 中不可见，解锁后才揭示内容。
> 用于创造惊喜感、探索发现、以及非目标导向的有趣行为。

---

## 设计思路

隐藏成就的核心价值在于**惊喜和探索**：

1. **创造惊喜时刻**：玩家无意中触发成就时，突然弹出的提示带来的惊喜感远超提前知晓的成就
2. **鼓励探索行为**：玩家会好奇"这个服务器还有哪些隐藏成就？"从而主动探索
3. **减轻 GUI 负担**：未解锁的隐藏成就不会出现在 GUI 中，避免被大量条目淹没

`hidden: true` 是唯一需要的标记——成就的其余结构和普通成就完全一致。

---

## 完整示例 1：世界探索者（WALK + hidden）

追踪玩家的行走距离。这是一个"终将发生"的隐藏成就——每个玩家迟早都会达成。

```yaml
world-explorer:
  type: WALK  # 触发类型：行走距离累积时检测
  name: "&b世界探索者"  # 成就显示名称（解锁后可见）
  description:
    - "&7你走了 &b10000 &7格"
  hidden: true  # 隐藏成就，解锁前不显示在菜单中
  tiers:
    1:
      required-amount: 10000  # 行走 10000 格即达标
      rewards:
        - type: points
          amount: 30
        - type: vault
          amount: 5000
        - type: broadcast  # 全服广播增加惊喜感
          message: "&b&l[隐藏成就] &f<player> &7踏遍了世界的每一个角落！"
        - type: message
          message: "&b你完成了隐藏成就：世界探索者！"
```

## 完整示例 2：猫有九条命（DEATH + hidden）

追踪玩家的死亡次数。幽默性质的隐藏成就——以"猫有九条命"为梗。

```yaml
cat-life:
  type: DEATH  # 触发类型：玩家死亡时检测
  name: "&c猫有九条命"  # 幽默风格的成就名称
  description:
    - "&7死亡 &c9 &7次……但你还在这里！"
  hidden: true  # 隐藏成就
  tiers:
    1:
      required-amount: 9  # 死亡 9 次触发
      rewards:
        - type: points
          amount: 5
        - type: vault
          amount: 500
        - type: broadcast
          message: "&c&l[隐藏成就] &f<player> &7用了 9 条命还活着！"
        - type: message
          message: "&c隐藏成就解锁：猫有九条命！"
```

## 完整示例 3：绝处逢生（RESURRECT + hidden）

追踪玩家使用不死图腾复活的次数。

```yaml
cheated-death:
  type: RESURRECT  # 触发类型：使用不死图腾复活时检测
  name: "&6绝处逢生"
  description:
    - "&7使用不死图腾逃过一死"
  hidden: true  # 隐藏成就
  tiers:
    1:
      required-amount: 1  # 使用 1 次不死图腾即达标
      rewards:
        - type: points
          amount: 15
        - type: vault
          amount: 2000
        - type: broadcast
          message: "&6&l[隐藏成就] &f<player> &7从死神手中逃脱了！"
        - type: item  # 奖励类型：给予物品
          material: TOTEM_OF_UNDYING  # 奖励一个新的不死图腾
          amount: 1
        - type: message
          message: "&6隐藏成就解锁：绝处逢生！"
```

## 完整示例 4：图腾猎手（KILL_TOTEM + hidden）

击杀持有不死图腾的敌对生物。这是史诗级隐藏成就——难度极高。

```yaml
totem-hunter:
  type: KILL_TOTEM  # 触发类型：击杀持有不死图腾的生物时检测
  name: "&5图腾猎手"
  description:
    - "&7击杀了持有不死图腾的生物"
  hidden: true  # 隐藏成就（稀有史诗级）
  tiers:
    1:
      required-amount: 1  # 击杀 1 次即达标（难度极高）
      rewards:
        - type: points
          amount: 50  # 高额成就点数奖励
        - type: vault
          amount: 10000
        - type: broadcast
          message: "&5&l[史诗隐藏成就] &f<player> &5击杀了持有不死图腾的生物！"
        - type: title  # 奖励类型：发送标题消息
          title: "&5&l史诗成就！"
          subtitle: "&7图腾猎手"
        - type: message
          message: "&5&l史诗成就解锁！"
```

## 关键概念总结

| 概念 | 说明 |
|------|------|
| `hidden: true` | 在 GUI 中隐藏该成就，解锁后才变为可见 |
| 无需额外条件 | WALK / DEATH / RESURRECT / KILL_TOTEM 通常不需要 `conditions` 字段 |
| Broadcast | 隐藏成就配合全服广播效果最佳，引发其他玩家好奇 |

### 常见隐藏成就类型

| 类型 | 触发时机 | 是否需要 conditions |
|------|---------|:------------------:|
| `WALK` | 行走距离累积 | 不需要 |
| `DEATH` | 玩家死亡 | 不需要 |
| `RESURRECT` | 不死图腾复活 | 不需要 |
| `KILL_TOTEM` | 击杀持图腾实体 | 不需要 |
| `KILL` | 击杀特定实体 | 需要 entities |
| `BREAK` | 破坏特定方块 | 需要 blocks |
| `FISH` | 钓到特定物品 | 需要 items |

> **核心原则：隐藏成就是为了惊喜，不是为了隐藏信息。**
>
> 如果成就本身是一个明确的、可主动追求的目标，通常不应隐藏。自然发生、难以预料的成就才适合设为隐藏。
