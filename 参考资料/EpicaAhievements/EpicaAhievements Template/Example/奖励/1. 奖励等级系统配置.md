# 1. 奖励等级系统配置

> 完整的 rewards.yml 等级奖励系统示例，包含多档奖励体系、点数需求公式和 GUI 显示配置。

---

## 设计思路

奖励等级系统是激励玩家持续完成成就的**核心驱动力**。玩家使用完成成就获得的点数来解锁不同等级的奖励。通过设计分层的奖励体系，玩家在每个阶段都能感受到成长和回报：

- **分层设计**：普通奖励（每级）、特殊奖励（每 5 级），形成递进体验
- **视觉反馈**：锁定（locked）、可领取（unclaimed）、已领取（claimed）三种显示状态
- **动态公式**：使用 `{level}` 变量动态计算需求点数

系统中可用的占位符：
- `{level}` — 当前等级编号
- `{points}` — 达到该等级所需的点数
- `{rewards}` — 奖励列表文本

---

## 完整示例：rewards.yml

```yaml
# ============================================================
# rewards.yml - 奖励等级系统
# 两档体系：普通（每级）、特殊（每5级）
# ============================================================
rewards:                        # 奖励等级根配置

  # ----- 普通奖励系列 (normal) -----
  # 每提升一级均可领取，以基础货币为主
  normal:                       # 奖励系列标识
    levels:                     # 等级范围配置
      from: 1                   # 起始等级
      to: 100                   # 结束等级
    required-points: "{level} * 100"  # 所需点数计算公式（等级 * 100）
    rewards:                    # 领取时发放的奖励列表
      - type: vault             # 奖励类型：Vault 货币
        amount: "{level} * 10"  # 金额公式：等级 * 10
      - type: message           # 奖励类型：发送消息
        message: "&a你领取了等级 {level} 的普通奖励！"

    # 锁定状态 - 点数不足时显示
    locked:                     # 锁定状态 GUI 显示
      material: COAL            # 物品材质
      name: "&c普通奖励等级 {level}"  # 显示名称
      lore:                     # 物品描述，每行一条
        - "&8等级 {level}"
        - "&7所需点数: &e{points}"
        - ""
        - "&7奖励:"
        - "{rewards}"
        - ""
        - "&c你还无法领取此奖励"

    # 未领取状态 - 点数足够但未领取时显示
    unclaimed:                  # 可领取状态 GUI 显示
      material: GOLD_NUGGET
      name: "&e普通奖励等级 {level}"
      lore:
        - "&8等级 {level}"
        - "&7所需点数: &e{points}"
        - ""
        - "&7奖励:"
        - "{rewards}"
        - ""
        - "&e点击领取此奖励！"
      glow: true                # 物品是否发光

    # 已领取状态 - 已领取后显示
    claimed:                    # 已领取状态 GUI 显示
      material: GOLD_NUGGET
      name: "&a普通奖励等级 {level}"
      lore:
        - "&8等级 {level}"
        - "&7所需点数: &e{points}"
        - ""
        - "&7奖励:"
        - "{rewards}"
        - ""
        - "&a你已经领取过此奖励！"

  # ----- 特殊奖励系列 (special) -----
  # 每 5 级出现一次，奖励更丰厚
  special:                      # 奖励系列标识
    levels:                     # 等级范围配置
      from: 5                   # 起始等级
      to: 100                   # 结束等级
      step: 5                   # 步进值：每 5 级出现一次
    required-points: "{level} * 500"  # 所需点数公式（等级 * 500）
    weight: 2                   # 同等级多系列时的优先级（数值越高越优先）
    rewards:
      - type: vault
        amount: "{level} * 50"
      - type: experience_levels  # 奖励类型：经验等级
        amount: "{level}"
      - type: broadcast          # 奖励类型：全服广播
        message: "&b&l[成就] &f{player} &7解锁了等级 {level} 的特殊奖励！"

    # 锁定状态
    locked:                     # 锁定状态 GUI 显示
      material: LAPIS_BLOCK     # 物品材质
      name: "&b特殊奖励等级 {level}"
      lore:                     # 物品描述
        - "&8等级 {level}"
        - "&7所需点数: &e{points}"
        - ""
        - "&7奖励:"
        - "{rewards}"
        - ""
        - "&c你还无法领取此奖励"

    # 未领取状态
    unclaimed:                  # 可领取状态 GUI 显示
      material: DIAMOND
      name: "&b特殊奖励等级 {level}"
      lore:
        - "&8等级 {level}"
        - "&7所需点数: &e{points}"
        - ""
        - "&7奖励:"
        - "{rewards}"
        - ""
        - "&e点击领取此奖励！"
      glow: true                # 物品是否发光

    # 已领取状态
    claimed:                    # 已领取状态 GUI 显示
      material: DIAMOND
      name: "&a特殊奖励等级 {level}"
      lore:
        - "&8等级 {level}"
        - "&7所需点数: &e{points}"
        - ""
        - "&7奖励:"
        - "{rewards}"
        - ""
        - "&a你已经领取过此奖励！"
```

## 配置属性说明

| 属性 | 说明 |
|------|------|
| `levels.from` | 该系列奖励的起始等级 |
| `levels.to` | 该系列奖励的结束等级 |
| `levels.step` | （可选）等级步进值，默认 1 |
| `required-points` | 达到该等级所需点数的计算公式 |
| `weight` | （可选）同一等级多系列时的优先级 |
| `locked` | 锁定状态的 GUI 显示（material, name, lore） |
| `unclaimed` | 可领取状态的 GUI 显示 |
| `claimed` | 已领取状态的 GUI 显示 |
| `rewards` | 领取时发放的奖励列表 |
| `glow` | （可选）物品是否发光 |

### 奖励系列适用场景

| 系列 | 间隔 | 定位 | 奖励内容建议 |
|:----:|:----:|:----:|-------------|
| `normal` | 每级 | 日常激励 | 基础货币 |
| `special` | 每 5-10 级 | 阶段性里程碑 | 较多货币、经验等级 |
| `legendary` | 每 50 级 | 终极成就 | 大量货币、特殊物品、全服广播 |

### 数学表达式参考

| 表达式 | 含义 | 示例（level=10） |
|--------|------|:----------------:|
| `{level} * 100` | 线性增长 | 1000 |
| `{level} ^ 2 * 10` | 平方增长 | 1000 |
| `{level} * 50 + 100` | 线性 + 基础值 | 600 |

> **核心原则：多档奖励 + 三态视觉反馈 = 持续驱动力。**
