## 使用说明

1. 先看 `Example/` 理解实际用法（"为什么这样写"）
2. 再查 `General/` 获取完整字段列表（"有哪些字段可用"）
3. 复制模板中的 YAML 配置到 `plugins/Oraxen/items/` 目录下的 `.yml` 文件中
4. 修改纹理路径、物品 ID、参数值等
5. 将纹理文件放入 `plugins/Oraxen/pack/textures/` 对应路径
6. 执行 `/oraxen reload all` 重载插件
7. 执行 `/oraxen pack send @a` 推送资源包

> **注意**：所有模板中的 `my_` 前缀物品 ID 需要替换为你自己的唯一 ID。
> `custom_variation` 值在同一方块类型中不可重复。
