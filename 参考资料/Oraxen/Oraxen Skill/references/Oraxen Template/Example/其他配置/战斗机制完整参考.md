# 战斗机制完整参考

> 基于 Oraxen 官方文档。Oraxen 提供 8 种内置战斗机制。
> 所有基于法术的机制（雷神之锤、能量冲击波、凋零骷髅头、火球）支持 `charges` 选项限制使用次数。
> `charges: -1` = 无限使用，正整数 = 使用指定次数后物品消失。

---

## 一、长矛突刺 (spear_lunge)

> 蓄力冲刺攻击。按住右键蓄力，松开后向前突刺，对路径上敌人造成伤害。
> **版本要求：** Minecraft 1.21.4+（蓄力动画模型交换需要）

### 参数速查表

| 参数 | 类型 | 默认值 | 有效范围 | 说明 |
|------|------|--------|----------|------|
| `active_model` | 字符串 | -- | 有效的模型路径 | **必填**。完全蓄力时的模型（突刺位置） |
| `intermediate_models` | 字符串列表 | `[]` | 模型路径列表 | 蓄力动画的中间帧 |
| `smooth_frames` | 整数 | `0` | `0` ~ N | 从 intermediate_models 中取前 N 个作为动画帧 |
| `charge_ticks` | 整数 | `12` | `1` ~ `200` | 蓄满力需要的刻数。`20` = 1秒 |
| `min_charge_percent` | 小数 | `0.3` | `0.0` ~ `1.0` | 触发攻击所需的最小蓄力百分比 |
| `charge_slowdown` | 小数 | `0.4` | `0.0` ~ `1.0` | 蓄力时移动减速倍率。`0`=无减速，`1`=完全冻结 |
| `max_hold_ticks` | 整数 | `60` | `1` ~ `200` | 自动取消前最大保持时间。防止无限蓄力 |
| `lunge_velocity` | 小数 | `0.6` | `0.0` ~ `5.0` | 突刺向前推进速度 |
| `max_range` | 小数 | `3.5` | `0.5` ~ `10.0` | 命中检测最大距离（方块） |
| `damage` | 小数 | `6.0` | `0.0` ~ `1000.0` | 满蓄力基础伤害 |
| `min_damage` | 小数 | `0.0` | `0.0` ~ `damage` | 最小蓄力时的伤害（线性增长到 damage） |
| `knockback` | 小数 | `0.5` | `0.0` ~ `10.0` | 击退力度 |
| `hitbox_radius` | 小数 | `0.5` | `0.1` ~ `5.0` | 射线追踪宽度，值越大越容易命中 |
| `max_targets` | 整数 | `1` | `1` ~ `50` | 单次突刺可穿透命中的最大实体数 |
| `particles.enabled` | 布尔 | `true` | `true`/`false` | 启用粒子系统 |
| `particles.charge` | 字符串 | -- | 粒子类型 | 蓄力时粒子 |
| `particles.lunge` | 字符串 | -- | 粒子类型 | 突刺时粒子 |
| `particles.hit` | 字符串 | -- | 粒子类型 | 命中时粒子 |
| `sounds.enabled` | 布尔 | `true` | `true`/`false` | 启用声音系统 |
| `sounds.charge` | 字符串 | -- | 声音 ID | 蓄力声音 |
| `sounds.lunge` | 字符串 | -- | 声音 ID | 突刺声音 |
| `sounds.hit` | 字符串 | -- | 声音 ID | 命中声音 |

### 完整 YAML 示例

```yaml
my_spear:
  material: IRON_SWORD
  displayname: "<gradient:#gold:#yellow>Battle Spear"
  Pack:
    generate_model: false
    model: default/spear_inactive          # 待机模型
  Mechanics:
    spear_lunge:
      active_model: default/spear_active   # 满蓄力模型
      intermediate_models:                 # 过渡动画帧
        - default/spear_frame0
        - default/spear_frame1
      smooth_frames: 2                     # 使用 2 帧过渡
      charge_ticks: 20                     # 1 秒蓄满
      min_charge_percent: 0.25             # 至少 25% 才能触发
      charge_slowdown: 0.5                 # 蓄力时减速 50%
      max_hold_ticks: 60                   # 3 秒后自动取消
      lunge_velocity: 0.8                  # 突刺速度
      max_range: 5.0                       # 5 格范围
      damage: 10.0                         # 满蓄力伤害
      min_damage: 2.0                      # 最低 2 点伤害
      knockback: 0.8                       # 击退力度
      hitbox_radius: 0.5
      max_targets: 3                       # 穿透 3 个目标
      particles:
        enabled: true
        charge: CRIT
        lunge: SWEEP_ATTACK
        hit: DAMAGE_INDICATOR
      sounds:
        enabled: true
        charge: ITEM_TRIDENT_RIPTIDE_1
        lunge: ENTITY_PLAYER_ATTACK_SWEEP
        hit: ENTITY_PLAYER_ATTACK_STRONG
```

### 工作流程

1. 按住右键开始蓄力 (charge_ticks)
2. 模型在帧间过渡，粒子生成，移速降低
3. 松开右键或左键突刺
4. 对前方射线上的敌人造成缩放伤害
5. 冷却后再次使用

## 二、雷神之锤 (thor)

> 右键在目标位置召唤闪电。可配置闪电数量和随机偏移。

### 参数速查表

| 参数 | 类型 | 默认值 | 有效范围 | 说明 |
|------|------|--------|----------|------|
| `lightning_bolts_amount` | 整数 | `1` | `1` ~ `100` | 每次生成的闪电数量 |
| `random_location_variation` | 小数 | `0.0` | `0.0` ~ `10.0` | 闪电落点随机偏移范围（方块）。值越大越分散 |
| `delay` | 整数 | `0` | `0` ~ `3600000` | 冷却时间（**毫秒**）。20000ms = 20秒 |
| `charges` | 整数 | `-1` | `-1` ~ `10000` | 使用次数。`-1`=无限 |

### 完整 YAML 示例

```yaml
thors_hammer:
  material: DIAMOND_AXE
  displayname: "<yellow>雷神之锤"
  lore:
    - "<gray>右键投掷闪电"
    - "<gray>毁灭你的敌人"
  Mechanics:
    thor:
      lightning_bolts_amount: 5            # 一次召唤 5 道闪电
      random_location_variation: 1.5       # 1.5 格随机偏移
      delay: 20000                         # 20 秒冷却
      charges: -1                           # 无限使用
```

## 三、生命吸取 (lifeleech)

> 攻击时从对手窃取生命值来治疗自己。

### 参数速查表

| 参数 | 类型 | 默认值 | 有效范围 | 说明 |
|------|------|--------|----------|------|
| `amount` | 小数 | `1` | `0.0` ~ `100.0` | 从对手吸取的**半颗心**数量。`1`=半颗心(0.5HP)，`2`=一颗心(1.0HP) |

### 完整 YAML 示例

```yaml
vampire_blade:
  material: IRON_SWORD
  displayname: "<red>吸血之刃"
  lore:
    - "<gray>击中敌人时吸取生命值"
  Mechanics:
    lifeleech:
      amount: 2                            # 每次命中吸取 1 颗心 (1.0 HP)
```

## 四、流血 (bleeding)

> 攻击概率让敌人流血，在持续时间内每间隔一段时间受到伤害。

### 参数速查表

| 参数 | 类型 | 默认值 | 有效范围 | 说明 |
|------|------|--------|----------|------|
| `chance` | 小数 | `1.0` | `0.0` ~ `1.0` | 施加流血的概率。`0.3`=30%，`1.0`=100% |
| `duration` | 整数 | `100` | `1` ~ `6000` | 流血持续时间（刻）。`20`=1秒，`100`=5秒 |
| `damage_per_interval` | 小数 | `1.0` | `0.1` ~ `100.0` | 每次间隔造成的伤害 |
| `interval` | 整数 | `20` | `1` ~ `200` | 两次伤害的间隔（刻）。`20`=1秒 |

### 完整 YAML 示例

```yaml
bloodletter:
  material: STONE_SWORD
  displayname: "<dark_red>放血者"
  lore:
    - "<gray>击中时有概率让敌人流血"
    - "<gray>流血造成持续伤害"
  Mechanics:
    bleeding:
      chance: 0.3                          # 30% 概率
      duration: 100                        # 持续 5 秒
      damage_per_interval: 0.5             # 每 1 秒扣 0.5 伤害
      interval: 20                         # 间隔 1 秒
```

## 五、能量冲击波 (energyblast)

> 右键释放锥形粒子能量攻击，对前方扇形区域的敌人造成范围伤害。

### 参数速查表

| 参数 | 类型 | 默认值 | 有效范围 | 说明 |
|------|------|--------|----------|------|
| `delay` | 整数 | `0` | `0` ~ `3600000` | 冷却时间（**毫秒**） |
| `length` | 整数 | `5` | `1` ~ `20` | 冲击波有效攻击距离（方块） |
| `damage` | 小数 | `5.0` | `0.1` ~ `1000.0` | 每个目标受到的伤害 |
| `charges` | 整数 | `-1` | `-1` ~ `10000` | 使用次数。`-1`=无限 |
| `particle.type` | 字符串 | `REDSTONE` | 粒子类型 | 粒子类型。仅 REDSTONE 可改颜色 |
| `particle.size` | 小数 | `1` | `0.1` ~ `10.0` | 粒子大小（仅 REDSTONE） |
| `particle.color.red` | 整数 | `0` | `0` ~ `255` | 红色通道 |
| `particle.color.green` | 整数 | `0` | `0` ~ `255` | 绿色通道 |
| `particle.color.blue` | 整数 | `0` | `0` ~ `255` | 蓝色通道 |

### 完整 YAML 示例

```yaml
energy_staff:
  material: BLAZE_ROD
  displayname: "<aqua>能量法杖"
  lore:
    - "<gray>释放一道能量冲击波"
    - "<gray>对前方敌人造成范围伤害"
  Mechanics:
    energyblast:
      delay: 20000                         # 20 秒冷却
      length: 5                            # 5 格射程
      damage: 10.0                         # 10 点伤害
      charges: -1                           # 无限使用
      particle:
        type: REDSTONE
        size: 1
        color:                              # 青色粒子 (RGB: 0, 255, 255)
          red: 0
          green: 255
          blue: 255
```

## 六、凋零骷髅头 (witherskull)

> 右键发射凋零骷髅头弹射物。充能版可破坏方块。

### 参数速查表

| 参数 | 类型 | 默认值 | 有效范围 | 说明 |
|------|------|--------|----------|------|
| `charged` | 布尔 | `false` | `true` / `false` | `true`=充能版，可破坏方块并造成大爆炸 |
| `delay` | 整数 | `0` | `0` ~ `3600000` | 冷却时间（**毫秒**） |
| `charges` | 整数 | `-1` | `-1` ~ `10000` | 使用次数 |

### 完整 YAML 示例

```yaml
wither_staff:
  material: WITHER_SKELETON_SKULL
  displayname: "<dark_gray>凋零法杖"
  lore:
    - "<gray>发射凋零骷髅头"
    - "<gray>充能的骷髅头可破坏方块"
  Mechanics:
    witherskull:
      charged: false                        # 不充能（保护建筑）
      delay: 3000                           # 3 秒冷却
      charges: -1                           # 无限使用
```

## 七、火球 (fireball)

> 右键发射火球，撞击爆炸并点燃周围区域。

### 参数速查表

| 参数 | 类型 | 默认值 | 有效范围 | 说明 |
|------|------|--------|----------|------|
| `delay` | 整数 | `0` | `0` ~ `3600000` | 冷却时间（**毫秒**） |
| `yield` | 小数 | `1.0` | `0.1` ~ `10.0` | 爆炸威力。`1.0`约等于TNT，值越大范围越大 |
| `speed` | 小数 | `1.0` | `0.1` ~ `5.0` | 火球飞行速度倍率 |
| `charges` | 整数 | `-1` | `-1` ~ `10000` | 使用次数 |

### 完整 YAML 示例

```yaml
fire_wand:
  material: FIRE_CHARGE
  displayname: "<gold>火焰魔杖"
  lore:
    - "<gray>发射爆炸火球"
    - "<gray>撞击时爆炸并点燃方块"
  Mechanics:
    fireball:
      delay: 3000                           # 3 秒冷却
      yield: 2.0                            # 两倍 TNT 威力
      speed: 1.0                            # 标准速度
      charges: 5                            # 仅可用 5 次，之后消失
```

## 八、击退连击 (knockback_strike)

> 连续命中达到阈值后触发强力击退。奖励持续战斗。

### 参数速查表

| 参数 | 类型 | 默认值 | 有效范围 | 说明 |
|------|------|--------|----------|------|
| `required_hits` | 整数 | `3` | `1` ~ `20` | 触发击退所需的连续命中次数 |
| `reset_time` | 整数 | `60` | `20` ~ `200` | 未命中后计数器重置时间（刻）。`60`=3秒 |
| `knockback_horizontal` | 小数 | `2.0` | `0.0` ~ `10.0` | 水平击退力度（向后推） |
| `knockback_vertical` | 小数 | `0.5` | `0.0` ~ `5.0` | 垂直击退力度（向上击飞） |
| `play_sound` | 布尔 | `true` | `true` / `false` | 触发时是否播放声音 |
| `sound_type` | 字符串 | `ENTITY_PLAYER_ATTACK_KNOCKBACK` | 声音 ID | 触发声音 |
| `sound_volume` | 小数 | `1.0` | `0.0` ~ `2.0` | 声音音量 |
| `sound_pitch` | 小数 | `1.0` | `0.5` ~ `2.0` | 声音音调。`<1`=低沉，`>1`=高亢 |
| `particle.type` | 字符串 | `CRIT` | 粒子类型 | 触发粒子 |
| `particle.count` | 整数 | `20` | `1` ~ `500` | 粒子数量 |
| `particle.spread` | 小数 | `0.5` | `0.0` ~ `5.0` | 粒子扩散半径（方块） |

### 完整 YAML 示例

```yaml
legendary_hammer:
  material: DIAMOND_PICKAXE
  displayname: "<gradient:#F06966:#FAD6A6>传奇战锤"
  lore:
    - "<#ff455b>» <#D5D6D8>用毁灭性的一击打击你的敌人"
    - "<#ff455b>» <#D5D6D8>在第15次命中时，玩家被向前击飞"
  Mechanics:
    knockback_strike:
      required_hits: 15                     # 需要 15 次连续命中
      reset_time: 80                        # 4 秒未命中则重置
      knockback_horizontal: 2.0             # 强力水平击退
      knockback_vertical: 1.2               # 强力垂直击飞
      play_sound: true
      sound_type: ENTITY_ENDER_DRAGON_HURT  # 龙受伤的震撼音效
      sound_volume: 1.5
      sound_pitch: 0.8                      # 低沉音效
      particle:
        type: DUST                          # 彩色粒子
        count: 200                          # 大量粒子
        spread: 0.5
```

### 工作流程

1. 每次命中 → 连击计数器 +1
2. 超过 reset_time 未命中 → 计数器归零
3. 命中次数达到 required_hits → 触发强力击退 + 粒子 + 声音
4. 计数器归零，重新开始

## 十一、冷却时间单位提醒

| 单位 | 使用位置 |
|------|---------|
| **毫秒 (ms)** | `thor.delay`, `energyblast.delay`, `witherskull.delay`, `fireball.delay` |
| **刻 (ticks)** | `spear_lunge.charge_ticks`, `bleeding.duration`, `bleeding.interval`, `knockback_strike.reset_time` |
| **秒** 无直接秒字段 | 需要自行换算: 1000ms = 1秒, 20ticks = 1秒 |

> **注意：** 战斗机制中的 `delay` 统一使用**毫秒**，而 `custom` 机制的 `cooldown` 使用**刻 (ticks)**。这是最容易混淆的地方。
