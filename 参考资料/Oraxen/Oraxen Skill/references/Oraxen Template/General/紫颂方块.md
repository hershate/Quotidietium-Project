# 紫颂方块 (ChorusBlock) 配置模板

> **机制说明**: 紫颂方块机制使用 Minecraft 的紫颂植物方块状态来创建自定义方块。提供多达 **63 种独特的方块变体**，最适合透明方块。
>
> **适用场景**: 透明方块（自定义树叶、玻璃变体）、需要透视渲染的单格家具、需要座椅功能的方块。
>
> **独有特性**: 紫颂方块是唯一支持 **座椅 (seat)** 功能的方块机制（家具除外），玩家可以坐在紫颂方块上。
>
> **Paper 服务器推荐**: 在 `config/paper-global.yml` 中启用:
> ```yaml
> block-updates:
>   disable-chorus-plant-updates: true
> ```

---

## 一、全局配置 (mechanics.yml)

将以下内容配置在 `plugins/Oraxen/mechanics.yml` 中：

```yaml
# ============================================================
# 紫颂方块机制全局配置 (plugins/Oraxen/mechanics.yml)
# ============================================================
chorusblock:
  # [必需] 启用/禁用此机制
  enabled: true

  # [可选] 可以破坏自定义方块的镐工具等级
  tool_types:
    - WOODEN
    - STONE
    - IRON
    - GOLDEN
    - DIAMOND
    - NETHERITE
```

## 二、最简配置

```yaml
# ============================================================
# 示例: 最简单的紫颂方块
# ============================================================
my_chorus_block:
  # ---- 基础信息 ----
  # [必需] 显示名称
  displayname: "<gray>自定义透明方块"

  # [必需] 基础材质，通常用 PAPER
  material: PAPER

  # ---- 资源包/模型配置 ----
  Pack:
    # [必需] 是否自动生成模型
    generate_model: true

    # [必需] 父模型类型
    # 常用: block/cube_all (普通方块), block/leaves (树叶), block/cross (植物)
    parent_model: "block/cube_all"

    # [必需] 纹理文件
    textures:
      - my_block_texture

  # ---- 方块机制配置 ----
  Mechanics:
    chorusblock:
      # [必需★] 自定义变体编号，范围 1-63
      # 每个紫颂方块必须使用唯一的 custom_variation
      custom_variation: 1

      # [必需★] 模型名称
      model: my_chorus_block

      # [可选] 硬度
      hardness: 5

      # [可选] 掉落物配置
      drop:
        silktouch: false
        loots:
          - { oraxen_item: my_chorus_block, probability: 1.0 }
```

## 三、完整配置模板（含所有可选字段）

```yaml
# ============================================================
# 完整示例: 带所有可选功能的紫颂方块
# ============================================================
custom_glass_block:
  displayname: "<#AAFFFF>自定义琉璃"
  material: PAPER
  Pack:
    generate_model: true
    parent_model: "block/cube_all"
    textures:
      - custom_glass

  Mechanics:
    chorusblock:
      # ========== 核心配置 ==========

      # [必需★] 自定义变体编号 (1-63)
      custom_variation: 1

      # [必需★] 模型名称
      model: custom_glass_block

      # ========== 物理属性 ==========

      # [可选] 硬度，数值越大挖掘时间越长
      # 参考: 玻璃=1, 石头=3, 黑曜石=50
      hardness: 1

      # [可选] 光照等级 0-15 (默认: 0)
      light: 8

      # [可选] 是否防爆 (默认: false)
      blast_resistant: false

      # [可选] 是否受重力影响下落 (默认: false)
      is_falling: false

      # [可选] 是否无法被活塞推动 (默认: false)
      immovable: false

      # ========== 方块音效 ==========
      # [可选] 自定义各种交互音效
      block_sounds:
        # 简写方式:
        place_sound: block.glass.place
        break_sound: block.glass.break
        hit_sound: block.glass.hit
        step_sound: block.glass.step
        fall_sound: block.glass.fall

        # 详细写法（逐音效自定义音量和音调）:
        # place:
        #   sound: block.glass.place
        #   volume: 1.0
        #   pitch: 0.9
        # break:
        #   sound: block.glass.break
        #   volume: 1.0
        #   pitch: 1.0

      # ========== 掉落物配置 ==========
      drop:
        # [可选] 是否需要精准采集才能掉落
        silktouch: true

        # [可选] 挖掘所需最低工具等级
        minimal_type: STONE
        # 可用值: WOODEN, STONE, IRON, GOLDEN, DIAMOND, NETHERITE

        # [可选] 最适合的挖掘工具
        best_tools:
          - PICKAXE

        # [必需] 掉落物列表
        loots:
          - oraxen_item: custom_glass_block
            probability: 1.0
            max_amount: 1

          # 额外掉落（概率独立计算）
          - oraxen_item: DIAMOND
            probability: 0.05          # 5% 额外掉落钻石
            max_amount: 2

      # ========== 座椅配置 (紫颂独有的功能!) ==========
      # [可选] 让玩家可以坐在方块上
      # seat:
      #   height: 0.5    # 从方块顶部的高度偏移 (0.0 = 方块表面, 0.5 = 半格)
      #   yaw: 0         # [可选] 坐下时的固定旋转角度 (0-360)
      #
      # 当玩家右键点击带座椅的方块时会自动坐下。
      # 座椅使用隐形盔甲架实体实现。
      # 非常适合做椅子、长凳、王座等。

      # ========== 存储容器 ==========
      # [可选] 将方块变成可打开的容器
      # storage:
      #   type: STORAGE
      #   rows: 3                     # 1-6 行
      #   title: "<aqua>琉璃储物柜"
      #   open_sound: block.chest.open
      #   close_sound: block.chest.close
      #
      # 存储类型:
      # - STORAGE      标准共享容器
      # - SHULKER      破坏时物品保留在方块中
      # - PERSONAL     每个玩家独立存储
      # - DISPOSAL     垃圾桶
      # - ENDERCHEST   打开玩家的末影箱

      # ========== 限制放置 ==========
      # [可选] 限制方块的放置位置
      # limited_placing:
      #   roof: false        # 天花板
      #   floor: true        # 地面
      #   wall: false        # 墙壁
      #   type: ALLOW        # ALLOW (白名单) 或 DENY (黑名单)
      #   block_types:       # 原版方块类型
      #     - GRASS_BLOCK
      #     - DIRT
      #     - STONE
      #   block_tags:        # 方块标签
      #     - base_stone_overworld
      #   oraxen_blocks:     # Oraxen 自定义方块
      #     - custom_stone

      # ========== BlockLocker 保护 ==========
      # blocklocker:
      #   can_protect: true
      #   protection_type: CONTAINER    # CONTAINER / DOOR / ATTACHABLE

      # ========== ClickActions 点击动作 ==========
      # [可选] 点击方块时执行动作
      # clickActions:
      #   - conditions:
      #       - '#player.hasPermission("special.use")'
      #     actions:
      #       - '[console] give %player% special_item 1'
      #       - '[message] <green>你获得了一件特殊物品!'
      #       - '{source=BLOCK volume=1.0 pitch=1.0} [sound] minecraft:block.note_block.chime'
      #   - conditions: []
      #     actions:
      #       - '[actionbar] <gray>右键点击以获得特殊物品'
```

## 四、典型场景示例

### 4.1 自定义树叶（透明方块）

```yaml
# ============================================================
# 自定义树叶 — 紫颂方块最适合的用途之一
# ============================================================
magic_leaves:
  displayname: "<gradient:#FF69B4:#8A2BE2>魔法树叶"
  material: PAPER
  Pack:
    generate_model: true
    parent_model: "block/leaves"     # 使用树叶父模型获得透明度
    textures:
      - magic_leaves
  Mechanics:
    chorusblock:
      custom_variation: 1
      model: magic_leaves
      hardness: 0.2                  # 树叶很容易破坏
      light: 4
      block_sounds:
        place_sound: block.grass.place
        break_sound: block.grass.break
        hit_sound: block.grass.hit
        step_sound: block.grass.step
        fall_sound: block.grass.fall
      drop:
        silktouch: true              # 只有精准采集才掉落树叶本身
        best_tools:
          - SHEARS
          - HOE
        loots:
          - oraxen_item: magic_leaves
            probability: 1.0
          # 没有精准采集时掉落其他物品的逻辑通过 silktouch: true 控制
```

### 4.5 带点击动作的交互方块

```yaml
# ============================================================
# 交互式透明方块 — 结合 ClickActions
# ============================================================
magic_altar:
  displayname: "<gradient:#FFD700:#FF6347>魔法祭坛"

    generate_model: true
    parent_model: "block/cube_all"

      custom_variation: 10
      model: magic_altar
      hardness: 10

      immovable: true
      block_sounds:
        place_sound: block.enchanting_table.place
        break_sound: block.enchanting_table.break
        step_sound: block.stone.step
      clickActions:
        - conditions:
            - '#player.hasPermission("magic.use")'
          actions:
            - '[message] <gradient:#FFD700:#FF6347>魔法祭坛感受到了你的力量...'
            - '{source=BLOCK volume=1.0 pitch=1.5} [sound] minecraft:block.enchanting_table.use'
            - '[console] effect give %player% minecraft:regeneration 10 1'
        - conditions: []
          actions:
            - '[message] <red>你没有使用祭坛的权限!'
      drop:
        silktouch: true
        minimal_type: DIAMOND
        best_tools:
          - PICKAXE
        loots:
          - oraxen_item: magic_altar
            probability: 1.0
```

## 六、配置字段速查表

```yaml
# ============================================================

# ============================================================
```

## 七、注意事项

1. **变体数量最少**: 紫颂方块只有 63 个变体，是所有方块机制中最少的。请合理规划使用。
2. **custom_variation 唯一性**: 每个紫颂方块必须使用唯一的 `custom_variation` 值 (1-63)。重复使用会导致方块渲染错误。
3. **Paper 优化**: 强烈建议在 `config/paper-global.yml` 中设置 `disable-chorus-plant-updates: true`，否则 Oraxen 必须监听昂贵的物理事件。
4. **透明方块最佳选择**: 对于透视渲染很重要的方块（树叶、玻璃类、透明家具），紫颂方块是比家具（展示实体）更高效的选择。
5. **座椅是独有功能**: 在三种核心方块机制中（音符盒、绊线、紫颂），只有紫颂支持座椅。如需在方块上实现座椅功能，请选择紫颂方块。
6. **使用 block/leaves 父模型**: 制作树叶等透明度方块时，使用 `parent_model: "block/leaves"` 来获得正确的透明通道渲染效果。
7. **不适合复杂模型**: 如果需要复杂的 3D 模型（如复杂的椅子、桌子），建议使用家具 (Furniture) 机制，它没有变体数量限制。
