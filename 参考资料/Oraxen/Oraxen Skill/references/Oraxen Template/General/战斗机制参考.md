## 长矛突刺 (spear_lunge)

### 概述

一种蓄力攻击机制，可将你的武器转变为毁灭性的突刺。按住右键蓄力，然后松开或左键向前突刺，对路径上的敌人造成伤害。

> **版本要求：** 需要 Minecraft 1.21.4+ 以在蓄力动画期间进行模型交换。

### 特性

- **模型动画**：武器模型在蓄力期间视觉上会过渡（需要 1.21.4+）
- **流畅动画**：可选的中间帧用于流畅的蓄力动画
- **多目标**：具有可配置穿透能力的突刺路径，可命中多个敌人
- **移动减速**：可配置蓄力时的速度降低
- **完全自定义**：粒子、声音、伤害、范围和击退均可配置

### 完整 YAML 配置

```yaml
# ============================================================
# 物品配置示例：长矛突刺
# ============================================================
my_spear:
  material: IRON_SWORD                                    # 【必填】物品的基础材质
  displayname: "<gradient:#gold:#yellow>Battle Spear"     # 【必填】物品的显示名称
  Pack:
    generate_model: false                                 # 【必填】是否自动生成模型，设为 false 以使用自定义模型
    model: default/spear_inactive                         # 【必填】基础模型路径（待机位置/未蓄力状态）
  Mechanics:
    spear_lunge:
      # ── 模型配置 ──────────────────────────────
      active_model: default/spear_active                  # 【必填】完全蓄力时的模型路径（突刺位置）
      intermediate_models:                                # 【可选】流畅蓄力动画的中间帧模型列表
        - default/spear_frame0                            #   蓄力动画帧 0
        - default/spear_frame1                            #   蓄力动画帧 1
      smooth_frames: 2                                    # 【可选】蓄力期间使用的动画帧数量（默认：0）

      # ── 蓄力参数 ──────────────────────────────
      charge_ticks: 20                                    # 【可选】蓄满力需要的刻数（20 刻 = 1 秒，默认：12）
      min_charge_percent: 0.25                            # 【可选】触发攻击所需的最小蓄力百分比 0.0-1.0（默认：0.3）
      charge_slowdown: 0.5                                # 【可选】蓄力时的移动速度降低倍率
                                                          #   0.0 = 无减速，1.0 = 完全冻结（默认：0.4）
      max_hold_ticks: 60                                  # 【可选】自动取消前保持蓄力的最大刻数（默认：60）
                                                          #   防止玩家无限期带着蓄力武器走动

      # ── 攻击参数 ──────────────────────────────
      lunge_velocity: 0.8                                 # 【可选】突刺释放时的向前速度倍率（默认：0.6）
      max_range: 5.0                                      # 【可选】最大命中检测范围，以方块计（默认：3.5）
      damage: 10.0                                        # 【可选】满蓄力时的基础伤害（默认：6.0）
      min_damage: 2.0                                     # 【可选】最低有效蓄力时的最小伤害（默认：0.0）
                                                          #   实际伤害按蓄力百分比从 min_damage 线性缩放到 damage
      knockback: 0.8                                      # 【可选】对目标施加的击退强度（默认：0.5）
      hitbox_radius: 0.5                                  # 【可选】命中检测的射线追踪宽度（默认：0.5，最大：5.0）
                                                          #   值越大越容易命中偏离中心的目标
      max_targets: 3                                      # 【可选】每次突刺命中的最大敌人数（默认：1）

      # ── 粒子效果 ──────────────────────────────
      particles:
        enabled: true                                     # 【可选】是否启用粒子效果
        charge: CRIT                                      # 【可选】蓄力期间显示的粒子类型
        lunge: SWEEP_ATTACK                               # 【可选】突刺时显示的粒子类型
        hit: DAMAGE_INDICATOR                             # 【可选】命中敌人时显示的粒子类型

      # ── 声音效果 ──────────────────────────────
      sounds:
        enabled: true                                     # 【可选】是否启用声音效果
        charge: ITEM_TRIDENT_RIPTIDE_1                    # 【可选】蓄力期间播放的声音
        lunge: ENTITY_PLAYER_ATTACK_SWEEP                 # 【可选】突刺时播放的声音
        hit: ENTITY_PLAYER_ATTACK_STRONG                  # 【可选】命中敌人时播放的声音
```

### 参数详解

| 参数 | 类型 | 默认值 | 有效范围 | 必填 | 说明 |
|------|------|--------|----------|------|------|
| `active_model` | 字符串 | - | 有效的模型路径 | **是** | 完全蓄力时的模型，用于动画过渡 |
| `intermediate_models` | 字符串列表 | `[]` | 有效的模型路径列表 | 否 | 蓄力动画的中间帧，按顺序播放 |
| `smooth_frames` | 整数 | `0` | `0` ~ N | 否 | 实际使用的中间帧数量（从 `intermediate_models` 中取前 N 个） |
| `charge_ticks` | 整数 | `12` | `1` ~ `200` | 否 | 达到满蓄力所需的刻数，20 刻 = 1 秒 |
| `min_charge_percent` | 小数 | `0.3` | `0.0` ~ `1.0` | 否 | 攻击所需的最小蓄力百分比，低于此值松开右键不会触发攻击 |
| `charge_slowdown` | 小数 | `0.4` | `0.0` ~ `1.0` | 否 | 蓄力期间的移动减速倍率，1.0 表示完全无法移动 |
| `max_hold_ticks` | 整数 | `60` | `1` ~ `200` | 否 | 自动取消前的最大保持时间。超过此时间攻击自动取消，不会造成伤害 |
| `lunge_velocity` | 小数 | `0.6` | `0.0` ~ `5.0` | 否 | 突刺时玩家向前推进的速度倍率 |
| `max_range` | 小数 | `3.5` | `0.5` ~ `10.0` | 否 | 命中检测的最大距离（以方块计） |
| `damage` | 小数 | `6.0` | `0.0` ~ `1000.0` | 否 | 满蓄力时造成的基础伤害 |
| `min_damage` | 小数 | `0.0` | `0.0` ~ `damage` | 否 | 最小蓄力时造成的伤害，随蓄力百分比线性增长至 damage |
| `knockback` | 小数 | `0.5` | `0.0` ~ `10.0` | 否 | 对目标施加的击退力度 |
| `hitbox_radius` | 小数 | `0.5` | `0.1` ~ `5.0` | 否 | 射线追踪的碰撞检测宽度，值越大越容易命中 |
| `max_targets` | 整数 | `1` | `1` ~ `50` | 否 | 单次突刺可穿透命中的最大实体数 |
| `particles.enabled` | 布尔 | `true` | `true` / `false` | 否 | 是否启用粒子效果系统 |
| `particles.charge` | 字符串 | - | 有效的粒子类型 | 否 | 蓄力时在玩家周围生成的粒子 |
| `particles.lunge` | 字符串 | - | 有效的粒子类型 | 否 | 突刺释放时生成的粒子 |
| `particles.hit` | 字符串 | - | 有效的粒子类型 | 否 | 命中目标时在目标位置生成的粒子 |
| `sounds.enabled` | 布尔 | `true` | `true` / `false` | 否 | 是否启用声音效果系统 |
| `sounds.charge` | 字符串 | - | 有效的 Minecraft 声音 ID | 否 | 蓄力时播放的声音 |
| `sounds.lunge` | 字符串 | - | 有效的 Minecraft 声音 ID | 否 | 突刺释放时播放的声音 |
| `sounds.hit` | 字符串 | - | 有效的 Minecraft 声音 ID | 否 | 命中目标时播放的声音 |

### 工作流程

1. **开始蓄力**：手持长矛按住右键开始蓄力
2. **视觉反馈**：武器模型在帧之间动画过渡，生成粒子，移动速度降低
3. **攻击**：蓄力后松开右键或左键向前突刺
4. **伤害**：前方射线上的敌人受到按蓄力百分比缩放的伤害（从 `min_damage` 到 `damage`）
5. **冷却时间**：攻击后有一个短暂冷却才能再次蓄力

> **警告：** 如果蓄力时间超过 `max_hold_ticks`，攻击将自动取消并恢复到非活动模型，不会造成伤害。这可以防止玩家无限期地带着蓄力武器四处走动。

## 雷神之锤 (thor)

### 概述

右键时在目标位置召唤闪电。可配置闪电数量、随机偏移和冷却时间。

### 完整 YAML 配置

```yaml
# ============================================================
# 物品配置示例：雷神之锤
# ============================================================
thors_hammer:
  material: DIAMOND_AXE                                   # 【必填】物品的基础材质
  displayname: "<yellow>雷神之锤"                           # 【必填】物品的显示名称
  lore:                                                    # 【可选】物品的描述文字
    - "<gray>右键投掷闪电"
    - "<gray>毁灭你的敌人"
  Mechanics:
    thor:
      lightning_bolts_amount: 5                            # 【可选】每次使用生成的闪电数量（默认：1）
                                                           #   有效范围：1 ~ 100
      random_location_variation: 1.5                       # 【可选】闪电之间的随机位置偏移，以方块计（默认：0.0）
                                                           #   有效范围：0.0 ~ 10.0
      delay: 20000                                         # 【可选】两次使用之间的冷却时间，以毫秒为单位（默认：0）
                                                           #   20000ms = 20 秒，1000ms = 1 秒
                                                           #   有效范围：0 ~ 3600000（1小时）
      charges: -1                                          # 【可选】物品消耗前的使用次数（默认：-1）
                                                           #   -1 = 无限使用
                                                           #   正整数 = 使用指定次数后物品被消耗
```

### 参数详解

| 参数 | 类型 | 默认值 | 有效范围 | 必填 | 说明 |
|------|------|--------|----------|------|------|
| `lightning_bolts_amount` | 整数 | `1` | `1` ~ `100` | 否 | 每次右键时生成的闪电数量 |
| `random_location_variation` | 小数 | `0.0` | `0.0` ~ `10.0` | 否 | 闪电落点相对于目标的随机偏移范围（以方块计），值越大闪电越分散 |
| `delay` | 整数 | `0` | `0` ~ `3600000` | 否 | 冷却时间（毫秒）。1000 毫秒 = 1 秒 |
| `charges` | 整数 | `-1` | `-1` ~ `10000` | 否 | 物品可使用的总次数。`-1` 表示无限使用。正整数表示使用对应次数后物品消失 |

### 工作流程

1. **瞄准**：玩家手持雷神之锤，准星对准目标位置
2. **触发**：右键点击，闪电在目标位置及周围随机偏移范围内生成
3. **伤害**：闪电对范围内的实体造成原版闪电伤害
4. **冷却**：触发后进入冷却时间，冷却期间无法再次使用

## 生命吸取 (lifeleech)

### 概述

在击中对手时窃取他们的生命值来治疗自己。

### 完整 YAML 配置

```yaml
# ============================================================
# 物品配置示例：生命吸取
# ============================================================
vampire_blade:
  material: IRON_SWORD                                   # 【必填】物品的基础材质
  displayname: "<red>吸血之刃"                             # 【必填】物品的显示名称
  lore:                                                    # 【可选】物品的描述文字
    - "<gray>击中敌人时吸取生命值"
  Mechanics:
    lifeleech:
      amount: 2                                            # 【可选】每次命中从对手窃取的半颗心数量（默认：1）
                                                           #   1 = 半颗心（0.5 生命值）
                                                           #   2 = 一颗心（1.0 生命值）
                                                           #   有效范围：0.0 ~ 100.0
```

### 参数详解

| 参数 | 类型 | 默认值 | 有效范围 | 必填 | 说明 |
|------|------|--------|----------|------|------|
| `amount` | 小数 | `1` | `0.0` ~ `100.0` | 否 | 从对手吸取的半颗心数量。1 = 半颗心（0.5 HP），2 = 一颗心（1.0 HP） |

### 工作流程

1. **攻击**：使用带有生命吸取机制的武器攻击实体
2. **吸血**：造成伤害的同时，从对手吸取指定数量的生命值
3. **治疗**：吸取的生命值直接加到玩家的生命值上

## 流血 (bleeding)

### 概述

攻击时有概率让敌人进入流血状态，在持续时间内每间隔一段时间受到伤害。

### 完整 YAML 配置

```yaml
# ============================================================
# 物品配置示例：流血
# ============================================================
bloodletter:
  material: STONE_SWORD                                   # 【必填】物品的基础材质
  displayname: "<dark_red>放血者"                           # 【必填】物品的显示名称
  lore:                                                    # 【可选】物品的描述文字
    - "<gray>击中时有概率让敌人流血"
    - "<gray>流血造成持续伤害"
  Mechanics:
    bleeding:
      chance: 0.3                                          # 【可选】命中时施加流血效果的概率（默认：1.0）
                                                           #   0.3 = 30%，1.0 = 100%
                                                           #   有效范围：0.0 ~ 1.0
      duration: 100                                        # 【可选】流血效果持续的刻数（默认：100）
                                                           #   20 刻 = 1 秒，100 刻 = 5 秒
                                                           #   有效范围：1 ~ 6000（5分钟）
      damage_per_interval: 0.5                             # 【可选】每个伤害间隔造成的伤害（默认：1.0）
                                                           #   0.5 = 四分之一颗心
                                                           #   有效范围：0.1 ~ 100.0
      interval: 20                                         # 【可选】伤害触发的间隔，以刻为单位（默认：20）
                                                           #   20 刻 = 1 秒
                                                           #   有效范围：1 ~ 200
```

### 参数详解

| 参数 | 类型 | 默认值 | 有效范围 | 必填 | 说明 |
|------|------|--------|----------|------|------|
| `chance` | 小数 | `1.0` | `0.0` ~ `1.0` | 否 | 每次成功命中时施加流血效果的概率 |
| `duration` | 整数 | `100` | `1` ~ `6000` | 否 | 流血效果的持续时间（刻）。20 刻 = 1 秒 |
| `damage_per_interval` | 小数 | `1.0` | `0.1` ~ `100.0` | 否 | 每个伤害间隔造成的伤害值 |
| `interval` | 整数 | `20` | `1` ~ `200` | 否 | 两次伤害之间的间隔（刻）。20 刻 = 1 秒 |

### 工作流程

1. **攻击**：使用带有流血机制的武器攻击实体
2. **概率判定**：按 `chance` 概率判定是否施加流血
3. **持续伤害**：施加后，每隔 `interval` 刻造成 `damage_per_interval` 伤害
4. **结束**：`duration` 刻后流血效果自动结束

## 能量冲击波 (energyblast)

### 概述

创建一个粒子锥形区域来攻击前方实体。右键触发，向前方扇形区域造成范围伤害。

### 完整 YAML 配置

```yaml
# ============================================================
# 物品配置示例：能量冲击波
# ============================================================
energy_staff:
  material: BLAZE_ROD                                     # 【必填】物品的基础材质
  displayname: "<aqua>能量法杖"                             # 【必填】物品的显示名称
  lore:                                                    # 【可选】物品的描述文字
    - "<gray>释放一道能量冲击波"
    - "<gray>对前方敌人造成范围伤害"
  Mechanics:
    energyblast:
      delay: 20000                                         # 【可选】冷却时间，以毫秒为单位（默认：0）
                                                           #   20000ms = 20 秒
                                                           #   有效范围：0 ~ 3600000
      length: 5                                            # 【可选】冲击波的有效长度，以方块计（默认：5）
                                                           #   有效范围：1 ~ 20
      damage: 10.0                                         # 【可选】冲击波对每个目标造成的伤害（默认：5.0）
                                                           #   有效范围：0.1 ~ 1000.0
      charges: -1                                          # 【可选】物品消耗前的使用次数（默认：-1）
                                                           #   -1 = 无限使用
      particle:                                            # 【可选】粒子效果配置
        type: REDSTONE                                     # 【可选】粒子类型（默认：REDSTONE）
                                                           #   只有 REDSTONE 粒子可以改变颜色和大小
                                                           #   其他可选：FLAME, SPELL_WITCH, DRAGON_BREATH 等
        size: 1                                            # 【可选】粒子大小（默认：1）
                                                           #   有效范围：0.1 ~ 10.0
        color:                                             # 【可选】粒子颜色（仅对 REDSTONE 类型有效）
          red: 0                                           #   红色通道 0-255
          green: 255                                       #   绿色通道 0-255（此例为青色）
          blue: 255                                        #   蓝色通道 0-255（此例为青色）
```

### 参数详解

| 参数 | 类型 | 默认值 | 有效范围 | 必填 | 说明 |
|------|------|--------|----------|------|------|
| `delay` | 整数 | `0` | `0` ~ `3600000` | 否 | 冷却时间（毫秒）。1000 毫秒 = 1 秒 |
| `length` | 整数 | `5` | `1` ~ `20` | 否 | 冲击波的有效攻击距离（以方块计） |
| `damage` | 小数 | `5.0` | `0.1` ~ `1000.0` | 否 | 冲击波对每个被命中目标造成的伤害 |
| `charges` | 整数 | `-1` | `-1` ~ `10000` | 否 | 物品可使用的总次数。`-1` 为无限使用 |
| `particle.type` | 字符串 | `REDSTONE` | 有效的粒子类型 | 否 | 粒子类型。若需自定义颜色和大小，需使用 `REDSTONE` |
| `particle.size` | 小数 | `1` | `0.1` ~ `10.0` | 否 | 粒子大小（仅 REDSTONE 粒子有效） |
| `particle.color.red` | 整数 | `0` | `0` ~ `255` | 否 | 粒子颜色的红色通道值 |
| `particle.color.green` | 整数 | `0` | `0` ~ `255` | 否 | 粒子颜色的绿色通道值 |
| `particle.color.blue` | 整数 | `0` | `0` ~ `255` | 否 | 粒子颜色的蓝色通道值 |

### 工作流程

1. **瞄准**：玩家手持能量法杖，准星对准目标方向
2. **触发**：右键点击释放冲击波
3. **伤害区域**：在玩家前方生成长度为 `length` 的锥形伤害区域
4. **粒子显示**：区域以指定颜色和大小的粒子填充
5. **伤害**：区域内的所有实体受到伤害
6. **冷却**：触发后进入冷却时间

## 凋零骷髅头 (witherskull)

### 概述

右键时发射凋零骷髅头弹射物。充能的骷髅头可以破坏方块。

### 完整 YAML 配置

```yaml
# ============================================================
# 物品配置示例：凋零骷髅头
# ============================================================
wither_staff:
  material: WITHER_SKELETON_SKULL                         # 【必填】物品的基础材质
  displayname: "<dark_gray>凋零法杖"                        # 【必填】物品的显示名称
  lore:                                                    # 【可选】物品的描述文字
    - "<gray>发射凋零骷髅头"
    - "<gray>充能的骷髅头可破坏方块"
  Mechanics:
    witherskull:
      charged: false                                       # 【可选】是否发射充能的骷髅头（默认：false）
                                                           #   true = 充能骷髅头，可破坏方块
                                                           #   false = 普通骷髅头，不能破坏方块
      delay: 3000                                          # 【可选】冷却时间，以毫秒为单位（默认：0）
                                                           #   3000ms = 3 秒
                                                           #   有效范围：0 ~ 3600000
      charges: -1                                          # 【可选】物品消耗前的使用次数（默认：-1）
                                                           #   -1 = 无限使用
```

### 参数详解

| 参数 | 类型 | 默认值 | 有效范围 | 必填 | 说明 |
|------|------|--------|----------|------|------|
| `charged` | 布尔 | `false` | `true` / `false` | 否 | 是否发射充能凋零骷髅头。充能版可破坏方块并造成更大爆炸 |
| `delay` | 整数 | `0` | `0` ~ `3600000` | 否 | 冷却时间（毫秒）。1000 毫秒 = 1 秒 |
| `charges` | 整数 | `-1` | `-1` ~ `10000` | 否 | 物品可使用的总次数。`-1` 为无限使用 |

### 工作流程

1. **瞄准**：玩家手持凋零法杖，准星对准目标
2. **发射**：右键发射凋零骷髅头
3. **飞行**：骷髅头沿瞄准方向直线飞行
4. **撞击**：撞到实体或方块时造成伤害和凋零效果
5. **方块破坏**：若 `charged: true`，充能骷髅头可破坏爆炸范围内的方块

## 火球 (fireball)

### 概述

右键时发射火球。火球在撞击时爆炸并点燃周围区域。

### 完整 YAML 配置

```yaml
# ============================================================
# 物品配置示例：火球
# ============================================================
fire_wand:
  material: FIRE_CHARGE                                   # 【必填】物品的基础材质
  displayname: "<gold>火焰魔杖"                             # 【必填】物品的显示名称
  lore:                                                    # 【可选】物品的描述文字
    - "<gray>发射爆炸火球"
    - "<gray>撞击时爆炸并点燃方块"
  Mechanics:
    fireball:
      delay: 3000                                          # 【可选】冷却时间，以毫秒为单位（默认：0）
                                                           #   3000ms = 3 秒
                                                           #   有效范围：0 ~ 3600000
      yield: 2.0                                           # 【可选】爆炸威力（默认：1.0）
                                                           #   1.0 = TNT 威力，2.0 = 两倍 TNT 威力
                                                           #   有效范围：0.1 ~ 10.0
      speed: 1.0                                           # 【可选】弹射物飞行速度（默认：1.0）
                                                           #   有效范围：0.1 ~ 5.0
      charges: 5                                           # 【可选】物品消耗前的使用次数（默认：-1）
                                                           #   5 = 使用 5 次后物品被消耗
                                                           #   -1 = 无限使用
```

### 参数详解

| 参数 | 类型 | 默认值 | 有效范围 | 必填 | 说明 |
|------|------|--------|----------|------|------|
| `delay` | 整数 | `0` | `0` ~ `3600000` | 否 | 冷却时间（毫秒）。1000 毫秒 = 1 秒 |
| `yield` | 小数 | `1.0` | `0.1` ~ `10.0` | 否 | 爆炸威力。1.0 约等于 TNT 爆炸，值越大爆炸范围越大 |
| `speed` | 小数 | `1.0` | `0.1` ~ `5.0` | 否 | 火球飞行的速度倍率 |
| `charges` | 整数 | `-1` | `-1` ~ `10000` | 否 | 物品可使用的总次数。`-1` 为无限使用 |

### 工作流程

1. **瞄准**：玩家手持火焰魔杖，准星对准目标方向
2. **发射**：右键发射火球弹射物
3. **飞行**：火球以 `speed` 倍率的速度沿瞄准方向飞行
4. **爆炸**：撞击实体或方块时，产生威力为 `yield` 的爆炸
5. **点燃**：爆炸范围内的方块和实体被点燃
6. **冷却**：触发后进入冷却时间

## 击退连击 (knockback_strike)

### 概述

基于连击的击退机制。在命中一定次数的连续攻击后触发强力击退，非常适合奖励持续战斗的武器。通过 ProtectionLib 尊重保护插件，在 PvP 被禁用的受保护区域不会触发。

### 特性

- **命中追踪**：计数连续命中次数，达到阈值时触发击退
- **可自定义击退**：配置水平和垂直击退力度
- **粒子效果**：击退触发时显示粒子
- **声音效果**：击退激活时播放声音
- **自动重置**：命中计数器在可配置的超时后重置
- **线程安全**：兼容 Folia 多线程服务器

### 完整 YAML 配置

```yaml
# ============================================================
# 物品配置示例：击退连击
# ============================================================
legendary_hammer:
  material: DIAMOND_PICKAXE                               # 【必填】物品的基础材质
  displayname: "<gradient:#F06966:#FAD6A6>传奇战锤"        # 【必填】物品的显示名称
  lore:                                                    # 【可选】物品的描述文字
    - "<#ff455b>» <#D5D6D8>用毁灭性的一击打击你的敌人"
    - "<#ff455b>» <#D5D6D8>在第15次命中时，玩家被向前击飞"
  Mechanics:
    knockback_strike:
      # ── 连击参数 ──────────────────────────────
      required_hits: 15                                    # 【可选】触发击退所需的连续命中次数（默认：3）
                                                           #   有效范围：1 ~ 20
      reset_time: 80                                       # 【可选】未命中后命中计数器重置前的刻数（默认：60）
                                                           #   20 刻 = 1 秒，80 刻 = 4 秒
                                                           #   有效范围：20 ~ 200

      # ── 击退力度 ──────────────────────────────
      knockback_horizontal: 2.0                            # 【可选】水平击退力度，向后推（默认：2.0）
                                                           #   有效范围：0.0 ~ 10.0
      knockback_vertical: 1.2                              # 【可选】垂直击退力度，向上击飞（默认：0.5）
                                                           #   有效范围：0.0 ~ 5.0

      # ── 声音效果 ──────────────────────────────
      play_sound: true                                     # 【可选】击退触发时是否播放声音（默认：true）
      sound_type: ENTITY_ENDER_DRAGON_HURT                # 【可选】触发时播放的声音类型
                                                           #   默认：ENTITY_PLAYER_ATTACK_KNOCKBACK
      sound_volume: 1.5                                    # 【可选】声音音量（默认：1.0）
                                                           #   有效范围：0.0 ~ 2.0
      sound_pitch: 0.8                                     # 【可选】声音音调（默认：1.0）
                                                           #   有效范围：0.5 ~ 2.0（越低越深沉）

      # ── 粒子效果 ──────────────────────────────
      particle:                                            # 【可选】粒子效果配置
        type: DUST                                         # 【可选】粒子类型（默认：CRIT）
                                                           #   常用类型：CRIT, EXPLOSION_NORMAL, FLAME,
                                                           #   SPELL_WITCH, DUST（彩色）, CLOUD,
                                                           #   DRAGON_BREATH, SWEEP_ATTACK
        count: 200                                         # 【可选】生成的粒子数量（默认：20）
                                                           #   有效范围：1 ~ 500
        spread: 0.5                                        # 【可选】粒子扩散半径，以方块计（默认：0.5）
                                                           #   有效范围：0.0 ~ 5.0
```

### 参数详解

| 参数 | 类型 | 默认值 | 有效范围 | 必填 | 说明 |
|------|------|--------|----------|------|------|
| `required_hits` | 整数 | `3` | `1` ~ `20` | 否 | 触发击退所需的连续命中次数 |
| `reset_time` | 整数 | `60` | `20` ~ `200` | 否 | 在未命中后，连击计数器重置为零所需的刻数 |
| `knockback_horizontal` | 小数 | `2.0` | `0.0` ~ `10.0` | 否 | 将目标向后推的水平击退力度 |
| `knockback_vertical` | 小数 | `0.5` | `0.0` ~ `5.0` | 否 | 将目标向上击飞的垂直击退力度 |
| `play_sound` | 布尔 | `true` | `true` / `false` | 否 | 击退触发时是否播放声音 |
| `sound_type` | 字符串 | `ENTITY_PLAYER_ATTACK_KNOCKBACK` | 有效的 Minecraft 声音 ID | 否 | 击退触发时播放的声音 |
| `sound_volume` | 小数 | `1.0` | `0.0` ~ `2.0` | 否 | 触发声音的音量大小 |
| `sound_pitch` | 小数 | `1.0` | `0.5` ~ `2.0` | 否 | 触发声音的音调高低。小于 1.0 = 更低沉，大于 1.0 = 更高亢 |
| `particle.type` | 字符串 | `CRIT` | 有效的粒子类型 | 否 | 击退触发时生成的粒子类型 |
| `particle.count` | 整数 | `20` | `1` ~ `500` | 否 | 击退触发时生成的粒子数量 |
| `particle.spread` | 小数 | `0.5` | `0.0` ~ `5.0` | 否 | 粒子的扩散半径（以方块计） |

### 支持的粒子类型

常见粒子类型：`CRIT`、`EXPLOSION_NORMAL`、`FLAME`、`SPELL_WITCH`、`DUST`（彩色）、`CLOUD`、`DRAGON_BREATH`、`SWEEP_ATTACK` 等。`DUST` 粒子类型显示为红色粉尘。

### 工作流程

1. **命中追踪**：每次用武器命中实体时，连击计数器递增
2. **超时重置**：如果在 `reset_time` 刻内没有命中下一次，计数器重置为零
3. **击退触发**：当命中次数达到 `required_hits` 时，对目标施加水平和垂直击退
4. **视觉效果**：粒子在目标位置生成，声音播放（如果启用）
5. **计数器重置**：触发后，计数器重置，循环重新开始

> **提示：** 连击计数器会在以下情况重置：(1) 超过 `reset_time` 未命中，(2) 触发击退后，(3) 玩家切换手中物品。

## 常见问题

### 如何设置物品为一次性使用？

将 `charges` 参数设置为 `1`。使用 1 次后物品消失。

### 如何设置无限使用？

将 `charges` 设置为 `-1`，或不设置此参数（默认值为 `-1`）。

### 多个战斗机制可以组合吗？

是的，你可以在同一物品上组合多种战斗机制。例如：

```yaml
Mechanics:
  lifeleech:
    amount: 1
  bleeding:
    chance: 0.3
    duration: 60
    damage_per_interval: 0.5
    interval: 20
```

这样武器既能吸血又能造成流血效果。

### 如何让火球不破坏方块？

将 `yield` 设置为非常小的值（如 `0.1`），或使用 `charged: false` 的凋零骷髅头代替。
