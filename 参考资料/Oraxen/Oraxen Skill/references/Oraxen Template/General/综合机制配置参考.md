## 文件概述

### 基本信息

| 属性 | 说明 |
|------|------|
| **文件位置** | `plugins/Oraxen/mechanics.yml` |
| **文件格式** | YAML |
| **重载命令** | `/oraxen reload all` |
| **机制总数** | 44 种 |
| **分类数量** | 5 大类 |

### 基本格式

```yaml
# 每个机制的基本格式
<mechanic_name>:
  enabled: true/false                                      # 启用或禁用此机制
  # 该机制特有的其他配置选项
```

### 机制分类总览

| 类别 | 数量 | 用途 |
|------|------|------|
| **杂项（Miscellaneous）** | 9 | 核心物品行为（命令、消耗品、灵魂绑定等） |
| **游戏玩法（Gameplay）** | 10 | 方块、家具、耐久度、修复系统等 |
| **装饰（Cosmetic）** | 5 | 视觉效果（帽子、皮肤、光环、背包装饰） |
| **战斗（Combat）** | 8 | 武器能力（雷神、火球、生命吸取等） |
| **农耕（Farming）** | 6 | 资源采集（收割、熔炼、范围挖掘等） |

## 完整配置结构

以下为 `mechanics.yml` 的完整参考配置，包含所有 44 种机制及其默认设置。

```yaml
# ============================================================
# mechanics.yml - Oraxen 完整机制配置参考
# 位置: plugins/Oraxen/mechanics.yml
# ============================================================

# ═══════════════════════════════════════════════════════════
# 杂项机制 (9种) - 核心物品行为
# ═══════════════════════════════════════════════════════════

# 1. 命令 - 物品使用时执行自定义命令
commands:
  enabled: true

# 2. 护甲效果 - 穿戴护甲时施加药水效果
armor_effects:
  enabled: true
  delay_in_ticks: 20                                       # 检查护甲效果的间隔（刻）
                                                           # 默认: 20（1秒）。增大可减少性能消耗

# 3. 消耗品 - 使物品可被消耗
consumable:
  enabled: true

# 4. 消耗品药水效果 - 消耗物品时施加药水效果
consumable_potion_effects:
  enabled: true

# 5. 自定义能力 - 事件/条件/动作系统
custom:
  enabled: true

# 6. 物品类型 - 自定义物品类型（与其他插件兼容）
itemtype:
  enabled: true

# 7. 灵魂绑定 - 死亡时保留物品
soulbound:
  enabled: true

# 8. 背包 - 功能性便携存储
backpack:
  enabled: true

# 9. 音乐唱片 - 自定义唱片机音乐
music_disc:
  enabled: true

# 10. 杂项属性 - 不属于其他分类的小型物品属性调整
misc:
  enabled: true

# ═══════════════════════════════════════════════════════════
# 游戏机制 (10种) - 方块、家具、耐久度系统
# ═══════════════════════════════════════════════════════════

# 11. 自定义方块音效 - 控制自定义方块和家具的音效系统
custom_block_sounds:
  noteblock_and_block: true                                # 为 NoteBlock 机制启用音效
  stringblock_and_furniture: true                          # 为 StringBlock 和家具启用音效
  chorusblock: true                                        # 为 ChorusBlock 机制启用音效

# 12. 音符盒 - 使用音符盒作为自定义方块（最快，兼容性最好）
noteblock:
  enabled: true
  tool_types:                                              # 可破坏自定义方块的工具体系
    - WOODEN
    - STONE
    - IRON
    - GOLDEN
    - DIAMOND
    - NETHERITE
  farmblock_check_delay: 1000                              # 农田干燥检查间隔（刻）
                                                           # 默认: 1000。增大可提升性能
  remove_mineable_tag: false                               # 是否移除 mineable/axe 标签
                                                           # true = 防止斧头快速破坏自定义方块
                                                           # false = 保留原版快速挖掘行为

# 13. 绊线钩方块 - 使用绊线作为自定义方块（支持树苗生长）
stringblock:
  enabled: true
  tool_types:
    - WOODEN
    - STONE
    - IRON
    - GOLDEN
    - DIAMOND
    - NETHERITE
  sapling_growth_check_delay: 4000                         # 树苗生长检查间隔（刻）
                                                           # 默认: 4000。增大可提升性能
  disable_vanilla_strings: false                           # 是否禁用原版绊线放置
                                                           # true = 仅允许自定义绊线方块

# 14. 紫颂植株方块 - 使用紫颂植株作为自定义方块（自然外观）
chorusblock:
  enabled: true
  tool_types:
    - WOODEN
    - STONE
    - IRON
    - GOLDEN
    - DIAMOND
    - NETHERITE

# 15. 成型方块 - 使用涂蜡铜块作为自定义楼梯/台阶/门/活板门
shaped_block:
  enabled: true
  tool_types:
    - WOODEN
    - STONE
    - IRON
    - GOLDEN
    - DIAMOND
    - NETHERITE
  convert_vanilla_waxed: true                              # 将原版涂蜡铜块转换为未涂蜡版本
                                                           # 将涂蜡铜材料专门保留给自定义方块
  handle_world_generation: true                            # 处理自然生成结构中的涂蜡铜块
                                                           # 确保自定义方块在生成结构中正常工作

# 16. 旧版方块 - 蘑菇柄方块（已弃用，建议使用 noteblock）
block:
  enabled: false                                           # 默认禁用，新项目请使用 noteblock
  tool_types:
    - WOODEN
    - STONE
    - IRON
    - GOLDEN
    - DIAMOND
    - NETHERITE

# 17. 家具 - 自定义 3D 家具（Display Entity 或 Item Frame）
furniture:
  enabled: true
  default_furniture_type: DISPLAY_ENTITY                   # 默认家具类型
                                                           # 可选: DISPLAY_ENTITY（1.19.4+ 最佳视觉效果）
                                                           #       ITEM_FRAME（旧版，更好兼容性）
                                                           #       GLOW_ITEM_FRAME（发光变体）
  tool_types:
    - WOODEN
    - STONE
    - IRON
    - GOLDEN
    - DIAMOND
    - NETHERITE
  evolution_check_delay: 200                               # 植物生长检查间隔（刻）
                                                           # 用于具有植物机制的自定义家具
  detect_viabackwards: true                                # 通过 ViaBackwards 检测旧客户端
                                                           # true = 在 <1.19.4 客户端上隐藏 Display Entity
                                                           # 防止旧客户端崩溃

# 18. 耐久度 - 自定义物品耐久度系统
durability:
  enabled: true

# 19. 效率 - 工具挖掘速度修改器
efficiency:
  enabled: true

# 20. 修复 - 自定义物品修复系统
repair:
  enabled: true
  oraxen_durability_only: false                            # 是否仅修复 Oraxen 自定义耐久度物品
                                                           # true = 仅修复 Oraxen 物品
                                                           # false = 也可修复原版物品

# 21. 自定义食物 - 自定义饥饿值/饱和度
food:
  enabled: true

# 22. 切换灯光 - 手持/放置时发光
toggle_light:
  enabled: true

# ═══════════════════════════════════════════════════════════
# 装饰机制 (5种) - 视觉效果
# ═══════════════════════════════════════════════════════════

# 23. 光环 - 玩家周围的粒子效果
aura:
  enabled: true

# 24. 装饰背包 - 玩家背上的可视化背包（仅装饰，无存储）
backpack_cosmetic:
  enabled: true                                            # 使用数据包盔甲架实现

# 25. 帽子 - 将物品作为帽子穿戴
hat:
  enabled: true

# 26. 皮肤 - 自定义物品纹理应用
skin:
  enabled: true

# 27. 可换肤 - 纹理可被皮肤物品更改
skinnable:
  enabled: true

# ═══════════════════════════════════════════════════════════
# 战斗机制 (8种) - 武器能力
# ═══════════════════════════════════════════════════════════

# 28. 生命吸取 - 造成伤害时治疗自身
lifeleech:
  enabled: true

# 29. 流血 - 攻击施加持续流血伤害
bleeding:
  enabled: true

# 30. 雷神之锤 - 召唤闪电
thor:
  enabled: true

# 31. 能量冲击波 - 投射锥形能量攻击
energyblast:
  enabled: true

# 32. 火球 - 发射爆炸火球
fireball:
  enabled: true

# 33. 凋零骷髅头 - 发射凋零骷髅头弹射物
witherskull:
  enabled: true

# 34. 击退连击 - 连续命中触发强力击退
knockback_strike:
  enabled: true

# 35. 长矛突刺 - 蓄力冲刺攻击
spear_lunge:
  enabled: true

# ═══════════════════════════════════════════════════════════
# 农耕机制 (6种) - 资源采集
# ═══════════════════════════════════════════════════════════

# 36. 范围挖掘 - 同时挖掘多个方块（连锁挖掘）
bigmining:
  enabled: true
  call_events: true                                        # 是否为每个破坏的方块调用 BlockBreakEvent
                                                           # true = 兼容保护插件，但可能与某些附魔插件冲突
                                                           # false = 仅监听事件，解决附魔插件冲突

# 37. 收割 - 自动收获并重新种植作物
harvesting:
  enabled: true

# 38. 熔炼 - 挖掘时自动熔炼矿石
smelting:
  enabled: true
  blacklist_cooked:                                        # 永不自动熔炼的物品黑名单
    - WET_SPONGE                                           # 默认：湿海绵（熔炼会使其变干海绵）
    # - ICE                                                # 可添加冰块防止熔化为水
    # - IRON_ORE                                           # 可添加铁矿石防止自动熔炼

# 39. 浇水 - 浇灌农田的工具
watering:
  enabled: true

# 40. 瓶装经验 - 在瓶子中存储和使用经验
bottledexp:
  enabled: true
  durability_cost: 10                                      # 每次使用消耗的耐久度
                                                           # 默认: 10。设为 0 不消耗耐久度

# 41. 基岩破坏 - 破坏基岩方块
bedrockbreak:
  enabled: true
  disable_on_first_layer: false                            # 是否禁止破坏 Y=0 层基岩
                                                           # true = 防止玩家掉入虚空
                                                           # false = 可破坏所有层基岩
  durability_cost: 500                                     # 破坏每个基岩方块消耗的耐久度
                                                           # 默认: 500。高消耗防止过度开采
```

## 机制分类详解

### 杂项机制 (9种)

| 序号 | 机制名称 | 配置文件键名 | 用途 |
|------|----------|-------------|------|
| 1 | 命令 | `commands` | 使用物品时执行自定义命令 |
| 2 | 护甲效果 | `armor_effects` | 装备护甲时施加药水效果 |
| 3 | 消耗品 | `consumable` | 使物品右键时可被消耗 |
| 4 | 消耗品药水效果 | `consumable_potion_effects` | 消耗物品时施加药水效果 |
| 5 | 自定义能力 | `custom` | 事件/条件/动作高级系统 |
| 6 | 物品类型 | `itemtype` | 定义物品类型以与其他插件兼容 |
| 7 | 灵魂绑定 | `soulbound` | 玩家死亡时物品不掉落 |
| 8 | 背包 | `backpack` | 便携式功能性存储 |
| 9 | 音乐唱片 | `music_disc` | 自定义唱片机音乐 |
| 10 | 杂项属性 | `misc` | 小型物品行为调整（防火、防仙人掌等） |

#### 护甲效果详细配置

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `enabled` | 布尔 | `true` | 是否启用护甲效果机制 |
| `delay_in_ticks` | 整数 | `20` | 检查并刷新效果的间隔（刻）。20=1秒。增大此值减少服务器性能消耗 |

#### 杂项属性支持的选项

在物品的 `Mechanics.misc` 中配置：

| 选项 | 默认值 | 说明 |
|------|--------|------|
| `breaks_from_cactus` | `true` | 碰到仙人掌是否损坏 |
| `burns_in_fire` | `true` | 在火中是否烧毁 |
| `burns_in_lava` | `true` | 在岩浆中是否烧毁 |
| `disable_vanilla_interactions` | `false` | 是否禁用原版交互 |
| `can_strip_logs` | `false` | 是否可剥树皮 |
| `piglins_ignore_when_equipped` | `false` | 装备后猪灵无视玩家 |
| `compostable` | `false` | 能否放入堆肥桶 |
| `allow_in_vanilla_recipes` | `true` | 能否用于原版合成配方 |

### 游戏机制 (10种)

| 序号 | 机制名称 | 配置文件键名 | 用途 |
|------|----------|-------------|------|
| 11 | 自定义方块音效 | `custom_block_sounds` | 控制自定义方块音效系统 |
| 12 | 音符盒 | `noteblock` | 使用音符盒实现自定义方块（推荐） |
| 13 | 绊线钩方块 | `stringblock` | 使用绊线实现自定义方块（支持树苗） |
| 14 | 紫颂植株方块 | `chorusblock` | 使用紫颂植株实现自定义方块 |
| 15 | 成型方块 | `shaped_block` | 使用涂蜡铜块实现楼梯/台阶/门 |
| 16 | 旧版方块 | `block` | 旧版蘑菇柄方块（已弃用） |
| 17 | 家具 | `furniture` | 自定义 3D 家具 |
| 18 | 耐久度 | `durability` | 自定义物品耐久度 |
| 19 | 效率 | `efficiency` | 工具挖掘速度 |
| 20 | 修复 | `repair` | 物品修复系统 |
| 21 | 自定义食物 | `food` | 自定义食物属性 |
| 22 | 切换灯光 | `toggle_light` | 交互式灯光系统 |

#### 自定义方块音效配置

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `noteblock_and_block` | 布尔 | `true` | 为 NoteBlock 机制方块启用音效 |
| `stringblock_and_furniture` | 布尔 | `true` | 为 StringBlock 和家具启用音效 |
| `chorusblock` | 布尔 | `true` | 为 ChorusBlock 机制方块启用音效 |

> **注意：** 如果两种机制的音效都被禁用，这些类型的音效将被强制关闭。

#### 音符盒配置关键参数

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `remove_mineable_tag` | 布尔 | `false` | 设为 `true` 防止斧头快速破坏自定义方块 |
| `farmblock_check_delay` | 整数 | `1000` | 农田干燥检查间隔（刻） |

#### 绊线钩方块配置关键参数

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `sapling_growth_check_delay` | 整数 | `4000` | 树苗生长检查间隔（刻） |
| `disable_vanilla_strings` | 布尔 | `false` | 设为 `true` 禁止放置原版绊线，专用于自定义方块 |

#### 成型方块配置关键参数

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `convert_vanilla_waxed` | 布尔 | `true` | 将原版涂蜡铜块转换为未涂蜡版，保留给自定义方块 |
| `handle_world_generation` | 布尔 | `true` | 处理自然生成结构中的涂蜡铜块（如试炼密室） |

#### 家具配置关键参数

| 参数 | 类型 | 默认值 | 可选值 | 说明 |
|------|------|--------|--------|------|
| `default_furniture_type` | 字符串 | `DISPLAY_ENTITY` | `DISPLAY_ENTITY`、`ITEM_FRAME`、`GLOW_ITEM_FRAME` | 默认家具渲染类型 |
| `evolution_check_delay` | 整数 | `200` | 任意正整数 | 植物家具生长检查间隔（刻） |
| `detect_viabackwards` | 布尔 | `true` | `true` / `false` | 防止 Display Entity 在旧客户端显示 |

#### 修复配置关键参数

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `oraxen_durability_only` | 布尔 | `false` | 设为 `true` 仅修复带有 Oraxen 自定义耐久度的物品 |

### 装饰机制 (5种)

| 序号 | 机制名称 | 配置文件键名 | 用途 |
|------|----------|-------------|------|
| 23 | 光环 | `aura` | 玩家周围粒子效果 |
| 24 | 装饰背包 | `backpack_cosmetic` | 玩家背上的可视化背包（仅装饰） |
| 25 | 帽子 | `hat` | 将物品装备为帽子 |
| 26 | 皮肤 | `skin` | 动态应用不同纹理 |
| 27 | 可换肤 | `skinnable` | 标记物品纹理可更改 |

> **注意：** `backpack` 和 `backpack_cosmetic` 是不同的机制。`backpack` 提供存储功能，`backpack_cosmetic` 仅为装饰性的可视化背包（基于盔甲架）。两者不能在同一物品上组合使用。

| 30 | 雷神之锤 | `thor` | 召唤闪电 |

| 32 | 火球 | `fireball` | 发射爆炸火球 |
| 33 | 凋零骷髅头 | `witherskull` | 发射凋零骷髅头 |

| 35 | 长矛突刺 | `spear_lunge` | 蓄力冲刺攻击 |

> **注意：** 所有法术类战斗机制（雷神、能量冲击波、凋零骷髅头、火球）支持 `charges` 选项限制使用次数。`-1` 表示无限使用。

### 农耕机制 (6种)

| 37 | 收割 | `harvesting` | 自动收获并补种 |
| 38 | 熔炼 | `smelting` | 挖掘时自动熔炼 |
| 39 | 浇水 | `watering` | 浇灌农田 |
| 40 | 瓶装经验 | `bottledexp` | 经验存储和转化 |
| 41 | 基岩破坏 | `bedrockbreak` | 破坏基岩方块 |

#### 范围挖掘配置关键参数

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `call_events` | 布尔 | `true` | `true`=调用 BlockBreakEvent（兼容保护插件）；`false`=仅监听（解决附魔插件冲突） |

#### 熔炼配置关键参数

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `blacklist_cooked` | 字符串列表 | `[WET_SPONGE]` | 不自动熔炼的物品。将需要排除的物品添加到此列表 |

#### 瓶装经验配置关键参数

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `durability_cost` | 整数 | `10` | 每次使用消耗的耐久度。设为 `0` 不消耗 |

#### 基岩破坏配置关键参数

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `disable_on_first_layer` | 布尔 | `false` | `true`=防止破坏 Y=0 层基岩（防掉虚空） |
| `durability_cost` | 整数 | `500` | 每个基岩方块消耗的耐久度 |

## 方块工具类型配置

以下机制支持 `tool_types` 配置，用于定义哪些工具品质可以破坏自定义方块：

- `noteblock`
- `stringblock`
- `chorusblock`
- `shaped_block`
- `block`（已弃用）
- `furniture`

### 可用工具类型

```yaml
tool_types:
  - WOODEN                                                 # 木制工具
  - STONE                                                  # 石制工具
  - IRON                                                   # 铁制工具
  - GOLDEN                                                 # 金制工具
  - DIAMOND                                                # 钻石工具
  - NETHERITE                                              # 下界合金工具
```

### 配置示例

```yaml
# 仅允许钻石及以上工具破坏
noteblock:
  enabled: true
  tool_types:
    - DIAMOND
    - NETHERITE

# 仅允许铁制工具破坏
stringblock:
  enabled: true
  tool_types:
    - IRON
```

## 机制组合与兼容性

### 可在同一物品上组合的机制

```yaml
# ── 多功能传奇镐 ──────────────────────────────
legendary_pickaxe:
  Mechanics:
    durability:                                            # 自定义耐久度
      value: 5000
    efficiency:                                            # 挖掘速度
      amount: 15
    bigmining:                                             # 范围挖掘
      radius: 2
      depth: 1
    smelting: {}                                           # 自动熔炼
    soulbound:                                             # 灵魂绑定
      lose_chance: 0

# ── 多功能武器 ────────────────────────────────
legendary_sword:
  Mechanics:
    lifeleech:                                             # 生命吸取
      amount: 1
    bleeding:                                              # 流血
      chance: 0.3
      duration: 60
    knockback_strike:                                      # 击退连击
      required_hits: 10
    aura:                                                  # 光环粒子
      type: ring
      particle: FLAME
```

### 不兼容的组合

| 不能组合的机制 | 原因 |
|---------------|------|
| 多种方块机制（noteblock + stringblock + chorusblock） | 一个物品只能是一种方块类型 |
| `backpack` 和 `backpack_cosmetic` | 功能背包和装饰背包互斥 |
| `skin` 和 `skinnable` 在相同物品上以冲突方式使用 | `skin` 是皮肤本身，`skinnable` 是可被换肤的目标 |
| `ratio` 和 `fixed_amount` 在 repair 中同时使用 | 修复比例和固定点数二选一 |

## 故障排除

### 常见问题与解决方案

#### "机制不工作"

**排查步骤：**
1. 检查 `mechanics.yml` 中该机制是否 `enabled: true`
2. 检查物品配置中是否正确定义了 Mechanics 部分
3. 执行 `/oraxen reload all` 重载所有配置
4. 检查服务器控制台是否有错误日志

#### "自定义方块被斧头破坏太快"

**解决方案：**
```yaml
noteblock:
  remove_mineable_tag: true                                # 移除 mineable/axe 标签
```

#### "附魔插件与范围挖掘冲突"

**解决方案：**
```yaml
bigmining:
  call_events: false                                       # 不主动调用 BlockBreakEvent
```

#### "Display Entity 家具导致旧客户端崩溃"

**解决方案：**
```yaml
furniture:
  detect_viabackwards: true                                # 检测并隐藏旧客户端的 Display Entity
```

#### "玩家开采基岩掉入虚空"

**解决方案：**
```yaml
bedrockbreak:
  disable_on_first_layer: true                             # 禁止破坏 Y=0 层基岩
```

#### "原版绊线与自定义方块冲突"

**解决方案：**
```yaml
stringblock:
  disable_vanilla_strings: true                            # 禁止放置原版绊线
```

#### "修复物品影响了原版物品"

**解决方案：**
```yaml
repair:
  oraxen_durability_only: true                             # 仅修复 Oraxen 自定义耐久度物品
```

#### "自动熔炼导致不需要的转化"

**解决方案：**
```yaml
smelting:
  blacklist_cooked:
    - WET_SPONGE
    - ICE                                                   # 添加需要排除的物品
```
