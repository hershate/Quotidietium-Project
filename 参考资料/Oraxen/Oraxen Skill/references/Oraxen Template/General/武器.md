# 武器模板

> 适用于创建带有战斗能力的自定义武器。
> 所有战斗机制（雷神、能量冲击波、凋零骷髅头、火球）都支持 `charges` 选项（-1 = 无限使用）。

---

## 基础武器配置

```yaml
# =============================================================================
# 自定义剑 - 基础武器模板
# =============================================================================
custom_sword:
  displayname: "<gradient:#FF4444:#FF8800>烈焰之刃"
  material: DIAMOND_SWORD          # 推荐材质: DIAMOND_SWORD, NETHERITE_SWORD
                                   #           IRON_SWORD, GOLDEN_SWORD
                                   #           STONE_SWORD, WOODEN_SWORD
  Pack:
    generate_model: true
    parent_model: "item/handheld"  # 武器必须使用 handheld 以正确握持
    textures:
      - custom_sword.png

  # ---------------------------------------------------------------------------
  # 耐久度 - 使用原版耐久系统（Minecraft 1.20.5+ 推荐使用 Components 方式）
  # ---------------------------------------------------------------------------
  Mechanics:
    durability:
      value: 2500                  # 自定义耐久度（钻石剑默认 1561）

  # ---------------------------------------------------------------------------
  # 属性修改器 - 修改攻击伤害、攻击速度等
  # ---------------------------------------------------------------------------
  AttributeModifiers:
    attack_damage:
      attribute: ATTACK_DAMAGE
      amount: 8                    # 基础伤害值
      operation: ADD_NUMBER        # ADD_NUMBER / ADD_SCALAR / MULTIPLY_SCALAR_1
      slot: HAND                   # 作用的槽位
    attack_speed:
      attribute: ATTACK_SPEED
      amount: -1.5
      operation: ADD_NUMBER
      slot: HAND
```

## 战斗机制详解

以下每种战斗机制都是独立的，按需选择并添加到 `Mechanics` 部分。
**注意：不可同时使用多个主动法术机制（它们共享右键触发）。**

---

### 1. 长矛突刺 (Spear Lunge)

> 需要 Minecraft 1.21.4+（用于模型动画）。按住右键蓄力，松开后向前突刺造成范围伤害。

```yaml
# melee_spear:
#   displayname: "<gradient:#FFD700:#FFA500>战斗长矛"
#   material: IRON_SWORD
#   Pack:
#     generate_model: false
#     model: default/spear_inactive     # 待机模型
#   Mechanics:
#     spear_lunge:
#       active_model: default/spear_active       # 满蓄力时的模型
#       intermediate_models:                     # 蓄力动画过渡帧（可选）
#         - default/spear_frame0
#         - default/spear_frame1
#       smooth_frames: 2                         # 使用的过渡帧数量
#       charge_ticks: 20                         # 蓄满力需要的刻数（20=1秒）
#       lunge_velocity: 0.8                      # 突刺时的向前速度
#       max_range: 5.0                           # 命中检测范围（方块）
#       damage: 10.0                             # 满蓄力伤害
#       min_damage: 2.0                          # 最低蓄力伤害
#       knockback: 0.8                           # 击退强度
#       hitbox_radius: 0.5                       # 射线宽度（最大5.0）
#       min_charge_percent: 0.25                 # 触发攻击所需的最小蓄力百分比
#       charge_slowdown: 0.5                     # 蓄力时移动减速（0=不减速, 1=冻结）
#       max_hold_ticks: 60                       # 最大保持蓄力时间（刻）
#       max_targets: 3                           # 每次突刺最大命中敌人数
#       particles:
#         enabled: true
#         charge: CRIT                           # 蓄力时粒子
#         lunge: SWEEP_ATTACK                    # 突刺时粒子
#         hit: DAMAGE_INDICATOR                  # 命中时粒子
#       sounds:
#         enabled: true
#         charge: ITEM_TRIDENT_RIPTIDE_1
#         lunge: ENTITY_PLAYER_ATTACK_SWEEP
#         hit: ENTITY_PLAYER_ATTACK_STRONG
```

### 2. 雷神之锤 (Thor's Hammer)

> 右键投掷闪电，对目标区域造成雷击伤害。

```yaml
# thors_hammer:
#   displayname: "<gradient:#00BFFF:#0044FF>雷神之锤"
#   material: DIAMOND_AXE
#   Pack:
#     generate_model: true
#     parent_model: "item/handheld"
#     textures:
#       - thors_hammer.png
#   Mechanics:
#     thor:
#       lightning_bolts_amount: 5                # 生成闪电数量
#       random_location_variation: 1.5           # 闪电位置随机偏移（方块）
#       delay: 20000                             # 冷却时间（毫秒，20000ms=20秒）
#       charges: -1                              # 使用次数（-1=无限，消耗后物品消失）
```

## 武器材质参考

| 材质 | 默认攻击伤害 | 默认攻击速度 | 默认耐久度 |
|------|-------------|-------------|-----------|
| `WOODEN_SWORD` | 4 | 1.6 | 59 |
| `STONE_SWORD` | 5 | 1.6 | 131 |
| `IRON_SWORD` | 6 | 1.6 | 250 |
| `GOLDEN_SWORD` | 4 | 1.6 | 32 |
| `DIAMOND_SWORD` | 7 | 1.6 | 1561 |
| `NETHERITE_SWORD` | 8 | 1.6 | 2031 |
| `DIAMOND_AXE` | 9 | 1.0 | 1561 |
| `NETHERITE_AXE` | 10 | 1.0 | 2031 |

> 注意：使用 `PAPER` 作为材质可获得最干净的默认属性配置，然后通过 `AttributeModifiers` 完全自定义属性。

## 组合示例：完整武器

```yaml
legendary_blade:
  displayname: "<gradient:#FF4444:#FFD700:#FF4444>传说之刃"
  material: NETHERITE_SWORD
  lore:
    - "<gray>一把蕴含着远古力量的剑"
    - ""
    - "<dark_gray>被动: <red>生命吸取</red></dark_gray>"
    - "<dark_gray>被动: <dark_red>流血</dark_red></dark_gray>"
  Pack:
    generate_model: true
    parent_model: "item/handheld"
    textures:
      - legendary_blade.png
  Mechanics:
    durability:
      value: 3500
    lifeleech:
      amount: 2
    bleeding:
      chance: 0.25
      duration: 60
      damage_per_interval: 0.5
      interval: 20
  AttributeModifiers:
    attack:
      attribute: ATTACK_DAMAGE
      amount: 10
      operation: ADD_NUMBER
      slot: HAND
```
