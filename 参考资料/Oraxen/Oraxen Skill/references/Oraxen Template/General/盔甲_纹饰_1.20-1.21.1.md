## 方法概述

纹饰方式利用了 Minecraft 1.20 引入的**盔甲纹饰系统 (Armor Trim System)**。Oraxen 通过数据包 (Datapack) 生成自定义纹饰图案和材质覆写，使锁链盔甲在外观上表现为完全自定义的纹理。

### 工作原理

1. Oraxen 以 **CHAINMAIL (锁链盔甲)** 为基础材质
2. 为每个盔甲部位生成一个**自定义纹饰图案** (Trim Pattern)
3. 通过数据包的**材质覆写 (Material Override)** 将锁链基础纹理替换为你的自定义纹理
4. 当玩家穿戴时，游戏渲染的纹饰层实际上是完整的自定义盔甲纹理

### 核心限制

| 限制 | 说明 |
|------|------|
| 基础材质固定 | 默认使用 CHAINMAIL, 可通过 settings.yml 更改但仍有局限 |
| 需要服务器重启循环 | 每次添加/移除盔甲套装需重启两次 |
| 版本上限 | 不支持 1.21.2+ (请使用组件方式) |

### 与其他方法的快速对比

| 特性 | 纹饰方式 | 组件方式 (1.21.2+) | 着色器方式 (1.18-1.19.4) |
|------|:--------:|:------------------:|:------------------------:|
| 基础材质限制 | 仅锁链 | **无限制** | 仅皮革 |
| 着色器兼容 | **原生** | **原生** | 需要 CIT |
| 服务器重启循环 | **需要** | 不需要 | 不需要 |
| 纹饰图案共存 | 冲突 (占用纹饰槽) | 允许 | 不适用 |

## 重要: 服务器重启流程

> **必须严格遵循以下步骤** — 纹饰方式依赖数据包, 跳过第二步会导致盔甲无法显示!

### 首次配置或添加新盔甲套装时

```
步骤 1: 在 items/*.yml 中配置好盔甲物品
        ↓
步骤 2: 启动服务器
        → Oraxen 读取配置, 生成数据包 (包含纹饰图案 + 材质覆写)
        ↓
步骤 3: 停止服务器
        → 数据包已生成到世界文件夹中
        ↓
步骤 4: 再次启动服务器
        → 服务器加载刚才生成的数据包, 盔甲生效
        ↓
步骤 5: 盔甲纹理正确显示 (如果仍不显示, 检查纹理文件)
```

### 移除盔甲套装时

同样需要两次重启:
1. 从配置中删除盔甲条目 → 启动服务器 → 停止
2. 再次启动服务器 (加载更新后的数据包)

### 为什么需要两次重启?

数据包是在服务器启动时从配置生成的。第一次启动生成数据包时, 该数据包尚未被加载。只有第二次启动才能加载上一次生成的数据包。

## 命名规范

### 物品 ID 命名

> **强制要求** — 与组件方式完全相同的规范。

```
<盔甲名>_<部位类型>

部位类型:
  _helmet      → 头盔
  _chestplate  → 胸甲
  _leggings    → 护腿
  _boots       → 靴子
```

### 纹理文件命名

> **强制要求** — 与组件方式完全相同的规范。

```
<盔甲名>_armor_layer_1.png   → 第一层纹理
<盔甲名>_armor_layer_2.png   → 第二层纹理
```

**注意**: 即使物品图标纹理和盔甲层纹理共享 `armorname` 作为前缀, 它们是独立的文件集:
- 物品图标: `<盔甲名>_<部位>.png` (如 `ruby_helmet.png`)
- 盔甲层: `<盔甲名>_armor_layer_1.png` (如 `ruby_armor_layer_1.png`)

## 纹理格式

### 分辨率

纹饰方式的盔甲分辨率同样在 `settings.yml` 中配置:

```yaml
# settings.yml
CustomArmor:
  armor_type: TRIMS             # [必须] 设为 TRIMS
  armor_resolution: 16          # [可选] 默认 16, 即 64x32 像素
```

| armor_resolution | 纹理尺寸 |
|:-----------------:|:---------|
| 16 (默认)         | 64 x 32  |
| 32                | 128 x 64 |
| 64                | 256 x 128 |

### 物品图标纹理

**不同于组件方式** — 在纹饰方式中, 物品图标纹理需要在 `Pack.textures` 中**指定两次**:

```yaml
Pack:
  generate_model: true
  parent_model: "item/generated"
  textures:
    - default/armors/ruby_helmet     # 第一次指定
    - default/armors/ruby_helmet     # 第二次指定 (必须重复)
```

这是纹饰方式的特殊性 — 重复指定确保纹理在纹饰覆写系统中被正确引用。

## 完整配置模板 (4件套)

以下是一套完整的 4 件盔甲配置, 适用于纹饰方式 (Minecraft 1.20-1.21.1)。

```yaml
# =============================================================================
# 红宝石盔甲套装 — 纹饰方式 (Minecraft 1.20-1.21.1)
# 使用方法: 全局替换 "ruby" 为你的盔甲名称, "Ruby" 为显示名称
# 重要: 配置后需要:
#   1. 启动服务器 → 停止服务器 → 再次启动服务器
#   2. 确保 settings.yml 中 CustomArmor.armor_type: TRIMS
# =============================================================================

# ============================
# 1. 头盔
# ============================
ruby_helmet:
  # ---- [必须] 显示名称 ----
  displayname: "<gradient:#FA7CBB:#F14658>Ruby Helmet"

  # ---- [必须] 基础材质 ----
  # 纹饰方式限定为 CHAINMAIL 系列材质。
  # 如需更改, 在 settings.yml 中配置 CustomArmor.base_material。
  material: CHAINMAIL_HELMET

  # ---- [必须] 资源包配置 ----
  # 注意: 纹理路径需要指定两次
  Pack:
    generate_model: true
    parent_model: "item/generated"
    textures:
      - default/armors/ruby_helmet      # 物品图标纹理
      - default/armors/ruby_helmet      # [必须重复] 纹饰覆写所需

  # ---- [可选] 纹饰图案 ----
  # 如果省略, Oraxen 会根据物品 ID 自动分配。
  # 自动分配的值: oraxen:<盔甲名>
  trim_pattern: oraxen:ruby

# ============================
# 2. 胸甲
# ============================
ruby_chestplate:
  displayname: "<gradient:#FA7CBB:#F14658>Ruby Chestplate"
  material: CHAINMAIL_CHESTPLATE
  Pack:
    generate_model: true
    parent_model: "item/generated"
    textures:
      - default/armors/ruby_chestplate
      - default/armors/ruby_chestplate
  trim_pattern: oraxen:ruby

# ============================
# 3. 护腿
# ============================
ruby_leggings:
  displayname: "<gradient:#FA7CBB:#F14658>Ruby Leggings"
  material: CHAINMAIL_LEGGINGS
  Pack:
    generate_model: true
    parent_model: "item/generated"
    textures:
      - default/armors/ruby_leggings
      - default/armors/ruby_leggings
  trim_pattern: oraxen:ruby

# ============================
# 4. 靴子
# ============================
ruby_boots:
  displayname: "<gradient:#FA7CBB:#F14658>Ruby Boots"
  material: CHAINMAIL_BOOTS
  Pack:
    generate_model: true
    parent_model: "item/generated"
    textures:
      - default/armors/ruby_boots
      - default/armors/ruby_boots
  trim_pattern: oraxen:ruby
```

### 使用此模板的步骤

1. **全局替换盔甲名称**: 将所有 `ruby` 替换为你的盔甲名, `Ruby` 替换为显示名
2. **确认 settings.yml**:
   ```yaml
   CustomArmor:
     armor_type: TRIMS
   ```
3. **准备纹理文件** (共 6 个):
   - `ruby_armor_layer_1.png` — 64x32 (resolution=16 时)
   - `ruby_armor_layer_2.png` — 64x32
   - `ruby_helmet.png` — 物品栏图标
   - `ruby_chestplate.png` — 物品栏图标
   - `ruby_leggings.png` — 物品栏图标
   - `ruby_boots.png` — 物品栏图标
4. **放置纹理**: 放入 `~/textures/default/armors/`
5. **执行重启流程**: 启动 → 停止 → 再次启动
6. **获取物品**: `/o give <玩家> ruby_helmet`

## 纹饰图案 (Trim Pattern) 详解

### 自动分配

如果你**不手动指定** `trim_pattern`, Oraxen 会根据物品 ID 自动推断并生成:

```
物品 ID: ruby_helmet
→ 自动 trim_pattern: oraxen:ruby

物品 ID: dragon_chestplate
→ 自动 trim_pattern: oraxen:dragon
```

**推断规则**: Oraxen 取物品 ID 的前缀 (第一个 `_` 之前的部分), 加上 `oraxen:` 命名空间。

### 手动指定

如果你需要自定义纹饰图案名称:

```yaml
ruby_helmet:
  trim_pattern: oraxen:ruby          # 推荐: 使用 oraxen 命名空间

dragon_helmet:
  trim_pattern: mypack:dragon_trim   # 也可以使用自定义命名空间
```

### 纹饰图案的副作用

**重要**: 使用纹饰方式制作自定义盔甲会消耗物品的纹饰槽位。这意味着:

- 玩家**不能在**锻造台给自定义纹饰盔甲再添加原版纹饰图案
- 纹饰槽位已被自定义纹理占用, 无法叠加
- 如果你需要同时保留原版纹饰功能, 请升级到 1.21.2+ 使用组件方式

## 材质覆写 (Material Overrides)

### 基础材质配置

在 `settings.yml` 中可以更改纹饰方式使用的基础盔甲材质:

```yaml
# settings.yml (默认值)
CustomArmor:
  armor_type: TRIMS
  base_material: CHAINMAIL            # 可选值:
                                       #   CHAINMAIL  (锁链, 默认)
                                       #   IRON       (铁)
                                       #   GOLD       (金)
                                       #   DIAMOND    (钻石)
                                       #   NETHERITE  (下界合金)
```

### 材质覆写对纹理的影响

Oraxen 生成的数据包会将选定基础材质的**所有纹理** (包括物品图标和盔甲层) 替换为你的自定义纹理。这是通过 Minecraft 原版的 `trim_material` 覆写机制实现的。

| 基础材质 | 物品栏外观 | 穿戴外观 | 防御值 |
|----------|:----------:|:--------:|:------:|
| CHAINMAIL (默认) | 自定义纹理 | 自定义纹理 | 锁链 (低) |
| IRON | 自定义纹理 | 自定义纹理 | 铁 (中) |
| DIAMOND | 自定义纹理 | 自定义纹理 | 钻石 (高) |

### 注意事项

- 更改 `base_material` 后, **所有**使用纹饰方式的自定义盔甲都会切换到新材质
- 不能在同一套盔甲的不同部位使用不同基础材质
- 如果你需要混合不同属性的盔甲, 请使用组件方式 (1.21.2+)

## 与其他方法的对比

### 何时选择纹饰方式

| 场景 | 选择 |
|------|------|
| 服务器版本 1.21.2+ | **使用组件方式**, 不要用纹饰 |
| 服务器版本 1.20-1.21.1 | **使用纹饰方式** |
| 需要保留原版纹饰功能 | **升级到 1.21.2+** 并使用组件方式 |
| 需要多种不同属性的盔甲 (锁链/铁/钻石并存) | 使用组件方式 |


### 纹饰方式 vs 着色器方式 (同为旧版环境)

| 对比点 | 纹饰 (1.20-1.21.1) | 着色器 (1.18-1.19.4) |
|--------|:------------------:|:--------------------:|
| Optifine/Iris 兼容 | **原生** | 需要 CIT |
| 基础材质 | 锁链 (可改) | 皮革 (不可改) |
| 防御值 | 可随材质变化 | 需要手动添加 |
| 可染色 | 否 | 是 |
| 纹理位深要求 | 无 | **32位强制** |
| 重启要求 | 2次重启 | 1次 `/o reload` |

## 常见问题

### Q: 我为啥看不到自定义盔甲纹理?

按顺序检查:
1. **settings.yml**: `CustomArmor.armor_type` 是否为 `TRIMS`
2. **纹理文件**: 名称和路径是否正确
3. **重启流程**: 是否完成了「启动 → 停止 → 再启动」两次重启
4. **数据包**: 检查世界文件夹 `datapacks/` 中是否生成了 Oraxen 的数据包

### Q: 可以在游戏中给自定义盔甲添加原版纹饰吗?

**不可以。** 纹饰方式通过覆写物品的纹饰槽位来显示自定义纹理。如果用原版纹饰覆盖, 自定义纹理将消失。

### Q: 我能混合使用纹饰方式和组件方式吗?

**可以, 但没必要。** 如果你在 1.21.2+ 服务器上, 应该全部使用组件方式。如果服务器版本不支持组件, 则全部使用纹饰方式。混合使用不会报错, 但组件方式在各方面都优于纹饰方式。

### Q: 每次添加新盔甲都要重启两次服务器吗?

**是的。** 这是纹饰方式的固有限制, 因为依赖数据包。如果你频繁添加盔甲套装且希望避免多次重启, 请考虑升级到 1.21.2+ 使用组件方式 (支持 `/o reload` 热重载)。

### Q: base_material 更改后为什么旧盔甲材质也变了?

`base_material` 是全局设置, 会影响所有使用纹饰方式的自定义盔甲。这是设计如此 — 纹饰方式使用一个统一的基础材质来覆写。

## 配置文件清单

创建一套完整的纹饰盔甲套装需要准备:

```
资源包纹理:
├── textures/default/armors/
│   ├── <盔甲名>_armor_layer_1.png     ← [必须] 盔甲层 1 (64x32@16px)
│   ├── <盔甲名>_armor_layer_2.png     ← [必须] 盔甲层 2 (64x32@16px)
│   ├── <盔甲名>_helmet.png            ← [必须] 头盔物品图标
│   ├── <盔甲名>_chestplate.png        ← [必须] 胸甲物品图标
│   ├── <盔甲名>_leggings.png          ← [必须] 护腿物品图标
│   └── <盔甲名>_boots.png             ← [必须] 靴子物品图标

Oraxen 配置:
├── settings.yml:
│   ├── CustomArmor.armor_type: TRIMS
│   └── CustomArmor.base_material: CHAINMAIL  ← [可选] 默认锁链
│
├── items/<你的配置>.yml:
│   ├── <盔甲名>_helmet       ← trim_pattern 可省略 (自动推断)
│   ├── <盔甲名>_chestplate
│   ├── <盔甲名>_leggings
│   └── <盔甲名>_boots
│
生成物 (自动):
└── <世界文件夹>/datapacks/oraxen_armor_trim/
    ├── pack.mcmeta
    └── data/oraxen/
        ├── trim_pattern/     ← 纹饰图案定义
        └── trim_material/    ← 材质覆写定义
```
