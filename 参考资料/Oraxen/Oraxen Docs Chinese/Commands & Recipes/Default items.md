# 默认物品

![](/assets/image.png)

![](/assets/obsidian_armor.jpg)

**黑曜石盔甲**不如钻石盔甲好，但拥有惊人的耐久度。

## 锤子

锤子是非常特殊的镐子，能够同时挖掘多个方块。传说它们是由 Notch 发明的，但他没有时间添加它们，所以只在铁砧修复界面中画了出来。

### **绿宝石锤**

![](/assets/emerald_hammer.jpg)

您可以找到的最基础的锤子是**绿宝石锤**，它可以挖掘 3x3 方块的正方形区域，这对于起步来说很不错，但绝对不是您能获得的最好的。

### 紫水晶锤

![](/assets/amethyst_hammer.jpg)

与绿宝石锤不同，**紫水晶锤**同样挖掘 3x3 方块的正方形区域，但深度为两个方块。

### 玛瑙锤

![](/assets/onyx_hammer.jpg)

将紫水晶锤升级改进后，您就得到了**玛瑙锤**。它比紫水晶锤能破坏更多的方块，因为它拥有很高的耐久度。

### Orax 锤

![](/assets/orax_hammer.jpg)

与它的兄弟们相比，**Orax 锤**是神一般的锤子：它可以挖掘一个非常大的正方形区域，深度为两个方块。

### 火焰锤

![](/assets/fire_hammer.jpg)

**火焰锤**的挖掘方式与基础锤子相同（3x3 方块，深度 1），但它能立即熔炼矿石！例如，如果您挖掘铁矿石，您将立即获得铁锭……而且它与时运附魔叠加！
