# 所有机制

Oraxen 提供了多种多样机制，能够为你的物品赋予特殊能力。这些机制按类别组织：

## [杂项](abilities/misc)

用于各种物品行为的通用机制：
- **自定义食物** - 自定义饥饿值/饱和度数值和效果
- **背包** - 将物品变为便携式存储
- **音乐唱片** - 带有自定义声音的自定义音乐唱片
- **耐久度** - 自定义耐久度数值
- **效率** - 挖掘速度提升
- **消耗品** - 使物品可右键消耗
- **修复** - 可修复其他物品的物品
- **命令** - 使用物品时执行命令
- **护甲效果** - 装备护甲时获得药水效果
- **光环** - 手持物品时的粒子效果
- **帽子** - 使任何物品可作为帽子穿戴
- **灵魂绑定** - 死亡时保留物品
- **可换肤/皮肤** - 动态更改物品纹理
- **切换灯光** - 右键时切换灯光。

## [战斗](abilities/combat)

用于战斗的武器和法术机制：
- **雷神** - 投掷闪电
- **生命吸取** - 从敌人那里窃取生命值
- **流血** - 随时间造成流血伤害
- **能量冲击波** - 粒子锥形攻击
- **凋零骷髅头** - 发射凋零骷髅头
- **火球** - 发射爆炸火球

## [农业](abilities/farming)

用于农业和采矿的工具：
- **收割** - 自动收割和重新种植作物
- **范围挖掘** - 一次性挖掘多个方块（3x3、5x5 等）
- **熔炼** - 挖掘时自动熔炼矿石
- **瓶装经验** - 将经验转化为经验瓶
- **基岩破坏** - 破坏基岩方块
- **浇水** - 用于农场的洒水壶系统

## 特殊机制

一些机制有专门的页面：
- [自定义机制](abilities/custom-ability) - 创建自定义基于事件的机制
- [点击动作](abilities/clickaction) - 点击方块/家具时运行动作
- [家具机制](/creating-content/furniture) - 自定义家具和装饰
- [音符盒机制](/creating-content/blocks/noteblock) - 使用音符盒的自定义方块
- [绊线钩方块机制](/creating-content/blocks/stringblock) - 使用绊线的自定义方块
