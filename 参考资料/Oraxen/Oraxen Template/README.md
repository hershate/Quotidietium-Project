# Oraxen 配置模板

> 本目录包含 Oraxen 插件所有可自定义内容类型的配置模板，基于 **Oraxen 1.216.0** 版本文档整理。
>
> 每个模板文件均包含完整的中文注释 YAML 配置、必填/可选字段标注、以及实战示例。

该模板由正版ID为 **ZTF3** 的玩家整理与编写。

## 使用说明

1. 找到对应类型的模板文件
2. 复制 YAML 配置到 `plugins/Oraxen/items/` 目录下的 `.yml` 文件中
3. 修改纹理路径、物品 ID、参数值等
4. 将纹理文件放入 `plugins/Oraxen/pack/textures/` 对应路径
5. 执行 `/oraxen reload all` 重载插件
6. 执行 `/oraxen pack send @a` 推送资源包

> **注意**：所有模板中的 `my_` 前缀物品 ID 需要替换为你自己的唯一 ID。
> `custom_variation` 值在同一方块类型中不可重复。
