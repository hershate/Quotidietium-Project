# 工具模板

> 适用于创建带有采矿、挖掘和农业能力的自定义工具。

---

## 基础工具配置

```yaml
# =============================================================================
# 自定义镐 - 基础工具模板
# =============================================================================
custom_pickaxe:
  displayname: "<gradient:#4488FF:#88CCFF>蓝晶镐"
  material: DIAMOND_PICKAXE         # 推荐材质:
                                    #   镐: DIAMOND_PICKAXE, NETHERITE_PICKAXE
                                    #   斧: DIAMOND_AXE, NETHERITE_AXE
                                    #   锹: DIAMOND_SHOVEL, NETHERITE_SHOVEL
                                    #   锄: DIAMOND_HOE, NETHERITE_HOE
  Pack:
    generate_model: true
    parent_model: "item/handheld"   # 工具必须使用 handheld
    textures:
      - custom_pickaxe.png

  Mechanics:
    durability:
      value: 3000                   # 自定义耐久度

  # 工具组件（1.20.5+）- 控制挖掘行为
  Components:
    durability:
      value: 3000
      damage_block_break: true      # 破坏方块时消耗耐久度
    tool:
      damage_per_block: 1           # 每个方块消耗的耐久度
      default_mining_speed: 1.5     # 基础挖掘速度倍率
      rules:
        - speed: 8.0               # 对符合条件方块的挖掘速度
          correct_for_drops: true   # 是否掉落物品（false=即使破坏也不掉落）
          tags:
            - minecraft:mineable/pickaxe
            - minecraft:needs_diamond_tool   # 可挖掘钻石级方块
```

## 工具机制详解

---

### 1. 基岩破坏 (Bedrock Break)

> 需要 ProtocolLib。允许工具破坏基岩（默认为第0层以上）。

```yaml
# bedrock_breaker:
#   displayname: "<#111111>基岩破坏者"
#   material: NETHERITE_PICKAXE
#   Pack:
#     generate_model: true
#     parent_model: "item/handheld"
#     textures:
#       - bedrock_breaker.png
#   Mechanics:
#     durability:
#       value: 50000                          # 建议高耐久度
#     bedrockbreak:
#       hardness: 10                          # 破坏动画切换间隔（刻）
#       probability: 0.5                      # 掉落概率（0.5=50%, 1.0=100%）
```

**全局配置**（`mechanics.yml`）:
```yaml
bedrockbreak:
  enabled: true
  disable_on_first_layer: false               # true=禁止破坏第0层
  durability_cost: 500                        # 每次破坏基岩消耗的耐久度
```

---

### 2. 范围挖掘 / 锤子 (Vein Miner / Big Mining)

> 一次破坏多个方块（3x3、5x5 等区域）。

```yaml
# hammer:
#   displayname: "<gradient:#888888:#CCCCCC>铁锤"
#   material: DIAMOND_PICKAXE

#     parent_model: "item/handheld"

#       depth: 1                               # 深度（方块），1=从点击面开始一层
```

---

### 3. 熔炼 (Smelting)

> 挖掘矿石时自动熔炼为成品（铁矿石 -> 铁锭，金矿石 -> 金锭）。
> 支持时运（Fortune）和精准采集（Silk Touch）。

```yaml
# smelting_pickaxe:
#   displayname: "<gradient:#FF6600:#FFCC00>熔炼镐"
#   material: IRON_PICKAXE
#   Pack:
#     generate_model: true
#     parent_model: "item/handheld"
#     textures:
#       - smelting_pickaxe.png
#   Mechanics:
#     durability:
#       value: 1500
#     smelting:
#       enabled: true
#       play_sound: true                       # 熔炼时播放火焰音效
```

---

### 4. 效率 (Efficiency)

> 手持物品时获得急迫效果（挖掘速度提升）。负值则为挖掘疲劳。

```yaml
# efficiency_tool:
#   displayname: "<#00FF00>高效工具"
#   material: IRON_PICKAXE
#   Pack:
#     generate_model: true
#     parent_model: "item/handheld"
#     textures:
#       - efficiency_tool.png
#   Mechanics:
#     efficiency:
#       amount: 2                              # 急迫等级（1-5），负值=挖掘疲劳
```

---

### 5. 收割 (Harvesting)

> 右键点击农田时自动收割并重新种植作物。

```yaml
# harvester_hoe:
#   displayname: "<#22DD44>收割锄"
#   material: DIAMOND_HOE
#   Pack:
#     generate_model: true
#     parent_model: "item/handheld"
#     textures:
#       - harvester_hoe.png

#       cooldown: 10000                        # 冷却时间（毫秒，10000=10秒）

```

---

### 6. 瓶装经验 (Bottled Exp)

> 右键将玩家的经验转化为经验瓶。

```yaml
# exp_bottler:
#   displayname: "<#55FF55>经验瓶装器"
#   material: GLASS_BOTTLE
#   Pack:
#     generate_model: true
#     parent_model: "item/generated"
#     textures:
#       - exp_bottler.png
#   Mechanics:
#     bottledexp:
#       ratio: 0.95                            # 转换率（0.95=损失5%经验）
```

**全局配置**（`mechanics.yml`）:
```yaml
bottledexp:
  enabled: true
  durability_cost: 1                           # 每次转换消耗的耐久度
```

## 工具材质参考

| 材质 | 默认挖掘速度 | 默认耐久度 | 可挖掘等级 |
|------|-------------|-----------|-----------|
| `WOODEN_PICKAXE` | 2 | 59 | 石头、煤矿 |
| `STONE_PICKAXE` | 4 | 131 | 铁矿石、青金石 |
| `IRON_PICKAXE` | 6 | 250 | 钻石、红石、金 |
| `GOLDEN_PICKAXE` | 12 | 32 | 同木镐（速度快但耐久极低） |
| `DIAMOND_PICKAXE` | 8 | 1561 | 黑曜石、远古残骸 |
| `NETHERITE_PICKAXE` | 9 | 2031 | 所有方块 |

**斧**: `WOODEN_AXE`, `STONE_AXE`, `IRON_AXE`, `GOLDEN_AXE`, `DIAMOND_AXE`, `NETHERITE_AXE`
**锹**: `WOODEN_SHOVEL`, `STONE_SHOVEL`, `IRON_SHOVEL`, `GOLDEN_SHOVEL`, `DIAMOND_SHOVEL`, `NETHERITE_SHOVEL`
**锄**: `WOODEN_HOE`, `STONE_HOE`, `IRON_HOE`, `GOLDEN_HOE`, `DIAMOND_HOE`, `NETHERITE_HOE`

## 组合示例：万能工具

```yaml
omnitool:
  displayname: "<gradient:#FF4444:#FFD700:#4488FF>万能工具"
  material: NETHERITE_PICKAXE
  lore:
    - "<gray>集多种功能于一身的神器"
    - ""
    - "<green>功能: 熔炼 | 范围挖掘 | 高耐久"
  Pack:
    generate_model: true
    parent_model: "item/handheld"
    textures:
      - omnitool.png
  Mechanics:
    durability:
      value: 8000
    smelting:
      enabled: true
      play_sound: true
    bigmining:
      radius: 1
      depth: 1
    efficiency:
      amount: 1
```
