# 基础物品模板

> 适用于创建带有自定义纹理和基础属性的简单物品。
> 这是所有 Oraxen 物品配置的起点。

---

## 完整模板

```yaml
# =============================================================================
# 物品 ID（必填）- 唯一标识符，用于命令 /o give <id> 和合成配方
# 只能使用小写字母、数字和下划线
# =============================================================================
my_custom_item:

  # ===========================================================================
  # 显示名称（必填）- 使用 MiniMessage 格式设置颜色和样式
  # 支持渐变: <gradient:#颜色1:#颜色2>文本</gradient>
  # 支持纯色: <#RRGGBB>文本
  # 支持原版颜色: <red>, <blue>, <gold> 等
  # ===========================================================================
  displayname: "<gradient:#4B36B1:#6699FF>我的自定义物品"

  # ===========================================================================
  # 基础材质（必填）- 选择 Minecraft 原版物品作为基础
  # 决定了物品的基础属性（如堆叠数量、默认耐久度）
  # 常用材质:
  #   - DIAMOND, EMERALD, IRON_INGOT 等（材料类）
  #   - DIAMOND_SWORD, NETHERITE_SWORD 等（武器类，注意会继承攻击属性）
  #   - PAPER（最灵活，无默认属性，推荐用于护甲和特殊物品）
  #   - DIAMOND_PICKAXE, NETHERITE_AXE 等（工具类）
  #   - COOKED_BEEF, APPLE 等（食物类）
  #   - LEATHER_HORSE_ARMOR（可染色物品）
  # 完整列表: https://hub.spigotmc.org/javadocs/spigot/org/bukkit/Material.html
  # ===========================================================================
  material: DIAMOND

  # ===========================================================================
  # 外观设置（Pack 部分）- 控制纹理和模型
  # ===========================================================================
  Pack:

    # -------------------------------------------------------------------------
    # 自动生成模型（必填）- true: 由 Oraxen 自动生成模型 JSON
    #   false: 使用手动创建的 JSON 模型文件
    # -------------------------------------------------------------------------
    generate_model: true

    # -------------------------------------------------------------------------
    # 父模型（generate_model: true 时必填）- 继承原版模型的渲染属性
    # 常用选项:
    #   "item/generated"    - 普通物品（材料、食物、宝石等）
    #   "item/handheld"     - 手持工具/武器（正确的握持角度）
    #   "item/handheld_rod" - 杆状物品（钓鱼竿等）
    #   "block/cube"        - 方块物品
    #   "builtin/entity"    - 实体物品（刷怪蛋等）
    # -------------------------------------------------------------------------
    parent_model: "item/generated"

    # -------------------------------------------------------------------------
    # 纹理列表（必填）- 纹理文件名，放在 pack/textures 文件夹中
    # 纹理文件路径: plugins/Oraxen/pack/textures/my_custom_item.png
    # .png 扩展名可省略
    # 对于方块父模型，可以使用键值对指定各面纹理
    # -------------------------------------------------------------------------
    textures:
      - my_custom_item.png

    # --- 以下是可选的外观配置 ---

    # 手动指定自定义模型数据值（可选）
    # 用于与其他插件兼容
    # custom_model_data: 452

    # 排除特定外观系统（可选，用于控制 1.21.4+ 的行为）
    # exclude_from_predicates: false     # 不生成旧版谓词文件
    # exclude_from_item_model: false     # 不生成 item_model 组件

  # ===========================================================================
  # 物品描述 Lore（可选）- 使用 MiniMessage 格式
  # 每行一个字符串，将在物品提示框中显示
  # ===========================================================================
  # lore:
  #   - "<gray>一件神秘的自定义物品"
  #   - "<#AAAAAA>右键点击以使用"
  #   - "<dark_gray>稀有度: <gold>传说</gold></dark_gray>"

  # ===========================================================================
  # 物品标志（可选）- 隐藏原版显示信息
  # 可用标志: HIDE_ATTRIBUTES, HIDE_ENCHANTS, HIDE_DESTROYS, HIDE_UNBREAKABLE
  #          HIDE_PLACED_ON, HIDE_ADDITIONAL_TOOLTIP, HIDE_ARMOR_TRIM
  # ===========================================================================
  # ItemFlags:
  #   - HIDE_ATTRIBUTES
  #   - HIDE_ENCHANTS

  # ===========================================================================
  # 机制（可选）- 物品的特殊能力
  # 详细文档见 物品能力总览.md
  # ===========================================================================
  # Mechanics:
  #   durability:
  #     value: 500
```

## 仅使用 JSON 模型（不使用自动生成）

```yaml
my_3d_item:
  displayname: "<#FF5500>3D 自定义物品"
  material: DIAMOND_SWORD
  Pack:
    generate_model: false                      # 禁用自动生成
    model: custom/models/my_3d_item            # JSON 模型路径（相对于 models 文件夹）
    # blocking_model: custom/models/my_shield_blocking   # 用于盾牌的格挡模型
    # pulling_models:                                   # 用于弓的拉弦模型
    #   - custom/bow_pulling_0
    #   - custom/bow_pulling_1
    #   - custom/bow_pulling_2
    # cast_model: custom/fishing_rod_cast               # 用于钓鱼竿的抛竿模型
    # damaged_models:                                   # 用于不同耐久度等级的模型
    #   - custom/sword_damaged1
    #   - custom/sword_damaged2
```

## 1.21.4+ GUI 模型分离

```yaml
# 仅在物品栏/GUI 中显示不同的模型
my_dual_model_item:
  displayname: "<#FFAA00>双模型物品"
  material: PAPER
  Pack:
    generate_model: false
    model: item/held_sword          # 手持或装备时的模型
    gui_model: item/gui_sword       # 物品栏和 GUI 中的模型
    oversized_in_gui: false         # 是否允许在 GUI 中超出格子边界
    hand_animation_on_swap: true    # 切换物品时是否播放手部动画
```

## 文件放置说明

```
plugins/Oraxen/
  items/                          # 物品 YAML 配置文件
    my_custom_item.yml            # 你的物品配置
  pack/
    textures/                     # 纹理文件（PNG）
      my_custom_item.png          # 你的物品纹理
    models/                       # JSON 模型文件（仅在使用自定义模型时需要）
      custom/
        my_3d_item.json
```

- 纹理必须放在 `plugins/Oraxen/pack/textures/` 目录中
- 纹理文件名全部使用小写字母
- 建议纹理尺寸: 16x16 像素（与 Minecraft 原版风格统一）
- Oraxen 启动时会自动将 `pack/` 文件夹打包为 `pack.zip` 资源包

## parent_model 选择指南

| 父模型 | 适用场景 | 手持角度 |
|--------|----------|----------|
| `item/generated` | 材料、宝石、食物、护甲图标 | 平面显示 |
| `item/handheld` | 剑、斧、镐、锹、锄 | 倾斜握持（工具/武器姿态） |
| `item/handheld_rod` | 钓鱼竿、胡萝卜钓竿 | 杆状握持 |
| `block/cube` | 方块物品 | 方块渲染 |
| `builtin/entity` | 刷怪蛋、画 | 实体渲染 |
