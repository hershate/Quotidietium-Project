# 形状方块 (ShapedBlock) 配置模板

> **机制说明**: 形状方块机制使用涂蜡铜方块作为基础材质，创建自定义的**楼梯、台阶、门、活板门、格栅和灯泡**。每种方块类型最多支持 **4 种自定义变体**（各自独立的 1-4 范围）。
>
> **适用场景**: 需要正确的方向性放置（楼梯朝向、台阶上下半层）、功能性门和活板门（带开合动画）、自定义树叶（格栅类型的透明渲染）、可切换光源（灯泡类型）。
>
> **重要提示**: 此机制会修改原版涂蜡铜的行为。原版涂蜡铜方块将被转换为普通铜（带氧化防止标记），以便为自定义方块保留涂蜡变体。

---

## 一、全局配置 (mechanics.yml)

将以下内容配置在 `plugins/Oraxen/mechanics.yml` 中：

```yaml
# ============================================================
# 形状方块机制全局配置 (plugins/Oraxen/mechanics.yml)
# ============================================================
shaped_block:
  # [必需] 启用/禁用此机制
  enabled: true

  # [可选] 可以破坏自定义方块的镐工具等级
  tool_types:
    - WOODEN
    - STONE
    - IRON
    - GOLDEN
    - DIAMOND
    - NETHERITE

  # [可选] 将原版涂蜡铜方块转换为带氧化防止标记的未涂蜡版本
  # true = 涂蜡铜被转换为普通铜（保持原版外观但不氧化）
  # false = 原版涂蜡铜保持原样（但无法用于自定义形状方块）
  # 建议: 保持 true
  convert_vanilla_waxed: true

  # [可选] 处理世界生成结构中的涂蜡铜（如试炼密室）
  # true = 自动转换自然生成的涂蜡铜，确保自定义方块在生成的结构中正常工作
  # false = 不处理世界生成中的涂蜡铜
  # 建议: 保持 true
  handle_world_generation: true
```

## 二、方块类型概览

```yaml
# ============================================================
# 六种形状方块类型及其特性
# ============================================================
# 类型       | 基础材质        | 变体范围 | 特性
# -----------|----------------|----------|---------------------------
# STAIR      | 涂蜡铜楼梯      | 1-4      | 方向性放置、含水、上下半层
# SLAB       | 涂蜡铜台阶      | 1-4      | 上半/下半/双层、含水
# DOOR       | 涂蜡铜门        | 1-4      | 两格高、可开合、红石供能
# TRAPDOOR   | 涂蜡铜活板门    | 1-4      | 可开合、红石供能、含水
# GRATE      | 涂蜡铜格栅      | 1-4      | 透明裁剪渲染、含水、适合树叶
# BULB       | 涂蜡铜灯泡      | 1-4      | 可切换光源、红石供能
#
# 重要: 每种类型的 custom_variation 范围是独立的 1-4。
#       例如: 可以有 STAIR 1-4, SLAB 1-4, DOOR 1-4 各4个方块。
```

## 三、完整配置示例

### 3.1 自定义楼梯 (STAIR)

```yaml
# ============================================================
# 自定义楼梯 — 完整配置示例
# ============================================================
custom_oak_stairs:
  # ---- 基础信息 ----
  displayname: "<#8B4513>自定义橡木楼梯"
  material: PAPER

  # ---- 资源包/模型配置 ----
  Pack:
    generate_model: true
    parent_model: block/stairs       # 楼梯专用父模型
    textures:
      - custom_oak_planks            # 所有纹理使用统一材质

  # ---- 方块机制配置 ----
  Mechanics:
    shaped_block:
      # [必需★] 方块类型
      type: STAIR

      # [必需★] 变体编号 (1-4)
      custom_variation: 1

      # [可选] 硬度
      hardness: 2

      # [可选] 方块音效
      block_sounds:
        break_sound: block.wood.break
        place_sound: block.wood.place
        hit_sound: block.wood.hit
        step_sound: block.wood.step
        fall_sound: block.wood.fall

      # [可选] 掉落物配置
      drop:
        silktouch: false
        fortune: false
        minimal_type: WOODEN
        best_tools:
          - AXE
        loots:
          - oraxen_item: custom_oak_stairs
            probability: 1.0

# ============================================================
# 楼梯的行为特性:
# - 根据玩家朝向自动定向
# - 支持含水 (可放置在水下)
# - 根据点击位置自动放置在正确半层 (上半/下半)
# - 拐角楼梯自动连接
# ============================================================
```

```yaml
        step_sound: block.stone.step
        fall_sound: block.stone.fall
      drop:
        silktouch: false
        minimal_type: WOODEN

          - PICKAXE
        loots:
          - oraxen_item: custom_stone_slab

# ============================================================
# 台阶的行为特性:
# - 支持上半、下半和双层放置
# - 根据点击位置自动判断放置在上半还是下半
# - 双层台阶 = 两个台阶放在同一格
# - 破坏双层台阶时自动掉落 2 个物品
# - 支持含水
# ============================================================
```

### 3.3 自定义门 (DOOR)

```yaml
# ============================================================
# 自定义门 — 完整配置示例
# ============================================================
custom_oak_door:
  displayname: "<#8B4513>自定义橡木门"
  material: PAPER

  # ---- 资源包/模型配置 ----
  # 门的特殊之处: Pack 部分使用 item/generated 作为手持图标，
  # 门实际放置后的外观在 mechanic 的 textures 中指定
  Pack:
    generate_model: true
    parent_model: item/generated       # 手持/物品栏显示的平面图标
    textures:
      - custom_oak_door_icon           # 物品图标纹理

  # ---- 方块机制配置 ----
  Mechanics:
    shaped_block:
      # [必需★] 方块类型
      type: DOOR

      # [必需★] 变体编号 (1-4)
      custom_variation: 1

      hardness: 2

      # [必需] 门放置后的方块纹理（下半和上半部分）
      textures:
        bottom: block/oak_door_bottom  # 门的下半部分纹理
        top: block/oak_door_top        # 门的上半部分纹理

      # [可选] 方块音效
      block_sounds:
        break_sound: block.wood.break
        place_sound: block.wood.place
        hit_sound: block.wood.hit
        step_sound: block.wood.step
        fall_sound: block.wood.fall

      # [可选] 掉落物配置
      drop:
        silktouch: false
        minimal_type: WOODEN
        best_tools:
          - AXE
        loots:
          - oraxen_item: custom_oak_door
            probability: 1.0

# ============================================================
# 门的行为特性:
# - 两格高，自动放置上下两半
# - 右键点击开合
# - 红石供能（如压力板、按钮可控制开关）
# - 破坏任一半都会移除整扇门
# - Pack 使用 item/generated 作为物品图标，纹理在 mechanism 中指定
# ============================================================
```

### 3.5 自定义格栅/树叶 (GRATE)

```yaml
# ============================================================
# 自定义格栅（GREAT FOR CUSTOM LEAVES!）
# 格栅使用裁剪渲染规则，允许纹理的透明通道透出
# 这是制作自定义树叶的最佳选择！
# ============================================================
crystalmush_leaves:
  displayname: "<gradient:#9966FF:#FF66CC>水晶蘑菇树叶"
  material: PAPER
  Pack:
    generate_model: true
    parent_model: block/leaves         # 使用 leaves 父模型获得透明度渲染
    textures:
      - default/crystalmush/crystalmush_leaves_anim
  Mechanics:
    shaped_block:
      # [必需★] 方块类型
      type: GRATE

      # [必需★] 变体编号 (1-4)
      custom_variation: 2

      # [可选] 发光！非常适合魔法树叶
      light: 12

      hardness: 0.2                    # 非常容易破坏
      block_sounds:
        break_sound: block.grass.break
        place_sound: block.grass.place
        hit_sound: block.grass.hit
        step_sound: block.grass.step
        fall_sound: block.grass.fall
      drop:
        silktouch: true                # 只有精准采集才掉落树叶本身
        best_tools:
          - SHEARS
          - HOE
        loots:
          - oraxen_item: crystalmush_leaves
            probability: 1.0

# ============================================================
# 格栅的行为特性:
# - 使用裁剪渲染 (cutout) 的透明效果
# - 纹理的透明通道像真实树叶一样透出
# - 支持含水
# - 光线可以透过
# - 非常适合自定义树叶、玻璃类方块、镂空装饰
#
# 父模型建议:
# - block/leaves  → 植被/树叶类透明度
# - block/cube_all → 玻璃/金属格栅类
# ============================================================
```

## 六、通用配置属性

所有形状方块类型共享以下可选属性：

```yaml
# ============================================================
# 通用配置属性 (适用于所有类型)
# ============================================================

# [可选] 硬度 (默认: 3)
hardness: 3

# [可选] 发光等级 0-15 (默认: 0)
# 注意: BULB 类型有特殊的开关光源机制，此 light 值为基础光照
light: 0

# [可选] 方块音效
block_sounds:
  break_sound: block.wood.break
  place_sound: block.wood.place
  hit_sound: block.wood.hit
  step_sound: block.wood.step
  fall_sound: block.wood.fall

# [可选] 掉落物配置
drop:
  silktouch: false          # 是否需要精准采集
  fortune: false            # 是否受时运影响
  minimal_type: WOODEN      # 最低工具等级
  best_tools:               # 最佳工具类型
    - PICKAXE
  loots:                    # 掉落物列表
    - oraxen_item: my_block
      probability: 1.0
```

## 七、门类型特殊配置说明

门是六种类型中最特殊的，需要额外注意：

```yaml
# ============================================================
# 门的配置要点
# ============================================================
# 1. Pack.parent_model 必须使用 item/generated
#    - 这用于手持时和物品栏中的图标显示
#
# 2. Pack.textures 指向物品图标的纹理
#    - 这是你在手中看到的平面贴图
#
# 3. Mechanics.shaped_block.textures 指定放置后的方块纹理
#    - bottom: 门下半部分的纹理
#    - top: 门上半部分的纹理
#    - 这才是实际放置在世界上门的纹理
#
# 4. 模板示例:
custom_door_template:
  displayname: "<gold>示例门"
  material: PAPER
  Pack:
    generate_model: true
    parent_model: item/generated          # [重要] 物品图标
    textures:
      - my_door_icon                      # 手持图标纹理
  Mechanics:
    shaped_block:
      type: DOOR
      custom_variation: 1
      textures:                           # [重要] 方块纹理
        bottom: block/my_door_bottom      # 下半部分
        top: block/my_door_top            # 上半部分
      # ... 其余配置
```

## 八、限制说明

1. **每种类型最多 4 个变体**: 楼梯、台阶、门、活板门、格栅、灯泡各最多 4 种自定义变体。总共最多 24 种自定义形状方块（6 类型 x 4 变体）。
2. **涂蜡铜被转换**: 当机制启用时,世界中现有的涂蜡铜方块将被转换为普通铜（带氧化防止标记）。玩家无法将涂蜡铜材料用于原版用途。
3. **变体编号独立**: 每种类型的 `custom_variation` 是独立的。STAIR 的 1-4 和 SLAB 的 1-4 互不冲突。
4. **不支持防爆/不可推动/下落**: 形状方块不支持 `blast_resistant`、`immovable`、`is_falling` 等属性。
5. **不支持存储/点击动作**: 形状方块不支持 `storage` 容器和 `clickActions` 点击动作。
6. **禁用机制可恢复**: 如果设置 `enabled: false`，原版涂蜡铜行为将被完全恢复。
7. **世界生成处理**: `handle_world_generation: true` 确保试炼密室等结构中的涂蜡铜被正确处理。

## 九、配置字段速查表

```yaml
# ============================================================
# 形状方块配置字段一览
# ============================================================
# 字段                | 类型      | 必需 | 默认值   | 说明
# ------------------- | --------- | ---- | -------- | ------------------

# drop                | object    | 可选 | -        | 掉落物配置
# textures [仅 DOOR]  | object    | ★DOOR | -        | 门的下半/上半纹理 (bottom, top)
```

## 十、注意事项

1. **变体总数限制**: 6 种类型 x 4 变体 = 最多 24 个形状方块，请合理规划使用。
2. **门的两格特性**: 门占据两格高，破坏任意一半都会掉落物品。
3. **涂蜡铜影响**: 启用此机制会影响服务器中所有涂蜡铜方块。在已有建筑的服务器上启用前请备份。
4. **格栅做树叶**: GRATE 类型配合 `block/leaves` 父模型是自定义树叶的绝佳选择。
5. **红石交互**: DOOR、TRAPDOOR、BULB 都支持红石供能，可以融入红石机械中。
6. **含水支持**: STAIR、SLAB、TRAPDOOR、GRATE 都支持含水。
