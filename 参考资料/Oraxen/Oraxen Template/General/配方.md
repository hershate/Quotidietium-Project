# Oraxen 配方 (Recipes) 配置模板

> 配方是 Minecraft 允许玩家从其他物品创建物品的方式。
> Oraxen 支持创建和管理多种类型的配方。
> ⚠️ **文档支持范围：** Recipes.md 明确声明"目前仅支持 shaped 配方"（for the moment only shaped recipes are supported）。
> 本模板另含 shapeless/furnace/blast_furnace/smoker/smithing 等类型作为完整参考，这些需较新版本 Oraxen 支持，使用前请按实际版本验证。
>
> **配置文件位置：** `plugins/Oraxen/recipes/` 目录下，按配方类型分文件存放。
>
> **相关命令：**
> - `/o recipe builder SHAPED` — 打开有序配方构建器界面
> - `/o recipe builder SHAPELESS` — 打开无序配方构建器界面
> - `/o recipe builder FURNACE` — 打开熔炉配方构建器界面
> - `/o recipe builder SMITHING` — 打开锻造配方构建器界面
> - `/o recipes save <name>` — 保存配方
> - `/o recipes save <name> <permission>` — 保存带权限的配方
> - `/o recipes open` — 重新打开之前未关闭的配方构建器
> - `/o recipes show all` — 显示已加载的配方
> - `/o recipes show <recipe>` — 显示指定配方
> - ⚠️ 配方保存后需**重启服务器**才能生效，不支持热重载（Recipes.md 明确说明：需等待服务器重启后方可使用）

## 一、有序配方（Shaped Recipe）

> 有序配方要求原料按照特定形状排列。适用于剑、盔甲、工具等需要精确位置的物品合成。
>
> **配置文件：** `plugins/Oraxen/recipes/shaped.yml`

### 配置模板

```yaml
# ============================================================
# 文件: plugins/Oraxen/recipes/shaped.yml
# ============================================================

# 配方 ID（也是命名空间键，例如 oraxen:custom_sword）
custom_sword:                           # 【必填】配方 ID，全局唯一标识符
  type: shaped                          # 【必填】配方类型，此处为 shaped（有序）
  shape:                                # 【必填】配方形状，3x3 网格，使用 1-3 行
    - "AAA"                             # 第一行：A = 同一种原料
    - "ABA"                             # 第二行：B = 另一种原料
    - " C "                             # 第三行：空格 = 留空，C = 第三种原料
  ingredients:                          # 【必填】原料映射
    A:                                  # 对应 shape 中的字母
      material: DIAMOND                 # 【必填】原料材质（原版 ID 或 oraxen:ID）
      # 可使用: oraxen:<oraxen_item_id>  来引用 Oraxen 自定义物品
    B:
      material: STICK
    C:
      material: oraxen:ruby_gem         # 使用 Oraxen 自定义物品作为原料
  result:                               # 【必填】合成结果
    material: oraxen:custom_sword       # 【必填】结果物品
    amount: 1                           # 【可选】产出数量，默认 1
  permission: "oraxen.recipe.sword"     # 【可选】合成此物品所需的权限节点
  # 如果设置了 permission，玩家需要该权限才能看到和使用此配方
```

### 形状定义详解

```
# 3x3 工作台网格形状示例:

# 1 行配方（例如木棍→木棍×4）:
shape:
  - "A"
  - "A"

# 2 行配方（例如剑）:
shape:
  - "A"
  - "A"
  - "B"

# 3 行完整配方（例如胸甲）:
shape:
  - "A A"
  - "AAA"
  - "AAA"

# 空格表示该格不需要放入物品
```

### 完整示例

```yaml
# ============================================================
# 示例 1: 自定义剑
# ============================================================
ruby_sword:
  type: shaped
  shape:
    - "R"
    - "R"
    - "S"
  ingredients:
    R:
      material: oraxen:ruby_gem
    S:
      material: STICK
  result:
    material: oraxen:ruby_sword
    amount: 1

# ============================================================
# 示例 2: 自定义胸甲
# ============================================================
ruby_chestplate:
  type: shaped
  shape:
    - "R R"
    - "RRR"
    - "RRR"
  ingredients:
    R:
      material: oraxen:ruby_gem
  result:
    material: oraxen:ruby_chestplate
    amount: 1

# ============================================================
# 示例 3: 带权限的配方（仅 VIP 可合成）
# ============================================================
vip_sword:
  type: shaped
  shape:
    - " D "
    - " D "
    - " S "
  ingredients:
    D:
      material: DIAMOND
    S:
      material: STICK
  result:
    material: oraxen:vip_sword
    amount: 1
  permission: "oraxen.recipe.vip_sword"

# ============================================================
# 示例 4: 使用原版物品的配方
# ============================================================
compressed_cobblestone:
  type: shaped
  shape:
    - "CCC"
    - "CCC"
    - "CCC"
  ingredients:
    C:
      material: COBBLESTONE
  result:
    material: oraxen:compressed_cobblestone
    amount: 1
```

## 二、无序配方（Shapeless Recipe）

> 无序配方不要求原料有特定排列，只需将所需原料以任意顺序放入工作台即可合成。
>
> **配置文件：** `plugins/Oraxen/recipes/shapeless.yml`

### 配置模板

```yaml
# ============================================================
# 文件: plugins/Oraxen/recipes/shapeless.yml
# ============================================================

# 配方 ID
custom_mixture:                         # 【必填】配方 ID
  type: shapeless                       # 【必填】配方类型，此处为 shapeless（无序）
  ingredients:                          # 【必填】原料列表（1-9 种）
    - material: REDSTONE                # 原料 1
    - material: GLOWSTONE_DUST          # 原料 2
    - material: GUNPOWDER               # 原料 3
    - material: oraxen:magic_dust       # 原料 4（Oraxen 自定义物品）
  result:                               # 【必填】合成结果
    material: oraxen:custom_mixture     # 【必填】结果物品
    amount: 4                           # 【可选】产出数量，默认 1
  permission: "oraxen.recipe.mixture"   # 【可选】所需权限
```

### 完整示例

```yaml
# ============================================================
# 示例 1: 魔法粉末（无序合成）
# ============================================================
magic_powder:
  type: shapeless
  ingredients:
    - material: oraxen:fire_essence
    - material: oraxen:water_essence
    - material: oraxen:earth_essence
    - material: oraxen:wind_essence
  result:
    material: oraxen:magic_powder
    amount: 2

# ============================================================
# 示例 2: 染料混合
# ============================================================
custom_dye:
  type: shapeless
  ingredients:
    - material: RED_DYE
    - material: BLUE_DYE
    - material: WHITE_DYE
  result:
    material: oraxen:custom_dye
    amount: 3

# ============================================================
# 示例 3: 简易维修套件
# ============================================================
repair_kit:
  type: shapeless
  ingredients:
    - material: IRON_INGOT
    - material: IRON_INGOT
    - material: STRING
  result:
    material: oraxen:repair_kit
    amount: 1
```

## 三、熔炉配方（Furnace Recipe）

> 熔炉配方通过在熔炉/高炉/烟熏炉中烧炼原料来获得物品。
>
> **配置文件：** `plugins/Oraxen/recipes/furnace.yml`

### 配置模板

```yaml
# ============================================================
# 文件: plugins/Oraxen/recipes/furnace.yml
# ============================================================

# 配方 ID
smelted_ruby:                           # 【必填】配方 ID
  type: furnace                         # 【必填】配方类型，此处为 furnace（熔炉）
  input:                                # 【必填】输入原料
    material: oraxen:ruby_ore           # 【必填】要烧炼的物品
  result:                               # 【必填】输出结果
    material: oraxen:ruby_gem           # 【必填】烧炼产物
    amount: 1                           # 【可选】产出数量，默认 1
  experience: 1.5                       # 【可选】烧炼完成后获得的经验值（浮点数）
  cooking_time: 200                     # 【可选】烧炼时间（游戏刻），默认 200（10 秒）
  # 100 刻 = 5 秒, 200 刻 = 10 秒（标准熔炉速度）
  # 高炉/烟熏炉速度减半（100 刻 = 5 秒）
  permission: "oraxen.recipe.smelt"     # 【可选】所需权限

# ============================================================
# 高炉配方 — 使用 BLASTING 类型
# ============================================================
refined_iron:
  type: blast_furnace                   # blast_furnace = 高炉（仅矿物类）
  input:
    material: oraxen:raw_iron_chunk
  result:
    material: oraxen:refined_iron
    amount: 1
  experience: 2.0
  cooking_time: 100                     # 高炉默认为 100 刻 (5秒)

# ============================================================
# 烟熏炉配方 — 使用 SMOKER 类型
# ============================================================
cooked_mystery_meat:
  type: smoker                          # smoker = 烟熏炉（仅食物类）
  input:
    material: oraxen:mystery_meat
  result:
    material: oraxen:cooked_mystery_meat
    amount: 1
  experience: 0.7
  cooking_time: 100                     # 烟熏炉默认为 100 刻 (5秒)
```

### 熔炉配方中的烧炼时间参考

| 熔炉类型 | 默认时间 | 说明 |
|----------|---------|------|
| `furnace` (普通熔炉) | 200 刻 (10秒) | 通用烧炼 |
| `blast_furnace` (高炉) | 100 刻 (5秒) | 仅矿物类物品 |
| `smoker` (烟熏炉) | 100 刻 (5秒) | 仅食物类物品 |
| `campfire` (营火) | 600 刻 (30秒) | 无需燃料 |

## 四、锻造配方（Smithing Recipe）

> 锻造配方使用锻造台将物品升级或转换。
> 需要 Minecraft 1.20+（支持锻造模板系统）。
>
> **配置文件：** `plugins/Oraxen/recipes/smithing.yml`

### 配置模板

```yaml
# ============================================================
# 文件: plugins/Oraxen/recipes/smithing.yml
# ============================================================

# 配方 ID
ruby_upgrade:                           # 【必填】配方 ID
  type: smithing                        # 【必填】配方类型，此处为 smithing（锻造）
  template:                             # 【必填】锻造模板（1.20+）
    material: NETHERITE_UPGRADE_SMITHING_TEMPLATE  # 或使用 oraxen:custom_template
  base:                                 # 【必填】基础物品
    material: DIAMOND_SWORD             # 要升级的基础物品
  addition:                             # 【必填】添加材料
    material: oraxen:ruby_gem           # 升级所用的材料
  result:                               # 【必填】锻造结果
    material: oraxen:ruby_sword         # 升级后得到的物品
    amount: 1
  permission: "oraxen.recipe.upgrade"   # 【可选】所需权限
```

### 完整示例

```yaml
# ============================================================
# 示例 1: 钻石剑升级为红宝石剑
# ============================================================
ruby_sword_smithing:
  type: smithing
  template:
    material: NETHERITE_UPGRADE_SMITHING_TEMPLATE
  base:
    material: DIAMOND_SWORD
  addition:
    material: oraxen:ruby_gem
  result:
    material: oraxen:ruby_sword
    amount: 1

# ============================================================
# 示例 2: 使用自定义锻造模板
# ============================================================
ancient_upgrade:
  type: smithing
  template:
    material: oraxen:ancient_template
  base:
    material: oraxen:ruby_sword
  addition:
    material: oraxen:ancient_core
  result:
    material: oraxen:ancient_sword
    amount: 1
  permission: "oraxen.recipe.ancient"
```

## 五、禁用原版或已有配方

> 通过 `disabled.yml` 文件禁用任何原版 Minecraft 配方或已存在的配方。
>
> **配置文件：** `plugins/Oraxen/recipes/disabled.yml`

```yaml
# ============================================================
# 文件: plugins/Oraxen/recipes/disabled.yml
# （此文件在 Oraxen 首次加载时自动创建）
# ============================================================

disabled:                               # 【必填】要禁用的配方列表
  - minecraft:diamond_sword             # 禁用原版钻石剑配方
  - minecraft:iron_pickaxe              # 禁用原版铁镐配方
  - minecraft:golden_apple              # 禁用原版金苹果配方
  - oraxen:old_recipe                   # 禁用 Oraxen 自定义配方
  # 命名空间键格式: <插件命名空间>:<配方ID>
  # 可以通过 /recipes 命令查看配方键（游戏中打开知识之书）
```

> 服务器需要重启才能使禁用配方生效。无效的配方键或不存在的配方将在控制台中显示警告。

## 六、配方类型速查表

| 配方类型 | type 值 | 配置文件 | 适用场景 |
|----------|---------|---------|---------|
| 有序合成 | `shaped` | `shaped.yml` | 剑、工具、盔甲 — 需要特定排列 |
| 无序合成 | `shapeless` | `shapeless.yml` | 染料、药水 — 不需要特定排列 |
| 熔炉烧炼 | `furnace` | `furnace.yml` | 矿石烧炼、食物烹饪 |
| 高炉烧炼 | `blast_furnace` | `furnace.yml` | 矿物快速烧炼 |
| 烟熏炉 | `smoker` | `furnace.yml` | 食物快速烹饪 |
| 营火 | `campfire` | `furnace.yml` | 无需燃料的烹饪 |
| 锻造 | `smithing` | `smithing.yml` | 物品升级/转换 (1.20+) |
| 禁用配方 | — | `disabled.yml` | 禁用原版或其他插件配方 |

## 七、配方解锁

> Oraxen 支持通过配方书解锁系统。玩家可以通过以下方式解锁配方：

1. **自动解锁：** 玩家获得配方中的任意原料后自动解锁
2. **权限解锁：** 通过 `permission` 字段控制，拥有权限的玩家才能看到和合成
3. **配方书命令：** 使用 `/recipe give <player> oraxen:<recipe_id>` 手动为玩家解锁

```yaml
# 带权限的配方示例
admin_sword:
  type: shaped
  shape:
    - "D"
    - "D"
    - "S"
  ingredients:
    D:
      material: DIAMOND_BLOCK
    S:
      material: STICK
  result:
    material: oraxen:admin_sword
    amount: 1
  permission: "oraxen.recipe.admin_sword"
  # 只有拥有 oraxen.recipe.admin_sword 权限的玩家才能合成
```

## 八、使用 Oraxen 物品作为原料/结果的注意点

```
# 在 recipes 配置中引用物品的正确格式:

# 原版物品 — 使用 Material 枚举名称（大写，下划线分隔）
material: DIAMOND
material: IRON_INGOT
material: NETHERITE_UPGRADE_SMITHING_TEMPLATE

# Oraxen 自定义物品 — 使用 oraxen:<物品ID> 格式
material: oraxen:ruby_gem
material: oraxen:custom_sword
material: oraxen:compressed_cobblestone

# 确保:
# 1. Oraxen 物品 ID 拼写正确
# 2. 对应的物品已在 items 目录下配置并正确加载
# 3. 物品配置中 Pack 生成已正确设置
```

## 九、游戏内配方构建器流程

```
1. 打开构建器界面:
   /o recipe builder SHAPED       # 打开有序配方构建器
   /o recipe builder SHAPELESS    # 打开无序配方构建器
   /o recipe builder FURNACE      # 打开熔炉配方构建器
   /o recipe builder SMITHING     # 打开锻造配方构建器

2. 放入原料:
   - 有序配方: 将原料按形状放在左侧部分
   - 无序配方: 将原料任意放入
   - 熔炉配方: 放入输入原料
   - 锻造配方: 放入模板、基础和添加材料

3. 放入结果:
   - 将期望的产出物品放在右侧的槽位中

4. 保存配方:
   /o recipes save <name>              # 保存（重启后生效）
   /o recipes save <name> <permission> # 保存并设置权限

5. 如需继续编辑（关闭界面后未保存）:
   /o recipes open                     # 重新打开之前的构建器

6. 重启服务器后配方生效（无法通过 /o reload 热加载配方）
```

## 十、注意事项

| 项目 | 说明 |
|------|------|
| 配方需要重启 | 配方在服务器重启后才能加载使用，不支持热重载（Recipes.md 明确说明需重启生效） |
| shape 中的字母 | 每个字母代表一种原料，最多 9 种不同字母（A-I），空格表示留空 |
| 原料数量限制 | 有序配方最多 9 种原料（3x3 网格），无序配方最多 9 种原料 |
| 命名空间键 | 配方保存在 `oraxen:` 命名空间下（例如 `oraxen:ruby_sword`） |
| 权限节点 | `permission` 字段控制谁能合成，无权限的玩家甚至看不到该配方 |
| disabled.yml | 需要重启服务器才能生效 |
| 调试 | 使用 `/o recipes show all` 和 `/o recipes show <id>` 检查配方加载状态 |
