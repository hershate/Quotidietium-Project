# 绊线方块 (StringBlock) 配置模板

> **机制说明**: 绊线机制使用 Minecraft 的绊线状态来创建自定义方块。提供多达 **127 种独特的方块变体**，非常适合植物、花朵和其他装饰元素。
>
> **适用场景**: 玩家可以穿过的小型装饰物、植物和花朵、需要含水的方块、高株植物（2 格高）。
>
> **与音符盒的关键区别**:
> - 玩家可以**穿过**绊线方块（无碰撞箱或极小碰撞箱）
> - 支持**含水**（可放置在水下）
> - 支持**高株植物**（`is_tall`）
> - 支持**随机放置**（`random_place`）
> - 支持**堆叠方块**（`stackable`）
> - 支持**树苗机制**（`sapling`）
> - **不支持**方向性放置（directional）
> - **不支持**座椅（seat）
> - 最多 127 个变体，而非 800 个

---

## 一、全局配置 (mechanics.yml)

将以下内容配置在 `plugins/Oraxen/mechanics.yml` 中：

```yaml
# ============================================================
# 绊线机制全局配置 (plugins/Oraxen/mechanics.yml)
# ============================================================
stringblock:
  # [必需] 启用/禁用此机制
  enabled: true

  # [可选] 可以破坏自定义方块的镐工具等级
  tool_types:
    - WOODEN
    - STONE
    - IRON
    - GOLDEN
    - DIAMOND
    - NETHERITE

  # [可选] 树苗生长检查间隔（刻），仅在使用树苗机制时需要
  # 20刻 = 1秒。值越大检查越少，性能越好
  sapling_growth_check_delay: 4000

  # [可选] 禁用原版绊线放置 (默认: false)
  # true = 玩家无法放置原版绊线，将绊线仅保留给自定义方块
  # false = 原版绊线正常工作
  disable_vanilla_strings: false
```

## 二、最简配置 (基本植物/装饰物)

```yaml
# ============================================================
# 示例: 最简单的绊线方块（花朵）
# ============================================================
jasmine_flower:
  # ---- 基础信息 ----
  # [必需] 显示名称
  displayname: "<white>茉莉花"

  # [必需] 基础材质，植物类通常用 PAPER
  material: PAPER

  # ---- 资源包/模型配置 ----
  Pack:
    # [必需] 是否自动生成模型
    generate_model: true

    # [必需] 父模型，植物通常使用 "block/cross"
    # 也可以用 "block/cube_all" 等（但较少见）
    parent_model: "block/cross"

    # [必需] 纹理文件
    textures:
      - custom/flowers/jasmine_flower

  # ---- 方块机制配置 ----
  Mechanics:
    stringblock:
      # [必需★] 唯一变体编号 1-127
      custom_variation: 2

      # [必需★] 模型名称
      model: jasmine_flower

      # [可选] 硬度
      hardness: 2

      # [可选] 掉落物配置
      drop:
        silktouch: false
        loots:
          - { oraxen_item: jasmine_flower, probability: 1.0 }
```

## 三、完整配置模板（含所有可选字段）

```yaml
# ============================================================
# 完整示例: 带所有可选功能的绊线方块
# ============================================================
magical_plant:
  displayname: "<gradient:#00FF88:#00CCFF>魔法植物"
  material: PAPER
  Pack:
    generate_model: true
    parent_model: "block/cross"
    textures:
      - custom/plants/magical_plant

  Mechanics:
    stringblock:
      # ========== 核心配置 ==========

      # [必需★] 自定义变体编号 (1-127)
      custom_variation: 1

      # [必需★] 模型名称
      model: magical_plant

      # ========== 物理属性 ==========

      # [可选] 硬度，数值越大挖掘时间越长
      hardness: 1

      # [可选] 光照等级 0-15 (默认: 0)
      light: 7

      # [可选] 是否防爆
      blast_resistant: false

      # [可选] 是否受重力影响下落 (类似沙子)
      is_falling: false

      # [可选] 是否无法被活塞推动
      immovable: false

      # ========== 绊线特有功能 ==========

      # [可选] 高株植物（2 格高），类似原版高草丛或向日葵
      is_tall: false

      # [可选] 含水，允许方块放置在水下
      waterloggable: false     # 注意: 此字段可能在源码中自动启用
                                # 绊线方块通常天然支持含水

      # [可选] 随机放置（从方块列表中随机选择）
      # 非常适合创建多样化的花丛！
      # random_place:
      #   blocks:
      #     - red_flower
      #     - blue_flower
      #     - yellow_flower
      #     - white_flower

      # ========== 方块音效 ==========
      block_sounds:
        place_sound: block.grass.place
        break_sound: block.grass.break
        hit_sound: block.grass.hit
        step_sound: block.grass.step
        fall_sound: block.grass.fall
        volume: 1.0
        pitch: 1.0

      # ========== 掉落物配置 ==========
      drop:
        silktouch: false       # 是否需要精准采集
        fortune: false         # 是否受时运影响
        minimal_type: STONE    # 最低工具等级
        best_tools:
          - SHEARS             # 最适合用剪刀
        loots:
          - oraxen_item: magical_plant
            probability: 1.0

      # ========== 存储容器 ==========
      # [可选] 将方块变成可打开的容器
      # storage:
      #   type: STORAGE
      #   rows: 3
      #   title: "小型容器"
      #   open_sound: block.chest.open
      #   close_sound: block.chest.close
      #
      # 存储类型:
      # - STORAGE      标准共享容器
      # - SHULKER      破坏时物品保留在方块中
      # - PERSONAL     每个玩家独立存储
      # - DISPOSAL     垃圾桶，关闭时物品被删除
      # - ENDERCHEST   打开玩家的末影箱

      # ========== BlockLocker 保护 ==========
      # blocklocker:
      #   can_protect: true
      #   protection_type: CONTAINER

      # ========== ClickActions 点击动作 ==========
      # clickActions:
      #   - conditions: []
      #     actions:
      #       - '[message] <green>你触摸了魔法植物!'
      #       - '[actionbar] <gray>感受到了魔法的力量...'
      #   - conditions:
      #       - '#player.hasPermission("magic.use")'
      #     actions:
      #       - '[console] give %player% magic_essence 1'
      #       - '{source=AMBIENT volume=0.5 pitch=1.2} [sound] minecraft:block.enchantment_table.use'

      # ========== 可堆叠方块 (stackable) ==========
      # [可选] 需要 Oraxen 1.212.0+
      # 创建右键可堆叠的方块，类似原版粉红色花瓣
      # stackable:
      #   - custom_variation: 2     # 下一个堆叠级别的变体编号
      #     model: my_plant_stage2  # 该级别的模型
      #   - custom_variation: 3     # 再下一个级别
      #     model: my_plant_stage3
      #   - custom_variation: 4
      #     model: my_plant_stage4
      #
      # 堆叠逻辑:
      # - 父方块首先被放置 (custom_variation: 1)
      # - 使用相同物品右键点击推进到下一个堆叠级别
      # - 破坏方块时掉落与堆叠级别数量相等的物品
      # - 每个堆叠变体消耗 127 个可用变体中的一个

      # ========== 树苗机制 (sapling) ==========
      # [可选] 需要 Oraxen 1.136.0+
      # 创建可以生长为结构的自定义树苗
      # sapling:
      #   canGrowNaturally: true        # 是否随时间自然生长
      #   naturalGrowthTime: 6000       # 自然生长所需刻数 (6000 = 5分钟)
      #   canGrowFromBoneMeal: true     # 是否可用骨粉催熟
      #   boneMealGrowChance: 50        # 每次骨粉使用成功几率 (%)
      #   growSound: block.grass.break  # 生长时播放的音效
      #   minLightLevel: 4              # 生长所需最低光照等级
      #   requiresWaterSource: false    # 是否需要附近有水源
      #   replaceBlocks: false          # 生长时是否替换现有方块
      #   schematicName: custom_tree    # 要生成的结构 schematic 文件名
      #
      # 树苗配置字段说明:
      # | 字段                  | 默认值  | 说明                                   |
      # |-----------------------|---------|----------------------------------------|
      # | canGrowNaturally      | true    | 树苗是否随时间自然生长                  |
      # | naturalGrowthTime     | 6000    | 自然生长所需刻数 (20刻=1秒)             |
      # | canGrowFromBoneMeal   | true    | 骨粉是否可以触发生长                    |
      # | boneMealGrowChance    | 50      | 每次使用骨粉的生长几率百分比 (0-100)    |
      # | growSound             | -       | 生长时播放的音效                        |
      # | minLightLevel         | 4       | 生长所需的最低光照等级                  |
      # | requiresWaterSource   | false   | 是否需要附近有水源                      |
      # | replaceBlocks         | false   | true=生长时替换现有方块, false=有方块时阻止生长 |
      # | schematicName         | -       | 树苗生长时粘贴的 schematic 文件名(需WorldEdit) |
```

## 四、特殊功能详细示例

### 4.1 高株植物 (is_tall)

```yaml
# ============================================================
# 2格高的植物，类似向日葵或高草丛
# ============================================================
tall_magic_grass:
  displayname: "<green>高魔法草"
  material: PAPER
  Pack:
    generate_model: true
    parent_model: "block/cross"
    textures:
      - custom/plants/tall_grass_top    # 上半部分纹理
      # 下半部分自动处理
  Mechanics:
    stringblock:
      custom_variation: 5
      model: tall_magic_grass
      is_tall: true    # [关键] 设置为2格高植物
      hardness: 0.5
      drop:
        silktouch: false
        loots:
          - { oraxen_item: tall_magic_grass, probability: 1.0 }
```

### 4.2 随机放置花丛

```yaml
# ============================================================
# 放置时随机选择花朵变体 — 非常适合野花花丛
# ============================================================
wildflower_cluster:
  displayname: "<yellow>野花花丛"
  material: PAPER
  Pack:
    generate_model: true
    parent_model: "block/cross"
    textures:
      - custom/flowers/wildflower_base
  Mechanics:
    stringblock:
      custom_variation: 10
      model: wildflower_cluster
      hardness: 0.5
      random_place:       # [关键] 随机选择外观
        blocks:
          - red_wildflower     # 红色变体
          - blue_wildflower    # 蓝色变体
          - yellow_wildflower  # 黄色变体
          - purple_wildflower  # 紫色变体
          - white_wildflower   # 白色变体
      drop:
        silktouch: false
        loots:
          - { oraxen_item: wildflower_cluster, probability: 1.0 }
```

### 4.3 可堆叠花瓣（类似粉红色花瓣）

### 4.4 树苗配置完整示例

```yaml
# ============================================================
# 自定义树苗 — 可生长为自定义树木结构
# ============================================================
magic_sapling:
  displayname: "<gradient:#FF69B4:#8A2BE2>魔法树苗"
  material: PAPER
  Pack:
    generate_model: true
    parent_model: "block/cross"
    textures:
      - custom/saplings/magic_sapling
  Mechanics:
    stringblock:
      custom_variation: 20
      model: magic_sapling
      hardness: 0.5
      drop:
        silktouch: false
        loots:
          - { oraxen_item: magic_sapling, probability: 1.0 }
      sapling:
        canGrowNaturally: true
        naturalGrowthTime: 12000       # 10 分钟
        canGrowFromBoneMeal: true
        boneMealGrowChance: 35         # 35% 几率
        growSound: block.grass.break
        minLightLevel: 4
        requiresWaterSource: true      # 需要水源附近
        replaceBlocks: false
        schematicName: magic_tree      # WorldEdit schematic 名称
```

## 六、变体编号范围说明

绊线方块有一个重要的变体行为差异：

```yaml
# ============================================================
# 变体编号范围与碰撞箱差异
# ============================================================
# custom_variation 在 1-64 范围内:
#   - 使用较大的碰撞箱
#   - 适合一般大小的装饰物
#
# custom_variation 在 65-127 范围内:
#   - 使用更小的碰撞箱
#   - 玩家更容易穿过
#   - 适合非常小的细节装饰物
#
# 注意: 无论使用哪个范围，绊线方块都没有完整的方块碰撞箱，
# 玩家始终可以穿过它们。
```

## 七、与音符盒 (NoteBlock) 的关键差异对比

```yaml
# ============================================================
# 绊线 vs 音符盒 机制对比
# ============================================================
# 特性            | 音符盒    | 绊线      | 说明
# ----------------|----------|----------|------------------------------
# 最大变体数       | ~800     | 127      | 绊线变体数较少
# 碰撞箱           | 完整方块  | 可穿过    | 绊线方块没有完整碰撞箱
# 含水             | 不支持    | 支持      | 绊线方块可放置在水下
# 高株植物         | 不支持    | 支持      | is_tall 实现2格高植物
# 随机放置         | 不支持    | 支持      | random_place 随机选择外观
# 堆叠方块         | 不支持    | 支持      | stackable 多级堆叠
# 树苗机制         | 不支持    | 支持      | sapling 自动生长
# 方向性放置       | 支持      | 不支持    | directional (LOG/FURNACE/DROPPER)
# 座椅             | 不支持    | 不支持    | 只有紫颂和家具支持座椅
# 去皮原木         | 支持      | 不支持    | logStrip 机制
# 农场方块         | 支持      | 不支持    | farmblock 子机制
# 发光             | 支持      | 支持      |
# 防爆             | 支持      | 支持      |
# 不可推动         | 支持      | 支持      |
# 下落方块         | 支持      | 支持      |
# 存储             | 支持      | 支持      |
# BlockLocker      | 支持      | 支持      |
# ClickActions     | 支持      | 支持      |
# 自定义音效       | 支持      | 支持      |
```

## 九、注意事项

1. **变体数量有限**: 绊线方块只有 127 个变体，请合理规划使用。
2. **堆叠消耗变体**: 每个 `stackable` 列表中的 `custom_variation` 都会消耗 127 个可用绊线变体中的一个。4级堆叠 = 消耗 4 个变体。
3. **变体 1-64 vs 65-127**: 两个范围的碰撞箱大小不同，注意根据装饰物大小选择合适的范围。
4. **Paper 优化**: 强烈建议在 `config/paper-global.yml` 中设置 `disable-tripwire-updates: true`。
5. **无碰撞箱**: 绊线方块没有完整的方块碰撞箱，不适合做墙壁、地板等需要碰撞的方块。需要碰撞箱请使用音符盒。
6. **禁用原版绊线**: 如果你的服务器需要大量使用自定义绊线方块，建议设置 `disable_vanilla_strings: true` 避免混淆。
7. **树苗需要 WorldEdit**: `sapling.schematicName` 需要 WorldEdit 来粘贴结构文件。
