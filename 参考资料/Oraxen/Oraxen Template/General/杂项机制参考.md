## 耐久度 (durability)

### 概述

允许你更改 Oraxen 物品的自定义耐久度。Minecraft 原版的系统不适合直接修改耐久度显示，因此此系统以百分比方式工作。例如基于木镐（默认耐久度 59）创建一个耐久度为 5900 的镐子，物品上仍显示 59，但你需要破坏 100 个方块才能消耗 1 点耐久度。耐久条会正确更新。

> **版本说明：** 在 Minecraft 1.20.5+ 上，建议改用新的 Durability Component。

### 完整 YAML 配置

```yaml
# ============================================================
# 物品配置示例：自定义耐久度
# ============================================================
crystal_sword:
  material: DIAMOND_SWORD                                 # 【必填】物品的基础材质
  displayname: "<aqua>水晶剑"                              # 【必填】物品的显示名称
  Mechanics:
    durability:
      value: 5000                                          # 【必填】自定义耐久度数值
                                                           #   基于基础材质，例如钻石剑默认耐久度为 1561
                                                           #   设置 5000 后约为原版耐久度的 3.2 倍
                                                           #   有效范围：1 ~ 100000
```

### 参数详解

| 参数 | 类型 | 默认值 | 有效范围 | 必填 | 说明 |
|------|------|--------|----------|------|------|
| `value` | 整数 | - | `1` ~ `100000` | **是** | 物品的自定义耐久度值 |

### 工作方式

- 物品显示原版耐久度数字不变，但实际耐久度按 `(自定义值 / 原版值)` 的倍数缩放
- 举例：钻石剑原版耐久度 1561，自定义 5000。每消耗 1 点显示耐久度，实际消耗 1561/5000 = 0.31 点真实耐久
- 物品上的耐久条百分比会正确更新

### 与 repair 机制的配合

修复机制支持两种方式修复耐久度物品：

```yaml
Mechanics:
  repair:
    ratio: 0.10        # 按百分比修复（0.10 = 修复 10% 最大耐久度）
    fixed_amount: 10   # 或按固定点数修复（修复 10 点耐久度）
```

> **注意：** `ratio` 和 `fixed_amount` 二选一，不能同时使用。

## 自定义食物 (food)

### 概述

允许你为任何食物物品设置自定义的饥饿值、饱和度、食用后替换物品以及药水效果。这意味着你可以创建恢复不同饥饿值和饱和度的食物，并在食用后赋予各种效果。

> **版本说明：** 在 Minecraft 1.20.5+ 上，建议改用新的 Food Component。

### 完整 YAML 配置

```yaml
# ============================================================
# 物品配置示例：自定义食物
# ============================================================
magic_apple:
  material: APPLE                                         # 【必填】物品的基础材质
  displayname: "<gold>魔法苹果"                             # 【必填】物品的显示名称
  lore:                                                    # 【可选】物品的描述文字
    - "<gray>恢复大量饥饿值"
    - "<gray>食用后获得增益效果"
  Mechanics:
    food:
      hunger: 10                                           # 【可选】恢复的饥饿值（默认：4）
                                                           #   10 等于 5 个鸡腿图标
                                                           #   有效范围：0 ~ 20
      saturation: 10                                       # 【可选】恢复的饱和度（默认：2.4）
                                                           #   有效范围：0.0 ~ 20.0
      replacement:                                         # 【可选】食用后的替换物品配置
        oraxen_item: any_oraxen_itemid                    #   Oraxen 物品 ID（三选一）
        # minecraft_type: BOWL                            #   或原版物品类型（三选一）
        # crucible_item: some_crucible_item               #   或 Crucible 物品 ID（三选一）
      effect_probability: 0.35                             # 【可选】每个药水效果的应用概率（默认：1.0）
                                                           #   0.35 = 35% 概率触发效果
                                                           #   有效范围：0.0 ~ 1.0
      effects:                                             # 【可选】食物提供的药水效果
        hunger:                                            #   效果名称必须是有效的药水效果类型
                                                           #   参阅：https://hub.spigotmc.org/javadocs/bukkit/org/bukkit/potion/PotionEffectType.html
          amplifier: 1                                     #   【可选】效果等级（默认：0 = 等级 1）
                                                           #     有效范围：0 ~ 255
          duration: 20                                     #   【可选】效果持续时间，以秒为单位（默认：1）
                                                           #     有效范围：1 ~ 3600
          is_ambient: true                                 #   【可选】是否为环境效果（默认：true）
                                                           #     环境效果粒子更透明
          has_particles: true                              #   【可选】是否显示粒子（默认：true）
          has_icon: true                                   #   【可选】是否显示图标（默认：true）
        night_vision:                                      #   可以添加多个效果
          duration: 60
          amplifier: 0
```

### 参数详解

| 参数 | 类型 | 默认值 | 有效范围 | 必填 | 说明 |
|------|------|--------|----------|------|------|
| `hunger` | 整数 | `4` | `0` ~ `20` | 否 | 食物恢复的饥饿值。1 = 半个鸡腿图标 |
| `saturation` | 小数 | `2.4` | `0.0` ~ `20.0` | 否 | 食物恢复的饱和度 |
| `replacement.oraxen_item` | 字符串 | 无 | 有效的 Oraxen 物品 ID | 否 | 食用后替换为该 Oraxen 物品 |
| `replacement.minecraft_type` | 字符串 | 无 | 有效的原版物品类型 | 否 | 食用后替换为该原版物品（如 BOWL） |
| `replacement.crucible_item` | 字符串 | 无 | 有效的 Crucible 物品 ID | 否 | 食用后替换为该 Crucible 物品 |
| `effect_probability` | 小数 | `1.0` | `0.0` ~ `1.0` | 否 | 所有效果应用的全局概率 |
| `effects.<type>.amplifier` | 整数 | `0` | `0` ~ `255` | 否 | 药水效果等级（0 = 等级 1） |
| `effects.<type>.duration` | 整数 | `1` | `1` ~ `3600` | 否 | 效果持续时间（秒） |
| `effects.<type>.is_ambient` | 布尔 | `true` | `true` / `false` | 否 | 是否为环境效果（粒子更半透明） |
| `effects.<type>.has_particles` | 布尔 | `true` | `true` / `false` | 否 | 是否显示粒子效果 |
| `effects.<type>.has_icon` | 布尔 | `true` | `true` / `false` | 否 | 是否在画面右上角显示效果图标 |

### 工作流程

1. **手持食物**：玩家手持带有 food 机制的食物物品
2. **食用**：按住右键食用
3. **恢复**：恢复设定的饥饿值和饱和度
4. **效果**：根据 `effect_probability` 概率施加药水效果
5. **替换**：如果有 `replacement` 配置，食用后物品变为替换物品

## 背包 (backpack)

### 概述

允许你将任何物品变成一个可打开的功能性背包，提供便携式存储空间。

> **已知问题：** 如果背包使用可堆叠材质（如纸），可能存在物品复制漏洞。强烈建议将背包物品设为不可堆叠。

### 完整 YAML 配置

```yaml
# ============================================================
# 物品配置示例：背包
# ============================================================
backpack:
  material: PAPER                                          # 【必填】物品的基础材质
  displayname: "<red>旅行背包"                              # 【必填】物品的显示名称
  unstackable: true                                        # 【强烈推荐】设为 true 防止堆叠复制漏洞
  lore:                                                    # 【可选】物品的描述文字
    - "<gray>右键打开便携存储"
    - "<gray>共 4 行存储空间"
  Mechanics:
    backpack:
      rows: 4                                              # 【可选】背包 GUI 的行数（默认：3）
                                                           #   每行 9 格，4 行 = 36 格
                                                           #   有效范围：1 ~ 6
      title: "<red>旅行背包"                                # 【可选】背包 GUI 标题（默认："Backpack"）
                                                           #   支持 MiniMessage 格式
      open_sound: "entity.shulker.open"                   # 【可选】打开背包时播放的声音（默认："entity.shulker.open"）
                                                           #   可设为空字符串 "" 禁用
      close_sound: "entity.shulker.close"                 # 【可选】关闭背包时播放的声音（默认："entity.shulker.close"）
                                                           #   可设为空字符串 "" 禁用
```

### 参数详解

| 参数 | 类型 | 默认值 | 有效范围 | 必填 | 说明 |
|------|------|--------|----------|------|------|
| `rows` | 整数 | `3` | `1` ~ `6` | 否 | 背包 GUI 的行数，每行 9 格 |
| `title` | 字符串 | `Backpack` | 任意文本（支持 MiniMessage） | 否 | 背包界面的标题 |
| `open_sound` | 字符串 | `entity.shulker.open` | 有效的声音 ID 或空字符串 | 否 | 打开背包时播放的声音 |
| `close_sound` | 字符串 | `entity.shulker.close` | 有效的声音 ID 或空字符串 | 否 | 关闭背包时播放的声音 |

> **重要：** `unstackable: true` 必须在物品根级别设置（而非 Mechanics 内），以防止潜影盒复制漏洞。

### 工作流程

1. **手持背包**：玩家手持带有 backpack 机制的物品
2. **右键打开**：右键打开便携存储界面
3. **存取物品**：在 GUI 中存取物品
4. **关闭**：关闭 GUI，物品安全保存在背包中

## 音乐唱片 (music_disc)

### 概述

允许你制作带有自定义声音的自定义音乐唱片。需要在 `sound.yml` 中预先定义声音，然后在物品中引用。

> **版本说明：** 在 Minecraft 1.21+ 上，建议改用新的 JukeboxPlayable Component。

> **声音格式：** 任何立体声声音不会在特定位置或跟随实体播放。如需指定位置播放，确保 .ogg 文件为单声道格式。

### 完整 YAML 配置

#### 步骤 1：在 sound.yml 中定义声音

```yaml
# ============================================================
# Oraxen/sound.yml 中的声音定义
# ============================================================
sounds:
  my_music_disc_song.mysong:                               # 声音 ID（命名空间:名称）
    category: record                                       # 声音类别，唱片必须为 "record"
    sound: mysong.ogg                                      # 声音文件名（位于 Oraxen/sounds/ 目录）
```

#### 步骤 2：在物品配置中引用

```yaml
# ============================================================
# 物品配置示例：音乐唱片
# ============================================================
custom_disc:
  material: MUSIC_DISC_13                                  # 【必填】物品的基础材质
  displayname: "<purple>自定义唱片"                         # 【必填】物品的显示名称
  Mechanics:
    music_disc:
      song: "minecraft:my_music_disc_song.mysong"          # 【必填】sound.yml 中定义的声音 ID
                                                           #   格式：<命名空间>:<声音名称>
                                                           #   默认命名空间为 "minecraft"
```

### 参数详解

| 参数 | 类型 | 默认值 | 有效范围 | 必填 | 说明 |
|------|------|--------|----------|------|------|
| `song` | 字符串 | - | sound.yml 中定义的有效声音 ID | **是** | 唱片播放的声音标识符，格式为 `namespace:sound_name` |

### 工作流程

1. **准备音频**：将 .ogg 文件放入 `Oraxen/sounds/` 目录
2. **定义声音**：在 `sound.yml` 中注册声音
3. **插入唱片机**：将自定义唱片插入唱片机
4. **播放**：唱片机播放自定义音乐

## 效率 (efficiency)

### 概述

在手持物品时给予玩家挖掘速度加成（急迫效果）。使用负值则变为挖掘疲劳减速效果。

### 完整 YAML 配置

```yaml
# ============================================================
# 物品配置示例：效率工具
# ============================================================
super_pickaxe:
  material: NETHERITE_PICKAXE                             # 【必填】物品的基础材质
  displayname: "<gold>超级镐"                               # 【必填】物品的显示名称
  lore:                                                    # 【可选】物品的描述文字
    - "<gray>手持时获得急迫 III 效果"
  Mechanics:
    efficiency:
      amount: 2                                            # 【可选】急迫效果等级（默认：1）
                                                           #   2 = 急迫 III（0=等级I, 1=等级II, 2=等级III）
                                                           #   有效范围：-255 ~ 255
                                                           #   负值 = 挖掘疲劳（-1 = 挖掘疲劳 I）
```

### 参数详解

| 参数 | 类型 | 默认值 | 有效范围 | 必填 | 说明 |
|------|------|--------|----------|------|------|
| `amount` | 整数 | `1` | `-255` ~ `255` | 否 | 急迫效果等级。正值=加速，负值=减速。`0` = 急迫I，`-1` = 挖掘疲劳I |

### 工作流程

1. **手持工具**：玩家手持带有效率机制的物品
2. **持续效果**：手持期间持续获得急迫（或反之挖掘疲劳）效果
3. **切换物品**：切换到其他物品后效果移除

## 消耗品 (consumable)

### 概述

使物品在右键时被消耗，物品数量减少 1。通常与 `consumable_potion_effects` 结合使用以创建类似药水的消耗品。

### 完整 YAML 配置

```yaml
# ============================================================
# 物品配置示例：消耗品
# ============================================================
magic_potion:
  material: POTION                                         # 【必填】物品的基础材质
  displayname: "<light_purple>魔法药水"                     # 【必填】物品的显示名称
  lore:                                                    # 【可选】物品的描述文字
    - "<gray>右键使用，获得临时增益"
  Mechanics:
    consumable: {}                                         # 【必填】空对象，声明此物品为消耗品
                                                           #   使用时物品数量减 1
```

### 参数详解

消耗品机制本身不需要参数，只需声明 `consumable: {}` 即可。使用时物品堆叠数量减少 1。

## 消耗品药水效果 (consumable_potion_effects)

### 概述

在物品被消耗时应用药水效果。通常与 `consumable` 机制结合使用。

### 完整 YAML 配置

```yaml
# ============================================================
# 物品配置示例：消耗品 + 药水效果
# ============================================================
speed_elixir:
  material: POTION                                         # 【必填】物品的基础材质
  displayname: "<aqua>速度灵药"                             # 【必填】物品的显示名称
  lore:                                                    # 【可选】物品的描述文字
    - "<gray>使用后获得 30 秒加速效果"
  Mechanics:
    consumable: {}                                         # 【必填】声明为消耗品
    consumable_potion_effects:                             # 【可选】消耗时应用的药水效果
      speed:                                               #   效果名称（必须是有效的药水效果类型）
                                                           #   参阅：https://hub.spigotmc.org/javadocs/bukkit/org/bukkit/potion/PotionEffectType.html
        amplifier: 1                                       #   【可选】效果等级（默认：0 = 等级 1）
                                                           #     有效范围：0 ~ 255
        duration: 600                                      #   【可选】持续时间，以刻为单位（默认：200）
                                                           #     600 刻 = 30 秒，20 刻 = 1 秒
                                                           #     有效范围：1 ~ 72000
        ambient: false                                     #   【可选】是否为环境效果（默认：false）
        particles: true                                    #   【可选】是否显示粒子（默认：true）
        icon: true                                         #   【可选】是否显示图标（默认：true）
      regeneration:                                        #   可以添加多个效果
        amplifier: 0
        duration: 200
```

### 参数详解

| 参数 | 类型 | 默认值 | 有效范围 | 必填 | 说明 |
|------|------|--------|----------|------|------|
| `<效果类型>.amplifier` | 整数 | `0` | `0` ~ `255` | 否 | 效果等级。0=等级I, 1=等级II, 以此类推 |
| `<效果类型>.duration` | 整数 | `200` | `1` ~ `72000` | 否 | 持续时间（刻）。20 刻 = 1 秒 |
| `<效果类型>.ambient` | 布尔 | `false` | `true` / `false` | 否 | 是否为环境效果（半透明粒子） |
| `<效果类型>.particles` | 布尔 | `true` | `true` / `false` | 否 | 是否显示粒子效果 |
| `<效果类型>.icon` | 布尔 | `true` | `true` / `false` | 否 | 是否显示效果图标 |

## 修复 (repair)

### 概述

允许你使用一个物品来修复另一个物品（支持原版耐久度和 Oraxen 自定义耐久度）。使用时只需手持修复物品，左键点击需要修复的物品即可。

### 完整 YAML 配置

```yaml
# ============================================================
# 物品配置示例：修复工具
# ============================================================
repair_kit:
  material: IRON_INGOT                                     # 【必填】物品的基础材质
  displayname: "<green>修复套件"                            # 【必填】物品的显示名称
  lore:                                                    # 【可选】物品的描述文字
    - "<gray>左键点击物品来修复它"
    - "<gray>修复 10% 的耐久度"
  Mechanics:
    repair:
      ratio: 0.10                                          # 【可选】按百分比修复（默认：无）
                                                           #   0.10 = 修复 10% 的最大耐久度
                                                           #   1.0 = 修复到 100%
                                                           #   有效范围：0.0 ~ 1.0
      fixed_amount: 10                                     # 【可选】按固定点数修复（默认：无）
                                                           #   修复 10 点耐久度
                                                           #   有效范围：1 ~ 100000
```

> **注意：** `ratio` 和 `fixed_amount` 二选一，不能在同一物品上同时使用。

### 参数详解

| 参数 | 类型 | 默认值 | 有效范围 | 必填 | 说明 |
|------|------|--------|----------|------|------|
| `ratio` | 小数 | 无 | `0.0` ~ `1.0` | 二选一 | 按最大耐久度的百分比修复。`0.15`=修复15%，`1.0`=修复到100% |
| `fixed_amount` | 整数 | 无 | `1` ~ `100000` | 二选一 | 按固定耐久度点数修复 |

### 全局配置（mechanics.yml）

```yaml
repair:
  enabled: true                                            # 是否全局启用修复机制
  oraxen_durability_only: false                            # 【可选】是否仅修复带有 Oraxen 耐久度机制的物品（默认：false）
                                                           #   true = 仅修复 Oraxen 自定义耐久度物品
                                                           #   false = 也可修复原版物品
```

### 工作流程

1. **手持修复物品**：玩家手持带有 repair 机制的物品
2. **点击目标**：左键点击需要修复的物品
3. **耐久恢复**：目标物品恢复相应比例或固定点数的耐久度
4. **消耗修复物品**：修复物品消耗 1 个

## 命令 (commands)

### 概述

允许你在使用物品时执行命令（以控制台、玩家或 OP 玩家身份）。可配置冷却时间、权限检查和使用次数。

### 完整 YAML 配置

```yaml
# ============================================================
# 物品配置示例：命令执行物品
# ============================================================
command_stick:
  material: STICK                                          # 【必填】物品的基础材质
  displayname: "<yellow>命令棒"                             # 【必填】物品的显示名称
  lore:                                                    # 【可选】物品的描述文字
    - "<gray>右键执行特殊命令"
  Mechanics:
    commands:
      cooldown: 5                                          # 【可选】冷却时间，以秒为单位（默认：0）
                                                           #   5 = 5 秒冷却
                                                           #   有效范围：0 ~ 3600
      permission: "my.awesome.perm"                        # 【可选】使用所需的权限节点（默认：无）
                                                           #   无权限的玩家无法使用
      one_usage: true                                      # 【可选】使用后是否消耗物品（默认：false）
                                                           #   true = 使用 1 次后物品消失
      console:                                             # 【可选】以控制台身份执行的命令列表
        - "kill %p%"                                       #   %p% 会被替换为玩家名称
        - "say %p% 使用了神秘物品"
      player:                                              # 【可选】以玩家身份执行的命令列表
        - "spawn"                                          #   玩家以其自身身份执行
      opped_player:                                        # 【可选】以临时 OP 身份执行的命令列表
        - "give %p% diamond_sword 1"                       #   用于需要 OP 权限的命令
```

### 参数详解

| 参数 | 类型 | 默认值 | 有效范围 | 必填 | 说明 |
|------|------|--------|----------|------|------|
| `cooldown` | 整数 | `0` | `0` ~ `3600` | 否 | 冷却时间（秒） |
| `permission` | 字符串 | 无 | 有效的权限节点 | 否 | 使用物品所需的权限。无权限玩家无法触发命令 |
| `one_usage` | 布尔 | `false` | `true` / `false` | 否 | 使用后物品是否减少 1 个 |
| `console` | 字符串列表 | `[]` | 有效的命令列表 | 否 | 以控制台身份执行的命令。`%p%` 为玩家名占位符 |
| `player` | 字符串列表 | `[]` | 有效的命令列表 | 否 | 以玩家自身身份执行的命令 |
| `opped_player` | 字符串列表 | `[]` | 有效的命令列表 | 否 | 以 OP 身份执行的命令（用于需要 OP 权限的命令） |

### 工作流程

1. **权限检查**（可选）：如果设置了 `permission`，检查玩家是否有该权限
2. **冷却检查**（可选）：如果设置了 `cooldown`，检查是否在冷却中
3. **执行命令**：
   - `console` 命令以控制台身份执行
   - `player` 命令以玩家身份执行
   - `opped_player` 命令以临时 OP 身份执行
4. **物品消耗**（可选）：如果 `one_usage: true`，物品消耗 1 个

## 护甲效果 (armor_effects)

### 概述

允许你将药水效果绑定到护甲（或帽子）上。装备护甲时自动获得效果，卸下后效果移除。支持要求穿戴完整套装才激活效果。

### 完整 YAML 配置

```yaml
# ============================================================
# 物品配置示例：护甲效果
# ============================================================
speed_boots:
  material: DIAMOND_BOOTS                                  # 【必填】物品的基础材质
  displayname: "<aqua>速度之靴"                             # 【必填】物品的显示名称
  lore:                                                    # 【可选】物品的描述文字
    - "<gray>装备时获得速度效果"
  Mechanics:
    armor_effects:
      speed:                                               # 药水效果类型
                                                           # 参阅：https://hub.spigotmc.org/javadocs/bukkit/org/bukkit/potion/PotionEffectType.html
        duration: 10                                       #   【可选】效果持续时间，以刻为单位（默认：无）
                                                           #     如果设置，效果会每 duration 刻刷新一次
        amplifier: 0                                       #   【可选】效果等级（默认：0 = 等级 1）
                                                           #     有效范围：0 ~ 255
        ambient: true                                      #   【可选】是否为环境效果（默认：true）
                                                           #     true = 粒子更半透明
        particles: true                                    #   【可选】是否显示粒子（默认：true）
        icon: true                                         #   【可选】是否显示图标（默认：true）

# ============================================================
# 套装效果示例：需要穿戴完整套装才生效
# ============================================================
full_set_chestplate:
  material: DIAMOND_CHESTPLATE
  displayname: "<red>套装胸甲"
  Mechanics:
    armor_effects:
      strength:                                            # 力量效果
        requires_full_set: true                            # 【可选】是否需要穿戴完整套装（默认：false）
                                                           #   true = 只有四件护甲都带有此效果的套装时生效
                                                           #   false = 单件即可生效
        amplifier: 1
```

### 参数详解

| 参数 | 类型 | 默认值 | 有效范围 | 必填 | 说明 |
|------|------|--------|----------|------|------|
| `<效果类型>.duration` | 整数 | 无 | `1` ~ `72000` | 否 | 效果持续时间（刻）。较大的值可减少服务器性能消耗 |
| `<效果类型>.amplifier` | 整数 | `0` | `0` ~ `255` | 否 | 效果等级 |
| `<效果类型>.ambient` | 布尔 | `true` | `true` / `false` | 否 | 是否为环境效果 |
| `<效果类型>.particles` | 布尔 | `true` | `true` / `false` | 否 | 是否显示粒子 |
| `<效果类型>.icon` | 布尔 | `true` | `true` / `false` | 否 | 是否显示图标 |
| `requires_full_set` | 布尔 | `false` | `true` / `false` | 否 | 是否要求全套护甲都带有相同效果类型才生效 |

### 工作流程

1. **装备护甲**：玩家装备带有 armor_effects 的护甲
2. **自动应用**：装备时自动施加药水效果
3. **持续刷新**：效果根据全局 `delay_in_ticks` 设置周期性刷新
4. **卸下移除**：卸下护甲后效果被移除

### 全局配置（mechanics.yml）

```yaml
armor_effects:
  enabled: true                                            # 是否全局启用护甲效果
  delay_in_ticks: 20                                       # 检查并刷新护甲效果的间隔（刻）（默认：20 = 1秒）
```

## 切换灯光 (toggle_light)

### 概述

为家具、音符盒和绊线钩方块创建交互式灯光系统。玩家右键点击物品在两种灯光等级之间切换，实现开灯和关灯功能。灯光状态在服务器重启后持久保存。

### 特性

- 支持静态基础灯光和可切换灯光
- 灯光状态在服务器重启后持久化
- 与现有家具机制无缝集成（屏障、存储、座位、旋转）
- 对于带屏障的家具：灯光在家具结构中的所有屏障方块之间切换

### 完整 YAML 配置

```yaml
# ============================================================
# 物品配置示例：切换灯光
# ============================================================
modern_lamp:
  material: PAPER                                          # 【必填】物品的基础材质
  displayname: "<yellow>现代灯具"                           # 【必填】物品的显示名称
  lore:                                                    # 【可选】物品的描述文字
    - "<gray>右键切换灯光"
  Mechanics:
    toggle_light:
      light: 5                                             # 【必填】基础灯光等级，始终激活（默认状态）
                                                           #   有效范围：0 ~ 15
                                                           #   0 = 无光，15 = 最亮
      toggle_light: 15                                     # 【可选】切换后的灯光等级（默认：无）
                                                           #   设置此项启用可切换灯光
                                                           #   有效范围：0 ~ 15
```

### 参数详解

| 参数 | 类型 | 默认值 | 有效范围 | 必填 | 说明 |
|------|------|--------|----------|------|------|
| `light` | 整数 | `0` | `0` ~ `15` | **是** | 默认灯光等级（0=无光，15=最亮） |
| `toggle_light` | 整数 | 无 | `0` ~ `15` | 否 | 切换后的灯光等级。设置此项才启用切换功能 |

### 工作流程

1. **放置**：放置带有 toggle_light 机制的家具/方块
2. **默认状态**：初始以 `light` 设定的灯光等级发光
3. **右键切换**：玩家右键方块，灯光等级切换到 `toggle_light` 设定的值
4. **再次切换**：再次右键，灯光等级切回 `light` 值
5. **持久化**：灯光状态在服务器重启后保持不变

```yaml
super_material_item:
  material: IRON_INGOT                                     # 【必填】物品的基础材质
  displayname: "<blue>超级材料"                             # 【必填】物品的显示名称
  Mechanics:
    itemtype:
      value: SUPER_MATERIAL                                # 【必填】自定义物品类型名称
                                                           #   必须在方块机制的全局配置中声明
```

### 参数详解

| 参数 | 类型 | 默认值 | 有效范围 | 必填 | 说明 |
|------|------|--------|----------|------|------|
| `value` | 字符串 | - | 在方块机制全局配置中声明的类型名 | **是** | 自定义物品类型名称 |

```yaml
consumable_potion_effects:

  enabled: true

itemtype:
  enabled: true

soulbound:
  enabled: true

  enabled: true

music_disc:
  enabled: true

  enabled: true
```
