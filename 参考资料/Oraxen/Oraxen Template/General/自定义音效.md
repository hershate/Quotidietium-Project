# Oraxen 自定义音效 (Sounds) 配置模板

> 通过 `sound.yml` 文件注册自定义音效、配置唱片机歌曲、替换原版音效。
> 音效文件必须为 OGG Vorbis (`.ogg`) 格式。
>
> **配置文件位置：** `plugins/Oraxen/sound.yml`
>
> **音效文件位置：** `plugins/Oraxen/pack/sounds/` —— 在此目录下放置所有 `.ogg` 文件（可创建子目录）

---

## 一、sound.yml 基础结构

```yaml
# ============================================================
# 文件: plugins/Oraxen/sound.yml
# ============================================================

settings:                               # 【可选】全局设置
  automatically_generate: true          # 【可选】自动为资源包生成 sounds.json，默认 true

sounds:                                 # 【必填】音效定义区域
  # 在此处添加音效配置（见下方各示例）
```

---

## 二、单个音效的完整配置

```yaml
# ============================================================
# 音效配置模板 — 所有可用字段
# ============================================================

sounds:
  my_custom_sound:                      # 【必填】音效 ID，全局唯一标识符
    category: block                     # 【必填】音效类别（控制音量滑块归属）
    sound: custom/my_sound.ogg          # 【必填】音效文件路径，相对于 pack/sounds/（扩展名可选）
    stream: false                       # 【可选】是否流式播放，默认 false（推荐长音乐设为 true）
    subtitle: "自定义音效"               # 【可选】游戏中启用字幕后显示的文本
    replace: false                      # 【可选】是否替换原版音效，默认 false
    jukebox_song:                       # 【可选】唱片机歌曲元数据（仅唱片机音乐需要）
      description: "歌曲描述"            # 【可选】物品提示中显示的歌曲标题
      length_in_seconds: 120            # 【可选】歌曲持续时间（用于停止播放）
      comparator_output: 15             # 【可选】播放时的红石比较器信号强度 (1-15)
```

### 配置项详解

| 配置项 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| `category` | 字符串 | **是** | — | 决定音效受哪个音量滑块控制 |
| `sound` | 字符串 | **是** | — | 音效文件路径（.ogg），相对于 `pack/sounds/` |
| `stream` | 布尔 | 否 | `false` | 是否流式播放，长音乐推荐 true |
| `subtitle` | 字符串 | 否 | — | 游戏字幕文本（需玩家启用字幕功能） |
| `replace` | 布尔 | 否 | `false` | 设为 true 将替换同名的原版音效 |
| `jukebox_song` | 映射 | 否 | — | 唱片机歌曲额外元数据 |

## 三、音效类别（category）

> 音效类别决定音效受游戏中哪个音量滑块控制。

```yaml
# 有效类别及其对应的音量滑块:
category: master          # 主音量滑块
category: music           # 音乐和唱片机音量（推荐用于唱片机歌曲）
category: record          # music 的别名（用于唱片机歌曲）
category: weather         # 天气音效
category: block           # 方块破坏/放置音效
category: hostile         # 敌对生物音效
category: neutral         # 中立生物音效
category: player          # 玩家音效（脚步声、受伤等）
category: ambient         # 环境音效
category: voice           # 语音/说话音效
```

## 五、唱片机歌曲

> 创建在唱片机中播放自定义歌曲的音乐唱片。需要同时配置音效和对应的物品。

### 5.1 歌曲音效配置

```yaml
# ============================================================
# 唱片机歌曲 — 完整的音乐配置
# ============================================================

sounds:
  welcome_song:
    category: records                   # 唱片机歌曲使用 records 或 music 类别
    sound: music/welcome.ogg            # 音乐文件路径
    stream: true                        # 【推荐】音乐必须使用流式播放
    subtitle: "欢迎曲"
    jukebox_song:                       # 【必填】唱片机歌曲元数据
      description:                      # 【可选】物品悬停提示中显示的歌曲信息
        - text: "Oraxen - 欢迎"         # 第一行
          color: "gray"                 # 颜色（MiniMessage 颜色名）
          italic: false
        - text: "服务器主题曲"          # 第二行
          color: "dark_gray"
          italic: true
      length_in_seconds: 180            # 【必填】歌曲总长度（秒），用于控制何时停止
      comparator_output: 15             # 【可选】红石比较器输出信号强度 (1-15)，默认 15

  boss_theme:
    category: records
    sound: music/boss_theme.ogg
    stream: true
    subtitle: "Boss 战斗主题曲"
    jukebox_song:
      description:
        - text: "Boss Theme"
          color: "gold"
          italic: false
        - text: "By Zurker"
          color: "gray"
      length_in_seconds: 240
      comparator_output: 15
```

### 5.2 对应的音乐唱片物品配置

```yaml
# ============================================================
# 文件: plugins/Oraxen/items/music_discs.yml
# ============================================================

welcome_disk:
  displayname: "<gradient:#9055FF:#13E2DA>欢迎唱片</gradient>"
  material: MUSIC_DISC_13               # 使用任意音乐唱片材质
  ItemFlags:
    - HIDE_ADDITIONAL_TOOLTIP           # 隐藏原版附加提示
  Components:                           # 1.21+ 物品组件
    jukebox_playable:                   # 【必填】唱片机可播放组件
      show_in_tooltip: true             # 是否在物品提示中显示歌曲信息
      song_key: "oraxen:welcome_song"   # 【必填】对应音效的命名空间键 (oraxen:<音效ID>)
  Pack:
    generate_model: true
    parent_model: "item/handheld"
    textures:
      - default/welcome_disk.png        # 唱片纹理文件

boss_disk:
  displayname: "<gradient:#FF0000:#FF5500>Boss 唱片</gradient>"
  material: MUSIC_DISC_CAT

    - HIDE_ADDITIONAL_TOOLTIP
  Components:
    jukebox_playable:
      show_in_tooltip: true
      song_key: "oraxen:boss_theme"
  Pack:
    generate_model: true
    parent_model: "item/handheld"
    textures:
      - default/boss_disk.png
```

## 六、替换原版音效

> 使用 `replace: true` 覆盖 Minecraft 默认音效。

```yaml
# ============================================================
# 常见原版音效替换
# ============================================================

sounds:
  # --- 自定义木头音效组 ---
  wood_break:
    category: block
    sound: blocks/wood/break.ogg
    replace: true                       # 替换原版木头破坏音效
    subtitle: "方块被破坏"

  wood_step:
    category: block
    sound: blocks/wood/step.ogg
    replace: true

  wood_place:
    category: block
    sound: blocks/wood/place.ogg
    replace: true
    subtitle: "方块被放置"

  # --- 自定义石头音效 ---
  stone_break:
    category: block
    sound: blocks/stone/break.ogg
    replace: true
    subtitle: "方块被破坏"

  stone_step:
    category: block
    sound: blocks/stone/step.ogg
    replace: true

  # --- 自定义方块必选音效组（required.* 前缀）---
  # required. 前缀告诉 Oraxen 这些是必选的音效映射
  required.wood.break:
    category: block
    sound: block/wood/break.ogg
    replace: true

  required.wood.step:
    category: block
    sound: block/wood/step.ogg
    replace: true

  required.wood.place:
    category: block
    sound: block/wood/place.ogg
    replace: true
```

## 七、将音效应用到自定义方块

> 在自定义方块的配置中引用已注册的音效。

```yaml
# ============================================================
# 文件: plugins/Oraxen/blocks/<your_block>.yml
# ============================================================

my_custom_block:
  displayname: "<green>自定义方块"
  material: NOTE_BLOCK
  # ... 其他方块属性 ...
  sounds:                               # 【可选】方块音效配置
    break: oraxen:crystal_break          # 方块被破坏时的音效
    place: oraxen:crystal_place          # 方块被放置时的音效
    step: oraxen:crystal_step            # 行走在方块上的脚步声
    hit: oraxen:crystal_break            # 敲击方块时的音效
    fall: oraxen:crystal_step            # 掉落在方块上的音效
```

## 八、在物品机制中使用音效

### 8.1 物品使用时播放

```yaml
# ============================================================
# 文件: plugins/Oraxen/items/magic_items.yml
# ============================================================

magic_wand:
  displayname: "<gradient:#AA00FF:#FF00AA>魔法杖</gradient>"
  material: STICK
  Pack:
    generate_model: true
    parent_model: "item/handheld"
    textures:
      - custom/magic_wand
  Mechanics:
    custom:
      on_use:
        event: CLICK:right:all          # 右键点击触发
        actions:
          sound:                        # 播放音效动作
            name: oraxen:magical_hum    # 音效命名空间键
            volume: 1.0                 # 音量 (0.0 - 1.0)
            pitch: 1.0                  # 音调 (0.5 = 低八度, 2.0 = 高八度)

  magic_sword:
    displayname: "<gradient:#FF0000:#FF5500>火焰剑</gradient>"
    material: IRON_SWORD
    Pack:
      generate_model: true
      parent_model: "item/handheld"
      textures:
        - custom/magic_sword
    Mechanics:
      custom:
        on_kill:
          event: KILL:player            # 击杀玩家时触发
          actions:
            sound:
              name: oraxen:victory_fanfare
              volume: 0.8
              pitch: 1.2
```

### 8.2 多个音效随机播放

```yaml

# 例如，在 Skript 或自定义插件中:
#   随机选择 footstep_1 / footstep_2 / footstep_3 中的一个播放
```

## 九、音效文件要求

### 格式规范

| 要求 | 说明 |
|------|------|
| **文件格式** | OGG Vorbis (`.ogg`) — 不接受 MP3/WAV/FLAC |
| **声道** | 单声道（Mono）推荐，立体声会自动转换但浪费空间 |
| **采样率** | 推荐 44.1kHz 或 48kHz |
| **比特率（音乐）** | 128-192 kbps |
| **比特率（音效）** | 64-96 kbps |
| **文件名** | 全小写、无空格、无特殊字符 |

### 文件放置结构

```
plugins/Oraxen/pack/sounds/
├── music/
│   ├── welcome.ogg
│   ├── boss_theme.ogg
│   └── ambient/
│       └── magical_hum.ogg
├── blocks/
│   ├── wood/
│   │   ├── break.ogg
│   │   ├── step.ogg
│   │   └── place.ogg
│   ├── stone/
│   │   ├── break.ogg
│   │   └── step.ogg
│   └── crystal/
│       ├── break.ogg
│       └── step.ogg
├── weapons/
│   └── sword_swing.ogg
├── ui/
│   └── menu_click.ogg
└── footsteps/
    ├── step1.ogg
    ├── step2.ogg
    └── step3.ogg
```

### 使用 FFmpeg 转换音频

```bash
# 将 MP3 转换为 OGG（单声道，128kbps 用于音乐）
ffmpeg -i input.mp3 -ac 1 -b:a 128k output.ogg

# 将 WAV 转换为 OGG（单声道，96kbps 用于音效）
ffmpeg -i input.wav -ac 1 -b:a 96k output.ogg

# 将立体声转换为单声道（减小文件体积）
ffmpeg -i input.ogg -ac 1 -b:a 96k output_mono.ogg

# 裁剪音频前 0.2 秒静音后输出
ffmpeg -i input.wav -ss 0.2 -ac 1 -b:a 96k output.ogg
```

## 十、流式播放 (stream) 选择指南

| 场景 | stream | 原因 |
|------|--------|------|
| 音乐唱片 | `true` | 音乐文件较大，流式播放节省内存 |
| 长环境音效（>10秒） | `true` | 避免一次性加载到内存 |
| 背景音乐 | `true` | 长持续时间的音频 |
| 旁白/对话 | `true` | 可能较长的语音 |
| 短音效（<5秒） | `false`（默认） | 完全加载到内存，播放响应更快 |
| 方块破坏/放置 | `false` | 需要即时响应 |
| UI 音效 | `false` | 短促，需要即时播放 |
| 频繁播放的音效 | `false` | 非流式播放无延迟 |

## 十二、在游戏中使用音效

```
# 使用 /playsound 命令播放音效:
/playsound oraxen:my_custom_sound master @a           # 对所有玩家播放
/playsound oraxen:sword_swing player @p               # 对最近的玩家播放
/playsound oraxen:epic_theme records @a ~ ~ ~ 1.0 1.0 # 指定位置、音量、音调

# 格式: /playsound <命名空间:音效ID> <类别> <目标> [x y z] [音量] [音调]
#   音调: 0.5 = 低八度, 1.0 = 原音, 2.0 = 高八度
#   音量: 0.0 = 无声, 1.0 = 最大, 可超过 1.0（最大 3.0 或更大）
```

## 十三、故障排除

| 问题 | 解决方案 |
|------|---------|
| 音效不播放 | 检查文件格式（必须 .ogg OGG Vorbis），检查文件路径 |
| 声音不完整/卡顿 | 检查比特率和编码，尝试降低比特率 |
| 唱片机歌曲不播放 | 验证 `song_key: "oraxen:<音效ID>"` 与 sound.yml 中的 ID 一致，确保 `stream: true` |
| 音效没有字幕 | 确保定义了 `subtitle` 且玩家启用了字幕（选项 > 辅助功能 > 字幕） |
| 替换原版音效失败 | 确保 `replace: true`，检查控制台是否有警告 |
| 音效音量不对 | 检查 `category` 对应正确的音量滑块，检查玩家音量设置 |
| 重载后不生效 | 执行 `/oraxen reload all`，然后 `/oraxen pack send @a` 重新发送资源包 |
| 客户端听不到 | 让客户端按 `F3 + T` 重新加载资源包 |
| 文件太大 | 降低比特率（音乐 128kbps，音效 64-96kbps），转换立体声为单声道 |
