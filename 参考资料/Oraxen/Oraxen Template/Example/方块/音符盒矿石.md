# 实战示例：音符盒矿石 (NoteBlock Ore)

> 本文件基于项目 `Oraxen/items/blocks.yml` 中的实际配置提取，展示最常用的自定义方块类型——矿石。
> 所有注释以该项目的实际值解释设计意图。

---

## 一、机制选择：为什么用音符盒做矿石？

```
矿石需要完整的方块碰撞箱（玩家无法穿过），音符盒机制是唯三支持此功能的之一。
对比：
  - 音符盒 (NoteBlock)  → 完整碰撞箱，最多 ~800 变体，最适合矿石
  - 绊线   (StringBlock) → 可穿过，最多 127 变体，适合植物花卉
  - 紫颂   (ChorusBlock) → 透明渲染，最多 63 变体，适合树叶/玻璃
结论：矿石属于"实心方块"，用音符盒。
```

---

## 二、全局配置 (mechanics.yml) 先决条件

```yaml
# ============================================================
# plugins/Oraxen/mechanics.yml — 音符盒全局配置
# ============================================================
noteblock:
  enabled: true                              # [必需] 启用机制

  # 允许破坏自定义方块的镐等级
  tool_types:
    - WOODEN                                # 木镐
    - STONE                                 # 石镐
    - IRON                                  # 铁镐
    - GOLDEN                                # 金镐
    - DIAMOND                               # 钻石镐
    - NETHERITE                             # 下界合金镐

  # 农场方块干燥检查间隔 (20刻=1秒)
  # 本项目暂未使用农场方块，此值预留
  farmblock_check_delay: 1000               # 每1000刻(50秒)检查一次

  # 是否移除 mineable/axe 标签
  # true = 斧头无法快速挖掘你的自定义"石头"类方块
  remove_mineable_tag: false                # 本项目保持false
```

## 三、示例1：紫水晶矿石 (block/cube_all 父模型)

从 `blocks.yml` 中 `amethyst_ore` 提取，展示了 `生成模型 + 父模型` 的自动化流程。

```yaml
# ============================================================
# 紫水晶矿石 — 使用 block/cube_all 父模型（6面相同纹理）
# ============================================================
amethyst_ore:
  # ---- 基础信息 ----
  # [必需] 物品显示名称，使用 MiniMessage 渐变格式
  # <gradient:起始色:结束色>文字</gradient>
  itemname: <gradient:#4B36B1:#6699FF>Amethyst Ore

  # [必需] 基础材质。方块类物品一律用 PAPER（避免占用原版方块材质）
  # 为什么用 PAPER？因为 PAPER 不是方块，不会与任何原版交互冲突
  material: PAPER

  # ---- 资源包/模型配置 ----
  Pack:
    # [必需] 启用自动模型生成。true = Oraxen 根据 parent_model 自动生成 JSON 模型
    generate_model: true

    # [必需] 父模型类型，决定方块的形状和纹理映射
    # block/cube_all = 所有6个面使用同一纹理（只需要1个纹理文件）
    # 非常适合矿石、金属块、石砖等
    parent_model: block/cube_all

    # [必需] 纹理文件列表（不需要 .png 扩展名）
    # 纹理放在 Oraxen/pack/textures/default/ 目录
    textures:
      - default/amethyst_ore                # 6面都用这个纹理

  # ---- 方块机制配置 ----
  Mechanics:
    noteblock:
      # ========== 方块音效 ==========
      # [可选] 控制方块在各种交互事件中播放的音效
      # 简写格式：直接写音效 ID（音量和音调均为默认1.0）
      block_sounds:
        break_sound: block.stone.break      # 被破坏时 → 石头破碎声
        place_sound: block.stone.place      # 被放置时 → 石头放置声
        # 未设置的 hit/step/fall 使用原版默认音效

      # ========== 核心配置 ==========
      # [必需★] 自定义变体编号，范围 1-800
      # 每个音符盒方块必须唯一！重复会导致渲染冲突
      custom_variation: 1

      # [必需★] 模型引用，与 Pack.generate_model 联动
      # 自动生成时通常等于物品 ID
      model: amethyst_ore

      # ========== 硬度 ==========
      # [可选] 破坏所需时间的倍率（默认1）
      # 实际破坏时间 = hardness * 工具修正 * 附魔修正
      # 参考：石头=3, 铁矿石=5, 黑曜石=50, 基岩=∞
      hardness: 6                            # 比铁矿石略硬

      # ========== 掉落物配置 ==========
      drop:
        # [可选] 是否必须精准采集才能掉落方块本身
        # true = 只有带 Silk Touch 的工具能掉落，否则掉配置的 loots
        # false = 任何工具破坏都能掉落
        silktouch: true                      # 需要精准采集

        # [可选] 是否受时运附魔影响
        # true = 时运 Fortune 附魔会增加掉落物数量
        fortune: true                        # 时运有效

        # [可选] 挖掘所需的最低工具等级
        # 低于此等级的工具破坏方块后不会掉落任何物品
        # 可选值: WOODEN, STONE, IRON, GOLDEN, DIAMOND, NETHERITE
        minimal_type: IRON                   # 至少铁镐

        # [可选] 最适合的挖掘工具类型
        # 使用正确工具类型的挖掘速度会显著加快
        best_tools:
          - PICKAXE                          # 镐是最佳工具

        # [必需] 掉落物列表
        # 每个 loot 条目的概率独立计算
        loots:
          - oraxen_item: amethyst            # 掉落紫水晶物品
            probability: 1.0                 # 100% 几率（必定掉落）
```

### 设计说明

```
紫水晶矿石是"标准矿石模板"，展示了以下设计选择：

1. parent_model: block/cube_all — 6面相同纹理，最省纹理文件的方案
2. hardness: 6 — 比铁矿石(5)硬，比黑曜石(50)软，适合中后期
3. silktouch: true + fortune: true — 标准矿石掉落逻辑
4. minimal_type: IRON — 确保玩家至少需要铁镐，有进度感
5. 只有一个 loot 条目，probability: 1.0 — 简单直接
```

## 四、示例2：红宝石矿石 (fortune 与时运联动)

```yaml
# ============================================================
# 红宝石矿石 — 包含时运幸运掉落
# ============================================================
ruby_ore:
  itemname: <gradient:#FA7CBB:#F14658>Ruby Ore
  material: PAPER
  Pack:
    generate_model: true
    parent_model: block/cube_all            # 同样使用 cube_all
    textures:
      - default/ruby_ore
  Mechanics:
    noteblock:
      block_sounds:
        break_sound: block.stone.break
        place_sound: block.stone.place
      custom_variation: 2                   # 注意：与紫水晶不同(2 ≠ 1)
      model: ruby_ore
      hardness: 7                           # 比紫水晶(6)更硬
      drop:
        silktouch: true                     # 精准采集
        fortune: true                       # 时运有效
        minimal_type: IRON                  # 最低铁镐
        best_tools:
          - PICKAXE
        loots:
          - oraxen_item: ruby               # 掉落红宝石
            probability: 1.0
```

### fortune: true 的工作原理

```
当 fortune: true 时：
  - 时运 I   → 33% 额外掉落（平均约 1.33 倍）
  - 时运 II  → 75% 额外掉落（平均约 1.75 倍）
  - 时运 III → 120% 额外掉落（平均约 2.20 倍）

具体实现：每次从 original_amount..max_amount 随机取值，
时运附魔会增加随机上限。如果 max_amount 未设置（默认1），
时运会增加概率以获得额外掉落。
```

## 五、示例3：黑曜石矿石 (高硬度 + 仅精准采集)

```yaml
# ============================================================
# 黑曜石矿石 — 高硬度方块示例
# ============================================================
onyx_ore:
  itemname: <#6f737d>Onyx Ore               # 纯色代码（非渐变）
  material: PAPER
  Pack:
    generate_model: true
    parent_model: block/cube_all
    textures:
      - default/onyx_ore
  Mechanics:
    noteblock:
      block_sounds:
        break_sound: block.stone.break
        place_sound: block.stone.place
      custom_variation: 3                   # 每个矿石独有的编号
      model: onyx_ore
      hardness: 8                           # 非常硬，接近黑曜石
      drop:
        silktouch: true                     # 精准采集
        fortune: true                       # 时运有效
        minimal_type: IRON
        best_tools:
          - PICKAXE
        loots:
          - oraxen_item: onyx
            probability: 1.0
```

### hardness 与实际破坏时间的关系

```
破坏时间(秒) = hardness × 1.5 / (工具速度 × 效率附魔修正)

以 onyx_ore (hardness=8) 为例：
  - 铁镐 (速度 6):  8 × 1.5 / 6  = 2.0 秒  (不带效率)
  - 钻石镐 (速度 8): 8 × 1.5 / 8  = 1.5 秒
  - 下界合金镐 (速度 9): 8 × 1.5 / 9 ≈ 1.33 秒
  - 木镐 (< minimal_type): 不掉落，白挖

对比原版：石头=1.5秒, 铁矿石=2.25秒, 黑曜石=9.4秒(用钻石镐)
onyx_ore 破坏时间比铁矿石略短但比石头长，是合理的矿石硬度。
```

## 七、parent_model 选择指南表

```
┌──────────────────────────┬──────────┬──────────────────────────┐
│ parent_model             │ 纹理数   │ 适用场景                 │
├──────────────────────────┼──────────┼──────────────────────────┤
│ block/cube_all           │ 1 个     │ 矿石、金属块、石砖、玻璃 │
│                          │          │ 所有6面相同纹理          │
├──────────────────────────┼──────────┼──────────────────────────┤
│ block/cube_column        │ 2 个     │ 原木、柱子、玄武岩       │
│                          │          │ 纹理1=顶/底，纹理2=侧面  │
├──────────────────────────┼──────────┼──────────────────────────┤
│ block/cross              │ 1 个     │ 花、树苗、草丛、蘑菇     │
│                          │          │ 十字交叉面片             │
├──────────────────────────┼──────────┼──────────────────────────┤
│ block/orientable         │ 3 个     │ 熔炉、侦测器             │
│                          │          │ 纹理1=前，2=侧，3=顶     │
├──────────────────────────┼──────────┼──────────────────────────┤
│ block/orientable_vertical│ 2 个     │ 垂直朝向方块             │
│                          │          │ 纹理1=顶/底，2=侧面      │
└──────────────────────────┴──────────┴──────────────────────────┘

矿石类方块一律选 block/cube_all，因为：
  1. 纹理最简单（只画1张图）
  2. 无方向性（任何朝向都一样）
  3. 与生成世界中的矿物替换最兼容
```

## 九、custom_variation 唯一性要求

```
custom_variation 是音符盒方块的身份标识。范围 1-800。

重要规则：
  1. 每个音符盒方块必须唯一，不能重复
  2. 范围外的值会导致渲染异常
  3. 方向性方块（directional）每个子方块也消耗一个变体
     - LOG 方向: 消耗 3 个变体 (原木 Y/X/Z 朝向)
     - FURNACE 方向: 消耗 4 个变体 (北/南/东/西)
     - DROPPER 方向: 消耗 6 个变体 (全部6面)
  4. 本项目矿石规划:
     caveblock(预留)=0, amethyst_ore=1, ruby_ore=2, onyx_ore=3, orax_ore=4

推荐做法：在项目文档中维护一个 custom_variation 分配表。
```

## 十、block_sounds 音效详解

```yaml
# 简写格式（本项目的选择）：
block_sounds:
  break_sound: block.stone.break    # 破坏音效
  place_sound: block.stone.place    # 放置音效
  hit_sound: block.stone.hit        # 击打音效（正在挖掘时）
  step_sound: block.stone.step      # 行走音效（踩在上面）
  fall_sound: block.stone.fall      # 摔落音效（掉在方块上）
  # volume: 1.0                    # [可选] 全局音量 0.0-1.0
  # pitch: 0.8                     # [可选] 全局音调 0.5-2.0

# 详细格式（逐音效自定义音量和音调）：
# block_sounds:
#   break:
#     sound: block.stone.break
#     volume: 1.0
#     pitch: 0.9
#   place:
#     sound: block.stone.place
#     volume: 0.8
#     pitch: 1.0

# 音效ID参考（完整的原版音效列表见 Minecraft Wiki Sound/IDs）：
# 石头类: block.stone.*
# 木头类: block.wood.*
# 玻璃类: block.glass.*
# 金属类: block.metal.*
# 沙砾类: block.sand.* / block.gravel.*
```

## 十一、矿石模板总结

```
本项目所有矿石的共性：
  - material: PAPER（统一的基础材质）
  - parent_model: block/cube_all（6面相同纹理）
  - block_sounds: block.stone.*（石头音效，与挖掘感一致）
  - silktouch: true（需要精准采集才能获得矿石方块）
  - fortune: true（时运增加矿物掉落）
  - minimal_type: IRON（铁镐起挖）
  - best_tools: [PICKAXE]（镐子最佳）

各矿石的区别仅在于：
  - custom_variation（唯一编号：1/2/3/4）
  - hardness（硬度：6/7/8/8）
  - 掉落物品（amethyst/ruby/onyx/orax）
  - 显示名称颜色

如果你要添加第5种矿石，只需：
  1. 复制任意矿石模板
  2. 改 custom_variation 为 5
  3. 改 itemname 颜色
  4. 改 textures 和 model 为新纹理路径
  5. 改 loots 掉落为新物品
  6. 定制 hardness 即可
```
