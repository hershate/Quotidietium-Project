# 实战示例：形状方块 (ShapedBlock)

> 形状方块机制使用涂蜡铜方块作为基础材质，创建自定义的楼梯、台阶、门、活板门、格栅和灯泡。
> 每种类型最多 4 种自定义变体（各自独立的 1-4 范围）。

---

## 一、机制原理：涂蜡铜的妙用

```
形状方块的工作原理：
  1. 原版涂蜡铜方块（Waxed Copper）有特殊的状态标记
  2. Oraxen 劫持这些涂蜡状态用于自定义方块模型
  3. 原版的涂蜡功能被替换——涂蜡铜方块被转换为带氧化防止标记的普通铜

全局配置 (mechanics.yml) 的核心选项：
  convert_vanilla_waxed: true  → 将原版涂蜡铜转换为普通铜（保留外观但不氧化）
  handle_world_generation: true → 自动处理试炼密室等结构中的涂蜡铜

重要：启用此机制后，玩家无法再制作原版涂蜡铜方块。
如果你需要原版涂蜡铜，禁用此机制或使用其他方块机制替代。
```

---

## 二、全局配置 (mechanics.yml)

```yaml
# ============================================================
# plugins/Oraxen/mechanics.yml — 形状方块全局配置
# ============================================================
shaped_block:
  enabled: true

  tool_types:
    - WOODEN
    - STONE
    - IRON
    - GOLDEN
    - DIAMOND
    - NETHERITE

  # [关键] 将原版涂蜡铜方块转换为带氧化防止标记的普通铜
  # true = 原版涂蜡铜不再可用（推荐，释放状态给自定义方块）
  # false = 原版涂蜡铜保留，但无法用于自定义形状方块
  convert_vanilla_waxed: true

  # [关键] 自动处理世界生成结构中的涂蜡铜（如试炼密室）
  # true = 自然生成的涂蜡铜自动转换
  handle_world_generation: true
```

## 三、六种形状方块类型概览

| 类型 | 基础原版方块 | 变体范围 | 特性 |
|:---|:---|:---:|:---|
| STAIR | 涂蜡铜楼梯 | 1-4 | 方向性、含水、半层 |
| SLAB | 涂蜡铜台阶 | 1-4 | 上半/下半/双层、含水 |
| DOOR | 涂蜡铜门 | 1-4 | 两格高、可开合、红石 |
| TRAPDOOR | 涂蜡铜活板门 | 1-4 | 可开合、红石、含水 |
| GRATE | 涂蜡铜格栅 | 1-4 | 透明裁剪、含水 |
| BULB | 涂蜡铜灯泡 | 1-4 | 可切换光源、红石 |

每种类型的 custom_variation 是独立的 1-4。
例如：你可以有 STAIR 1-4 + SLAB 1-4 = 8 个不同的方块。
总共最多 6×4 = 24 个形状方块。

## 四、示例1：自定义橡木楼梯 (STAIR)

```yaml
# ============================================================
# 自定义橡木楼梯 — 方向性放置 + 含水
# ============================================================
custom_oak_stairs:
  # ---- 基础信息 ----
  itemname: <#8B4513>自定义橡木楼梯
  material: PAPER

  # ---- 资源包/模型配置 ----
  Pack:
    generate_model: true
    parent_model: block/stairs               # 楼梯专用父模型
    textures:
      - default/custom_oak_planks            # 一个纹理覆盖所有面

  # ---- 方块机制配置 ----
  Mechanics:
    shaped_block:
      # [必需★] 类型 STAIR
      type: STAIR

      # [必需★] 变体编号 1-4 (每种类型独立)
      custom_variation: 1

      # [可选] 硬度
      hardness: 2                            # 和木板差不多

      # [可选] 方块音效
      block_sounds:
        break_sound: block.wood.break
        place_sound: block.wood.place
        hit_sound: block.wood.hit
        step_sound: block.wood.step
        fall_sound: block.wood.fall

      # [可选] 掉落物
      drop:
        silktouch: false                     # 不需要精准采集
        minimal_type: WOODEN
        best_tools:
          - AXE                              # 斧头最佳
        loots:
          - oraxen_item: custom_oak_stairs
            probability: 1.0

# 楼梯的行为特性（自动获得，无需配置）：
# - 根据玩家朝向自动旋转
# - 支持含水（可放在水下）
# - 根据点击位置自动放在上半/下半
# - 拐角楼梯自动连接
```

## 五、示例2：自定义石台阶 (SLAB)

```yaml
# ============================================================
# 自定义石台阶 — 支持上半/下半/双层

    textures:

  Mechanics:
    shaped_block:
      type: SLAB
      custom_variation: 1                    # SLAB 类型独立的 1-4
      hardness: 4                            # 比楼梯硬（石头类）
      block_sounds:
        break_sound: block.stone.break
        place_sound: block.stone.place
        hit_sound: block.stone.hit
        step_sound: block.stone.step
        fall_sound: block.stone.fall
      drop:
        silktouch: false
        minimal_type: WOODEN
        best_tools:
          - PICKAXE                          # 镐子最佳
        loots:
          - oraxen_item: custom_stone_slab
            probability: 1.0

# 台阶的行为特性：
# - 支持上半、下半和双层放置
# - 根据点击位置自动判断放置在上半还是下半
# - 双层台阶 = 两个台阶放在同一格
# - 破坏双层台阶时自动掉落 2 个物品
```

## 六、示例3：自定义门 (DOOR)

门是六种类型中最特殊的——Pack 部分使用 `item/generated` 作为手持图标，实际方块纹理在 mechanism 中指定。

```yaml
# ============================================================
# 自定义橡木门 — Pack 使用 item/generated（手持图标）
# ============================================================
custom_oak_door:
  itemname: <#8B4513>自定义橡木门
  material: PAPER

  # ---- 资源包/模型配置 (物品栏/手持图标) ----
  Pack:
    generate_model: true
    # [重要] 门的手持图标用 item/generated，不是方块模型！
    # 这是因为门的方块模型由原版门机制控制
    parent_model: item/generated
    textures:
      - default/custom_oak_door_icon        # 手持时显示的图标

  # ---- 方块机制配置 ----
  Mechanics:
    shaped_block:
      type: DOOR
      custom_variation: 1                    # DOOR 类型独立的 1-4

      # [必需] 门放置后的方块纹理
      # 这是门在世界上放置后的实际外观
      textures:
        bottom: default/oak_door_bottom      # 门的下半部分
        top: default/oak_door_top            # 门的上半部分

      hardness: 2
      block_sounds:
        break_sound: block.wood.break
        place_sound: block.wood.place
        hit_sound: block.wood.hit
        step_sound: block.wood.step
        fall_sound: block.wood.fall
      drop:
        silktouch: false
        minimal_type: WOODEN
        best_tools:
          - AXE
        loots:
          - oraxen_item: custom_oak_door
            probability: 1.0

# 门的行为特性：
# - 两格高，自动放置上下两半
# - 右键点击开合
# - 红石供能（压力板、按钮可控制）
# - 破坏任一半都移除整扇门
```

## 八、示例5：自定义格栅/树叶 (GRATE)

GRATE 类型使用裁剪渲染 (cutout)，是制作自定义树叶和玻璃装饰的绝佳选择。

```yaml
# ============================================================
# 自定义水晶树叶 — GRATE 类型的透明渲染
# ============================================================
crystal_leaves:
  itemname: <gradient:#9966FF:#FF66CC>水晶树叶
  material: PAPER
  Pack:
    generate_model: true
    # [关键] 使用 block/leaves 父模型获得树叶透明度
    # GRATE 的透明裁剪 + leaves 父模型 = 完美的自定义树叶
    parent_model: block/leaves
    textures:
      - default/crystal_leaves
  Mechanics:
    shaped_block:
      type: GRATE                          # 格栅类型
      custom_variation: 1                   # GRATE 类型独立的 1-4
      light: 12                             # 魔法树叶发光
      hardness: 0.2                         # 非常容易破坏
      block_sounds:
        break_sound: block.grass.break
        place_sound: block.grass.place
        hit_sound: block.grass.hit
        step_sound: block.grass.step
        fall_sound: block.grass.fall
      drop:
        silktouch: true                     # 只有精准采集才掉
        best_tools:
          - SHEARS
          - HOE
        loots:
          - oraxen_item: crystal_leaves
            probability: 1.0

# GRATE 的行为特性：
# - 使用裁剪渲染 (cutout) 的透明效果
# - 纹理的透明通道像真实树叶一样透出
# - 支持含水
# - 光线可以透过
# - 非常适合自定义树叶、玻璃类、镂空装饰
```

## 十、涂蜡铜转换机制说明

```
convert_vanilla_waxed: true 的完整影响：

  1. 原版涂蜡铜方块（含楼梯、台阶等）被转换为普通铜方块
  2. 转换后的铜方块带有氧化防止标记（不会继续氧化）
  3. 外观保持不变——玩家看不出区别
  4. 涂蜡状态被释放给 Oraxen 的自定义形状方块

  这就是为什么"涂蜡"这个名字很关键：
    - 原版：涂蜡 = 防止铜氧化
    - Oraxen：涂蜡 = 自定义形状方块的容器

  如果你的服务器已有很多原版涂蜡铜建筑：
    → 启用前先备份世界
    → 已存在的涂蜡铜会自动转换（外观不变）
    → 玩家无法再制作新的原版涂蜡铜
```


## 十二、父模型参考表

| 类型 | 推荐 parent_model | 说明 |
|:---|:---|:---|
| STAIR | block/stairs | 楼梯专用 |
| SLAB | block/slab | 台阶专用 |
| DOOR | item/generated（方块纹理在 mechanism 中指定） | 手持图标 |
| TRAPDOOR | block/template_trapdoor_bottom | 活板门专用 |
| GRATE | block/leaves 或 block/cube_all | leaves=植被透明，cube_all=玻璃 |
| BULB | block/cube_all | 普通方块模型 |

## 十三、形状方块的限制

```
1. 每种类型最多 4 个变体 (6类型 × 4变体 = 最多24个方块)
2. 不支持 blast_resistant (防爆)
3. 不支持 immovable (不可推动)
4. 不支持 is_falling (下落)
5. 不支持 storage (存储容器)
6. 不支持 clickActions (点击动作)
7. 不支持 directional (方向性——内置在类型自身中)
8. 启用后原版涂蜡铜方块不可用

如果需要超出这些限制的功能，请考虑使用音符盒(NoteBlock)机制。
```
