# 实战示例：进化植物 (Evolution Plant — Inline Stages)

> 本文件基于项目 `Oraxen/items/plants.yml` 中的实际配置提取，
> 展示 Oraxen 新版内联阶段 (inline stages) 植物进化系统。
> 这是创建多阶段生长植物的**推荐方式**。

---

## 一、新旧系统对比

| 方式 | 描述 | 状态 |
|:---|:---|:---|
| 内联阶段(stages) | 1个物品 → N个阶段，Pack.models 内联 | ★强烈推荐（新版），1个文件，高性能 |
| 旧版多物品 | N个物品 → N个阶段，各自独立配置 | 已弃用（有警告），N个文件，低性能 |

内联阶段的优势：
  - 一个物品定义所有阶段 → 维护简单
  - Pack.models 内联模型 → 不占额外物品ID
  - 模型切换而非实体重建 → 高性能
  - 自动按数组顺序进化 → 不需要手动 next_stage

---

## 二、示例1：大麻 (weed) — 5阶段进化植物

从 `plants.yml` 中的 `weed_seed` 提取。包括 4 个生长阶段 + 1 个收获阶段。

```yaml
# ============================================================
# 大麻种子 — 5阶段内联进化（0→1→2→3→收获）
# ============================================================
weed_seed:
  # ---- 基础信息 ----
  # [必需] 种子物品的显示名称
  displayname: <gradient:#46EEAA:#2CBFC7>Weed Seed

  # [必需] 基础材质
  material: PAPER

  # ---- 资源包/模型配置 ----
  Pack:
    generate_model: true
    parent_model: item/generated            # 手持物品用平面图标
    textures:
      - default/weed/seed                   # 种子图标纹理

    # ========== [关键★] 内联阶段模型定义 ==========
    # 每个阶段的模型在这里定义
    # 键名在 stages 的 model 字段中引用
    models:
      stage0: default/weed/stage0           # 刚种下的幼苗
      stage1: default/weed/stage1           # 生长阶段1
      stage2: default/weed/stage2           # 生长阶段2
      stage3: default/weed/stage3           # 接近成熟

  # ---- 方块机制配置 ----
  Mechanics:
    furniture:
      # ========== 基础配置 ==========
      barrier: false                        # 植物不需要碰撞

      # [关键] 需要种在自定义农场方块上
      # 与 farmland_required 二选一
      # farmblock_required → 需要 Oraxen 自定义耕地方块
      # farmland_required  → 需要原版耕地
      farmblock_required: true

      # [可选] 放置时从第几个阶段开始（默认0）
      initial_stage: 0

      # ========== [关键★] stages: 内联阶段列表 ==========
      # 按生长顺序排列，最后一个阶段不要写 evolution！
      stages:
        # ---------- 阶段 0: 种子/幼苗 ----------
        - model: stage0                     # 引用 Pack.models 中的键名
          evolution:                        # 进化到下一阶段的条件
            delay: 10000                    # 检查间隔（刻，10000=约8分20秒）
            probability: 0.5               # 通过概率（50%）

            # [可选] 光照加速 — 简写格式
            # true = 启用默认光照加速（最低光照9）
            light_boost: true

            # [可选] 骨粉催熟
            bone_meal:
              chance: 50                    # 使用骨粉有50%几率推进

          drop:                             # 破坏此阶段时的掉落物
            silktouch: true
            loots:
              - oraxen_item: weed_seed      # 掉回种子
                probability: 1.0

        # ---------- 阶段 1 ----------
        - model: stage1
          evolution:
            delay: 10000
            probability: 0.5
            light_boost: true
            bone_meal:
              chance: 50
          drop:
            silktouch: true
            loots:
              - oraxen_item: weed_seed
                probability: 1.0

        # ---------- 阶段 2 ----------
        - model: stage2
          evolution:
            delay: 10000
            probability: 0.5
            light_boost: true
            bone_meal:
              chance: 50
          drop:
            silktouch: true
            loots:
              - oraxen_item: weed_seed
                probability: 1.0

        # ---------- 阶段 3: 成熟（最终收获阶段）----------
        - model: stage3
          # [重要] 最后一个阶段没有 evolution！
          # 没有 evolution = 不再生长，这是最终阶段
          drop:
            silktouch: true
            loots:
              # 必掉种子（可多个）
              - oraxen_item: weed_seed
                max_amount: 2               # 最多掉2个种子
                probability: 0.75           # 75%几率
              # 额外掉落产品
              - oraxen_item: weed_leaf      # 大麻叶
                max_amount: 5               # 最多掉5个
                probability: 0.55           # 55%几率

# 生长流程：
#   阶段0 (种子) → 阶段1 (幼苗) → 阶段2 (成长) → 阶段3 (成熟/收获)
#   每个箭头: delay=10000刻 + probability=0.5
#   总期望时间: 3 × 10000 / 0.5 = 60000刻 = 50分钟（光照充足会缩短）
```

## 三、示例2：葡萄 (grape) — 6阶段进化植物

从 `plants.yml` 中的 `grape_seeds` 提取。展示更多阶段的配置。

```yaml
# ============================================================
# 葡萄种子 — 6阶段内联进化（0→1→2→3→4→收获）
# ============================================================
grape_seeds:
  displayname: <gradient:#46EEAA:#2CBFC7>Grape Seeds
  material: PAPER
  Pack:
    generate_model: true
    parent_model: item/generated
    textures:
      - default/grape_seeds                # 种子图标
    # 定义5个生长阶段模型（比 weed 多一个）
    models:
      stage0: default/grape/stage0
      stage1: default/grape/stage1
      stage2: default/grape/stage2
      stage3: default/grape/stage3
      stage4: default/grape/stage4

  Mechanics:
    furniture:
      barrier: false
      farmblock_required: true              # 同样需要自定义耕地
      initial_stage: 0

      stages:
        # --- 阶段 0 ---
        - model: stage0
          evolution:
            delay: 10000
            probability: 0.5
            light_boost: true
            bone_meal:
              chance: 50
          drop:
            silktouch: true
            loots:
              - oraxen_item: grape_seeds
                probability: 1.0

        # --- 阶段 1 ---
        - model: stage1
          evolution:
            delay: 10000
            probability: 0.5
            light_boost: true
            bone_meal:
              chance: 50
          drop:
            silktouch: true
            loots:
              - oraxen_item: grape_seeds
                probability: 1.0

        # --- 阶段 2 ---
        - model: stage2
          evolution:
            delay: 10000
            probability: 0.5
            light_boost: true
            bone_meal:
              chance: 50
          drop:
            silktouch: true
            loots:
              - oraxen_item: grape_seeds
                probability: 1.0

        # --- 阶段 3 ---
        - model: stage3
          evolution:
            delay: 10000
            probability: 0.5
            light_boost: true
            bone_meal:
              chance: 50
          drop:
            silktouch: true
            loots:
              - oraxen_item: grape_seeds
                probability: 1.0

        # --- 阶段 4: 最终收获阶段 ---
        - model: stage4
          # 无 evolution = 最终阶段
          drop:
            silktouch: true
            loots:
              - oraxen_item: grape_seeds    # 种子
                max_amount: 2
                probability: 0.75
              - oraxen_item: grape          # 葡萄果实
                max_amount: 2
                probability: 0.55

# 葡萄 vs 大麻的差异：
#   葡萄: 5个生长阶段 → 6个阶段总（0-4生长 + 4收获）
#   大麻: 4个生长阶段 → 5个阶段总（0-3生长 + 3收获）
#   葡萄多一个阶段 = 总生长时间更长
```

## 五、evolution 进化选项完整说明

```yaml
evolution:
  # ---- 基础参数 ----
  delay: 10000                    # [必需] 进化检查间隔（刻，20刻=1秒）
                                  # 10000刻 ≈ 8分20秒
                                  # 6000刻 = 5分钟
                                  # 12000刻 = 10分钟
                                  # 24000刻 = 20分钟

  probability: 0.5                # [必需] 到达delay后成功进化的概率 (0.0-1.0)
                                  # 0.5 = 50%几率
                                  # 1.0 = 必定进化（最快）

  # ---- 光照加速 (light_boost) ----
  # 简写格式（使用默认值）:
  light_boost: true               # 启用，最低光照9，默认 boost_tick

  # 详细格式（自定义参数）:
  # light_boost:
  #   minimum_light_level: 9      # 加速所需的最低光照等级 (0-15)
  #   boost_tick: 500             # 光照充足时每次额外增加进度（刻）

  # ---- 雨天加速 (rain_boost) ----
  # 简写格式:
  rain_boost: true                # 启用雨天加速（本项目 weed/grape 未使用）

  # 详细格式:
  # rain_boost:
  #   boost_tick: 500             # 下雨时每次额外增加进度（刻）

  # ---- 骨粉催熟 (bone_meal) ----
  # 简写格式:
  bone_meal: true                 # 启用，默认 50% 几率

  # 详细格式:
  bone_meal:
    chance: 50                    # 使用骨粉成功推进的百分比几率 (0-100)
```

### 加速机制工作原理

```
光照加速 (light_boost)：
  → 每次进化检查时，如果光照 >= minimum_light_level
  → 进度额外增加 boost_tick 刻
  → 这"不改变" probability，而是让检查来得更快
  → 相当于：好光照 = 更快能达到下一次检查

雨天加速 (rain_boost)：
  → 类似光照加速，但是下雨时触发
  → 可以同时拥有 light_boost 和 rain_boost

骨粉催熟 (bone_meal)：
  → 玩家手持骨粉右键植物
  → 每次使用有 chance% 的几率立即推进一个阶段
  → 可以在任何有 evolution 的阶段使用
  → 最终阶段（无 evolution）不能使用骨粉

本项目的 weed 和 grape 都只用了 light_boost + bone_meal
没有用 rain_boost（植物在室内也能生长）
```

## 六、stage 阶段配置选项

```
stages 数组中每个阶段的可用字段：

  model: <string>               [必需] 引用 Pack.models 中的键名

  evolution: <object>           [生长阶段必需] 进化到下一阶段的条件
    → 最终阶段必须省略此项

  drop: <object>                [可选] 此阶段的特定掉落物
    → 省略时继承全局 drop
    → 最终阶段通常配置多种掉落（种子+果实）

  light: <integer>              [可选] 此阶段的光照等级
    → -1 表示继承全局 light
    → 例如：成熟果实阶段发光
```

## 七、farmland_required vs farmblock_required

```yaml
# 两种耕地要求的区别：

# farmland_required: true
# → 植物只能种在原版耕地上
# → 不需要自定义方块
# → 与任何使用原版耕地的系统兼容

# farmblock_required: true (本项目使用)
# → 植物只能种在 Oraxen 自定义耕地方块上
# → 需要配套的农场方块（如魔法土壤 / 湿润魔法土壤）
# → 更灵活（可自定义耕地外观和行为）

# 二选一，不能同时使用
```

## 八、最终阶段的特殊掉落设计

```
本项目的 weed 和 grape 最终阶段掉落设计：

weed (阶段3):
  - weed_seed (种子): max=2, prob=0.75
    → 大概率回本 (75%几率掉1-2个种子)
    → 期望回收: 2*0.75 = 1.5个种子 > 1个投入
    → 可持续种植
  - weed_leaf (产品): max=5, prob=0.55
    → 55%几率掉1-5个产品
    → 期望产出: 3*0.55 = 1.65个产品 (平均max=3)

grape (阶段4):
  - grape_seeds: max=2, prob=0.75
    → 同样的可持续设计
  - grape: max=2, prob=0.55
    → 更保守的产出 (比 weed_leaf 少)

设计原则：
  1. 种子回收率 > 100% → 玩家不会"绝种"
  2. 产品掉率低于种子 → 需要多轮种植积累
  3. 概率不是1.0 → 有惊喜感和波动
```

## 九、注意事项

1. **最后一个阶段不要写 evolution**: 写了 evolution 但没有更多阶段会导致错误。

2. **initial_stage 默认 0**: 如果你想让植物放置时直接是成熟状态，设为更大的值。

3. **Pack.models 键名必须在 stages 中引用**: 键名不存在会导致模型加载失败。

4. **drop 在每个阶段独立配置**: 生长阶段的 drop 通常只掉种子，最终阶段才掉产品。

5. **bone_meal 只在有 evolution 的阶段有效**: 最终阶段无 evolution，骨粉无法使用。

6. **旧版多物品已弃用**: 新项目一律使用内联 stages。旧版会产生控制台警告。

7. **性能优势**: 内联阶段使用模型切换而非实体重建，比旧版高效得多。大量植物时性能差异显著。
