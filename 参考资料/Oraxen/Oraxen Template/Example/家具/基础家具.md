# 实战示例：基础家具 (Basic Furniture)

> 本文件基于项目 `Oraxen/items/furniture.yml` 中的实际配置提取，
> 展示 Oraxen 家具机制的核心概念：类型选择、屏障配置、有限放置。

---

## 一、家具类型选择

```
Oraxen 家具支持 4 种渲染类型：

  type                  │ 版本要求    │ 性能  │ 推荐度
  ──────────────────────┼─────────────┼───────┼────────
  DISPLAY_ENTITY        │ 1.19.4+     │ 中    │ ★★★★★ (首选)
  ITEM_FRAME            │ 1.16+       │ 高    │ ★★★   (兼容低版本)
  GLOW_ITEM_FRAME       │ 1.17+       │ 高    │ ★★    (特殊发光需求)
  ARMOR_STAND           │ 1.16+       │ 低    │ ★     (不建议)

本项目选择策略：
  - table, shelf → ITEM_FRAME（简单家具，低版本兼容）
  - cart, chair, coach, turntable → DISPLAY_ENTITY（复杂模型，需要 hitbox 或 display 变换）
```

---

## 二、全局配置 (mechanics.yml)

```yaml
# ============================================================
# plugins/Oraxen/mechanics.yml — 家具全局配置
# ============================================================
furniture:
  enabled: true

  # 注意：家具机制不需要额外的全局配置项（如 tool_types 等）
  # 所有配置都在每个物品的 Mechanics.furniture 中进行
```

## 三、示例1：桌子 (table) — ITEM_FRAME 类型 + barrier

从 `furniture.yml` 中的 `table` 提取。

```yaml
# ============================================================
# 桌子 — 最简单的家具，ITEM_FRAME + 单个 barrier
# ============================================================
table:
  # ---- 基础信息 ----
  itemname: <gray>桌子
  material: PAPER

  # ---- 方块机制配置 ----
  Mechanics:
    furniture:
      # [可选] 家具类型（1.19.4+ 默认 DISPLAY_ENTITY，否则 ITEM_FRAME）
      # 这里显式指定 ITEM_FRAME 用于低版本兼容
      type: ITEM_FRAME

      # ========== 有限放置 ==========
      # [可选] 限制家具只能放在特定表面
      limited_placing:
        roof: false                         # 不能放在天花板上
        floor: true                         # 只能放在地面上
        wall: false                         # 不能放在墙上

      # ========== 屏障 ==========
      # [可选] 在家具位置生成一个隐形屏障方块
      # true = 单屏障 (x:0, y:0, z:0)
      # 屏障提供物理碰撞和右键交互区域
      barrier: true

      # ========== 发光 ==========
      # [可选] 光照等级 1-15，0 = 不发光
      light: 5                              # 桌子发出 5 级光

      # ========== 掉落物 ==========
      drop:
        silktouch: false
        loots:
          - oraxen_item: table
            probability: 1.0

  # ---- 资源包/模型配置 ----
  Pack:
    generate_model: false                   # 使用预制 Blockbench 模型
    model: default/table                    # 模型路径
```

### 设计说明

```
桌子 (table) 的设计选择：
  1. type: ITEM_FRAME — 因为桌子是简单几何体，ITEM_FRAME 性能更好
  2. barrier: true — 提供碰撞（玩家无法穿过桌子）+ 右键交互
  3. light: 5 — 桌子是发光方块，提供环境照明
  4. limited_placing — 只允许放在地面，不能上天花板/墙壁
  5. generate_model: false — 桌子需要自定义 3D 模型

为什么不用 DISPLAY_ENTITY？
  → ITEM_FRAME 更高效（方块实体 vs 展示实体）
  → 桌子不需要 display_entity_properties 的精细控制
  → 兼容低版本客户端
```

## 四、示例2：书架 (shelf) — wall-only 放置 + DENY 类型

从 `furniture.yml` 中的 `shelf` 提取。

```yaml
# ============================================================
# 书架 — 只允许放在墙上的家具
# ============================================================
shelf:
  itemname: <gray>书架
  material: PAPER
  Mechanics:
    furniture:
      type: ITEM_FRAME

      # ========== 有限放置 (墙壁专用) ==========
      limited_placing:
        roof: false                         # 禁止天花板
        floor: false                        # 禁止地面
        wall: true                          # 只允许墙壁

        # [可选] 放置限制类型
        # ALLOW = 白名单（只能放在下方列出的方块上）
        # DENY  = 黑名单（不能放在下方列出的方块上）
        type: DENY

        # [可选] 原版方块类型黑名单/白名单
        block_types: []                     # 空列表 = 不限制原版方块类型

        # [可选] 原版方块标签黑名单/白名单
        block_tags: []                      # 空列表 = 不限制标签

        # [可选] Oraxen 自定义方块黑名单/白名单
        oraxen_blocks: []                   # 空列表 = 不限制 Oraxen 方块

      # ========== 无屏障 ==========
      # 书架是墙上装饰，不需要碰撞
      barrier: false

      drop:
        silktouch: false
        loots:
          - oraxen_item: shelf
            probability: 1.0

  Pack:
    generate_model: false
    model: default/shelf
```

### shelf 的 limited_placing 详解

```
"只允许放在墙上"的配置需要同时满足：
  1. wall: true     → 启用墙壁放置
  2. roof: false    → 禁用天花板
  3. floor: false   → 禁用地面
  4. type: DENY + 空列表 → 不拒绝任何具体方块

为什么用 DENY + 空列表而不是 ALLOW + 全选？
  → DENY 空列表 = "不拒绝任何方块"（所有墙面都接受）
  → ALLOW 全选 = 需要明确列出所有方块类型（容易遗漏）

如果只想放在木板墙上：
  limited_placing:
    wall: true
    type: ALLOW
    block_types:
      - OAK_PLANKS
      - SPRUCE_PLANKS
      - BIRCH_PLANKS
      # ... 逐一列出所有木板
    # 或使用标签(推荐):
    block_tags:
      - planks                            # 所有木板
```

## 五、limited_placing 完整配置说明

```yaml
# ============================================================
# limited_placing 的所有配置选项
# ============================================================
limited_placing:
  # ---- 放置面 ----
  roof: true/false          # 天花板 (方块的下表面)
  floor: true/false          # 地面 (方块的上表面)
  wall: true/false           # 墙壁 (方块的侧面)

  # ---- 半径限制 ----
  # [可选] 限制同种家具在指定半径内的放置数量
  radius_limitation:
    radius: 16               # 检查半径（方块单位）
    amount: 5                # 此半径内最多放置几个

  # ---- 限制类型 ----
  type: ALLOW/DENY
  # ALLOW = 白名单（只能放在下方列出的方块上）
  # DENY  = 黑名单（不能放在下方列出的方块上）

  # ---- 原版方块材质列表 ----
  block_types:
    - GRASS_BLOCK
    - DIRT
    - STONE
    # 完整列表见: https://hub.spigotmc.org/javadocs/spigot/org/bukkit/Material.html

  # ---- 原版方块标签（推荐，一组方块） ----
  block_tags:
    - base_stone_overworld                # 主世界石头
    - base_stone_nether                   # 下界石头
    - dirt                                # 所有泥土变体
    - planks                              # 所有木板变体
    # 标签列表: https://minecraft.fandom.com/wiki/Tag#Block_tags

  # ---- Oraxen 自定义方块 ----
  oraxen_blocks:
    - custom_floor                        # 允许/禁止放在自定义方块上
    - another_furniture                   # 注意：家具需要 barrier 才能被检测
```

## 六、barrier vs hitbox 对比

```
┌──────────┬──────────────────────┬──────────────────────┐
│ 特性     │ barrier              │ hitbox               │
├──────────┼──────────────────────┼──────────────────────┤
│ 实现方式 │ 隐形屏障方块         │ 交互实体              │
│ 碰撞形状 │ 1x1x1 方块          │ width × height 矩形   │
│ 可见性   │ 完全隐形             │ 完全隐形              │
│ 性能     │ 每 barrier 一个实体  │ 只一个交互实体        │
│ 版本要求 │ 无特殊要求           │ 1.19.4+              │
│ 座位支持 │ 必需（座位依赖屏障） │ 可选                  │
│ 存储支持 │ 必需（存储依赖屏障） │ 可选                  │
│ 多碰撞区 │ barriers: [...] 列表 │ 不可（只有单个矩形）  │
│ 精确形状 │ 方块级（粗糙）       │ 浮点精度（精细）      │
│ 红石交互 │ 支持（方块实体）     │ 不支持                │
└──────────┴──────────────────────┴──────────────────────┘

选择策略：
  - 桌椅等简单方块 → barrier: true（简单可靠）
  - 需要精确碰撞的装饰 → hitbox（尺寸精确）
  - 大型家具需要多区域碰撞 → barriers: [...]（多个屏障）
  - 需要座位 → barrier 必须有（seat 依赖 barrier）
  - 需要存储 → barrier 必须有（storage 依赖 barrier）
  - 可同时使用 hitbox + barrier → 兼顾精确交互和功能
```

## 七、手推车 (cart) — DISPLAY_ENTITY + hitbox

从 `furniture.yml` 中提取，展示 DISPLAY_ENTITY 类型的基础用法。

```yaml
# ============================================================
# 手推车 — DISPLAY_ENTITY 类型 + hitbox 碰撞
# ============================================================
cart:
  itemname: <gray>手推车
  material: PAPER
  Mechanics:
    furniture:
      type: DISPLAY_ENTITY                 # 使用展示实体（1.19.4+）

      # ========== 碰撞箱 (hitbox) ==========
      # DISPLAY_ENTITY 类型独有的碰撞方式
      # 比 barrier 更精细的碰撞区域定义
      hitbox:
        width: 1.0                         # X/Z 轴宽度（方块为单位）
        height: 1.0                        # Y 轴高度（方块为单位）

      # ========== 展示实体属性 ==========
      display_entity_properties:
        # [可选] 显示变换，决定模型在展示实体中的映射方式
        # NONE = 与 BlockBench 中默认显示一致
        # FIXED = 类似物品展示框的位置（墙壁装饰用）
        # HEAD = 类似盔甲架头部位置
        display_transform: FIXED

      # ========== 屏障（可与 hitbox 共存）==========
      barrier: true

      # ========== 有限放置 ==========
      limited_placing:
        roof: false
        floor: true
        wall: false

      drop:
        silktouch: false
        loots:
          - oraxen_item: cart
            probability: 1.0

  Pack:
    generate_model: false
    model: default/cart
```

## 九、项目家具模板总结

```
从本项目 furniture.yml 中提取的共性：
  - 所有家具 material: PAPER
  - 所有家具 generate_model: false（使用预制 Blockbench 模型）
  - 所有家具 drop.silktouch: false
  - 所有家具 drop.loots 只有一个条目，probability: 1.0
  - ITEM_FRAME 类型用于简单家具（table, shelf）
  - DISPLAY_ENTITY 类型用于复杂或需要座位/变换的家具（cart, chair, coach, turntable）

新增家具步骤：
  1. 确定类型（简单→ITEM_FRAME, 复杂→DISPLAY_ENTITY）
  2. 确定碰撞方式（barrier vs hitbox）
  3. 配置 limited_placing（地面/墙壁/天花板 + ALLOW/DENY）
  4. 配置 drop 掉落
  5. 配置 Pack.model 模型路径
  6. 可选：light, seat, storage, jukebox, block_sounds
```
