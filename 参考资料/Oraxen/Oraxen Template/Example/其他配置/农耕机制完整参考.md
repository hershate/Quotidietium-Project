# 农耕机制完整参考

> 基于 Oraxen 官方文档。Oraxen 提供 6 种内置农耕/采矿机制。
> 涵盖自动收割、范围挖掘、熔炼、瓶装经验、基岩破坏和浇水系统。

---

## 一、收割 (harvesting)

> 右键成熟作物，在一定半径内自动收获并重新种植。
> 适用于小麦、胡萝卜、马铃薯、甜菜根等所有原版作物 + Oraxen 自定义作物。

### 参数速查表

| 参数 | 类型 | 默认值 | 有效范围 | 说明 |
|------|------|--------|----------|------|
| `cooldown` | 整数 | `0` | `0` ~ `3600000` | 冷却时间（**毫秒**）。`10000`=10秒 |
| `radius` | 整数 | `3` | `1` ~ `10` | 以点击方块为中心的水平收获半径。`3`=7x7区域 |
| `height` | 整数 | `1` | `1` ~ `10` | 以点击方块为起点的垂直向上收获范围 |
| `lower_item_durability` | 布尔 | `true` | `true` / `false` | 收获是否消耗工具耐久度 |

### 完整 YAML 示例

```yaml
harvesting_scythe:
  material: IRON_HOE
  displayname: "<green>收割镰刀"
  lore:
    - "<gray>右键收获范围内所有成熟作物"
    - "<gray>自动重新种植"
  Mechanics:
    harvesting:
      cooldown: 10000                       # 10 秒冷却
      radius: 5                             # 11x11 区域（以目标为中心的 5 格半径）
      height: 3                             # 向上 3 层
      lower_item_durability: true           # 每次收获消耗耐久
```

### 工作流程

1. 手持收割工具右键成熟作物
2. 以目标为中心的 radius x height 范围内所有成熟作物被收获
3. 自动从背包消耗种子重新种植
4. 进入冷却（如有），消耗耐久（如启用）

## 二、范围挖掘 (bigmining)

> 挖掘一个方块时同时破坏周围匹配类型的方块。常被称为"连锁挖掘"或"矿脉挖掘"。
> 适用于镐子、铲子、斧头等任何工具。

### 参数速查表

| 参数 | 类型 | 默认值 | 有效范围 | 说明 |
|------|------|--------|----------|------|
| `radius` | 整数 | `1` | `0` ~ `5` | 水平挖掘半径。`1`=3x3，`2`=5x5，以此类推 |
| `depth` | 整数 | `1` | `0` ~ `5` | 垂直挖掘深度。`1`=上下各1层（共3层） |

### 全局配置 (mechanics.yml)

```yaml
bigmining:
  enabled: true
  call_events: true          # true=调用BlockBreakEvent(兼容保护插件)
                             # false=仅监听事件(解决附魔插件冲突)
```

### 完整 YAML 示例

```yaml
excavation_hammer:
  material: DIAMOND_PICKAXE
  displayname: "<blue>挖掘锤"
  lore:
    - "<gray>一次性挖掘 3x3 区域"
    - "<gray>适合快速采矿"
  Mechanics:
    bigmining:
      radius: 1                             # 3x3 区域
      depth: 1                              # 上下各 1 层（共 3 层）

# ── 更大的范围 ──
mega_hammer:
  material: NETHERITE_PICKAXE
  displayname: "<gold>大型挖掘锤"
  lore:
    - "<gray>一次性挖掘 5x5 区域"
  Mechanics:
    bigmining:
      radius: 2                             # 5x5 区域
      depth: 1
```

### 工作流程

1. 手持带有 bigmining 的镐子挖掘一个方块
2. 在 radius x depth 范围内自动破坏所有**相同类型**的方块
3. 每破坏一个方块消耗 1 点耐久度
4. 掉落物按正常方式处理（含时运等附魔加成）

> **注意：** 只会连锁破坏与被挖掘方块**完全相同类型**的方块。挖石头不会顺带破坏铁矿。

## 三、熔炼 (smelting)

> 挖掘矿石时自动将其熔炼为成品。例如：铁矿石 -> 铁锭。
> 原生支持时运（Fortune）和精准采集（Silk Touch）。

### 参数速查表

| 参数 | 类型 | 默认值 | 有效范围 | 说明 |
|------|------|--------|----------|------|
| `enabled` | 布尔 | `false` | `true` / `false` | **必填**。是否启用自动熔炼 |
| `play_sound` | 布尔 | `true` | `true` / `false` | 熔炼时是否播放音效 |

### 全局配置 (mechanics.yml)

```yaml
smelting:
  enabled: true
  blacklist_cooked:                        # 不应自动熔炼的物品黑名单
    - WET_SPONGE                            # 湿海绵（熔炼后变干海绵）
    # - ICE                                 # 可添加冰块
```

### 完整 YAML 示例

```yaml
autosmelter_pickaxe:
  material: NETHERITE_PICKAXE
  displayname: "<gold>熔炼镐"
  lore:
    - "<gray>挖掘矿石时自动将其熔炼"
  Mechanics:
    smelting:
      enabled: true                         # 启用熔炼
      play_sound: true                      # 播放熔炼音效
```

### 支持的默认熔炼转换（部分）

| 矿石 | 自动转化产物 |
|------|------------|
| 铁矿石 / 深层铁矿石 | 铁锭 |
| 金矿石 / 深层金矿石 | 金锭 |
| 铜矿石 / 深层铜矿石 | 铜锭 |
| 远古残骸 | 下界合金碎片 |
| 沙子 | 玻璃 |
| 仙人掌 | 绿色染料 |
| 湿海绵 | 海绵（如不在黑名单） |

## 四、瓶装经验 (bottledexp)

> 右键将自身经验值转换为经验瓶物品。支持转换效率损失配置。

### 参数速查表

| 参数 | 类型 | 默认值 | 有效范围 | 说明 |
|------|------|--------|----------|------|
| `ratio` | 小数 | `1.0` | `0.0` ~ `1.0` | 经验转换效率。`1.0`=无损失，`0.95`=损失5% |

### 全局配置 (mechanics.yml)

```yaml
bottledexp:
  enabled: true
  durability_cost: 10                      # 每次使用消耗的耐久度。设为 0 不消耗
```

### 完整 YAML 示例

```yaml
experience_bottle:
  material: GLASS_BOTTLE
  displayname: "<yellow>经验瓶"
  lore:
    - "<gray>右键将经验存入瓶中"
    - "<gray>转换效率：95%"
  Mechanics:
    bottledexp:
      ratio: 0.95                           # 95% 效率（5% 经验损失）
```

## 五、基岩破坏 (bedrockbreak)

> 允许使用特定工具破坏基岩方块。依赖 ProtocolLib 提供动画效果。
> **依赖：** 需要 ProtocolLib 插件。

### 参数速查表

| 参数 | 类型 | 默认值 | 有效范围 | 说明 |
|------|------|--------|----------|------|
| `hardness` | 整数 | `10` | `1` ~ `200` | 破坏动画切换间隔（刻）。值越小破坏越快。`10`=约0.5秒/阶段 |
| `probability` | 小数 | `1.0` | `0.0` ~ `1.0` | 破坏后基岩方块的掉落概率。`1.0`=100%掉落 |

### 全局配置 (mechanics.yml)

```yaml
bedrockbreak:
  enabled: true
  disable_on_first_layer: false            # true=禁止破坏Y=0层基岩（防掉虚空）
  durability_cost: 500                     # 每破坏一块基岩消耗的耐久度
```

### 完整 YAML 示例

```yaml
bedrock_breaker:
  material: NETHERITE_PICKAXE
  displayname: "<dark_gray>基岩破坏者"
  lore:
    - "<gray>能够破坏基岩"
    - "<gray>需要一定时间来凿穿"
    - "<gray>每次破坏消耗大量耐久度"
  Mechanics:
    bedrockbreak:
      hardness: 10                          # 每 0.5 秒推进一阶段
      probability: 1.0                      # 100% 掉落
```

### 工作流程

1. 手持工具持续挖掘基岩
2. 经过 hardness 刻切换一次破坏动画阶段
3. 到达最终阶段后基岩被破坏
4. 按 probability 概率掉落基岩方块
5. 从工具扣除 durability_cost 耐久度

## 六、浇水 (watering)

> 洒水壶系统。需要定义两个物品：空壶和装满水的壶。
> 空壶右键水源/含水炼药锅装水；满壶右键农田浇灌。

### 参数速查表

| 参数 | 类型 | 默认值 | 有效范围 | 说明 |
|------|------|--------|----------|------|
| `filledCanItem` | 字符串 | -- | 有效的 Oraxen 物品 ID | **空壶必填**。装水后变成的满壶物品 ID |
| `emptyCanItem` | 字符串 | -- | 有效的 Oraxen 物品 ID | **满壶必填**。浇灌后变成的空壶物品 ID |

### 完整 YAML 示例

```yaml
# ============================================================
# 物品 1: 空洒水壶
# ============================================================
empty_watering_can:
  material: PAPER
  displayname: "<gray>空洒水壶"
  lore:
    - "<gray>右键水源或含水炼药锅来装水"
  Mechanics:
    watering:
      filledCanItem: filled_watering_can    # 指向满壶

# ============================================================
# 物品 2: 装满的洒水壶
# ============================================================
filled_watering_can:
  material: PAPER
  displayname: "<aqua>装满的洒水壶"
  lore:
    - "<gray>右键农田来浇灌作物"
  Mechanics:
    watering:
      emptyCanItem: empty_watering_can      # 指向空壶
```

> **关键：** 两个物品必须互相链接（空壶的 filledCanItem 指向满壶，满壶的 emptyCanItem 指向空壶），否则系统无法正常工作。

## 七、所有农耕机制全局配置（mechanics.yml）

```yaml
# ── 在 mechanics.yml 中启用农耕机制 ──
harvesting:
  enabled: true
bigmining:
  enabled: true
  call_events: true          # true=兼容保护插件, false=解决附魔冲突
smelting:
  enabled: true
  blacklist_cooked:
    - WET_SPONGE
bottledexp:
  enabled: true
  durability_cost: 10
watering:
  enabled: true
bedrockbreak:
  enabled: true
  disable_on_first_layer: false
  durability_cost: 500
```

## 八、农耕机制组合示例

### 终极矿镐（范围挖掘 + 自动熔炼 + 耐久度 + 急迫）

```yaml
ultimate_pickaxe:
  material: NETHERITE_PICKAXE
  displayname: "<gradient:gold:red>终极矿镐"
  lore:
    - "<gray>5x5 区块挖掘"
    - "<gray>自动熔炼矿石"
    - "<gray>手持获得急迫 V"
    - "<gray>死亡不掉落"
  Mechanics:
    durability:
      value: 10000                          # 超高耐久
    efficiency:
      amount: 4                             # 急迫 V（0=I, 1=II, ...）
    bigmining:
      radius: 2                             # 5x5 区块
      depth: 1
    smelting:
      enabled: true                         # 自动熔炼
      play_sound: true
    soulbound:
      lose_chance: 0                        # 永不掉落
```

### 农耕套装（收割 + 浇水 + 经验瓶）

```yaml
# 收割镰刀
farm_scythe:
  material: IRON_HOE
  displayname: "<green>农耕镰刀"
  Mechanics:
    harvesting:
      radius: 3                             # 7x7 区域
      height: 2
      cooldown: 5000                        # 5 秒冷却

# 洒水壶（同上，见第五节）

# 经验瓶工具
exp_collector:
  material: GLASS_BOTTLE
  displayname: "<yellow>经验收集器"
  Mechanics:
    bottledexp:
      ratio: 0.98                           # 98% 效率
```
