## 一、节日限定食物

> 来自项目实际配置 `items/festival/dragon_boat_fest.yml` 的粽子。这是最简单的物品类型——仅需 food 机制。

### 实际配置（dragon_boat_fest.yml）

```yaml
# ============================================================
# 文件: items/festival/dragon_boat_fest.yml
# 最简单的节日食物 — 粽子
# 只用了 Components.food，没有 Mechanics
# ============================================================
zongzi:
  itemname: "粽子"                            # 物品名称
  material: COOKED_BEEF                       # 伪装材质: 熟牛肉
  Pack:
    generate_model: true                      # 自动生成 2D 模型
    parent_model: item/generated              # 平放的 2D 物品
    textures:
    - festival/zongzi.png                     # 纹理文件路径
  Components:
    food:
      nutrition: 10                           # 恢复 10 饥饿值（5 鸡腿）
      saturation: 10                          # 高饱和度
      can_always_eat: true                    # 饱食时也可食用
```

### 扩展：带药水效果的食物

```yaml
# ============================================================
# 加入 Mechanics.food 以添加药水效果和食用替换
# ============================================================
festival_feast:
  itemname: "<gradient:#FF0000:#FFD700>节日盛宴"
  material: COOKED_BEEF
  Pack:
    generate_model: true
    parent_model: item/generated
    textures:
      - festival/festival_feast.png
  Mechanics:
    food:
      hunger: 20                              # 恢复满饥饿值
      saturation: 20                          # 满饱和度
      replacement:
        minecraft_type: BOWL                  # 食用后留下碗
      effect_probability: 1.0                 # 100% 触发效果
      effects:
        regeneration:
          amplifier: 2                        # 生命恢复 III
          duration: 30                        # 30 秒
        absorption:
          amplifier: 4                        # 伤害吸收 V (20 额外生命)
          duration: 120                       # 2 分钟
        speed:
          amplifier: 1                        # 速度 II
          duration: 60
```

## 二、多功能武器

> 展示在单个武器上组合多种战斗机制、耐久度和装饰效果。

### 示例 1：吸血 + 流血 + 耐久度（中等复杂度）

```yaml
# ============================================================
# 吸血鬼之刃 — 吸血 + 流血 + 自定义耐久度
# 三个机制独立工作，互不干扰
# ============================================================
vampire_blade:
  displayname: "<gradient:#8B0000:#FF0000>吸血鬼之刃"
  material: IRON_SWORD
  Pack:
    generate_model: true
    parent_model: "item/handheld"
    textures:
      - weapons/vampire_blade
  Mechanics:
    # ── 机制 1: 自定义耐久度 ──────────────────
    durability:
      value: 3000                            # 约 12x 铁剑耐久 (250)

    # ── 机制 2: 生命吸取 ──────────────────────
    lifeleech:
      amount: 2                              # 每次命中吸取 1 颗心

    # ── 机制 3: 流血 ──────────────────────────
    bleeding:
      chance: 0.4                            # 40% 概率
      duration: 80                           # 4 秒
      damage_per_interval: 0.5               # 每 1 秒扣 0.5
      interval: 20                           # 1 秒间隔
```

### 示例 2：雷神之锤 + 击退连击 + 光环（复杂组合）

```yaml
# ============================================================
# 雷神战锤 — 右键召唤闪电 + 连击强力击退 + 火焰光环
# 注意 thor.delay 是毫秒，knockback_strike 在每次攻击时异步触发
# ============================================================
thors_warhammer:
  displayname: "<gradient:#FFD700:#FF4500>雷神战锤"
  material: DIAMOND_AXE
  lore:
    - "<gray>右键: 召唤雷电风暴"
    - "<gray>连击: 10 次命中触发强力击退"
    - "<gray>手持时散发雷霆光环"
  Pack:
    generate_model: true
    parent_model: "item/handheld"
    textures:
      - weapons/thors_warhammer
  Mechanics:
    # ── 机制 1: 雷神之锤（右键触发）──────
    thor:
      lightning_bolts_amount: 8              # 8 道闪电
      random_location_variation: 2.0         # 2 格随机偏移
      delay: 30000                           # 30 秒冷却（毫秒）
      charges: -1                            # 无限使用

    # ── 机制 2: 击退连击（攻击触发）──────
    knockback_strike:
      required_hits: 10                      # 10 次连续命中触发
      reset_time: 100                        # 5 秒未命中则重置
      knockback_horizontal: 2.5              # 强力水平击退
      knockback_vertical: 1.5                # 强力击飞
      play_sound: true
      sound_type: ENTITY_LIGHTNING_BOLT_THUNDER
      sound_volume: 1.5
      sound_pitch: 0.7
      particle:
        type: FLAME
        count: 100
        spread: 1.0

    # ── 机制 3: 光环（手持时始终显示）────
    aura:
      type: helix                            # 螺旋上升粒子
      particle: END_ROD                      # 末地烛粒子（白色光柱感）

    # ── 机制 4: 灵魂绑定（死亡不掉落）────
    soulbound:
      lose_chance: 0                         # 永不丢失
```

## 三、终极套装

> 完整的盔甲套装 + 护甲效果 + 光环 + 灵魂绑定 + 自定义耐久度。
> 展示套装效果（requires_full_set）的用法。

```yaml
# ============================================================
# 终极套装 — 四件套完整盔甲
# 每件都有自定义耐久度和灵魂绑定

# 靴子和头盔有独立的单件效果

  Pack:
    generate_model: true
    parent_model: "item/generated"
    textures:
      - armor/ultimate_helmet
  Mechanics:
    durability:
      value: 5000
    armor_effects:
      night_vision:
        amplifier: 0                        # 夜视 I
        duration: 200                       # 10 秒刷新
        ambient: true
        particles: false                    # 不显示粒子（保持画面干净）
        icon: true
      water_breathing:
        amplifier: 0                        # 水下呼吸 I

        particles: false
        icon: true

      lose_chance: 0
```

## 四、复杂交互物品

> 结合 Custom 机制实现多种交互行为 + 多种杂项机制。

```yaml
# ============================================================
# 神器之心 — 右键/装备/卸下/丢弃各有行为
# 展示 Custom 的多个事件 + 灵魂绑定 + 光环 + 换肤
# ============================================================
artifact_heart:
  displayname: "<gradient:#FF0000:#FFD700>神器之心"
  material: NETHER_STAR
  unstackable: true
  lore:
    - "<gray>右键: 获得生命恢复"
    - "<gray>装备: 获得力量"
    - "<gray>丢弃: 物品被召回"
    - "<gray>死亡: 不掉落"
    - "<gray>持有时散发金色光环"
  Pack:
    generate_model: true
    parent_model: "item/generated"
    textures:
      - mystical/artifact_heart
  Mechanics:
    # ── Custom: 右键恢复生命 ──────────────────
    custom:
      heal_use:
        event: "CLICK:right:all"
        cooldown: 600                        # 30 秒冷却（刻）
        conditions:
          - "HAS_PERMISSION:artifact.use"
        actions:
          - "COMMAND:console:effect give <player> minecraft:regeneration 10 2"
          - "MESSAGE:<green>神器之心赋予你生命恢复 III！"
          - "ACTIONBAR:<gold>生命恢复 III 持续 10 秒"
          sound:
            name: minecraft:block.beacon.activate
            volume: 1.0
            pitch: 1.5

      # ── Custom: 装备时 ──────────────────────
      equip_heart:
        event: "EQUIP"
        conditions: []
        actions:
          - "COMMAND:console:effect give <player> minecraft:strength -1 1"
          - "MESSAGE:<gold>神器之心装备！获得力量 II"

      # ── Custom: 卸下时 ──────────────────────
      unequip_heart:
        event: "UNEQUIP"
        conditions: []
        actions:
          - "COMMAND:console:effect clear <player> minecraft:strength"
          - "MESSAGE:<gray>神器之心已卸下"

      # ── Custom: 丢弃时（召回物品）──────────
      drop_heart:
        event: "DROP"
        conditions: []
        actions:
          - "COMMAND:console:give <player> minecraft:nether_star{display:{Name:'{\"text\":\"神器之心\",\"color\":\"gold\"}'}} 1"
          - "MESSAGE:<red>神器之心被神秘力量召回！"

    # ── 光环: 手持时金色粒子 ────
    aura:
      type: helix
      particle: END_ROD

    # ── 灵魂绑定: 死亡不掉落 ────
    soulbound:
      lose_chance: 0
```

## 五、机制组合规则

### 可以在同一物品上组合的机制（已验证）

| 组合 | 说明 |
|------|------|
| `durability` + 任意机制 | 耐久度可以叠加在任何物品上 |
| `soulbound` + 任意机制 | 灵魂绑定独立工作，不影响其他机制 |
| `aura` + 任意机制 | 纯装饰，与所有机制兼容 |
| `lifeleech` + `bleeding` | 吸血和流血同时生效 |
| `lifeleech` + `bleeding` + `knockback_strike` | 三个战斗机制共存 |
| `bigmining` + `smelting` + `efficiency` | 农耕三件套 |
| `armor_effects` + `durability` + `soulbound` | 护甲标准组合 |
| 多个 `custom` 能力 | 同一物品可定义多个不同事件的自定义能力 |

### 不能组合的机制

| 冲突组合 | 原因 |
|----------|------|
| `noteblock` + `stringblock` + `chorusblock` | 一个物品只能是一种方块类型 |
| `backpack` + `backpack_cosmetic` | 功能背包和装饰背包互斥 |
| `repair` 中的 `ratio` + `fixed_amount` | 修复比例和固定点数二选一 |
| `furniture` + 方块机制 | 家具和方块是不同的放置系统 |
| `consumable` + `one_usage: false` + 重要物品 | 消耗品会被用掉，不要放在需要保留的物品上 |

### 机制执行的优先级和顺序

```
物品被触发时（右键/攻击/装备等）:

1. 先检查 custom 机制的事件匹配
   ├── 匹配的事件按条件顺序检查
   └── 第一组满足条件的执行动作

2. 战斗机制并行生效
   ├── lifeleech: 造成伤害时同步触发
   ├── bleeding: 造成伤害时概率判定
   └── knockback_strike: 造成伤害时计数

3. 装饰机制始终运行
   ├── aura: 手持时持续渲染
   └── hat/backpack_cosmetic: 装备时持续渲染

4. 被动机制始终生效
   ├── soulbound: 死亡时检查
   ├── durability: 消耗耐久时检查
   └── armor_effects: 装备时周期性刷新
```

## 附录：配置风格参考（来自项目实际）

```yaml
# ============================================================
# 项目实际配置风格总结
# ============================================================

# 1. 字段命名风格
#    旧格式（dragon_boat_fest.yml）:
#      itemname: "粽子"
#      Components.food.nutrition: 10
#
#    新格式（推荐用 Mechanics）:
#      displayname: "<颜色>物品名"
#      Mechanics.food.hunger: 10

# 2. 颜色使用
#    渐变: <gradient:#起始色:#结束色>
#    纯色: <颜色名> 或 <#六位HEX>
#    项目中颜色风格: 稀有物品用渐变，普通物品用纯色

# 3. Lore 风格（项目常用）
#    - "<#6f737d>» <#D5D6D8>描述文字"
#    » 是装饰性分隔符，灰色 » 接浅灰色文字

# 4. 父模型选择
#    item/generated  = 2D 物品（食物、材料、护甲、宝石）
#    item/handheld   = 手持物品（武器、工具、魔杖）
#    block/cube_all  = 全尺寸方块
#    block/stairs    = 楼梯
#    block/slab      = 台阶

# 5. 机制启用
#    所有机制在 mechanics.yml 中必须 enabled: true
#    否则物品配置中的机制定义会被静默忽略
```
