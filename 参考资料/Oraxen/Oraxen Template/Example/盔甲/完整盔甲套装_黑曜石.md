# 完整盔甲套装 — 黑曜石 (Obsidian)

> **适用版本**: Minecraft 1.21.2+ (组件方式)
> **设计理念**: 纯耐久型防御套装 -- 极致耐久度，专注护甲，无生命加成
> **参考来源**: 项目 `Oraxen/items/armors.yml` 的 `obsidian` 套装 (4件)
> **推荐对比阅读**: `完整盔甲套装_绿宝石.md` (生命强化型) 和 `完整盔甲套装_红宝石.md` (标准防御型)

---

## 套装概览

黑曜石套装是"耐久之王"的范例。它的设计理念与绿宝石套装截然不同:

| 设计维度 | 绿宝石套装 | **黑曜石套装** |
|----------|:----------:|:--------------:|
| 核心特色 | HP 加成 (生命强化) | **10倍耐久度 (耐久之王)** |
| 护甲值 | 钻石标准 (20合计) | 低于钻石 (15合计) |
| 护甲韧性 | 钻石标准 (每件2) | 无 (韧性=0) |
| HP 加成 | +10 (5心) | **无** (纯防御型) |
| 定位 | 血牛坦克 | 永不磨损的日常护甲 |

| 部位 | 物品 ID | 耐久度 | 护甲值 | 护甲韧性 | HP加成 | 槽位 |
|------|---------|:------:|:------:|:--------:|:------:|:----:|
| 头盔 | `obsidian_helmet` | 4370 | 2 | 0 | 0 | HEAD |
| 胸甲 | `obsidian_chestplate` | 6350 | 6 | 0 | 0 | CHEST |
| 护腿 | `obsidian_leggings` | 5950 | 5 | 0 | 0 | LEGS |
| 靴子 | `obsidian_boots` | 5160 | 2 | 0 | 0 | FEET |
| **合计** | | **21,830** | **15** | **0** | **0** | |

> **对比**: 原版钻石全套耐久 = 1,815 (363+528+495+429)。黑曜石套装总耐久 = 21,830 —— 约为钻石套的 **12 倍**。

## 为什么是"纯耐久型"设计？

黑曜石套装的设计哲学体现了 Minecraft 装备设计中一个重要的权衡:

```
           高耐久度 ←→ 高属性值
              ↑           ↑
         黑曜石套装    绿宝石套装
       (12x 钻石耐久)  (钻石护甲 + HP加成)
```

**三种典型设计路线**:

| 路线 | 代表套装 | 耐久度 | 护甲 | 额外属性 | 适用场景 |
|------|----------|:------:|:----:|:--------:|----------|
| 纯耐久型 | **黑曜石** | 极高 | 中 | 无 | 日常探索、长时间冒险 |
| HP 强化型 | 绿宝石 | 中 | 高 | +HP | Boss 战、高伤害场景 |
| 标准防御型 | 红宝石 | 中 | 高 | 韧性 | 通用战斗 |

> **设计启示**: 不要试图在一个套装里塞入所有最强属性。让不同套装各有侧重, 给玩家选择的空间——这才是好设计。

## 完整 YAML 配置 (4件套)

```yaml
# =============================================================================
# 黑曜石盔甲套装 — 组件方式 (Minecraft 1.21.2+)
#
# 设计理念: 纯耐久型防御套装
#   - 耐久度 = 原版钻石套的 12 倍 (每件 10x)
#   - 护甲值略低于钻石套标准 (合计 15 vs 钻石 20)
#   - 无护甲韧性 (0)
#   - 无额外 HP 加成 (纯防御, 不强化生命)
#   - 定位: 永不磨损的日常冒险装备
#
# 与绿宝石套装的对比:
#   - 绿宝石: 高属性值 + HP 加成 + 标准耐久
#   - 黑曜石: 极致耐久 + 中等护甲 + 无 HP 加成
#   两者互补, 给玩家不同的选择
#
# 使用方法: 全局替换 "obsidian" 为你的盔甲名称, "Obsidian" 为显示名称
# =============================================================================

# ====================================================================
# 1. 黑曜石头盔 — obsidian_helmet
# ====================================================================
obsidian_helmet:
  # ---- 显示名称 ----
  # 颜色选择了深紫色渐变, 呼应黑曜石的深紫色游戏外观
  # #4B36B1 = 深靛蓝紫色, #6699FF = 柔和亮蓝色
  # 与绿宝石套装 (#89E59D → #37C6BA 绿/青色系) 形成视觉区分
  displayname: <gradient:#4B36B1:#6699FF>Obsidian Helmet

  # ---- 基础材质 ----
  # 同样是 PAPER, 与绿宝石套装保持一致。所有属性由下方 AttributeModifiers 精确控制。
  material: PAPER

  # ---- 物品描述 ----
  # 简洁明了地告知玩家核心特色: "Ludicrous durability" (滑稽的耐久度)
  # 与绿宝石套装的 "Gives X extra ♥" 形成对比——一个强调耐久之"量", 一个强调生命之"质"
  lore:
    - <#6f737d>» <#D5D6D8>Ludicrous durability

  # ---- 物品组件 ----
  Components:
    max_stack_size: 1

    # ---- 耐久度: 重点对比 ----
    #
    #  套装    头盔    胸甲    护腿    靴子     总耐久    倍数
    #  钻石     363    528    495    429     1,815     1x
    #  绿宝石   437    635    595    516     2,183    ~1.2x
    #  红宝石   547    792    742    643     2,724    ~1.5x
    #  黑曜石  4370   6350   5950   5160    21,830   ~12x ← 耐久之王!
    #
    # durability.value 设计逻辑:
    #   每个部位的耐久都是原版钻石对应部位的 10 倍:
    #     钻石头盔 363 x 10 ≈ 3630 → 设为 4370 (稍高)
    #     钻石胸甲 528 x 10 ≈ 5280 → 设为 6350 (稍高)
    #     钻石护腿 495 x 10 ≈ 4950 → 设为 5950 (稍高)
    #     钻石靴子 429 x 10 ≈ 4290 → 设为 5160 (稍高)
    #   实际取值为钻石 x10 后再上浮, 进一步强化"耐久之王"定位。
    #
    # durability.damage_entity_hit: true
    #   即使用黑曜石头盔打人也会消耗耐久。
    #   不过以 4370 的耐久来说, 这个消耗基本可以忽略不计。
    #
    durability:
      value: 4370                        # 钻石 x10 + 额外上浮
      damage_entity_hit: true

    equippable:
      slot: HEAD
      model: oraxen:obsidian             # 注意: 4件套 model 名相同

  # ---- 属性修改器 ----
  #
  # 黑曜石套装只配置了 ARMOR 属性, **没有** MAX_HEALTH 和 ARMOR_TOUGHNESS。
  # 这是有意为之的设计选择:
  #   - 无 MAX_HEALTH: 黑曜石定位是"永不磨损的日常护甲", 不是"战斗用血牛装"
  #   - 无 ARMOR_TOUGHNESS: 韧性=0 意味着高伤攻击的穿透效果更明显
  #     (韧性越低, 面对高伤时护甲的减免效果衰减越严重)
  #   - 低护甲值: 头盔=2 (相当于锁链/铁头盔), 不是钻石的 3
  #
  # 这种设计让黑曜石套装在高难度战斗中不如绿宝石套装,
  # 但在日常探险中几乎不需要修理——这就是"耐久优先"的取舍。
  #
  AttributeModifiers:
    # 护甲值: 2 (铁/锁链头盔水平, 低于钻石的 3)
    - attribute: ARMOR
      amount: 2
      operation: 0
      slot: HEAD

  # ---- 资源包配置 ----
  Pack:
    generate_model: true
    parent_model: item/generated
    textures:
      - default/armors/obsidian_helmet


# ====================================================================
# 2. 黑曜石胸甲 — obsidian_chestplate
# ====================================================================
obsidian_chestplate:
  displayname: <gradient:#4B36B1:#6699FF>Obsidian Chestplate
  material: PAPER
  lore:
    - <#6f737d>» <#D5D6D8>Ludicrous durability

  Components:
    max_stack_size: 1
    durability:
      value: 6350                        # 钻石胸甲 (528) x 10 + 上浮
      damage_entity_hit: true
    equippable:
      slot: CHEST
      model: oraxen:obsidian

  AttributeModifiers:
    # 胸甲护甲值: 6 (铁水平, 低于钻石的 8)
    - attribute: ARMOR
      amount: 6
      operation: 0
      slot: CHEST

  Pack:
    generate_model: true
    parent_model: item/generated
    custom_model_data: 2
    textures:
      - default/armors/obsidian_chestplate


# ====================================================================
# 3. 黑曜石护腿 — obsidian_leggings
# ====================================================================
obsidian_leggings:
  displayname: <gradient:#4B36B1:#6699FF>Obsidian Leggings
  material: PAPER
  lore:
    - <#6f737d>» <#D5D6D8>Ludicrous durability

  Components:
    max_stack_size: 1
    durability:
      value: 5950                        # 钻石护腿 (495) x 10 + 上浮
      damage_entity_hit: true
    equippable:
      slot: LEGS
      model: oraxen:obsidian

  AttributeModifiers:
    # 护腿护甲值: 5 (铁=5, 钻石=6 — 略低于钻石)
    - attribute: ARMOR
      amount: 5
      operation: 0
      slot: LEGS

  Pack:
    generate_model: true
    parent_model: item/generated
    textures:
      - default/armors/obsidian_leggings


# ====================================================================
# 4. 黑曜石靴子 — obsidian_boots
# ====================================================================
#
# 注意: 源配置中 displayname 写的是 "Boots Boots" —— 这是一个明显的笔误,
# 应该是 "Obsidian Boots"。此处已修正。
#
obsidian_boots:
  displayname: <gradient:#4B36B1:#6699FF>Obsidian Boots
  material: PAPER
  lore:
    - <#6f737d>» <#D5D6D8>Ludicrous durability

  Components:
    max_stack_size: 1
    durability:
      value: 5160                        # 钻石靴子 (429) x 10 + 上浮
      damage_entity_hit: true
    equippable:
      slot: FEET
      model: oraxen:obsidian

  AttributeModifiers:
    # 靴子护甲值: 2 (铁/锁链靴子水平, 低于钻石的 3)
    - attribute: ARMOR
      amount: 2
      operation: 0
      slot: FEET

  Pack:
    generate_model: true
    parent_model: item/generated
    textures:
      - default/armors/obsidian_boots
```

## 设计对比总结

### 三种套装, 三种定位

| 维度 | 绿宝石 | **黑曜石** | 红宝石 |
|------|:------:|:----------:|:------:|
| 耐久度 (相对钻石) | 1.2x | **12x** | 1.5x |
| 护甲值合计 | 20 (钻石级) | 15 (铁级) | 20 (钻石级) |
| 护甲韧性 | 8 (钻石级) | 0 (无) | 8 (钻石级) |
| HP 加成 | +10 (5心) | 0 | 0 |
| 专长 | 高 HP + 高防御 | **超高耐久** | 标准高防御 |
| 玩家选择理由 | "我需要更多生命值应对 Boss" | "我不想频繁修理装备" | "我要标准的强力防护" |

### 套装设计的核心原则

```
一个好的装备体系应该让玩家面临有意义的选择, 而不是一个套装的每一项都是最强。

反例 (糟糕设计):
  ┌─────────────────────────────────────┐
  │ 全能套装: 最高耐久 + 最高护甲 + 最高HP  │
  │ → 玩家没有选择空间, 其他套装毫无意义   │
  └─────────────────────────────────────┘

正例 (本项目设计):
  ┌──────────────┐ ┌──────────────┐ ┌──────────────┐
  │  绿宝石套装   │ │ 黑曜石套装   │ │  红宝石套装   │
  │  HP强化坦克   │ │  耐久之王    │ │  标准高防     │
  │  选择理由:    │ │  选择理由:   │ │  选择理由:    │
  │  Boss战生存   │ │  日常不修理  │ │  通用战斗     │
  └──────────────┘ └──────────────┘ └──────────────┘
      各有取舍, 各有场景 → 玩家需要思考后做出选择
```

## 如何基于此模板创建自己的纯耐久套装

1. **决定耐久倍数**: 你的套装耐久是钻石的几倍? 5x? 10x? 20x? 越高越"黑曜石化"
2. **决定护甲水平**: 护甲值设为铁级 (15) 还是钻石级 (20)? 耐久越高, 护甲应越低以保持平衡
3. **决定是否有次级属性**: 是否加护甲韧性? (本套装全部不加)
4. **命名和配色**: 深色、坚硬质感的名字 (Obsidian, Bedrock, Steel 等) + 冷色调渐变色
5. **纹理**: 黑色/深紫色系纹理, 体现坚硬、耐久的感觉
