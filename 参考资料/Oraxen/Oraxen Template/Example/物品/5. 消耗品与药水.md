# 消耗品与药水

> 涵盖：投掷型药水(Splash Potion)的颜色+效果配置、右键消耗品（药品/卷轴等）、
> Components 系统与 Mechanics 系统的两种配置方式对比、多效果叠加。

---

## 1. 自定义投掷型药水 -- Splash Potion

> 原版药水系统中最灵活的投掷物。Oraxen 允许自定义颜色和效果。

```yaml
# =============================================================================
# Wither Potion - 凋零药水（投掷型）
# 设计理念：仿原版喷溅药水，但应用自定义凋零效果
# 颜色使用 RGB 格式 (红, 绿, 蓝)，每个分量 0~255
# =============================================================================
wither_potion:
  # --- 显示名称 ---
  # 纯灰色 #6f737d —— 契合凋零的暗黑色调
  displayname: <#6f737d>凋零药水
  # 英文参考: Wither Potion

  # --- 基础材质 ---
  # SPLASH_POTION: 原版喷溅药水
  # 选择这个材质的原因：
  #   - 可以被投掷（右键扔出去）
  #   - 落地后产生区域效果
  #   - Oraxen 会自动注入 PotionEffects 和自定义颜色
  material: SPLASH_POTION

  # --- injectID ---
  # 为什么设为 false？
  # 因为投掷型药水在扔出后会变成实体，实体落地后消失
  # Oraxen 不需要追踪它是否"在物品栏中"——它瞬间就没了
  # 设置 false 避免不必要的 NBT 标记
  injectID: false

  # =========================================================================
  # color: 药水颜色（RGB 格式）
  # 格式: R, G, B（逗号+空格分隔）
  # 每个分量范围: 0~255
  # 34, 0, 10 = 深暗红色——凋零主题色
  # 颜色会用于：
  #   - 药水瓶中的液体颜色
  #   - 投掷后的粒子颜色
  #   - 滞留药水区域粒子的颜色
  # =========================================================================
  color: 34, 0, 10                     # 深暗红——凋零色调

  # =========================================================================
  # PotionEffects: 药水效果列表
  # 投掷后会对范围内的所有实体施加这些效果
  # =========================================================================
  PotionEffects:
    # --- 凋零效果 ---
    # type: wither —— 凋零效果（持续扣血，类似凋零骷髅攻击）
    # 注意：type 是小写英文名，不是 minecraft: 前缀格式
    - type: wither
      # duration: 效果持续时间（单位：刻 ticks）
      #   200 ticks = 10 秒
      #   注意！PotionEffects 中 duration 的单位是刻(tick)
      #   与 Components.consumable 中的 duration(秒)不同！这是历史遗留的不一致情况
      #   换算: 秒 × 20 = 刻
      duration: 200                    # 10 秒 (200 ticks)

      # amplifier: 效果等级
      #   2 = III 级凋零（每 2 秒扣 1.5❤，参考原版数据）
      #   0 = I 级, 1 = II 级, 2 = III 级
      amplifier: 2

      # ambient: 是否环境来源
      #   false = 粒子不透明（玩家清晰看到被负面效果命中）
      ambient: false

      # particles: 是否显示粒子效果
      particles: true

      # icon: 是否在右上角显示效果图标
      icon: true
```

## 2. 消耗品 -- 右键使用的药品/卷轴

> 非投掷型消耗品：右键使用 1 个，获得药水效果。

### 2.1 新版 Components 方式（1.21.2+ 推荐）

```yaml
# =============================================================================
# 魔力药水 - 使用 Components 系统
# 右键喝掉，获得速度和生命恢复效果
# 整个药水瓶被消耗——使用后物品栏少 1 个
# =============================================================================
magic_potion:
  displayname: <gradient:#FF00FF:#8800FF>魔力药水
  # 英文参考: Magic Potion
  material: POTION                     # 用普通药水瓶作为伪装材质
  Pack:
    generate_model: true
    parent_model: item/generated
    textures:
      - magic_potion.png

  Components:
    # --- 消耗品组件 ---
    # 注意：这里只设置 consumable，不设置 food
    # 意味着这个物品纯粹是"使用后触发效果"，不恢复饥饿值
    consumable:
      consume_seconds: 1.6             # 饮用时间 1.6 秒
      animation: DRINK                 # 喝药动画
      sound: entity.generic.drink
      has_consume_particles: true

      on_consume_effects:
        # --- 效果组 1：速度 + 生命恢复（100% 同时触发）---
        - type: apply_effects
          effects:
            # 速度 II —— 移动速度 +40%
            minecraft:speed:
              duration: 30             # 30 秒（Components 中 duration 是秒）
              amplifier: 1             # II 级（+40% 移速）
              ambient: false           # 主动效果——粒子清晰
              show_particles: true
              show_icon: true

            # 生命恢复 I —— 缓慢回血
            minecraft:regeneration:
              duration: 10             # 10 秒（恢复约 4❤）
              amplifier: 0             # I 级
              ambient: false
              show_particles: true
              show_icon: true
          probability: 1.0             # 100% 触发

        # --- 效果组 2：清除中毒（100% 独立触发）---
        # remove_effects: 移除指定的药水效果
        # 这里设计为"喝药后自动清除中毒状态"——模拟万能解毒剂
        - type: remove_effects
          effects:
            - minecraft:poison         # 移除中毒
            - minecraft:wither         # 移除凋零
          probability: 1.0

    # =========================================================================
    # use_cooldown: 使用冷却（可选）
    # 防止玩家连续狂喝药水
    # =========================================================================
    use_cooldown:
      seconds: 2.5                     # 2.5 秒冷却
      # group: oraxen:healing_items    # 可选：同组物品共享冷却
```

## 3. 两种方式详细对比

### 字段对照表

| 功能 | Components 方式 (1.21.2+) | Mechanics 方式 (旧版) |
|------|--------------------------|----------------------|
| **消耗物品** | 内置于 consumable 组件 | `Mechanics.consumable: {}` |
| **效果字段** | `effects:` 映射表 | `consumable_potion_effects:` 映射表 |
| **duration 单位** | **秒** | **刻 (ticks)** |
| **粒子字段名** | `show_particles` | `particles` |
| **图标字段名** | `show_icon` | `icon` |
| **环境来源字段名** | `ambient` | `ambient` |
| **多效果独立概率** | 支持（多个 apply_effects 组） | 不支持（所有效果共享概率） |
| **移除效果** | `remove_effects` 类型 | 不支持 |
| **清除所有效果** | `clear_all_effects` 类型 | 不支持 |
| **使用冷却** | `Components.use_cooldown` | 不支持（需额外机制） |

### duration 单位陷阱

**这是最容易出错的地方！务必注意：**

```yaml
# Components 方式 —— duration 单位是秒
Components:
  consumable:
    on_consume_effects:
      - type: apply_effects
        effects:
          minecraft:speed:
            duration: 30             # 30 秒！不是刻！

# Mechanics 方式 —— duration 单位是刻
Mechanics:
  consumable_potion_effects:
    speed:
      duration: 600                  # 600 刻 = 30 秒！
```

> **记忆口诀：** "组件秒，机制刻" —— Components 用秒，Mechanics 用刻。

## 4. 完整示例：多效果急救包

展示 Components 系统的所有 `on_consume_effects` 类型：

```yaml
# =============================================================================
# 全能急救包 - 展示所有 on_consume_effects 效果类型
# =============================================================================
ultimate_first_aid:
  displayname: <gradient:#FF0000:#FFD700>全能急救包
  # 英文参考: Ultimate First Aid
  material: PAPER
  Pack:
    generate_model: true
    parent_model: item/generated
    textures:
      - first_aid_kit.png

  Components:
    consumable:
      consume_seconds: 2.5
      animation: EAT                  # 使用包扎动画
      sound: entity.generic.eat
      has_consume_particles: true

      on_consume_effects:
        # --- 类型 1: apply_effects —— 应用药水效果 ---
        # 必定获得生命恢复和抗性提升
        - type: apply_effects
          effects:
            minecraft:regeneration:
              duration: 10            # 10 秒恢复
              amplifier: 1            # II 级（快速恢复）
              ambient: false
              show_particles: true
              show_icon: true
            minecraft:resistance:
              duration: 30            # 30 秒减伤
              amplifier: 0            # I 级（20% 减伤）
              ambient: false
              show_particles: true
              show_icon: true
          probability: 1.0

        # --- 类型 2: remove_effects —— 移除负面效果 ---
        # 清除中毒和凋零
        - type: remove_effects
          effects:
            - minecraft:poison
            - minecraft:wither
            - minecraft:nausea
          probability: 1.0

        # --- 类型 3: clear_all_effects —— 清除所有效果 ---
        # 注意：这会清除所有正面和负面效果！
        # 只在特定场景使用（如"净化"类物品）
        # - type: clear_all_effects

        # --- 类型 4: play_sound —— 播放音效 ---
        # 额外的音效反馈（与 consumable.sound 叠加）
        - type: play_sound
          sound: entity.player.levelup  # 升级音效——让玩家感觉"获救了"
          probability: 1.0

        # --- 类型 5: teleport_randomly —— 随机传送 ---
        # 紧急逃生：使用后随机传送（在 8 格直径内）
        # - type: teleport_randomly
        #   diameter: 8                  # 传送范围直径（默认 16）

    # --- 使用冷却 ---
    use_cooldown:
      seconds: 60                      # 60 秒冷却——急救包不能连用
      group: oraxen:first_aid          # 同类物品共享冷却

    # --- 消耗后返还物品 ---
    # 使用后返还一个"用过的绷带"（或空瓶等）
    # use_remainder:
    #   minecraft_type: PAPER          # 原版物品
    #   # oraxen_item: used_bandage    # 或自定义物品 ID
    #   amount: 1
```
