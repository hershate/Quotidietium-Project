# 音乐唱片

> 自定义音乐唱片配置。涵盖：物品端配置（Items）、歌曲端配置（sounds.yml）。
> 基于项目实际使用的 Welcome Disk 完整配置。

---

## 工作原理简述

自定义音乐唱片需要两个部分的配置协作：

1. **物品配置（Items YAML）** -- 定义唱片物品的外观和行为，通过 `jukebox_playable` 组件指向一个歌曲键
2. **歌曲配置（sounds.yml）** -- 定义歌曲键对应的音频文件、元数据、唱片机信息

```
玩家右键唱片机 → jukebox_playable 组件 → song_key 指向 → sounds.yml 中的歌曲定义 → 播放 .ogg 文件
```

## 1. 物品配置 -- Welcome Disk

```yaml
# =============================================================================
# Welcome Disk - 自定义音乐唱片
# 使用 Components.jukebox_playable 而非旧版 Mechanics.music_disc
# =============================================================================
welcome_disk:
  # --- 显示名称 ---
  # 从紫色(#9055FF)渐变到青色(#13E2DA) —— 传达"欢迎"的温暖感
  displayname: <gradient:#9055FF:#13E2DA>Welcome Disk
  # 英文参考: Welcome Disk
  material: PAPER                      # 唱片不需要继承原版唱片属性，用 PAPER

  # =========================================================================
  # Components - 使用新版组件系统
  # =========================================================================
  Components:

    # --- 最大堆叠数 ---
    # 唱片应该不可堆叠（1 个占 1 格）
    # 这符合原版唱片的行为——你不会想要"64 个唱片叠一起"
    max_stack_size: 1

    # =========================================================================
    # jukebox_playable 组件 —— 唱片机播放功能
    # 这是 Minecraft 1.21+ 的新版唱片组件
    # 替代了旧版的 Mechanics.music_disc
    # =========================================================================
    jukebox_playable:
      # show_in_tooltip: 是否在物品提示框中显示歌曲信息
      #   true = 鼠标悬停时显示"歌曲: xxx"（像原版唱片一样）
      #   false = 不显示（适合隐藏彩蛋歌曲）
      show_in_tooltip: true

      # song_key: 歌曲键名 —— 指向 sounds.yml 中的歌曲定义
      #
      # 命名空间说明：
      #   oraxen:welcome
      #   └─┬──┘ └──┬──┘
      #     命名空间   歌曲 ID
      #
      # 命名空间可以是:
      #   oraxen:...    - Oraxen 自定义歌曲（最常用）
      #   minecraft:... - 原版歌曲（如 minecraft:music_disc.cat）
      #
      # 歌曲 ID "welcome" 对应 sounds.yml 中:
      #   sounds:
      #   welcome:       <-- 这个 id
      #     category: records
      #     sound: welcome.ogg
      #     ...
      #
      # 注意：song_key 不需要写 .ogg 扩展名，只需要 sounds.yml 中定义的 id
      song_key: oraxen:welcome

  # =========================================================================
  # 外观配置
  # =========================================================================
  Pack:
    generate_model: true
    # parent_model: item/handheld —— 唱片用手持模型（有点像手持物品的倾斜感）
    # 使用 handheld 而不是 generated，因为唱片在原版中也是这样显示的
    parent_model: item/handheld
    textures:
      - default/welcome_disk.png
```

## 2. 歌曲配置 -- sounds.yml

> 文件位置：`plugins/Oraxen/sounds.yml`

```yaml
# =============================================================================
# sounds.yml - Oraxen 自定义音效配置文件
# 文件路径: plugins/Oraxen/sounds.yml
# =============================================================================

# --- 全局设置 ---
settings:
  # automatically_generate: 是否自动生成 sounds.json
  #   true = Oraxen 自动根据下方 sounds 列表生成客户端音效注册文件
  #   false = 你需要手动管理 sounds.json
  #   推荐保持 true（省心）
  automatically_generate: true

# --- 歌曲列表 ---
sounds:

  # ===========================================================================
  # Welcome 歌曲
  # ===========================================================================
  welcome:                        # 歌曲 ID —— 对应于物品侧的 song_key: oraxen:welcome

    # category: 音效类别
    #   records = 唱片机音效类别（最重要的选项！）
    #   使用 records 类别意味着：
    #     - 玩家可以在设置中独立调整唱片音量
    #     - 歌曲会像原版唱片一样在唱片机中播放
    #     - 支持 stream 流式播放（长音频）
    category: records

    # sound: 音频文件路径
    #   welcome.ogg —— 放在 plugins/Oraxen/pack/sounds/welcome.ogg
    #   .ogg 扩展名可省略（Oraxen 自动查找 .ogg）
    #   音频文件要求：
    #     - 格式: OGG Vorbis（Minecraft 只支持 OGG）
    #     - 采样率: 推荐 44100Hz
    #     - 位深度: 16-bit
    #     - 声道: 单声道或立体声均可
    sound: welcome.ogg

    # stream: 是否使用流式播放
    #   true = 流式播放（适合长音频，边加载边播放）
    #   false = 完全加载后再播放（适合短音效）
    #   对于唱片歌曲，必须设为 true！
    #   —— 唱片歌曲通常 > 1 分钟，流式播放避免加载卡顿
    stream: true

    # subtitle: 字幕文本（可选）
    #   当玩家在字幕设置中开启时，会显示这个文字
    subtitle: Welcome Song

    # =========================================================================
    # jukebox 唱片机配置 —— 控制歌曲在唱片机中的表现
    # 注意：这里的配置会自动生成对应的数据包
    # =========================================================================
    jukebox_song:
      # description: 唱片机界面的歌曲描述
      #   使用文本组件列表格式（每项含 text/color/italic 等字段）
      #   当玩家把唱片放入唱片机后，这个文字会显示在提示框中
      description:
        - text: "Welcome"
          color: "gold"
        - text: "Song"
          color: "yellow"

      # length_in_seconds: 歌曲时长（秒，数字）
      #   180 = 3 分钟
      #   这个值用于：
      #     - 唱片机界面显示时长
      #     - 客户端播放进度同步
      #     - 比较器输出信号时长
      #
      #   注意：你需要确保音频文件的实际时长与这里一致
      #   可以使用音频编辑软件（如 Audacity）查看精确时长
      length_in_seconds: 180

      # comparator_output: 比较器输出强度
      #   唱片机旁边的比较器会输出红石信号
      #   信号强度 = 这个值（0~15）
      #   12 = 较高的信号强度——表示歌曲仍在播放中
      #   参考：原版唱片取值 1~15 不等
      comparator_output: 12
```

### 另一个实际示例：长歌曲配置

```yaml
# ===========================================================================
# ONEXHS - 琐欢行乐 主奏曲 - 盛辉（更长、更复杂的歌曲）
# ===========================================================================
sounds:
  nugalaetiter_thick:
    category: records
    sound: onexhs/nugalaetiter_thick.ogg    # 子目录下的音频文件
    stream: true
    subtitle: "ONEXHS - Nugalaetiter - 琐欢行乐 主奏曲 - 盛辉"
    jukebox_song:
      description:
        - text: "ONEXHS"
          color: "green"
        - text: "- Nugalaetiter - 琐欢行乐 主奏曲 - 盛辉"
          color: "gold"
      length_in_seconds: 314                  # 5 分 14 秒
      comparator_output: 12
```

## 3. 文件放置说明

```
plugins/Oraxen/
  items/
    welcome_disk.yml              # 唱片物品配置（你写的 YAML）
  sounds.yml                      # 歌曲定义配置文件
  pack/
    textures/
      default/
        welcome_disk.png          # 唱片纹理（建议 16x16）
    sounds/
      welcome.ogg                 # 歌曲音频文件（OGG Vorbis 格式）
      onexhs/
        nugalaetiter_thick.ogg    # 子目录中的歌曲文件
        nugalaetiter_light.ogg
```

## 4. 旧版 Mechanics.music_disc 对照（仅供参考）

如果你需要兼容 Minecraft 1.20.4 及更早版本，使用旧版 Mechanics 方式：

```yaml
# =============================================================================
# 旧版唱片配置（Minecraft 1.20.4 及更早版本）
# 仅供参考，新项目不要使用
# =============================================================================
# legacy_disk:
#   displayname: "<gradient:#9055FF:#13E2DA>Old Welcome Disk"
#   material: PAPER
#   Pack:
#     generate_model: true
#     parent_model: item/handheld
#     textures:
#       - default/welcome_disk.png
#   Mechanics:
#     music_disc:
#       song: oraxen:welcome        # 旧版字段：song（不是 song_key）
#       # 旧版不支持 show_in_tooltip（始终显示）
```

### 新旧版对照

| 功能 | 新版 Components (1.21+) | 旧版 Mechanics |
|------|------------------------|---------------|
| 定义方式 | `Components.jukebox_playable` | `Mechanics.music_disc` |
| 歌曲键字段 | `song_key` | `song` |
| 提示信息控制 | `show_in_tooltip: true/false` | 不支持（始终显示） |
| sounds.yml 适配 | 自动 | 自动 |

## 5. 歌曲时长与比较器输出参考

| 歌曲时长 | 推荐 comparator_output | 说明 |
|---------|:---:|------|
| < 60s | 3~5 | 短歌曲 |
| 60~120s | 6~8 | 中等歌曲 |
| 120~180s | 9~12 | 标准歌曲 |
| 180~300s | 12~14 | 长歌曲 |
| > 300s | 14~15 | 超长歌曲 |

`comparator_output` 在唱片机播放期间持续输出，可用于制作"音乐门"、"节奏灯"等红石装置。

## 6. 快速排查常见问题

| 问题 | 原因 | 解决 |
|------|------|------|
| 右键唱片机没反应 | `song_key` 拼写或命名空间错误 | 检查 sounds.yml 中 id 是否一致 |
| 放进唱片机但没声音 | OGG 文件格式问题或路径不对 | 确保是 OGG Vorbis 格式，放在 `pack/sounds/` 下 |
| 歌曲播放但卡顿 | `stream: false` 或文件过大 | 大文件设为 `stream: true` |
| 提示框不显示歌曲信息 | `show_in_tooltip: false` | 改为 `true` |
| 歌曲时长显示错误 | sounds.yml 中 duration 与实际不一致 | 用音频软件查看精确时长后更新 |
