# 武器

> 多种武器类型的实战配置对比，从极简到复杂。
> 涵盖：玻璃剑（极简）、雷神之剑（主动法术）、吸血之剑（被动效果）、战斗弓（多阶段模型）、武士刀（快速武器）。

---

## 1. 玻璃剑 -- 极简武器

> 最简单的武器配置：高伤害 + 极低耐久 + 2D 纹理。适合作为"新手教学武器"。

```yaml
# =============================================================================
# 玻璃剑 - 极简武器配置
# 设计理念：用最少的配置行数创造一个可用武器
# 核心特点：伤害 10（高于钻石剑的 7），但耐久只有 8（几乎一击就碎）
#           模拟"玻璃锋利但易碎"的概念
# =============================================================================
glass_sword:

  # --- 显示名称 ---
  # 纯白色 <#D5D6D8>：低调不花哨
  displayname: <#D5D6D8>玻璃剑          # 中文名
  # 英文参考: Glass Sword

  # --- 基础材质 ---
  # 为什么用 DIAMOND_SWORD？
  # - 让物品继承剑的"可攻击"行为（左键能打怪）
  # - 继承剑的横扫攻击（Sweep Attack）
  # - 如果用 PAPER，玩家左键将无法造成伤害（除非额外配置 AttributeModifiers）
  material: DIAMOND_SWORD

  # --- 描述文字 ---
  # lore 是可选的，但建议加上——让玩家知道这个武器"易碎"
  lore:
    - <#6f737d>» <#D5D6D8>易碎        # 灰色箭头装饰 + 浅灰文字

  # =========================================================================
  # 属性修改器 (AttributeModifiers) - 控制武器的数值属性
  #
  # 每个属性修改器有三个关键参数：
  #   attribute: 要修改的属性类型（见下方属性列表）
  #   amount:    修改量（正数为增加，负数为减少）
  #   operation: 运算方式（0=直接加，1=按比例加，2=百分比乘）
  #   slot:      生效槽位（见下方槽位说明）
  # =========================================================================
  AttributeModifiers:

    # --- 攻击伤害 ---
    # attribute: ATTACK_DAMAGE - 每次命中造成的基础伤害
    #   - 1 点伤害 = 半颗心（0.5❤）
    #   - amount: 10 = 5 颗心的基础伤害（钻石剑默认 7 = 3.5❤）
    #   - 最终伤害 = 基础伤害 × 攻击冷却条百分比
    # operation: 0 (ADD_NUMBER) - 直接在原基础上加值
    #   其他选项: 1 = ADD_SCALAR（按比例加）, 2 = MULTIPLY_SCALAR_1（百分比乘）
    # slot: HAND - 仅在主手时生效
    - attribute: ATTACK_DAMAGE
      amount: 10                        # 伤害值（半心数 = amount / 2）
      operation: 0                      # 0 = 直接加值（ADD_NUMBER）
      slot: HAND                        # 只主手生效

    # --- 攻击速度 ---
    # attribute: ATTACK_SPEED - 控制攻击冷却恢复速度
    #   - Minecraft 基础攻速为 4.0（每秒可攻击 4 次）
    #   - 剑默认攻速 1.6（每秒 1.6 次攻击，即每次攻击间隔 0.625 秒）
    #   - amount: 1.6 = 设置攻速为 1.6
    #   - 注意：如果你想要攻速比默认更快，需要 amount > 1.6
    #     例如 amount: 5.0 意味着每秒可攻击 5 次
    #
    # 攻速参考值：
    #   1.6  = 剑的标准速度（约 0.6 秒一次）
    #   2.0  = 稍快
    #   3.2  = 快（Storm Sword 使用的值）
    #   5.0  = 非常快（武士刀使用的值）
    #   10.0 = 极快（几乎无冷却）
    - attribute: ATTACK_SPEED
      amount: 1.6                       # 标准剑速
      operation: 0
      slot: HAND

  # =========================================================================
  # 外观配置
  # =========================================================================
  Pack:
    # generate_model: true + parent_model: item/handheld
    # 生成一个 2D 纹理的物品，但在手中以"工具握持角度"显示
    # 这比 item/generated 更好看——物品在手中微微倾斜
    generate_model: true
    parent_model: item/handheld         # 倾斜握持，像真正的剑
    textures:
      - default/glass_sword.png

  # =========================================================================
  # 耐久度 - 使用 Components 系统（Minecraft 1.20.5+）
  #
  # Components.durability 有两种写法：
  #   简化写法: durability: 8          （仅设置最大耐久值）
  #   完整写法: durability: { value: 8, ... }（设置更多选项）
  #
  # 为什么玻璃剑耐久只有 8？
  #   8 次攻击就碎，模拟玻璃的脆弱。
  #   对比：原版钻石剑耐久 1561，这个只有它的 0.5%。
  # =========================================================================
  Components:
    durability: 8                       # 极低耐久，一击即碎的概念
```

## 2. 雷神之剑 (Storm Sword) -- 主动法术武器

> 右键释放闪电，带冷却时间。使用 3D 模型和多段闪电。

```yaml
# =============================================================================
# Storm Sword - 雷神之剑
# 设计理念：右键召唤闪电攻击目标区域
# 核心机制：thor（雷神）——冷却长（20秒）但效果震撼（5道闪电）
# =============================================================================
storm_sword:
  displayname: <gradient:#3685EC:#72C1E4>雷神之剑
  # 英文参考: Storm Sword
  material: DIAMOND_SWORD

  # --- 属性 ---
  # 攻击 10（5❤），攻速 3.2（钻石剑的两倍速度）
  AttributeModifiers:
    - attribute: ATTACK_DAMAGE
      amount: 10
      operation: 0
      slot: HAND
    - attribute: ATTACK_SPEED
      amount: 3.2                      # 快速攻击（每秒 3.2 次）
      operation: 0
      slot: HAND

  # --- Lore ---
  lore:
    - <#6f737d>» <#D5D6D8>右键召唤闪电   # 告诉玩家怎么用

  # =========================================================================
  # 3D 模型配置
  # generate_model: false - 不使用自动生成的 2D 模型
  # model: default/storm_sword - 指向你手动创建的 JSON 模型文件
  #   文件路径: plugins/Oraxen/pack/models/default/storm_sword.json
  #   这是 Blockbench 导出的 3D 模型，.json 扩展名可省略
  # =========================================================================
  Pack:
    generate_model: false              # 关闭自动生成，使用手动 3D 模型
    model: default/storm_sword         # 3D 模型文件路径

  # =========================================================================
  # Mechanics（机制）- Oraxen 物品的特殊能力
  # =========================================================================
  Mechanics:

    # --- thor 机制（雷神）---
    # 右键释放：在目标位置降下多道闪电
    # 每次使用后进入冷却，冷却期间右键无效
    thor:
      # lightning_bolts_amount: 闪电数量
      #   每道闪电对范围内的实体造成约 5 点伤害（2.5❤）
      #   5 道闪电 = 理论最大伤害约 25 点（12.5❤）
      #   但因为 random_location_variation，实际不一定全命中
      lightning_bolts_amount: 5

      # random_location_variation: 闪电落地随机偏移（单位：方块）
      #   1.5 = 闪电在目标位置周围 1.5 格半径内随机落地
      #   值越大，闪电越分散（难以全命中单一目标，但覆盖范围更广）
      #   值越小，闪电越集中（适合单体高伤害）
      #   建议范围：0.5（集中）~ 3.0（大范围）
      random_location_variation: 1.5

      # delay: 冷却时间（单位：毫秒 ms）
      #   20000ms = 20 秒
      #   为什么用毫秒而不是刻(ticks)？
      #   因为 Oraxen 内部使用 Java 的 System.currentTimeMillis() 做冷却判定
      #   毫秒精度比刻更精确（1 刻 = 50ms，但服务器刻可能不稳定）
      #
      #   换算参考：
      #     1000ms  = 1 秒
      #     3000ms  = 3 秒（快速法术）
      #     10000ms = 10 秒（标准冷却）
      #     20000ms = 20 秒（强力技能冷却）
      #     60000ms = 1 分钟（终极技能）
      delay: 20000                      # 20 秒冷却

      # charges（可选，未在示例中使用）
      #   -1  = 无限使用（默认）
      #   5   = 使用 5 次后物品消失
      #   10  = 使用 10 次后物品消失
      # 省略此参数等同于 -1（无限使用）
```

## 3. 吸血之剑 (Blood Sword) -- 被动效果组合

> 两个被动效果叠加：吸血（命中回血）+ 流血（概率持续伤害）。

```yaml
# =============================================================================
# Blood Sword - 吸血之剑
# 设计理念：被动效果武器——不需要右键，每次攻击都可能触发效果
# 核心机制：lifeleech（吸血）+ bleeding（流血）
# 两者是独立的被动效果，可以同时触发
# =============================================================================
blood_sword:
  displayname: <gradient:#FA7CBB:#F14658>吸血之剑
  # 英文参考: Blood Sword
  material: DIAMOND_SWORD

  lore:
    - <#6f737d>» <#D5D6D8>吸取敌人的生命
    - <#6f737d>» <#D5D6D8>使敌人流血

  AttributeModifiers:
    - attribute: ATTACK_DAMAGE
      amount: 8                         # 略低于 Storm Sword，因为有吸血补偿
      operation: 0
      slot: HAND
    - attribute: ATTACK_SPEED
      amount: 1.6                       # 标准速度
      operation: 0
      slot: HAND

  Pack:
    generate_model: false
    model: default/blood_sword          # 3D 模型

  Mechanics:

    # --- lifeleech 机制（吸血）---
    # 被动触发：每次用此武器命中实体时，恢复自身生命值
    # 不需要右键，不需要概率——每次命中必定吸血
    lifeleech:
      # amount: 每次命中吸取的生命值（单位：半颗心）
      #   2 = 恢复 1 颗心（2 点生命值）
      #   值越大吸血越多，但注意平衡性：
      #     - 1~2：轻微吸血，适合普通武器
      #     - 3~4：强力吸血，适合 Boss 武器
      #     - 5+： 生存模式可能过强
      # 实际回血 = amount × 0.5❤
      amount: 2                          # 每次命中恢复 1❤

    # --- bleeding 机制（流血）---
    # 被动触发：命中时以概率 chance 对目标施加持续流血伤害
    # 与 lifeleech 独立运作——一次攻击可能同时触发吸血 + 流血
    bleeding:
      # chance: 触发概率（0.0 ~ 1.0）
      #   0.3 = 30% 概率触发
      #   0.0 = 永不触发
      #   1.0 = 100% 必定触发
      chance: 0.3                        # 30% 概率

      # duration: 流血持续时间（单位：刻 ticks）
      #   20 ticks = 1 秒
      #   100 ticks = 5 秒
      #   目标被命中后，会在这 5 秒内持续受到 damage_per_interval 伤害
      #   持续时间越长总伤害越大：
      #     100 ticks / 20 间隔 = 5 次伤害
      #     5 × 0.5 = 2.5 点总伤害（约 1.25❤）
      duration: 100                      # 5 秒

      # damage_per_interval: 每次间隔造成的伤害（单位：半颗心）
      #   0.5 = 1/4 颗心
      #   1.0 = 1/2 颗心
      #   2.0 = 1 颗心
      #   注意：这个伤害忽略护甲，是真实伤害
      damage_per_interval: 0.5           # 每跳 0.25❤

      # interval: 伤害间隔（单位：刻 ticks）
      #   20 = 1 秒一次
      #   10 = 0.5 秒一次（更密集）
      #   40 = 2 秒一次（更稀疏）
      #   interval 越短，总伤害越高（在相同 duration 下更多次触发）
      interval: 20                       # 每秒一跳

  Components:
    durability: 500                      # 中等耐久
```

## 4. 战斗弓 (Combat Bow) -- 多阶段拉弓模型

> 展示弓类武器的 pulling_models 配置——不同拉弓阶段的渐变模型。

```yaml
# =============================================================================
# Combat Bow - 战斗弓
# 设计理念：比原版弓更强力的战斗弓
# 核心特点：pulling_models 三阶段拉弓模型
# =============================================================================
combat_bow:
  displayname: <gradient:#F69D84:#FAD98D>战斗弓
  # 英文参考: Combat Bow
  material: BOW                         # 必须用 BOW 材质才能正常射箭

  # --- 属性 ---
  # 弓的攻击伤害会影响箭的伤害
  # ATTACK_DAMAGE 用于近战（左键敲击），远程伤害由箭的初速度决定
  AttributeModifiers:
    - attribute: ATTACK_DAMAGE
      amount: 7                         # 近战伤害（同钻石剑）
      operation: 0
      slot: HAND

  Pack:
    generate_model: false
    model: default/combat_bow           # 主模型（未拉弓状态）

    # --- pulling_models（拉弓阶段模型）---
    # 当玩家按住右键拉弓时，模型会依次切换：
    #   拉弓进度 0% ~ 33%： 显示 combat_bow_pulling_0
    #   拉弓进度 34% ~ 66%：显示 combat_bow_pulling_1
    #   拉弓进度 67% ~ 100%: 显示 combat_bow_pulling_2
    #
    # 模型数量必须是 3 个，这是 Minecraft 原版弓的硬编码要求
    # 每个模型显示不同的弓弦拉开程度：
    #   pulling_0 = 轻微拉开
    #   pulling_1 = 半拉开
    #   pulling_2 = 完全拉开
    pulling_models:
      - default/combat_bow_pulling_0
      - default/combat_bow_pulling_1
      - default/combat_bow_pulling_2
```

## 5. 武士刀 (Katana) -- 高攻速低伤害的快速武器

> 攻速 5.0 = 每秒 5 次攻击，但每次伤害只有 5。展示"快攻"设计思路。

```yaml
# =============================================================================
# Katana - 武士刀
# 设计理念：高频低伤 vs 玻璃剑的低频高伤 —— 提供不同的战斗风格
# 攻速对比：
#   原版钻石剑: 攻速 1.6, 伤害 7 -----> DPS ≈ 11.2
#   玻璃剑:     攻速 1.6, 伤害 10 ----> DPS ≈ 16.0
#   武士刀:     攻速 5.0, 伤害 5 -----> DPS ≈ 25.0
# 武士刀理论 DPS 最高，但因为每次伤害低，受护甲减免影响更大
# =============================================================================
katana:
  displayname: <gradient:#F69D84:#FAD98D>武士刀
  # 英文参考: Katana
  material: DIAMOND_SWORD

  AttributeModifiers:
    - attribute: ATTACK_DAMAGE
      amount: 5                         # 低伤害（只有 2.5❤）
      operation: 0
      slot: HAND
    - attribute: ATTACK_SPEED
      amount: 5.0                       # 极高攻速（每秒 5 次）
      operation: 0
      slot: HAND

  Pack:
    generate_model: false
    model: default/katana               # 3D 模型

  Components:
    durability: 1000                    # 高耐久——快攻武器磨损慢
```

## 核心概念深入

### AttributeModifiers 的 slot 参数详解

`slot` 决定属性修改器在**哪个装备槽位**生效。不同 slot 的行为差异巨大：

| slot 值 | 含义 | 何时生效 | 使用场景 |
|---------|------|---------|---------|
| `HAND` | 主手 | 物品在主手时 | **武器伤害、攻速、工具效率** |
| `OFFHAND` | 副手 | 物品在副手时 | 盾牌、副手工具 |
| `HEAD` | 头部 | 装备在头盔槽 | **帽子、头盔** |
| `CHEST` | 胸甲 | 装备在胸甲槽 | **胸甲** |
| `LEGS` | 护腿 | 装备在护腿槽 | **护腿** |
| `FEET` | 靴子 | 装备在靴子槽 | **靴子** |
| `BODY` | 马铠位 | 装备在马铠槽 | 马铠、狼铠 |
| `ANY` | 任意槽 | 物品在**任何**装备槽 | 全局属性（如+移动速度的饰品） |
| `ARMOR` | 任意护甲槽 | HEAD/CHEST/LEGS/FEET 之一 | 护甲效果 |

**关键区别：**
- 武器的 `ATTACK_DAMAGE` 应使用 `HAND`——只有主手持有时伤害才生效
- 护甲的 `ARMOR` 应使用 `HEAD/CHEST/LEGS/FEET`——穿在对应部位才生效
- 通用饰品（如戒指）用 `ANY`——放哪个槽都生效

### 两种耐久度配置方式对比

当前项目使用 `Components.durability` 方式（新版）：

```yaml
# 方式一：Components 系统（1.20.5+，推荐）
Components:
  durability: 500                  # 简化写法：仅设置最大耐久
  # durability:
  #   value: 500                   # 完整写法
  #   damage_block_break: true     # 破坏方块时消耗耐久
  #   damage_entity_hit: true      # 攻击实体时消耗耐久（默认 true for sword）
```

```yaml
# 方式二：Mechanics 系统（旧版，仍可用但不推荐用于新项目）
Mechanics:
  durability:
    value: 500                     # 注意这里是 value 不是直接写数字
```

> **建议：1.21+ 服务器统一使用 `Components.durability`。** 旧版 `Mechanics.durability` 仍可用但在未来版本可能被弃用。

### 武器 balance 速查表

| 武器类型 | 伤害 | 攻速 | DPS | 耐久 | 特殊机制 |
|---------|------|------|-----|------|---------|
| 原版钻石剑 | 7 | 1.6 | 11.2 | 1561 | 横扫攻击 |
| 玻璃剑 | 10 | 1.6 | 16.0 | 8 | 无 |
| Storm Sword | 10 | 3.2 | 32.0 | (默认) | 闪电 |
| Blood Sword | 8 | 1.6 | 12.8 | 500 | 吸血+流血 |
| Katana | 5 | 5.0 | 25.0 | 1000 | 无 |

> DPS (Damage Per Second) 是理想值，实际战斗中受攻击冷却、护甲减免、走位等因素影响。
