# Oraxen 表情字形实战示例

> 字形是 Minecraft 资源包中的带纹理 Unicode 字符。Oraxen 将它们封装为易于配置的 YAML 条目，使其可在聊天、物品名称、物品描述 (lore)、计分板、Boss 栏、操作栏等任何显示文本的地方使用。
>
> **关键原理：** 每个字形内部映射到一个 Unicode 字符（由 Oraxen 自动分配）。Minecraft 的字体提供器系统将此字符渲染为你指定的纹理图片。Oraxen 自动管理字符分配和资源包生成，你只需编写 YAML 配置即可。
>
> **本文件基于项目实际配置：** `Oraxen/glyphs/emoji.yml` 和 `Oraxen/glyphs/chat_tags.yml`

---

## 一、字形文件位置约定

```
Oraxen/
├── glyphs/                          # 所有字形配置文件（.yml）
│   ├── emoji.yml                    # 表情字形
│   ├── chat_tags.yml                # 聊天标签字形
│   ├── interface.yml                # 界面字形（logo, banner 等）
│   └── required.yml                 # 必需字形（插件核心依赖）
│
├── pack/textures/                   # 所有纹理 PNG 文件
│   ├── default/chat/                # 聊天相关纹理
│   │   ├── heart.png                # 爱心表情纹理
│   │   ├── farmer_tag.png           # 农民标签纹理
│   │   └── ...
│   └── required/                    # 插件必需纹理
│
└── fonts.yml                        # 字体配置（位图定义、TTF 字体）
```

> **纹理路径规则：** 在 glyphs 配置中写 `texture: default/chat/heart`，实际对应文件 `Oraxen/pack/textures/default/chat/heart.png`。路径不加 `.png` 扩展名，使用正斜杠 `/` 分隔。

## 二、爱心表情字形 — 最简完整示例

来自项目 `Oraxen/glyphs/emoji.yml` 的真实配置：

```yaml
# ============================================================
# 文件: plugins/Oraxen/glyphs/emoji.yml
# ============================================================

heart:                                  # 【必填】字形 ID，全局唯一标识符
                                        #         引用时使用 <glyph:heart> 语法
  texture: default/chat/heart           # 【必填】纹理路径
                                        #         实际文件: pack/textures/default/chat/heart.png
                                        #         路径不加 .png 扩展名
  ascent: 8                             # 【必填】垂直位移（像素）
                                        #         正值 = 字符向上移动
                                        #         值越大，字形在文本行中越靠上
  height: 8                             # 【必填】字符占位高度（像素）
                                        #         控制字形在文本行中占据的"行高"
                                        #         也影响纹理的缩放大小
  chat:                                 # 【可选】聊天中的使用配置
    placeholders:                       # 【可选】聊天占位符列表
      - "<3"                            #         玩家输入 <3 会自动替换为爱心图标
                                        #         支持多个占位符（如下一行）
      - ":heart:"                       #         第二个占位符
    permission: "oraxen.emoji.heart"    # 【可选】使用此字形需要的权限节点
                                        #         无权限的玩家输入占位符不会替换
  char: ꐘ                             # 【内部】Unicode 字符映射
                                        #         由 Oraxen 自动管理，手动指定需谨慎
                                        #         取值由 Oraxen 自动分配（注：U+A000~U+A4FF 实为 Yi 音节区，并非私有使用区 PUA）
```

### 参数详解

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `texture` | 路径字符串 | **是** | 纹理 PNG 文件的相对路径（相对于 `pack/textures/`），不加 `.png` |
| `ascent` | 整数 | **是** | 字形在文本行基线之上的偏移量（像素）。正值 = 上移，负值 = 下移 |
| `height` | 整数 | **是** | 字符占用空间的高度（像素）。增大此值会使纹理拉伸变大 |
| `chat.placeholders` | 字符串列表 | 否 | 聊天中的快捷替代文本，玩家输入这些文本将自动替换为字形 |
| `chat.permission` | 字符串 | 否 | 使用此字形需要的权限节点 |
| `chat.tabcomplete` | 布尔 | 否 | 是否在聊天 Tab 补全中显示（1.19.3+），默认 false |
| `is_emoji` | 布尔 | 否 | 是否在 `/oraxen emojis` 列表中显示，默认 false |
| `char` | Unicode 字符 | 否 | 手动指定 Unicode 字符。留空则由 Oraxen 自动分配 |

### Unicode 字符原理

```
字形系统的核心原理:

1. Oraxen 为每个字形分配一个 Unicode 字符（由 Oraxen 自动分配，无需手动指定）
2. 你写的 MiniMessage 标签 <glyph:heart> → 解析为 Unicode 字符 ꐘ (U+A418)
3. Minecraft 字体提供器匹配此字符 → 渲染 heart.png 纹理
4. 整个过程对玩家透明 — 玩家只看到图标，看不到 Unicode 字符

私有使用区 (PUA):
- Unicode 标准的私有使用区为 U+E000~U+F8FF（以及补充 PUA U+F0000~U+10FFFF）
- 上方示例中的 U+A4xx 字符位于 Yi 音节区（U+A000~U+A4FF），并非 PUA；实际 char 由 Oraxen 自动管理
- 每个字形需要唯一的 char，不能重复
- 一般不需要手动设置 char，让 Oraxen 自动分配即可
```

### 在聊天中的使用方式

```
玩家在聊天中输入:
  "我喜欢 <3 这个符号"

实际显示效果（对有此行权限的玩家）:
  "我喜欢 [爱心图标] 这个符号"

占位符替换规则:
  - <3         → 被替换为 heart 字形
  - :heart:    → 同样被替换为 heart 字形
  - 占位符区分大小写
  - 占位符前后需要空格或行首/行尾才会被替换
```

## 四、ascent 与 height 的像素级精准说明

```
文本基线 (Baseline) 示意图:

         ┌─────────────┐  ↑
         │             │  │ height = 8
         │   爱心图标   │  │ (纹理被拉伸/缩放到
         │   (纹理)     │  │  占用 8 像素高度的空间)
         │             │  ↓
  ───────┴─────────────┴──── 文本基线 (Baseline)
         │                    ↑ ascent = 8
         │                    │ (从基线向上偏移 8 像素)
         │                    ↓

实际效果:
  - 文本 "你好 <glyph:heart> 世界" 中，爱心图标出现在文字上方 8 像素处
  - height=8 表示图标在文本行中占据 8 像素的垂直空间
  - 如果 ascent 很大而 height 很小: 图标会浮在文字上方很远的位置，但不占用太多行高
  - 如果 ascent 和 height 相等: 图标底部对齐基线，占用 height 像素的高度

常用经验值:
  - 聊天小图标 (表情/标签):  ascent=8,  height=8  或  ascent=9,  height=10
  - 物品名内嵌图标:        ascent=7,  height=7
  - Lore 中的小装饰:       ascent=6,  height=6
  - 大型界面元素:          见《界面字形.md》
```

## 五、字形在不同场景中的使用语法

### 5.1 聊天中使用

```
# MiniMessage 标签（在支持 MiniMessage 的聊天插件中直接使用）
<glyph:heart> 我喜欢这个
<glyph:farmer_tag> 出售农作物

# PlaceholderAPI 占位符（在任何支持 PAPI 的文本中使用）
%oraxen_heart%
%oraxen_farmer_tag%

# 聊天占位符（在 chat.placeholders 中定义的快捷方式）
<3                    → 自动变为爱心
:heart:               → 自动变为爱心
:farmer:              → 自动变为农民标签
```

### 5.2 物品名称中使用

```yaml
# 在物品配置 (items/*.yml) 中使用:
my_special_item:
  displayname: "<glyph:heart> <gradient:#FF6B6B:#FF0000>爱心之剑</gradient>"
  # 效果: [爱心图标] 爱心之剑（红色渐变）

  lore:
    - "<gray>这把剑蕴含着</gray>"
    - "<gray>无尽的爱意 <glyph:heart:c></gray>"
    #      注意 :c 后缀 = colorable（可着色），让字形继承文本颜色
    - ""
    - "<yellow>右键点击 <glyph:heart> 来使用</yellow>"
```

### 5.3 计分板中使用

```yaml
# 在任何计分板插件中使用 PlaceholderAPI 占位符:
scoreboard:
  title: "<glyph:heart> 服务器信息"
  lines:
    - "在线玩家: %server_online%"
    - "你的金币: %vault_eco_balance% %oraxen_heart%"
```

### 5.4 在其他插件中引用

```
# DeluxeMenus / TrMenu 等菜单插件的标题或物品名:
title: "<shift:0><glyph:heart> 主菜单"

# BossBar 标题:
bossbar_color: RED
bossbar_title: "<glyph:farmer_tag> 农场大战进行中!"

# ActionBar:
actionbar: "<shift:100><glyph:heart:c> %player_health% / %player_max_health%"

# Tab 列表:
tab_header: "<glyph:heart> 欢迎来到服务器 <glyph:heart>"
```

## 六、自定义字体命名空间 — 独立字体域与进度条字形

当你有多个系统需要使用字形（如魔力条、Boss 血条、自定义 GUI），推荐为每个系统创建独立的字体命名空间，避免字形之间的冲突。

### 6.1 字体命名空间原理

```
默认情况下，所有字形使用 minecraft:default 字体域。
通过 appearance.font 可以指定独立的命名空间，例如：

  appearance:
    font: my_font               → 资源包 assets/my_font/font/ 中定义
    font: mana_bar              → 资源包 assets/mana_bar/font/ 中定义

好处：
  - 不同系统的字形不会互相干扰
  - 可以通过切换字体来批量启用/禁用一组字形
  - 便于管理和维护多个系统的界面元素
```

### 6.2 魔力条字形示例（独立字体命名空间）

```yaml
# ============================================================
# 文件: plugins/Oraxen/glyphs/mana_bar.yml
# 用途: 魔力条进度条字形（使用独立的 my_font 命名空间）
# ============================================================

# --- 负空间分隔符（用于像素级位移）---
'-1':                                   # 使用 "-1" 作为 ID（特殊用途）
  texture: font/base/space_split        # 纹理: pack/textures/font/base/space_split.png
  height: -3                            # 负高度创造"负空间"，用于微调字符间距
  ascent: -512                          # 极大的负 ascent，将字符推到屏幕之外
                                        # 组合效果: 这个字形实际上"不可见"，用于精确位移
  appearance:
    font: my_font                       # 使用 my_font 命名空间
  char: ꐠ

# --- 进度条左端 ---
mana_bar_left:
  texture: font/mana_bar/left           # 纹理: pack/textures/font/mana_bar/left.png
  height: 8
  ascent: 8
  appearance:
    font: my_font                       # 使用 my_font 命名空间（不会出现在默认字体中）
  char: ꐡ

# --- 进度条满格（有魔力）---
mana_bar_full:
  texture: font/mana_bar/full
  height: 8
  ascent: 8
  appearance:
    font: my_font
  char: ꐢ

# --- 进度条空格（无魔力）---
mana_bar_empty:
  texture: font/mana_bar/empty
  height: 8
  ascent: 8
  appearance:
    font: my_font
  char: ꐣ

# --- 进度条右端 ---
mana_bar_right:
  texture: font/mana_bar/right
  height: 8
  ascent: 8
  appearance:
    font: my_font
  char: ꐤ
```

### 6.3 使用方式

```yaml
# 在物品 lore 或 GUI 中构建进度条:
# 例如 60% 魔力 → 左端 + 6个满格 + 4个空格 + 右端

lore:
  - "<glyph:mana_bar_left><glyph:mana_bar_full><glyph:mana_bar_full><glyph:mana_bar_full><glyph:mana_bar_full><glyph:mana_bar_full><glyph:mana_bar_full><glyph:mana_bar_empty><glyph:mana_bar_empty><glyph:mana_bar_empty><glyph:mana_bar_empty><glyph:mana_bar_right>"
  - "<gray>魔力: 60 / 100"
```

> **appearance.font 说明：** 当你在 `appearance` 中指定了 `font`，此字形将使用该字体命名空间而非默认的 `minecraft:default`。这允许你在同一个资源包中为不同插件/系统创建独立的字体域。字体命名空间需要在资源包 `assets/<font_name>/font/` 目录中定义对应的字体提供器。

## 八、占位符与权限的最佳实践

```
权限命名约定:
  oraxen.emoji.<name>        表情字形权限
  oraxen.chattag.<name>      聊天标签权限
  oraxen.gui.<name>          GUI 界面权限
  oraxen.hud.<name>          HUD 元素权限

占位符命名约定:
  :emoji_name:              聊天表情（冒号包围）
  <3                        符号快捷方式（仅限聊天输入）
  %oraxen_glyph_id%         PlaceholderAPI 占位符

权限使用策略:
  - 不需要限制的字形: 不设置 permission 字段（所有人可用）
  - 仅聊天限制: 只设置 chat.permission（lore/物品名中不限制）
  - 不希望玩家手动使用: 用 permission 限制，仅通过标签在配置中引用
  - /oraxen emojis 命令查看: 设置 is_emoji: true
```

## 九、常见问题排查

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| 字形显示为方块 | 纹理文件缺失或路径错误 | 确认 `textures/<路径>.png` 文件存在 |
| 字形太小/太大 | height 值不合适 | 调整 height，通常 7-10 适用于聊天表情 |
| 字形位置偏上/偏下 | ascent 值不合适 | 增大 ascent 向上移，减小（甚至负数）向下移 |
| 聊天不替换占位符 | 权限问题或 PAPI 未安装 | 检查 chat.permission，确保玩家拥有该权限 |
| 占位符被当作普通文本 | 占位符前后有粘性字符 | 确保占位符前后是空格或行首/行尾 |
| 字体回退到默认 | appearance.font 未正确设置 | 检查字体命名空间是否在资源包中存在 |
| /oraxen emojis 不显示 | is_emoji 未设为 true | 在配置中添加 `is_emoji: true` |
