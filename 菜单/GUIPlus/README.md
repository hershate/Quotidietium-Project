# 内容创作者说明

> 说明：
> 该菜单版本经过检查，仅适用于GUIPlus3.6.1以下版本，对于更高版本的兼容存在问题，会显示菜单的数据格式不对，目前正在尝试迁移到更新版本，请大家见谅

菜单的第一版由正版ID为 **ONEXHS** 的玩家创建
此后由正版ID为 **ZTF3** 的玩家持续维护并进行更新

该菜单基于GUIPlus插件创建，使用了如下插件的命令：
```
CMI;    MyPet； GUIPlus；   TAB；   Trademe；   PAPI；  ResourceWorld
```
若要用于其他插件请自行使用AI转换

使用该开源菜单内容时，请明确标出
```
ONEXHS创建第一版
ZTF3参与后续开发与维护
```
或类似的，能够确认作者的描述
