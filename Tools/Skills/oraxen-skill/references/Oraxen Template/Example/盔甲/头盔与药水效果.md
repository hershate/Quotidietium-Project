# 头盔与药水效果

> **适用版本**: Minecraft 1.21.2+ (组件方式)
> **核心机制**: `armor_effects` — 穿戴头盔时自动给予玩家药水效果
> **参考来源**: 项目 `Oraxen/items/hats.yml` 的 Anubis Head、Crown、Pharaoh Head、Witch Hat、Space Helmet
> **推荐阅读**: `参考资料/Oraxen/Oraxen Template/General/盔甲_组件_1.21.2+.md`

---

## 概述

Oraxen 的 `armor_effects` 机制允许头盔在穿戴时自动给予玩家药水效果。这是制作功能性头盔的核心工具——不需要任何命令方块或插件脚本, 纯配置即可实现。

本文档涵盖两类头盔:
1. **功能性头盔** — 穿戴时给予药水效果 (Anubis Head: 夜视)
2. **纯装饰头盔** — 只有护甲值, 无药水效果 (Crown, Pharaoh Head, Witch Hat, Space Helmet)

---

## 机制总览: armor_effects

### 工作原理

```
玩家穿戴头盔 → Oraxen 检测物品是否有 armor_effects 配置
  ├→ 有: 持续给予玩家指定的药水效果 (每 N 秒刷新一次)
  └→ 没有: 无特殊效果 (仅护甲值生效)

脱下头盔 → 药水效果被移除
```

### armor_effects 的完整配置结构

```yaml
Mechanics:
  armor_effects:
    <药水效果类型>:          # 使用小写蛇形命名 (如 night_vision, speed, jump_boost)
      amplifier: <等级>      # 药水效果等级 (0 = I级, 1 = II级, 2 = III级 ...)
      ambient: <true/false>  # 是否产生更半透明的环境粒子 (视觉效果)
      particles: <true/false># 是否显示粒子效果
      icon: <true/false>     # 是否在屏幕右上角显示药水图标
```

### 各字段详解

| 字段 | 类型 | 默认值 | 说明 |
|------|------|:------:|------|
| `amplifier` | 整数 | 0 | 药水效果等级。0 = I级, 1 = II级, 2 = III级, 以此类推 |
| `ambient` | 布尔 | false | 设为 true 时, 药水粒子更加半透明、更"环境化"。视觉上更低调, 适合营造氛围感 |
| `particles` | 布尔 | true | 是否从玩家身上产生药水粒子。设为 false 可完全隐藏粒子, 适合 PvP 场景 |
| `icon` | 布尔 | true | 是否在屏幕右上角显示药水效果图标。设为 false 可隐藏图标, 让效果"隐形" |

### 常用药水效果列表

| 效果类型 (YAML 键) | 中文名称 | 说明 |
|---------------------|----------|------|
| `night_vision` | 夜视 | 在黑暗中看清一切, 画面亮如白昼 |
| `speed` | 速度 | 提升移动速度 |
| `jump_boost` | 跳跃提升 | 提高跳跃高度, 减少摔落伤害 |
| `strength` | 力量 | 增加近战攻击伤害 |
| `regeneration` | 生命恢复 | 持续恢复生命值 |
| `fire_resistance` | 抗火 | 免疫火焰和岩浆伤害 |
| `water_breathing` | 水下呼吸 | 在水下不消耗氧气 |
| `invisibility` | 隐身 | 使玩家隐身 (但盔甲仍然可见) |
| `slow_falling` | 缓降 | 缓慢下落, 免疫摔落伤害 |
| `haste` | 急迫 | 加快挖掘速度 |
| `resistance` | 抗性 | 减少受到的伤害 |
| `absorption` | 伤害吸收 | 提供临时的额外生命值 (黄色心) |
| `saturation` | 饱和 | 恢复饱食度 |
| `dolphins_grace` | 海豚的恩惠 | 在水中游泳速度大幅提升 |

> **完整列表**: 参考 [Spigot PotionEffectType JavaDoc](https://hub.spigotmc.org/javadocs/spigot/org/bukkit/potion/PotionEffectType.html) — YAML 中直接使用小写蛇形命名 (SCREAMING_SNAKE_CASE → screaming_snake_case)。

## 需要的纹理文件

### Anubis Head (3D 模型头盔)

```
资源包模型和纹理:
├── assets/oraxen/models/default/anubis_head.json    ← [必须] 3D 模型文件 (Blockbench 导出)
├── textures/default/anubis_head.png                  ← [必须] 3D 模型的纹理贴图
```

> **3D 模型头盔**: Anubis Head 使用 Blockbench 创建的 3D 模型, 而非 2D 纹理贴图。Pack 中 `generate_model: false` + `model: default/anubis_head` 指向手工制作的模型文件。

### 装饰头盔 (Crown / Pharaoh Head / Witch Hat / Space Helmet)

每个装饰头盔都需要各自的 3D 模型文件和纹理:

```
├── assets/oraxen/models/default/crown.json           ← Crown 3D 模型
├── assets/oraxen/models/default/pharaoh_head.json    ← Pharaoh Head 3D 模型
├── assets/oraxen/models/default/witch_hat.json       ← Witch Hat 3D 模型
├── assets/oraxen/models/default/space_helmet.json    ← Space Helmet 3D 模型
└── textures/default/
    ├── crown.png
    ├── pharaoh_head.png
    ├── witch_hat.png
    └── space_helmet.png
```

## 完整 YAML 配置

### 示例 1: 功能性头盔 — Anubis Head (穿戴时给予夜视效果)

```yaml
# ====================================================================
# Anubis Head — 3D 模型头盔 + 穿戴夜视效果
# ====================================================================
#
# 这是功能性头盔的完整范例。玩家穿戴后:
#   1. 获得 3 点护甲值 (等同钻石头盔)
#   2. 获得 2 点护甲韧性 (等同钻石)
#   3. 获得持续夜视效果 —— 在黑暗中视物清晰
#
# MiniMessage 渐变色: #3948AE (深蓝) → #6699FF (亮蓝) — 呼应阿努比斯的夜空/神秘主题
#
anubis_head:
  # ---- 显示名称 ----
  displayname: <gradient:#3948AE:#6699FF>Anubis Head

  # ---- 基础材质 ----
  # PAPER: 白板材质, 所有属性由下方手动控制
  material: PAPER

  # ---- 物品描述 (Lore) ----
  # 清晰告知玩家穿戴后获得什么效果
  lore:
    - <#6f737d>» <#D5D6D8>NightVision when worn

  # ================================================================
  # 属性修改器
  # ================================================================
  #
  # 头盔的护甲值参考: 钻石头盔 = 3 armor + 2 toughness
  # Anubis Head 使用与钻石头盔相同的值, 确保它不仅仅是一个"玩具", 而是实用的战斗头盔
  #
  AttributeModifiers:
    # 护甲值: 3 (钻石头盔标准)
    - attribute: ARMOR
      amount: 3
      operation: 0
      slot: HEAD
    # 护甲韧性: 2 (钻石标准)
    - attribute: ARMOR_TOUGHNESS
      amount: 2
      operation: 0
      slot: HEAD

  # ================================================================
  # 资源包配置 — 3D 模型头盔
  # ================================================================
  #
  # 3D 模型头盔 vs 2D 纹理头盔的 Pack 配置差异:
  #
  #   3D 模型头盔 (本示例):
  #     generate_model: false          ← 不自动生成, 使用手工制作的 .json 模型
  #     model: default/anubis_head     ← 指向 Blockbench 导出的 3D 模型文件
  #     (不需要 textures 列表)          ← 纹理路径已在模型 JSON 中定义
  #
  #   2D 纹理头盔 (盔甲套装):
  #     generate_model: true           ← 自动生成物品模型
  #     parent_model: item/generated   ← 使用 Minecraft 原版 generated 父模型
  #     textures:                       ← 必须指定纹理路径
  #       - default/armors/xxx_helmet
  #
  #   .json 扩展名是可选的 — Oraxen 会自动补全
  #
  Pack:
    generate_model: false             # 使用手工制作的模型, 不自动生成
    model: default/anubis_head        # 指向 assets/oraxen/models/default/anubis_head.json

  # ================================================================
  # 物品组件 — 1.21.2+ 的 equippable 方式
  # ================================================================
  #
  # 在 1.21.2 之前, 头盔通过旧版 hat 机制实现。现在统一使用 equippable 组件。
  #
  Components:
    equippable:
      slot: HEAD                      # 装备到头部槽位

  # ================================================================
  # 核心机制: armor_effects — 穿戴时的药水效果
  # ================================================================
  #
  # 每当玩家将此物品装备在指定槽位时, Oraxen 会自动给予配置的药水效果。
  # 当物品被卸下时, 效果自动移除。
  #
  Mechanics:
    armor_effects:
      # --- 夜视效果 ---
      # amplifier: 0 = 夜视 I (标准亮度, 足够看清一切)
      #   0 = I级 (标准), 1 = II级 (无实际提升 — 夜视没有等级差异)
      #
      # ambient: true = 粒子更加半透明/环境化
      #   对夜视来说设为 true 让粒子更不显眼, 减少视觉干扰
      #
      # particles: true = 显示药水粒子
      #   夜视的粒子本身就很淡 — 设为 true 不影响美观
      #
      # icon: true = 在右上角显示夜视图标
      #   让玩家知道夜视正在生效 —— 好的 UX 不隐藏状态
      #
      night_vision:
        amplifier: 0                  # 夜视 I 级 (标准亮度)
        ambient: true                 # 环境粒子 (更半透明, 不突兀)
        particles: true               # 显示粒子效果
        icon: true                    # 显示状态图标
```


### 示例 2: 纯装饰头盔 — Crown (皇冠)

```yaml
# ====================================================================
# Crown — 纯装饰 3D 模型头盔, 无药水效果
# ====================================================================
#
# Crown 是一个纯粹的装饰性头盔。它提供少量护甲值 (让你不至于光着头被打),
# 但没有药水效果 — 玩家穿戴它纯粹是为了外观。
#
# 渐变色: #F06966 (暖珊瑚红) → #FAD6A6 (柔和杏色) — 金色的皇冠感
#
crown:
  displayname: <gradient:#F06966:#FAD6A6>Crown
  material: PAPER

  # 基础护甲值: 3 (钻石头盔标准)
  # 即使是装饰性头盔, 也给一点护甲值 — 不至于让玩家感觉"戴了等于没戴"
  AttributeModifiers:
    - attribute: ARMOR
      amount: 3
      operation: 0
      slot: HEAD
    - attribute: ARMOR_TOUGHNESS
      amount: 2
      operation: 0
      slot: HEAD

  # 3D 模型头盔的 Pack 配置
  Pack:
    generate_model: false             # 使用手工制作的 3D 模型
    model: default/crown              # 指向 assets/oraxen/models/default/crown.json

  Components:
    equippable:
      slot: HEAD

  # 注意: 没有 Mechanics.armor_effects 块!
  # 这就是纯装饰头盔 —— 只有护甲值, 没有特殊效果。
```


## 3D 模型头盔 vs 2D 纹理头盔: Pack 配置对比

| 维度 | 3D 模型头盔 | 2D 纹理头盔 |
|------|:-----------:|:-----------:|
| **Pack.generate_model** | `false` | `true` |
| **Pack.model** | `default/hat_name` (手工 .json) | 不设置 |
| **Pack.parent_model** | 不设置 | `item/generated` |
| **Pack.textures** | 不设置 (纹理在 .json 中定义) | `- default/armors/xxx_helmet` |
| **模型来源** | Blockbench 导出 | Oraxen 自动生成 |
| **视觉效果** | 立体 3D, 可旋转/缩放 | 平面 2D, 原版物品外观 |
| **制作难度** | 需要 Blockbench 建模 | 仅需 2D 像素画纹理 |
| **适用场景** | 独特形状 (皇冠/帽子/面具) | 标准盔甲 (头盔/胸甲/护腿/靴子) |
| **穿戴后的外观** | 3D 模型附着在玩家头部 | 原版盔甲层纹理包裹玩家头部 |
| **equippable 配置** | `slot: HEAD` | `slot: HEAD` + `model: oraxen:xxx` |

### 关键区别

- **3D 模型头盔**: 通过 Blockbench 创建的 `.json` 模型文件直接渲染在玩家头部。适合形状不规则的头饰 (皇冠、帽子、面具等)。
- **2D 纹理头盔**: 通过 Minecraft 原版盔甲层系统渲染。纹理包裹在玩家头部表面。适合标准头盔。

> **重要**: 3D 模型头盔在 1.21.2+ 中通过 `equippable` 组件的 `slot: HEAD` 实现。旧版需使用 `hat` 机制 (在 Components 出现之前)。

## armor_effects 的使用技巧

### 1. 隐藏效果 — PvP 场景

在 PvP 服务器中, 玩家不希望对手看到自己的药水粒子:

```yaml
Mechanics:
  armor_effects:
    strength:
      amplifier: 0
      ambient: false
      particles: false       # ← 不显示粒子, 对手不知道你有效果!
      icon: true              # ← 但自己可以看到图标, 知道效果在生效
```

### 2. 组合多个效果

一个头盔可以同时给予玩家多个药水效果:

```yaml
Mechanics:
  armor_effects:
    night_vision:             # 夜视
      amplifier: 0
      ambient: true
      particles: true
      icon: true
    speed:                    # 同时加速!
      amplifier: 0
      ambient: false
      particles: true
      icon: true
    water_breathing:          # 还防水下窒息!
      amplifier: 0
      ambient: false
      particles: false
      icon: true
```

### 3. 渐强效果 — 高等级药水

```yaml
Mechanics:
  armor_effects:
    speed:
      amplifier: 2            # 速度 III 级 (比 I 级快很多)
      ambient: false
      particles: true
      icon: true
```

### 4. 氛围型效果 — 纯装饰

```yaml
Mechanics:
  armor_effects:
    night_vision:
      amplifier: 0
      ambient: true            # 半透明粒子
      particles: true          # 有粒子但很淡
      icon: false              # 不显示图标 — 让玩家觉得是"自然"的视觉改善
```

## 如何基于此模板创建自己的功能性头盔

### 步骤清单

1. **确定效果**: 选择药水效果类型 (如 `night_vision`, `speed`, `strength` 等)
2. **确定等级**: `amplifier: 0` = I级, `amplifier: 1` = II级
3. **确定粒子策略**: PvP → 隐藏粒子; PvE → 显示粒子; 氛围 → ambient + 无 icon
4. **确定护甲值**: 功能头盔 (钻石头盔标准 3+2); 纯装饰 (可降为 1+0 或完全不加)
5. **创建 3D 模型**: 在 Blockbench 中建模, 导出为 `.json`
6. **配置物品**: 复制 Anubis Head 的模板, 修改名称/效果/模型路径
