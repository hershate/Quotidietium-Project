# 自定义鞘翅 (Custom Elytra)

> **适用版本**: Minecraft 1.21.2+ (组件方式)
> **核心机制**: `equippable` 组件 + `_elytra` 命名后缀 + `ELYTRA` 材质自动检测
> **参考来源**: `参考资料/Oraxen/Oraxen Template/General/盔甲_组件_1.21.2+.md` 的「自定义鞘翅」章节
> **推荐阅读**: `完整盔甲套装_绿宝石.md` (标准盔甲套装的对照参考)

---

## 概述

Oraxen 的组件方式允许创建具有自定义纹理的鞘翅。与标准盔甲不同的是, 鞘翅有自己的命名约定、材质推荐和自动检测机制。

### 鞘翅 vs 胸甲

| 维度 | 胸甲 (Chestplate) | 鞘翅 (Elytra) |
|------|:-----------------:|:-------------:|
| 物品 ID 命名 | `<盔甲名>_chestplate` | `<前缀>_elytra` |
| 材质建议 | PAPER 或 DIAMOND_CHESTPLATE | **ELYTRA** (推荐) |
| equippable.slot | CHEST | CHEST |
| equippable.model | `oraxen:<盔甲名>` (不含 `_chestplate`) | `oraxen:<前缀>_elytra` (**保留** `_elytra` 后缀!) |
| 纹理文件 | `<盔甲名>_armor_layer_1/2.png` + 物品图标 | `<前缀>_elytra.png` (翅膀纹理 + 物品图标共用) |
| 飞行行为 | 无 | **有** (滑翔飞行) |
| 占用槽位 | 胸部 | 胸部 (与胸甲**互斥**) |

> **关键注意**: 鞘翅与胸甲共享 CHEST 槽位 —— 玩家不能同时穿戴胸甲和鞘翅!

---

## 鞘翅的自动检测机制

Oraxen 通过以下三种方式之一识别物品是否为鞘翅。满足**任意一个条件**即可触发原版鞘翅飞行行为:

### 方式 1: 物品 ID 包含 `_elytra` 后缀 (推荐)

```
物品 ID: magic_elytra       → 检测到 _elytra 后缀 → 识别为鞘翅 ✓
物品 ID: dragon_elytra      → 检测到 _elytra 后缀 → 识别为鞘翅 ✓
物品 ID: emerald_chestplate → 没有 _elytra 后缀  → 不识别为鞘翅 ✗
```

这是**最推荐**的方式 —— 简单、明确、符合约定。

### 方式 2: material 设为 `ELYTRA`

```
material: ELYTRA  → Oraxen 识别为鞘翅 ✓
material: PAPER   → 仅当同时满足方式 1 时才识别为鞘翅
```

使用 `ELYTRA` 材质的好处是物品会继承原版鞘翅的默认行为 (如飞行时的粒子、声音等), 无需额外配置。

### 方式 3: 物品元标记 `isGlider()`

这是 Java API 层面的标记, 普通 YAML 配置通常不需要手动设置。当方式 1 和 2 都不满足但你确实需要鞘翅行为时使用 (高级/极端用法)。

### 检测优先级

```
Oraxen 检查物品:
  1. 物品 ID 是否以 _elytra 结尾?
     ├→ 是 → 识别为鞘翅 ✓ (无论 material 是什么)
     └→ 否 → 继续检查
  2. material 是否为 ELYTRA?
     ├→ 是 → 识别为鞘翅 ✓
     └→ 否 → 不识别为鞘翅 (除非有 isGlider() 标记)
```

## 命名规范

### 物品 ID

```
<前缀>_elytra

规则:
  - 必须以 _elytra 结尾 (英文小写)
  - 前缀可以是任意名称 (如 magic, dragon, phoenix, angel 等)
  - 不要使用 _chestplate 后缀 (会被识别为普通胸甲)
```

### 纹理文件

```
<前缀>_elytra.png

示例:
  magic_elytra   → ~/textures/default/armors/magic_elytra.png
  dragon_elytra  → ~/textures/default/armors/dragon_elytra.png
```

> **与标准盔甲的纹理差异**: 标准盔甲需要 6 个纹理文件 (2个盔甲层 + 4个物品图标), 而鞘翅只需要 **1 个纹理文件** (`<前缀>_elytra.png`)。这个文件同时服务两种用途: 作为物品栏图标 (通过 Pack.textures) 和作为翅膀纹理 (通过 equippable.model)。

### equippable.model 命名

```
物品 ID: magic_elytra
  → model: oraxen:magic_elytra  ← 注意: 保留 _elytra 后缀!

与标准盔甲的区别:
  标准盔甲: emerald_helmet  → model: oraxen:emerald    ← 去除 _helmet
  鞘翅:      magic_elytra   → model: oraxen:magic_elytra ← 保留 _elytra!
```

> **为什么鞘翅保留后缀?** 标准盔甲的 4 件套共享同一个 model 名 (如 `oraxen:emerald`), 系统根据 slot 区分部位。而鞘翅是独立的单品 —— 保留 `_elytra` 后缀确保模型名在整个配置中唯一, 不与同前缀的胸甲冲突。

## 完整 YAML 配置

### 示例 1: 基础自定义鞘翅 — Magic Elytra

```yaml
# ====================================================================
# 自定义鞘翅 — Magic Elytra
# ====================================================================
#
# 一个带有自定义渐变翅膀纹理的鞘翅。
# 使用 ELYTRA 材质以获得原版鞘翅的飞行行为和默认音效。
#
# 检测方式: 同时满足所有三种检测方式:
#   1. 物品 ID 以 _elytra 结尾 ✓
#   2. material 为 ELYTRA ✓
#   3. (自动 isGlider 标记) ✓
#
# 渐变色: #FA7CBB (粉红) → #F14658 (玫红) — 魔法/幻想的色彩
#
magic_elytra:
  # ---- [必须] 显示名称 ----
  displayname: "<gradient:#FA7CBB:#F14658>Magic Elytra"

  # ---- [必须] 基础材质 ----
  # ELYTRA 是**强烈推荐**的材质选择, 原因:
  #   1. 自动获得原版鞘翅的飞行行为 (滑翔、烟花加速等)
  #   2. 自动获得原版鞘翅的音效 (飞行声、展开声、损坏声)
  #   3. 自动获得原版鞘翅的耐久度系统
  #   4. 自动获得原版鞘翅的粒子效果 (飞行时的尾迹粒子)
  #   5. 满足鞘翅检测方式 2 (material: ELYTRA)
  #
  # 你也可以使用 PAPER, 但需要:
  #   - 手动配置 durability 组件
  #   - 确保物品 ID 以 _elytra 结尾 (满足检测方式 1)
  #   - 飞行行为在 1.21.2+ 由 equippable 组件自动处理
  #
  material: ELYTRA

  # ---- [必须] 资源包配置 ----
  Pack:
    generate_model: true               # 自动生成物品模型
    parent_model: "item/generated"     # 使用 generated 父模型
    textures:
      - default/armors/magic_elytra    # 指向 textures/default/armors/magic_elytra.png
                                       # 这个文件既是物品栏图标, 也是翅膀纹理

  # ---- [必须] 可装备组件 ----
  #
  # slot: CHEST — 鞘翅必须装备在胸部槽位
  #   这意味著玩家不能同时穿戴胸甲和鞘翅!
  #   如果在有胸甲的情况下装备鞘翅, 胸甲会被卸下。
  #
  # model: oraxen:magic_elytra — 注意保留 _elytra 后缀
  #   与标准盔甲不同 (emerald_helmet → model: oraxen:emerald),
  #   鞘翅的 model 名保留完整的 _elytra 后缀。
  #
  Components:
    equippable:
      slot: CHEST                       # 鞘翅占据胸部槽位 (与胸甲互斥)
      model: oraxen:magic_elytra        # 注意: 保留 _elytra 后缀!
```


### 示例 2: 使用 PAPER 材质 + 手动耐久度的鞘翅

```yaml
# ====================================================================
# 自定义鞘翅 — Dragon Elytra (PAPER 材质 + 手动耐久)
# ====================================================================
#
# 如果你不想继承 ELYTRA 的默认耐久系统, 可以使用 PAPER 并手动配置一切。
# 注意: 必须确保物品 ID 以 _elytra 结尾, 否则 Oraxen 不会识别为鞘翅!
#
dragon_elytra:
  displayname: "<gradient:#F06966:#FAD6A6>Dragon Elytra"
  material: PAPER                       # 使用 PAPER 而非 ELYTRA

  # 使用 PAPER 时需手动添加 durability 组件
  # 否则鞘翅将永不损坏 (可能不是你想要的)

  Pack:
    generate_model: true
    parent_model: "item/generated"
    textures:
      - default/armors/dragon_elytra

  Components:
    max_stack_size: 1                   # 鞘翅也不能堆叠
    # 原版鞘翅耐久 = 432
    # 这里设为 864 (2x) 让龙翼更耐用
    durability:
      value: 864
      damage_entity_hit: false          # 用鞘翅打人不消耗耐久 (正常行为)
    equippable:
      slot: CHEST
      model: oraxen:dragon_elytra
```


### 示例 3: 带 Attribute 的鞘翅 — Phoenix Elytra (火焰免疫)

```yaml
# ====================================================================
# 自定义鞘翅 — Phoenix Elytra (带火焰免疫 + 护甲值)
# ====================================================================
#
# 鞘翅也可以配置 AttributeModifiers!
# Phoenix Elytra 在提供飞行能力的同时, 还给予火焰免疫和一点护甲值。
#
phoenix_elytra:
  displayname: "<gradient:#FF8C00:#FF4500>Phoenix Elytra"
  material: ELYTRA

  lore:
    - <#6f737d>» <#D5D6D8>Grants Fire Resistance while worn

  Pack:
    generate_model: true
    parent_model: "item/generated"
    textures:
      - default/armors/phoenix_elytra

  Components:
    equippable:
      slot: CHEST
      model: oraxen:phoenix_elytra

  # 鞘翅也可以添加属性!
  # 但由于鞘翅占据 CHEST 槽位 (而不是专门的 ELYTRA 槽位),
  # 属性的 slot 应设为 CHEST
  AttributeModifiers:
    # 给一点护甲值 — 凤凰之翼不只用于飞行, 还能提供微弱的防护
    - attribute: ARMOR
      amount: 2                        # 提供 2 点护甲 (类似锁链/铁胸甲的一半)
      operation: 0
      slot: CHEST
    # 护甲韧性
    - attribute: ARMOR_TOUGHNESS
      amount: 1
      operation: 0
      slot: CHEST

  # 也可以通过 armor_effects 添加药水效果!
  Mechanics:
    armor_effects:
      fire_resistance:                 # 穿戴时免疫火焰
        amplifier: 0
        ambient: false
        particles: true
        icon: true
```


### 示例 4: 最简鞘翅 — 仅飞行, 无任何额外属性

```yaml
# ====================================================================
# 最简自定义鞘翅 — Minimal Elytra
# ====================================================================
#
# 这是创建一个自定义外观鞘翅所需的最少配置。
# 只需 5 个字段: displayname, material, Pack (含3个子字段), Components.equippable
#
minimal_elytra:
  displayname: "<#D5D6D8>Minimal Elytra"
  material: ELYTRA                      # ELYTRA 提供所有原版行为
  Pack:
    generate_model: true
    parent_model: "item/generated"
    textures:
      - default/armors/minimal_elytra   # 唯一的纹理文件
  Components:
    equippable:
      slot: CHEST
      model: oraxen:minimal_elytra
```

## 纹理设计指南

### 原版鞘翅纹理参考

原版鞘翅纹理 (`minecraft:textures/entity/elytra.png`) 的布局:

- 纹理尺寸: 64x32 像素（原版）
- 纹理左半部（32x32） → 左翼（左侧）
- 纹理右半部（32x32） → 右翼（右侧）
- 镜像对称：左翼是右侧纹理，右翼是左侧纹理（游戏会镜像左翼）

### 设计步骤

1. **创建 64x64 像素画布** (推荐使用比原版 64x32 高一些的分辨率以获得更精细的纹理)
2. **左半部分 (0-31)** 绘制右翼纹理
3. **右半部分 (32-63)** 绘制左翼纹理 (或让它们对称)
4. **保存为 PNG** (支持透明)
5. **使用命名规则**: `<your_elytra_name>_elytra.png`

### 常见错误

| 错误 | 后果 | 修复 |
|------|------|------|
| 忘记 `_elytra` 后缀 | 物品被识别为普通胸甲, 无法飞行 | 重命名为 `<name>_elytra` |
| model 名去掉 `_elytra` | 纹理无法加载, 显示紫黑方块 | 保留 model 名中的 `_elytra` |
| 使用 PAPER 且 ID 不含 `_elytra` | 物品完全没有鞘翅行为 | 确保至少满足一种检测方式 |
| 纹理文件放错目录 | 物品栏图标或翅膀纹理不显示 | 放在 `textures/default/armors/` 中 |

## 与原版鞘翅的交互

### 鞘翅飞行机制

装备自定义鞘翅后, 飞行操作与原版鞘翅完全相同:

1. **起跳滑翔**: 在空中按**跳跃键** (默认空格) 展开鞘翅开始滑翔
2. **烟花加速**: 手持烟花火箭**右键**获得推进力
3. **耐久消耗**: 滑翔每秒消耗 1 点耐久 (如使用 ELYTRA 材质)

### 鞘翅与胸甲的互斥

```
装备槽位 CHEST:
  ┌────────────────────────────┐
  │  胸甲          鞘翅        │
  │  (iron_chestplate)         │
  │       ╳ 互斥 ╳             │  ← 只能装备其中一个!
  │                (magic_elytra) │
  └────────────────────────────┘
```

> **设计注意**: 如果你的服务器在胸甲槽位给玩家提供了强力属性 (如 HP 加成), 那么鞘翅就意味着放弃这些属性以换取飞行能力。这是一个有意义的取舍 —— 不要试图绕过去。

## 快速检查清单

在部署自定义鞘翅之前, 确认以下事项:

- [ ] 物品 ID 以 `_elytra` 结尾 (或 material 设为 ELYTRA)?
- [ ] `equippable.model` 中保留了 `_elytra` 后缀?
- [ ] 纹理文件 `textures/default/armors/<name>_elytra.png` 存在?
- [ ] `Pack.textures` 路径正确指向该纹理文件?
- [ ] `equippable.slot` 设为 `CHEST`?
- [ ] 已了解鞘翅与胸甲的互斥关系?
- [ ] 如果使用 PAPER 材质, 已手动配置 `durability` 组件?
- [ ] 如果添加了 `AttributeModifiers`, `slot` 设为 `CHEST`?
