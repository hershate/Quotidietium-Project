# 实战示例：紫颂透明方块 (ChorusBlock)

> 紫颂 (ChorusBlock) 机制是三种方块机制中变体最少但特色最鲜明的。
> 它使用 Minecraft 的紫颂植物方块状态，提供**透明渲染**和**座椅**两大独有功能。

---

## 一、机制对比：为什么选择紫颂方块？

三大方块机制的功能差异：

| 功能 | 音符盒 | 绊线 | 紫颂 |
|:----|:----:|:----:|:----:|
| 最大变体数 | ~800 | 127 | 63（最少） |
| 完整碰撞箱 | 有 | 无（可穿过） | 有 |
| 透明渲染 | 不支持 | 部分 | 支持（独有） |
| 座椅(seat) | 不支持 | 不支持 | 支持（独有） |
| 方向性 | 支持 | 不支持 | 不支持 |
| 含水 | 不支持 | 支持 | 不支持 |
| 高株植物 | 不支持 | 支持 | 不支持 |
| 树苗机制 | 不支持 | 支持 | 不支持 |
| 农场方块 | 支持 | 不支持 | 不支持 |

结论：
  - 需要透明方块（树叶、玻璃类）→ 紫颂
  - 需要座椅功能 → 紫颂（方块中唯一）或家具
  - 需要最多变体 → 音符盒
  - 需要含水/花朵 → 绊线

## 二、全局配置 (mechanics.yml)

```yaml
# ============================================================
# plugins/Oraxen/mechanics.yml — 紫颂方块全局配置
# ============================================================
chorusblock:
  enabled: true

  tool_types:
    - WOODEN
    - STONE
    - IRON
    - GOLDEN
    - DIAMOND
    - NETHERITE

  # 注意：紫颂方块没有 farmblock_check_delay 等额外配置项
  # 其功能集比较精简
```

**Paper 服务器重要优化：**
```yaml
# 在 config/paper-global.yml 中：
block-updates:
  disable-chorus-plant-updates: true
# 必须启用此选项！否则 Oraxen 必须监听昂贵的紫颂植物物理事件
# 导致大量性能开销。不启用 = 每个紫颂方块都会触发不必要的方块更新
```

## 三、示例1：自定义树叶 (透明渲染的核心场景)

自定义树叶是紫颂方块最典型的用途。

```yaml
# ============================================================
# 自定义魔法树叶 — 使用 block/leaves 父模型获得透明度
# ============================================================
magic_leaves:
  # ---- 基础信息 ----
  itemname: <gradient:#FF69B4:#8A2BE2>魔法树叶
  material: PAPER

  # ---- 资源包/模型配置 ----
  Pack:
    generate_model: true

    # [关键] parent_model: block/leaves 提供树叶专用透明渲染
    # 与 block/cube_all 不同，leaves 父模型支持透明通道和半透明
    # 纹理中透明区域会正确显示为透明，不会变成黑色
    parent_model: block/leaves

    textures:
      - default/magic_leaves               # 树叶纹理(含透明通道)

  # ---- 方块机制配置 ----
  Mechanics:
    chorusblock:                            # 注意：是 chorusblock
      # [必需★] 变体编号 1-63
      custom_variation: 1

      # [必需★] 模型名称
      model: magic_leaves

      # 硬度：树叶应该很容易破坏
      hardness: 0.2                         # 比玻璃(1)还软

      # 发光等级：魔法树叶微微发光
      light: 4                              # 0-15，4级微弱发光

      # 方块音效：树叶类音效
      block_sounds:
        break_sound: block.grass.break
        place_sound: block.grass.place
        hit_sound: block.grass.hit
        step_sound: block.grass.step
        fall_sound: block.grass.fall

      # 掉落物：精准采集才掉树叶本身
      drop:
        silktouch: true                     # 只有精准采集才掉落
        best_tools:
          - SHEARS                          # 剪刀最佳
          - HOE                             # 锄头也可
        loots:
          - oraxen_item: magic_leaves
            probability: 1.0
```

## 四、示例2：自定义玻璃 (透明渲染)

```yaml
# ============================================================
# 自定义磨砂玻璃 — block/cube_all + 紫颂透明
# ============================================================
frosted_glass:
  itemname: <#CCEEFF>磨砂玻璃
  material: PAPER
  Pack:
    generate_model: true
    parent_model: block/cube_all            # 使用 cube_all 而非 leaves
    # 即使是 cube_all 父模型，紫颂机制也会提供透明渲染
    # 纹理中的半透明区域会正确显示
    textures:
      - default/frosted_glass
  Mechanics:
    chorusblock:
      custom_variation: 2
      model: frosted_glass
      hardness: 1                           # 玻璃硬度，容易碎
      light: 0                              # 不发光
      block_sounds:
        break_sound: block.glass.break      # 玻璃特有音效
        place_sound: block.glass.place
        hit_sound: block.glass.hit
        step_sound: block.glass.step
        fall_sound: block.glass.fall
      drop:
        silktouch: true                     # 玻璃需要精准采集
        minimal_type: STONE
        best_tools:
          - PICKAXE
        loots:
          - oraxen_item: frosted_glass
            probability: 1.0
```

## 五、示例3：带座椅的紫颂方块 (紫颂独有功能)

```yaml
# ============================================================
# 自定义椅子方块 — 紫颂独有的座椅功能
# 注意：对于复杂椅子模型，推荐使用家具(Furniture)机制
# 紫颂座椅适合"方块形状的椅子"（如石凳、树桩凳）
# ============================================================
stone_stool:
  itemname: <#808080>石凳
  material: PAPER
  Pack:
    generate_model: false                   # 使用预制模型
    model: custom/furniture/stone_stool
  Mechanics:
    chorusblock:
      custom_variation: 3
      model: custom/furniture/stone_stool
      hardness: 3
      block_sounds:
        break_sound: block.stone.break
        place_sound: block.stone.place
        step_sound: block.stone.step

      # ========== 座椅配置 [紫颂独有] ==========
      seat:
        # [必需] 从方块顶部的高度偏移（方块为单位）
        # 0.0 = 坐在方块表面
        # 0.5 = 坐在方块上方半格
        # 负值 = 坐在方块内部（下沉坐姿）
        height: 0.5

        # [可选] 固定旋转角度 (0/90/180/270)
        # 0=南, 90=西, 180=北, 270=东
        # 不设置 = 玩家保持原有朝向
        yaw: 0

      drop:
        best_tools:
          - PICKAXE
        loots:
          - oraxen_item: stone_stool
            probability: 1.0
```

## 六、座椅 (seat) 配置详解

```
座椅功能是紫颂方块相比音符盒和绊线最独特的优势。

工作原理：
  1. 玩家右键点击紫颂方块
  2. Oraxen 在方块上方生成一个隐形盔甲架
  3. 玩家被传送到盔甲架的位置（模拟坐下）
  4. 玩家按潜行键(Sneak)站起

seat 属性说明：
  height: 浮点数，单位是方块
    正值 = 坐在方块上方（如 height: 0.5 = 坐半格高）
    0 = 坐在方块表面
    负值 = 下沉坐姿（如 height: -0.3 = 往下坐0.3格）

  yaw: 整数，可选
    0 = 朝南 (south, Z+)
    90 = 朝西 (west, X-)
    180 = 朝北 (north, Z-)
    270 = 朝东 (east, X+)
    不设置此字段 = 保持玩家坐下前的朝向（推荐）

注意：
  - 座椅功能不需要 barrier: true（这是与家具座椅的区别）
  - 紫颂的座椅直接通过方块右键触发
  - 家具的座椅需要通过屏障(barrier)右键触发
```

## 七、带完整功能的紫颂方块 (矿石+座椅+发光)

```yaml
# ============================================================
# 祭坛方块 — 结合所有紫颂特性的综合示例
# ============================================================
magic_altar:
  itemname: <gradient:#FFD700:#FF6347>魔法祭坛
  material: PAPER
  Pack:
    generate_model: true
    parent_model: block/cube_all
    textures:
      - default/magic_altar
  Mechanics:
    chorusblock:
      custom_variation: 10
      model: magic_altar
      hardness: 10                          # 很硬
      light: 10                             # 发光 10 级
      blast_resistant: true                 # 防爆
      immovable: true                       # 无法被活塞推动

      block_sounds:
        break_sound: block.enchanting_table.break
        place_sound: block.enchanting_table.place
        hit_sound: block.stone.hit
        step_sound: block.stone.step
        fall_sound: block.stone.fall

      # 座椅：祭坛中心可坐
      seat:
        height: 0.6                         # 坐在祭坛上方

      # 点击动作：右键交互
      clickActions:
        - conditions:
            - '#player.hasPermission("magic.use")'
          actions:
            - '[message] <gradient:#FFD700:#FF6347>魔法祭坛感受到了你的力量...'
            - '{source=BLOCK volume=1.0 pitch=1.5} [sound] minecraft:block.enchanting_table.use'
        - conditions: []
          actions:
            - '[message] <red>你没有使用祭坛的权限!'

      drop:
        silktouch: true
        minimal_type: DIAMOND
        best_tools:
          - PICKAXE
        loots:
          - oraxen_item: magic_altar
            probability: 1.0
```

## 八、与音符盒/绊线的功能对比总结


| 功能 | 音符盒 | 绊线 | 紫颂 |
|:----|:----:|:----:|:----:|
| 完整碰撞箱 | 是 | 否 | 是 |
| 透明渲染 | 否 | 部分 | 是（最佳） |
| 座椅 | 否 | 否 | 是（独有） |
| 最大变体数 | ~800 | 127 | 63 |
| 方向性放置 | 是 | 否 | 否 |
| 含水 | 否 | 是 | 否 |
| 高株植物 | 否 | 是 | 否 |
| 随机放置 | 否 | 是 | 否 |
| 堆叠方块 | 否 | 是 | 否 |
| 树苗机制 | 否 | 是 | 否 |
| 农场方块 | 是 | 否 | 否 |
| 去皮原木 | 是 | 否 | 否 |
| 存储容器 | 是 | 是 | 是 |
| 发光 | 是 | 是 | 是 |
| 防爆 | 是 | 是 | 是 |
| 下落 | 是 | 是 | 是 |
| 不可推动 | 是 | 是 | 是 |
| ClickActions | 是 | 是 | 是 |
| BlockLocker | 是 | 是 | 是 |
| 自定义音效 | 是 | 是 | 是 |

选择建议：
  - 实心方块、矿石、存储、方向性 → 音符盒（功能最全）
  - 植物、花朵、含水、高株、树苗 → 绊线（特色功能）
  - 透明方块、树叶、玻璃、座椅 → 紫颂（独有优势）
  - 复杂3D家具、无变体限制 → 家具机制（不占用方块变体）

## 九、parent_model 在紫颂方块中的选择

```
紫颂方块的 parent_model 选择与其他方块机制略有不同：

  block/leaves：
    → 透明度渲染 + 树叶专用光照
    → 最适合树叶、植被类方块
    → 推荐用于所有需要透明度的自然方块

  block/cube_all：
    → 标准立方体渲染 + 紫颂透明通道
    → 最适合玻璃、水晶、冰块类方块

  block/cross：
    → 十字交叉面片（同绊线花朵）
    → 适合紫颂植物、发光蘑菇等

注意：紫颂机制仅影响渲染方式和功能集，不影响父模型的选择。
你仍然可以根据纹理需要选择任意 parent_model。
```

## 十、注意事项

1. **变体最少**: 只有 63 个变体，是所有方块机制中最少的。新建紫颂方块时务必规划好编号。

2. **Paper 性能优化必须**: 务必在 `paper-global.yml` 中设置 `disable-chorus-plant-updates: true`，否则自定义紫颂方块会造成严重的服务器性能问题。

3. **座椅与家具的选择**: 紫颂的座椅适合"方块型椅子"。如果你的椅子模型很复杂（高精度3D模型），建议用家具(Furniture)机制+barrier+seat，因为它不受63变体的限制。

4. **透明方块最佳选择**: 对于透视渲染很重要的方块（树叶、玻璃类、水晶），紫颂方块是比家具（展示实体）更高效的选择——方块渲染比实体渲染性能好。

5. **不支持方向性**: 紫颂方块不能像音符盒那样用 directional (LOG/FURNACE/DROPPER) 做方向性放置。

6. **不支持农场方块**: 需要 farmblock 子机制的功能只能搭配音符盒使用。
