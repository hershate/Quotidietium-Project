# 实战示例：农场方块 (FarmBlock) 与洒水壶系统

> 本文件基于 Oraxen 官方文档的 FarmBlock 与 Farming 章节，
> 展示纯 Oraxen 原生农场方块系统（干燥+湿润双方块）和洒水壶浇水机制的完整配置。

---

## 一、核心概念：双方块系统

```
农场方块系统的核心设计模式 —— 一个方块有两个状态：

  [干燥方块]  ←── 放置时获得
     │
     │ 玩家手持洒水壶右键浇水
     ↓
  [湿润方块]  ←── 浇水后切换
     │
     │ 经过 farmBlockDryOutTime (毫秒)
     ↓
  [干燥方块]  ←── 水分耗尽，自动变回

每一个农场方块 = 消耗 2 个音符盒变体 (干燥 + 湿润各一个)。
```

---

## 二、全局配置 (mechanics.yml)

```yaml
# ============================================================
# plugins/Oraxen/mechanics.yml — 农场方块相关配置
# ============================================================

# 农场方块基于音符盒机制，所以先配置 noteblock
noteblock:
  enabled: true
  tool_types:
    - WOODEN
    - STONE
    - IRON
    - GOLDEN
    - DIAMOND
    - NETHERITE

  # [关键] 农场方块干燥检查间隔（刻）
  # 20刻 = 1秒
  # 值越小检查越频繁，干旱响应越灵敏
  # 值越大性能越好（推荐 1000+）
  # 默认设置：1000刻 = 50秒检查一次
  farmblock_check_delay: 1000

# 浇水机制
watering:
  enabled: true                              # 启用洒水壶浇水系统

# 收获机制
harvesting:
  enabled: true                              # 启用自动收获和补种
```

## 三、示例1：干燥魔法土壤 (magic_soil_dry)

玩家可直接获得的方块，放置后为干燥状态。

```yaml
# ============================================================
# 干燥魔法土壤 — 玩家物品栏中持有的版本
# ============================================================
magic_soil_dry:
  # ---- 基础信息 ----
  displayname: "<white>魔法土壤"
  material: PAPER

  # ---- 资源包/模型配置 ----
  Pack:
    generate_model: false                   # 使用预制模型（Blockbench制作）
    model: block/farm/magic_soil_dry

  # ---- 方块机制配置 ----
  Mechanics:
    noteblock:                              # 基于音符盒机制
      # [必需] 变体编号
      custom_variation: 1

      # [必需] 模型路径
      model: block/farm/magic_soil_dry

      # [可选] 硬度
      hardness: 5                           # 中等硬度

      # ========== 农场方块子机制 ==========
      farmblock:
        # [必需] 湿润版本的 Oraxen 物品 ID
        moistFarmBlockPath: magic_soil_wet
        # [必需] 水分耗尽时间（毫秒）
        # 30000ms = 30秒, 60000ms = 1分钟, 300000ms = 5分钟
        farmBlockDryOutTime: 30000

      # ========== 掉落物 ==========
      drop:
        silktouch: false
        best_tools:
          - SHOVEL                           # 铲子最佳
        loots:
          - oraxen_item: magic_soil_dry
            probability: 1.0
```

## 四、示例2：湿润魔法土壤 (magic_soil_wet)

浇水后自动从干燥切换为此状态。物品栏中隐藏。

```yaml
# ============================================================
# 湿润魔法土壤 — 浇水后的状态，物品栏中隐藏
# ============================================================
magic_soil_wet:
  # [关键] 排除此物品在 Oraxen 物品栏/GUI 中的显示
  # 玩家只能通过浇水操作看到湿润状态
  excludeFromInventory: true

  # ---- 基础信息 ----
  displayname: "<white>魔法土壤（湿润）"
  material: PAPER

  # ---- 资源包/模型配置 ----
  Pack:
    generate_model: false
    model: block/farm/magic_soil_wet

  # ---- 方块机制配置 ----
  Mechanics:
    noteblock:
      # [关键] 与干燥版本不同的变体！
      custom_variation: 2
      model: block/farm/magic_soil_wet
      hardness: 5

      # ========== 农场方块子机制 ==========
      farmblock:
        # [必需] 干燥版本的 Oraxen 物品 ID
        farmBlockPath: magic_soil_dry
        # [必需] 建议与干燥版本保持一致的时间
        farmBlockDryOutTime: 30000

      # ========== 掉落物 ==========
      drop:
        silktouch: false
        best_tools:
          - SHOVEL
        loots:
          # [重要] 湿润方块破坏时掉落干燥版本
          # 玩家物品栏中应该只有干燥版本
          - oraxen_item: magic_soil_dry
            probability: 1.0
```

## 五、moistFarmBlockPath 和 farmBlockPath 的互链机制

```
完整的农场方块双配置需要互相引用：

干燥方块的 farmblock 配置:
  moistFarmBlockPath: magic_soil_wet   → "浇水后变成哪个方块"
  farmBlockDryOutTime: 30000           → "湿润能保持多久"

湿润方块的 farmblock 配置:
  farmBlockPath: magic_soil_dry        → "水分耗尽后变回哪个方块"
  farmBlockDryOutTime: 30000           → "建议与干燥版本一致"

互链图解:
  ┌─────────────────┐      浇水      ┌─────────────────┐
  │ magic_soil_dry  │ ──→ moistFarmBlockPath ──→ │ magic_soil_wet  │
  │   (干燥版本)    │                    │   (湿润版本)     │
  │                 │ ←── farmBlockPath ──────── │                 │
  └─────────────────┘   (水分耗尽后变回)  └─────────────────┘

如果互链配置不一致（例如 dry→wet 但 wet→另一个方块），会导致状态异常。
```

## 六、excludeFromInventory 的用法

```yaml
# ============================================================
# 湿润方块通常需要从物品栏中隐藏
# ============================================================
magic_soil_wet:
  excludeFromInventory: true

  displayname: "<white>魔法土壤（湿润）"
  material: PAPER
  # ... 其余配置

# 为什么需要 excludeFromInventory？
# 1. 防止玩家直接放置湿润方块（跳过浇水过程）
# 2. 保持物品栏整洁（只显示干燥版本）
# 3. 湿润版本是"中间状态"，不应作为独立物品存在
```

## 七、洒水壶系统 (Watering Can)

Oraxen 内置洒水壶机制，需要两个物品（空壶 + 满壶），互相关联。

### 7.1 全局启用

```yaml
# mechanics.yml
watering:
  enabled: true
```

### 7.2 物品配置

```yaml
# ============================================================
# 空洒水壶 — 玩家手持此物品右键水源来装水
# ============================================================
empty_magic_watering_can:
  displayname: "<gray>空魔法洒水壶"
  material: LEATHER_HORSE_ARMOR
  Pack:
    generate_model: false
    model: items/empty_magic_watering_can
  Mechanics:
    watering:
      # [必需] 装满水后变成哪个物品
      filledCanItem: filled_magic_watering_can

# ============================================================
# 满洒水壶 — 右击农场方块给土壤浇水
# ============================================================
filled_magic_watering_can:
  displayname: "<aqua>满魔法洒水壶"
  material: LEATHER_HORSE_ARMOR
  Pack:
    generate_model: false
    model: items/filled_magic_watering_can
  Mechanics:
    watering:
      # [必需] 水用完后变回哪个物品
      emptyCanItem: empty_magic_watering_can
```

### 7.3 工作流程

```
玩家手持 [空魔法洒水壶]
  │
  │ 右击水源方块（水/炼药锅）
  ↓
玩家手持 [满魔法洒水壶]
  │
  │ 右击干燥的农场方块
  ↓
农场方块: magic_soil_dry → magic_soil_wet (浇水成功)
  │
  │ 洒水壶变回空壶
  ↓
玩家手持 [空魔法洒水壶]
  │
  │ 循环...
  ↓
```

## 八、farmBlockDryOutTime 配置详解

```
farmBlockDryOutTime 用于控制湿润方块保持水分的时间。

单位：毫秒 (ms)
  1000ms  = 1秒
  60000ms = 1分钟
  300000ms = 5分钟
  600000ms = 10分钟
  1800000ms = 30分钟

选择建议：
  - 小型种植盆：30000-60000ms（30秒-1分钟）
    → 适合活跃的游戏循环，玩家需要频繁浇水

  - 中型农场：300000ms（5分钟）
    → 适合标准农耕体验

  - 大型农田：600000ms（10分钟）
    → 适合休闲玩法

重要规则：
  1. 干燥和湿润版本的 farmBlockDryOutTime 必须保持一致
  2. 值越小，服务器检查负载越高（但影响很小）
  3. 值越大，玩家浇水频率越低
```

## 十、农场方块配置速查

```
干燥方块 (玩家可获取):
  Mechanics:
    noteblock:
      custom_variation: <唯一编号>
      model: <干燥模型路径>
      farmblock:
        moistFarmBlockPath: <湿润方块ID>    # 浇水后变成谁
        farmBlockDryOutTime: 30000          # 水分保持时间(ms)
      drop:
        loots:
          - oraxen_item: <干燥方块ID>       # 掉落自身
            probability: 1.0

湿润方块 (excludeFromInventory: true):
  Mechanics:
    noteblock:
      custom_variation: <与干燥不同!>
      model: <湿润模型路径>
      farmblock:
        farmBlockPath: <干燥方块ID>         # 干燥后变回谁
        farmBlockDryOutTime: 30000          # 建议一致
      drop:
        loots:
          - oraxen_item: <干燥方块ID>       # 掉落干燥版本
            probability: 1.0

洒水壶 (empty/filled 配对):
  empty_<name>:
    Mechanics:
      watering:
        filledCanItem: <满壶ID>
  filled_<name>:
    Mechanics:
      watering:
        emptyCanItem: <空壶ID>
```

## 十一、注意事项

1. **双方块各需变体**: 一个农场方块消耗 2 个音符盒变体（干燥+湿润）。3 级土壤 = 6 个变体。

2. **custom_variation 不能重复**: 干燥和湿润必须用不同的变体编号。

3. **farmBlockDryOutTime 双向一致**: 干燥和湿润版本的时间必须相同，否则会出现切换损坏。

4. **excludeFromInventory 必须**: 湿润方块应设置 excludeFromInventory: true，防止玩家直接获取。

5. **基于音符盒**: 农场方块是音符盒的子机制，受 noteblock 全局配置影响。

6. **farmblock_check_delay**: 在 mechanics.yml 中设置。值越小干旱响应越快，但性能消耗越大。推荐 1000 刻 (50秒)。

7. **破坏湿润方块**: 湿润方块被破坏时通常掉落干燥版本，确保玩家物品栏中只有干燥版。

8. **洒水壶配对**: 空壶和满壶通过 filledCanItem/emptyCanItem 互相引用，必须双向配置完整。

9. **模型要求**: 每个农场方块需要预制模型（Blockbench 制作）——干燥和湿润各一个模型文件。
