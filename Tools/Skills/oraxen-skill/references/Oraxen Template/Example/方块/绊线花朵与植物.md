# 实战示例：绊线花朵与植物 (StringBlock Flower & Plant)

> 本文件基于项目 `Oraxen/items/flowers.yml` 中的实际配置提取，展示绊线机制在植物/花卉中的最佳实践。

---

## 一、为什么花朵用绊线 (StringBlock) 而非音符盒？

```
花朵的核心需求：玩家可以穿过它们（没有完整碰撞箱）。

三种方块机制的碰撞箱特性：
  - 音符盒 (NoteBlock)      → 完整 1x1x1 方块碰撞箱（实心）
  - 绊线   (StringBlock)    → 无碰撞箱或极小碰撞箱（可穿过）
  - 紫颂   (ChorusBlock)    → 可自定义碰撞箱

花朵是"玩家应能穿过的装饰物"，所以必须用绊线。
如果某装饰物需要碰撞（如路障、栅栏装饰），则用音符盒。
```

## 二、全局配置 (mechanics.yml)

```yaml
# ============================================================
# plugins/Oraxen/mechanics.yml — 绊线全局配置
# ============================================================
stringblock:
  enabled: true

  tool_types:
    - WOODEN
    - STONE
    - IRON
    - GOLDEN
    - DIAMOND
    - NETHERITE

  # 树苗生长检查间隔（本项目暂未使用树苗机制）
  sapling_growth_check_delay: 4000         # 每4000刻(200秒)检查

  # 是否禁用原版绊线放置
  # true = 原版绊线无法被玩家放置，仅用于自定义方块
  # false = 原版绊线正常工作
  disable_vanilla_strings: false
```

## 三、示例1：基础花朵 (block/cross 父模型)

从 `flowers.yml` 中的 `brunnera` 提取。

```yaml
# ============================================================
# Brunnera — 最简单的绊线花朵
# ============================================================
brunnera:
  # ---- 基础信息 ----
  # [必需] 显示名称，纯色代码
  itemname: <#34d8eb>Brunnera

  # [必需] 基础材质。植物类统一用 PAPER
  material: PAPER

  # ---- 资源包/模型配置 ----
  Pack:
    # [必需] 自动生成模型
    generate_model: true

    # [必需] 父模型 block/cross = 十字交叉面片模型
    # 这是植物/花朵的专用模型，纹理作为平面交叉显示
    # 纹理需要包含透明通道（PNG格式）来实现不规则形状
    parent_model: block/cross

    # [必需] 纹理文件
    textures:
      - default/flowers/brunnera.png

  # ---- 方块机制配置 ----
  Mechanics:
    stringblock:                            # 注意：是 stringblock 不是 noteblock
      # ---- 基础音效 ----
      block_sounds:
        break_sound: block.grass.break      # 破坏时 → 草声
        place_sound: block.grass.place      # 放置时 → 草声

      # ---- 核心配置 ----
      # [必需★] 绊线变体编号，范围 1-127
      # 注意：绊线有碰撞箱大小之分（见下文）
      custom_variation: 1

      # [必需★] 模型名称
      model: brunnera

      # ---- 硬度 ----
      hardness: 2                           # 很容易破坏

      # ---- 掉落物 ----
      drop:
        silktouch: false                    # 不需要精准采集就能掉落
        loots:
          - oraxen_item: brunnera           # 破坏后掉自身
            probability: 1.0                # 100% 掉率
```

## 八、custom_variation 范围与碰撞箱差异

```
这是绊线方块特有的行为差异：

  custom_variation 在 1-64 范围内：
    → 使用较大的碰撞箱
    → 玩家穿过时略有阻滞感
    → 适合一般大小的装饰物、小灌木

  custom_variation 在 65-127 范围内：
    → 使用更小的碰撞箱
    → 玩家几乎无感穿过
    → 适合非常小的细节装饰、花瓣、苔藓

本项目的三个花朵使用 1/2/3（大碰撞箱范围），适合花的大小。
如果你要做"落在地上的花瓣"类微小装饰，用 65-127 范围。
```

## 九、StringBlock vs NoteBlock 选择建议

| 需求 | 推荐机制 | 原因 |
|:---|:---|:---|
| 实心方块/矿石 | NoteBlock（音符盒） | 完整碰撞箱，800变体 |
| 花朵/草丛/植物 | StringBlock（绊线） | 可穿过，含水，高株 |
| 树苗 | StringBlock | 有 sapling 树苗机制 |
| 2格高植物 | StringBlock | is_tall 支持 |
| 水下装饰 | StringBlock | 绊线天然含水 |
| 随机外观花丛 | StringBlock | random_place 独有 |
| 可堆叠花瓣 | StringBlock | stackable 独有 |
| 透明方块/树叶 | ChorusBlock（紫颂） | 透明渲染，座椅 |
| 方向性方块/原木 | NoteBlock | directional 支持 |
| 存储箱 | NoteBlock | storage 支持 |

## 十、项目花朵模板总结

```
本项目所有花朵的共性：
  - material: PAPER
  - parent_model: block/cross（十字交叉面片，支持透明通道）
  - break_sound/place_sound: block.grass.*（植物音效）
  - hardness: 2（容易破坏）
  - silktouch: false（不需要精准采集）
  - 每个花朵一个 loot 条目，probability: 1.0

新增花朵的步骤：
  1. 复制任意花朵配置
  2. 改 custom_variation（递增占用：现在用了1/2/3，下一个用4）
  3. 改 itemname 颜色
  4. 改 textures 为新纹理文件路径
  5. 改 model 名称为新花朵ID
  6. 改 loots 掉落为自身
  7. 其他保持默认即可
```
