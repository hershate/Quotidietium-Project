# 自定义能力与点击动作 (Custom & ClickAction) 实战配置手册

> 基于 Oraxen 官方文档。这两个系统是 Oraxen 中最强大的可编程机制——
> 不需要写任何 Java 代码就能实现复杂物品行为。

---

## 速查：Custom vs ClickAction 对比

| 特性 | Custom | ClickAction |
|------|--------|-------------|
| **适用范围** | 物品（items） | 方块（noteblock/stringblock/chorusblock）和家具（furniture） |
| **条件系统** | `HAS_PERMISSION`（简单直接） | SpEL 表达式（强大灵活） |
| **事件类型** | CLICK, DROP, PICKUP, BREAK, EQUIP, UNEQUIP, INV_CLICK, DEATH（8种） | 仅点击 |
| **动作类型** | COMMAND, MESSAGE, ACTIONBAR, SOUND | [console], [player], [message], [actionbar], [sound] |
| **多组条件/动作** | 不支持（每个能力一个事件 + 条件 + 动作） | **支持**（按顺序匹配，第一组满足即执行） |
| **复杂度** | 简单易用 | 灵活强大 |

---

## 一、Custom 机制（物品用）

### 基本结构

```yaml
Mechanics:
  custom:
    <能力名称>:                               # 每个能力的唯一标识符
      one_usage: false                         # 使用后是否消耗物品
      cooldown: <刻数>                         # 冷却时间，单位 ticks（20 ticks = 1秒）
      event: "<事件类型>"                      # 触发时机
      conditions:                              # 触发前必须满足的条件
        - "<条件表达式>"
      actions:                                 # 触发后执行的动作
        - "<动作表达式>"
```

### 参数速查表

| 参数 | 类型 | 必填 | 默认值 | 有效范围 | 说明 |
|------|------|:--:|--------|----------|------|
| `one_usage` | 布尔 | 否 | `false` | `true` / `false` | `true` = 使用一次后物品消失（消耗1个） |
| `cooldown` | 整数 | 否 | `0` | `1` ~ `72000` | 冷却时间（刻 ticks）。`20` = 1秒，`100` = 5秒 |
| `event` | 字符串 | **是** | -- | 见下方事件类型表 | 触发此能力的时机 |
| `conditions` | 字符串列表 | 否 | `[]` | `HAS_PERMISSION:<权限>` | 触发前必须满足的条件 |
| `actions` | 字符串列表 | **是** | `[]` | 见下方动作类型表 | 触发后执行的动作 |

---

### 事件类型速查表

| 事件字符串 | 触发时机 | 说明 |
|-----------|---------|------|
| `CLICK:right:all` | 右键点击任意目标 | 最常用 —— 右键空气或方块都触发 |
| `CLICK:right:block` | 右键点击方块 | 只有点击方块才触发 |
| `CLICK:right:air` | 右键点击空气 | 只有点击空气才触发 |
| `CLICK:left:all` | 左键点击任意目标 | 左键通用 |
| `CLICK:left:block` | 左键点击方块 | 左键方块 |
| `CLICK:left:air` | 左键点击空气 | 左键空气 |
| `CLICK:all:all` | 任意按键点击任意目标 | 最宽松 —— 左右键、空气或方块都行 |
| `DROP` | 玩家丢弃物品时 | 按 Q 键丢弃触发 |
| `PICKUP` | 玩家拾取物品时 | 从地面捡起触发 |
| `BREAK` | 物品耐久耗尽损坏时 | 工具/武器用坏时触发 |
| `EQUIP` | 物品被装备时 | 放入护甲槽或副手 |
| `UNEQUIP` | 物品被卸下时 | 从护甲槽或副手取出 |
| `INV_CLICK` | 物品栏中点击物品时 | 背包内点击 |
| `DEATH` | 玩家死亡且物品通常会掉落时 | 死亡时刻触发 |

---

### 动作类型速查表

| 动作格式 | 说明 | 示例 |
|----------|------|------|
| `COMMAND:console:<命令>` | 以控制台身份执行命令 | `COMMAND:console:give <player> diamond 1` |
| `COMMAND:player:<命令>` | 以玩家身份执行命令 | `COMMAND:player:spawn` |
| `MESSAGE:<消息>` | 发送聊天消息（支持 MiniMessage） | `MESSAGE:<green>操作成功!` |
| `ACTIONBAR:<消息>` | 发送操作栏消息（支持 MiniMessage） | `ACTIONBAR:<yellow>冷却中...` |
| `sound:` + 子参数 | 播放音效 | 见下方 sound 动作详解 |

#### Sound 动作详解

```yaml
actions:
  sound:
    name: oraxen:<音效ID>                    # 引用 sound.yml 中的音效
    volume: 1.0                              # 音量: 0.0-1.0+
    pitch: 1.0                               # 音调: 0.5=低八度, 2.0=高八度
```

#### 占位符

| 占位符 | 说明 |
|--------|------|
| `<player>` | 在执行 COMMAND 时自动替换为使用物品的玩家名称 |

### 完整配置示例

#### 示例 1：简单右键物品（最基础）

```yaml
# ============================================================
# 右键物品获得熟牛肉（带权限检查）
# ============================================================
magic_stick:
  material: STICK
  displayname: "<light_purple>魔法棒"
  lore:
    - "<gray>右键获得熟牛肉"
    - "<gray>需要 example.permission 权限"
  Mechanics:
    custom:
      test:
        one_usage: false                     # 无限使用
        event: "CLICK:right:all"             # 右键任意目标
        conditions:
          - "HAS_PERMISSION:example.permission"  # 需要此权限
        actions:
          - "COMMAND:console:give <player> cooked_beef 1"  # 控制台给物品
```

#### 示例 2：传送物品（无条件 + 冷却）

```yaml
# ============================================================
# 右键传送回出生点（无条件，10秒冷却）
# ============================================================
teleport_stick:
  material: BLAZE_ROD
  displayname: "<aqua>传送棒"
  lore:
    - "<gray>右键传送回出生点"
    - "<gray>冷却时间: 10 秒"
  Mechanics:
    custom:
      teleport:
        one_usage: false                     # 不消耗物品
        cooldown: 200                        # 200 刻 = 10 秒冷却
        event: "CLICK:right:all"
        conditions: []                       # 无条件
        actions:
          - "COMMAND:player:spawn"           # 玩家执行 /spawn
          - "MESSAGE:<green>已传送至出生点!"
```

#### 示例 3：一次性消耗品

```yaml
# ============================================================
# 使用一次后消失的飞行魔杖
# ============================================================
one_time_wand:
  material: END_ROD
  displayname: "<red>一次性魔杖"
  lore:
    - "<gray>使用后消失"
    - "<gray>给予 30 秒飞行能力"
  Mechanics:
    custom:
      fly_grant:
        one_usage: true                      # 关键: 使用后消耗 1 个
        event: "CLICK:right:all"
        conditions: []
        actions:
          - "COMMAND:console:fly enable <player>"
          - "MESSAGE:<green>飞行模式已启用（30秒）!"
          - "ACTIONBAR:<aqua>你飞起来了!"
```

#### 示例 4：多事件复杂物品（装备/卸下/右键/死亡各有行为）

```yaml
# ============================================================
# 高级神器 — 装备/卸下/右键/死亡各有不同行为
# ============================================================
advanced_artifact:
  material: NETHER_STAR
  displayname: "<gold>高级神器"
  lore:
    - "<gray>装备时获得力量"
    - "<gray>右键获得经验"
    - "<gray>死亡时不掉落（但会发送消息）"
  Mechanics:
    custom:
      # ── 右键点击：获得经验 ─────────────────
      use_artifact:
        one_usage: false
        event: "CLICK:right:all"
        conditions: []
        actions:
          - "COMMAND:console:xp add <player> 100"
          - "ACTIONBAR:<aqua>获得 100 点经验!"

      # ── 装备时：发送消息 ─────────────────
      equip_artifact:
        one_usage: false
        event: "EQUIP"
        conditions: []
        actions:
          - "MESSAGE:<gold>神器装备！力量涌入你的身体！"

      # ── 卸下时：发送消息 ─────────────────
      unequip_artifact:
        one_usage: false
        event: "UNEQUIP"
        conditions: []
        actions:
          - "MESSAGE:<gray>神器已卸下。"

      # ── 死亡时：发送消息 ─────────────────
      death_artifact:
        one_usage: false
        event: "DEATH"
        conditions: []
        actions:
          - "MESSAGE:<dark_red>神器随你一同陨落..."

    # ── 灵魂绑定：死后保留物品 ─────────────
    soulbound:
      lose_chance: 0
```

#### 示例 5：带音效的右键物品

```yaml
# ============================================================
# 魔法杖 — 右键播放音效
# ============================================================
magic_wand:
  material: STICK
  displayname: "<gradient:#AA00FF:#FF00AA>魔法杖"
  Mechanics:
    custom:
      on_use:
        event: "CLICK:right:all"
        actions:
          sound:
            name: oraxen:magical_hum         # 引用 sound.yml 音效
            volume: 1.0
            pitch: 1.0
```

## 二、ClickAction 系统（方块/家具用）

### 基本结构

```yaml
Mechanics:
  furniture:                                 # 或 noteblock / stringblock / chorusblock
    clickActions:
      - conditions:                          # 条件列表（全部满足才触发）
          - '<SpEL 条件表达式>'
        actions:                             # 条件满足时执行的动作
          - "[动作标签] 动作内容"
```

> **匹配规则：** clickActions 是列表，按**从上到下**的顺序匹配。第一组条件全部满足的被执行，后面的不再检查。因此：把最严格的条件放在最上面。

### ClickAction 条件系统（SpEL 表达式）

> SpEL = Spring Expression Language。Oraxen 使用它让条件极度灵活。
> 条件以 `#player.` 或 `#server.` 开头。

#### 条件表达式速查表

| 表达式 | 说明 | 典型值 |
|--------|------|--------|
| `#player.hasPermission("perm")` | 检查玩家权限 | `"vip.access"`, `"admin"` |
| `#player.world.name == "world"` | 检查玩家所在世界 | `"world"`, `"world_nether"`, `"world_the_end"` |
| `#player.gamemode.name() == "SURVIVAL"` | 检查游戏模式 | `"SURVIVAL"`, `"CREATIVE"`, `"ADVENTURE"`, `"SPECTATOR"` |
| `#player.name == "Steve"` | 检查玩家名称 | 玩家名字符串 |
| `#player.health > 20` | 检查生命值 | 数字（每颗心=2） |
| `#player.level >= 30` | 检查经验等级 | 数字 |
| `#player.foodLevel > 10` | 检查饥饿值 | 数字（0-20） |
| `#player.isSneaking()` | 检查是否潜行 | `true` / `false` |
| `#player.isSprinting()` | 检查是否疾跑 | `true` / `false` |
| `#player.isFlying()` | 检查是否飞行 | `true` / `false` |
| `#player.isOnGround()` | 检查是否在地面 | `true` / `false` |
| `#player.isInWater()` | 检查是否在水中 | `true` / `false` |
| `#player.inventory.itemInMainHand.type.name() == "DIAMOND_SWORD"` | 检查主手物品类型 | Material 枚举 |
| `#server.getOnlinePlayers().size() > 10` | 检查在线玩家数 | 数字 |
| `#server.getAllowEnd()` | 检查服务器是否允许末地 | `true` / `false` |
| `#server.getMaxPlayers()` | 获取最大玩家数 | 数字 |

#### 条件组合

| 组合方式 | 语法 | 示例 |
|----------|------|------|
| 多条件（全部满足） | 多条 conditions 列表项 | `- '#player.hasPermission("vip")'` <br> `- '#player.world.name == "world"'` |
| 或关系（任一满足） | `or` 关键字 | `'#player.hasPermission("admin") or #player.hasPermission("mod")'` |
| 与关系（全部满足） | `and` 关键字 | `'#player.level >= 10 and #player.level < 30'` |

### ClickAction 动作系统

| 动作标签 | 格式 | 说明 |
|----------|------|------|
| `[console]` | `[console] <命令>` | 以控制台身份执行命令。`<player>` 自动替换为玩家名 |
| `[player]` | `[player] <命令>` | 以玩家身份执行命令 |
| `[message]` | `[message] <消息>` | 发送聊天消息（支持 MiniMessage） |
| `[actionbar]` | `[actionbar] <消息>` | 发送操作栏消息（支持 MiniMessage） |
| `[sound]` | `[sound] <声音ID>` 或 `{参数} [sound] <声音ID>` | 播放声音 |

### ClickAction 完整示例

#### 示例 1：权限门系统

```yaml
# ============================================================
# 只有 VIP 玩家才能进入的门
# ============================================================
vip_door:
  material: PAPER
  displayname: "<gold>VIP 入口"
  Mechanics:
    furniture:
      clickActions:
        # 第一组: VIP 玩家（优先匹配）
        - conditions:
            - '#player.hasPermission("vip.access")'
          actions:
            - "[console] tp <player> vip_area"
            - "[message] <green>欢迎来到 VIP 区域!"
        # 第二组: 无条件（兜底，没有权限的玩家看到）
        - conditions: []
          actions:
            - "[message] <red>你没有访问此区域的权限!"


# ============================================================
# 商店交易系统 — 消耗钻石换绿宝石
# ============================================================
shop_trader:
  material: PAPER
  displayname: "<yellow>宝石商人"
  Mechanics:
    furniture:
      clickActions:
        - conditions:
            - '#player.hasPermission("shop.use")'
          actions:
            - "[console] take <player> diamond 10"
            - "[console] give <player> emerald 20"
            - "[message] <green>交易成功！用 10 钻石兑换了 20 绿宝石"
            - "{source=AMBIENT volume=0.5 pitch=1} [sound] minecraft:entity.villager.trade"
        - conditions: []
          actions:
            - "[message] <red>你不能使用此商店!"
```

#### 示例 2：传送菜单

```yaml
# ============================================================
# 传送中心 — 点击前往不同地点
# ============================================================
teleport_hub:
  material: PAPER
  displayname: "<aqua>传送中心"
  Mechanics:
    furniture:
      clickActions:
        # 潜行点击 → 出生点
        - conditions:
            - '#player.isSneaking()'
          actions:
            - "[player] spawn"
            - "[message] <green>潜行传送至出生点!"
        # 普通点击 → 商店
        - conditions: []
          actions:
            - "[player] warp shop"
            - "[message] <green>传送至商店!"
```

#### 示例 3：带音效的多条件交互

```yaml
# ============================================================
# 高级祭坛 — 管理员/VIP/普通玩家三种不同的交互
# ============================================================
advanced_altar:
  material: PAPER
  displayname: "<gold>高级祭坛"
  Mechanics:
    furniture:
      clickActions:
        # 管理员专用
        - conditions:
            - '#player.hasPermission("admin.altar")'
          actions:
            - "[console] say <player> 以管理员身份使用了祭坛"
            - "[message] <red>管理员模式已激活"
            - "{source=MASTER volume=1.0 pitch=1.5} [sound] minecraft:block.end_portal.spawn"

        # VIP 玩家
        - conditions:
            - '#player.hasPermission("vip.altar")'
          actions:
            - "[console] give <player> diamond 5"
            - "[message] <aqua>你获得了 5 颗钻石!"
            - "{source=AMBIENT volume=0.5 pitch=1} [sound] minecraft:entity.player.levelup"

        # 普通玩家（无条件兜底）
        - conditions: []
          actions:
            - "[message] <gray>你没有使用此祭坛的权限"
```

## 三、条件表达式进阶

### 比较运算符

| 运算符 | 说明 | 示例 |
|--------|------|------|
| `==` | 等于 | `#player.world.name == "world"` |
| `!=` | 不等于 | `#player.gamemode.name() != "CREATIVE"` |
| `>` | 大于 | `#player.level > 30` |
| `<` | 小于 | `#player.health < 10` |
| `>=` | 大于等于 | `#player.foodLevel >= 15` |
| `<=` | 小于等于 | `#player.level <= 5` |
| `and` | 逻辑与 | `#player.level >= 10 and #player.level < 30` |
| `or` | 逻辑或 | `#player.hasPermission("a") or #player.hasPermission("b")` |

### SpEL 表达式的注意事项

1. 必须以 `#player.` 或 `#server.` 开头
2. 方法调用需要 `()` 括号，例如 `#player.gamemode.name()`
3. 字符串值用英文双引号 `"..."` 包裹
4. 整个表达式用英文单引号 `'...'` 包裹（在 YAML 中）

## 四、常见用例速查

| 用例 | 推荐系统 | 关键配置 |
|------|---------|---------|
| 右键获得物品 | Custom | `event: CLICK:right:all` + `COMMAND:console:give` |
| 右键传送 | Custom | `event: CLICK:right:all` + `COMMAND:player:spawn` |
| 一次性消耗品 | Custom | `one_usage: true` |
| 带冷却时间 | Custom | `cooldown: <刻数>` |
| 权限门 | ClickAction | `conditions: '#player.hasPermission("...")'` |
| 商店/交易 | ClickAction | `[console] take` + `[console] give` |
| 传送菜单 | ClickAction | 多组 clickActions + 不同 conditions |
| 装备/卸下事件 | Custom | `event: EQUIP` / `event: UNEQUIP` |
| 死亡事件 | Custom | `event: DEATH` |
