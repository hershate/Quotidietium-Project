> 命令、护甲效果、光环、帽子、皮肤/换肤、灵魂绑定、消耗品、切换灯光等所有杂项机制。

## 一、耐久度 (durability)

> 为 Oraxen 物品设置自定义耐久度。耐久度数值基于底层材质缩放。
> 例如：基于木镐（原版耐久度 59）设置 5900 耐久度 → 需要破坏 100 个方块才消耗 1 点显示耐久。

| 参数 | 类型 | 默认值 | 有效范围 | 说明 |
|------|------|--------|----------|------|
| `value` | 整数 | -- | `1` ~ `100000` | **必填**。自定义耐久度值 |

```yaml
crystal_sword:
  material: DIAMOND_SWORD                    # 原版耐久度 1561
  displayname: "<aqua>水晶剑"
  Mechanics:
    durability:
      value: 5000                            # 约 3.2x 原版耐久
```

### 耐久度倍数计算

- 物品显示的原版数字不变，但实际耐久按 `(value / 原版耐久)` 的倍数缩放
- 例如：钻石剑原版 1561，自定义 5000。每消耗 1 显示耐久度，实际消耗 1561/5000 = 0.31 真实耐久
- 耐久条百分比正确更新

## 二、修复 (repair)

> 使用一个物品修复另一个物品的耐久度。

| 参数 | 类型 | 默认值 | 有效范围 | 说明 |
|------|------|--------|----------|------|
| `ratio` | 小数 | 无 | `0.0` ~ `1.0` | **二选一**。按百分比修复。`0.10`=修复10%，`1.0`=完全修复 |
| `fixed_amount` | 整数 | 无 | `1` ~ `100000` | **二选一**。按固定点数修复 |

> **注意：** `ratio` 和 `fixed_amount` 二选一，不能同时使用。

### 全局配置 (mechanics.yml)

```yaml
repair:
  enabled: true
  oraxen_durability_only: false   # true=仅修复带Oraxen耐久度的物品
```

```yaml
repair_kit:
  material: IRON_INGOT
  displayname: "<green>维修套件"
  lore:
    - "<gray>左键点击物品来修复"
    - "<gray>修复 10% 的耐久度"
  Mechanics:
    repair:
      ratio: 0.10                            # 修复 10%
```

### 工作流程

1. 手持修复物品
2. 左键点击需要修复的物品
3. 目标物品恢复相应耐久度
4. 修复物品消耗 1 个

## 三、效率 (efficiency)

> 手持物品时给予玩家急迫（Haste）效果。负值 = 挖掘疲劳。

| 参数 | 类型 | 默认值 | 有效范围 | 说明 |
|------|------|--------|----------|------|
| `amount` | 整数 | `1` | `-255` ~ `255` | 急迫等级。`0`=急迫I，`1`=急迫II，`-1`=挖掘疲劳I |

```yaml
super_pickaxe:
  material: NETHERITE_PICKAXE
  displayname: "<gold>超级镐"
  lore:
    - "<gray>手持时获得极速挖掘"
  Mechanics:
    efficiency:
      amount: 5                              # 急迫 VI（极快）
```

## 四、自定义食物 (food)

> 设置食物的饥饿值、饱和度、食用后效果和替换物品。

| 参数 | 类型 | 默认值 | 有效范围 | 说明 |
|------|------|--------|----------|------|
| `hunger` | 整数 | `4` | `0` ~ `20` | 恢复饥饿值。`1`=半个鸡腿 |
| `saturation` | 小数 | `2.4` | `0.0` ~ `20.0` | 恢复饱和度 |
| `replacement.oraxen_item` | 字符串 | 无 | Oraxen 物品 ID | 食用后替换为该物品（三选一） |
| `replacement.minecraft_type` | 字符串 | 无 | Material 枚举 | 食用后替换为原版物品（如 `BOWL`） |
| `replacement.crucible_item` | 字符串 | 无 | Crucible 物品 ID | 三选一 |
| `effect_probability` | 小数 | `1.0` | `0.0` ~ `1.0` | 所有效果应用的概率 |
| `effects.<类型>.amplifier` | 整数 | `0` | `0` ~ `255` | 效果等级（0=等级I） |
| `effects.<类型>.duration` | 整数 | `1` | `1` ~ `3600` | 效果持续时间（秒） |
| `effects.<类型>.is_ambient` | 布尔 | `true` | `true/false` | 环境效果（半透明粒子） |
| `effects.<类型>.has_particles` | 布尔 | `true` | `true/false` | 显示粒子 |
| `effects.<类型>.has_icon` | 布尔 | `true` | `true/false` | 显示图标 |

### 来自项目实际配置：粽子（dragon_boat_fest.yml）

```yaml
zongzi:
  displayname: "粽子"
  material: COOKED_BEEF
  Pack:
    generate_model: true
    parent_model: item/generated
    textures:
    - festival/zongzi.png
  Components:
    food:
      nutrition: 10                          # 恢复 5 个鸡腿
      saturation: 10                         # 高饱和度
      can_always_eat: true                   # 饱食时也可食用
```

### 使用 Mechanics 的 food 配置（通用格式）

```yaml
magic_apple:
  material: APPLE
  displayname: "<gold>魔法苹果"
  lore:
    - "<gray>恢复大量饥饿值"
    - "<gray>食用后获得增益"
  Mechanics:
    food:
      hunger: 10                             # 恢复 5 个鸡腿
      saturation: 10                         # 高饱和度
      replacement:
        minecraft_type: BOWL                 # 食用后留下碗
      effect_probability: 0.35               # 35% 概率触发效果
      effects:
        regeneration:
          amplifier: 2                       # 生命恢复 III
          duration: 30                       # 30 秒
        absorption:
          amplifier: 4                       # 伤害吸收 V
          duration: 120                      # 2 分钟
```

## 五、背包 (backpack)

> 创建功能性便携存储。右键打开 GUI。

| 参数 | 类型 | 默认值 | 有效范围 | 说明 |
|------|------|--------|----------|------|
| `rows` | 整数 | `3` | `1` ~ `6` | GUI 行数。每行 9 格，`4`=36格 |
| `title` | 字符串 | `Backpack` | 支持 MiniMessage | GUI 标题 |
| `open_sound` | 字符串 | `entity.shulker.open` | 声音 ID 或空字符串 | 打开声音 |
| `close_sound` | 字符串 | `entity.shulker.close` | 声音 ID 或空字符串 | 关闭声音 |

> **重要：** 在物品根级别设置 `unstackable: true` 防止堆叠复制漏洞。

```yaml
backpack:
  material: PAPER
  displayname: "<red>旅行背包"
  unstackable: true                         # 必须在根级别！
  lore:
    - "<gray>右键打开便携存储"
    - "<gray>共 4 行存储空间"
  Mechanics:
    backpack:
      rows: 4                                # 36 格存储
      title: "<red>旅行背包"
      open_sound: "entity.shulker.open"
      close_sound: "entity.shulker.close"
```

| 参数 | 类型 | 默认值 | 有效范围 | 说明 |
|------|------|--------|----------|------|
| *(此机制的详细字段未在官方文档中列出)* |||||

```yaml

  material: PAPER
  displayname: "<aqua>装饰背包"
```

## 七、音乐唱片 (music_disc)

> 制作自定义唱片机音乐。需要与 sound.yml 配合。

| 参数 | 类型 | 默认值 | 有效范围 | 说明 |
|------|------|--------|----------|------|
| `song` | 字符串 | -- | `namespace:sound_name` | **必填**。sound.yml 中的声音 ID |

```yaml
custom_disc:
  material: MUSIC_DISC_13
  displayname: "<purple>自定义唱片"
  Components:
    jukebox_playable:                       # 1.21+ 使用这个组件
      show_in_tooltip: true
      song_key: "oraxen:mysong"             # 引用 sound.yml 音效
  Pack:
    generate_model: true
    parent_model: "item/handheld"
    textures:
      - default/custom_disc.png
```

## 八、命令 (commands)

> 使用物品时执行命令（控制台/玩家/OP）。

| 参数 | 类型 | 默认值 | 有效范围 | 说明 |
|------|------|--------|----------|------|
| `cooldown` | 整数 | `0` | `0` ~ `3600` | 冷却时间（秒） |
| `permission` | 字符串 | 无 | 权限节点 | 使用所需的权限 |
| `one_usage` | 布尔 | `false` | `true/false` | 使用后是否消耗物品 |
| `console` | 字符串列表 | `[]` | 命令列表 | 控制台身份执行。`%p%`=玩家名 |
| `player` | 字符串列表 | `[]` | 命令列表 | 玩家身份执行 |
| `opped_player` | 字符串列表 | `[]` | 命令列表 | 临时 OP 身份执行 |

```yaml
command_stick:
  material: STICK
  displayname: "<yellow>命令棒"
  lore:
    - "<gray>右键执行特殊命令"
  Mechanics:
    commands:
      cooldown: 5                            # 5 秒冷却
      permission: "my.awesome.perm"
      one_usage: false                       # 不消耗
      console:
        - "kill %p%"
        - "say %p% 使用了神秘物品"
      player:
        - "spawn"
      opped_player:
        - "give %p% diamond_sword 1"
```

## 九、护甲效果 (armor_effects)

> 装备护甲时自动获得药水效果。卸下后移除。

| 参数 | 类型 | 默认值 | 有效范围 | 说明 |
|------|------|--------|----------|------|
| `<效果>.amplifier` | 整数 | `0` | `0` ~ `255` | 效果等级 |
| `<效果>.duration` | 整数 | 无 | `1` ~ `72000` | 持续时间（刻）。20刻=1秒 |
| `<效果>.ambient` | 布尔 | `true` | `true/false` | 是否为环境效果 |
| `<效果>.particles` | 布尔 | `true` | `true/false` | 显示粒子 |
| `<效果>.icon` | 布尔 | `true` | `true/false` | 显示图标 |
| `requires_full_set` | 布尔 | `false` | `true/false` | 是否需要全套护甲才生效 |

```yaml
speed_boots:
  material: DIAMOND_BOOTS
  displayname: "<aqua>速度之靴"
  lore:
    - "<gray>装备时获得速度 II"
  Mechanics:
    armor_effects:
      speed:
        amplifier: 1                          # 速度 II
        duration: 10                          # 每 10 刻刷新
        ambient: true
        particles: true
        icon: true

# 套装效果 — 需要全套才激活
set_chestplate:
  material: DIAMOND_CHESTPLATE
  displayname: "<red>套装胸甲"
  Mechanics:
    armor_effects:
      strength:
        requires_full_set: true               # 全套激活力量
        amplifier: 1                          # 力量 II
```

### 全局配置 (mechanics.yml)

```yaml
armor_effects:
  enabled: true
  delay_in_ticks: 20                # 效果刷新间隔。20=1秒
```

## 十、光环 (aura)

> 手持物品时显示粒子光环。

| 参数 | 类型 | 默认值 | 有效范围 | 说明 |
|------|------|--------|----------|------|
| `type` | 字符串 | `simple` | `simple` / `ring` / `helix` | 光环显示类型 |
| `particle` | 字符串 | `FLAME` | 有效粒子类型 | 显示的粒子 |

| 光环类型 | 效果 |
|----------|------|
| `simple` | 随机散落粒子 |
| `ring` | 环形粒子圈 |
| `helix` | 螺旋上升粒子 |

```yaml
particle_sword:
  material: GOLDEN_SWORD
  displayname: "<yellow>粒子剑"
  Mechanics:
    aura:
      type: ring
      particle: PORTAL
```

## 十二、灵魂绑定 (soulbound)

> 死亡时物品不掉落。

| 参数 | 类型 | 默认值 | 有效范围 | 说明 |
|------|------|--------|----------|------|
| `lose_chance` | 小数 | `0` | `0.0` ~ `1.0` | 死亡时丢失概率。`0`=永不，`0.5`=50%，`1`=总是 |

```yaml
legendary_sword:
  material: NETHERITE_SWORD
  displayname: "<gradient:red:gold>传奇之剑"
  lore:
    - "<gray>死亡时不掉落"
  Mechanics:
    soulbound:
      lose_chance: 0                        # 永不丢失
```

## 十三、皮肤 (skin) 与可换肤 (skinnable)

> `skinnable` 标记物品可被换肤。`skin` 是实际应用皮肤的消耗品。
> 两者必须使用**相同的材质**。

```yaml
# 可换肤的目标物品
custom_sword:
  material: DIAMOND_SWORD
  displayname: "<aqua>可换肤剑"
  Mechanics:
    skinnable: {}                           # 空配置 = 可换肤

# 皮肤物品（右键目标物品应用）
sword_skin:
  material: DIAMOND_SWORD                    # 必须与目标材质相同！
  displayname: "<gold>剑皮肤"
  lore:
    - "<gray>右键可换肤物品来应用此皮肤"
  Mechanics:
    skin:
      consume: true                          # 使用后消耗皮肤物品
```

## 十四、消耗品 (consumable) 与消耗品药水效果 (consumable_potion_effects)

> 右键使用物品时消耗，并施加药水效果。

```yaml
speed_elixir:
  material: POTION
  displayname: "<aqua>速度灵药"
  lore:
    - "<gray>使用后获得 30 秒加速"
  Mechanics:
    consumable: {}                          # 声明为消耗品
    consumable_potion_effects:
      speed:
        amplifier: 1                        # 速度 II
        duration: 600                       # 30 秒（刻）
        ambient: false
        particles: true
        icon: true
```

| 参数 | 类型 | 默认值 | 有效范围 | 说明 |
|------|------|--------|----------|------|
| `<效果>.amplifier` | 整数 | `0` | `0` ~ `255` | 效果等级 |
| `<效果>.duration` | 整数 | `200` | `1` ~ `72000` | 持续时间（刻） |
| `<效果>.ambient` | 布尔 | `false` | `true/false` | 环境效果 |
| `<效果>.particles` | 布尔 | `true` | `true/false` | 显示粒子 |
| `<效果>.icon` | 布尔 | `true` | `true/false` | 显示图标 |

## 十五、切换灯光 (toggle_light)

> 右键方块切换灯光等级。用于交互式灯具。

| 参数 | 类型 | 默认值 | 有效范围 | 说明 |
|------|------|--------|----------|------|
| `light` | 整数 | `0` | `0` ~ `15` | **必填**。默认灯光等级 |
| `toggle_light` | 整数 | 无 | `0` ~ `15` | 切换后的灯光等级。设置此项启用切换 |

```yaml
modern_lamp:
  material: PAPER
  displayname: "<yellow>现代灯具"
  lore:
    - "<gray>右键切换灯光"
  Mechanics:
    toggle_light:
      light: 5                               # 默认微亮
      toggle_light: 15                       # 切换后全亮
```

## 十六、杂项属性 (misc)

> 物品行为的细微调整。

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `breaks_from_cactus` | 布尔 | `true` | 碰到仙人掌是否损坏 |
| `burns_in_fire` | 布尔 | `true` | 在火中是否烧毁 |
| `burns_in_lava` | 布尔 | `true` | 在岩浆中是否烧毁 |
| `disable_vanilla_interactions` | 布尔 | `false` | 禁用原版交互（如用斧头剥树皮） |
| `can_strip_logs` | 布尔 | `false` | 能否剥树皮 |
| `piglins_ignore_when_equipped` | 布尔 | `false` | 装备后猪灵无视玩家 |
| `compostable` | 布尔 | `false` | 能否放入堆肥桶 |
| `allow_in_vanilla_recipes` | 布尔 | `true` | 能否用于原版合成配方 |

```yaml
special_item:
  material: STICK
  displayname: "<white>特殊物品"
  Mechanics:
    misc:
      burns_in_fire: false                  # 防火
      burns_in_lava: false                   # 防岩浆
      disable_vanilla_interactions: true     # 禁用原版交互
```
