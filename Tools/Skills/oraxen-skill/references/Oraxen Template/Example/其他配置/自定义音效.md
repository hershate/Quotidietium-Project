# 自定义音效 (Sounds) 实战配置手册

> 基于 Oraxen 官方文档与本项目 `sounds.yml` 实际配置。
> 音效让自定义物品、方块和唱片机拥有独特的声音体验。

---

## 速查：核心概念

| 概念 | 说明 |
|------|------|
| **配置文件** | `plugins/Oraxen/sound.yml` |
| **音效文件** | 放在 `plugins/Oraxen/pack/sounds/` 目录，必须是 `.ogg` 格式 |
| **音效 ID** | `sound.yml` 中定义的唯一标识符，引用格式为 `oraxen:<音效ID>` |
| **自动生成** | Oraxen 会自动将 `sound.yml` 中的音效注册到资源包的 `sounds.json` |
| **重载命令** | `/o reload all` 然后 `/o pack send @a` |

---

## 一、sound.yml 基本结构

```yaml
# ============================================================
# 文件: plugins/Oraxen/sound.yml
# ============================================================
settings:
  automatically_generate: true             # 自动生成资源包中的 sounds.json（几乎永远设为 true）

sounds:                                    # 所有音效定义放在这里
  # ... 音效条目 ...
```

## 二、单个自定义音效的完整配置

### 参数速查表

| 参数 | 类型 | 必填 | 默认值 | 有效范围 | 说明 |
|------|------|:--:|--------|----------|------|
| `category` | 字符串 | **是** | -- | 见下方类别表 | 决定此音效受哪个音量滑块控制 |
| `sound` | 字符串 | **是** | -- | `.ogg` 文件路径（相对 `pack/sounds/`） | 音效文件路径，`.ogg` 扩展名可省略 |
| `stream` | 布尔 | 否 | `false` | `true` / `false` | 是否流式播放。长音乐必须设为 `true`；短音效设为 `false` |
| `subtitle` | 字符串 | 否 | -- | 任意文本 | 游戏中启用字幕后显示的文本 |
| `replace` | 布尔 | 否 | `false` | `true` / `false` | 设为 `true` 替换同名原版音效 |
| `jukebox_song` | 映射 | 否 | -- | -- | 唱片机歌曲元数据（仅唱片机音乐需要） |

### 音效类别（category）

| 类别值 | 对应的音量滑块 | 典型用途 |
|--------|--------------|---------|
| `master` | 主音量 | UI 点击、通用音效 |
| `music` | 音乐和唱片机 | 背景音乐 |
| `records` | 音乐和唱片机（别名） | **唱片机歌曲专用** |
| `weather` | 天气 | 雨、雷 |
| `block` | 方块 | 方块破坏/放置/脚步声 |
| `hostile` | 敌对生物 | 怪物吼叫 |
| `neutral` | 中立/友好生物 | 动物叫声 |
| `player` | 玩家 | 受伤、脚步声 |
| `ambient` | 环境 | 洞穴回声、风声 |
| `voice` | 语音/说话 | NPC 对话 |

### 完整示例

```yaml
sounds:
  # ============================================================
  # 示例 1: 短音效 — 方块破坏
  # ============================================================
  crystal_break:
    category: block                         # 受"方块"音量滑块控制
    sound: blocks/crystal/break.ogg         # 文件: pack/sounds/blocks/crystal/break.ogg
    subtitle: "水晶碎裂"                     # 字幕文本

  # ============================================================
  # 示例 2: 流式环境音效
  # ============================================================
  magical_hum:
    category: ambient                       # 环境音效
    sound: ambient/magical_hum.ogg
    stream: true                            # 长音效 → 流式播放（节省内存）
    subtitle: "魔法嗡鸣"

  # ============================================================
  # 示例 3: 带多个变体的脚步声（随机播放）
  # ============================================================
  custom_footstep:
    category: block
    subtitle: "脚步声"
    sounds:                                 # 多个音效变体，每次随机选一个
      - step/wood1
      - step/wood2
      - step/wood3
      - step/wood4
      - step/wood5
      - step/wood6
```

## 三、唱片机歌曲完整配置

> 唱片机歌曲需要两部分配合：`sound.yml` 中的音效定义 + 物品配置中的 `Components.jukebox_playable`。

### 3.1 来自项目实际配置的唱片机示例

```yaml
# ============================================================
# 项目文件: sounds.yml（节选）
# ============================================================
sounds:
  - id: welcome                            # 音效 ID
    category: records                      # 唱片机专用类别
    sound: welcome.ogg                     # 文件: pack/sounds/welcome.ogg
    stream: true                           # 音乐必须流式播放
    subtitle: Welcome Song                 # 字幕
    jukebox_song:                               # 唱片机元数据
      description: <gold>Welcome <yellow>Song</yellow></gold>
      length_in_seconds: 180              # 歌曲时长: 3分钟
      comparator_output: 12               # 红石比较器信号强度 (1-15)

  - id: nugalaetiter_light
    category: records
    sound: onexhs/nugalaetiter_light.ogg   # 子目录: pack/sounds/onexhs/
    stream: true
    subtitle: "ONEXHS - Nugalaetiter - 琐欢行乐 主奏曲 - 畅清"
    jukebox_song:
      description: <green>ONEXHS <blue>- Nugalaetiter - 琐欢行乐 主奏曲 - 畅清</blue></green>
      length_in_seconds: 210              # 3分30秒
      comparator_output: 12

  - id: nugalaetiter_thick
    category: records
    sound: onexhs/nugalaetiter_thick.ogg
    stream: true
    subtitle: "ONEXHS - Nugalaetiter - 琐欢行乐 主奏曲 - 盛辉"
    jukebox_song:
      description: <green>ONEXHS <gold>- Nugalaetiter - 琐欢行乐 主奏曲 - 盛辉</gold></green>
      length_in_seconds: 314              # 5分14秒
      comparator_output: 12
```

### 3.2 对应的音乐唱片物品配置

```yaml
# ============================================================
# 物品配置: 音乐唱片
# ============================================================
welcome_disk:
  displayname: "<gradient:#9055FF:#13E2DA>欢迎唱片</gradient>"
  material: MUSIC_DISC_13                  # 使用原版音乐唱片材质
  ItemFlags:
    - HIDE_ADDITIONAL_TOOLTIP              # 隐藏原版附加提示
  Components:
    jukebox_playable:                      # 1.21+ 唱片机可播放组件
      show_in_tooltip: true                # 在物品提示中显示歌曲信息
      song_key: "oraxen:welcome"           # 引用 sound.yml 中的音效 ID
  Pack:
    generate_model: true
    parent_model: "item/handheld"
    textures:
      - default/welcome_disk.png

# 引用格式: oraxen:<音效ID>
# song_key: "oraxen:welcome" 对应 sound.yml 中 - id: welcome
```

### 唱片机参数速查表

| 参数 | 类型 | 必填 | 默认值 | 有效范围 | 说明 |
|------|------|:--:|--------|----------|------|
| `category` | 字符串 | **是** | -- | `records` | 唱片机歌曲必须用 `records` |
| `stream` | 布尔 | **是** | -- | `true` | 音乐必须流式播放 |
| `jukebox_song.description` | 字符串 | 否 | -- | MiniMessage 格式 | 唱片悬停提示中显示的歌曲标题 |
| `jukebox_song.length_in_seconds` | 整数 | 否 | -- | 秒数 | 歌曲总时长，用于控制停止播放的时间点 |
| `jukebox_song.comparator_output` | 整数 | 否 | `15` | `1` ~ `15` | 播放时红石比较器输出的信号强度 |

## 四、原版音效替换

> 使用 `replace: true` 覆盖 Minecraft 原版音效。来自项目实际配置。

```yaml
# ============================================================
# 项目文件: sounds.yml（节选）
# 替换原版木头/石头音效组
# ============================================================
sounds:
  # 替换原版木头破坏音效
  - id: block.wood.break
    replace: true                           # 关键: replace: true
  - id: block.wood.place
    replace: true
  - id: block.wood.step
    replace: true
  - id: block.wood.fall
    replace: true
  - id: block.wood.hit
    replace: true

  # 替换原版石头音效组
  - id: block.stone.break
    replace: true
  - id: block.stone.place
    replace: true
  - id: block.stone.step
    replace: true
  - id: block.stone.fall
    replace: true
  - id: block.stone.hit
    replace: true

  # 然后提供自定义的 required.* 音效组
  - id: required.wood.hit
    subtitle: subtitles.block.generic.hit
    sounds:                                 # 6 种变体随机播放
      - step/wood1
      - step/wood2
      - step/wood3
      - step/wood4
      - step/wood5
      - step/wood6
  - id: required.wood.place
    subtitle: subtitles.block.generic.place
    sounds:
      - dig/wood1
      - dig/wood2
      - dig/wood3
      - dig/wood4
  - id: required.wood.break
    subtitle: subtitles.block.generic.break
    sounds:
      - dig/wood1
      - dig/wood2
      - dig/wood3
      - dig/wood4
  - id: required.wood.step
    subtitle: subtitles.block.generic.footsteps
    sounds:
      - step/wood1
      - step/wood2
      - step/wood3
      - step/wood4
      - step/wood5
      - step/wood6
  - id: required.wood.fall
    sounds:
      - step/wood1
      - step/wood2
      - step/wood3
      - step/wood4
      - step/wood5
      - step/wood6
```

> **注意：** `block.wood.*` 的 `replace: true` 告诉 Oraxen "不要用默认的木头音效"。`required.wood.*` 是实际提供自定义音效文件。两者配合使用才能完整替换原版音效组。

### 原版音效 ID 参考

| 原版音效组 | 替换需要的 ID |
|-----------|--------------|
| 木头方块 | `block.wood.break`, `block.wood.place`, `block.wood.step`, `block.wood.fall`, `block.wood.hit` |
| 石头方块 | `block.stone.break`, `block.stone.place`, `block.stone.step`, `block.stone.fall`, `block.stone.hit` |
| 羊毛/布料 | `block.wool.break`, `block.wool.place`, `block.wool.step`, `block.wool.fall`, `block.wool.hit` |
| 玻璃 | `block.glass.break`, `block.glass.place`, `block.glass.step`, `block.glass.fall`, `block.glass.hit` |

## 五、在物品机制中引用自定义音效

```yaml
# ============================================================
# 在 custom 机制中播放音效
# ============================================================
magic_wand:
  material: STICK
  displayname: "<gradient:#AA00FF:#FF00AA>魔法杖"
  Mechanics:
    custom:
      on_use:
        event: CLICK:right:all              # 右键点击触发
        actions:
          sound:                             # 播放音效动作
            name: oraxen:magical_hum         # 引用 sound.yml 中的音效 ID
            volume: 1.0                      # 音量: 0.0=静音, 1.0=最大, 可超过 1.0
            pitch: 1.0                       # 音调: 0.5=低八度, 1.0=原音, 2.0=高八度

# ============================================================
# 在 ClickAction 中播放音效（方块/家具）
# ============================================================
actions:
  - "{source=AMBIENT volume=0.5 pitch=1} [sound] minecraft:block.note_block.chime"
  - "[sound] minecraft:entity.player.levelup"
```

### 声音动作参数（物品 Mechanics）

| 参数 | 类型 | 默认值 | 有效范围 | 说明 |
|------|------|--------|----------|------|
| `name` | 字符串 | -- | `oraxen:<音效ID>` | 引用 sound.yml 注册的音效 |
| `volume` | 小数 | `1.0` | `0.0` ~ `+∞` | 音量大小 |
| `pitch` | 小数 | `1.0` | `0.5` ~ `2.0` | 音调高低。0.5=低八度，2.0=高八度 |

### 声音动作参数（ClickAction 方块/家具）

| 参数 | 默认值 | 可选值 | 说明 |
|------|--------|--------|------|
| `source` | `MASTER` | `MASTER`, `MUSIC`, `RECORDS`, `WEATHER`, `BLOCKS`, `HOSTILE`, `NEUTRAL`, `PLAYERS`, `AMBIENT`, `VOICE` | 声音来源分类 |
| `volume` | `1.0` | `0.0` ~ `2.0` | 音量 |
| `pitch` | `1.0` | `0.5` ~ `2.0` | 音调 |

## 六、音效文件格式要求

| 要求 | 说明 |
|------|------|
| **文件格式** | OGG Vorbis (`.ogg`) -- 不接受 MP3/WAV/FLAC |
| **声道** | **单声道（Mono）** 强烈推荐。立体声会自动被转换但浪费文件空间 |
| **采样率** | 推荐 44.1kHz 或 48kHz |
| **比特率（音乐）** | 128-192 kbps |
| **比特率（短音效）** | 64-96 kbps |
| **文件名** | 全小写、无空格、无特殊字符、使用下划线分隔 |

### 使用 FFmpeg 转换音频

```bash
# MP3 → OGG（单声道，128kbps 用于音乐）
ffmpeg -i input.mp3 -ac 1 -b:a 128k output.ogg

# WAV → OGG（单声道，96kbps 用于短音效）
ffmpeg -i input.wav -ac 1 -b:a 96k output.ogg

# 立体声 → 单声道（减小文件体积）
ffmpeg -i input.ogg -ac 1 -b:a 96k output_mono.ogg

# 裁剪前 0.2 秒静音
ffmpeg -i input.wav -ss 0.2 -ac 1 -b:a 96k output.ogg
```

## 七、流式播放选择指南

| 场景 | stream 值 | 原因 |
|------|----------|------|
| 音乐唱片 | `true` | 音乐文件大，流式播放节省内存 |
| 长环境音效（>10秒） | `true` | 避免一次性全部加载 |
| 旁白/对话 | `true` | 可能较长 |
| 短音效（<5秒） | `false`（默认） | 完全加载到内存，响应更快 |
| 方块破坏/放置 | `false` | 需要即时响应 |
| UI 点击 | `false` | 短促，即时播放 |
| 频繁播放的音效 | `false` | 无延迟 |

## 八、常见问题

| 问题 | 解决方案 |
|------|---------|
| 音效不播放 | 检查文件格式（必须是 .ogg OGG Vorbis），检查文件路径是否正确 |
| 声音卡顿 | 降低比特率，尝试 96kbps 或 64kbps |
| 唱片机不播放 | 验证 `song_key` 格式: `"oraxen:<音效ID>"`，确保 `stream: true` |
| 音效没有字幕 | 检查 `subtitle` 字段，确保玩家在设置中启用了字幕 |
| 替换原版音效失败 | 确保 `replace: true`，检查音效 ID 拼写与原版一致 |
| 重载后不生效 | 执行 `/o reload all`，然后 `/o pack send @a` 重新发送资源包 |
| 客户端听不到 | 客户端按 `F3 + T` 重新加载资源包 |
