# 配方 (Recipes) 实战配置手册

> 基于 Oraxen 官方文档与本项目 `recipes/` 目录下的实际配置。
> 配方让玩家通过工作台、熔炉、锻造台等方式合成 Oraxen 自定义物品。

## 一、有序合成（Shaped Recipe）

> 玩家必须在 3x3 工作台中将原料按指定形状摆放才能合成。
> 配置文件：`plugins/Oraxen/recipes/shaped.yml`

### 参数速查表

| 参数 | 类型 | 必填 | 默认值 | 有效范围 | 说明 |
|------|------|:--:|--------|----------|------|
| `result` | 映射 | **是** | -- | -- | 合成结果物品 |
| `result.oraxen_item` | 字符串 | 二选一 | -- | 有效的 Oraxen 物品 ID | Oraxen 物品作为产物 |
| `result.minecraft_item` | 映射 | 二选一 | -- | ItemStack 序列化 | 原版物品作为产物（含 NBT） |
| `result.amount` | 整数 | 否 | `1` | `1` ~ `64` | 产物数量 |
| `shape` | 字符串列表 | **是** | -- | 1-3 行，每行 1-3 字符 | 合成图案，空格 `_` 表示留空 |
| `ingredients` | 映射 | **是** | -- | -- | 字母到原料的映射 |
| `ingredients.<字母>.minecraft_type` | 字符串 | 二选一 | -- | 原版 Material 枚举（大写） | 原版物品作为原料 |
| `ingredients.<字母>.oraxen_item` | 字符串 | 二选一 | -- | 有效的 Oraxen 物品 ID | Oraxen 物品作为原料（项目中实际使用） |
| `ingredients.<字母>.amount` | 整数 | 否 | `1` | `1` ~ `64` | 该原料位的数量需求（项目中不常用） |
| `permission` | 字符串 | 否 | 无 | 权限节点字符串 | 拥有此权限的玩家才能查看和使用此配方 |

> **重要：** 本项目实际配方使用的字段名是 `minecraft_type` 和 `oraxen_item`（不是 `material`）。空格用 `_` 下划线表示。

### 完整配置示例（来自项目 shapeless.yml / shaped.yml）

```yaml
# ============================================================
# 示例 1: 巧克力吧 — 纯原版原料有序合成
# 项目文件: recipes/shaped.yml -> item_chocolate_bar_shaped
# ============================================================
item_chocolate_bar_shaped:                  # 配方 ID（全局唯一）
  result:                                   # 合成产物
    oraxen_item: chocolate_bar              # 产物 Oraxen ID
    amount: 2                               # 一次合成产出 2 个
  ingredients:                              # 原料映射
    A:
      minecraft_type: COCOA_BEANS           # 原版物品使用 minecraft_type
  shape:                                    # 3x3 合成图案（2 行）
    - AA_                                   # 第 1 行: A=可可豆, _=留空
    - AA_                                   # 第 2 行: 同上
    - AA_                                   # 第 3 行: 同上
  # 效果: 6 个可可豆（2x3 排列）→ 2 个巧克力吧


# ============================================================
# 示例 2: 巧克力冰淇淋 — 混合原版 + Oraxen 原料
# 项目文件: recipes/shaped.yml -> item_chocolate_icecream_shaped
# ============================================================
item_chocolate_icecream_shaped:
  result:
    oraxen_item: chocolate_ice_cream
  ingredients:
    C:
      minecraft_type: SUGAR                 # 原版糖
    D:
      minecraft_type: WHEAT                 # 原版小麦
    A:
      oraxen_item: chocolate_bar            # Oraxen 自定义物品！链式配方
    B:
      minecraft_type: COCOA_BEANS           # 原版可可豆
  shape:
    - _A_                                   # 顶部: 巧克力吧
    - BCB                                   # 中层: 可可豆+糖+可可豆
    - _D_                                   # 底部: 小麦
  # 效果: 巧克力吧 + 2 可可豆 + 1 糖 + 1 小麦 → 巧克力冰淇淋


# ============================================================
# 示例 3: 包装巧克力吧 — 用纸包裹巧克力吧
# 项目文件: recipes/shaped.yml -> item_packed_chocolate_bar_shaped
# ============================================================
item_packed_chocolate_bar_shaped:
  result:
    oraxen_item: wrapped_chocolate_bar
  ingredients:
    A:
      minecraft_type: PAPER                 # 纸
    B:
      oraxen_item: chocolate_bar            # 巧克力吧
  shape:
    - ___                                   # 第 1 行: 全空
    - ABA                                   # 第 2 行: 纸+巧克力+纸
    - _A_                                   # 第 3 行: 纸
  # 效果: 3 纸 + 1 巧克力吧 → 包装巧克力吧


# ============================================================
# 示例 4: 玻璃剑 — 最简单的有序合成
# 项目文件: recipes/shaped.yml -> weapon_glass_sword_shaped
# ============================================================
weapon_glass_sword_shaped:
  result:
    oraxen_item: glass_sword
  ingredients:
    B:
      minecraft_type: STICK
    A:
      minecraft_type: GLASS
  shape:
    - _A_                                   # 玻璃
    - _A_                                   # 玻璃
    - _B_                                   # 木棍
  # 效果: 2 玻璃 + 1 木棍 → 玻璃剑


# ============================================================
# 示例 5: 面包变种 — 单原料多产物
# 项目文件: recipes/shaped.yml -> item_toast_shaped
# ============================================================
item_toast_shaped:
  result:
    oraxen_item: toast
    amount: 2                               # 产出 2 个吐司
  ingredients:
    A:
      minecraft_type: BREAD                 # 面包
  shape:
    - AA_
    - AA_
    - AA_
  # 效果: 6 个面包 → 2 个吐司
```

### 形状定义详解

```
# 工作台的 3x3 网格与 shape 的对应关系:

shape:
  - "123"       # 工作台第 1 行（顶部）: 格子 0,0 / 0,1 / 0,2
  - "456"       # 工作台第 2 行（中部）: 格子 1,0 / 1,1 / 1,2
  - "789"       # 工作台第 3 行（底部）: 格子 2,0 / 2,1 / 2,2

# 每个字符含义:
#   字母（A-I）: 需要放入该字母对应的原料
#   _（下划线）: 该格子必须留空（不能放任何物品）
#   空格:       该格子可以放任何物品（Oraxen 中不推荐，用 _ 代替）

# 常见形状:
# 1 行配方（例如 3×1 = 3 格宽）:
#   - "A_A"
#   - "B_B"
#
# 2 行配方（例如剑，2 格宽 2 格高）:
#   - "A"
#   - "A"
#   - "B"
#
# 3 行完整配方（例如胸甲）:
#   - "A_A"
#   - "AAA"
#   - "AAA"
```

## 二、无序合成（Shapeless Recipe）

> 玩家只需将所需原料放入工作台（任意排列）即可合成。
> 配置文件：`plugins/Oraxen/recipes/shapeless.yml`

### 参数速查表

| 参数 | 类型 | 必填 | 默认值 | 有效范围 | 说明 |
|------|------|:--:|--------|----------|------|
| `result.oraxen_item` | 字符串 | 二选一 | -- | 有效的 Oraxen 物品 ID | Oraxen 物品作为产物 |
| `result.amount` | 整数 | 否 | `1` | `1` ~ `64` | 产物数量 |
| `ingredients` | 映射 | **是** | -- | -- | 原料映射（字母: 原料） |
| `ingredients.<字母>.minecraft_type` | 字符串 | 二选一 | -- | 原版 Material 枚举 | 原版物品 |
| `ingredients.<字母>.oraxen_item` | 字符串 | 二选一 | -- | 有效的 Oraxen 物品 ID | Oraxen 物品 |
| `ingredients.<字母>.amount` | 整数 | 否 | `1` | `1` ~ `64` | 该原料位的数量 |

### 完整配置示例

```yaml
# ============================================================
# 示例 1: 生培根 — 单原料无序合成
# 项目文件: recipes/shapeless.yml -> bacon_raw
# ============================================================
bacon_raw:
  result:
    oraxen_item: bacon_raw                 # 产物: 生培根
    amount: 2                              # 一次产出 2 个
  ingredients:
    A:
      amount: 1                            # 需要 1 个猪排
      minecraft_type: PORKCHOP
  # 效果: 1 猪排 → 2 生培根（任意位置放猪排即可）


# ============================================================
# 示例 2: 胡萝卜汁 — 双原料无序合成
# 项目文件: recipes/shapeless.yml -> drink_carrot
# ============================================================
drink_carrot:
  result:
    oraxen_item: carrot_juice
  ingredients:
    A:
      amount: 1
      minecraft_type: GLASS_BOTTLE         # 玻璃瓶
    B:
      amount: 1
      minecraft_type: CARROT               # 胡萝卜
  # 效果: 1 玻璃瓶 + 1 胡萝卜 → 胡萝卜汁


# ============================================================
# 示例 3: 番茄酱 — Oraxen 物品作为原料
# 项目文件: recipes/shapeless.yml -> raw_tomato_sauce_shapeless
# ============================================================
raw_tomato_sauce_shapeless:
  result:
    oraxen_item: tomato_paste
  ingredients:
    A:
      amount: 1
      oraxen_item: tomato                  # Oraxen 自定义番茄
  # 效果: 1 番茄 → 番茄酱
```

## 三、熔炉配方（Furnace Recipe）

> 将原料放入熔炉烧炼获得产物。
> 配置文件：`plugins/Oraxen/recipes/furnace.yml`

### 参数速查表

| 参数 | 类型 | 必填 | 默认值 | 有效范围 | 说明 |
|------|------|:--:|--------|----------|------|
| `result.oraxen_item` | 字符串 | 二选一 | -- | 有效的 Oraxen 物品 ID | 烧炼产物 |
| `result.amount` | 整数 | 否 | `1` | `1` ~ `64` | 产物数量 |
| `input.oraxen_item` | 字符串 | 二选一 | -- | 有效的 Oraxen 物品 ID | 输入原料（Oraxen 物品） |
| `input.minecraft_type` | 字符串 | 二选一 | -- | 原版 Material 枚举 | 输入原料（原版物品） |
| `cookingTime` | 整数 | 否 | `200` | `1` ~ `72000` | 烧炼时间（刻）。`200` = 10秒，`100` = 5秒，`600` = 30秒 |
| `experience` | 整数/小数 | 否 | `0` | `0.0` ~ `1000.0` | 烧炼完成后获得的经验值 |

### 完整配置示例

```yaml
# ============================================================
# 示例 1: 烤培根 — 普通熔炉
# 项目文件: recipes/furnace.yml -> bacon_baked_furnace
# ============================================================
bacon_baked_furnace:
  result:
    oraxen_item: bacon_cooked              # 产物: 熟培根
  input:
    oraxen_item: bacon_raw                 # 原料: 生培根(Oraxen物品)
  cookingTime: 250                         # 12.5 秒（比标准略慢）


# ============================================================
# 示例 2: 煎蛋 — 用原版鸡蛋烧炼
# 项目文件: recipes/campfire.yml -> baked_egg
# ============================================================
baked_egg:
  result:
    oraxen_item: fried_egg                 # 产物: 煎蛋
  input:
    minecraft_type: EGG                    # 原料: 原版鸡蛋
  cookingTime: 200                         # 10 秒（标准速度）
  experience: 5                            # 获得 5 点经验


# ============================================================
# 示例 3: 紫水晶矿石烧炼 — 标准矿石配方
# ============================================================
amethyst:
  result:
    oraxen_item: amethyst                  # 产物: 紫水晶
  input:
    oraxen_item: amethyst_ore              # 原料: 紫水晶矿石
  cookingTime: 200                         # 10 秒（标准矿石烧炼）
  experience: 200                          # 200 点经验（大量经验）
```

### 各熔炉类型的烧炼时间对照

| 熔炉类型 | 配置文件 | 默认 cookingTime | 实际时间 | 适用物品 |
|----------|---------|-----------------|---------|---------|
| `furnace` (普通熔炉) | `furnace.yml` | 200 刻 | 10 秒 | 所有物品 |
| `blast_furnace` (高炉) | `blasting.yml` | 100 刻 | 5 秒 | 仅矿物 |
| `smoker` (烟熏炉) | `smoking.yml` | 100 刻 | 5 秒 | 仅食物 |
| `campfire` (营火) | `campfire.yml` | 600 刻 | 30 秒 | 仅食物 |

> **注意：** 熔炉类型由**配置文件决定**，不是由 `type` 字段决定。高炉配方放在 `blasting.yml`，烟熏炉配方放在 `smoking.yml`，营火配方放在 `campfire.yml`。

## 四、锻造台配方（Smithing Recipe）

> 使用锻造台（1.20+ 模板系统）进行物品升级。
> 配置文件：`plugins/Oraxen/recipes/smithing.yml`

### 参数速查表

| 参数 | 类型 | 必填 | 默认值 | 有效范围 | 说明 |
|------|------|:--:|--------|----------|------|
| `template` | 映射 | **是** | -- | -- | 锻造模板 |
| `template.minecraft_type` | 字符串 | 二选一 | -- | 原版物品 | 模板物品（如 `NETHERITE_UPGRADE_SMITHING_TEMPLATE`） |
| `template.oraxen_item` | 字符串 | 二选一 | -- | 有效的 Oraxen 物品 ID | 自定义模板 |
| `base` | 映射 | **是** | -- | -- | 基础物品（要被升级的物品） |
| `addition` | 映射 | **是** | -- | -- | 添加材料（升级所用的材料） |
| `result` | 映射 | **是** | -- | -- | 锻造结果 |

### 完整配置示例

```yaml
# ============================================================
# 示例 1: 使用原版下界合金升级模板
# ============================================================
ruby_sword_smithing:
  template:
    minecraft_type: NETHERITE_UPGRADE_SMITHING_TEMPLATE
  base:
    minecraft_type: DIAMOND_SWORD         # 钻石剑
  addition:
    oraxen_item: ruby                      # Oraxen 红宝石
  result:
    oraxen_item: ruby_sword                # 产物: 红宝石剑


# ============================================================
# 示例 2: 使用自定义锻造模板
# ============================================================
ancient_upgrade:
  template:
    oraxen_item: ancient_template          # Oraxen 自定义模板
  base:
    oraxen_item: ruby_sword                # 红宝石剑
  addition:
    oraxen_item: ancient_core              # 远古核心
  result:
    oraxen_item: ancient_sword             # 产物: 远古之剑
  permission: "oraxen.recipe.ancient"      # 需要权限
```

## 六、禁用原版/已有配方

> 通过 `recipes/disabled.yml` 禁止特定配方生效。需要**重启服务器**才能应用。

```yaml
# ============================================================
# 文件: plugins/Oraxen/recipes/disabled.yml
# ============================================================
disabled:
  # 禁用原版配方（命名空间: minecraft:）
  - minecraft:diamond_sword               # 禁用原版钻石剑（强制玩家用自定义配方）
  - minecraft:diamond_chestplate
  - minecraft:iron_pickaxe

  # 禁用 Oraxen 自定义配方（命名空间: oraxen:）
  - oraxen:old_recipe                     # 禁用已过时的自定义配方

  # 禁用其他插件的配方
  - itemsadder:some_item                  # 禁用 ItemsAdder 等插件的配方
```

> **查找配方键：** 在游戏中对准工作台按 F3+H 打开高级提示，或使用 `/o recipes show all` 命令查看已加载的配方键。

## 七、引用格式总结表

| 场景 | 字段名 | 格式 | 示例 |
|------|--------|------|------|
| Oraxen 物品作为原料 | `oraxen_item` | `<物品ID>` | `oraxen_item: chocolate_bar` |
| 原版物品作为原料 | `minecraft_type` | 大写 Material 枚举 | `minecraft_type: STICK` |
| Oraxen 物品作为产物 | `oraxen_item` | `<物品ID>` | `oraxen_item: bacon_cooked` |
| 原版物品作为产物（含 NBT） | `minecraft_item` | ItemStack 序列化 | 见 builders_wand 示例 |
| 产物数量 | `amount` | 整数 | `amount: 2` |
| 锻造模板（原版） | `minecraft_type` | 模板 Material | `NETHERITE_UPGRADE_SMITHING_TEMPLATE` |
| 锻造模板（自定义） | `oraxen_item` | `<物品ID>` | `oraxen_item: ancient_template` |

## 八、常见问题

### 配方不生效？

1. 配方文件放在正确的目录下（`recipes/` 子目录）
2. 配方中的物品 ID 拼写与 items/ 目录下的配置完全一致
3. `oraxen_item` 引用的物品已正确配置并加载
4. **配方需要重启服务器**（或执行 `/o reload recipes`，但某些情况仍需要重启）

### 如何查看配方是否加载？

```
/o recipes show all          # 列出所有已加载的配方
/o recipes show <id>         # 查看指定配方的详细信息
```

### 如何调试配方？

1. 在游戏内用 `/o recipe builder SHAPED` 打开配方构建器
2. 手动放入原料和产物来验证配方图案
3. 使用 `/o recipes save <name>` 保存，重启后生效
