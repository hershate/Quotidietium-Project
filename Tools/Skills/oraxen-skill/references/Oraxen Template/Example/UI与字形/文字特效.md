# Oraxen 文字特效 (Text Effects) 实战示例

> 文字特效是基于 GLSL 着色器（Shader）的视觉效果系统，可应用于 Minecraft 中的任何文本。与动画字形不同，文字特效直接在 GPU 上修改现有字符的渲染方式 —— 包括颜色、位置、不透明度、运动轨迹等，而无需为每个效果制作精灵表。
>
> **核心原理：** Oraxen 将特效文本中的每个字符替换为使用专用字体的版本，并用唯一的"触发颜色"标记。着色器在 GPU 端检测触发颜色，应用 GLSL 代码中定义的视觉效果。整个过程对玩家透明 —— 他们只看到最终渲染结果。
>
> **版本要求：** Minecraft 1.21.4+
>
> **配置文件位置：**
> - `plugins/Oraxen/settings.yml` —— 总开关和着色器生成设置
> - `plugins/Oraxen/text_effects.yml` —— 特效定义和 GLSL 代码
>
> **本文件基于项目参考资料：** `参考资料/Oraxen/Oraxen Template/General/文字特效.md`

---

## 一、在 settings.yml 中启用文字特效

在 Oraxen 主配置中开启总开关：

```yaml
# ============================================================
# 文件: plugins/Oraxen/settings.yml
# 在文件中找到或添加 TextEffects 配置段
# ============================================================

TextEffects:
  enabled: true                         # 【必填】所有文字特效的总开关
                                        #         false = 完全禁用（忽略 text_effects.yml）
                                        #         修改后需 /oraxen reload all
  # 自定义特效也可以在此控制（与 text_effects.yml 同名覆盖）
  glow:                               # 自定义的 glow 特效
    enabled: true
  # 临时禁用某个有问题的特效:
  my_bugged_effect:
    enabled: false
```

## 二、text_effects.yml 基础结构

```yaml
# ============================================================
# 文件: plugins/Oraxen/text_effects.yml
# ============================================================

version: 1                              # 【必填】文件格式版本（当前为 1）
                                        #         保留给未来格式更新使用

# ---- 共享 GLSL 代码（所有特效公用）----
shared:                                 # 【可选】所有特效可共用的 GLSL 辅助代码
                                        #         避免在每个特效中重复定义相同的函数
  fragment_prelude: |                   # 【可选】片段着色器前导代码
                                        #         在所有 fragment snippet 之前执行
    // 在此定义可重用的辅助函数
    // 例如: HSV → RGB 颜色转换（彩虹特效需要）
    vec3 hsv2rgb(vec3 c) {
        vec4 K = vec4(1.0, 2.0/3.0, 1.0/3.0, 3.0);
        vec3 p = abs(fract(c.xxx + K.xyz) * 6.0 - K.www);
        return c.z * mix(K.xxx, clamp(p - K.xxx, 0.0, 1.0), c.y);
    }

# ---- 特效定义 ----
effects:                                # 【必填】特效定义区域
  # 在此处添加每个特效的配置
```

## 三、单个特效的完整配置模板

```yaml
# ============================================================
# 特效配置模板 — 展示所有可用字段
# ============================================================

effects:
  example_effect:                       # 【必填】特效名称
                                        #         用于 <effect:example_effect> 标签
                                        #         命名建议: 小写字母 + 下划线，描述视觉效果
    id: 3                               # 【可选】数字特效 ID (范围 0-7)
                                        #         省略时按顺序自动分配
                                        #         系统最多支持 8 个特效（ID 0-7）
                                        #         每个特效的 ID 必须唯一
    enabled: true                       # 【可选】此特效是否启用，默认 true
                                        #         可被 settings.yml 中的同名配置覆盖
    trigger_color: "#FD0300"            # 【可选】触发颜色
                                        #         着色器通过 24 位精确颜色匹配来触发特效
                                        #         默认: #FDxD00（其中 x=id，如 id=3 → #FD3D00）
                                        #         不要在普通文本中使用触发颜色！
    description: "示例文字特效"          # 【可选】描述文字
                                        #         在 /oraxen texteffects 命令中显示
                                        #         建议用中文简短描述特效效果
    snippets:                           # 【必填】GLSL 代码片段列表
                                        #         至少需要一个 fragment 或 vertex
      - fragment: |                     # 【可选】片段着色器代码
          // 控制颜色、不透明度等像素级属性
          // 可用的变量: timeSeconds, charIndex, texColor
          texColor.rgb = vec3(1.0, 0.0, 0.0);  // 设置为红色
        vertex: |                       # 【可选】顶点着色器代码
          // 控制位置、运动等顶点级属性
          // 可用的变量: timeSeconds, charIndex, pos
          pos.y += sin(timeSeconds) * 2.0;     // 垂直正弦波运动

      # 可以有多个 snippet，按顺序叠加应用
      # 版本化的 snippet 根据 MC 版本自动选择（见第七节）
```

### 配置项详解

| 配置项 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| `id` | 整数 0-7 | 否 | 自动分配 | 数字 ID，8 个槽位，必须唯一 |
| `enabled` | 布尔 | 否 | `true` | 控制启用状态 |
| `trigger_color` | 十六进制 | 否 | `#FDxD00` | 24 位精确匹配的触发色 |
| `description` | 字符串 | 否 | 无 | `/oraxen texteffects` 显示 |
| `snippets` | 列表 | **是** | — | GLSL 代码片段 |

## 四、GLSL 可用变量

在代码片段中可以访问以下预定义变量：

| 变量 | 类型 | 可用范围 | 说明 |
|------|------|---------|------|
| `timeSeconds` | `float` | fragment / vertex | 游戏内经过的秒数，从世界加载开始计时。用于创建基于时间的动画 |
| `charIndex` | `float` | fragment / vertex | 当前字符在文本中的索引（从 0 开始）。每个字符有唯一索引，可创建"波浪"效果 |
| `pos` | `vec3` | 仅 vertex | 顶点在屏幕空间的位置 (x, y, z)。修改此值可移动字符位置 |
| `texColor` | `vec4` | 仅 fragment | 当前字符的纹理颜色 (r, g, b, a)，分量范围 0.0 ~ 1.0。修改此值可改变颜色和透明度 |

## 五、内置预设特效配置

Oraxen 内置了 4 个预设特效，可以直接使用：

### 5.1 彩虹 (rainbow)

```yaml
effects:
  rainbow:                              # 彩虹循环颜色
    enabled: true
    description: "随时间循环彩虹颜色"
    snippets:
      - fragment: |
          float hue = fract(charIndex * 0.03 + timeSeconds * 0.09);
          texColor.rgb = hsv2rgb(vec3(hue, 0.9, 1.0));

# 工作原理:
#   charIndex * 0.03:  每个字符有轻微的颜色相位差（渐变效果）
#   timeSeconds * 0.09: 颜色随时间缓慢循环（每 ~11 秒完成一个周期）
#   fract():           将值限制在 0.0~1.0 范围（色相循环）
#   hsv2rgb():         将 HSV 转换为 RGB（需要 shared.fragment_prelude 中的定义）
#   saturation 0.9:    高饱和度（颜色鲜艳）
#   value 1.0:          最高亮度
```

### 5.2 波浪 (wave)

```yaml
effects:
  wave:                                 # 垂直正弦波运动
    enabled: true
    description: "垂直正弦波运动"
    snippets:
      - fragment: |
          texColor.rgb = vec3(0.333, 0.804, 0.988);  # 固定为天蓝色
        vertex: |
          float phase = charIndex * 0.6 + timeSeconds * 6.0;
          pos.y += sin(phase) * 2.0;    # 垂直振幅 ±2 像素

# 工作原理:
#   charIndex * 0.6:    相邻字符有 0.6 弧度的相位差（形成波浪形状）
#   timeSeconds * 6.0:  每秒 6 弧度 ≈ 每秒约 1 个完整波周期
#   sin(phase) * 2.0:   正弦波，振幅 2 像素（上下浮动范围）
#   fragment 固定颜色:  波浪特效本身强制一种颜色，覆盖原文本颜色
```

### 5.3 抖动 (shake)

```yaml
effects:
  shake:                                # 随机抖动
    enabled: true
    description: "随机抖动"
    snippets:
      - fragment: |
          texColor.rgb = vec3(1.0, 0.42, 0.42);  # 固定为红色
        vertex: |
          float seed = charIndex + floor(timeSeconds * 32.0);
          pos.x += (fract(sin(seed * 12.9898) * 43758.5453) - 0.5) * 1.5;
          pos.y += (fract(sin(seed * 78.233) * 43758.5453) - 0.5) * 1.5;

# 工作原理:
#   floor(timeSeconds * 32.0):  每 1/32 秒（约 0.031 秒）更新一次种子值
#                               产生"高速抖动"的效果
#   sin(seed * 大质数) * 大质数: 经典的 GLSL 伪随机数生成法
#   fract(...) - 0.5:          将随机数映射到 [-0.5, 0.5] 范围
#   * 1.5:                      缩放偏移范围（±0.75 像素的随机位移）
#   分别处理 x 和 y:            用不同质数产生独立随机数（避免对角线抖动）
```

### 5.4 脉冲 (pulse)

```yaml
effects:
  pulse:                                # 不透明度淡入淡出
    enabled: true
    description: "不透明度淡入淡出"
    snippets:
      - fragment: |
          texColor.rgb = vec3(1.0, 0.85, 0.24);  # 固定为金色
          float pulse = (sin(timeSeconds * 1.5 + charIndex * 0.3) + 1.0) * 0.5;
          texColor.a *= 0.3 + pulse * 0.7;

# 工作原理:
#   timeSeconds * 1.5:        主脉冲频率（每 ~4.2 秒一个周期）
#   charIndex * 0.3:          每个字符有轻微相位差（产生"游走光晕"效果）
#   (sin(...) + 1.0) * 0.5:   将正弦波映射到 [0.0, 1.0] 范围
#   0.3 + pulse * 0.7:        将 pulse 映射到 [0.3, 1.0] 范围
#                              最低透明度 30%，最高 100%（不会完全消失）
```

## 六、自定义 GLSL 特效示例

### 6.1 发光特效 (glow)

```yaml
effects:
  glow:                                 # 发光亮度脉冲
    enabled: true
    description: "发光亮度脉冲 — 文字周期性变亮变暗"
    snippets:
      - fragment: |
          // 计算当前发光相位
          float glow = (sin(timeSeconds * 3.0) + 1.0) * 0.5;
          // 亮度范围: 0.7 ~ 1.3 (70% ~ 130%)
          float brightness = 0.7 + glow * 0.6;
          // 设置颜色为暖金色，乘以亮度系数
          texColor.rgb = vec3(0.9, 0.7, 0.2) * brightness;
```

### 6.2 弹跳特效 (bounce)

```yaml
effects:
  bounce:                               # 字符逐个弹跳
    enabled: true
    description: "字符逐个上下弹跳"
    snippets:
      - vertex: |
          // 每个字符延迟 0.2 秒
          float delay = charIndex * 0.2;
          // 弹跳函数: abs(sin(...)) 产生 0→1→0 的乒乓效果
          float bounce = abs(sin((timeSeconds - delay) * 3.0)) * 3.0;
          pos.y += bounce;              // 垂直位移，最大 3 像素
```

### 6.3 故障特效 (glitch)

```yaml
effects:
  glitch:                               # 赛博朋克风格故障效果
    enabled: true
    description: "随机故障位移和颜色闪烁"
    snippets:
      - fragment: |
          // 5% 概率触发的颜色故障
          float r = fract(sin(timeSeconds * 100.0 + charIndex) * 43758.5);
          if (r > 0.95) {
              texColor.rgb = vec3(1.0, 0.0, 0.0);  // 闪烁红色
          }
        vertex: |
          // 10% 概率触发的水平位移故障
          float glitch = fract(sin(floor(timeSeconds * 20.0) + charIndex) * 43758.5);
          if (glitch > 0.9) {
              pos.x += (fract(sin(charIndex) * 43758.5) - 0.5) * 5.0;
          }
```

### 6.4 颜色闪烁特效 (color_cycle)

```yaml
effects:
  color_cycle:                          # 红蓝之间循环渐变
    enabled: true
    description: "在红色和蓝色之间循环闪烁"
    snippets:
      - fragment: |
          // 计算循环值 (0.0 ~ 1.0)
          float cycle = (sin(timeSeconds * 2.0) + 1.0) * 0.5;
          // 红色通道: 从 1.0 渐变到 0.0
          texColor.r = 1.0 - cycle;
          // 蓝色通道: 从 0.0 渐变到 1.0
          texColor.b = cycle;
          // 绿色通道: 保持关闭（纯红蓝变换）
          texColor.g = 0.0;
```

### 6.5 旋转特效 (spin)

```yaml
effects:
  spin:                                 # 字符围绕中心旋转
    enabled: true
    description: "字符围绕中心旋转"
    snippets:
      - vertex: |
          // 旋转角度 = 时间 + 字符偏移（每个字符角度不同）
          float angle = timeSeconds * 0.5 + charIndex * 0.3;
          // 旋转半径 2.0 像素
          float radius = 2.0;
          // 围绕原始位置 (pos.x, pos.y) 做圆周运动
          pos.x += cos(angle) * radius;
          pos.y += sin(angle) * radius;
```

### 6.6 呼吸缩放 (breath)

```yaml
effects:
  breath:                               # 缓慢的缩放脉冲
    enabled: true
    description: "缓慢的呼吸式缩放 — 文字周期性放大缩小"
    snippets:
      - vertex: |
          // 呼吸系数: 在 0.9 ~ 1.1 之间波动
          float breath = (sin(timeSeconds * 1.5) + 1.0) * 0.1 + 0.9;
          // 缩放所有顶点位置
          pos *= breath;
```

### 6.7 淡入特效 (fade_in)

```yaml
effects:
  fade_in:                              # 字符从左到右逐个淡入
    enabled: true
    description: "字符从透明渐显 — 逐字淡入效果"
    snippets:
      - fragment: |
          // 总淡入时间: 2 秒
          float fadeTime = 2.0;
          // 当前进度 (0.0 ~ 1.0)
          float progress = clamp(timeSeconds / fadeTime, 0.0, 1.0);
          // 每个字符的透明度 = 平滑步进(字符索引/20, 字符索引/20+0.1, 进度)
          // 第 1 个字符在 progress=0 时开始显示
          // 第 20 个字符在 progress=1.0 时才完全显示
          float alpha = smoothstep(charIndex / 20.0, charIndex / 20.0 + 0.1, progress);
          texColor.a *= alpha;
```

### 6.8 纯色替换特效

```yaml
effects:
  green_text:                           # 最简单的纯色替换
    enabled: true
    description: "绿色文本 — 覆盖为纯绿色"
    snippets:
      - fragment: |
          texColor.rgb = vec3(0.0, 1.0, 0.0);  # R=0, G=1, B=0 = 纯绿色

  gold_text:                            # 金色文本
    enabled: true
    description: "金色文本 — 覆盖为金色"
    snippets:
      - fragment: |
          texColor.rgb = vec3(1.0, 0.84, 0.0);  # 经典金色
```

## 七、使用方式：MiniMessage 标签语法

### 8.1 基本用法

```
在支持 MiniMessage 的文本中使用:

# 基本语法
<effect:rainbow>这段文字是彩虹色的！</effect>
<effect:wave>这里是波浪文字</effect>
<effect:shake>抖动文字！</effect>
<effect:pulse>脉冲文字</effect>

# 自定义特效
<effect:glow>发光文字</effect>
<effect:bounce>弹跳文字</effect>
<effect:glitch>故障特效文字</effect>
<effect:color_cycle>颜色闪烁</effect>
<effect:spin>旋转文字</effect>
<effect:breath>呼吸文字</effect>
<effect:fade_in>淡入文字</effect>

# 缩略形式（效果标签需配对）
<effect:rainbow>彩虹文字</effect>
```

```
# 组合: 彩虹 + 粗体
<bold><effect:rainbow>粗体彩虹文字</effect></bold>

# 组合: 波浪 + 渐变
<effect:wave><gradient:#FF0000:#0000FF>渐变波浪</gradient></effect>

# 组合: 脉冲 + 删除线
<strikethrough><effect:pulse>脉冲删除线</effect></strikethrough>

# 组合: 抖动 + 斜体 + 彩虹
<italic><effect:shake><effect:rainbow>斜体抖动彩虹</effect></effect:shake></italic>
```

```yaml
  displayname: "<effect:rainbow>传说之剑</effect>"
```

## 九、特效工作原理（深入理解）

```
文字特效的完整执行流程:

1. MiniMessage 解析阶段（服务端）:
   输入: "<effect:rainbow>Hello</effect>"
   输出: 每个字符被标注为 "rainbow" 特效
   
2. 字体分配阶段（服务端 + 资源包）:
   - 每个字符被设置为使用专用字体: oraxen:effect/0（对应 rainbow 的 id=0）
   - 每个字符被着色为触发颜色: #FD0D00（rainbow 的默认触发色）
   
3. 数据发送阶段（服务端 → 客户端）:
   - 打包后的聊天数据发送给客户端
   - 数据包含: 文本内容 + 字体引用 + 颜色信息
   
4. GPU 渲染阶段（客户端）:
   - Minecraft 的文本渲染着色器检测到触发颜色
   - 应用特效对应的 GLSL 片段/顶点着色器代码
   - GPU 执行你定义的视觉效果（颜色变换、位移等）
   
5. 显示阶段（客户端）:
   - 经过着色器处理后的文本渲染到屏幕上
   - 玩家看到的是最终效果，触发颜色和字体引用对玩家不可见

关键点:
  - 触发颜色使用 24 位精确 RGB 匹配
  - 正常渐变/文本颜色几乎不可能恰好匹配触发色
  - 特效计算在客户端 GPU 上执行，对服务器零性能影响
  - 特效不影响游戏逻辑，纯视觉表现
```

## 十、GLSL 常用函数与模式速查

```glsl
// ============================================================
// 三角函数
// ============================================================
sin(x)                              // 正弦
cos(x)                              // 余弦
tan(x)                              // 正切

// ============================================================
// 数学函数
// ============================================================
abs(x)                              // 绝对值
floor(x)                            // 向下取整: 3.7 → 3.0
ceil(x)                             // 向上取整: 3.2 → 4.0
fract(x)                            // 小数部分: 3.7 → 0.7
mod(x, y)                           // 取模: mod(7, 3) → 1.0
clamp(x, min, max)                  // 限制范围: clamp(1.5, 0, 1) → 1.0
mix(a, b, t)                        // 线性插值: a*(1-t) + b*t
step(edge, x)                       // 阶跃函数: x < edge → 0.0, x >= edge → 1.0
smoothstep(e0, e1, x)               // 平滑步进（缓入缓出）
pow(x, y)                           // 幂函数: x^y
sqrt(x)                             // 平方根

// ============================================================
// 向量函数
// ============================================================
length(v)                           // 向量长度
normalize(v)                        // 单位向量化
dot(a, b)                           // 点积

// ============================================================
// 常用动画模式
// ============================================================

// 平滑振荡 [0.0, 1.0]
float wave = (sin(timeSeconds * speed) + 1.0) * 0.5;

// 锯齿波 [0.0, 1.0] 重复
float saw = fract(timeSeconds * speed);

// 离散帧（类帧动画）
float frame = floor(timeSeconds * fps);

// 伪随机数
float rand = fract(sin(seed * 12.9898) * 43758.5453);

// 乒乓振荡 [0.0, 1.0, 0.0, ...]
float pingpong = abs(mod(timeSeconds, 2.0) - 1.0);

// 每个字符的相位偏移（创造波浪效果）
float phase = charIndex * 0.5 + timeSeconds * 3.0;

// 字符分组（例如每组 3 个字符）
float group = floor(charIndex / 3.0);

// 字符奇偶判断
bool isEven = mod(charIndex, 2.0) < 1.0;

// ============================================================
// 颜色空间转换（需在 shared.fragment_prelude 中定义）
// ============================================================
// HSV → RGB（用于彩虹等基于色相的特效）
vec3 hsv2rgb(vec3 c) {
    vec4 K = vec4(1.0, 2.0/3.0, 1.0/3.0, 3.0);
    vec3 p = abs(fract(c.xxx + K.xyz) * 6.0 - K.www);
    return c.z * mix(K.xxx, clamp(p - K.xxx, 0.0, 1.0), c.y);
}

// RGB → HSV（用于基于颜色的条件判断）
vec3 rgb2hsv(vec3 c) {
    vec4 K = vec4(0.0, -1.0/3.0, 2.0/3.0, -1.0);
    vec4 p = mix(vec4(c.bg, K.wz), vec4(c.gb, K.xy), step(c.b, c.g));
    vec4 q = mix(vec4(p.xyw, c.r), vec4(c.r, p.yzx), step(p.x, c.r));
    float d = q.x - min(q.w, q.y);
    float e = 1.0e-10;
    return vec3(abs(q.z + (q.w - q.y) / (6.0 * d + e)), d / (q.x + e), q.x);
}
```

## 十一、限制与注意事项

| 项目 | 说明 |
|------|------|
| **Minecraft 版本** | 需要 1.21.4 或更高版本 |
| **特效数量上限** | 最多 8 个特效槽位（ID 0-7）。如果需要超过 8 个特效，需要卸载不用的旧特效来释放槽位 |
| **资源包冲突** | 文字特效修改了 `rendertype_text.vsh` / `rendertype_text.fsh`。任何其他同样修改这些文件的资源包会与之冲突 |
| **OptiFine / Sodium / Iris** | 着色器修改可能与这些模组不兼容。在模组环境中充分测试 |
| **文本阴影** | 特效文本的阴影会自动隐藏，以避免着色器修改后的视觉伪影 |
| **触发颜色** | 永远不要在普通文本、消息、物品名、配置文件的其他地方使用触发颜色（如 `#FD0D00`），否则会意外触发特效 |
| **性能影响** | GLSL 代码在客户端 GPU 上执行，对服务器性能零影响。但复杂的 GLSL 代码可能降低客户端 FPS |
| **重载** | 修改 `text_effects.yml` 后需要 `/oraxen reload all` 才能生效（资源包需要重新生成） |
| **颜色精度** | 触发颜色使用 24 位精确匹配。理论上极不可能与正常文本颜色冲突，但不要故意使用接近的值 |

## 十二、故障排除

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| 特效完全不工作 | `settings.yml` 中未启用 | 检查 `TextEffects.enabled: true` |
| 特效不工作 | Minecraft 版本过低 | 需要 1.21.4+ |
| 着色器编译错误（启动时报错） | GLSL 语法错误 | 检查: 缺少分号 `;`、变量未声明、类型不匹配、括号不成对 |
| 文字不可见 | `texColor.a` 被设为 0 | 检查是否设置了不透明度，确保可见颜色 |
| 特效随机触发 | 普通文本使用了触发颜色 | 更换更独特的触发颜色值 |
| 特效 ID 冲突 | 重复 ID | 确保每个特效的 `id` 唯一且 <= 7 |
| 资源包不更新 | 缓存问题 | `/oraxen reload all` 后按 F3+T 刷新资源包 |
| 客户端 FPS 骤降 | GLSL 代码过于复杂 | 简化片段着色器，减少数学运算次数 |
| 修改后不生效 | 未重载 | 执行 `/oraxen reload all` |
| 特效只有颜色变了但没移动 | 只写了 fragment 没写 vertex | 位移/运动效果需要在 vertex snippet 中实现 |
