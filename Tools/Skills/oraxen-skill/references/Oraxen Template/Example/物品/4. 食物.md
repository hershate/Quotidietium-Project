# 食物

> 通用食物示例。
> 涵盖：生食（低营养+负面效果）、熟食（高营养+正面效果）、酒精（概率负面）、饮料（DRINK 动画）。
> 重点展示 Components 系统（Minecraft 1.21.2+）的完整用法。

---

## 版本说明

本文件所有示例使用 **Components 系统**（Minecraft 1.21.2+ 推荐格式）。

在 1.21.2+ 版本中，食物属性被拆分为两个独立组件：
- `Components.food` — 只负责营养值、饱和度、是否满饱腹可吃
- `Components.consumable` — 只负责食用行为：动画、音效、耗时、食用后效果

旧版 `Mechanics.food` 方式见本文末尾对照章节。

## 1. 生食 -- 低营养 + 概率负面效果

> 设计目的：鼓励玩家烹饪。生吃受罪，熟吃得 buff。

### 1.1 生培根 -- 30% 概率食物中毒

```yaml
# =============================================================================
# 生培根 - 经典"吃了可能不舒服"的生肉
# 设计理由：现实中猪肉必须彻底煮熟才能安全食用
# =============================================================================
bacon_raw:
  displayname: 生培根                   # 中文名
  # 英文参考: Raw Bacon
  material: BEEF                        # 用生牛肉作为伪装材质

  Pack:
    generate_model: true
    parent_model: item/generated
    textures:
      - food/bacon_raw.png

  Components:

    # =========================================================================
    # food 组件 - 控制营养值和饱食度
    # =========================================================================
    food:
      # nutrition: 恢复的饥饿值（单位：半鸡腿，即半个图标）
      #   2 = 恢复 1 个完整的鸡腿图标
      #   原版参考：牛排=8, 面包=5, 苹果=4
      #   生食 nutrition 低（1~2）是设计意图：鼓励烹饪
      nutrition: 2

      # saturation: 饱和度修饰符
      #   饱和度比 nutrition 更先消耗——高饱和度的食物更"耐饿"
      #   通常取值范围：nutrition × 0.6 ~ nutrition × 1.6
      #   1.2 = nutrition(2) × 0.6 —— 生肉吸收率低，饿得快
      saturation: 1.2

      # can_always_eat: 饱腹时是否仍能食用
      #   false = 饥饿条满了就不能吃（防止误食浪费）
      #   为什么生食设 false？—— 满血满饱腹时不该冒险吃可能有毒的生肉
      can_always_eat: false

    # =========================================================================
    # consumable 组件 - 控制食用行为和食用后效果
    # =========================================================================
    consumable:
      # consume_seconds: 食用所需时间（单位：秒）
      #   2.5 秒 = 需要按住右键 2.5 秒才能吃完
      #   参考：零食≈1.6s, 正餐≈3~4s, 饮料≈2s
      consume_seconds: 2.5

      # animation: 食用动画类型
      #   EAT   = 吃东西动画（固体食物）
      #   DRINK = 喝东西动画（液体）
      #   BLOCK = 格挡动画（盾牌类）
      #   BOW   = 拉弓动画
      animation: EAT

      # sound: 食用时播放的音效
      #   entity.generic.eat   = 咀嚼声
      #   entity.generic.drink = 喝水声
      sound: entity.generic.eat

      # has_consume_particles: 是否显示食用粒子效果
      has_consume_particles: true

      # =======================================================================
      # on_consume_effects: 食用后触发的效果（可以有多个效果组）
      # 每个效果组独立判定概率
      # =======================================================================
      on_consume_effects:

        # --- 效果组：饥饿（模拟食物中毒）---
        - type: apply_effects            # 应用药水效果类型

          # effects: 要应用的药水效果映射表
          # 格式: minecraft:<效果ID>:
          #          duration: <秒>
          #          amplifier: <等级>
          #          ...
          effects:
            minecraft:hunger:            # 饥饿效果——加速饱食度消耗
              # duration: 效果持续时间（单位：秒）
              #   注意！Components 系统中 duration 的单位是秒
              #   旧版 Mechanics 系统中 duration 的单位也是秒
              #   只有流血机制的 duration 用刻(ticks)
              #   换算：30秒 = 600 ticks (= 30 × 20)
              duration: 30             # 30 秒的饥饿状态

              # amplifier: 效果等级
              #   0 = I 级（基础效果）
              #   1 = II 级
              #   2 = III 级
              #   ...
              #   I 级饥饿：饱食度消耗速度 +1 (原版默认速度的一倍)
              amplifier: 0              # I 级饥饿

              # ambient: 是否为环境来源效果
              #   true = 粒子半透明（更柔和），通常用于信标等环境效果
              #   false = 粒子不透明，通常用于药水等主动效果
              #   对于负面效果，通常设为 false（让玩家清楚看到"中招了"）
              ambient: false

              show_particles: true       # 是否显示药水粒子
              show_icon: true            # 是否在右上角显示效果图标

          # probability: 该效果组的触发概率（0.0 ~ 1.0）
          #   0.3 = 30% 概率触发饥饿
          #   为什么是 30% 而不是 100%？
          #   - 如果 100% 触发，玩家会彻底不敢吃生肉
          #   - 30% 让生食有"赌一把"的趣味性
          #   - 紧急情况（快饿死时），玩家可能冒这个风险
          probability: 0.3
```

### 1.2 生鸡腿 -- 50% 概率食物中毒（更危险）

```yaml
# =============================================================================
# 生鸡腿 - 比生培根更危险的生禽
# 设计理由：参照原版"生鸡肉 30% 食物中毒"的设定
#           鸡腿是大块肉，危险系数更高 → 50% 概率
# =============================================================================
raw_chicken_thigh:
  displayname: 生鸡腿
  # 英文参考: Raw Chicken Thigh
  material: CHICKEN                    # 用生鸡肉材质（与设定一致）
  Pack:
    generate_model: true
    parent_model: item/generated
    textures:
      - food/raw_chicken_thigh.png
  Components:
    food:
      nutrition: 2
      saturation: 1.0                  # 比培根更低——鸡腿更瘦
      can_always_eat: false
    consumable:
      consume_seconds: 2.5
      animation: EAT
      sound: entity.generic.eat
      has_consume_particles: true
      on_consume_effects:
        - type: apply_effects
          effects:
            minecraft:hunger:
              duration: 45             # 45 秒——比培根(30秒)更持久
              amplifier: 0
              ambient: false
              show_particles: true
              show_icon: true
          probability: 0.5             # 50%——比培根(30%)更危险
```

## 2. 熟食 -- 高营养 + 概率正面效果

> 设计目的：让烹饪变得有价值。生食材烹饪后 nutrition 翻倍，还能获得增益。

### 2.1 熟培根 -- 50% 力量效果

```yaml
# =============================================================================
# 熟培根 - 高蛋白熟肉
# nutrition 从 2 → 6（翻了三倍！烹饪的回报）
# 50% 概率获得力量 I（+3 攻击伤害）持续 60 秒
# =============================================================================
bacon_cooked:
  displayname: 熟培根
  # 英文参考: Cooked Bacon
  material: COOKED_BEEF               # 用熟牛排作为伪装
  Pack:
    generate_model: true
    parent_model: item/generated
    textures:
      - food/bacon_cooked.png
  Components:
    food:
      nutrition: 6                     # 接近牛排(8)的水平
      saturation: 7.2                  # nutrition × 1.2 —— 高饱腹
      can_always_eat: true             # 熟食当然随时能吃
    consumable:
      consume_seconds: 2               # 熟食吃得快（好吃）
      animation: EAT
      sound: entity.generic.eat
      has_consume_particles: true
      on_consume_effects:
        - type: apply_effects
          effects:
            # strength: 力量效果 —— 增加近战攻击伤害
            #   I 级: +3 近战伤害 (1.5❤)
            #   II 级: +6 近战伤害 (3❤)
            minecraft:strength:
              duration: 60             # 60 秒——战斗增益的标准时长
              amplifier: 0             # I 级，+3 伤害
              ambient: true            # 环境来源——粒子半透明，视觉效果柔和
              show_particles: true
              show_icon: true
          probability: 0.5             # 50%——能吃到 buff 但不是必定
```

## 3. 酒精类 -- 概率负面效果

> 设计目的：酒精是社交/角色扮演物品，不是高效食物。适度有益，过量有害。

### 3.1 啤酒 -- 40% 反胃 + 20% 虚弱

```yaml
# =============================================================================
# 啤酒 - 经典酒精饮品
# 设计思路：啤酒度数高→反胃概率高(40%)
#           醉酒→四肢无力(虚弱 20%)
#           两个效果独立判定——可能只反胃、只虚弱、两者都有、或都没事
# =============================================================================
beer:
  displayname: 啤酒
  # 英文参考: Beer
  material: HONEY_BOTTLE              # 瓶装物品
  Pack:
    generate_model: true
    parent_model: item/generated
    textures:
      - food/beer.png
  Components:
    food:
      nutrition: 2                     # 酒精几乎没有实际营养
      saturation: 2.0
      can_always_eat: true             # 酒随时能喝（虽然不一定应该喝）
    consumable:
      consume_seconds: 2               # 喝酒较快
      animation: DRINK                 # 液体→喝的动作
      sound: entity.generic.drink
      has_consume_particles: true
      on_consume_effects:

        # --- 效果组 1：反胃（40% 独立概率）---
        - type: apply_effects
          effects:
            # nausea: 反胃 —— 视野摇晃扭曲
            minecraft:nausea:
              duration: 10             # 10 秒——短暂但难受
              amplifier: 0
              ambient: false
              show_particles: true
              show_icon: true
          probability: 0.4             # 40%——啤酒容易上头

        # --- 效果组 2：虚弱（20% 独立概率）---
        # 注意：这是独立的效果组！
        # 玩家可能同时触发反胃+虚弱（40% × 20% = 8% 概率）
        # 也可能只触发一个，或都不触发
        - type: apply_effects
          effects:
            # weakness: 虚弱 —— 减少近战攻击伤害
            #   I 级: -4 近战伤害
            minecraft:weakness:
              duration: 20             # 20 秒四肢无力
              amplifier: 0
              ambient: false
              show_particles: true
              show_icon: true
          probability: 0.2             # 20%——不是每次都会醉
```

## 4. 饮料 -- DRINK 动画 + 正面增益

> 瓶装饮品，全部使用 DRINK 动画和 drink 音效。

### 4.1 胡萝卜汁 -- 100% 夜视

```yaml
# =============================================================================
# 胡萝卜汁 - 致敬原版"金胡萝卜→夜视药水"的设定
# 100% 获得夜视——比吃金胡萝卜更方便
# =============================================================================
carrot_juice:
  displayname: 胡萝卜汁
  # 英文参考: Carrot Juice
  material: HONEY_BOTTLE
  Pack:
    generate_model: true
    parent_model: item/generated
    textures:
      - food/carrot_juice.png
  Components:
    food:
      nutrition: 4                     # 液体，营养适中
      saturation: 4.8                  # nutrition × 1.2
      can_always_eat: true
    consumable:
      consume_seconds: 2
      animation: DRINK                 # 液体必须用 DRINK
      sound: entity.generic.drink
      has_consume_particles: true
      on_consume_effects:
        - type: apply_effects
          effects:
            # night_vision: 夜视 —— 亮度提升，看清黑暗区域
            minecraft:night_vision:
              duration: 30             # 30 秒——适合短途探矿
              amplifier: 0
              ambient: true            # 环境来源——粒子柔和不刺眼
              show_particles: true
              show_icon: true
          probability: 1.0             # 100%——胡萝卜汁必然获得夜视
```

### 4.2 香蕉奶昔 -- 多效果叠加

```yaml
# =============================================================================
# 香蕉奶昔 - 两种正面效果
# 设计理由：香蕉提供钾（速度）+ 奶提供蛋白质（恢复）
# 两个效果在同一个 apply_effects 组内——共享 100% 概率，同时触发
# =============================================================================
banana_shake:
  displayname: 香蕉奶昔
  # 英文参考: Banana Shake
  material: HONEY_BOTTLE
  Pack:
    generate_model: true
    parent_model: item/generated
    textures:
      - food/banana_shake.png
  Components:
    food:
      nutrition: 6                     # 奶昔营养最高
      saturation: 5.4
      can_always_eat: true
    consumable:
      consume_seconds: 2.5             # 奶昔稠——喝得慢
      animation: DRINK
      sound: entity.generic.drink
      has_consume_particles: true
      on_consume_effects:
        - type: apply_effects
          effects:
            # 两个效果在同一个组内，共享 probability: 1.0
            # 意味着速度+恢复必定同时触发
            minecraft:speed:           # 速度——移动速度提升
              duration: 30             # 30 秒奔跑加速
              amplifier: 0             # I 级，+20% 移速
              ambient: true
              show_particles: true
              show_icon: true
            minecraft:regeneration:    # 生命恢复——缓慢回血
              duration: 5              # 5 秒
              amplifier: 0             # I 级，每 2.5 秒恢复 1❤
              ambient: true
              show_particles: true
              show_icon: true
          probability: 1.0
```

## 5. 效果持续时间换算参考

`Components.consumable.on_consume_effects` 中的 **duration 单位是秒**。

| 秒 | 刻 (ticks) | 适用场景 |
|---:|:---:|------|
| 5 | 100 | 瞬时效果（反胃、恢复等短效） |
| 10 | 200 | 短效效果 |
| 20 | 400 | 短期增益 |
| 30 | 600 | 标准增益 |
| 45 | 900 | 中期增益（战斗全程） |
| 60 | 1200 | 长期增益（下矿、探索） |
| 120 | 2400 | 超长增益 |

## 6. 旧版 Mechanics.food 对照（仅供参考）

如果你需要兼容 Minecraft 1.20.4 及更早版本，使用旧版 Mechanics 方式：

```yaml
# =============================================================================
# 旧版 Mechanics.food 方式（Minecraft 1.20.4 及更早版本）
# 仅供参考，新项目不要使用
# =============================================================================
# legacy_bread:
#   displayname: "<#FFAA00>旧版面包"
#   material: BREAD
#   Pack:
#     generate_model: true
#     parent_model: "item/generated"
#     textures:
#       - legacy_bread.png
#   Mechanics:
#     food:
#       hunger: 10                    # 恢复的饥饿值（旧版字段名）
#       saturation: 10                # 饱和度（旧版字段名）
#       effect_probability: 0.35      # 效果触发概率（全局，不可分组）
#       effects:                      # 药水效果
#         speed:
#           amplifier: 1
#           duration: 20              # 注意！这里 duration 也是秒
#           is_ambient: true
#           has_particles: true
#           has_icon: true
```

### 新旧版主要差异

| 特性 | 新版 Components | 旧版 Mechanics |
|------|----------------|---------------|
| nutrition 字段 | `food.nutrition` | `food.hunger` |
| 食用时间 | `consumable.consume_seconds` | `food.eat_seconds` (旧版Components) |
| 效果概率 | 每个效果组独立 `probability` | 全局 `effect_probability` |
| 多效果 | 多个 `apply_effects` 组，独立概率 | 所有效果共享同一概率 |
| 动画控制 | `consumable.animation: EAT/DRINK` | 不支持 |
| 返还物品 | `Components.use_remainder` | `Mechanics.food.replacement` |

> **结论：** 如果服务器版本 >= 1.21.2，务必使用 Components 系统。它提供了更细粒度的控制（独立概率、动画选择、多效果类型如 remove_effects/clear_all_effects/teleport_randomly）。
