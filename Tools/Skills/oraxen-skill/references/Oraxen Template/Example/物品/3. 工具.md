# 工具

> 多种工具类型的实战配置对比，涵盖：基岩镐、范围挖掘锤（多种半径）、火焰锤（多机制组合）、修理齿轮、收割镰刀。
> 特别关注：多机制组合、新旧耐久度系统对比、效率机制的灵活运用。

---

## 1. 基岩镐 -- 破坏基岩的工具

> 使用 `bedrockbreak` 机制，允许挖掘通常不可破坏的基岩方块。

```yaml
# =============================================================================
# Bedrock Pickaxe - 基岩镐
# 设计理念：服务器中唯一能破坏基岩的工具——需要大量资源才能制作
# 核心机制：bedrockbreak（基岩破坏）
# 需要前置：ProtocolLib 插件（Oraxen 依赖它拦截基岩破坏事件）
# =============================================================================
bedrock_pickaxe:
  displayname: <gradient:#3685EC:#72C1E4>基岩镐
  # 英文参考: Bedrock Pickaxe
  material: STONE_PICKAXE               # 使用石镐作为伪装基础

  lore:
    - <#6f737d>» <#D5D6D8>可挖掘基岩

  Pack:
    generate_model: false
    model: default/bedrock_pickaxe       # 3D 模型

  Mechanics:
    # --- bedrockbreak 机制 ---
    bedrockbreak:
      # hardness: 破坏动画切换间隔（单位：刻 ticks）
      #   定义你需要持续挖掘多少刻才能破坏基岩
      #   10 = 需要挖掘 10 刻（0.5 秒）才能破坏
      #   数值越大，挖掘所需时间越长
      #   参考：原版黑曜石 ≈ 50 刻（钻石镐），基岩的 hardness 设为 10 相对容易
      #
      #   设计建议：
      #     - 5~10：较快（适合高级工具）
      #     - 15~25：适中
      #     - 30+：非常慢（需要耐心）
      hardness: 10

      # probability: 基岩被破坏后掉落物品的概率（0.0 ~ 1.0）
      #   1.0 = 100% 掉落基岩物品（玩家可以收集基岩）
      #   0.5 = 50% 概率掉落
      #   0.0 = 破坏后不掉落任何物品（适合纯粹需要"打开通道"的场景）
      #
      # 为什么设 1.0？
      #   因为这个镐的用途就是"收集基岩"，破坏了当然应该掉基岩
      #   如果只是需要穿透基岩，可以设 0.0（破坏后无掉落、不增库存）
      probability: 1.0

      # delay（可选，此示例中未使用）
      #   冷却时间（毫秒），控制连续破坏基岩的速度
      #   如果不设置，没有冷却限制

  Components:
    durability: 5000                    # 高耐久——基岩镐制作成本高，应该耐用
```

### 全局配置参考 (mechanics.yml)

基岩破坏还需要在 `plugins/Oraxen/mechanics.yml` 中启用：

```yaml
# mechanics.yml 中的相关配置
bedrockbreak:
  enabled: true                         # 是否启用基岩破坏机制
  disable_on_first_layer: false         # true = 禁止破坏 Y=0 以下的基岩
  durability_cost: 500                  # 每次破坏基岩额外消耗的耐久度（与正常挖掘叠加）
```

## 2. 火焰锤 -- 多机制组合工具

> 一个工具同时拥有 `smelting`（自动熔炼）和 `bigmining`（范围挖掘）。演示如何组合多种机制。

```yaml
# =============================================================================
# Fire Hammer - 火焰锤
# 设计理念：挖掘矿石时自动熔炼 + 一次挖多个方块
# 核心机制：smelting（熔炼）+ bigmining（范围挖掘）
# 两个机制同时生效，互不干扰
# =============================================================================
fire_hammer:
  displayname: <gradient:#F06966:#FAD6A6>火焰锤
  # 英文参考: Fire Hammer
  material: DIAMOND_PICKAXE             # 用镐作为基础材质（继承"可挖掘"行为）

  lore:
    - <#6f737d>» <#D5D6D8>3x3 范围挖掘
    - <#6f737d>» <#D5D6D8>自动熔炼矿石

  Pack:
    generate_model: true
    parent_model: item/handheld
    textures:
      - default/fire_hammer.png

  Mechanics:
    # --- smelting 机制（自动熔炼）---
    # 被动触发：挖掉矿石方块时，掉落物自动替换为熔炼后的成品
    # 例如：铁矿石 → 铁锭，金矿石 → 金锭，远古残骸 → 下界合金碎片
    # 支持时运(Fortune)附魔——时运会增加熔炼产物的掉落数量
    # 支持精准采集(Silk Touch)——如果有时运/精准采集，优先遵循附魔规则
    smelting:
      enabled: true                     # 启用熔炼
      play_sound: true                  # 熔炼时播放火焰音效（增强沉浸感）

    # --- bigmining 机制（范围挖掘）---
    # 被动触发：破坏方块时，同时破坏周围一定范围的同类方块
    # 只影响"能被该工具正常挖掘"的方块
    bigmining:
      radius: 1                         # 水平半径 = 1 → 3×3 区域
      depth: 1                          # 垂直深度 = 1 → 仅当前层

  Components:
    durability: 4683                    # 约为钻石镐的 3 倍（范围挖掘加速磨损）
```

## 3. 范围挖掘锤 -- radius 与 depth 参数详解

> 四种不同尺寸的锤子对比：从 3x3 到 5x5x2。

### 3.1 翡翠锤 -- 3x3（半径1，深度1）

```yaml
# =============================================================================
# 3×3 挖掘区域示意:
#   [ ] [ ] [ ]
#   [ ] [X] [ ]    X = 挖掘点
#   [ ] [ ] [ ]
# 总共破坏 9 个方块（含中心）
# =============================================================================
emerald_hammer:
  displayname: <gradient:#89E59D:#37C6BA>翡翠锤
  # 英文参考: Emerald Hammer
  material: DIAMOND_PICKAXE
  lore:
    - <#6f737d>» <#D5D6D8>3x3 范围挖掘
  Pack:
    generate_model: true
    parent_model: item/handheld
    textures:
      - default/emerald_hammer.png
  Mechanics:
    bigmining:
      radius: 1                         # 水平半径 1 = 3×3
      depth: 1                          # 垂直深度 1 = 仅一层
  # 注意：此锤未设置 Components.durability
  # 它将使用 DIAMOND_PICKAXE 的默认耐久 1561
```

### 3.2 紫水晶锤 -- 3x3x2（半径1，深度2）

```yaml
# =============================================================================
# 3×3×2 挖掘区域示意:
#   第一层：     第二层：
#   [ ] [ ] [ ]  [ ] [ ] [ ]
#   [ ] [X] [ ]  [ ] [ ] [ ]
#   [ ] [ ] [ ]  [ ] [ ] [ ]
# 总共破坏 18 个方块（两层各 9 个）
# =============================================================================
amethyst_hammer:
  displayname: <gradient:#4B36B1:#6699FF>紫水晶锤
  # 英文参考: Amethyst Hammer
  material: DIAMOND_PICKAXE
  lore:
    - <#6f737d>» <#D5D6D8>3x3x2 范围挖掘
  Pack:
    generate_model: true
    parent_model: item/handheld
    textures:
      - default/amethyst_hammer.png
  Mechanics:

```

### 3.3 缟玛瑙锤 -- 3x3x2 + 自定义耐久

```yaml
# =============================================================================
# 与紫水晶锤相同范围，但显式设置了耐久度

    textures:
      - default/onyx_hammer.png

```

### 3.4 欧拉克斯锤 -- 5x5x2（半径2，深度2）

```yaml
# =============================================================================
# 5×5×2 挖掘区域示意:
#   第一层：           第二层：
#   [ ] [ ] [ ] [ ] [ ]  [ ] [ ] [ ] [ ] [ ]
#   [ ] [ ] [ ] [ ] [ ]  [ ] [ ] [ ] [ ] [ ]
#   [ ] [ ] [X] [ ] [ ]  [ ] [ ] [ ] [ ] [ ]
#   [ ] [ ] [ ] [ ] [ ]  [ ] [ ] [ ] [ ] [ ]
#   [ ] [ ] [ ] [ ] [ ]  [ ] [ ] [ ] [ ] [ ]
# 总共破坏 50 个方块（两层各 25 个）
# =============================================================================
orax_hammer:
  displayname: <gradient:#3685EC:#72C1E4>欧拉克斯锤
  # 英文参考: Orax Hammer
  material: DIAMOND_PICKAXE
  lore:
    - <#6f737d>» <#D5D6D8>5x5x2 范围挖掘
  Pack:
    generate_model: true
    parent_model: item/handheld
    textures:
      - default/orax_hammer.png
  Mechanics:
    bigmining:
      radius: 2                         # 水平半径 2 = 5×5
      depth: 2                          # 垂直 2 层
  Components:
    durability: 4683                    # 约三倍钻石镐——大面积挖掘磨损更快
```

### radius 和 depth 换算表

| radius | 水平范围 | depth | 垂直范围 | 总方块数(单层) | 总方块数 |
|--------|---------|-------|---------|:---:|:---:|
| 1 | 3×3 | 1 | 1层 | 9 | 9 |
| 1 | 3×3 | 2 | 2层 | 9 | 18 |
| 2 | 5×5 | 1 | 1层 | 25 | 25 |
| 2 | 5×5 | 2 | 2层 | 25 | 50 |
| 3 | 7×7 | 3 | 3层 | 49 | 147 |

> **耐久度建议：** 范围越大，挖掘速度越快，但也意味着耐久消耗越快（每次破坏 N 个方块）。建议大范围锤的耐久度至少是同等材质镐的 2~4 倍。

## 4. 修理齿轮 -- repair 机制

> 可消耗物品，右键另一个已损坏的物品来修复其耐久度。

```yaml
# =============================================================================
# 修理齿轮系列 - 铁/金/钻石三种等级
# 设计理念：消耗齿轮来修复另一个物品的耐久度
# 使用方式：手持齿轮，右键点击需要修复的物品
# 三种等级的修复比例递增
# =============================================================================

# --- 铁齿轮：修复 10% 耐久 ---
# ratio: 0.1 = 修复目标物品最大耐久度的 10%
# 例：修复一个最大耐久 1561 的钻石镐
#      修复量 = 1561 × 0.1 = 156 点耐久
#      修复后耐久 = 当前耐久 + 156
# 适合：基础修理，制作便宜但效果有限
iron_cog:
  displayname: <#D5D6D8>铁齿轮
  # 英文参考: Iron Cog
  material: PAPER                      # PAPER: 不是手持工具，不需要工具属性
  lore:
    - <#6f737d>» <#D5D6D8>右键损坏物品来修复
    - '   <#D5D6D8>10% 最大耐久度'     # 前置空格对齐，视觉美观
  Pack:
    generate_model: true
    parent_model: item/handheld         # 手持时倾斜显示，更有"使用中"的感觉
    textures:
      - default/iron_cog.png
  Mechanics:
    repair:
      # ratio: 修复比例（0.0 ~ 1.0）
      #   0.1 = 修复 10%
      #   0.5 = 修复 50%
      #   1.0 = 修复 100%（完全修复）
      ratio: 0.1

# --- 金齿轮：修复 50% 耐久 ---
gold_cog:
  displayname: <gradient:#F06966:#FAD6A6>金齿轮
  # 英文参考: Gold Cog
  material: PAPER
  lore:
    - <#6f737d>» <#D5D6D8>右键损坏物品来修复
    - '   <#D5D6D8>50% 最大耐久度'
  Pack:
    generate_model: true
    parent_model: item/handheld
    textures:
      - default/gold_cog.png
  Mechanics:
    repair:
      ratio: 0.5

# --- 钻石齿轮：修复 100% 耐久 ---
diamond_cog:
  displayname: <gradient:#3685EC:#72C1E4>钻石齿轮
  # 英文参考: Diamond Cog
  material: PAPER
  lore:
    - <#6f737d>» <#D5D6D8>右键损坏物品来修复
    - '   <#D5D6D8>100% 最大耐久度'
  Pack:
    generate_model: true
    parent_model: item/handheld
    textures:
      - default/diamond_cog.png
  Mechanics:
    repair:
      ratio: 1.0                        # 完全修复——最稀有等级
```

## 5. 收割镰刀 -- harvesting 机制

> 右键农田时自动收割并重新种植作物。

```yaml
# =============================================================================
# Iron Serpe - 铁镰刀
# 设计理念：简化农耕——右键即可收割大片农田
# 核心机制：harvesting（收割）
# =============================================================================
iron_serpe:
  displayname: <#D5D6D8>铁镰刀
  # 英文参考: Iron Serpe
  material: WOODEN_HOE                  # 用锄头作为基础——继承"可锄地"的行为

  Pack:
    generate_model: true
    parent_model: item/handheld
    textures:
      - default/iron_serpe.png

  Mechanics:
    harvesting:
      # cooldown: 冷却时间（单位：毫秒 ms）
      #   10000ms = 10 秒
      #   为什么这么长？因为一次性收割大片农田太强了，
      #   长时间冷却防止玩家滥用（不停右键刷作物）
      #   实际使用中 10 秒通常够用了——收割一次等作物再长大
      cooldown: 10000                    # 10 秒冷却

      # radius: 水平收割半径（单位：方块）
      #   5 = 以玩家为中心，11×11 的正方形区域（实际可能有圆形判定）
      #   值越大收割范围越大，但服务器性能消耗也越大
      radius: 5

      # height: 垂直收割范围（单位：方块，向上）
      #   3 = 包括玩家站立的方块往上 3 层
      #   这允许收割"梯田"式农场——不同高度的作物一次性收割
      height: 3

      lower_item_durability: true          # 收割时是否消耗耐久（可选，默认: true）
```

## 6. 效率机制 -- 灵活的双向用法

```yaml
# =============================================================================
# 效率机制 - 手持物品时获得急迫/挖掘疲劳效果
# 注意：这里的 efficiency 是一个 Oraxen 机制（Mechanics）
# 不要与原版附魔 Efficiency 混淆——虽然效果类似（都加速挖掘）
# =============================================================================

# --- 正向用法：挖掘加速 ---
# amount 为正 → 急迫效果 → 挖掘速度提升
# 每级急迫增加 20% 挖掘速度
turbo_pickaxe:
  displayname: <gradient:#59A7EA:#F1D2FF>涡轮镐
  # 英文参考: Turbo Pickaxe
  material: DIAMOND_PICKAXE
  Mechanics:
    efficiency:
      amount: 3                         # 急迫 III（挖掘速度 +60%）
      # 取值范围：1~5（I~V 级急迫）
      # 参考：
      #   1 = 急迫 I  (+20%)
      #   2 = 急迫 II (+40%)
      #   3 = 急迫 III (+60%)
      #   4 = 急迫 IV (+80%)
      #   5 = 急迫 V  (+100%)

# --- 反向用法：挖掘减速 ---
# amount 为负 → 挖掘疲劳效果 → 挖掘速度降低
# 用于"惩罚工具"或"搞笑物品"
# 负值参考：
#   -1 = 挖掘疲劳 I (速度 -20%)
#   -3 = 挖掘疲劳 III (速度 -60%)
slow_pickaxe:
  displayname: <gradient:#59A7EA:#F1D2FF>龟速镐
  # 英文参考: Slow Pickaxe
  material: DIAMOND_PICKAXE
  Mechanics:
    efficiency:
      amount: -3                        # 挖掘疲劳 III（速度 -60%）
```

## 核心概念深入

### Components.durability vs Mechanics.durability

两种耐久度配置方式的详细对比：

| 特性 | `Components.durability` | `Mechanics.durability` |
|------|------------------------|------------------------|
| 支持版本 | Minecraft 1.20.5+ | 所有版本 |
| 语法 | `durability: 500` 或 `durability: { value: 500 }` | `durability: { value: 500 }` |
| 破坏方块耗耐久控制 | `damage_block_break: true/false` | 不支持（自动消耗） |
| 攻击实体耗耐久控制 | `damage_entity_hit: true/false` | 不支持（自动消耗） |
| 与 tool 组件配合 | 支持（同一 Components 块内） | 不支持 |
| 推荐情况 | **新项目使用此方式** | 旧版本兼容 |

```yaml
# Components 方式的完整写法（1.20.5+）
Components:
  durability:
    value: 500                          # 最大耐久度
    damage_block_break: true            # 破坏方块时消耗 1 点耐久？默认 true
    damage_entity_hit: true             # 攻击实体时消耗 1 点耐久？默认 true

# Mechanics 方式的完整写法（全版本兼容）
Mechanics:
  durability:
    value: 500                          # 最大耐久度
```

> 在同一个物品中，**不要同时使用两种方式**。如果必须在旧版服务器上运行，用 `Mechanics.durability`；新服务器一律用 `Components.durability`。

### 工具材质选择建议

| 材质 | 可挖掘等级 | 默认耐久 | 推荐用于 |
|------|-----------|---------|---------|
| `WOODEN_PICKAXE` | 石头、煤矿 | 59 | 基础锤 |
| `STONE_PICKAXE` | 铁、青金石 | 131 | 基岩镐（项目用法） |
| `IRON_PICKAXE` | 钻石、金、红石 | 250 | 基础镐 |
| `DIAMOND_PICKAXE` | 黑曜石、远古残骸 | 1561 | 高级锤、火焰锤 |
| `NETHERITE_PICKAXE` | 所有方块 | 2031 | 顶级锤 |
| `WOODEN_HOE` | N/A | 59 | 收割镰刀 |
| `PAPER` | N/A | N/A | 修理齿轮（非工具） |

> **注意：** 使用 `DIAMOND_PICKAXE` 作为 material 意味着工具继承了"钻石镐可挖掘黑曜石"的权限。如果你用 `STONE_PICKAXE` 作为基岩镐的基础，玩家**仍然可以破坏基岩**（因为 `bedrockbreak` 机制绕过了原版挖掘限制），但正常挖其他高级方块时会受限。
