# 背包

> 皮革背包 (Leather Backpack) 的完整配置——双机制协同工作：
> `backpack`（存储功能）+ `backpack_cosmetic`（背部装饰显示）。
> 这是 Oraxen 中较复杂的多机制组合案例之一。

---

## 工作原理

背包由两个独立机制组成，各司其职：

```
backpack 机制        →  右键打开存储界面（功能）
backpack_cosmetic 机制 →  玩家背部显示 3D 背包模型（视觉效果）

两者独立但互补：
- backpack 负责"能用"
- backpack_cosmetic 负责"能看"
```

`backpack_cosmetic` 渲染原理：Oraxen 使用**隐形盔甲架**挂在玩家背后，盔甲架手持背包物品，利用数据包实现可见/不可见控制。

---

## 完整配置

```yaml
# =============================================================================
# Leather Backpack - 皮革背包
# 放在物品栏任意位置 → 背部显示背包模型
# 右键背包物品 → 打开 4 行存储界面
# =============================================================================
leather_backpack:
  # --- 显示名称 ---
  # <#8B4513> 棕色——皮革的颜色
  displayname: <#8B4513>皮革背包
  # 英文参考: Leather Backpack

  # --- 基础材质 ---
  # PAPER: 背包不需要任何原版物品行为
  material: PAPER

  # =========================================================================
  # 外观配置 - 使用 3D 模型
  # =========================================================================
  Pack:
    generate_model: false              # 关闭自动生成，使用 Blockbench 3D 模型
    model: default/bag                 # 3D 背包模型文件路径
                                       # 文件: plugins/Oraxen/pack/models/default/bag.json

  # =========================================================================
  # Mechanics - 双重机制
  # =========================================================================
  Mechanics:

    # =========================================================================
    # 机制一: backpack —— 存储功能
    # 右键打开一个便携式容器界面
    # =========================================================================
    backpack:
      # rows: 存储行数
      #   4 = 4 行 × 9 列 = 36 个槽位
      #   可选值: 1~6 行
      #   参考:
      #     1 行 = 9 槽（小型背包）
      #     3 行 = 27 槽（小型箱子大小）
      #     4 行 = 36 槽（本配置——中型背包）
      #     6 行 = 54 槽（大型箱子大小）
      rows: 4

      # title: 容器界面标题
      #   使用 MiniMessage 格式，显示在容器界面上方
      #   与物品名相同的颜色保持一致性
      title: <#8B4513>皮革背包

      # open_sound: 打开背包时播放的音效
      #   格式: 命名空间:路径
      #   minecraft:item.armor.equip_leather = 穿皮革装备的音效
      #   为什么用装备音效而不是箱子音效？
      #   —— 背包装备在"身上"，用装备音效更符合直觉（像穿上/脱下）
      #
      #   其他常用音效:
      #     minecraft:block.chest.open         - 开箱子声
      #     minecraft:block.ender_chest.open   - 开末影箱声
      #     minecraft:block.barrel.open        - 开木桶声
      #     minecraft:item.armor.equip_iron    - 穿铁装声
      open_sound: minecraft:item.armor.equip_leather

      # close_sound: 关闭背包时播放的音效
      #   与 open_sound 保持对称（开和关用同类音效）
      close_sound: minecraft:item.armor.equip_leather

    # =========================================================================
    # 机制二: backpack_cosmetic —— 背部装饰显示
    # 纯视觉：在玩家背部显示 3D 背包模型
    # =========================================================================
    backpack_cosmetic:

      # =======================================================================
      # slot: 触发显示的条件槽位
      #   INVENTORY = 物品在玩家物品栏中任意位置时显示
      #   HAND      = 仅物品在主手时显示
      #   OFFHAND   = 仅物品在副手时显示
      #
      # 为什么选 INVENTORY？
      #   背包应该"放在包里就显示在背上"——
      #   不需要手持，不需要装备在特定槽位
      #   只要背包在身上（物品栏中），背部就有显示
      # =======================================================================
      slot: INVENTORY

      # =======================================================================
      # offset: 模型相对于玩家背部的位置偏移
      # 单位: 方块（1.0 = 1 个方块 = 1 米）
      #
      # 坐标系:
      #   x: 左右偏移（正=左，负=右，从玩家视角）
      #   y: 上下偏移（正=上，负=下）
      #   z: 前后偏移（正=后/远离背部，负=前/穿入身体）
      #
      # 当前值为 0.0, 0.0, 0.0 —— 原点（模型默认位置）
      # 如果背包模型看起来"飘在背后"或"嵌进身体"，调整 z 值：
      #   z: -0.1  = 向身体靠近 0.1 方块（1.6 像素）
      #   z: 0.2   = 远离身体 0.2 方块（3.2 像素）
      # =======================================================================
      offset:
        x: 0.0                          # 不左右偏移
        y: 0.0                          # 不上下偏移
        z: 0.0                          # 不前后偏移

      # =======================================================================
      # scale: 模型缩放比例
      #   1.0 = 原始大小（100%）
      #   0.5 = 一半大小
      #   2.0 = 两倍大小
      #
      # 缩放建议:
      #   - 模型如果太大占满整个背部 → 减小 (0.8~0.9)
      #   - 模型太小看不清 → 增大 (1.1~1.3)
      #   - 一般保持 1.0，在 Blockbench 中调整模型本身的大小
      # =======================================================================
      scale: 1.0

      # =======================================================================
      # view_distance: 可见距离（单位：方块）
      #   48 = 其他玩家在 48 格内可以看到你的背包
      #
      # 取值范围建议:
      #   16 = 近距离（节省性能，适合小型服务器）
      #   32 = 中距离
      #   48 = 远距离（本项目使用值——较大可见范围）
      #   64+ = 极大范围（可能影响性能，不推荐）
      #
      # 注意：值越大，服务器需要发送更多数据包给更多玩家
      # =======================================================================
      view_distance: 48

      # =======================================================================
      # hide_in_spectator: 观察者模式下是否隐藏
      #   true = 观察者模式的玩家看不到背包（推荐）
      #   false = 观察者也能看到
      # =======================================================================
      hide_in_spectator: true

      # =======================================================================
      # small: 是否使用小型盔甲架
      #   true = 使用小型盔甲架（更精准的定位）
      #   false = 使用普通大小盔甲架
      #
      # 为什么设 true？
      #   小型盔甲架碰撞体积更小、定位更精确
      #   它不会意外地阻挡玩家或实体移动
      #   是背包显示的最佳选择
      # =======================================================================
      small: true

      # =======================================================================
      # visible_to_self: 自己是否能看到背上的背包
      #   true = 第一人称也能通过 F5（第三人称视角）看到
      #   false = 只有其他玩家能看到（对自己隐藏）
      #   设为 true 让玩家知道自己背着包（增强沉浸感）
      # =======================================================================
      visible_to_self: true
```

## offset 微调指南

offset 单位是**方块**（1 方块 = 1.0），每个方向微调时建议以 0.05 为步进：

```yaml
# 场景 1: 背包飘在背后太远 → 拉近
offset:
  x: 0.0
  y: 0.0
  z: -0.1       # 向身体靠近 0.1 方块

# 场景 2: 背包嵌进身体 → 推远
offset:
  x: 0.0
  y: 0.0
  z: 0.15       # 远离身体 0.15 方块

# 场景 3: 背包位置太低 → 上移
offset:
  x: 0.0
  y: 0.2        # 向上移动 0.2 方块（约肩膀高度）
  z: 0.0

# 场景 4: 背包偏向一侧
offset:
  x: 0.1        # 向右偏移（从玩家背后看）
  y: 0.0
  z: 0.0
```

## 存储行数选择指南

| rows | 槽位 | 相当于 | 推荐用途 |
|:---:|:---:|------|------|
| 1 | 9 | 1 行热键栏 | 小型腰包、文具袋 |
| 2 | 18 | 小箱子的一半 | 小型背包 |
| 3 | 27 | 小型箱子 | 中型背包 |
| 4 | 36 | *本项目配置* | **标准背包** |
| 5 | 45 | 大型箱子 - 9 | 大型背包 |
| 6 | 54 | 大型箱子 | 超大容量背包 |

> 行数越多，背包越强大。但注意平衡性——如果 6 行背包太容易获得，会削弱末影箱和管理员商店的价值。

## 关键注意事项

1. **背包数据存储**：背包内容存储在该物品的 NBT 数据中。如果物品被销毁（掉进岩浆、仙人掌等），内容物也会丢失。建议配合 `soulbound` 机制（死亡不掉落）使用。

2. **不可堆叠**：如果背包物品可以堆叠（堆到 64 个），那么每个背包是否共享内容？答案是：Oraxen 背包机制默认不支持堆叠——但最好显式设置 `unstackable: true` 以确保安全。

3. **性能考虑**：`backpack_cosmetic` 使用隐身盔甲架，每个背包装备的玩家都会在世界中创建一个。`view_distance` 设太大可能在高人口服务器造成性能压力。

4. **与皮肤系统的配合**：背包可以作为 `skinnable` 物品——不同皮肤显示不同的背包外观（参见"皮肤系统"文档）。
