# 基础材料与宝石

> 最简单的 Oraxen 物品类型。材料类物品没有特殊机制，纯粹作为合成原料存在。
> 这是理解 Oraxen 物品配置体系的**最佳起点**——从这里学会基础语法后再看武器和工具。

---

## 设计思路

**为什么材料不需要 Mechanics？**

材料物品的唯一用途是"被持有、被放入合成台、被展示"。它们不需要右键能力、不需要攻击特效、不需要耐久度。一个纯粹的材料只做三件事：
1. 在物品栏/手中显示一个自定义纹理
2. 在合成配方中被识别
3. 通过 `/o give <id>` 命令获取

因此材料配置 = `displayname` + `material` + `Pack`（模型+纹理），仅此而已。

---

## 完整示例：紫水晶 (Amethyst)

```yaml
# =============================================================================
# 物品 ID（必填）- 所有小写字母、数字和下划线
# 用于命令: /o give amethyst
# 用于配方: oraxen:amethyst
# =============================================================================
amethyst:

  # ===========================================================================
  # 显示名称（必填）- 使用 MiniMessage 格式
  # <gradient:#起始颜色:#结束颜色> - 渐变文字，从紫色渐变到蓝色
  # 这是项目实际配置中使用的格式，与英文名对照方便国际化
  # ===========================================================================
  displayname: <gradient:#4B36B1:#6699FF>紫水晶  # 中文显示名
  # 英文参考: Amethyst

  # ===========================================================================
  # 基础材质（必填）- 选择一个"伪装"用的原版物品
  #
  # 为什么用 PAPER？
  # - PAPER 没有任何默认行为：无攻击伤害、无耐久度、无食物属性、无放置行为
  # - 如果你用 DIAMOND，物品会继承钻石的"闪闪发光"渲染
  # - 如果你用 DIAMOND_SWORD，物品会自动获得攻击属性（需要额外 AttributeModifiers 覆盖）
  # ======================================================================
  # 所以：材料类物品一律用 PAPER。Oraxen 会完全替换其外观和属性。
  # - 正确：PAPER（纯净，无污染）
  # - 避免：DIAMOND_SWORD（会误继承攻击属性）
  # - 避免：STONE（可以被放置为方块）
  # ===========================================================================
  material: PAPER

  # ===========================================================================
  # 外观配置（Pack 部分）- 控制物品的视觉表现
  # ===========================================================================
  Pack:

    # -------------------------------------------------------------------------
    # 自动生成模型（必填）- true 表示让 Oraxen 自动创建模型 JSON 文件
    # 对于 2D 物品（宝石、材料、食物等），一律设为 true
    # 只有使用 Blockbench 制作的 3D 模型时才设为 false
    # -------------------------------------------------------------------------
    generate_model: true

    # -------------------------------------------------------------------------
    # 父模型（generate_model: true 时必填）
    # item/generated = 标准 2D 物品渲染
    #   - 物品在手中平放（像纸片）
    #   - 物品在物品栏中居中显示
    #   - 适用于：材料、宝石、食物、药水、非手持物品
    #
    # 注意与 item/handheld 的区别：
    #   - item/handheld: 物品倾斜握持（像剑/工具），用于武器和工具
    #   - item/generated: 物品平放，用于材料
    # -------------------------------------------------------------------------
    parent_model: item/generated

    # -------------------------------------------------------------------------
    # 纹理路径列表（必填）
    # 纹理文件放在: plugins/Oraxen/pack/textures/default/amethyst.png
    # .png 扩展名可省略，Oraxen 会自动追加
    # 纹理建议尺寸: 16x16 或 32x32 像素（保持 Minecraft 风格统一）
    # -------------------------------------------------------------------------
    textures:
      - default/amethyst.png

  # ===========================================================================
  # injectID（可选，默认 true）
  #
  # 作用：控制 Oraxen 是否在物品内部注入识别标记
  #   - true（默认）: Oraxen 可以识别这个物品，支持 /o give、配方匹配等
  #   - false: Oraxen 不注入 ID，物品变回"普通原版物品"
  #
  # 什么时候设为 false？
  #   几乎永远不需要设为 false。只有一种场景：你希望某个物品"看起来和原版完全一样"
  #   且不希望 Oraxen 接管它（例如：用原版指令检查 NBT 的其他插件需要纯净物品）。
  #
  # 本项目不显式设置 injectID，依赖默认值 true。
  # ===========================================================================
  # injectID: true  # 默认值，通常省略不写
```

## 对比示例：红宝石 (Ruby) -- 渐变名称

```yaml
# =============================================================================
# Ruby - 使用双色渐变
# 是从粉色(#FA7CBB)渐变到红色(#F14658)，模拟红宝石的色泽
# =============================================================================
ruby:
  displayname: <gradient:#FA7CBB:#F14658>红宝石
  # 英文参考: Ruby
  material: PAPER
  Pack:
    generate_model: true
    parent_model: item/generated
    textures:
      - default/ruby.png
```

## 对比示例：缟玛瑙 (Onyx) -- 纯色名称

```yaml
# =============================================================================
# Onyx - 使用纯灰色
# <#6f737d> 是单色标记，适合不需要渐变的物品
# 纯色 vs 渐变的选择：
#   - 普通材料用纯色（干净利落）
#   - 稀有/传说材料用渐变（突出珍贵感）
# =============================================================================
onyx:
  displayname: <#6f737d>缟玛瑙
  # 英文参考: Onyx
  material: PAPER
  Pack:
    generate_model: true
    parent_model: item/generated
    textures:
      - default/onyx.png
```

## 可选增强：添加 Lore 描述

```yaml
# =============================================================================
# 带 Lore 的宝石 - 在物品提示框中添加描述文字
# Lore 使用 MiniMessage 格式，每行一个 <gray> 灰色文字
# 这是可选的，大多数基础材料不需要 lore，
# 只有高级/稀有材料才值得添加描述
# =============================================================================
orax:
  displayname: <gradient:#3685EC:#72C1E4>欧拉克斯宝石
  # 英文参考: Orax
  material: PAPER

  # ---------------------------------------------------------------------------
  # lore（可选）- 物品描述行
  # 每行独立字符串，使用 MiniMessage 颜色格式
  # » 符号是装饰性分隔符（项目中常用的风格）
  # ---------------------------------------------------------------------------
  lore:
    - <#6f737d>» <#D5D6D8>一种稀有的合成材料
    - <#6f737d>» <#D5D6D8>散发着神秘的能量

  Pack:
    generate_model: true
    parent_model: item/generated
    textures:
      - default/orax.png
```

## 关键概念总结

| 概念 | 说明 | 材料物品是否必需 |
|------|------|:---:|
| `displayname` | MiniMessage 格式的显示名称 | 必填 |
| `material` | 原版伪装材质（推荐 PAPER） | 必填 |
| `Pack.generate_model` | true = 自动生成模型 | 必填 |
| `Pack.parent_model` | 模型类型（item/generated） | generate_model=true 时必填 |
| `Pack.textures` | 纹理文件路径列表 | 必填 |
| `lore` | 物品描述行 | 可选 |
| `injectID` | 是否注入识别标记 | 可选（默认 true） |
| `Mechanics` | 物品特殊能力 | 材料不需要 |

## 材质选择快速参考

| 材质 | 默认行为 | 推荐用于 |
|------|---------|---------|
| `PAPER` | 无任何默认属性 | **材料、宝石、护甲、特殊物品** |
| `DIAMOND` | 无特殊行为 | 材料类（不常用，PAPER 更好） |
| `IRON_INGOT` | 无特殊行为 | 金属类材料 |
| `SUGAR` | 无特殊行为 | 粉末类材料 |
| `GUNPOWDER` | 无特殊行为 | 粉末类材料 |
| `DRIED_KELP` | 无特殊行为 | 薄片类材料 |

> **核心原则：材料用 PAPER，工具用对应的 PICKAXE/AXE/SWORD，食物用对应的食物材质。**
>
> PAPER 是"白板"材质——没有攻击伤害、没有耐久度、没有食物属性、不能被放置。这就是为什么它是自定义物品的最佳起点。

## 文件放置参考

```
plugins/Oraxen/
  items/
    amethyst.yml          # 材料物品配置（你写的 YAML）
  pack/
    textures/
      default/
        amethyst.png      # 16x16 或 32x32 的像素纹理
        ruby.png           # PNG 格式，文件名全小写
        onyx.png
        orax.png
```

- 所有纹理文件统一放在 `textures/default/` 下
- 文件名应全小写，使用下划线分隔
- 推荐使用 16x16 像素保持 Minecraft 原版风格
