# 帽子与头部装备

> 涵盖：使用 `equippable` 组件 + `slot: HEAD` 的帽子配置、`armor_effects` 机制（穿戴时给予药水效果）、
> 使用 PAPER 材质 + 3D 模型的帽子、AttributeModifiers 中的 ARMOR 和 ARMOR_TOUGHNESS。
> 基于项目实际使用的 Anubis Head、Crown、Pharaoh Head、Witch Hat、Space Helmet 配置。

---

## 核心概念

帽子 = 可装备在头部的装饰/功能性物品。Oraxen 中配置帽子需要三部分协作：

```
equippable 组件    →  允许物品装备到头部槽位（Minecraft 1.21.2+）
armor_effects 机制 →  装备期间持续给予药水效果
AttributeModifiers →  提供护甲值（ARMOR）和韧性（ARMOR_TOUGHNESS）
```

---

## 1. 基础帽子 -- 纯装饰（无效果）

> 最简单的帽子配置：只有 equippable 组件 + 护甲属性，没有额外效果。

```yaml
# =============================================================================
# Crown - 皇冠
# 纯装饰帽子——戴上好看，提供基础护甲，无特殊效果
# =============================================================================
crown:
  # --- 显示名称 ---
  # 从红色(#F06966)渐变到金色(#FAD6A6) —— 皇冠的金色质感
  displayname: <gradient:#F06966:#FAD6A6>皇冠
  # 英文参考: Crown

  # --- 基础材质 ---
  # PAPER: 帽子不需要继承任何原版头盔属性
  # 使用 PAPER 然后用 AttributeModifiers 完全自定义属性
  material: PAPER

  # =========================================================================
  # AttributeModifiers - 帽子穿戴时的属性加成
  # slot: HEAD 确保只在头盔槽时生效
  # =========================================================================
  AttributeModifiers:

    # --- 护甲值 ---
    # attribute: ARMOR —— 基础护甲值
    #   每点护甲值大约减少 4% 的伤害
    #   3 = 约 12% 减伤
    #   原版参考：皮革头盔=1, 铁头盔=2, 钻石头盔=3
    #   amount: 3 = 与钻石头盔相同的护甲值
    # operation: 0 (ADD_NUMBER) —— 直接加值（而非百分比乘法）
    # slot: HEAD —— 只在头部槽位生效
    - attribute: ARMOR
      amount: 3                         # 3 点护甲（≈ 12% 减伤）
      operation: 0
      slot: HEAD

    # --- 护甲韧性 ---
    # attribute: ARMOR_TOUGHNESS —— 护甲韧性
    #   韧性影响高伤害攻击时的护甲保护效果
    #   高伤害攻击会穿透普通护甲，韧性可以抵抗这种穿透
    #   原版参考：皮革=0, 铁=0, 钻石=2, 下界合金=3
    #   amount: 2 = 与钻石装备相同的韧性
    #   为什么帽子也要有韧性？
    #   —— 如果不设韧性，高伤害攻击（如苦力怕爆炸）会完全忽略这 3 点护甲
    - attribute: ARMOR_TOUGHNESS
      amount: 2                         # 2 点韧性（钻石级）
      operation: 0
      slot: HEAD

  # =========================================================================
  # 外观配置 - 3D 模型
  # =========================================================================
  Pack:
    generate_model: false              # 3D 模型
    model: default/crown               # 皇冠模型路径

  # =========================================================================
  # Components
  # =========================================================================
  Components:

    # --- equippable 组件 ---
    # slot: HEAD —— 允许物品装备到头部槽位
    #
    # 这是 Minecraft 1.21.2+ 的标准方式
    # 之前（1.20.5-1.21.1）的版本中，需要使用 Mechanics.hat 机制
    #
    # 可用的 slot 值：
    #   HEAD   = 头盔槽
    #   CHEST  = 胸甲槽
    #   LEGS   = 护腿槽
    #   FEET   = 靴子槽
    #   BODY   = 马铠/狼铠槽
    equippable:
      slot: HEAD

      # 可选：自定义护甲模型（1.21.2+）
      # model: oraxen:crown

      # 可选：装备声音
      # equip_sound: item.armor.equip_chain

      # 可选：覆盖纹理（如南瓜头模糊效果）
      # camera_overlay: minecraft:pumpkin_blur
```

## 2. Anubis Head -- 带药水效果的帽子

> 使用 `armor_effects` 机制：穿戴期间持续给予玩家药水效果。

```yaml
# =============================================================================
# Anubis Head - 阿努比斯头
# 穿戴时给予夜视效果——适合下矿和探索
# =============================================================================
anubis_head:
  displayname: <gradient:#3948AE:#6699FF>阿努比斯头
  # 英文参考: Anubis Head

  material: PAPER

  # --- Lore 描述：告诉玩家这个帽子的效果 ---
  lore:
    - <#6f737d>» <#D5D6D8>穿戴时获得夜视效果

  # --- 护甲属性 ---
  AttributeModifiers:
    - attribute: ARMOR
      amount: 3                         # 钻石头盔级别的护甲
      operation: 0
      slot: HEAD
    - attribute: ARMOR_TOUGHNESS
      amount: 2                         # 钻石级韧性
      operation: 0
      slot: HEAD

  # --- 3D 模型 ---
  Pack:
    generate_model: false
    model: default/anubis_head          # .json 扩展名可省略

  # --- 1.21.2+ 装备组件 ---
  Components:
    equippable:
      slot: HEAD

  # =========================================================================
  # Mechanics - armor_effects 机制
  #
  # armor_effects: 当物品装备在指定槽位时，持续给予玩家药水效果
  #
  # 特性：
  #   - 玩家穿戴 → 立即获得效果 → 脱掉 → 效果立即消失
  #   - 效果不会在玩家身上留下药水粒子残留（比喝药水干净）
  #   - 多个护甲效果可以叠加（头盔+胸甲+护腿+靴子各有效果）
  # =========================================================================
  Mechanics:
    armor_effects:

      # --- 夜视效果 ---
      # 效果名称格式：小写 snake_case 英文名
      # 注意：这里不用 minecraft: 前缀，直接用效果名
      #
      # amplifier: 效果等级
      #   0 = 夜视 I（原版夜视的标准等级）
      #   1 = 夜视 II（更亮，但通常 I 级就足够）
      #
      # 为什么 amplifier 设为 0？
      #   夜视 I 已经让所有方块亮度达到 15（最亮）
      #   更高的等级不会让画面更亮——所以 I 级就够了
      night_vision:
        amplifier: 0                    # 夜视 I

        # ambient: 是否为环境来源效果
        #   true = 粒子半透明（柔和），效果图标会有青色边框
        #      —— 表示这不是"喝药水"得到的，而是"环境/装备"提供的
        #   推荐帽子效果设为 true —— 它们是装备提供的持续性效果
        #   不是一次性药水，粒子应该低调一些
        ambient: true

        # particles: 是否显示效果粒子
        #   true = 玩家身上飘出药水粒子（让其他人知道你戴了这个帽子）
        #   false = 隐藏粒子（适合想低调的玩家或 PvP 场景）
        particles: true

        # icon: 是否在右上角显示效果图标
        #   true = 显示图标（方便查看剩余时间——但装备效果没有"剩余时间"概念）
        #   false = 隐藏图标
        #   设为 true 让玩家知道这个效果正在生效
        icon: true
```

## 5. equippable 组件 vs 旧版 hat 机制

| 特性 | Components.equippable (1.21.2+) | Mechanics.hat (旧版) |
|------|-------------------------------|---------------------|
| 定义方式 | `Components.equippable.slot: HEAD` | `Mechanics.hat: {}` |
| 装备声音 | 支持自定义 `equip_sound` | 不支持 |
| 覆盖纹理 | 支持 `camera_overlay` | 不支持 |
| 跨槽位 | 支持 HEAD/CHEST/LEGS/FEET/BODY | 仅 HEAD |
| 护甲属性 | 通过 AttributeModifiers 配合 | 通过 AttributeModifiers 配合 |
| 推荐情况 | **新项目必须使用** | 旧版本兼容 |

```yaml
# 旧版 hat 机制对照（仅供参考）
# legacy_hat:

#     generate_model: false
#     model: default/old_hat
#   Mechanics:
#     hat: {}                      # 旧版：空花括号 = 可装备在头部
#     armor_effects:
#       night_vision:
#         amplifier: 0
#         ambient: true
#         particles: true
```

## 6. ARMOR 和 ARMOR_TOUGHNESS 详解

### ARMOR（护甲值）

| amount | 减伤幅度 | 相当于 |
|:---:|:---:|------|
| 1 | ~4% | 皮革头盔 |
| 2 | ~8% | 铁头盔 |
| 3 | ~12% | 钻石头盔 |
| 4 | ~16% | 下界合金头盔 |
| 5 | ~20% | 较强自定义装备 |
| 10 | ~40% | 非常强（Boss掉落） |

### ARMOR_TOUGHNESS（护甲韧性）

韧性保护的是"高伤害攻击下的护甲衰减"。公式：

```
有效护甲 = 护甲值 × (1 - min(20, max(0, 伤害 - 1) / (2 + 韧性 / 4)) / 25)
```

简化理解：
- 受到 5 点伤害时，0 韧性 = 护甲效果打 92% 折扣；2 韧性 = 护甲效果打 94% 折扣
- 受到 20 点伤害时（苦力怕爆炸），0 韧性 = 护甲效果打 68% 折扣；2 韧性 = 护甲效果打 78% 折扣
- **结论：韧性在对抗高伤害时价值更大**

| amount | 效果 |
|:---:|------|
| 0 | 无韧性保护（皮革/铁/金/锁链装备） |
| 2 | 钻石装备级韧性 |
| 3 | 下界合金装备级韧性 |
| 4+ | 自定义高级装备 |

### 为什么帽子也要配 ARMOR_TOUGHNESS？

如果帽子只有 ARMOR 但没有 ARMOR_TOUGHNESS（或值为 0），在高伤害场景中（Boss战、爆炸），这些护甲属性效果会大打折扣。给帽子配 2 点韧性确保它"名副其实"地起到钻石头盔级别的保护。

## 7. 帽子设计 checklist

配置一个新帽子时，按以下清单逐项确认：

- [ ] `displayname` — 名称已设定，使用合适的 MiniMessage 颜色
- [ ] `material: PAPER` — 使用 PAPER 而非原版头盔材质
- [ ] `Pack.model` — 3D 模型文件已导出并放在 `models/` 目录
- [ ] `AttributeModifiers` — 护甲值和韧性已配置，`slot: HEAD` 正确
- [ ] `Components.equippable.slot: HEAD` — 装备组件已设置
- [ ] `Mechanics.armor_effects` — 如有需要，药水效果已配置
- [ ] `lore` — 用 Lore 告知玩家帽子的效果（好的 UX）
- [ ] 音效 — 可选但推荐设置 `equip_sound`
