# 实战示例：座椅与大型家具 (Seat & Large Furniture)

> 本文件基于项目 `Oraxen/items/furniture.yml` 中的 `chair` 和 `coach` 提取，
> 展示座椅配置和大型家具的多屏障系统。

---

## 一、示例1：椅子 (chair) — DISPLAY_ENTITY + seat

从 `furniture.yml` 中的 `chair` 提取。

```yaml
# ============================================================
# 椅子 — DISPLAY_ENTITY + hitbox + seat
# ============================================================
chair:
  # ---- 基础信息 ----
  itemname: <gray>椅子
  material: PAPER

  # ---- 方块机制配置 ----
  Mechanics:
    furniture:
      # [必需场景] 椅子需要 display_transform 控制模型朝向
      # 所以使用 DISPLAY_ENTITY 而非 ITEM_FRAME
      type: DISPLAY_ENTITY

      # ========== 碰撞箱 ==========
      # 椅子的碰撞区域：1格宽 × 2格高
      # 2格高确保玩家坐上去后不会被"挤出"
      hitbox:
        width: 1.0                         # 水平宽度（方块单位）
        height: 2.0                        # 垂直高度（2格，覆盖坐姿玩家）

      # ========== 展示实体属性 ==========
      display_entity_properties:
        # FIXED 变换让模型显示位置与 ITEM_FRAME 一致
        # 这是为了与旧版 ITEM_FRAME 家具兼容
        display_transform: FIXED

      # ========== 屏障 ==========
      # [必需] 座椅功能必须有 barrier！
      # 玩家右键 barrier 方块来坐下
      barrier: true

      # ========== 有限放置 ==========
      limited_placing:
        roof: false                         # 只能放地上
        floor: true
        wall: false

      # ========== 座位配置 ==========
      seat:
        # [必需] 从屏障高度偏移（方块为单位）
        # 0 = 坐在屏障方块表面
        # 正值 = 向上偏移（如 0.5 = 坐半格高）
        # 负值 = 向下偏移（如 -0.3 = 下沉坐姿）
        height: 0                           # 坐在方块表面

        # [可选] 固定旋转角度，不推荐设置
        # 不设置 = 玩家保持坐下前的朝向

      # ========== 掉落物 ==========
      drop:
        silktouch: false
        loots:
          - oraxen_item: chair
            probability: 1.0

  # ---- 资源包/模型 ----
  Pack:
    generate_model: false
    model: default/chair
```

### 座椅工作原理

```
玩家右键 barrier 方块 → Oraxen 生成隐形盔甲架 → 玩家传送到盔甲架位置

座椅需求：
  1. barrier: true（必须有！seat 依赖 barrier）
  2. 玩家右键 barrier → 坐下
  3. 玩家按潜行键(Shift) → 站起

height 参数：
  0   → 坐在屏障方块表面（大多数椅子的选择）
  0.5 → 坐在高出半格的位置（高脚凳）
  -0.3 → 下沉坐姿（沙发、矮凳）

hitbox.height: 2.0 的原因：
  如果高度只有 1.0，玩家坐下后头部会穿透 hitbox
  设置为 2.0 确保完整覆盖坐姿玩家
```

## 二、示例2：长沙发 (coach) — 多个 barriers 列表

从 `furniture.yml` 中的 `coach` 提取。长沙发是一个 1×3 的大型家具，需要 6 个屏障覆盖整个区域。

```yaml
# ============================================================
# 长沙发 — 1×3 大型家具 + 6 个屏障
# ============================================================
coach:
  itemname: <gray>Coach
  material: PAPER
  Mechanics:
    furniture:
      type: DISPLAY_ENTITY

      # ========== 展示实体属性 ==========
      display_entity_properties:
        display_transform: FIXED

      # ========== 屏障（单个主屏障）==========
      barrier: true                         # 原点位置的屏障

      # ========== 有限放置 ==========
      limited_placing:
        roof: false
        floor: true
        wall: false

      # ========== 多个屏障列表 ==========
      # [关键] 注意是复数 barriers（不是 barrier）
      # 为 1×3 的长沙发添加额外碰撞区域
      barriers:
        # ---- 原点（已由 barrier: true 包含，但显式写出更清晰） ----
        - origin                            # {x:0, y:0, z:0} 简写

        # ---- 前方两格（Z 轴正方向） ----
        - z: 1                              # {x:0, y:0, z:1} 简写
        - z: 2                              # {x:0, y:0, z:2}

        # ---- 右侧 ----
        - x: 1                              # {x:1, y:0, z:0} 简写

        # ---- 右前方（对角） ----
        - x: 1                              # 多行格式
          z: 1                              # 等价于 {x:1, y:0, z:1}

        - x: 1
          z: 2                              # {x:1, y:0, z:2}

      drop:
        silktouch: false
        loots:
          - oraxen_item: coach
            probability: 1.0

  Pack:
    generate_model: false
    model: default/coach
```

### 长沙发的 barrier 布局图解

```
俯瞰 (鸟瞰图, X=右, Z=前):

     Z=0    Z=1    Z=2
     ┌───┬───┬───┐
  X=0│ O │ 1 │ 2 │    ← O=origin, 数字=barrier位置
     ├───┼───┼───┤
  X=1│ 3 │ 4 │ 5 │    ← 共6个barrier覆盖1×3区域
     └───┴───┴───┘

  坐标对应:
    origin     = (0,0,0)
    z:1        = (0,0,1)
    z:2        = (0,0,2)
    x:1        = (1,0,0)
    x:1, z:1   = (1,0,1)
    x:1, z:2   = (1,0,2)
```

## 三、barriers 坐标格式详解

```
三种写法，按精度递增：

1. 简写 —— 只指定单轴
   origin        → {x:0, y:0, z:0}
   x: 1          → {x:1, y:0, z:0}
   z: 1          → {x:0, y:0, z:1}
   y: 1          → {x:0, y:1, z:0}（极少用，通常不抬高屏障）

2. 多行格式 —— 指定两个轴
   x: 1          → {x:1, y:0, z:1}
     z: 1

   x: -1         → {x:-1, y:1, z:0}
     y: 1

3. 完整格式 —— 显式指定所有轴
   { x: 1, y: 0, z: 1 }
   { x: -1, y: 1, z: 0 }

坐标规则：
  - X: 东/西（正=东, 负=西）
  - Y: 上/下（正=上, 负=下）
  - Z: 南/北（正=南, 负=北）
  - 所有坐标相对于家具放置位置
```

## 四、display_transform 说明

```yaml
# display_entity_properties 中的 display_transform 控制模型映射方式

display_entity_properties:
  display_transform: FIXED

# 可选值及其效果：
# NONE   = 模型在 BlockBench 中的默认显示方式（推荐新项目使用）
# FIXED  = 模型按物品展示框的方式显示（兼容旧版 ITEM_FRAME 家具）
# HEAD   = 模型按盔甲架头部方式显示

# 本项目中使用 FIXED 的原因：
# 1. 保持与 ITEM_FRAME 类型家具一致的视觉位置
# 2. 迁移自旧版时不需要调整 BlockBench 模型
# 3. chair 和 coach 的模型在 BlockBench 中按 FIXED 预设制作

# 如果是全新项目，推荐使用 NONE：
# display_entity_properties:
#   display_transform: NONE
```

## 五、座椅与大型家具的完整示例

综合展示一个 2×2 的沙发组合（4个座椅 + 8个屏障）：

```yaml
# ============================================================
# 大型转角沙发 — 2×2 区域 + 4 个座椅
# ============================================================
corner_sofa:
  itemname: <gray>转角沙发
  material: PAPER
  Mechanics:
    furniture:
      type: DISPLAY_ENTITY
      display_entity_properties:
        display_transform: FIXED

      # 主屏障
      barrier: true
      limited_placing:
        roof: false
        floor: true
        wall: false

      # 2×2 区域的 4 个屏障
      barriers:
        - origin                            # (0,0,0)
        - z: 1                              # (0,0,1)
        - x: 1                              # (1,0,0)
        - { x: 1, z: 1 }                    # (1,0,1)

      # 座位：每个 barrier 生成一个座位
      # 所以 4 个 barrier = 4 个座位
      seat:
        height: -0.2                        # 沙发略微下沉

      drop:
        silktouch: false
        loots:
          - oraxen_item: corner_sofa
            probability: 1.0

  Pack:
    generate_model: false
    model: default/corner_sofa
```

## 六、座椅高度参考值

```
家具类型          │ seat.height  │ 说明
─────────────────┼─────────────┼──────────────────
标准椅子          │ 0           │ 坐在方块表面
高脚凳            │ 0.3 - 0.5   │ 坐高一些
矮凳/蒲团         │ -0.2 - -0.1 │ 略微下沉
沙发/长沙发       │ -0.3 - -0.2 │ 软座下沉感
王座/高背椅       │ 0.1 - 0.2   │ 略高于表面
地面坐垫/榻榻米   │ -0.5 - -0.4 │ 接近地面
```

## 七、注意事项

1. **座椅必须 barrier**: seat 功能依赖 barrier 方块。没有 barrier 的家具无法坐下。

2. **每个 barrier 一个座位**: barriers 列表中的每个 barrier 都会生成一个座位。

3. **hitbox 不提供座位**: hitbox 是碰撞区域，不能替代 barrier 用于座位。

4. **大型家具的 barrier 数量**: 每个 barrier = 一个方块实体。大型家具（如 2×3）意味着 6 个屏障方块。不要过度使用（单个家具不建议超过 10 个 barrier）。

5. **yaw 不推荐设置**: seat.yaw 可以固定玩家坐下后的朝向，但推荐不设置，让系统保持玩家原有朝向。

6. **display_transform 与模型匹配**: 确保 display_transform 值与 BlockBench 中的 Display 预设一致。不一致会导致模型位置偏移。
