# 实战示例：唱片机 (Jukebox Furniture)

> 本文件基于项目 `Oraxen/items/furniture.yml` 中的 `turntable` 配置提取，
> 展示 Oraxen 家具唱片机的完整配置：双模型切换、Pack.models 内联定义。

---

## 一、核心概念

```
Oraxen 唱片机的工作流程：

  1. 默认状态 → 显示基础 model（如唱片机关闭状态）
  2. 玩家右键 barrier → 放入音乐唱片
  3. 模型切换 → active_model（如唱片机打开状态）
  4. 音乐播放 → volume + pitch 控制
  5. 音乐结束/取出唱片 → 模型恢复为基础 model
```

---

## 二、示例：Turntable 唱片机 (完整从项目提取)

从 `furniture.yml` 中的 `turntable` 提取。

```yaml
# ============================================================
# Turntable — 带双模型切换的唱片机
# ============================================================
turntable:
  # ---- 基础信息 ----
  itemname: <gray>Turntable
  material: PAPER

  # ---- 方块机制配置 ----
  Mechanics:
    furniture:
      # 使用 DISPLAY_ENTITY 因为需要 display_entity_properties 微调
      type: DISPLAY_ENTITY

      # ========== 有限放置 ==========
      limited_placing:
        roof: false
        floor: true                         # 只能放地上
        wall: false

      # ========== 屏障 (唱片机交互需要) ==========
      barrier: true

      # ========== 发光 ==========
      light: 5                              # 唱片机工作时发光

      # ========== 掉落物 ==========
      drop:
        silktouch: false
        loots:
          - oraxen_item: turntable
            probability: 1.0

      # ========== 展示实体属性 ==========
      display_entity_properties:
        # 缩放：把模型缩小到 75%
        scale:
          x: 0.75
          y: 0.75
          z: 0.75

        # [关键] translation 微调位置
        # 单位是方块（0.1 = 1/10 方块）
        # 作用：在不修改 BlockBench 模型的情况下微调放置位置
        translation:
          x: 0.0                            # 左右不偏移
          y: 0.1                            # 向上抬 0.1 格（避免陷入地面）
          z: 0.0                            # 前后不偏移

      # ========== 唱片机配置 ==========
      jukebox:
        # [关键★] active_model 指向 Pack.models 中定义的键名
        # 播放唱片时模型从 turntable_closed 切换到 turntable_opened
        active_model: opened

        # [可选] 播放音量 (默认 1.0)
        # 0.0 = 静音, 1.0 = 正常, >1.0 = 放大（可能失真）
        volume: 1.0

        # [可选] 播放音调 (默认 1.0)
        # 0.5 = 低八度, 1.0 = 正常, 2.0 = 高八度
        pitch: 1.0

        # [可选] 播放权限 (空 = 任何人都能播放)
        # 设为权限节点 = 只允许有该权限的玩家放入唱片
        permission: ""                      # 本项目无限制

  # ---- 资源包/模型配置 ----
  Pack:
    generate_model: false

    # [关键] 基础模型：唱片机关闭状态（不播放时显示）
    model: default/turntable_closed

    # [关键★] Pack.models：内联定义额外的模型变体
    # 键名 "opened" 在上方的 jukebox.active_model 中引用
    # 自动注册路径：oraxen:turntable/opened
    models:
      opened: default/turntable_opened      # 唱片机打开状态模型
```

### 为什么需要两个模型？

```
唱片机有两个视觉状态：
  关闭状态 (turntable_closed)：
    - 没有唱片时显示
    - 唱片播放完毕后恢复此状态
    - 是 Pack.model 指定的默认模型

  打开状态 (turntable_opened)：
    - 有唱片正在播放时显示
    - 通过 jukebox.active_model 指定
    - 在 Pack.models 中定义
    - 可以展示"盖子打开"、"转盘旋转"等视觉效果

为什么不能用一个模型？
  → 唱片机是交互设备，视觉反馈很重要
  → 玩家需要一眼看出唱片机是否在工作
  → 打开/关闭的视觉差异提供清晰的用户反馈
```

## 三、Pack.models 内联模型详解

```yaml
# ============================================================
# Pack.models 的完整说明
# ============================================================
Pack:
  # 基础/默认模型（不播放唱片时显示）
  model: default/turntable_closed
  # 自动注册为: oraxen:turntable

  # 额外模型变体（键值映射）
  models:
    opened: default/turntable_opened
    # 自动注册为: oraxen:turntable/opened

    # 可以定义更多变体（虽然唱片机只用到一个）
    # empty: default/turntable_empty
    # broken: default/turntable_broken

# 自动注册规则：
#   Pack.model           → oraxen:<物品ID>
#   Pack.models.<key>    → oraxen:<物品ID>/<key>

# 以 turntable 为例：
#   配置                                  自动注册路径
#   ───────────────────────────────────  ──────────────────────
#   model: default/turntable_closed      oraxen:turntable
#   models.opened: default/..._opened    oraxen:turntable/opened
```

## 四、jukebox 配置选项详解

```yaml
jukebox:
  # active_model — 播放时切换到的模型
  # 类型: string，可选
  # 引用 Pack.models 中的键名
  # 不设置 = 播放时不切换模型
  active_model: opened

  # volume — 播放音量
  # 类型: float，可选，默认 1.0
  # 0.0 = 静音
  # 1.0 = 正常音量
  # 1.5 = 放大 50%（可能失真）
  volume: 1.0

  # pitch — 播放音调
  # 类型: float，可选，默认 1.0
  # 0.5 = 降低一个八度
  # 1.0 = 原始音调
  # 2.0 = 升高一个八度
  pitch: 1.0

  # permission — 播放权限
  # 类型: string，可选，默认 ""
  # "" (空字符串) = 任何玩家都可以放入唱片
  # "oraxen.jukebox.vip" = 只有有该权限的玩家可以播放
  permission: ""
```

## 五、完整唱片机示例（带权限和音效增强）

```yaml
# ============================================================
# VIP 唱片机 — 权限控制 + 增强音效
# ============================================================
vip_jukebox:
  itemname: <light_purple>VIP 唱片机
  material: PAPER
  Pack:
    generate_model: false
    model: default/vip_jukebox_closed
    models:
      active: default/vip_jukebox_active    # 播放状态模型
  Mechanics:
    furniture:
      type: DISPLAY_ENTITY
      barrier: true
      light: 3                              # 微弱发光

      display_entity_properties:
        scale:
          x: 0.8
          y: 0.8
          z: 0.8
        translation:
          y: 0.05

      jukebox:
        active_model: active                # 引用 Pack.models.active
        volume: 1.2                         # 音量增强 20%
        pitch: 1.0
        permission: "oraxen.jukebox.vip"    # [关键] 只有VIP能播放

      block_sounds:
        place_sound: block.metal.place
        break_sound: block.metal.break
        hit_sound: block.metal.hit

      drop:
        silktouch: false
        loots:
          - oraxen_item: vip_jukebox
            probability: 1.0
```

## 七、display_entity_properties.translation 的微调作用

```yaml
# translation 允许在不重新编辑 BlockBench 模型的情况下微调家具位置

display_entity_properties:
  translation:
    x: 0.0          # 左右偏移（方块为单位，0.1 = 1/10方块）
    y: 0.1          # 上下偏移
    z: 0.0          # 前后偏移

# 本项目 turntable 的 y: 0.1 的原因：
#   - 唱片机模型在 BlockBench 中可能略微偏低
#   - 向上抬 0.1 格 = 1/10 方块 = 大约 1.6 厘米（游戏中）
#   - 这样唱片机不会"陷入"地面，看起来更自然

# 常见微调参考：
#   融入地面的物品（地毯）    → y: -0.1 到 -0.05
#   正常放置的家具            → y: 0.0 到 0.05
#   略微抬起的物品（展示台）  → y: 0.05 到 0.15
#   墙壁装饰                  → 调整 z 偏移
```

## 八、与自定义音乐唱片配合

唱片机需要音乐唱片才能工作。这里是一个配套的自定义唱片物品配置：

```yaml
# ============================================================
# 自定义音乐唱片 — 配合唱片机家具使用
# ============================================================
my_custom_disc:
  itemname: <green>自定义音乐唱片
  material: PAPER
  Pack:
    generate_model: false
    model: item/my_custom_disc
  Mechanics:

      song: "custom:my_song"                # 音乐资源标识

      comparator_signal: 15
```

## 九、常见问题

**Q: 唱片机需要 barrier 吗？**
A: 是的。玩家右键 barrier 方块来放入/取出唱片。没有 barrier 无法交互。也可以用 `hitbox` 替代。

**Q: active_model 切换的是什么？**
A: 切换的是展示实体显示的 Oraxen 模型，不是方块本身。原版的唱片机方块不受影响（本来就没有）。

**Q: 可以在唱片机上同时使用存储功能吗？**
A: 不建议。唱片机的右键交互用于放入/取出唱片，存储功能的右键交互与之冲突。两者只能用其一。

**Q: 播放结束或取出唱片后，模型会自动恢复吗？**
A: 是的。取出唱片或音乐播放完毕后，模型自动恢复为基础 `model`（本例中的 turntable_closed）。

**Q: 为什么要有两个模型而不是用进化阶段？**
A: 唱片机的两个状态是对称的（播放/不播放），进化阶段是线性的（0→1→2→3）。唱片机用 active_model 切换更合适。
