# 1.21.2+ 组件物品模板

> 适用于 Minecraft 1.21.2 及以上版本，使用原版数据驱动组件 (Data Components) 定义物品属性。
> 组件系统替代了旧的 NBT 标签方式，提供更原生的物品自定义体验。

---

## 什么是组件系统？

从 Minecraft 1.20.5 开始，Mojang 引入了数据驱动物品组件系统。Oraxen 通过 `Components` 配置部分完整支持这些原版组件。

**版本要求：**
- **基础组件**（durability, fire_resistant, hide_tooltip）：Minecraft 1.20.5+
- **食物/消耗品组件**（food, consumable）：1.20.5+（1.21.2+ 拆分）；1.20.5-1.21 使用旧版 food 组件
- **装备组件**（equippable）：Minecraft 1.21.2+
- **视觉组件**（item_model, tooltip_style）：Minecraft 1.21.2+
- **音频组件**（jukebox_playable）：Minecraft 1.21+，需要 Paper 服务端
- **通用组件系统**：Minecraft 1.21.3+
- **display 模式**：Minecraft 1.21.6+

## 一、耐久度组件 (durability)

为任意物品设置自定义耐久度。

```yaml
# 自定义耐久度物品
# durable_item:
#   displayname: "<#AAAAFF>耐久物品"
#   material: PAPER
#   Pack:
#     generate_model: true
#     parent_model: "item/generated"
#     textures:
#       - durable_item.png
#   Components:
#     durability:
#       value: 500                             # 最大耐久度
#       damage_block_break: true               # 破坏方块时消耗耐久（可选）
#       damage_entity_hit: true                # 攻击实体时消耗耐久（可选）
```

**简单写法：**
```yaml
#   Components:
#     durability: 100                          # 仅设置最大耐久值
```

## 三、消耗品组件 (consumable)

> 1.21.2+ 版本中的消耗行为控制。

```yaml
# consumable_item:
#   displayname: "<#FF00FF>魔法药剂"
#   material: POTION
#   Pack:
#     generate_model: true
#     parent_model: "item/generated"
#     textures:
#       - magic_potion.png
#   Components:
#     consumable:
#       consume_seconds: 1.6                    # 消耗时间（秒）
#       animation: DRINK                        # 动画: EAT, DRINK, BLOCK, BOW, SPEAR
#                                               #       CROSSBOW, SPYGLASS, TOOT_HORN, BRUSH
#       sound: entity.generic.drink             # 消耗声音
#       has_consume_particles: true             # 是否显示消耗粒子
#       on_consume_effects:                     # 消耗后触发的效果
#         - type: apply_effects                 # 应用药水效果
#           effects:
#             minecraft:speed:
#               duration: 600
#               amplifier: 1
#               ambient: false
#               show_particles: true
#               show_icon: true
#           probability: 1.0
#         - type: remove_effects                # 移除特定效果
#           effects:
#             - minecraft:poison
#             - minecraft:wither
#         - type: clear_all_effects             # 清除所有效果
#         - type: teleport_randomly             # 随机传送
#           diameter: 16
#         - type: play_sound                    # 播放声音
#           sound: entity.enderman.teleport
```

## 四、工具组件 (tool)

定义物品的挖掘行为。

```yaml
# custom_tool:
#   displayname: "<gradient:#FF4488:#FFAA00>超级镐"
#   material: DIAMOND_PICKAXE
#   Pack:
#     generate_model: true
#     parent_model: "item/handheld"
#     textures:
#       - custom_tool.png
#   Components:
#     durability: 2000
#     fire_resistant: true                      # 防火（不会在岩浆中烧毁）
#     tool:
#       damage_per_block: 1                     # 每方块消耗耐久度
#       default_mining_speed: 2.0               # 基础挖掘速度（倍率）
#       rules:
#         - speed: 10.0                        # 对符合条件方块的挖掘速度
#           correct_for_drops: true             # 方块是否正常掉落物品
#           tags:                               # 使用方块标签匹配
#             - minecraft:mineable/pickaxe
#             - minecraft:needs_diamond_tool
#           # 也可使用具体材质:
#           # material: DIAMOND_BLOCK           # 单个材质
#           # materials:                        # 多个材质
#           #   - DIAMOND_BLOCK
#           #   - NETHERITE_BLOCK
#           # tag: minecraft:mineable/pickaxe   # 单个标签
```

## 五、装备组件 (equippable)

> 需要 Minecraft 1.21.2+。使物品可以装备到护甲槽位。

```yaml
# custom_helmet:
#   displayname: "<gradient:#89E59D:#37C6BA>翡翠头盔"
#   material: PAPER
#   Pack:
#     generate_model: true
#     parent_model: "item/generated"
#     textures:
#       - custom_helmet.png
#   Components:
#     durability:
#       value: 437
#       damage_entity_hit: true
#     equippable:
#       slot: HEAD                              # HEAD, CHEST, LEGS, FEET, BODY
#       model: oraxen:custom_armor              # 自定义护甲模型（可选）
#       camera_overlay: minecraft:pumpkin_blur  # 装备时的覆盖纹理（可选）
#       equip_sound: item.armor.equip_chain    # 装备声音（仅 Paper）
#       allowed_entity_types:                   # 可装备的实体（可选，默认全部）
#         - PLAYER
#         - SKELETON
#       dispensable: true                       # 可通过发射器装备
#       swappable: true                         # 可与已装备物品交换
#       damage_on_hurt: true                    # 受伤时消耗耐久
```

## 七、属性修改器 (AttributeModifiers)

> 需要 Minecraft 1.20.5+。现代格式使用命名小节。

```yaml
# attribute_item:
#   displayname: "<#FF4444>力量戒指"
#   material: PAPER
#   Pack:
#     generate_model: true
#     parent_model: "item/generated"
#     textures:
#       - power_ring.png
#   AttributeModifiers:
#     # 每个修饰符是一个命名小节
#     attack_boost:
#       attribute: ATTACK_DAMAGE               # 要修改的属性
#       amount: 5                              # 修饰符数值
#       operation: ADD_NUMBER                  # ADD_NUMBER / ADD_SCALAR / MULTIPLY_SCALAR_1
#       slot: HAND                             # HAND, OFFHAND, HEAD, CHEST, LEGS, FEET, ARMOR, ANY
#     move_speed:
#       attribute: MOVEMENT_SPEED
#       amount: 0.05
#       operation: ADD_NUMBER
#       slot: ANY
```

## 通用组件系统（1.21.3+）

Oraxen 支持通过通用组件系统设置任意 Minecraft 数据组件。对于 Oraxen 未显式处理的组件，可以直接使用原版组件格式。

```yaml
# custom_component_item:
#   displayname: "<#AAFFAA>通用组件物品"
#   material: PAPER
#   Components:
#     # 原版维修组件（repairable）
#     repairable:
#       items:
#         - minecraft:diamond
#     # 自定义模组/数据包组件
#     my_custom_component:
#       some_property: value
#       another_property: 123
```

## 完整示例：带所有组件的高级自定义物品

```yaml
ultimate_item:
  displayname: "<gradient:#FF0000:#FFD700:#00FF00>终极物品"
  material: DIAMOND_SWORD
  lore:
    - "<gray>集成了所有组件系统的示例物品"
  Pack:
    generate_model: true
    parent_model: "item/handheld"
    textures:
      - ultimate_item.png

  Components:
    # 耐久度
    durability:
      value: 5000
      damage_block_break: true
      damage_entity_hit: true
    # 防火
    fire_resistant: true
    # 工具属性
    tool:
      damage_per_block: 1
      default_mining_speed: 3.0
      rules:
        - speed: 12.0
          correct_for_drops: true
          tags:
            - minecraft:mineable/pickaxe
            - minecraft:mineable/axe
        - speed: 15.0
          correct_for_drops: false
          materials:
            - COBBLESTONE

  # 属性修改
  AttributeModifiers:
    damage:
      attribute: ATTACK_DAMAGE
      amount: 12
      operation: ADD_NUMBER
      slot: HAND
    speed:
      attribute: ATTACK_SPEED
      amount: -1.0
      operation: ADD_NUMBER
      slot: HAND
    health:
      attribute: MAX_HEALTH
      amount: 4
      operation: ADD_NUMBER
      slot: HAND

  # 传统机制（仍然可与 Components 共存）
  Mechanics:
    lifeleech:
      amount: 1
```

## 常见可用属性列表 (Attribute)

用于 `AttributeModifiers`：

| 属性名 | 描述 |
|--------|------|
| `ATTACK_DAMAGE` | 攻击伤害 |
| `ATTACK_SPEED` | 攻击速度 |
| `MAX_HEALTH` | 最大生命值 |
| `MOVEMENT_SPEED` | 移动速度 |
| `ARMOR` | 护甲值 |
| `ARMOR_TOUGHNESS` | 护甲韧性 |
| `KNOCKBACK_RESISTANCE` | 击退抗性 |
| `LUCK` | 幸运值 |
| `BLOCK_INTERACTION_RANGE` | 方块交互范围 |
| `ENTITY_INTERACTION_RANGE` | 实体交互范围 |
| `STEP_HEIGHT` | 步高 |
| `JUMP_STRENGTH` | 跳跃力 |
| `BURNING_TIME` | 燃烧时间 |
| `EXPLOSION_KNOCKBACK_RESISTANCE` | 爆炸击退抗性 |

### 属性操作

| 操作 | 值 | 说明 |
|------|-----|------|
| `ADD_NUMBER` | 0 | 直接加值 |
| `ADD_SCALAR` | 1 | 按比例加法 |
| `MULTIPLY_SCALAR_1` | 2 | 百分比乘法（1=+100%） |
