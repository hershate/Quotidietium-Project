# 可染色物品模板

> 适用于创建可以使用染料改变颜色的自定义物品。
> 基于 `LEATHER_HORSE_ARMOR` 或 `POTION` 材质的原版染色系统。

---

## 基础可染色物品配置

```yaml
# =============================================================================
# 可染色物品 - 基础模板
# =============================================================================
dyeable_item:
  displayname: "<white>可染色物品"

  # ---------------------------------------------------------------------------
  # 材质（必填）- 必须使用支持染色的基础材质
  #   LEATHER_HORSE_ARMOR  - 皮马铠（推荐，支持完整 RGB 染色）
  #   POTION               - 药水（使用原版药水染色系统）
  #   LEATHER_CHESTPLATE   - 皮革胸甲
  #   LEATHER_LEGGINGS     - 皮革护腿
  #   LEATHER_BOOTS        - 皮革靴子
  #   LEATHER_HELMET       - 皮革头盔
  #   ⚠️ docs（Dyeable Items.md）仅明确支持 POTION 与 LEATHER_HORSE_ARMOR；皮革护甲（LEATHER_*）染色需较新版本 Oraxen 验证
  # ---------------------------------------------------------------------------
  material: LEATHER_HORSE_ARMOR

  # ---------------------------------------------------------------------------
  # 默认颜色（可选）- RGB 格式，范围 0-255
  # 格式: R, G, B
  # 这是在材质纹理基础上的默认色调
  # ---------------------------------------------------------------------------
  color: 255, 255, 255                # 白色（默认不染色）

  Pack:
    generate_model: true
    parent_model: "item/generated"
    textures:
      - dyeable_item.png

  Mechanics:
    # 家具机制示例中的可染色家具配置
    # 如果是普通物品而非家具，无需 Mechanics 部分
    furniture:
      barrier: false
      drop:
        silktouch: false
        loots:
          - { oraxen_item: dyeable_item, probability: 1.0 }
```

## Blockbench 模型染色准备

> 要让自定义模型支持染色，需要在 Blockbench 中启用 `tint` 选项。

### 操作步骤

1. **打开你的模型** - 在 Blockbench 中加载 3D 模型文件
2. **选择要染色的面** - 点击选中模型中需要响应染色的面
3. **启用 `tint` 选项** - 在右侧面板勾选 `tint`（色彩索引）
4. **应用到所有需要染色的面** - 重复步骤 2-3，为所有需要染色的面启用 tint
5. **使用白色纹理** - 纹理使用白色可以获得最佳染色效果

## 可染色物品的染色方式

### 原版染料染色

玩家可以使用原版染料在工作台中给可染色物品染色：

```
工作台配方（无需额外配置）:
  染料 + LEATHER_HORSE_ARMOR物品 -> 染色后的物品
```

染色后的颜色由染料的 RGB 值决定，多个染料可以混合。

### 颜色计算原理

- Minecraft 使用叠加染色系统
- 每次染色 = 当前颜色与染料颜色混合
- 使用 `color` 字段设置初始默认颜色
- RGB 范围：`0` 到 `255`
- 白色 `255, 255, 255` = 不染色（显示纹理原色）

## 注意事项

1. **材质限制**: docs（Dyeable Items.md）明确支持 `POTION` 与 `LEATHER_HORSE_ARMOR`；皮革护甲（`LEATHER_*`）染色需较新版本 Oraxen 验证
2. **纹理推荐**: 纹理中使用白色/灰色区域会在染色后呈现染料颜色；纯白区域效果最佳
3. **Blockbench**: 每个需要染色的面都必须单独启用 `tint` 选项
4. **json 模型**: 自定义 JSON 模型中使用了 tintindex 的面会自动响应染色
5. **叠加染色**: 在原版中多次染色会产生叠加效果，这一点在制作时需要注意
6. **color 字段**: 仅在小节顶层直接使用（如 `color: 255, 255, 255`），不在 Mechanics 内部

## Tint 索引说明

在 JSON 模型中，可以通过 `tintindex` 控制哪些纹理层响应染色：

```json
{
  "parent": "item/generated",
  "textures": {
    "layer0": "oraxen:item/dyeable_base",      // 基础纹理（不染色）
    "layer1": "oraxen:item/dyeable_overlay"     // 覆盖纹理（响应染色，tintindex: 1）
  }
}
```

- `tintindex: 0`（默认）= 响应染色的图层
- 未指定 `tintindex` 的图层不响应染色
- 通常只对一层使用 tint，保持基础纹理固定
