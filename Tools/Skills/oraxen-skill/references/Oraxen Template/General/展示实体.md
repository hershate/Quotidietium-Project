# 展示实体（Display Entity）参考文档

> 展示实体是 Minecraft 1.19.4 引入的新型实体，用于高效渲染 3D 模型。
> Oraxen 从 1.154.0 版本开始支持展示实体作为家具的渲染方式。

---

## 一、版本要求

| 组件 | 最低版本 |
|------|----------|
| 服务端 | 1.19.4+ |
| 客户端 | 1.19.4+（低版本客户端看不到展示实体家具） |
| Oraxen | 1.154.0+ |

> **重要警告:** ViaVersion 无法让低版本客户端看到展示实体。如果你的服务器需要支持 <1.19.4 的客户端，请使用 `type: ITEM_FRAME` 作为替代。

---

## 二、展示实体类型

> Minecraft 原版提供 4 种展示实体子类型。Oraxen 家具主要使用第 1 种和第 4 种。

| 类型 | 原版 ID | Oraxen 用途 | 说明 |
|------|--------|------------|------|
| **Item Display** | `minecraft:item_display` | 家具模型渲染 | 渲染 3D 物品模型，Oraxen 家具的核心 |
| **Block Display** | `minecraft:block_display` | 不常用 | 渲染方块模型 |
| **Text Display** | `minecraft:text_display` | 文本标签 | 渲染浮空文字（`text_entity` / `text_entities`） |
| **Interaction Entity** | `minecraft:interaction` | 碰撞箱 | 隐形实体，仅用于碰撞检测（`hitbox`） |

### 2.1 Item Display（物品展示实体）

> Oraxen 家具默认使用的展示实体类型。将自定义模型作为物品渲染。

```
放置家具 → 生成 Item Display 实体 → 实体持有 Oraxen 物品模型
↓
客户端看到的就是浮在空中的 3D 模型
```

**优势:**
- 不会被剔除（不会在特定角度消失不渲染）
- 支持丰富的显示变换和动画
- 支持亮度和阴影控制

**劣势:**
- 实体渲染性能低于方块渲染
- 低版本客户端不可见

### 2.2 Block Display（方块展示实体）

> 渲染方块模型。Oraxen 家具通常不使用此类型，但了解其存在有助于理解展示实体系统。

### 2.3 Text Display（文本展示实体）

> 在家具上方渲染浮空文字。Oraxen 通过 `text_entity` 和 `text_entities` 配置使用此类型。

```yaml
# 文本显示配置（详见基础家具模板 第十四节）
Mechanics:
  furniture:
    type: DISPLAY_ENTITY
    text_entity:
      text: "<gold>标签文字</gold>"
      offset: { x: 0, y: 1.2, z: 0 }
      billboard: CENTER
      shadow: true
```

### 2.4 Interaction Entity（交互实体）

> 完全隐形的实体，仅用于检测玩家交互（点击/碰撞）。
> Oraxen 使用它来实现 `hitbox`（碰撞箱）功能。

```yaml
# 交互实体配置（碰撞箱）
Mechanics:
  furniture:
    type: DISPLAY_ENTITY
    hitbox:
      width: 0.6
      height: 0.8
```

## 三、Oraxen 家具类型（type 字段）

> Oraxen 家具机制的 `type` 字段决定使用哪种实体渲染。

```yaml
Mechanics:
  furniture:
    type: DISPLAY_ENTITY     # [推荐] 展示实体，1.19.4+ 服务器默认
    # 其他可选值:
    # ITEM_FRAME              # 旧版物品展示框（兼容 <1.19.4）
    # GLOW_ITEM_FRAME         # 发光物品展示框
    # ARMOR_STAND             # 盔甲架
```

| type 值 | 渲染方式 | 最低版本 | 性能 | 选项丰富度 |
|---------|----------|----------|------|-----------|
| `DISPLAY_ENTITY` | 展示实体 | 1.19.4 | 中 | 高 |
| `ITEM_FRAME` | 物品展示框 | 1.16+ | 高 | 低 |
| `GLOW_ITEM_FRAME` | 发光物品展示框 | 1.17+ | 高 | 低 |
| `ARMOR_STAND` | 盔甲架 | 1.16+ | 低 | 中 |

> **默认行为:** 服务器版本 1.19.4+ 时默认使用 `DISPLAY_ENTITY`，否则默认 `ITEM_FRAME`。

## 四、显示变换（display_transform）

> `display_transform` 决定模型如何映射到展示实体上。
> 对应 BlockBench 中 Display 选项卡的各变换预设。

```yaml
Mechanics:
  furniture:
    type: DISPLAY_ENTITY
    display_entity_properties:
      display_transform: NONE
```

### 4.1 可用变换值

| 值 | BlockBench 等效 | 视觉效果 | 适用场景 |
|----|----------------|----------|----------|
| `NONE` | 默认 | 与 BlockBench 中打开模型时相同 | 大多数家具（推荐） |
| `HEAD` | Head | 类似盔甲架头部位置 | 与旧版盔甲架家具兼容 |
| `FIXED` | Fixed | 类似物品展示框的位置和方向 | 模拟 ITEM_FRAME 位置 |
| `GROUND` | Ground | 类似掉落物平放在地面 | 地面装饰 |
| `GUI` | GUI | GUI 界面中的显示方式 | (一般不用于家具) |
| `FIRSTPERSON_LEFTHAND` | First Person Left Hand | 第一人称左手 | (一般不用于家具) |
| `FIRSTPERSON_RIGHTHAND` | First Person Right Hand | 第一人称右手 | (一般不用于家具) |
| `THIRDPERSON_LEFTHAND` | Third Person Left Hand | 第三人称左手 | (一般不用于家具) |
| `THIRDPERSON_RIGHTHAND` | Third Person Right Hand | 第三人称右手 | (一般不用于家具) |

### 4.2 推荐设置

```
一般家具:       display_transform: NONE
墙壁装饰/照片:   display_transform: FIXED
兼容旧版数据:    display_transform: HEAD
```

## 五、变换与动画属性

> 以下属性均在 `display_entity_properties` 下配置。

### 5.1 位置偏移 (translation)

```yaml
display_entity_properties:
  translation:
    x: 0.0           # 左右偏移（方块为单位，0.1 = 1/10 方块）
    y: 0.05          # 上下偏移
    z: 0.0           # 前后偏移
```

**适用场景:**
- 微调家具在方块上的位置
- 修正模型中心偏移
- 无需在 BlockBench 中重新编辑模型

### 5.2 缩放 (scale)

```yaml
display_entity_properties:
  scale:
    x: 1.0           # X 轴缩放
    y: 1.0           # Y 轴缩放
    z: 1.0           # Z 轴缩放
```

### 5.3 旋转跟踪 (tracking_rotation)

> 控制展示实体是否"面向"玩家。用于公告板、路标等。

```yaml
display_entity_properties:
  tracking_rotation: FIXED     # 不跟踪（默认）
  # 其他选项:
  # VERTICAL   → 仅左右朝向玩家
  # HORIZONTAL → 仅上下朝向玩家
  # CENTER     → 始终保持正面朝向玩家
```

### 5.4 亮度 (brightness)

> 与 `light` 发光机制不同，`brightness` 控制的是**模型的渲染亮度**而非环境光照。

```yaml
display_entity_properties:
  brightness:
    block_light: 15    # 方块光照等级 (0-15)，最大值时模型不受黑暗影响
    sky_light: 0       # 天空光照等级 (0-15)
```

### 5.5 动画属性 (interpolation)

> 控制展示实体变换（缩放、旋转）的平滑过渡。

```yaml
display_entity_properties:
  interpolation_duration: 10    # 变换动画完成所需刻数 (0=无动画, 直接跳变)
  interpolation_delay: 0        # 变换开始前的等待刻数
```

**工作原理:**
```
触发变换 → 等待 interpolation_delay 刻 → 在 interpolation_duration 刻内平滑过渡到目标值
```

### 5.6 阴影属性

```yaml
display_entity_properties:
  shadow_radius: 0.5        # 阴影扩散半径
  shadow_strength: 0.8      # 阴影强度 (0.0 = 无阴影, 1.0 = 最深)
```

### 5.7 可见距离与剔除

```yaml
display_entity_properties:
  view_range: 64            # 模型可见距离（以方块计）
  displayWidth: 1.0         # 剔除判断用的包围盒宽度
  displayHeight: 1.0        # 剔除判断用的包围盒高度
```

> `displayWidth` 和 `displayHeight` 用于判断实体是否在视野内（剔除优化）。如果家具在特定角度消失，尝试增大这些值。

## 六、Hitbox（碰撞箱）vs Barrier（屏障）对比

> 两种碰撞实现方式的区别和选择建议。

### 6.1 Hitbox

| 项目 | 说明 |
|------|------|
| 实现 | 基于交互实体 (Interaction Entity) |
| 碰撞形状 | 精确的矩形碰撞箱 (width x height) |
| 可见性 | 完全隐形 |
| 性能 | 轻量（一个交互实体） |
| 版本要求 | 1.19.4+ |
| 配置 | `hitbox: { width: X, height: Y }` |

```yaml
# Hitbox 配置
Mechanics:
  furniture:
    type: DISPLAY_ENTITY
    hitbox:
      width: 0.8
      height: 0.6
```

### 6.2 Barrier（屏障）

| 项目 | 说明 |
|------|------|
| 实现 | 隐形屏障方块 |
| 碰撞形状 | 方块级碰撞（每次 1x1x1 方块） |
| 可见性 | 隐形方块 |
| 性能 | 每增加一个屏障就增加一个方块实体 |
| 版本要求 | 无特殊要求 |
| 配置 | `barrier: true` 或 `barriers: [...]` |

```yaml
# 单个屏障
barrier: true

# 多个屏障
barriers:
  - origin
  - { x: 1, z: 0 }
  - { x: 0, z: 1 }
```

### 6.3 选择建议

| 场景 | 推荐 | 原因 |
|------|------|------|
| 小型家具（椅子、台灯） | Hitbox | 精确碰撞，性能好 |
| 大型家具（桌子、柜台） | Hitbox | 一个碰撞箱覆盖大区域 |
| 复杂多层家具 | 屏障 (多个) | 可定义多个方块级的碰撞位置 |
| 需要红石交互 | 屏障 | 红石信号需要方块 |
| 兼容 <1.19.4 | 屏障 | Hitbox 不可用 |
| 座位功能 | 屏障 (必须) | 座位依赖屏障方块 |
| 存储功能 | 任意 + 屏障 | 存储需要屏障；可以同时有 Hitbox+Barrier |

### 6.4 Hitbox + Barrier 共存

```yaml
# 可以同时使用两者
Mechanics:
  furniture:
    type: DISPLAY_ENTITY
    hitbox:
      width: 1.0
      height: 0.5
    barrier: true        # 同时启用屏障（用于座位/存储）
    seat:
      height: -0.3
```

> `hitbox` 提供精确交互区域，`barrier` 提供座位和存储所需的方块级碰撞。

## 七、展示实体属性完整参考

> 所有 `display_entity_properties` 可配置属性的汇总表。

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `display_transform` | 枚举 | `NONE` | 模型显示变换方式 |
| `tracking_rotation` | 枚举 | `FIXED` | 是否跟踪面向玩家 |
| `translation.x` | 浮点 | `0.0` | X 轴位置偏移（方块单位） |
| `translation.y` | 浮点 | `0.0` | Y 轴位置偏移（方块单位） |
| `translation.z` | 浮点 | `0.0` | Z 轴位置偏移（方块单位） |
| `scale.x` | 浮点 | `1.0` | X 轴缩放 |
| `scale.y` | 浮点 | `1.0` | Y 轴缩放 |
| `scale.z` | 浮点 | `1.0` | Z 轴缩放 |
| `brightness.block_light` | 整数 | `-1` | 方块光照覆盖 (0-15, -1=默认) |
| `brightness.sky_light` | 整数 | `-1` | 天空光照覆盖 (0-15, -1=默认) |
| `view_range` | 浮点 | `64` | 可见距离（方块） |
| `shadow_radius` | 浮点 | `0.0` | 阴影半径 |
| `shadow_strength` | 浮点 | `1.0` | 阴影强度 (0.0-1.0) |
| `interpolation_duration` | 整数 | `0` | 变换动画刻数 |
| `interpolation_delay` | 整数 | `0` | 动画延迟刻数 |
| `displayWidth` | 浮点 | `1.0` | 剔除包围盒宽度 |
| `displayHeight` | 浮点 | `1.0` | 剔除包围盒高度 |

## 八、完整配置示例

### 8.1 基础展示实体家具

```yaml
basic_display_furniture:
  displayname: "<white>基础展示家具</white>"
  material: PAPER
  Pack:
    generate_model: false
    model: default/basic_display
  Mechanics:
    furniture:
      type: DISPLAY_ENTITY
      hitbox:
        width: 0.8
        height: 0.8
      display_entity_properties:
        display_transform: NONE
        scale: { x: 1.0, y: 1.0, z: 1.0 }
        view_range: 48
```

### 8.2 带全套展示属性的家具

```yaml
advanced_display_furniture:
  displayname: "<gold>高级展示家具</gold>"
  material: PAPER
  Pack:
    generate_model: false
    model: default/advanced_display
  Mechanics:
    furniture:
      type: DISPLAY_ENTITY
      barrier: true
      hitbox:
        width: 1.0
        height: 1.2
      seat:
        height: -0.3
      display_entity_properties:
        display_transform: NONE
        translation:
          x: 0.0
          y: 0.05
          z: 0.0
        scale:
          x: 1.0
          y: 1.0
          z: 1.0
        brightness:
          block_light: 15
          sky_light: 0
        view_range: 64
        shadow_radius: 0.5
        shadow_strength: 0.6
        interpolation_duration: 10
        interpolation_delay: 0
        displayWidth: 1.0
        displayHeight: 1.0
      block_sounds:
        place_sound: block.stone.place
        break_sound: block.stone.break
        hit_sound: block.stone.hit
        step_sound: block.stone.step
        fall_sound: block.stone.fall
      drop:
        silktouch: false
        loots:
          - { oraxen_item: advanced_display_furniture, probability: 1.0 }
```

## 九、旧版 ITEM_FRAME 迁移注意事项

> 如果你正在从 `type: ITEM_FRAME` 迁移到 `type: DISPLAY_ENTITY`：

1. **已放置的家具不会自动更新。** 旧家具保持为 ITEM_FRAME 类型，新家具才使用 DISPLAY_ENTITY。
2. **修改配置前先移除旧家具。** 否则可能造成损坏。
3. **建议分批迁移。** 给玩家缓冲时间移除和重新放置。
4. **模型朝向可能不同。** ITEM_FRAME 使用 FIXED 变换，DISPLAY_ENTITY 默认使用 NONE。你可能需要调整 `display_transform` 为 `FIXED` 来匹配旧外观。

## 十、性能调优建议

| 场景 | 建议 |
|------|------|
| 大量同一家具 | 使用 `ITEM_FRAME` 类型（更高效） |
| 大规模装饰区域 | 放宽 `view_range` 限制 |
| 小范围精细装饰 | 使用 `DISPLAY_ENTITY` 以获得不剔除效果 |
| 静态不交互家具 | 关闭 `interpolation_duration` (设为 0) |
| 大量文本标签 | 增大 `refresh_ticks` 以减少网络更新频率 |
