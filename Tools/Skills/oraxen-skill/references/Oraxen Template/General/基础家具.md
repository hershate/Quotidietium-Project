# 基础家具配置模板

> 此模板涵盖 Oraxen 展示实体（DISPLAY_ENTITY）家具的全部基础配置。适用于椅子、桌子、灯具、装饰品等所有标准家具类型。

---

## 一、基础框架

```yaml
# ============================================================
# 物品 ID（必须唯一，用于 /oraxen give 和所有引用）
# ============================================================
my_furniture:
  # ----------------------------------------------------------
  # 显示名称（支持 MiniMessage 格式）
  # ----------------------------------------------------------
  displayname: "<white>我的家具"

  # ----------------------------------------------------------
  # 基础材质（物品栏/手中显示的物品，仅用于辨识）
  # 常见选择: PAPER, DIAMOND, LEATHER_HORSE_ARMOR
  # ----------------------------------------------------------
  material: PAPER

  # ==========================================================
  # Pack 节 —— 模型和资源包配置
  # ==========================================================
  Pack:
    # --------------------------------------------------------
    # generate_model: 是否自动生成模型
    #   true  = 使用 parent_model + textures 自动生成
    #   false = 使用自定义 BlockBench 模型
    # --------------------------------------------------------
    generate_model: false

    # --------------------------------------------------------
    # model: 主模型路径（相对于 assets/oraxen/models/）
    # 实际路径示例: Oraxen/pack/assets/oraxen/models/default/table.json
    # --------------------------------------------------------
    model: default/my_furniture

    # --------------------------------------------------------
    # models: [可选] 定义额外的模型变体
    # 自动注册为 oraxen:<物品id>/<键名>
    # 用于唱片机 active_model、进化阶段等场景
    # --------------------------------------------------------
    models:
      variant_special: default/my_furniture_special
      variant_alt: default/my_furniture_alt

  # ==========================================================
  # Mechanics 节 —— 家具机制核心配置
  # ==========================================================
  Mechanics:
    furniture:
      # ======================================================
      # type: 家具类型（必填）
      #   DISPLAY_ENTITY   - 1.19.4+ 展示实体（推荐）
      #   ITEM_FRAME       - 旧版物品展示框（兼容 <1.19.4）
      #   GLOW_ITEM_FRAME  - 发光物品展示框
      #   ARMOR_STAND      - 盔甲架
      # ------------------------------------------------------
      # 注意: 服务器 1.19.4+ 默认 DISPLAY_ENTITY，否则默认 ITEM_FRAME
      # ======================================================
      type: DISPLAY_ENTITY
```

## 二、屏障（碰撞方块）

> 屏障是随家具放置的隐形方块，提供物理碰撞。**座位和存储功能都需要屏障**。
>
> 对于展示实体类型，你也可以使用下方的 `hitbox` 替代屏障。

### 2.1 单个屏障

```yaml
Mechanics:
  furniture:
    type: DISPLAY_ENTITY
    barrier: true   # 在家具正下方 {x:0, y:0, z:0} 放置一个屏障
```

### 2.2 多个屏障

> 适用于大型家具或需要复杂碰撞箱的场景。每个屏障占据 1 个方块空间。

```yaml
Mechanics:
  furniture:
    type: DISPLAY_ENTITY
    barriers:                    # 多个屏障列表（注意复数 barriers）
      - origin                   # {x:0, y:0, z:0} 的简写
      - z: 1                     # 仅指定 z，则 x=0, y=0
      - z: 2                     # 前方两个方块都有碰撞
      - x: 1                     # 右侧
      - { x: 1, z: 1 }           # 对角（对象格式）
      - x: 1                     # 多行格式也支持
        z: 2
      - { x: -1, y: 1, z: 0 }   # 上方一层（大型多层家具）
```

## 三、碰撞箱（Hitbox）—— 仅展示实体

> `hitbox` 是 1.19.4+ 展示实体的新功能。基于交互实体实现，完全隐形，仅提供碰撞区域。
>
> 可**与屏障同时使用**。hitbox 定义精确碰撞区域，屏障定义方块级碰撞。

```yaml
Mechanics:
  furniture:
    type: DISPLAY_ENTITY
    hitbox:
      width: 0.8    # 碰撞箱宽度（以方块为单位，默认 1.0）
      height: 0.6   # 碰撞箱高度（以方块为单位，默认 1.0）
    barrier: true   # 可同时启用屏障
```

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `width` | float | `1.0` | 碰撞箱宽度（X/Z 轴），以方块为单位 |
| `height` | float | `1.0` | 碰撞箱高度（Y 轴），以方块为单位 |

## 四、座位

> **需要启用屏障**才能使用座位。如果配置了多个屏障，每个屏障都会生成一个座位。
>
> 建议不要设置 yaw（旋转角度），让系统自动处理朝向。

```yaml
Mechanics:
  furniture:
    type: DISPLAY_ENTITY
    barrier: true         # 座位必须启用屏障

    # ----------------------------------------------------------
    # 基础座位（仅高度偏移）
    # ----------------------------------------------------------
    seat:
      height: -0.3        # 相对于屏障的坐高偏移
                          # 正值 = 向上，负值 = 向下
                          # 示例: -0.3 表示坐在比屏障低 0.3 格的位置

    # ----------------------------------------------------------
    # 带旋转的座位（不推荐手动设置）
    # ----------------------------------------------------------
    # seat:
    #   height: -0.5
    #   yaw: 90            # 旋转角度（0/90/180/270）
```

## 六、可旋转与限制旋转

### 6.1 可旋转

```yaml
Mechanics:
  furniture:
    type: DISPLAY_ENTITY
    rotatable: true        # 允许玩家手持该物品时右键旋转已放置的家具
```

### 6.2 限制旋转方向

> 限制家具旋转的朝向数量。

```yaml
Mechanics:
  furniture:
    type: DISPLAY_ENTITY
    rotatable: true
    restricted_rotation: STRICT       # 8 个方向（每 45° 一个，默认值）
    # 或
    # restricted_rotation: VERY_STRICT   # 4 个方向（每 90° 一个）
```

| 值 | 方向数 | 每次旋转 |
|----|--------|----------|
| `STRICT` | 8 个方向 | 45° |
| `VERY_STRICT` | 4 个方向 | 90° |

## 七、有限放置

> 限制家具可以/不可以放置在哪些方块上。

```yaml
Mechanics:
  furniture:
    type: DISPLAY_ENTITY
    limited_placing:
      # --------------------------------------------------------
      # 半径限制: 在指定半径内限制同种家具的数量
      # --------------------------------------------------------
      radius_limitation:
        radius: 16         # 检查半径（以方块计）
        amount: 5          # 此半径内最多允许放置的数量

      # --------------------------------------------------------
      # 放置面: 允许/禁止放在哪些面上
      # --------------------------------------------------------
      roof: false          # 禁止放在天花板上
      floor: true          # 允许放在地板上
      wall: false          # 禁止放在墙上

      # --------------------------------------------------------
      # type: ALLOW 或 DENY
      #   ALLOW = 只允许放在下方列出的方块上（白名单）
      #   DENY  = 不允许放在下方列出的方块上（黑名单）
      # --------------------------------------------------------
      type: ALLOW

      # --------------------------------------------------------
      # block_types: 原版方块材质列表
      # --------------------------------------------------------
      block_types:
        - GRASS_BLOCK
        - DIRT
        - STONE
        - DEEPSLATE

      # --------------------------------------------------------
      # block_tags: 原版方块标签（推荐用于一组方块）
      # 参考: https://minecraft.fandom.com/wiki/Tag#Block_tags
      # --------------------------------------------------------
      block_tags:
        - base_stone_overworld
        - base_stone_nether
        - dirt

      # --------------------------------------------------------
      # oraxen_blocks: Oraxen 自定义方块/家具 ID
      # 注意: 家具需要屏障才能被此类限制检测到
      # --------------------------------------------------------
      oraxen_blocks:
        - custom_floor_block
        - another_furniture
```

## 八、硬度

> 控制破坏家具所需的时间。默认值为 1（类似木板）。

```yaml
Mechanics:
  furniture:
    type: DISPLAY_ENTITY
    barrier: true
    hardness: 8           # 硬度值，数字越大越难挖
                          # 参考: 石头=3, 铁块=5, 黑曜石=50
```

## 九、掉落配置

> 控制挖掘/破坏家具后掉落的物品。

```yaml
Mechanics:
  furniture:
    type: DISPLAY_ENTITY
    barrier: true

    drop:
      # --------------------------------------------------------
      # silktouch: 是否需要精准采集才能掉落
      #   true  = 仅精准采集工具挖掘时掉落
      #   false = 不使用精准采集也能掉落
      # --------------------------------------------------------
      silktouch: false

      # --------------------------------------------------------
      # 掉落列表
      #   oraxen_item: Oraxen 物品 ID
      #   probability: 掉落概率 (0.0 ~ 1.0)
      #   max_amount:  最大掉落数量（可选，默认 1）
      #   minimal_type: 最低工具等级要求（WOODEN/STONE/IRON/GOLDEN/DIAMOND/NETHERITE）
      #   best_tools: 最佳采集工具（可选，加快挖掘速度）
      # --------------------------------------------------------
      loots:
        - oraxen_item: my_furniture
          probability: 1.0
          max_amount: 1

      # 更复杂的掉落示例:
      # loots:
      #   - oraxen_item: my_furniture
      #     probability: 1.0
      #     max_amount: 1
      #   - oraxen_item: bonus_material
      #     probability: 0.3
      #     max_amount: 2
```

### 带工具要求的掉落

```yaml
Mechanics:
  furniture:
    drop:
      silktouch: true                 # 需要精准采集
      minimal_type: IRON              # 最低需要铁质工具
      best_tools:
        - PICKAXE                     # 镐子挖掘最快
        - AXE                         # 斧头也可以
      loots:
        - oraxen_item: my_furniture
          probability: 1.0
```

## 十二、自定义方块音效

### 12.1 简单格式（默认音量和音调）

```yaml
Mechanics:
  furniture:
    type: DISPLAY_ENTITY
    barrier: true
    block_sounds:
      place_sound: block.stone.place       # 放置音效
      break_sound: block.stone.break       # 破坏音效
      hit_sound: block.stone.hit           # 击打音效
      step_sound: block.stone.step         # 行走音效
      fall_sound: block.stone.fall         # 摔落音效

      # 也可以使用自定义音效（需在 Oraxen/sound.yml 中定义）
      # 并在 Oraxen/pack-folder 中有对应的音效文件
      # hit_sound: my.custom.hitsound
      # step_sound: my.custom.stepsound
```

### 12.2 详细格式（可自定义音量和音调）

> 两种格式可以混合使用 —— 部分用简单格式，部分用详细格式。

```yaml
Mechanics:
  furniture:
    type: DISPLAY_ENTITY
    barrier: true
    block_sounds:
      place:
        sound: block.stone.place
        volume: 1.0                       # 音量 (默认 1.0)
        pitch: 0.8                        # 音调 (默认 1.0)
      break_sound: block.stone.break      # 混合写法: break 用简单格式
      hit:
        sound: my.custom.hitsound         # 自定义音效
        volume: 0.9
        pitch: 1.2
      step_sound: block.stone.step
      fall_sound: block.stone.fall
```

## 十三、展示实体属性

> 仅对 `type: DISPLAY_ENTITY` 有效。控制模型的显示方式、亮度、缩放等。

```yaml
Mechanics:
  furniture:
    type: DISPLAY_ENTITY
    barrier: true

    display_entity_properties:
      # --------------------------------------------------------
      # display_transform: 模型显示变换方式
      #   NONE                    = BlockBench 中默认显示（推荐）
      #   HEAD                    = 类似盔甲架头部显示
      #   FIXED                   = 类似物品展示框位置
      #   FIRSTPERSON_LEFTHAND    = 第一人称左手
      #   FIRSTPERSON_RIGHTHAND   = 第一人称右手
      #   GROUND                  = 掉落物地面显示
      #   GUI                     = GUI 界面显示
      #   THIRDPERSON_LEFTHAND    = 第三人称左手
      #   THIRDPERSON_RIGHTHAND   = 第三人称右手
      # --------------------------------------------------------
      display_transform: NONE

      # --------------------------------------------------------
      # tracking_rotation: 是否跟踪（面向）玩家
      #   FIXED      = 不旋转（默认）
      #   VERTICAL   = 绕垂直轴旋转（左右）
      #   HORIZONTAL = 绕水平轴旋转（上下）
      #   CENTER     = 绕中心旋转
      # 主要用于公告板、排行榜等
      # --------------------------------------------------------
      # tracking_rotation: FIXED

      # --------------------------------------------------------
      # brightness: 发光方式（与 light 属性配合）
      #   block_light: 方块光照 (0-15)
      #   sky_light:   天空光照 (0-15)
      # --------------------------------------------------------
      brightness:
        block_light: 15
        sky_light: 0

      # --------------------------------------------------------
      # scale: 模型缩放
      # --------------------------------------------------------
      scale:
        x: 1.0
        y: 1.0
        z: 1.0

      # --------------------------------------------------------
      # translation: 模型位置偏移（微调用，单位为方块）
      # 不需要在 BlockBench 中修改模型即可调整位置
      # --------------------------------------------------------
      translation:
        x: 0.0                            # 左右偏移
        y: 0.05                           # 上下偏移（抬离地面）
        z: 0.0                            # 前后偏移

      # --------------------------------------------------------
      # view_range: 可见距离（以方块计）
      # --------------------------------------------------------
      view_range: 64

      # --------------------------------------------------------
      # shadow_radius & shadow_strength: 阴影设置
      # --------------------------------------------------------
      shadow_radius: 0.5                  # 阴影半径
      shadow_strength: 0.8                # 阴影强度 (0.0-1.0)

      # --------------------------------------------------------
      # 动画属性
      # --------------------------------------------------------
      interpolation_duration: 10          # 变换动画持续刻数（0=无动画）
      interpolation_delay: 0              # 动画开始前的延迟刻数

      # --------------------------------------------------------
      # displayWidth & displayHeight: 剔除包围盒
      # 控制用于剔除判断（超出视野时隐藏）的包围盒尺寸
      # --------------------------------------------------------
      displayWidth: 1.0
      displayHeight: 1.0
```

## 十四、文本显示

### 14.1 单个文本显示 (`text_entity`)

> 文本显示是纯客户端效果 —— 不会创建真实服务端实体，不增加碰撞或实体 AI 负载。
> 需要服务器版本支持展示实体（1.19.4+）。

```yaml
Mechanics:
  furniture:
    type: DISPLAY_ENTITY
    barrier: true

    text_entity:
      # --------------------------------------------------------
      # text: 显示的文本（支持 MiniMessage 格式和 PlaceholderAPI）
      # 列表形式则每个元素为独立一行
      # --------------------------------------------------------
      text:
        - "<gold><b>工坊桌</b></gold>"
        - "<gray>%player_name%</gray>"

      # --------------------------------------------------------
      # offset: 文本相对家具基础实体的位置
      # X/Z 偏移会随家具的旋转而旋转
      # --------------------------------------------------------
      offset:
        x: 0.0
        y: 1.2                            # 家具上方 1.2 格
        z: 0.0

      # --------------------------------------------------------
      # scale: 文本显示缩放
      # --------------------------------------------------------
      scale:
        x: 1.0
        y: 1.0
        z: 1.0

      # --------------------------------------------------------
      # billboard: 文本面朝方式（公告板效果）
      #   FIXED      = 固定，不朝向玩家
      #   VERTICAL   = 仅绕垂直轴旋转（左右朝向玩家）
      #   HORIZONTAL = 仅绕水平轴旋转（上下朝向玩家）
      #   CENTER     = 始终面向玩家（默认）
      # --------------------------------------------------------
      billboard: CENTER

      # --------------------------------------------------------
      # alignment: 文本对齐方式
      #   LEFT   = 左对齐
      #   CENTER = 居中对齐（默认）
      #   RIGHT  = 右对齐
      # --------------------------------------------------------
      alignment: CENTER

      # --------------------------------------------------------
      # shadow: 是否显示原版文本阴影
      # --------------------------------------------------------
      shadow: true

      # --------------------------------------------------------
      # see_through: 是否穿透方块渲染
      # --------------------------------------------------------
      see_through: false

      # --------------------------------------------------------
      # default_background: 使用客户端默认文本显示背景
      # --------------------------------------------------------
      # default_background: false

      # --------------------------------------------------------
      # background_color: ARGB 十六进制背景颜色
      # 格式: #AARRGGBB（AA 为 alpha 通道）
      # 六位 RGB 值自动使用 alpha=40 (0x40)
      # --------------------------------------------------------
      background_color: "#40000000"       # 半透明黑色背景

      # --------------------------------------------------------
      # text_opacity: 文本不透明度 (-1 到 127)
      #   -1 = 默认（完全可见）
      # --------------------------------------------------------
      text_opacity: -1

      # --------------------------------------------------------
      # line_width: 自动换行的最大行宽
      # --------------------------------------------------------
      line_width: 200

      # --------------------------------------------------------
      # view_range: 文本最大可见距离（以方块计）
      # --------------------------------------------------------
      view_range: 32

      # --------------------------------------------------------
      # refresh_ticks: 文本元数据刷新间隔（刻）
      #   0  = 不自动刷新（文本中有占位符时自动刷新）
      #   >0 = 每 N 刻刷新一次，对每个观察者单独刷新
      #        这样 PlaceholderAPI 占位符可以为不同玩家显示不同内容
      # --------------------------------------------------------
      refresh_ticks: 20
```

### 14.2 多个文本显示 (`text_entities`)

> 用于需要在不同位置显示多个独立文本的场景。

```yaml
Mechanics:
  furniture:
    type: DISPLAY_ENTITY
    barrier: true

    text_entities:
      # 标签 1: 营业状态
      - text: "<green>营业中</green>"
        offset:
          x: 0.0
          y: 1.1
          z: 0.0
        billboard: CENTER
        shadow: true
        scale:
          x: 0.8
          y: 0.8
          z: 0.8

      # 标签 2: 价格
      - text: "<yellow>5 金币 / 次</yellow>"
        offset:
          x: 0.0
          y: 0.6
          z: 0.0
        scale: [0.6, 0.6, 0.6]           # 也支持数组简写
        billboard: CENTER
        background_color: "#80000000"
```

| 属性 | 默认值 | 描述 |
|------|--------|------|
| `text` | (空) | 字符串或字符串列表。列表渲染为独立行。支持 MiniMessage。 |
| `offset` | `{x:0, y:0.6, z:0}` | 相对家具基础实体的位置。X/Z 偏移随家具旋转。支持 `[x,y,z]` 数组。 |
| `scale` | `{x:1, y:1, z:1}` | 文本显示缩放。支持 `[x,y,z]` 数组。 |
| `billboard` | `CENTER` | `FIXED`、`VERTICAL`、`HORIZONTAL` 或 `CENTER`。 |
| `alignment` | `CENTER` | `LEFT`、`CENTER` 或 `RIGHT`。 |
| `shadow` | `false` | 是否添加原版文本阴影。 |
| `see_through` | `false` | 是否穿透方块渲染。 |
| `default_background` | `false` | 使用客户端默认文本显示背景。 |
| `background_color` | `#40000000` | ARGB 十六进制颜色。六位 RGB 值自动使用 alpha=`40`。 |
| `text_opacity` | `-1` | 原版文本不透明度值，范围 `-1` 到 `127`。 |
| `line_width` | `200` | 换行前的最大文本行宽度。 |
| `view_range` | `32` | 最大可见距离（以方块计）。 |
| `refresh_ticks` | `0` | 元数据刷新间隔。`>0` 时每个观察者单独刷新。 |

## 十六、完整示例

> 以下是一个完整的、可直接参考的家具配置示例 —— 一个带发光、可旋转、有座位、有限放置的展示实体椅子。

```yaml
wooden_chair:
  displayname: "<yellow>木椅</yellow>"
  material: PAPER
  Pack:
    generate_model: false
    model: default/wooden_chair
    models:
      oak: default/wooden_chair_oak
      birch: default/wooden_chair_birch
  Mechanics:
    furniture:
      type: DISPLAY_ENTITY
      barrier: true
      seat:
        height: -0.3
      rotatable: true
      restricted_rotation: VERY_STRICT
      hardness: 3
      limited_placing:
        roof: false
        floor: true
        wall: false
        type: DENY
        block_types:
          - AIR
          - CAVE_AIR
          - VOID_AIR
      drop:
        silktouch: false
        loots:
          - oraxen_item: wooden_chair
            probability: 1.0
      block_sounds:
        place_sound: block.wood.place
        break_sound: block.wood.break
        hit_sound: block.wood.hit
        step_sound: block.wood.step
        fall_sound: block.wood.fall
      display_entity_properties:
        display_transform: NONE
        brightness:
          block_light: 0
          sky_light: 0
        scale:
          x: 1.0
          y: 1.0
          z: 1.0
        view_range: 48
```

## 字段汇总

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `type` | 枚举 | 否 | `DISPLAY_ENTITY`(1.19.4+) | 家具渲染类型 |
| `barrier` | 布尔 | 否 | `false` | 单个屏障 |
| `barriers` | 列表 | 否 | (空) | 多个屏障列表 |
| `hitbox.width` | 浮点 | 否 | `1.0` | 展示实体碰撞箱宽度 |
| `hitbox.height` | 浮点 | 否 | `1.0` | 展示实体碰撞箱高度 |
| `seat.height` | 浮点 | 否 | - | 座位高度偏移 |
| `seat.yaw` | 浮点 | 否 | - | 座位旋转角度（不推荐） |
| `light` | 整数 | 否 | - | 光照等级 (1-15)；省略则不发光 |
| `rotatable` | 布尔 | 否 | `false` | 是否可旋转 |
| `restricted_rotation` | 枚举 | 否 | `STRICT` | 旋转方向限制 |
| `hardness` | 浮点 | 否 | `1` | 破坏硬度 |
| `item` | 字符串 | 否 | (自身) | 放置时替代显示的物品 ID |
| `farmland_required` | 布尔 | 否 | `false` | 需要原版耕地 |
| `farmblock_required` | 布尔 | 否 | `false` | 需要自定义耕地方块 |
| `drop.silktouch` | 布尔 | 否 | `false` | 是否仅精准采集掉落 |
| `drop.loots` | 列表 | 否 | - | 掉落物列表 |
| `limited_placing.*` | - | 否 | - | 放置限制配置 |
| `block_sounds.*` | - | 否 | - | 方块音效配置 |
| `display_entity_properties.*` | - | 否 | - | 展示实体属性 |
| `text_entity` | 对象 | 否 | - | 单个文本显示 |
| `text_entities` | 列表 | 否 | - | 多个文本显示 |
| `blocklocker.*` | - | 否 | - | BlockLocker 保护配置 |
| `evolution.*` | - | 否 | - | 进化配置（见家具进化模板） |
| `storage.*` | - | 否 | - | 存储配置（见家具存储模板） |
| `jukebox.*` | - | 否 | - | 唱片机配置（见唱片机模板） |
| `modelengine_id` | 字符串 | 否 | - | ModelEngine 模型 ID |
