## ClickAction 点击动作

### ClickAction 概述

`clickAction` 机制允许你在玩家点击方块或家具时运行命令、播放声音、发送消息或执行其他动作。它高度可配置，支持条件判断和并发动作。

> **适用范围：** 仅用于方块（noteblock、stringblock、chorusblock）和家具（furniture）。不支持没有碰撞箱的家具。对于物品的自定义行为，请使用 [Custom 自定义能力](#custom-自定义能力)。

### ClickAction 基本配置

要开始使用，首先创建一个方块或家具物品。然后在 mechanics 部分下添加 clickActions 配置。

#### 无条件的点击动作

```yaml
# ============================================================
# 方块配置示例：无条件点击动作
# ============================================================
my_furniture:
  material: PAPER
  displayname: "<yellow>交互家具"
  Mechanics:
    furniture:                                             # 或 noteblock / stringblock / chorusblock
      clickActions:
        - conditions: []                                   # 【必填】空数组表示无条件，但必须存在
          actions:                                         # 【必填】触发时执行的动作列表
            - "[console] say <player> 点击了这个家具!"
            - "[message] <green>你点击了家具!"
```

#### 带条件的点击动作

```yaml
# ============================================================
# 方块配置示例：带条件的点击动作
# ============================================================
my_furniture:
  material: PAPER
  displayname: "<yellow>权限家具"
  Mechanics:
    furniture:
      clickActions:
        - conditions:                                      # 【必填】必须满足的条件列表（全部满足才触发）
            - '#player.hasPermission("test.permission")'  #   玩家必须拥有此权限
          actions:                                         # 【必填】条件满足时执行的动作
            - "[console] say <player> 拥有正确权限!"
            - "[sound] minecraft:block.note_block.chime"
```

### ClickAction 条件系统

条件是高度可配置的 SpEL（Spring Expression Language）表达式。你可以使用 Player 或 Server 对象的任何 "get" 方法。

#### 条件格式

条件必须以 `#player.`（访问玩家对象）或 `#server.`（访问服务器对象）开头。

#### 可用条件示例

```yaml
# ── 权限检查 ──────────────────────────────────
conditions:
  - '#player.hasPermission("test.permission")'             # 检查玩家是否拥有指定权限

# ── 世界检查 ──────────────────────────────────
conditions:
  - '#player.world.name == "world"'                         # 检查玩家所在世界名称

# ── 游戏模式检查 ──────────────────────────────
conditions:
  - '#player.gamemode.name() == "ADVENTURE"'              # 检查玩家是否为冒险模式
  - '#player.gamemode.name() == "SURVIVAL"'               # 检查玩家是否为生存模式
  - '#player.gamemode.name() == "CREATIVE"'               # 检查玩家是否为创造模式

# ── 玩家数量检查 ──────────────────────────────
conditions:
  - '#server.getOnlinePlayers().size() > 10'               # 服务器在线玩家数大于 10

# ── 服务端属性检查 ────────────────────────────
conditions:
  - '#server.getAllowEnd()'                                # 检查服务器是否允许末地
  - '#server.getDefaultGameMode()'                         # 检查服务器默认游戏模式

# ── 玩家属性检查 ──────────────────────────────
conditions:
  - '#player.name == "Steve"'                              # 检查玩家名称
  - '#player.health > 10'                                  # 检查玩家生命值
  - '#player.level >= 30'                                  # 检查玩家等级

# ── 物品检查 ──────────────────────────────────
conditions:
  - '#player.inventory.itemInMainHand.type.name() == "DIAMOND_SWORD"'  # 主手物品类型

# ── 多条件组合（全部必须满足）───────────────
conditions:
  - '#player.hasPermission("vip.access")'
  - '#player.world.name == "world"'
  - '#player.gamemode.name() == "SURVIVAL"'

# ── 布尔组合（任意一个为真）───────────────
conditions:
  - '#player.hasPermission("admin") or #player.hasPermission("mod")'
```

> **提示：** 按 "CTRL + F" 在 Spigot Javadocs 页面搜索 "get" 来查找所有可用的获取方法。Spring 文档也是理解 SpEL 表达式的好资源。

### ClickAction 动作系统

动作定义了条件满足后要执行的操作。每个动作有特定格式。

#### 动作类型总览

| 动作标签 | 格式 | 说明 | 示例 |
|----------|------|------|------|
| `[console]` | `[console] <命令>` | 以控制台身份执行命令 | `[console] say hello` |
| `[player]` | `[player] <命令>` | 以玩家身份执行命令 | `[player] spawn` |
| `[message]` | `[message] <消息>` | 发送聊天消息（支持 MiniMessage） | `[message] <blue>Hello!` |
| `[actionbar]` | `[actionbar] <消息>` | 发送操作栏消息（支持 MiniMessage） | `[actionbar] <gray>Hello from the actionbar!` |
| `[sound]` | `{参数} [sound] <声音>` | 播放声音 | `{source=AMBIENT volume=0.1 pitch=1} [sound] minecraft:block.shulker_box.close` |

#### 完整动作示例

```yaml
# ============================================================
# 综合动作示例
# ============================================================
actions:
  # 控制台命令：以控制台执行
  - "[console] say <player> 欢迎来到服务器!"

  # 玩家命令：以玩家身份执行
  - "[player] spawn"

  # OP 命令：以临时 OP 身份执行（注意：clickAction 中如需 OP 命令，使用 [console] 配合权限）
  - "[console] give <player> diamond 1"

  # 聊天消息（支持 MiniMessage 颜色和格式）
  - "[message] <green>操作成功!"

  # 操作栏消息
  - "[actionbar] <gold>当前状态: 就绪"

  # 播放声音
  - "{source=AMBIENT volume=0.1 pitch=1} [sound] minecraft:block.shulker_box.close"

  # 播放声音（使用默认 source/volume/pitch）
  - "[sound] minecraft:entity.player.levelup"
```

### ClickAction 完整示例

```yaml
# ============================================================
# 综合示例：带多个条件和多种动作的家具
# ============================================================
advanced_altar:
  material: PAPER
  displayname: "<gold>高级祭坛"
  Mechanics:
    furniture:
      clickActions:
        # ── 管理员专用：全面功能 ──────────────
        - conditions:
            - '#player.hasPermission("admin.altar")'
          actions:
            - "[console] say <player> 以管理员身份使用了祭坛"
            - "[message] <red>管理员模式已激活"
            - "{source=MASTER volume=1.0 pitch=1.5} [sound] minecraft:block.end_portal.spawn"

        # ── VIP 玩家：简化功能 ──────────────
        - conditions:
            - '#player.hasPermission("vip.altar")'
          actions:
            - "[console] give <player> diamond 5"
            - "[message] <aqua>你获得了 5 颗钻石!"
            - "{source=AMBIENT volume=0.5 pitch=1} [sound] minecraft:entity.player.levelup"

        # ── 普通玩家：提示消息 ──────────────
        - conditions: []
          actions:
            - "[message] <gray>你没有使用此祭坛的权限"
```

## Custom 自定义能力

### Custom 概述

`custom` 机制是一种无需编程即可实现极其可自定义物品行为的事件驱动系统。每个自定义能力由三部分组成：

- **事件（Event）**：定义何时触发此能力
- **条件（Conditions）**：定义触发前必须满足的前提条件
- **动作（Actions）**：定义触发后执行的操作

> **适用范围：** 仅适用于物品。对于方块和家具，请使用 [ClickAction 点击动作](#clickaction-点击动作)。

### Custom 基本配置

```yaml
# ============================================================
# 基本结构
# ============================================================
Mechanics:
  custom:
    <能力名称>:                                            # 【必填】自定义能力的唯一标识符
      one_usage: false                                     # 【可选】是否一次性使用（默认：false）
      event: "<事件类型>"                                  # 【必填】触发此能力的事件
      conditions:                                          # 【可选】触发前需满足的条件列表
        - "<条件表达式>"
      actions:                                             # 【必填】触发后执行的动作列表
        - "<动作表达式>"
```

### Custom 事件类型

#### CLICK 事件（点击事件）

**格式：** `CLICK:<鼠标按键>:<目标类型>`

| 组成部分 | 可选值 | 说明 |
|----------|--------|------|
| `<鼠标按键>` | `right`、`left`、`all` | 触发点击的鼠标按键 |
| `<目标类型>` | `block`、`air`、`all` | 点击目标类型。block=方块，air=空气，all=任意 |

**示例：**

```yaml
# 右键点击任意目标（方块或空气）
event: "CLICK:right:all"

# 左键点击方块
event: "CLICK:left:block"

# 任意按键点击空气
event: "CLICK:all:air"

# 任意按键点击任意目标
event: "CLICK:all:all"
```

#### DROP 事件（丢弃事件）

当玩家丢弃物品时触发。

```yaml
event: "DROP"
```

#### PICKUP 事件（拾取事件）

当玩家拾取物品时触发。

```yaml
event: "PICKUP"
```

#### BREAK 事件（损坏事件）

当物品耐久度耗尽损坏时触发。

```yaml
event: "BREAK"
```

#### EQUIP 事件（装备事件）

当玩家装备物品时触发（放入护甲槽或副手）。

```yaml
event: "EQUIP"
```

#### UNEQUIP 事件（卸下事件）

当玩家卸下物品时触发（从护甲槽或副手取出）。

```yaml
event: "UNEQUIP"
```

#### INV_CLICK 事件（背包点击事件）

当玩家在物品栏中点击物品时触发。

```yaml
event: "INV_CLICK"
```

#### DEATH 事件（死亡事件）

当玩家死亡且该物品通常会掉落时触发。

```yaml
event: "DEATH"
```

### Custom 条件类型

#### HAS_PERMISSION 条件

检查玩家是否拥有特定权限。

**格式：** `HAS_PERMISSION:<权限节点>`

```yaml
conditions:
  - "HAS_PERMISSION:example.permission"
  - "HAS_PERMISSION:vip.feature.access"
```

### Custom 动作类型

#### COMMAND 动作

执行命令。

**格式：** `COMMAND:<执行者>:<命令>`

| `<执行者>` | 说明 |
|-------------|------|
| `console` | 以控制台身份执行命令 |
| `player` | 以玩家身份执行命令 |

```yaml
actions:
  # 控制台给予玩家物品（<player> 为玩家名占位符）
  - "COMMAND:console:give <player> cooked_beef 1"

  # 控制台发送消息（注意：这里是 /say 命令，不是聊天消息）
  - "COMMAND:console:say <player> 使用了神秘物品"

  # 玩家执行 spawn 命令
  - "COMMAND:player:spawn"

  # 控制台杀死玩家（危险操作示例）
  - "COMMAND:console:kill <player>"
```

#### MESSAGE 动作

向玩家发送聊天消息。支持 MiniMessage 格式。

**格式：** `MESSAGE:<消息内容>`

```yaml
actions:
  - "MESSAGE:<green>你使用了特殊能力!"
  - "MESSAGE:<gradient:red:gold>传说级物品效果已触发!"
  - "MESSAGE:<#ff455b>自定义颜色的消息"
```

#### ACTIONBAR 动作

向玩家发送操作栏消息。支持 MiniMessage 格式。

**格式：** `ACTIONBAR:<消息内容>`

```yaml
actions:
  - "ACTIONBAR:<yellow>能力冷却中..."
  - "ACTIONBAR:<aqua>效果剩余时间：30秒"
```

### Custom 完整示例

#### 示例 1：简单右键物品

```yaml
# ============================================================
# 右键物品获得熟牛肉（需要权限）
# ============================================================
magic_stick:
  material: STICK
  displayname: "<light_purple>魔法棒"
  lore:
    - "<gray>右键获得熟牛肉"
    - "<gray>需要 example.permission 权限"
  Mechanics:
    custom:
      test:
        one_usage: false                                   # 不消耗物品
        event: "CLICK:right:all"                           # 右键点击任意目标
        conditions:
          - "HAS_PERMISSION:example.permission"            # 需要此权限
        actions:
          - "COMMAND:console:give <player> cooked_beef 1"  # 控制台给予熟牛肉
```

#### 示例 2：传送物品（带冷却时间）

```yaml
# ============================================================
# 右键传送回出生点
# ============================================================
teleport_stick:
  material: BLAZE_ROD
  displayname: "<aqua>传送棒"
  lore:
    - "<gray>右键传送回出生点"
    - "<gray>冷却时间：10 秒"
  Mechanics:
    custom:
      teleport:
        one_usage: false                                   # 不消耗物品
        event: "CLICK:right:all"                           # 右键点击任意目标
        conditions: []                                     # 无条件
        actions:
          - "COMMAND:player:spawn"                         # 玩家执行 /spawn
          - "MESSAGE:<green>已传送至出生点!"
```

#### 示例 3：一次性消耗品

```yaml
# ============================================================
# 一次性使用物品，使用后消失
# ============================================================
one_time_wand:
  material: END_ROD
  displayname: "<red>一次性魔杖"
  lore:
    - "<gray>使用后消失"
    - "<gray>给予 30 秒飞行能力"
  Mechanics:
    custom:
      fly_grant:
        one_usage: true                                    # 使用后消耗物品
        event: "CLICK:right:all"
        conditions: []
        actions:
          - "COMMAND:console:fly enable <player>"          # 控制台执行飞行开启
          - "MESSAGE:<green>飞行模式已启用（30秒）!"
```

#### 示例 4：多事件综合物品

```yaml
# ============================================================
# 复杂物品：装备/卸下/右键各有不同行为
# ============================================================
advanced_artifact:
  material: NETHER_STAR
  displayname: "<gold>高级神器"
  lore:
    - "<gray>装备时获得力量"
    - "<gray>右键获得经验"
    - "<gray>死亡时不掉落（但会发送消息）"
  Mechanics:
    # ── 右键点击：获得经验 ─────────────────
    custom:
      use_artifact:
        one_usage: false
        event: "CLICK:right:all"
        conditions: []
        actions:
          - "COMMAND:console:xp add <player> 100"
          - "ACTIONBAR:<aqua>获得 100 点经验!"

    # ── 装备时：发送消息 ─────────────────
      equip_artifact:
        one_usage: false
        event: "EQUIP"
        conditions: []
        actions:
          - "MESSAGE:<gold>神器装备！力量涌入你的身体！"

    # ── 卸下时：发送消息 ─────────────────
      unequip_artifact:
        one_usage: false
        event: "UNEQUIP"
        conditions: []
        actions:
          - "MESSAGE:<gray>神器已卸下。"

    # ── 死亡时：发送消息 ─────────────────
      death_artifact:
        one_usage: false
        event: "DEATH"
        conditions: []
        actions:
          - "MESSAGE:<dark_red>神器随你一同陨落..."

  # ── 灵魂绑定：死后保留物品 ─────────────
    soulbound:
      lose_chance: 0
```

#### 示例 5：条件判断 - 只有特定玩家可用

```yaml

# VIP 专属物品：管理员和 VIP 可用
# ============================================================
```

## 条件表达式详解

### SpEL 表达式语法

在 `clickAction` 中使用的条件基于 Spring Expression Language (SpEL)。基本格式：

```
#对象.方法(参数) 比较运算符 值
```

### 常用表达式参考

| 表达式 | 说明 |
|--------|------|
| `#player.hasPermission("perm")` | 检查玩家权限 |
| `#player.world.name == 'world'` | 检查世界名称 |
| `#player.gamemode.name() == 'SURVIVAL'` | 检查游戏模式 |
| `#player.name == 'PlayerName'` | 检查玩家名称 |
| `#player.health > 20` | 检查生命值 |
| `#player.level >= 30` | 检查经验等级 |
| `#player.foodLevel > 10` | 检查饥饿值 |
| `#player.isSneaking()` | 检查是否潜行 |
| `#player.isSprinting()` | 检查是否疾跑 |
| `#player.isFlying()` | 检查是否飞行 |
| `#player.isOnGround()` | 检查是否在地面 |
| `#player.isInWater()` | 检查是否在水中 |
| `#server.getOnlinePlayers().size() > 10` | 检查在线人数 |
| `#server.getAllowEnd()` | 检查允许末地 |
| `#server.getMaxPlayers()` | 获取最大玩家数 |
| `#server.getMotd()` | 获取服务器 MOTD |

### 比较运算符

| 运算符 | 说明 |
|--------|------|
| `==` | 等于 |
| `!=` | 不等于 |
| `>` | 大于 |
| `<` | 小于 |
| `>=` | 大于等于 |
| `<=` | 小于等于 |
| `and` | 逻辑与 |
| `or` | 逻辑或 |

## 动作类型详解

### ClickAction 中的动作

| 动作类别 | 格式 | 说明 |
|----------|------|------|
| **命令-控制台** | `[console] <命令>` | 以控制台身份执行命令。`<player>` 会被自动替换为玩家名 |
| **命令-玩家** | `[player] <命令>` | 玩家以自身身份执行命令 |
| **聊天消息** | `[message] <消息>` | 向玩家发送聊天消息。支持 MiniMessage 格式 |
| **操作栏** | `[actionbar] <消息>` | 向玩家发送操作栏消息。支持 MiniMessage 格式 |
| **声音** | `{参数} [sound] <声音ID>` | 播放声音，可指定 source、volume、pitch |

### Custom 中的动作

| 动作类别 | 格式 | 说明 |
|----------|------|------|
| **命令-控制台** | `COMMAND:console:<命令>` | 以控制台身份执行命令。`<player>` 为玩家名占位符 |
| **命令-玩家** | `COMMAND:player:<命令>` | 玩家以自身身份执行命令 |
| **聊天消息** | `MESSAGE:<消息>` | 向玩家发送聊天消息。支持 MiniMessage 格式 |
| **操作栏** | `ACTIONBAR:<消息>` | 向玩家发送操作栏消息。支持 MiniMessage 格式 |

### 声音参数（ClickAction）

声音动作支持的参数：

| 参数 | 默认值 | 有效范围 | 说明 |
|------|--------|----------|------|
| `source` | `MASTER` | `MASTER`、`MUSIC`、`RECORDS`、`WEATHER`、`BLOCKS`、`HOSTILE`、`NEUTRAL`、`PLAYERS`、`AMBIENT`、`VOICE` | 声音来源分类 |
| `volume` | `1.0` | `0.0` ~ `2.0` | 声音音量 |
| `pitch` | `1.0` | `0.5` ~ `2.0` | 声音音调 |

**示例：**

```yaml
# 低音量环境声音
- "{source=AMBIENT volume=0.1 pitch=1} [sound] minecraft:block.shulker_box.close"

# 大音量、低音调（深沉音效）
- "{source=MASTER volume=2.0 pitch=0.5} [sound] minecraft:entity.ender_dragon.growl"

# 默认参数（可省略 source/volume/pitch）
- "[sound] minecraft:entity.player.levelup"
```

## 常见用例

### 用例 1：权限门系统

只有拥有特定权限的玩家才能进入某个区域。

```yaml
Mechanics:
  noteblock:
    clickActions:
      - conditions:
          - '#player.hasPermission("area.vip.access")'
        actions:
          - "[console] tp <player> vip_area"
          - "[message] <green>欢迎来到 VIP 区域!"
      - conditions: []
        actions:
          - "[message] <red>你没有访问此区域的权限!"
```

### 用例 2：商店/交易系统

点击方块消耗物品获得奖励。

```yaml
Mechanics:
  furniture:
    clickActions:
      - conditions:
          - '#player.hasPermission("shop.use")'
        actions:
          - "[console] take <player> diamond 10"
          - "[console] give <player> emerald 20"
          - "[message] <green>交易成功！用 10 钻石兑换了 20 绿宝石"
          - "{source=AMBIENT volume=0.5 pitch=1} [sound] minecraft:entity.villager.trade"
```

### 用例 3：传送菜单

创建传送中心，点击前往不同地点。

```yaml
Mechanics:
  furniture:
    clickActions:
      - conditions:
          - '#player.hasPermission("teleport.spawn")'
        actions:
          - "[player] spawn"
          - "[message] <green>传送至出生点!"
      - conditions:
          - '#player.hasPermission("teleport.shop")'
        actions:
          - "[player] warp shop"
          - "[message] <green>传送至商店!"
```

### 用例 4：一次性消耗品（物品）

创建一个右键使用的消耗品。

```yaml
magic_scroll:
  material: PAPER
  displayname: "<yellow>传送卷轴"
  Mechanics:
    custom:
      teleport_scroll:
        one_usage: true
        event: "CLICK:right:all"
        conditions: []
        actions:
          - "COMMAND:player:spawn"
          - "MESSAGE:<green>卷轴化为光芒，将你传送至出生点!"
```

### 用例 5：自动消息物品

手持物品时每隔一段时间发送提示。

```yaml
compass_guide:
  material: COMPASS
  displayname: "<aqua>引导指南针"
  Mechanics:
    custom:
      compass_use:
        one_usage: false
        event: "CLICK:right:all"
        conditions: []
        actions:
          - "ACTIONBAR:<yellow>距离最近的目标：前方 50 米"
```

## ClickAction vs Custom 对比

| 特性 | ClickAction | Custom |
|------|-------------|--------|
| **适用范围** | 方块（noteblock/stringblock/chorusblock）和家具 | 物品 |
| **条件系统** | SpEL 表达式（强大灵活） | HAS_PERMISSION（简单直接） |
| **动作类型** | 命令、消息、操作栏、声音 | 命令、消息、操作栏 |
| **事件类型** | 仅点击 | 点击、丢弃、拾取、损坏、装备、卸下、背包点击、死亡 |
| **多组条件/动作** | 支持（按顺序匹配） | 不支持（单一事件/条件/动作块） |
| **复杂度** | 更灵活 | 更简单 |
