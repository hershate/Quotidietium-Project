# Oraxen 文字特效 (Text Effects) 配置模板

> 文字特效是基于着色器（Shader）的视觉效果，可应用于 Minecraft 中的任何文本。
> 与动画字形不同，文字特效使用 GLSL 着色器修改现有字符的渲染方式（颜色、位置、不透明度）。
>
> **要求：** Minecraft 1.21.4+ 且启用着色器的 Oraxen 资源包。
>
> **配置文件位置：**
> - `plugins/Oraxen/settings.yml` — 总开关和着色器设置
> - `plugins/Oraxen/text_effects.yml` — 特效定义和 GLSL 代码片段

---

## 一、settings.yml 中的文字特效总开关

```yaml
# ============================================================
# 文件: plugins/Oraxen/settings.yml
# （找到或添加 TextEffects 部分）
# ============================================================

TextEffects:
  enabled: true                         # 【必填】所有文字特效的总开关

  shader:                               # 【必填】着色器生成模式
    template: auto                      # 【必填】可选值:
                                        #   auto           - 同时生成文字特效和动画字形着色器（推荐）
                                        #   effects_only   - 仅生成文字特效着色器
                                        #   animated_only  - 仅生成动画字形着色器

  effects:                              # 【可选】按特效覆盖启用状态
    rainbow:
      enabled: true                     # 单独启用/禁用彩虹特效
    wave:
      enabled: true
    shake:
      enabled: true
    pulse:
      enabled: true
    # 如果你自定义了特效，也可以在这里按名称控制
    my_custom_effect:
      enabled: false                    # 临时禁用某个特效
```

## 二、text_effects.yml 基础结构

```yaml
# ============================================================
# 文件: plugins/Oraxen/text_effects.yml
# ============================================================

version: 1                              # 【必填】文件格式版本（当前为 1）

# ---- 共享 GLSL 代码 ----
shared:                                 # 【可选】所有特效可共用的 GLSL 辅助函数
  fragment_prelude: |                   # 【可选】片段着色器前导代码（在所有 fragment 之前执行）
    // 在此定义可重用的辅助函数
    vec3 hsv2rgb(vec3 c) {
        vec4 K = vec4(1.0, 2.0/3.0, 1.0/3.0, 3.0);
        vec3 p = abs(fract(c.xxx + K.xyz) * 6.0 - K.www);
        return c.z * mix(K.xxx, clamp(p - K.xxx, 0.0, 1.0), c.y);
    }

  vertex_prelude: |                     # 【可选】顶点着色器前导代码（在所有 vertex 之前执行）
    // 在此定义顶点着色器辅助函数

# ---- 特效定义 ----
effects:                                # 【必填】特效定义区域
  # 在此处添加特效（见下方各示例）
```

## 三、单个特效的完整配置

```yaml
# ============================================================
# 特效配置模板 — 所有可用字段
# ============================================================

effects:
  rainbow:                              # 【必填】特效名称（用于 <effect:rainbow> 标签）
    id: 0                               # 【可选】数字特效 ID (0-7)，省略时按顺序自动分配
    enabled: true                       # 【可选】此特效是否启用，默认 true
    trigger_color: "#FD0D00"            # 【可选】触发此特效的十六进制颜色，默认 #FDxD00（x=id）
    description: "随时间循环彩虹颜色"    # 【可选】描述文字，在 /oraxen texteffects 中显示
    snippets:                           # 【必填】包含特效逻辑的 GLSL 代码片段列表
      - fragment: |                     # 【可选/至少一个】片段着色器代码（控制颜色、不透明度）
          float hue = fract(charIndex * 0.03 + timeSeconds * 0.09);
          texColor.rgb = hsv2rgb(vec3(hue, 0.9, 1.0));
        vertex: |                       # 【可选】顶点着色器代码（控制位置、运动）
          // 此处可添加顶点运动逻辑
```

### 配置项详解

| 配置项 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| `id` | 整数 0-7 | 否 | 自动分配 | 特效的数字 ID，最多 8 个特效（0-7），每个 ID 必须唯一 |
| `enabled` | 布尔 | 否 | `true` | 控制特效是否启用 |
| `trigger_color` | 十六进制颜色 | 否 | `#FDxD00` | 着色器匹配此颜色来触发特效，使用 24 位精确匹配 |
| `description` | 字符串 | 否 | — | 在 `/oraxen texteffects` 命令中显示 |
| `snippets` | 列表 | **是** | — | GLSL 代码片段列表，至少需要一个 fragment 或 vertex |

## 四、GLSL 可用变量

> 在 GLSL 代码片段中可以使用以下变量：

| 变量 | 类型 | 可用范围 | 说明 |
|------|------|---------|------|
| `timeSeconds` | `float` | fragment / vertex | 游戏时间（秒），用于动画 |
| `charIndex` | `float` | fragment / vertex | 当前字符在字符串中的索引（从 `gl_VertexID` 获取），从 0 开始 |
| `pos` | `vec3` | 仅 vertex | 顶点位置 (x, y, z) |
| `texColor` | `vec4` | 仅 fragment | 纹理颜色 (r, g, b, a)，每个分量范围 0.0-1.0 |

## 五、内置特效配置

### 5.1 彩虹特效（rainbow）

```yaml
effects:
  rainbow:
    enabled: true
    description: "随时间循环彩虹颜色"
    snippets:
      - fragment: |
          float hue = fract(charIndex * 0.03 + timeSeconds * 0.09);
          texColor.rgb = hsv2rgb(vec3(hue, 0.9, 1.0));
```

### 5.2 波浪特效（wave）

```yaml
effects:
  wave:
    enabled: true
    description: "垂直正弦波运动"
    snippets:
      - fragment: |
          texColor.rgb = vec3(0.333, 0.804, 0.988);
        vertex: |
          float phase = charIndex * 0.6 + timeSeconds * 6.0;
          pos.y += sin(phase) * 2.0;
```

### 5.3 抖动特效（shake）

```yaml
effects:
  shake:
    enabled: true
    description: "随机抖动"
    snippets:
      - fragment: |
          texColor.rgb = vec3(1.0, 0.42, 0.42);
        vertex: |
          float seed = charIndex + floor(timeSeconds * 32.0);
          pos.x += (fract(sin(seed * 12.9898) * 43758.5453) - 0.5) * 1.5;
          pos.y += (fract(sin(seed * 78.233) * 43758.5453) - 0.5) * 1.5;
```

### 5.4 脉冲特效（pulse）

```yaml
effects:
  pulse:
    enabled: true
    description: "不透明度淡入淡出"
    snippets:
      - fragment: |
          texColor.rgb = vec3(1.0, 0.85, 0.24);
          float pulse = (sin(timeSeconds * 1.5 + charIndex * 0.3) + 1.0) * 0.5;
          texColor.a *= 0.3 + pulse * 0.7;
```

## 六、自定义特效示例

### 6.1 纯色替换

```yaml
effects:
  green_text:
    enabled: true
    description: "绿色文本"
    snippets:
      - fragment: |
          texColor.rgb = vec3(0.0, 1.0, 0.0);
```

### 6.2 发光亮度脉冲

```yaml
effects:
  glow:
    enabled: true
    description: "发光亮度脉冲"
    snippets:
      - fragment: |
          float glow = (sin(timeSeconds * 3.0) + 1.0) * 0.5;
          float brightness = 0.7 + glow * 0.6;
          texColor.rgb = vec3(0.9, 0.7, 0.2) * brightness;
```

### 6.3 弹跳动画

```yaml
effects:
  bounce:
    enabled: true
    description: "字符上下弹跳"
    snippets:
      - vertex: |
          float delay = charIndex * 0.2;
          float bounce = abs(sin((timeSeconds - delay) * 3.0)) * 3.0;
          pos.y += bounce;
```

### 6.4 故障特效

```yaml
effects:
  glitch:
    enabled: true
    description: "随机故障位移和颜色闪烁"
    snippets:
      - fragment: |
          float r = fract(sin(timeSeconds * 100.0 + charIndex) * 43758.5);
          if (r > 0.95) {
              texColor.rgb = vec3(1.0, 0.0, 0.0);
          }
        vertex: |
          float glitch = fract(sin(floor(timeSeconds * 20.0) + charIndex) * 43758.5);
          if (glitch > 0.9) {
              pos.x += (fract(sin(charIndex) * 43758.5) - 0.5) * 5.0;
          }
```

### 6.5 颜色渐变循环

```yaml
effects:
  color_cycle:
    enabled: true
    description: "在红色和蓝色之间循环"
    snippets:
      - fragment: |
          float cycle = (sin(timeSeconds * 2.0) + 1.0) * 0.5;
          texColor.r = 1.0 - cycle;
          texColor.b = cycle;
          texColor.g = 0.0;
```

### 6.6 旋转文字

```yaml
effects:
  spin:
    enabled: true
    description: "字符围绕中心旋转"
    snippets:
      - vertex: |
          float angle = timeSeconds * 0.5 + charIndex * 0.3;
          float radius = 2.0;
          pos.x += cos(angle) * radius;
          pos.y += sin(angle) * radius;
```

### 6.7 呼吸缩放

```yaml
effects:
  breath:
    enabled: true
    description: "缓慢的缩放脉冲"
    snippets:
      - vertex: |
          float breath = (sin(timeSeconds * 1.5) + 1.0) * 0.1 + 0.9;
          pos *= breath;
```

### 6.8 淡入特效

```yaml
effects:
  fade_in:
    enabled: true
    description: "字符从透明渐显"
    snippets:
      - fragment: |
          float fadeTime = 2.0;
          float progress = clamp(timeSeconds / fadeTime, 0.0, 1.0);
          float alpha = smoothstep(charIndex / 20.0, charIndex / 20.0 + 0.1, progress);
          texColor.a *= alpha;
```

## 七、基于版本的代码片段

> 可以为不同的 Minecraft 版本定义不同的 GLSL 代码。

```yaml
effects:
  custom_versioned:
    enabled: true
    description: "支持多版本的文字特效"
    snippets:
      # 适用于 1.21.6+
      - targets:
          min_version: "1.21.6"
        fragment: |
          texColor.rgb = vec3(1.0, 0.5, 0.0);

      # 适用于 1.21.4 - 1.21.5 的回退
      - targets:
          max_version: "1.21.5"
          min_version: "1.21.4"
        fragment: |
          texColor.rgb = vec3(0.8, 0.4, 0.0);

      # 无 targets —— 始终匹配（作为最终回退）
      - fragment: |
          texColor.rgb = vec3(0.6, 0.3, 0.0);
```

### 版本目标选项

| 选项 | 说明 |
|--------|-------------|
| `min_pack_format` | 最低资源包格式版本号 |
| `max_pack_format` | 最高资源包格式版本号 |
| `min_version` | 最低 Minecraft 版本（例如 `"1.21.4"`） |
| `max_version` | 最高 Minecraft 版本（例如 `"1.21.5"`） |

> 使用第一个匹配的片段（基于 `targets`）。没有 targets 的片段始终匹配。

## 八、GLSL 常用函数速查

```glsl
// ---- 三角函数 ----
sin(x), cos(x), tan(x)

// ---- 数学函数 ----
abs(x)                  // 绝对值
floor(x)                // 向下取整
ceil(x)                 // 向上取整
fract(x)                // 小数部分 (x - floor(x))
mod(x, y)               // 取模
clamp(x, min, max)      // 限制在范围内
mix(a, b, t)            // 线性插值: a*(1-t)+b*t
step(edge, x)           // x < edge ? 0.0 : 1.0
smoothstep(e0, e1, x)   // 平滑步进（缓入缓出）
pow(x, y)               // 幂函数
sqrt(x)                 // 平方根

// ---- 向量函数 ----
length(v)               // 向量长度
normalize(v)            // 单位向量
dot(a, b)               // 点积

// ---- 常用模式 ----
// 平滑振荡 (0.0 到 1.0)
float wave = (sin(timeSeconds * speed) + 1.0) * 0.5;

// 锯齿波 (0.0 到 1.0 重复)
float saw = fract(timeSeconds * speed);

// 离散步进（类似帧动画）
float frame = floor(timeSeconds * stepsPerSecond);

// 伪随机
float rand = fract(sin(seed * 12.9898) * 43758.5453);

// 乒乓振荡 (0 -> 1 -> 0)
float pingpong = abs(mod(timeSeconds, 2.0) - 1.0);

// 每个字符的相位偏移
float phase = charIndex * 0.5 + timeSeconds * 3.0;

// 分组字符
float group = floor(charIndex / 3.0);
```

## 九、使用方法

### 9.1 MiniMessage 标签

```
<effect:rainbow>这段文字是彩虹色的！</effect>
<effect:wave>这里是波浪文字</effect>
<effect:shake>抖动文字！</effect>
<effect:pulse>脉冲文字</effect>
<effect:glow>发光文字</effect>

# 与其他 MiniMessage 标签组合
<bold><effect:rainbow>粗体彩虹文字</effect></bold>
<effect:wave><gradient:#FF0000:#0000FF>渐变波浪</gradient></effect>
```

### 9.2 游戏内命令

```
/oraxen texteffects                        # 列出所有可用特效
/oraxen texteffect <effect> <text>         # 对文本应用特效
/oraxen texteffect rainbow Hello World!    # 示例
/oraxen texteffect wave Wavy Text          # 示例
/oraxen texteffect shake Very Shaky!       # 示例

# 权限: oraxen.command.texteffect
```

## 十、插件 API 使用

> Oraxen 提供 Java API 用于在插件中以编程方式应用文字特效。

### 基本用法

```java
import io.th0rgal.oraxen.font.TextEffect;
import net.kyori.adventure.text.Component;

// 通过名称获取特效定义
TextEffect.Definition rainbow = TextEffect.getEffect("rainbow");

// 对文本应用特效
Component text = TextEffect.apply("Hello World!", rainbow);

// 通过名称直接应用
Component waveText = TextEffect.apply("Wavy text!", "wave");

// 内置特效的便捷方法
Component rainbowText = TextEffect.rainbow("Rainbow text!");
Component wavyText = TextEffect.wave("Wavy text!");
Component shakyText = TextEffect.shake("Shaky text!");
Component pulsingText = TextEffect.pulse("Pulsing text!");

// 检查状态
boolean enabled = TextEffect.isEnabled();
boolean rainbowEnabled = TextEffect.isEffectEnabled("rainbow");
```

### MiniMessage 集成

```java
import io.th0rgal.oraxen.utils.AdventureUtils;

// AdventureUtils.MINI_MESSAGE 已包含文字特效标签解析器
Component text = AdventureUtils.MINI_MESSAGE.deserialize(
    "<effect:rainbow>彩虹文字！</effect>"
);

// 与其他标签结合
Component mixed = AdventureUtils.MINI_MESSAGE.deserialize(
    "<bold><effect:wave>粗体波浪文字！</effect></bold>"
);
```

### 自定义 MiniMessage 实例

```java
import io.th0rgal.oraxen.font.TextEffectTag;
import net.kyori.adventure.text.minimessage.MiniMessage;
import net.kyori.adventure.text.minimessage.tag.resolver.TagResolver;

MiniMessage mm = MiniMessage.builder()
    .tags(TagResolver.resolver(
        TagResolver.standard(),
        TextEffectTag.RESOLVER
    ))
    .build();

Component text = mm.deserialize("<effect:rainbow>你好！</effect>");
```

## 十一、特效工作原理

```
1. 应用特效时，Oraxen 将每个字符设置为使用「特效专用字体」
   （例如彩虹使用 oraxen:effect/0）
2. 每个字符被着色为特效的「触发颜色」
   （例如彩虹的 #FD0D00）
3. 着色器匹配此确切颜色并应用视觉特效
4. 使用 24 位精确颜色匹配，极不可能与普通渐变冲突
```

## 十二、限制与注意事项

| 项目 | 说明 |
|------|------|
| 最大特效数 | 8 个特效槽位（ID 0-7） |
| Minecraft 版本 | 需要 1.21.4+ |
| 资源包冲突 | 可能与其他修改 `rendertype_text.vsh` / `rendertype_text.fsh` 的资源包冲突 |
| 文本阴影 | 带特效的文本阴影会被隐藏以避免视觉伪影 |
| 性能 | 特效在客户端 GPU 上运行，对服务器性能影响极小 |
| 触发颜色 | 不要在普通文本/消息中使用触发颜色 |

### 故障排除

| 问题 | 解决方案 |
|------|---------|
| 特效不工作 | 检查 `settings.yml` 中 `TextEffects.enabled: true`，确认 Minecraft 版本 >= 1.21.4 |
| 着色器编译错误 | 检查 GLSL 语法：缺少分号、变量名拼写、类型不匹配 |
| 特效随机触发 | 触发颜色出现在普通文本中，更换更独特的触发颜色 |
| 特效 ID 冲突 | 检查是否有重复 ID，确保总数不超过 8 个 |
| 文本不可见 | 检查 `texColor.a` 是否设置为 0，确保设置了可见颜色 |
| 应用更改 | 编辑 `text_effects.yml` 后在游戏内执行 `/oraxen reload all` |
