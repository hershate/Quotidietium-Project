# Oraxen 字形 (Glyphs) 配置模板

> 字形是带纹理的 Unicode 符号，可在聊天、物品名称、描述、计分板、Boss栏、操作栏等任何显示文本的地方使用。
>
> **配置文件位置：** `plugins/Oraxen/glyphs/` 目录下的任意 `.yml` 文件
>
> **位图配置位置：** `plugins/Oraxen/fonts.yml`

---

## 一、基础字形配置（简单表情/图标）

```yaml
# ============================================================
# 基础字形 - 最简单的单纹理字形
# 纹理文件应放在: plugins/Oraxen/pack/textures/ 目录下
# 纹理格式: PNG，建议 256x256 像素以内
# ============================================================

heart:                                  # 【必填】字形 ID，全局唯一标识符
  texture: default/chat/heart           # 【必填】纹理路径，相对于 pack/textures/，不加 .png 扩展名
  ascent: 8                             # 【必填】垂直偏移（像素），控制字形在文本行中的上下位置
  height: 8                             # 【必填】显示高度（像素），控制字形的缩放大小
  is_emoji: true                        # 【可选】是否出现在 /oraxen emojis 列表中，默认 false

  # ---- 外观配置（1.21.4+）----
  appearance:                           # 【可选】高级样式选项
    font: "minecraft:default"           # 【可选】自定义字体命名空间，默认 minecraft:default
    shadow_color: "#80000000"           # 【可选】阴影颜色，ARGB 十六进制格式 (1.21.4+)
    # 颜色格式说明:
    #   #AARRGGBB  完整格式（含透明度）
    #   #RRGGBB    RGB 格式（假定 FF 透明度）
    #   #RGB       短格式（扩展为 #FFRRGGBB）
    # 示例: #80000000 = 半透明黑色阴影

  # ---- 聊天使用配置 ----
  chat:                                 # 【可选】配置聊天中使用方式
    placeholders:                       # 【可选】聊天中的占位符列表
      - "<3"                            # 玩家在聊天中输入 <3 即显示此字形
      - ":heart:"
    permission: "oraxen.emoji.heart"    # 【可选】使用此字形所需的权限节点
    tabcomplete: true                   # 【可选】是否启用 Tab 补全 (1.19.3+)，默认 false
```

## 二、点位图字形（一张图片包含多个字形）

> 当你的 PNG 纹理由多个表情/图标组成时，使用位图方式可以在一张图上绑定多个字形。
> 这需要在 `fonts.yml` 中先定义位图，然后在字形配置中引用。

### 第一步：在 `fonts.yml` 中定义位图

```yaml
# 文件位置: plugins/Oraxen/fonts.yml
# ============================================================
# bitmaps 部分 — 定义所有多点阵图纹理
# ============================================================

bitmaps:
  example_bitmap:                       # 【必填】位图 ID，在字形配置中引用
    texture: example/example_bitmap     # 【必填】纹理路径，相对于 pack/textures/
    rows: 4                             # 【必填】位图的行数（垂直方向的表情数量）
    columns: 9                          # 【必填】位图的列数（水平方向的表情数量）
    ascent: 8                           # 【必填】应用于此位图所有字形的垂直偏移
    height: 8                           # 【必填】应用于此位图所有字形的显示高度

  # 可以定义多个位图
  icon_sheet:
    texture: icons/icon_sheet
    rows: 2
    columns: 8
    ascent: 12
    height: 12
```

### 第二步：在字形配置中引用位图

```yaml
# ============================================================
# 点位图字形 — 引用 fonts.yml 中定义的位图的特定格子
# ============================================================

example_glyph:                          # 【必填】字形 ID
  texture: default/chat/example_glyph   # 【必填】纹理路径（建议与位图路径一致或相关）
  bitmap:                               # 【必填】位图引用
    id: example_bitmap                  # 【必填】对应 fonts.yml 中定义的位图 ID
    row: 1                              # 【必填】行号（从 1 开始，从上往下数）
    column: 1                           # 【必填】列号（从 1 开始，从左往右数）
  # ascent 和 height 已在 fonts.yml 的位图定义中指定，此处无需重复
  # 如果在此设置，会覆盖位图中的默认值

  chat:
    placeholders:
      - ":example:"
```

## 三、网格字形（多字符大型图片）

> 当纹理大于 256x256 像素，或需要在聊天/描述中显示大型图片时，使用网格模式。
> 插件会自动将纹理分割到多个 Unicode 字符上显示。

```yaml
# ============================================================
# 网格字形 — 跨越多个字符的大型纹理
# ============================================================

large_banner:                           # 【必填】字形 ID
  texture: custom/large_banner          # 【必填】纹理路径
  ascent: 8                             # 【必填】垂直偏移
  height: 128                           # 【必填】显示高度（每个分块的高度）
  grid:                                 # 【必填】网格配置
    rows: 2                             # 【必填】图片跨越的行数
    columns: 3                          # 【必填】图片跨越的列数
  # 插件将自动分配 rows × columns 个 Unicode 字符
  # 本例中为 2×3 = 6 个字符

  # ---- MiniMessage 标签使用方式 ----
  # <glyph:large_banner>        显示所有字符，行之间用换行分隔
  # <glyph:large_banner:1>      仅显示第 1 个字符
  # <glyph:large_banner:1..4>   显示第 1 到第 4 个字符

# ---- 另一个网格字形示例：大型图标 ----
rank_badge:
  texture: ranks/elite_badge
  ascent: 8
  height: 64
  grid:
    rows: 1
    columns: 4                           # 1行4列 = 4个字符宽的大图标
  chat:
    placeholders:
      - ":elite:"
    permission: "oraxen.rank.elite"
```

## 四、动画字形

> 动画字形从 **PNG 精灵表**（帧垂直堆叠）渲染帧。
> 动画由 Oraxen 在资源包生成期间生成的着色器处理。
>
> 限制：每个动画最多支持 **16 帧**。
> 非循环动画（`loop: false`）与服务器时间同步播放。

```yaml
# ============================================================
# 动画字形 — 基于精灵表的帧动画
# 精灵表中的帧垂直堆叠（从上到下）
# ============================================================

loading:                                # 【必填】字形 ID
  texture: animations/loading           # 【必填】精灵表纹理路径（不加 .png）
  animation:                            # 【必填】动画配置
    frames: 12                          # 【必填】精灵表中的帧数（最大: 16）
    fps: 12                             # 【可选】每秒帧数，范围 1-127，默认 10
    loop: true                          # 【可选】是否循环播放，默认 true
    offset: 0                           # 【可选】水平像素偏移
  ascent: 8                             # 【必填】垂直偏移
  height: 16                            # 【必填】显示高度

  chat:
    placeholders:
      - ":loading:"

# ---- 非循环动画示例 ----
explosion_anim:
  texture: animations/explosion
  animation:
    frames: 8
    fps: 16
    loop: false                         # 不循环，播放一次后停止
  ascent: 8
  height: 16
```

## 五、引用字形（别名）

> 引用字形允许你**别名现有字形的一部分**（例如网格字形的一个子集），
> 无需生成新的提供器/纹理，使资源包更小。

```yaml
# ============================================================
# 引用字形 — 指向现有字形的别名，可选取子集
# ============================================================

gui_header:                             # 【必填】新的字形 ID（别名）
  reference:                            # 【必填】引用配置
    glyph: full_gui                     # 【必填】源字形 ID
    index: 1..3                         # 【必填】要包含的字符索引（从 1 开始）
    # index 格式:
    #   N       单个字符
    #   N..M    字符范围（含 N 和 M）

  chat:                                 # 【可选】此别名的独立聊天配置
    placeholders:
      - ":header:"
    permission: "gui.header"

# ---- 另一个引用示例 ----
gui_footer:
  reference:
    glyph: full_gui
    index: 4..6
  chat:
    placeholders:
      - ":footer:"
```

## 六、位移（Shift/偏移定位）

> 位移已内置于 Oraxen，使用自动注入到默认字体中的空格字体提供器。
> 不再需要 `glyphs/shifts.yml` 文件（已弃用，可安全删除）。

```yaml
# 位移通过 MiniMessage 标签或 PlaceholderAPI 使用，无需在字形配置中特别设置。

# ---- MiniMessage 标签使用方式 ----
# <shift:8>              向右移动 8 像素
# <shift:-8>             向左移动 8 像素
# <shift:211>            向右移动 211 像素

# ---- PlaceholderAPI 占位符 ----
# %oraxen_shift_8%       向右移动 8 像素
# %oraxen_neg_shift_8%   向左移动 8 像素
# %oraxen_shift_16%      向右移动 16 像素
# %oraxen_neg_shift_100% 向左移动 100 像素

# ---- 在字形配置中使用 shift 的组合示例 ----
# 在你其他插件的 GUI 标题中:
# "<shift:100><glyph:my_icon><shift:-50>文字内容"
```

## 七、字形标签选项速查

```
<glyph:heart>                 基本用法（自动应用配置的 shadow_color）
<g:heart>                     简写语法
<glyph:heart:c>               可着色 - 继承周围文本的颜色
<glyph:heart:colorable>       同上（完整名称）
<glyph:heart:s:#FF0000>       覆盖阴影颜色（红色）
<glyph:heart:shadow:#FF0000>  同上（完整名称）
<glyph:grid_icon:2>           选择特定字符索引（从 1 开始）
<glyph:grid_icon:1..4>        选择字符范围

# 多个选项可以组合:
<glyph:heart:c:s:#80FF0000>   可着色 + 自定义半透明红色阴影
```

## 八、完整示例：简单表情字形

```yaml
# ============================================================
# 文件: plugins/Oraxen/glyphs/emojis.yml
# ============================================================

# --- 爱心表情 ---
heart:
  texture: default/chat/heart           # 纹理文件: pack/textures/default/chat/heart.png
  ascent: 8
  height: 8
  is_emoji: true                        # 出现在 /oraxen emojis 列表中
  chat:
    tabcomplete: true
    placeholders:
      - "<3"
      - ":heart:"
    permission: "oraxen.emoji.heart"

# --- 笑脸表情 ---
smile:
  texture: default/chat/smile
  ascent: 8
  height: 8
  is_emoji: true
  chat:
    tabcomplete: true
    placeholders:
      - ":)"
      - ":smile:"

# --- 稀有度星标 ---
star_rare:
  texture: icons/star_rare
  ascent: 7
  height: 7
  # is_emoji 不设置，默认 false，不会出现在表情列表中。
  # 此字形仅用于物品的 name/lore 中。

# --- 位移到特定位置的字形 ---
# 在你的物品描述中使用:
# lore:
#   - "<shift:150><glyph:star_rare> 稀有物品"
```

## 九、完整示例：位图表情表

### `fonts.yml` 配置

```yaml
# ============================================================
# 文件: plugins/Oraxen/fonts.yml
# ============================================================

bitmaps:
  chat_emojis:
    texture: default/chat/emojis_sheet  # pack/textures/default/chat/emojis_sheet.png
    rows: 4                             # 4 行表情
    columns: 9                          # 9 列表情（共 36 个表情）
    ascent: 8
    height: 8
```

### 对应的字形配置

```yaml
# ============================================================
# 文件: plugins/Oraxen/glyphs/bitmap_emojis.yml
# ============================================================

# 引用位图第 1 行第 1 列的表情
emoji_laugh:
  texture: default/chat/emojis_sheet
  bitmap:
    id: chat_emojis
    row: 1
    column: 1
  chat:
    placeholders:
      - ":laugh:"
      - "XD"

# 引用位图第 2 行第 3 列的表情
emoji_cry:
  texture: default/chat/emojis_sheet
  bitmap:
    id: chat_emojis
    row: 2
    column: 3
  chat:
    placeholders:
      - ":cry:"
      - "T_T"

# 引用位图第 3 行第 5 列的表情
emoji_angry:
  texture: default/chat/emojis_sheet
  bitmap:
    id: chat_emojis
    row: 3
    column: 5
  chat:
    placeholders:
      - ":angry:"
      - ">_<"
```

## 十、PlaceholderAPI 集成

```
# 字形占位符格式: %oraxen_<字形ID>%
%oraxen_heart%                    # 显示 heart 字形
%oraxen_star_rare%                # 显示 star_rare 字形

# 在 LuckPerms 前缀中使用:
# /lp group default meta setprefix "%oraxen_heart% &c管理员 "

# 如果遇到占位符不解析的问题，使用 Utils-Expansion 进行二次解析:
# %utils_parse:2_luckperms_prefix%
```
